# rzc — 多语言 Rust 教学方言编译器

用你的母语编写 Rust 程序，由 rzc 自动翻译为标准 Rust 并编译运行。

```rust
// src/main.zh —— 中文 Rust 教学方言
函数 主函数() {
    让 可变 数量 = 10;
    数量 = 数量 + 1;
    打印行!("数量是：{}", 数量);
}
```

```
$ rzc run src/main.zh
数量是：11
```

## 功能特性

- **母语编程**：用中文关键字（`函数`、`让`、`如果`、`返回`…）编写完整 Rust 程序
- **多语言原生**：架构天生支持任意自然语言，内置中文语言包，可远程安装其他语言
- **扩展名自动识别**：`.zh`、`.ja`、`.ru` 等扩展名自动匹配对应语言包
- **中文错误诊断**：解析 rustc 输出翻译为中文，附带 💡 教学提示
- **所有权可视化**：配合 VS Code 扩展，用颜色高亮变量的移动与再使用
- **完整 LSP 支持**：补全、悬停、定义跳转、引用查找、重命名、代码操作
- **宏自动补全**：宏调用可省略感叹号（`打印行(...)`），转译时自动补全
- **渐进过渡**：`eject` 一键导出标准 Rust 代码

## 安装

```bash
cargo install rzc
```

## 快速开始

```bash
rzc init 我的项目
cd 我的项目
rzc run src/main.zh
```

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `rzc init <项目名>` | 创建新项目（内置中文语言包） |
| `rzc run <文件>` | 翻译并运行方言源码 |
| `rzc check <文件>` | 类型检查，输出中文教学诊断 |
| `rzc eject <文件>` | 导出为标准 Rust 代码 |
| `rzc lang` | 语言包管理（list / install / remove） |
| `rzc mapping auto <crate>` | 自动生成第三方库映射 |
