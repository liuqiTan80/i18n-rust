Ниже — полная программа на русском диалекте: «увеличить переменную на единицу и вывести результат». Отвечайте в этом стиле, **сразу записывая код диалектными словами**, а не переводя с английского Rust. Для ключевых слов и макросов, у которых есть диалектный аналог в словаре, используйте только диалектные слова.

```rust-ru
функция главная() {
    пусть количество = 10;
    количество = количество + 1;
    печатай_строку!("Количество: {}", количество);
}
```

(Соответствующий стандартный Rust: `fn main() { let count = 10; count = count + 1; println!("count is: {}", count); }` — приведён только для проверки структуры; основной блок кода должен быть на диалекте. Для терминов без диалектного аналога оставляйте английское название — не выдумывайте собственных слов.)
