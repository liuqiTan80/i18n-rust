# rzc: Многоязычный компилятор учебного диалекта Rust

Пишите программы на Rust на родном языке — rzc автоматически переведёт их в стандартный Rust и скомпилирует. Учитесь программировать, а не английский.

```rust
// src/main.ru — русский учебный диалект Rust
функция главная() {
    пусть изменяемый число = 10;
    число = число + 1;
    печатай_строку!("Число: {}", число);
}
```

```bash
$ rzc run src/main.ru
Число: 11
```

## 📦 Установка

Одна команда — и rzc доступен глобально:

```bash
cargo install rzc
```

> Требуется [инструментарий Rust](https://www.rust-lang.org/tools/install) (stable через rustup). Языковые пакеты встроены — дополнительная настройка не нужна.

Можно также собрать из исходников:

```bash
git clone https://github.com/liuqiTan80/i18n-rust.git
cd i18n-rust
cargo build --release --workspace                # бинарник: target/release/rzc
```

## 🚀 Быстрый старт

```bash
rzc init мой-проект
cd мой-проект
rzc run src/main.ru
```

`rzc init` создаёт готовый каркас проекта (`Cargo.toml` + `src/main.ru`) — можно сразу запускать.

## 🛠️ Основные команды

| Команда | Описание |
|---------|----------|
| `rzc init <имя>` | Создать новый проект |
| `rzc run <файл>` | Перевести и запустить диалектный исходник |
| `rzc check <файл>` | Проверка типов с учебной диагностикой на родном языке |
| `rzc eject <файл>` | Экспорт в стандартный код Rust |
| `rzc lang list` | Список установленных языковых пакетов |
| `rzc mapping auto <crate>` | Автоматическая генерация маппингов |

## ✨ Возможности

- **Программирование на родном языке**: полные программы на Rust с ключевыми словами вашего языка
- **Многоязычность**: 11 встроенных языковых пакетов (ru/zh/en/de/ja/es/fr/pt/ko/ar/hi), автоопределение по расширению файла
- **Локализованная диагностика**: `rzc check` переводит ошибки rustc на язык файла, с 💡 учебными подсказками
- **Визуализация владения**: расширение VS Code (поиск `i18n-rust`) подсвечивает перемещения и повторное использование переменных
- **Полная поддержка LSP**: автодополнение, наведение, переход к определению, поиск ссылок, переименование
- **Плавный переход**: `rzc eject` экспортирует стандартный код Rust в один шаг
