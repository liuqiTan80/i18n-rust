# rzc: Многоязычный учебный диалектный компилятор Rust

Пишите программы на Rust на своём родном языке. rzc автоматически переводит их в стандартный Rust, компилирует и запускает — программирование возвращается к логическому мышлению, а не к запоминанию английского.

```rust
// src/main.zh — Китайский учебный диалект Rust
函数 主函数() {
    让 可变 数量 = 10;
    数量 = 数量 + 1;
    打印行!("数量是：{}", 数量);
}
```

```bash
$ rzc run src/main.zh
数量是：11
```

## ✨ Возможности

- **Программирование на родном языке**: пишите полные программы на Rust с китайскими ключевыми словами (`函数`, `让`, `如果`, `返回`…)
- **Многоязычная архитектура**: нативная поддержка любого языка; китайский пакет встроен, остальные устанавливаются удалённо
- **Автоопределение по расширению**: `.zh`, `.ja`, `.ru` автоматически сопоставляются с языковым пакетом
- **Локализованная диагностика**: ошибки rustc переводятся с 💡 учебными подсказками; ошибки собственности визуализируются через JSON
- **Визуализация владения**: расширение VS Code подсвечивает перемещения (жёлтый), повторное использование (красный) и времена жизни (зелёный)
- **Полная поддержка LSP**: автодополнение, наведение, переход к определению, поиск ссылок, переименование
- **Автодополнение макросов**: можно опускать `!` при вызове макросов — добавляется автоматически
- **Плавный переход**: `eject` экспортирует стандартный код Rust одним шагом
- **Полный учебник**: 24 главы + 4 приложения, от новичка до комплексного проекта

## 📦 Установка

### Через crates.io (рекомендуется)

```bash
cargo install rzc
```

### Из исходников

```bash
# Китайское зеркало
git clone https://gitcode.com/tan80/zrRust.git
# Международное
git clone https://github.com/liuqiTan80/i18n-rust.git

cd zrRust или i18n-rust
cargo build --release --workspace
```

## 🚀 Быстрый старт

```bash
rzc init мой-проект
cd мой-проект
rzc run src/main.zh
```

## 🛠️ Команды

| Команда | Описание |
|---------|----------|
| `rzc init <имя>` | Создать новый проект |
| `rzc run <файл>` | Перевести и запустить `.zh` код |
| `rzc check <файл>` | Проверка типов с учебной диагностикой |
| `rzc eject <файл>` | Экспорт в стандартный `.rs` |
| `rzc lang list` | Список установленных языковых пакетов |
| `rzc lang install <источник>` | Установить языковой пакет |
| `rzc lang remove <код>` | Удалить пользовательский языковой пакет |
| `rzc mapping auto <crate>` | Автогенерация маппингов сторонних crate |

## 🌍 Управление языковыми пакетами

rzc поставляется с китайским языковым пакетом (115+ ключевых слов, 496 маппингов стандартной библиотеки, 53 перевода кодов ошибок).

- **Автоопределение**: `main.zh` — китайский, `main.ja` — японский
- **Удалённая установка**: загрузка с GitCode, резерв — GitHub
- **Локальная установка**: `rzc lang install ./языковой-пакет`

## ❓ FAQ

**Q: Почему макросы можно вызывать без восклицательного знака?**
Чтобы уменьшить запоминание для начинающих. Транспилятор добавляет `!` автоматически.

**Q: Можно ли использовать китайские имена переменных?**
Да. Rust поддерживает Unicode-идентификаторы.

**Q: Как установить другие языковые пакеты?**
`rzc lang install 日本語` (удалённо) или `rzc lang install ./каталог` (локально).
