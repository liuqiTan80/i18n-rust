# rzc: Многоязычный компилятор учебного диалекта Rust

> 🌍 **Пиши на Rust на своём родном языке.** · 10 языков · настоящий Rust, настоящий тулчейн · выпустись в любой момент через `rzc eject`

**rzc — многоязычный компилятор диалектов Rust**: вы пишете код на родном языке, rzc в реальном времени переводит его в стандартный Rust, официальный инструментарий компилирует и запускает программу, а все диагностические сообщения возвращаются на вашем языке с учебными подсказками. Учитесь программировать, а не английский.

- 🌍 **Не псевдокод**: код на родном языке полностью изоморфен стандартному Rust — компиляция, запуск, зависимости и экосистема на 100% настоящие
- 🎓 **Для начинающих**: сообщения об ошибках превращаются в подсказки «что делать дальше», а не в стену английского текста
- 🚪 **Выпуск в любой момент**: `rzc eject` в один шаг экспортирует стандартный Rust — без привязки, полная совместимость с мейнстримом

```rust
// src/main.ru — русский учебный диалект Rust
функция главная() {
    пусть изменяемый число = 10;
    число = число + 1;
    печатай_строку!("Число: {}", число);
}
```

```bash
$ rzc run src/main.ru
Число: 11
```

Ошиблись? Не страшно — ошибки тоже на родном языке:

```
Ошибка[E0384]: Невозможно дважды присвоить значение неизменяемой переменной `число`
  --> src/main.ru:3:5
💡 Если нужно изменить значение переменной, объявите её через `пусть изменяемый`.
```

Та же программа работает во всех 10 встроенных диалектах — например, на китайском (`函数 主函数()`, `打印行!`) или японском (`関数 主関数()`, `表示行!`). Стандартный Rust (`fn main()`) всегда принимается как есть.

## 📦 Установка

Два способа: **Способ 1 — установка из crates.io** (рекомендуется, подходит большинству); **Способ 2 — сборка из исходников** (свежая dev-версия или локальная сборка после правок rzc).

**Способ 1: установка из crates.io (рекомендуется)** — опубликовано на crates.io; при установленном инструментарии Rust хватает одной команды:

```bash
cargo install rzc        # получить из crates.io и собрать локально (1–3 минуты)
rzc --version            # номер версии — значит, успех
rzc init мой-проект && cd мой-проект && rzc run src/main.ru
```

> Языковые пакеты встроены — дополнительная настройка не нужна. Страница крейта: <https://crates.io/crates/rzc>; обновление: `cargo install rzc --force`. Ещё нет инструментария Rust? Сначала «1.» ниже.

**Способ 2: сборка из исходников (для разработчиков)** — для свежей dev-версии или сборки после правок rzc. **Кратчайший путь** (при установленном инструментарии Rust — 4 команды до первой программы):

```bash
git clone https://github.com/liuqiTan80/i18n-rust && cd i18n-rust
cargo build --release --workspace   # около 1–3 минут
cargo install --path crates/cli     # чтобы rzc был доступен глобально (можно и ./target/release/rzc)
rzc init мой-проект && cd мой-проект && rzc run src/main.ru
```

Ниже — полная пошаговая инструкция для способа 2 (предварительные требования → сборка → проверка); пункт «1.» общий для обоих способов.

### Предварительные требования

| Инструмент | Назначение | Обязательно? |
|---|---|---|
| **Инструментарий Rust** (rustc + cargo) | Сборка самого rzc | ✅ Да |
| **git** | Получение исходников | ✅ Да (можно и ZIP) |
| **Интернет** | Загрузка зависимостей при первой сборке | ✅ Да (первый раз) |
| **Node.js 18+ и npm** | Сборка расширения VS Code | По желанию (только для IDE) |
| **rust-analyzer** | Бэкенд автодополнения/диагностики IDE | По желанию (только для IDE) |

### 1. Установка инструментария Rust

Рекомендуемый способ — [rustup](https://rustup.rs) (устанавливает rustc, cargo и rustup одной командой).

- **Linux / macOS** (в терминале):

  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```

  Затем выполните `source "$HOME/.cargo/env"` (или переоткройте терминал).

- **Windows**: скачайте [rustup-init.exe](https://rustup.rs) и следуйте мастеру (или выполните в PowerShell `winget install --id Rustlang.Rustup`).

Проверка (после переоткрытия терминала):

```bash
rustc --version   # например: rustc 1.98.0
cargo --version
```

### 2. Получение исходников и сборка

```bash
git clone https://github.com/liuqiTan80/i18n-rust.git
cd i18n-rust
cargo build --release --workspace
./target/release/rzc --version
```

Первая сборка загружает зависимости и компилирует все компоненты (1–3 минуты). Результат:

- `target/release/rzc` — консольный инструмент
- `target/release/i18n-rust-lsp` — языковой сервер (бэкенд расширения VS Code)

### 3. (По желанию) Сделать rzc глобально доступным

```bash
cargo install --path crates/cli   # локальная сборка и установка в ~/.cargo/bin
```

### 4. (По желанию) Установить rust-analyzer для функций IDE

```bash
rzc install toolchain --ra-only --force
```

Официальный standalone rust-analyzer устанавливается в `~/.rz/toolchain` — rzc и языковой сервер автоматически предпочитают его.

### 5. (По желанию) Сборка расширения VS Code

Требуются Node.js 18+ и npm ([nodejs.org](https://nodejs.org)):

```bash
cd tools/vscode-extension
npm ci
npm run package    # создаёт i18n-rust-<версия>.vsix
```

Установите `.vsix` через «Install from VSIX...» в VS Code — получите подсветку синтаксиса, автодополнение, диагностику, наведение и визуализацию владения; языковой сервер предоставляет `rzc install lsp` (он сам находит встроенный тулчейн).

### Полная настройка функций (по одной команде)

```bash
rzc install lsp          # языковой сервер (бэкенд автодополнения/диагностики/наведения VS Code)
rzc install toolchain    # встроенный официальный тулчейн (standalone rustc/cargo/rust-analyzer в ~/.rz/toolchain)
rzc doctor               # состояние окружения тулчейна (встроенный / PATH / сравнение версий)
```

После установки rzc и языковой сервер автоматически предпочитают встроенный тулчейн; однофайловые проекты вызывают rustc напрямую, без индекса cargo.

### Переменные окружения (необязательно, обычно не нужны)

| Переменная | Назначение |
|---|---|
| `RZ_LANG_DIR` | Каталог языковых пакетов (по умолчанию встроенные) |
| `RUST_ANALYZER_PATH` | Путь к rust-analyzer (при сбое автоопределения) |

Настройка VS Code `i18n-rust.serverPath` явно указывает путь к бинарнику языкового сервера (используется при сбое автоопределения).

### Обновление отдельного компонента тулчейна

| Сценарий | Команда |
|---|---|
| Обновить rustc/cargo (например, 1.98 → 1.99) | `rzc install toolchain --version 1.99.0 --force` |
| Обновить только rust-analyzer (без повторной загрузки 300 МБ) | `rzc install toolchain --ra-tag <тег-даты> --ra-only --force` |
| Показать текущие версии и состояние | `rzc doctor` |

### Смена редактора (VSCodium / Cursor и другие VS Code-совместимые)

Расширение i18n-rust (`.vsix`) совместимо со всеми VS Code-совместимыми редакторами; rzc, языковой сервер и тулчейн от редактора не зависят:

1. В новом редакторе: Расширения → «Install from VSIX» → выберите `i18n-rust-<версия>.vsix`;
2. Подключите компоненты в стандартные места (используя собранный rzc):
   ```bash
   rzc install lsp        # языковой сервер → ~/.cargo/bin
   rzc install toolchain  # встроенный тулчейн → ~/.rz/toolchain (онлайн; или скопируйте из офлайн-пакета распространителя)
   ```
3. Откройте файл `.ru` — и всё готово (расширение само найдёт сервер и тулчейн; можно переопределить через `RUST_ANALYZER_PATH` или настройку `i18n-rust.serverPath`).

### Для распространителей: офлайн-пакет релиза (раздача для учебных классов)

В репозитории есть скрипты упаковки в один заход (локальная сборка, пакет под текущую платформу — для Release / файловых хранилищ):

| Платформа | Команда | Артефакт |
|---|---|---|
| Linux / macOS | `./release-offline.sh` | `release/rzc-<версия>-linux/macos-<архитектура>.tar.gz` |
| Windows (PowerShell) | `.\release-offline.ps1` | `release/rzc-<версия>-windows-x86_64.zip` |

Предусловие: собранный release (шаг 2 выше) и один онлайн-запуск `rzc install toolchain --ra-only --force` (упаковщик скопирует rust-analyzer платформы в пакет).

Скрипт сам определяет платформу (Linux / Darwin / Windows); пакет содержит rzc, i18n-rust-lsp, rust-analyzer, 11 встроенных языковых пакетов (10 естественных языков + тождественный пакет `en`) и учебник — распакуйте и пользуйтесь (подробности — приложение D.5 учебника).

rzc init мой-проект        # создаёт каркас проекта (Cargo.toml + src/main.ru)

Три шага — и ваша первая программа на родном Rust работает.

## 🛠️ Основные команды

| Команда | Описание |
|------------------------------------|------------------------------------------------------|
| `rzc init <имя>` | Создать проект (версия тулчейна фиксируется по локальной; сразу готов к IDE) |
| `rzc run <файл>` | Перевести и запустить; предупреждения/ошибки/прогресс сборки — на родном языке |
| `rzc check <файл>` | Проверка типов с учебной диагностикой на родном языке |
| `rzc eject <файл>` | Экспорт в стандартный Rust (постепенный переход) |
| `rzc transpile <файл>` | Только перевод — стандартный Rust в stdout |
| `rzc cheat <язык>` | Шпаргалка «родной ↔ Rust» (`--markdown` для встраивания в документацию) |
| `rzc add <крейт>[@версия]` | Добавить зависимость (обёртка `cargo add` с подсказками родных маппингов) |
| `rzc doctor` | Диагностика окружения тулчейна (встроенный / PATH / сравнение версий) |
| `rzc lang list` | Список установленных языковых пакетов |
| `rzc lang install <код/каталог>` | Установить языковой пакет (удалённый репозиторий или локальный каталог) |
| `rzc lang search [слово]` | Поиск доступных для установки языковых пакетов |
| `rzc lang remove <код>` | Удалить установленный пользователем языковой пакет |
| `rzc mapping auto <крейт> [--target-version <версия>]` | Автогенерация родных маппингов стороннего крейта (AI/правила); фиксация базовой версии генерации |
| `rzc mapping check [цель]` | Проверка качества маппингов (дубликаты ключей / конфликты ключевых слов / конфликты между файлами / обязательные разделы) |
| `rzc mapping coverage [--lang <язык>]` | Оценка покрытия языкового пакета на реальном коде; список недостающих маппингов (запуск из корня репозитория) |
| `rzc mapping scaffold <источник> <цель>` | Скелет перевода для нового языка; `--provider deepseek` — авто-перевод через AI |
| `rzc crate search [слово]` | Поиск маппингов сторонних крейтов, которыми делится сообщество (реестр) |
| `rzc crate install <крейт> --lang <язык>` | Установить один маппинг из реестра в глобальный языковой пакет |
| `rzc crate list` | Список установленных маппингов сообщества |
| `rzc crate remove <крейт> --lang <язык>` | Удалить установленный маппинг сообщества |
| `rzc crate update` | Повторно загрузить все установленные маппинги по манифесту (получить обновления) |
| `rzc crate publish <крейт> --lang <язык>` | Опубликовать локальные маппинги в реестр (сначала пройти контроль качества) |
| `rzc install <lsp\|toolchain>` | Установка сопутствующих компонентов (языковой сервер / встроенный официальный тулчейн) |

Полный справочник — [Приложение D: шпаргалка команд rzc (кит.)](tutorials/附录D：rzc命令速查.md).

## ✨ Возможности

### Программирование на родном языке

Пишите полные программы с русскими ключевыми словами (`функция`, `пусть`, `если`, `матч`…) и родной стандартной библиотекой (`строка`, `вектор::новый()`, `используй стандарт::коллекции::словарь`). Макросы, времена жизни, обобщения и трейты — всё поддерживается.

### 10 встроенных языков

| Язык    | Расш. | Язык      | Расш. |
|---------|-------|-----------|--------|
| 中文    | `.zh` | Español   | `.es`  |
| Deutsch | `.de` | Français  | `.fr`  |
| 日本語  | `.ja` | Português | `.pt`  |
| 한국어  | `.ko` | العربية   | `.ar`  |
| Русский | `.ru` | हिन्दी    | `.hi`  |

Сам Rust написан на английском, поэтому английский не входит в число учебных диалектов (тождественные маппинги не имеют учебной ценности); в каталоге языковых пакетов есть отдельный тождественный пакет `en` (расширение `.en`) — для сценариев тождественного маппинга и английских UI-строк. 10 естественных языков выше определяются по расширению файла и могут смешиваться в одном проекте.

### Учебная диагностика

- **Двойной перевод: коды ошибок + сообщения**: покрывает коды rustc, предупреждения lint без кодов и help-фразы
- **Локализация имён типов**: `std::fmt::Display` → `стандарт::форматирование::отображаемый`
- **💡 Учебные подсказки**: к каждой ошибке — совет «что делать дальше»; к ошибкам владения — 📌 нарратив перемещения/заимствования
- **Подсказки по зависимостям**: обнаружение необъявленных сторонних крейтов и предложение `rzc add <крейт>`

### Полноценная IDE (расширение VS Code / Qoder)

Подсветка синтаксиса, умное автодополнение, документация при наведении, переход к определению, поиск ссылок, переименование, форматирование кода, запуск/проверка в один клик, автоконвертация полноширинных знаков препинания, AI-помощь в переводе.

### Локализация сторонних крейтов

`rzc mapping auto` извлекает публичный API установленных крейтов и генерирует родные имена (AI); для продакшн-маппингов базовая версия генерации фиксируется через `--target-version` (записывается в заголовок файла); маппинги сообщества проходят контроль качества `rzc mapping check`.

### Почему это не «игрушечный язык»

| | Типичные «родные» игрушки | rzc |
|---|---|---|
| Форма кода | Самодельный синтаксис или псевдокод | Полный изоморфизм стандартному Rust — локализованы только идентификаторы |
| Компиляция и запуск | Собственный интерпретатор / только трансляция | Официальные rustc/cargo — настоящая компиляция и запуск |
| Экосистема зависимостей | Закрытая или урезанная | Весь crates.io (`rzc add` + родные маппинги) |
| Опыт ошибок | Английский как есть или самодельные подсказки | Перевод + коды ошибок + учебные подсказки |
| Цена выхода | Переписывать с нуля | `rzc eject` в один шаг экспортирует стандартный Rust |

## 🏗️ Структура проекта и как это работает

```text
Исходник на родном языке (.ru)
   │  лексический перевод → замена путей модулей → замена псевдонимов   ← engine (не зависит от языка)
   ▼
Исходник на стандартном Rust
   │  cargo build / run (официальный тулчейн)
   ▼
JSON-диагностика → перевод кодов/сообщений + локализация типов + учебные подсказки → вывод на родном языке
```

| Каталог                    | Ответственность                                                                 |
|----------------------------|---------------------------------------------------------------------------------|
| `crates/engine`            | Языконезависимое ядро: конвейер перевода, управление маппингами, перевод диагностики, инкрементальный кэш, проверки безопасности Unicode |
| `crates/cli`               | инструмент командной строки `rzc` |
| `crates/lsp`               | `i18n-rust-lsp`: проксирует официальный языковой сервер (rust-analyzer), двусторонне переводя позиции и диагностику |
| `crates/engine/lang-packs` | 11 встроенных языковых пакетов (10 естественных языков + тождественный пакет `en`: ключевые слова / стандартная библиотека / пути модулей / переводы ошибок / UI-тексты) |
| `tools/vscode-extension`   | расширение VS Code / Qoder |
| `tools`                    | гейты и скрипты сборки: проверка учебника, регрессия бенчмарков, сборка сайта документации ([tools/README.md](tools/README.md)) |
| `tutorials`                | учебник на китайском в 26 главах с приложениями (переводы en/ja/ru в работе) |
| `book`                     | исходники сборки сайта документации (mdBook, [book/README.md](book/README.md)) |
| `docs`                     | справочные и dev-документы, [карта проекта](docs/project-map.md); операции и роадмап — [docs/strategy/](docs/strategy/README.md) |

**Принцип дизайна**: ядро не привязано ни к какому конкретному языку — добавить естественный язык = добавить один каталог языкового пакета (пакеты встраиваются при сборке). О портировании этой парадигмы на другие языки программирования (например, китайский Python) — см. [чертёж фреймворка диалектов](docs/dialect-framework-blueprint.md).

## 🤝Участие в проекте

- **Впервые здесь?** Начните с [карты проекта (справочник мейнтейнера)](docs/project-map.md) — «куда идти за X и как проверить правку»; окружение разработки и соглашения о коммитах — [CONTRIBUTING.md](CONTRIBUTING.md)
- **Гид по недостающим словам для разработчиков приложений**: [docs/missing-mapping-guide.md](docs/missing-mapping-guide.md) (как доопределять слова / кастомизировать маппинги по ходу написания приложения — для новичков)
- **Добавление языкового пакета**: [docs/contributing-lang-pack.md](docs/contributing-lang-pack.md) (включая AI-перевод через `rzc mapping scaffold`)
- **Маппинги сторонних крейтов**: [docs/third-party-mapping.md](docs/third-party-mapping.md)
- **Реестр совместного использования**: [docs/third-party-registry.md](docs/third-party-registry.md) (загрузка/скачивание маппингов сообщества)
- **Перевод учебника**: источник — `tutorials/`, сохраняйте структуру глав; панель прогресса — [translation-status.md](docs/translation-status.md)
- Перед отправкой убедитесь, что `make gate` полностью зелёный (эквивалент тестового гейта CI)
