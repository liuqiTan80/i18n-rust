## 1. 项目定位与核心愿景

### 1.1 定位

i18n-rust 是一个面向 Rust 教学的多语言方言编译器。它允许初学者使用自己的母语（如中文、日文、韩文等）编写 Rust 程序，在零英语障碍下学习编程概念和 Rust 思想。

### 1.2 核心愿景

- **教育优先**：让编程教育回归逻辑思维，而非英语记忆。
- **母语可执行**：学习者用母语编写的伪代码可直接编译运行。
- **渐进过渡**：掌握概念后可平滑切换到标准 Rust，保留全部生态能力。
- **多语言原生**：架构天生支持任意自然语言，不局限于中文。

### 1.3 关键设计原则

- **语言无关核心**：词法替换引擎只依赖语言包，不硬编码任何具体语言。
- **关键词一对一映射**：每种语言提供关键字到英文的映射表。
- **中文优先**：中文是第一官方支持语言，映射表质量最高，错误消息最完善。
- **教学友好错误**：诊断信息包含母语解释、学习建议和标准 Rust 对照。
- **版本锁定**：教学环境默认锁定 Rust 工具链版本，保证稳定性。

```text
│   │   ├── mapping_source.rs

│   │   ├── alias.rs
│   │   └── mapping_manager.rs
│   ├── cli/                       # rzc 命令行工具
│   │   └── main.rs
│   └── lsp/                       # i18n-rust-lsp
│       ├── server.rs
│       ├── translation_cache.rs
│       └── response_map.rs
├── lang-packs/
│   ├── zh/                        # 中文语言包
│   │   ├── keywords.toml
│   │   ├── errors.toml
│   │   ├── stdlib.toml
│   │   └── module_paths.toml
│   ├── en/                        # 英文语言包
│   ├── ja/                        # 日本語 (示例)
│   └── ko/                        # 한국어 (示例)
├── tutorials/
│   ├── 第一章：你好世界.md
│   └── ...
├── tools/
│   └── vscode-extension/          # vscode-i18n-rust
└── release/                       # 离线发布包产物
```

### 2.2 模块依赖关系

```text
┌─────────────────────────────┐
│        语言包 (数据)          │
│  关键字、错误、提示、别名     │
└──────────┬──────────────────┘
           │ 加载
┌──────────▼──────────────────┐
│    核心引擎 (i18n-rust-engine) │
│  词法替换、源映射、诊断框架    │
│  代码生成 (语言无关)          │
└──────────┬──────────────────┘
           │ 使用
    ┌──────┴──────┐
    │             │
┌───▼───┐   ┌────▼────┐
│ 命令行  │   │ LSP代理 │
│ 教学工具│   │ 教学IDE │
└────────┘   └─────────┘
```

- 核心引擎是纯库，不依赖任何语言包，只依赖 `rustc_lexer`, `syn`, `prettyplease` 等。
- 语言包是纯数据（TOML + 可选资源），可在运行时或编译时加载。
- 命令行工具和 LSP 代理加载特定语言包，并集成教学功能。

## 3. 语言包规范

语言包是包含以下文件的目录，例如 `lang-packs/zh/`：

### 3.1 文件结构

```text
zh/
├── lang_info.toml          # 语言元数据
├── keywords.toml           # 关键字映射
├── errors.toml             # 错误码及动态消息翻译
├── stdlib.toml             # 标准库标识符别名
├── module_paths.toml       # 模块路径映射
└── crates/                 # 第三方库映射
```

### 3.2 包信息.toml

```toml
[语言包]
名称 = "中文"
代码 = "zh"
目标语言 = "Rust"
版本 = "1.0"
最低引擎版本 = "0.1"
描述 = "中文 Rust 方言语言包，面向教学。"
```

### 3.3 关键字.toml

```toml
[关键字]
fn = "函数"
let = "让"
mut = "可变"
if = "如果"
else = "否则"
# ...
```

### 3.4 错误消息.toml

```toml
[E0308]
消息模板 = "类型不匹配：期望 `{期望}`，实际得到 `{实际}`"
教学提示 = "请检查变量类型是否与上下文要求一致。尝试使用 `作为` 进行类型转换。"
```

### 3.5 教学提示.toml

定义常见模式的母语教学注释，例如：

```toml
[模式."移动后使用"]
描述 = "你试图在值被移动后再次使用它。"
修复建议 = "考虑使用 `引用` 或 `克隆` 来避免移动。"
```

### 3.6 语言包加载接口

```rust
pub trait 语言包 {
    fn 获取关键字映射(&self) -> HashMap<String, String>;
    fn 获取错误消息(&self, 错误码: &str) -> Option<错误消息>;
    fn 获取教学提示(&self, 模式: &str) -> Option<String>;
    // ...
}

pub fn 加载语言包(路径: &Path) -> Box<dyn 语言包>;
```

## 4. 核心引擎模块（语言无关）

### 4.1 词法处理.rs

- **输入**：源代码字符串 + 关键字映射 `HashMap<String, String>`
- **输出**：标准 Rust 源代码字符串
- 完全复用先前设计的词法替换逻辑，但不内置任何关键字，全部由语言包提供。
- **接口**：

```rust
pub fn 转译源码(源码: &str, 关键字映射: &HashMap<String, String>) -> String;
```

### 4.2 源映射.rs

保持不变，生成原始母语代码与英文 Rust 代码之间的偏移映射。

### 4.3 诊断框架.rs

- 接收 `syn::Error` 或 `rustc` JSON 诊断，结合语言包的错误消息和教学提示，生成**教学诊断**结构。
- 每条诊断包含：母语错误描述、教学建议、标准 Rust 对照（方便查阅英文资料）。

### 4.4 代码生成.rs

使用 `syn` 和 `prettyplease` 格式化英文 Rust 代码，与语言无关。

## 5. 中文语言包

### 5.1 关键字覆盖

完整映射所有活动关键字（约 35 个）和保留关键字（约 20 个）。特别处理 `r#` 原始标识符。

### 5.2 错误消息中文化

优先翻译最常见的 50 个 Rust 错误码，覆盖初学者 90% 会遇到的情况。包含教学提示，用中文解释所有权、借用等概念。

### 5.3 教学提示系统

针对 Rust 特有的学习难点（移动、借用、生命周期、模式匹配等），为每种错误模式编写中文学习卡片。LSP 代理可在 VS Code 中以悬浮卡片形式展示。

## 6. 命令行教学工具

### 6.1 命令设计

- `i18n init <项目名> --语言=中文`：创建固定 Rust 版本的教学项目，自动生成 `.母语扩展名` 文件（如 `.zh`）。
- `i18n run`：翻译并执行（适合单文件教学脚本）。
- `i18n check`：类型检查，输出全中文诊断。
- `i18n eject`：导出标准 Rust 代码，展示母语与英文对照。
- `i18n serve`：启动本地教学游乐场。

### 6.2 版本锁定

`i18n init` 生成的项目包含 `rust-toolchain.toml`：

```toml
[toolchain]
channel = "1.75.0"   # 固定版本，确保长期可用
components = ["rustc", "cargo"]
```

同时生成 `Cargo.toml` 包含固定依赖版本。

## 7. LSP 代理与教学 IDE 集成

### 7.1 LSP 代理

- 加载指定语言包。
- 维护母语源码到英文虚拟文件的实时翻译缓存。
- 转发 LSP 请求到 rust-analyzer，并反向映射所有位置。
- 增强诊断：将 rust-analyzer 的英文诊断结合语言包转换为母语教学诊断。

### 7.2 VS Code 扩展功能

- **语法高亮**（基于 TextMate，支持多语言包切换）。
- **错误显示**在问题面板，附带"学习更多"链接。
- **所有权可视化**：在编辑器中高亮变量的移动、借用路径（需结合 rust-analyzer 的 span 信息，用装饰器实现）。
- **母语/英文对照视图**：并排显示母语代码和翻译后的标准 Rust 代码，帮助过渡学习。
- **语言包选择器**：在状态栏切换当前语言。

## 10. 第三方库与多语言生态

### 10.1 第三方库的母语别名

- 库作者可提供 `语言映射/中文.toml` 等文件，遵循语言包规范。
- 社区可维护常用库的中文别名仓库，教学环境默认加载该仓库。

### 10.2 多语言扩展

- 鼓励社区制作其他语言包，核心引擎无需改动。
- 语言包质量分级：官方维护中文包，社区贡献日、韩等包需经过评审。

## 11. 维护策略与版本锁定

### 11.1 教学稳定版

- 每学期/每年发布一个"教学长期支持版"（类似 Ubuntu LTS），锁定 Rust 工具链和语言包版本。
- 核心引擎向前兼容，语言包可独立更新。

### 11.2 自动化监控

- CI 每周检测最新 stable/nightly Rust 的关键字变化，若新增则自动向语言包仓库发 PR。
- 错误码映射覆盖度报告，追踪未翻译的编译器消息。

### 11.3 社区共建

- 语言包和教程翻译可通过 Crowdin 或 GitHub 协作完成。
- 核心引擎维护由项目核心团队负责。

## 12. 安全与健壮性

- **混淆字符检测**：词法分析前扫描母语源码，拒绝包含混淆 Unicode 的标识符。
- **临时文件安全**：LSP 代理在临时目录创建虚拟英文文件时，设置仅当前用户可读权限。
- **供应链安全**：语言包和插件加载进行完整性校验（可选签名验证）。

## 14. 附录：术语与约定

| 母语术语（中文） | 英文概念 | 说明 |
| --- | --- | --- |
| 函数 | `fn` | |
| 让 | `let` | |
| 可变 | `mut` | |
| 结构体 | `struct` | |
| 实现 | `impl` | |
| 特征 | `trait` | |
| 枚举 | `enum` | |
| 匹配 | `match` | |
| 如果 / 否则 | `if` / `else` | |
| 循环 | `loop` | |
| 当 | `while` | |
| 对于 … 在 | `for … in` | |
| 返回 | `return` | |
| 自身 / 自身类型 | `self` / `Self` | |
| 不安全 | `unsafe` | |
| 异步 / 等候 | `async` / `await` | |

### 通用约定

- 母语源码文件扩展名建议使用语言代码，如 `.zh`（中文）、`.ja`（日文）。
- 原始标识符 `r#` 机制保留，中文关键字前加 `r#` 可作为普通标识符。
- 所有符号（`{}`, `()`, `;` 等）保持半角不变，确保与 Rust 词法兼容。
- 本项目源代码使用中文标识符，但 Cargo 包名和 `Cargo.toml` 键名保留英文。
