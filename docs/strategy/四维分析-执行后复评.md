## （1）易用性

### 结论
命令面已经收敛且自解释（init/run/check/eject/lang/mapping/crate/install/doctor/cheat），
CLI 交互摩擦主要只剩"安装"一段。**当前第一摩擦仍是安装**：README.en 明言
"no prebuilt online installer"，全球新用户必须 rustup + 源码编译。

### 问题与措施（按优先级）

1. **【P0·维护者动作】crates.io 发布**：工程侧全部就绪（元数据/include 白名单/发布顺序），
   仅差 `cargo login <token>`。发布后 `cargo install rzc` 即全球一行安装，README.en
   安装章节同步改写为三种路径（cargo install / 下载二进制 / 源码编译）。
2. **【P0·维护者动作】Marketplace + OpenVSX**：package.json 元数据完整（publisher/
   repository/engines），`vsce package` 在本机一条命令；沙箱内存限制无法代跑。
3. **【P1】init 交互式语言选择**：locale 检测修复后（本次），下一步是 `init` 不带
   `--lang` 且 locale 不在 10 语言集合时，列出语言菜单而非静默回退。
4. **【P1】README 顶部演示 GIF**：三语言报错对照录屏（15 秒）仍是转化的最大缺口，
   需要屏幕录制（工具链就绪：`vhs` 或 OBS + `rzc` 实机）。
5. **【P2】ar/hi 终端体验标注**：`lang list` 与 README 标注"建议配合 VS Code 扩展"。

## （2）易学性

### 结论
教程 25 章且 CI 逐块验证是最大的学习资产，但**语言覆盖 = 中文**；`rzc cheat`
（本次新增）解决了"查映射"，还没解决"学路径"。

### 问题与措施

1. **【P0】英文教程**：AI 翻译正文 + 代码块保持原样（`verify-tutorials.py` 逐块
   编译验证是翻译安全护栏）。英文版是全球易学性的关键一跃，也是 ja/ko/es 版的
   复用模板。预计 2-3 天。
2. **【P1】mdBook 文档站**：聚合教程/附录/命令参考 + 语言切换，GitHub Pages 自动
   构建。文档骨架（教程/附录/术语表/贡献指南）已齐，只差组装。
3. **【P1】init 生成 LEARNING.md**：新项目骨架内置"从这里开始"（教程链接 +
   `rzc cheat` 提示），把 first-run 引导从控制台延伸到项目内。
4. **【P2】贡献指南英文化 + AI 翻译 SOP**：第 11 种语言的外部贡献路径。

## （3）可扩展性

### 结论
架构对全球目标是**就绪**的：语言无关引擎 + 数据驱动语言包 + 跨语言一致性门禁
（本次核验 10 语言 ui.toml 注册中心文案全部齐平）+ crate-registry 跨语言共享映射。
新增第 11 种语言的边际成本仍趋近于零。

### 问题与措施

1. **【P1】CLI 侧 OpenAI 兼容 provider**：`mapping auto` 仅 DeepSeek；抽象
   base_url/key/model 三环境变量与扩展侧对齐，全球用户才能真正用上 AI 生成映射。
2. **【P1】ui.toml 键英文字典**：从 zh/ui.toml + 使用处生成 `docs/ui-keys.md`，
   第 11 种语言贡献者的权威参考。
3. **【P2】main.rs 诊断管线区抽模块**（沿用 mapping_gen/diagnostic/response_map
   的既有模式）；server.rs 维持不拆。
4. **【P2】engine 显式 locale API**：`语言::set_language` 全局态对第三方嵌入不友好，
   出现嵌入需求再做。
5. **【备忘】third-party/index.json 的 `registry: "zrRust-crate-mappings"` 标识**：
   数据文件中的命名，与仓库改名解耦；建议后续注册中心数据 v2 时统一改为
   `i18n-rust-crate-mappings`（需同步 init-registry.sh 与消费端）。

## （4）可推广性

### 结论
品牌已统一（i18n-rust / rzc / "Write Rust in your native language."），双平台
同名同内容，二进制就绪——**全球传播的全部前置条件里，现在只剩"发布"和"素材"两项**。

### 问题与措施

1. **【P0】凭据类发布**（crates.io / Marketplace / OpenVSX）：见易用性 1-2，
   是推广内容投放的前置——文章里的安装命令依赖它。
2. **【P0】演示素材**：README GIF + B 站/YouTube 短视频（同一素材双语字幕）。
3. **【P1】全球渠道叙事**：dev.to → r/rust → Show HN → This Week in Rust；
   叙事框架用"native-language programming for everyone"（多语言并举，规避
   中文编程立场论战），差异化锚点 = 确定性 + 离线 + 编辑器闭环（AI 短板）。
4. **【P1】中文渠道**（docs/strategy/推广方案.md 全套）与全球渠道并行。
5. **【P2】教学机构试点**：离线包 + 教程打包直投 1-2 所职校，产生真实课堂信号。

## 六、一句话结论

**上一轮列的"最后一公里"清单已完成三分之二（品牌、速查、CHANGELOG、init
locale 缺省、双平台同步、release 二进制），剩余三件事——crates.io/Marketplace
发布（差 token）、演示 GIF（差录屏）、英文教程（差 2-3 天 AI 辅助翻译）——全部
没有工程阻塞。做完这三件事，"全球用户用母语写 Rust"就从口号变成一条可执行的
用户旅程：cargo install rzc → 母语 init → 母语报错 → cheat 速查 → eject 毕业。**
