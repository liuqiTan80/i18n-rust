# 发布准备清单（全球分发第 1 周执行项）

> 对应 docs/strategy/四维分析-全球用户.md 的"立即实施"清单。
> 以下为需要维护者凭据在沙箱外执行的步骤，工程侧已全部就绪。

## 1. crates.io 发布（~30 分钟）

前置：注册 crates.io 账号，`cargo login <API_TOKEN>`。

```bash
# 顺序固定（依赖关系），CI release.yml 亦可自动执行：
cargo publish -p i18n-rust-engine   # path 依赖自动转为版本依赖
cargo publish -p i18n-rust-lsp
cargo publish -p rzc                # 此后全球用户：cargo install rzc
```

发布前自检（已在本地通过）：
- [x] `repository`/`homepage`/`readme` 元数据统一（本次已改至 GitHub 规范地址）
- [x] `rzc cheat` 新命令入 CHANGELOG Unreleased
- [ ] `cargo publish --dry-run`（需网络，发布机执行）

## 2. GitHub Release 挂三平台二进制（~15 分钟）

```bash
git push origin main && git push gitcode main   # 双平台同步
git tag v0.7.1 && git push origin v0.7.1
# 或手动触发 release.yml（三平台构建产物自动上传）
```

## 3. VS Code Marketplace + OpenVSX（~1 小时含注册）

- Marketplace：Azure DevOps 组织 → Personal Access Token（Marketplace Manage 权限）
  ```bash
  cd tools/vscode-extension
  npx @vscode/vsce package
  npx @vscode/vsce publish        # 或 `vsce publish <version>`
  ```
- OpenVSX（VSCodium/Cursor 用户）：
  ```bash
  npx ovsx publish --pat <OPENVSX_TOKEN>
  ```
- 发布前核对 package.json：publisher（注册 publisher id）、repository.url、
  license 字段与 LICENSE 文件一致、icon 512px。
