## 1. crates.io 发布（~30 分钟）

前置：注册 crates.io 账号，`cargo login <API_TOKEN>`。

```bash
# 顺序固定（依赖关系），CI release.yml 亦可自动执行：
cargo publish -p i18n-rust-engine   # path 依赖自动转为版本依赖
cargo publish -p i18n-rust-lsp
cargo publish -p rzc                # 此后全球用户：cargo install rzc
```

发布前自检（已在本地通过）：
- [x] `repository`/`homepage`/`readme` 元数据统一（本次已改至 GitHub 规范地址）
- [x] `rzc cheat` 新命令入 CHANGELOG Unreleased
- [x] `cargo publish --dry-run`（需网络，发布机执行）——三 crate 0.8.2 已于 2026-09-21 正式发布（engine → lsp → rzc）

## 2. GitHub Release + GitCode Release 双平台（~15 分钟）

前置（GitCode 侧，仅需一次）：仓库 Secrets 配置 `GITCODE_TOKEN`
（GitCode 头像 → 设置 → 私人令牌，需 releases 权限）；未配置时
workflow 仅告警跳过 GitCode Release，其余产物不受影响。

```bash
git push origin main && git push gitcode main   # 双平台同步
git tag v0.8.2 && git push origin v0.8.2
# 或手动触发 release.yml（三平台构建产物自动上传）
```

发布后核验（维护者，~5 分钟）：
- [ ] GitHub Release：三平台产物 + `SHA256SUMS` 齐全
- [ ] GitCode Release（https://gitcode.com/tan80/i18n-rust/releases）：
      vsix 与 `SHA256SUMS` 附件齐全（rzc 离线包由 release-offline 脚本手动上传）
- [ ] 下载任一产物执行 `sha256sum -c SHA256SUMS` 校验通过
- [ ] 若 GITCODE_TOKEN 未配置：补配后在 Actions 页重跑 publish job（或重推 tag）

## 3. VS Code Marketplace + OpenVSX（~1 小时含注册）

- Marketplace：Azure DevOps 组织 → Personal Access Token（Marketplace Manage 权限）
  ```bash
  cd tools/vscode-extension
  npx @vscode/vsce package
  npx @vscode/vsce publish        # 或 `vsce publish <version>`
  ```
- OpenVSX（VSCodium/Cursor 用户）：
  ```bash
  npx ovsx publish --pat <OPENVSX_TOKEN>
  ```
- 发布前核对 package.json：publisher（注册 publisher id，当前为 `i18n-rust`）、
  repository.url、license 字段与 LICENSE 文件一致、icon 512px（当前 1024px ✓）。
- [x] 本地打包链路已验证（2026-09-25：`vsce package` → `i18n-rust-0.8.2.vsix`，
  21 文件 985KB，一次通过）
