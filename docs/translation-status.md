**翻译管线**（每个文件四步）：
1. AI 转创翻译正文（不逐字直译，按目标语言技术写作习惯重写）；
2. **代码块用读者母语方言**（核心原则：始终用母语编写代码）——标准 Rust は英語話者の母語方言；
   `fn main()` のまま、ja は `関数 主関数()`、ru はロシア語方言…各言語パックの対応表に従う。
   方言コードは `tools/dialect-convert.py --lang <lang>` で標準 Rust → 方言へ自動変換できる。
3. `python3 tools/verify-tutorials.py --dir tutorials/<lang> --lang <lang> --allowlist tools/expected-failures.json`
   が全コードブロックを実コンパイル検証（多言語対応：`--lang` で主関数頭・宣言語・拡張子を切替）。
4. 人工抽校后提交。

> 注：検証器・コンバータは rzc の多言語機能（crates/engine/lang-packs/）に依存。
