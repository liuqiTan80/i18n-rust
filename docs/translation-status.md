**翻译管线**（每个文件四步）：
1. AI 转创翻译正文（不逐字直译，按目标语言技术写作习惯重写）；
2. **代码块用读者母语方言**（核心原则：始终用母语编写代码）——标准 Rust 即英语读者的母语方言；
   `fn main()` 保持不变，ja 为 `関数 主関数()`，ru 为俄语方言——各按语言包对应表。
   方言代码可用 `tools/dialect-convert.py --lang <lang>` 从标准 Rust 自动转换。
3. `python3 tools/verify-tutorials.py --dir tutorials/<lang> --lang <lang> --allowlist tools/expected-failures.json`
   对全部代码块实机编译验证（多语言支持：`--lang` 切换主函数头、声明词与临时项目扩展名）。
4. 人工抽校后提交。

> 注：验证器与转换器依赖 rzc 的多语言功能（crates/engine/lang-packs/）。
> 2026-09-07 修复了 rzc 引擎缺陷（含多字节标识符的源码映射切片 panic——
> `文字列型::から(...)` 等触发），ja 在内的全部方言从此可编译。
