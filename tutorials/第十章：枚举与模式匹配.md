# 第十章：枚举与模式匹配

上一章学了结构体——把多个数据打包在一起。但有时候，一个值**只能是几种情况之一**。

比如一个方向：只能是东、南、西、北中的一个。或者一个选项：要么有值，要么没有。不可能"半个有值"。

这就是**枚举**的用武之地。

---

## 10.1 什么是枚举

> **生活类比**：枚举就像一个**自动售货机的按钮面板**——你只能按"可乐"、"雪碧"、"矿泉水"中的一个。每个按钮对应一种确定的选择，没有"半个可乐"这种模糊状态。枚举让你的代码**不可能表示非法的值**。

```
┌──── 售货机按钮 ────┐
│  ○ 可乐            │  ← 方向::东
│  ○ 雪碧            │  ← 方向::南
│  ○ 矿泉水          │  ← 方向::西
│  ○ 果汁            │  ← 方向::北
└────────────────────┘
  只能选一个，不能选"半个可乐"
```

**为什么需要枚举？** 因为用整数表示方向（0=东，1=南...）容易出错——你可以写 99，但那不是任何方向。枚举让你**只能**选择合法的值。

### 定义枚举

```rust
枚举 方向 {
    东,
    南,
    西,
    北,
}

函数 主函数() {
    让 朝向 = 方向::北;

    匹配 朝向 {
        方向::东 => 打印行!("向东走"),
        方向::南 => 打印行!("向南走"),
        方向::西 => 打印行!("向西走"),
        方向::北 => 打印行!("向北走"),
    }
}
```

逐行解释：

- 第 1-6 行：**`枚举 方向 { ... }`** 定义了四个可能的值——就像售货机的四个按钮
- 第 9 行：用 **`方向::北`** 访问枚举值——`::` 表示"属于这个类型"
- 第 11-16 行：用 **`匹配`** 处理每种情况——就像逐一检查每个按钮

```
匹配的执行流程：

朝向 = 方向::北
    │
    ├── 是东？── 否
    ├── 是南？── 否
    ├── 是西？── 否
    └── 是北？── 是 → 执行 "向北走"
```

## 10.2 带数据的枚举

枚举的每个变体可以**携带数据**——这是枚举比很多语言强大的地方。

**为什么需要携带数据？** 因为有时候你不仅需要知道"是什么类型"，还需要知道"具体数据是什么"。比如"消息"可以是退出、挪动、写文字——每种消息附带的数据不同。

```rust
枚举 消息 {
    退出,                          // 无数据
    挪动 { 横: 整数, 纵: 整数 },   // 类似结构体——带命名数据
    写(字符串),                    // 类似元组——带位置数据
    改颜色(整数, 整数, 整数),      // 多个值
}
```

```
┌── 消息 ──────────────────────────────────┐
│                                          │
│  退出 ─────────────── 无数据             │
│                                          │
│  挪动 { 横, 纵 } ─── 命名数据（像结构体） │
│                                          │
│  写(内容) ────────── 位置数据（像元组）   │
│                                          │
│  改颜色(红值,绿值,蓝值) ─ 多个值          │
│                                          │
└──────────────────────────────────────────┘
```

```rust
函数 主函数() {
    让 消息1 = 消息::退出;
    让 消息2 = 消息::挪动 { 横: 10, 纵: 20 };
    让 消息3 = 消息::写("你好".转字符串());
    让 消息4 = 消息::改颜色(255, 0, 0);

    处理消息(&消息1);
    处理消息(&消息2);
    处理消息(&消息3);
    处理消息(&消息4);
}

函数 处理消息(消息体: &消息) {
    匹配 消息体 {
        消息::退出 => 打印行!("退出"),
        消息::挪动 { 横, 纵 } => 打印行!("挪动到 ({}, {})", 横, 纵),
        消息::写(内容) => 打印行!("写入：{}", 内容),
        消息::改颜色(红值, 绿值, 蓝值) => 打印行!("颜色 RGB({},{},{})", 红值, 绿值, 蓝值),
    }
}
```

**什么是解构？** `匹配` 时写 `消息::挪动 { 横, 纵 }`，意思是"如果消息是挪动，就把里面的横、纵取出来放进两个变量"——就像拆开快递箱，把里面的东西拿出来。`消息::写(内容)` 同理：把携带的字符串取出来，命名为 `内容`。这种"把数据拆开取出来"的操作叫**解构**。

> 📌 **为什么变体叫 `挪动`？** 因为 `移动` 是中文 Rust 的**关键字**（对应英文 `move`，下一章讲所有权时会见到），不能用作名字。改叫 `挪动` 意思不变，还能避开关键字。

## 10.3 最重要的两个枚举

Rust 标准库有两个极其重要的枚举，你会天天用到：

### `选项`（Option）—— "有还是没有？"

> **类比**：你打开一个**快递箱**——要么里面有东西（`有些(物品)`），要么是空的（`无`）。Rust 没有 `null`，用 `选项` 安全地表示"可能没有值"。

**为什么不用 null？** 因为 null 会导致"空指针异常"——你以为里面有东西，其实是空的。`选项` 强制你检查"到底有没有"，避免这种错误。

```rust
函数 查找用户(编号: 整数) -> 选项<字符串> {
    如果 编号 == 1 {
        选项::有些("小明".转字符串())
    } 否则 {
        选项::无
    }
}

函数 主函数() {
    让 用户 = 查找用户(1);

    匹配 用户 {
        选项::有些(名字) => 打印行!("找到：{}", 名字),
        选项::无 => 打印行!("未找到"),
    }
}
```

逐行解释：

- 第 1 行：函数返回 `选项<字符串>`——意思是"可能有字符串，也可能没有"
- 第 2-3 行：编号是 1 时，返回 `有些(...)`——箱子里有东西
- 第 4-5 行：否则返回 `无`——箱子是空的
- 第 12-15 行：用匹配检查——有值就取出名字，没值就显示"未找到"

> **为什么必须用匹配？** `选项` 像一个"密封的箱子"——你不能直接拿出里面的东西，必须先打开检查（匹配或如果让）。这样编译器强制你考虑"可能没有值"的情况，就不会忘。

### `结果`（Result）—— "成功还是失败？"

> **类比**：你去银行办事——要么**办成了**（`成功(结果)`），要么**被拒绝了**（`错误(原因)`）。Rust 不用异常，用 `结果` 让每个可能失败的操作都明确告诉你结果。

```rust
函数 安全除法(甲: 浮点数, 乙: 浮点数) -> 结果<浮点数, 字符串> {
    如果 乙 == 0.0 {
        结果::错误("除数不能为零".转字符串())
    } 否则 {
        结果::成功(甲 / 乙)
    }
}

函数 主函数() {
    匹配 安全除法(10.0, 3.0) {
        结果::成功(数值) => 打印行!("结果：{}", 数值),
        结果::错误(错误信息) => 打印行!("错误：{}", 错误信息),
    }
}
```

逐行解释：

- 第 1 行：返回 `结果<浮点数, 字符串>`——成功时返回浮点数，失败时返回字符串
- 第 2-3 行：除数为零时返回错误
- 第 4-5 行：否则返回成功的结果

## 10.4 如果让（if let）

当你只关心一种情况时，用 **`如果让`** 比 `匹配` 更简洁：

**为什么需要 `如果让`？** 因为有时候你只关心一种情况。比如你只想知道"有没有值"，不关心"没有值时怎么办"。用匹配写起来太啰嗦。

```rust
函数 主函数() {
    让 数值 = 选项::有些(42);

    // 用匹配（完整但冗长）
    匹配 数值 {
        选项::有些(数) => 打印行!("值是 {}", 数),
        _ => (),  // 其他情况什么都不做
    }

    // 用如果让（简洁）
    如果让 选项::有些(数) = 数值 {
        打印行!("值是 {}", 数);
    }
}
```

逐行解释：

- 第 4-8 行：用匹配——必须写一个 `_` 分支处理"其他情况"（`_` 表示"任何东西"，在这里直接忽略不处理）
- 第 10-13 行：用 `如果让`——只关心 `有些(数)` 的情况，其他直接跳过

```
匹配：穷尽所有情况        如果让：只关心一种情况
┌──────────────┐         ┌──────────────┐
│ 匹配 数值 {  │         │ 如果让 选项  │
│   有些(数)=>…│         │   ::有些(数) │
│   _ => ()   │         │   = 数值 {   │
│ }           │         │   …          │
└──────────────┘         │ }           │
  必须处理所有情况        └──────────────┘
                           只处理关心的
```

### 加上 `否则`

```rust
函数 主函数() {
    让 数值: 选项<整数> = 选项::无;  // 类型标注：这是个装着整数的选项

    如果让 选项::有些(数) = 数值 {
        打印行!("值是 {}", 数);
    } 否则 {
        打印行!("没有值");
    }
}
```

> ✨ **小提示**：为什么这里要写 `: 选项<整数>`？因为 `无` 本身不携带任何信息，编译器猜不出它"装着什么类型"（就像空盒子看不出装过什么），所以我们要告诉它。之前写过类型标注的话，这里就是复习。

## 10.5 当让（while let）

**`当让`** 在匹配成功时持续循环：

**为什么用 `当让`？** 因为有些操作会反复返回 `选项`——有值时继续，没值时停止。比如从栈中弹出元素。

```rust
函数 主函数() {
    让 可变 栈 = 向量![1, 2, 3];

    当让 选项::有些(顶部) = 栈.弹() {
        打印行!("弹出：{}", 顶部);
    }
    打印行!("栈已空");
}
```

逐行解释：

- 第 2 行：创建一个向量当栈用
- 第 4 行：`栈.弹()` 从末尾取出一个元素——有值时返回 `有些(值)`，空时返回 `无`。注意 `弹()` 会**修改**栈本身（取出后就没了），所以 `栈` 必须写成 `让 可变`
- `当让` 在返回 `有些(值)` 时循环，返回 `无` 时停止——自动处理"弹出所有元素"的常见场景

输出：

```
弹出：3
弹出：2
弹出：1
栈已空
```

## 10.6 模式匹配语法大全

`匹配` 不仅能匹配枚举，还能匹配各种模式：

| 模式 | 匹配什么 | 示例 |
|------|---------|------|
| 字面量 | 具体的值 | `1`、`"你好"`、`真` |
| 变量名 | 任何值，并绑定为变量 | `数` |
| 通配符 | 任何东西（忽略） | `_` |
| 范围 | 一个区间 | `1..=5` |
| 解构枚举 | 枚举变体 | `选项::有些(数)` |
| `\|` | 多种情况 | `1 \| 2 \| 3` |
| 守卫 | 附加条件 | `数 如果 数 > 0` |

**模式是什么？** 模式就像"筛子"——`匹配` 从上到下依次拿值和每个模式比对，第一个匹配上的分支执行。比如 `1 | 2 | 3` 表示"1 或 2 或 3"；守卫 `数 如果 数 > 0` 表示"先绑定到变量 数，再检查 数 是否大于 0"。

```rust
函数 主函数() {
    让 数 = 3;

    匹配 数 {
        1 => 打印行!("一"),
        2 => 打印行!("二"),
        3..=5 => 打印行!("三到五"),        // 范围
        数 如果 数 > 0 => 打印行!("正数：{}", 数),  // 守卫
        _ => 打印行!("其他"),
    }
}
```

## 常见错误

### ❌ 匹配没有穷尽所有情况

```rust
枚举 颜色 { 红, 绿, 蓝 }

函数 主函数() {
    让 颜色值 = 颜色::红;
    匹配 颜色值 {
        颜色::红 => 打印行!("红色"),
        // ❌ 漏了 绿 和 蓝！编译器报错
    }
    // 修复：加上其他分支，或用 _ 兜底
}
```

### ❌ 忘记用 `::` 访问枚举值

```rust
函数 主函数() {
    // 让 朝向 = 方向::北;  // ✅ 正确
    让 朝向 = 北;           // ❌ 编译器不知道"北"是什么
}
```

### ❌ 对 `选项` 直接取值

```rust
函数 主函数() {
    让 数值 = 选项::有些(42);
    // 打印行!("{}", 数值);  // ❌ 不能直接打印 选项
    // 修复：先匹配取出里面的值
    如果让 选项::有些(n) = 数值 {
        打印行!("{}", n);  // ✅
    }
}
```

### 练习 2：简单计算器

用枚举表示四则运算（加、减、乘、除），写一个 `计算` 函数，返回 `选项<浮点数>`（除零时返回 `无`）。

<details>
<summary>参考答案</summary>

```rust
枚举 运算 {
    加(浮点数, 浮点数),
    减(浮点数, 浮点数),
    乘(浮点数, 浮点数),
    除(浮点数, 浮点数),
}

函数 计算(算式: 运算) -> 选项<浮点数> {
    匹配 算式 {
        运算::加(甲, 乙) => 选项::有些(甲 + 乙),
        运算::减(甲, 乙) => 选项::有些(甲 - 乙),
        运算::乘(甲, 乙) => 选项::有些(甲 * 乙),
        运算::除(甲, 乙) => {
            如果 乙 == 0.0 { 选项::无 }
            否则 { 选项::有些(甲 / 乙) }
        }
    }
}

函数 主函数() {
    打印行!("{:?}", 计算(运算::加(10.0, 5.0)));  // 有些(15)
    打印行!("{:?}", 计算(运算::除(10.0, 0.0)));  // 无
}
```
</details>

### 练习 3：链式调用选项

写一个函数 `取第一个字符(内容: &文本) -> 选项<字符>`，如果内容为空返回 `无`。然后链式调用：先取第一个字符，再判断是否是元音字母。

<details>
<summary>参考答案</summary>

```rust
函数 取第一个字符(句子: &文本) -> 选项<字符> {
    句子.逐字符().下一个()
}

函数 是否元音(字: 字符) -> 布尔 {
    匹配 字 {
        'a' | 'e' | 'i' | 'o' | 'u' => 真,
        _ => 假,
    }
}

函数 主函数() {
    让 内容 = "你好";
    如果让 选项::有些(首字) = 取第一个字符(内容) {
        如果 是否元音(首字) {
            打印行!("{} 是元音", 首字);
        } 否则 {
            打印行!("{} 不是元音", 首字);
        }
    }
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| `枚举` | 定义一个值的多种可能情况 |
| 带数据变体 | 每个变体可以携带不同类型和数量的数据 |
| `匹配` | 处理枚举的主要方式，必须穷尽所有情况 |
| `选项` | `有些(值)` / `无` —— 表示"有值或没有" |
| `结果` | `成功(值)` / `错误(原因)` —— 表示"成功或失败" |
| `如果让` | 简化只关心一种情况的匹配 |
| `当让` | 在匹配成功时持续循环 |
