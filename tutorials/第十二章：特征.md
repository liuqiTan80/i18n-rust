# 第十二章：特征

上一章学了泛型——写一次代码适用于多种类型。但泛型函数怎么知道类型 `T` 能做什么？如果 `T` 不能比较大小，你怎么写 `a > b`？

答案是**特征**——定义类型"能做什么"。

---

## 12.1 什么是特征

> **生活类比**：特征就像一张**岗位说明书**。"司机"这个岗位要求你会开车——不管你开的是卡车、轿车还是公交车，只要你会开车，你就是"司机"。特征定义"会做什么"，类型通过**实现**特征来证明自己"会"。

```
┌──── 岗位说明书：可摘要 ────┐
│  要求：                     │
│    函数 摘要(&自我) -> 字符串 │
│                             │
│  谁能应聘？                  │
│  ┌──────┐ ┌──────┐         │
│  │ 文章 │ │ 推文 │  ...    │
│  │ ✅   │ │ ✅   │         │
│  └──────┘ └──────┘         │
└─────────────────────────────┘
```

**为什么要用特征？** 因为你想写一个函数，接受"任何能生成摘要的东西"——文章能生成摘要，推文也能。你不想为每种类型写一遍。

### 定义特征

```rust
特征 可摘要 {
    函数 摘要(&自我) -> 字符串;
}
```

逐行解释：

- 第 1 行：**`特征 可摘要`** 定义了一个新的岗位说明书，名字叫"可摘要"
- 第 2 行：要求任何"应聘"这个岗位的类型，必须有一个 `摘要` 方法，接收自己，返回一段文字

注意：这里只写了方法的**签名**（名字、参数、返回类型），没有写具体实现。具体实现由每个类型自己决定。

---

## 12.2 实现特征

> **生活类比**：定义了岗位要求，现在要"应聘上岗"。每种类型用自己的方式完成要求——文章用标题和开头做摘要，推文用用户名和内容做摘要。

```rust
特征 可摘要 {
    函数 摘要(&自我) -> 字符串;
}

结构体 文章 {
    标题: 字符串,
    内容: 字符串,
}

// 文章用自己的方式实现"摘要"
实现 可摘要 对于 文章 {
    函数 摘要(&自我) -> 字符串 {
        格式化!("《{}》：{}...", 自我.标题, &自我.内容[..20])
    }
}

结构体 推文 {
    用户名: 字符串,
    内容: 字符串,
}

// 推文用自己的方式实现"摘要"
实现 可摘要 对于 推文 {
    函数 摘要(&自我) -> 字符串 {
        格式化!("@{}：{}", 自我.用户名, 自我.内容)
    }
}

函数 主函数() {
    让 我的文章 = 文章 {
        标题: "入门教程".转字符串(),
        内容: "这是一篇关于编程的入门教程...".转字符串(),
    };
    让 我的推文 = 推文 {
        用户名: "小明".转字符串(),
        内容: "今天学了新东西！".转字符串(),
    };

    打印行!("{}", 我的文章.摘要());
    打印行!("{}", 我的推文.摘要());
}
```

逐行解释：

- 第 9 行：**`实现 可摘要 对于 文章`** 意思是"文章应聘可摘要岗位"
- 第 10-12 行：文章的摘要方式是"标题加内容的前 20 个字符"
- 第 21 行：**`实现 可摘要 对于 推文`** 推文也应聘同一个岗位
- 第 22-24 行：推文的摘要方式不同——"用户名加完整内容"
- 第 34-35 行：虽然调用方式一样（都是 `.摘要()`），但不同类型的实现方式不同

```
同样的方法，不同的实现：

文章.摘要() → "《入门教程》：这是一篇关于编..."
推文.摘要() → "@小明：今天学了新东西！"
     ↑ 同一个方法名，不同内容
```

## 12.3 特征作为参数

特征最大的作用是**作为函数参数的要求**——接受"任何实现了某特征的类型"：

> **生活类比**：你在招聘会上说"我要招一个司机"——不管来的是卡车司机还是公交司机，只要有驾照就行。特征参数就是这个意思——"我不管你是什么类型，只要实现了这个特征就行"。

```rust
特征 可打印 {
    函数 描述(&自我) -> 字符串;
}

结构体 猫;
结构体 狗;

实现 可打印 对于 猫 {
    函数 描述(&自我) -> 字符串 { "喵喵喵".转字符串() }
}

实现 可打印 对于 狗 {
    函数 描述(&自我) -> 字符串 { "汪汪汪".转字符串() }
}

// 参数要求：任何实现了"可打印"的类型
函数 让动物说话(动物: &实现 可打印) {
    打印行!("动物说：{}", 动物.描述());
}

函数 主函数() {
    让 小猫 = 猫;
    让 小狗 = 狗;

    让动物说话(&小猫);  // 动物说：喵喵喵
    让动物说话(&小狗);  // 动物说：汪汪汪
}
```

逐行解释：

- 第 1-3 行：定义"可打印"特征——要求有 `描述` 方法
- 第 8-10 行：猫实现了可打印——描述是"喵喵喵"
- 第 12-14 行：狗实现了可打印——描述是"汪汪汪"
- 第 17 行：**`动物: &实现 可打印`** 意思是"参数可以是任何类型，只要它实现了可打印特征"
- 第 23-24 行：猫和狗都能传入，因为它们都实现了可打印

```
让动物说话 的门槛：

┌── 让动物说话 ──────────────────────┐
│  参数要求：&实现 可打印              │
│  含义：任何实现了"可打印"的东西     │
│                                    │
│  传入猫 → 猫实现了可打印 → ✅ 通过  │
│  传入狗 → 狗实现了可打印 → ✅ 通过  │
│  传入石头 → 没实现 → ❌ 编译器拒绝  │
└────────────────────────────────────┘
```

## 12.4 特征对象

如果你需要在**同一个列表**中存放不同类型，用**特征对象**：

> **生活类比**：普通列表只能放同一种东西——"一盒苹果"或"一盒橘子"。但特征对象就像一个**混合水果篮**——只要它是水果（实现了"水果"特征），就能放进去。

```rust
特征 形状 {
    函数 面积(&自我) -> 浮点数;
}

结构体 圆形 { 半径: 浮点数 }
结构体 方形 { 边长: 浮点数 }

实现 形状 对于 圆形 {
    函数 面积(&自我) -> 浮点数 {
        3.14159 * 自我.半径 * 自我.半径
    }
}

实现 形状 对于 方形 {
    函数 面积(&自我) -> 浮点数 {
        自我.边长 * 自我.边长
    }
}

函数 主函数() {
    // 用"盒子"把不同类型包起来，放进同一个列表
    让 图形们: 向量<盒子<动态 形状>> = 向量![
        盒子::新建(圆形 { 半径: 5.0 }),
        盒子::新建(方形 { 边长: 4.0 }),
        盒子::新建(圆形 { 半径: 3.0 }),
    ];

    对于 图形 在 图形们 {
        打印行!("面积：{}", 图形.面积());
    }
}
```

逐行解释：

- 第 1-3 行：定义"形状"特征——要求有 `面积` 方法
- 第 5-6 行：定义两种不同的形状
- 第 8-19 行：圆形和方形分别用自己的方式计算面积
- 第 23 行：**`盒子<动态 形状>`** 意思是"盒子里装的是任何实现了形状特征的东西"
- 第 24-27 行：圆形和方形虽然类型不同，但都能放进同一个列表
- 第 30 行：遍历时，每个图形都能调用 `.面积()`，因为编译器知道它们都实现了"形状"

```
向量<盒子<动态 形状>>：
┌──────────────────────────────────┐
│ [0] 盒子 → 圆形 { 半径: 5.0 }   │  → 面积 = 78.54
│ [1] 盒子 → 方形 { 边长: 4.0 }   │  → 面积 = 16.0
│ [2] 盒子 → 圆形 { 半径: 3.0 }   │  → 面积 = 28.27
└──────────────────────────────────┘
  不同类型放在同一个列表里！
  因为它们都"实现了形状特征"
```

**`动态`** 是什么意思？就是"运行时才知道具体类型"。编译器在编译时不知道盒子里是圆形还是方形，运行时才知道。就像你蒙着眼睛摸水果篮里的水果——摸到一个才知道是苹果还是橘子。

## 12.5 常用内置特征

Rust 自带了很多有用的特征。你不用自己定义，直接用就行：

| 特征 | 作用 | 怎么用 |
|------|------|--------|
| `可显示` | 用 `{}` 打印出好看的格式 | 自己实现 |
| `可调试` | 用 `{:?}` 打印调试信息 | 加 `#[派生(可调试)]` |
| `可克隆` | 能复制一份 | 加 `#[派生(可克隆)]` |
| `相等` | 能用 `==` 比较 | 加 `#[派生(相等)]` |

**为什么要知道这些？** 因为你想打印自己的结构体、比较两个结构体是否相等，都需要实现对应的特征。

### 用 `#[派生(...)]` 自动实现

手动实现这些特征太麻烦了。Rust 提供了一个快捷方式——`#[派生(...)]`，意思是"帮我自动实现"：

```rust
// 这一行的意思是：帮我自动实现"可调试"、"可克隆"、"相等"
#[派生(可调试, 可克隆, 相等)]
结构体 点 {
    x: 整数,
    y: 整数,
}

函数 主函数() {
    让 p1 = 点 { x: 1, y: 2 };
    让 p2 = p1.克隆();  // 复制一份
    打印行!("{:?}", p1);       // 点 { x: 1, y: 2 }
    打印行!("相等？{}", p1 == p2);  // 相等？真
}
```

逐行解释：

- 第 2 行：**`#[派生(可调试, 可克隆, 相等)]`** 自动为"点"实现三个特征
- 第 3-6 行：定义"点"结构体
- 第 10 行：`.克隆()` 复制了一个一模一样的点
- 第 11 行：`{:?}` 用"可调试"特征打印详细信息
- 第 12 行：`==` 用"相等"特征比较两个点是否一样

## 常见错误

### 忘记实现特征

```rust
特征 可打招呼 { 函数 你好(&自我); }
结构体 猫;
// 忘记为猫实现可打招呼！
函数 主函数() {
    让 c = 猫;
    // c.你好();  // ❌ 编译器报错：猫没有实现可打招呼
}
```

### 在列表中混放不同类型

```rust
结构体 猫; 结构体 狗;
函数 主函数() {
    // ❌ 猫和狗类型不同，不能放在同一个列表
    // 让 动物们 = 向量![猫, 狗];

    // ✅ 修复方法：用特征对象
    // 让 动物们: 向量<盒子<动态 动物特征>> = ...
}
```

### 方法签名不匹配

```rust
特征 可摘要 { 函数 摘要(&自我) -> 字符串; }
结构体 文章 { 标题: 字符串 }

实现 可摘要 对于 文章 {
    // ❌ 返回类型不对——特征要求返回"字符串"，你返回了"文字引用"
    // 函数 摘要(&自我) -> &文本 { &自我.标题 }

    // ✅ 返回字符串
    函数 摘要(&自我) -> 字符串 { 自我.标题.克隆() }
}
```

## 练习题

### 练习 1：实现可显示特征

为 `结构体 学生 { 姓名: 字符串, 成绩: 浮点数 }` 实现 `可显示` 特征，格式为 `"学生(姓名, 成绩分)"`。

<details>
<summary>参考答案</summary>

```rust
结构体 学生 { 姓名: 字符串, 成绩: 浮点数 }

实现 标准库::fmt::显示 对于 学生 {
    函数 fmt(&自我, f: &可变 标准库::fmt::格式化器) -> 标准库::fmt::结果 {
        写入格式化!(f, "学生({}, {}分)", 自我.姓名, 自我.成绩)
    }
}

函数 主函数() {
    让 s = 学生 { 姓名: "小明".转字符串(), 成绩: 95.5 };
    打印行!("{}", s);  // 学生(小明, 95.5分)
}
```
</details>

### 练习 2：特征对象列表

定义 `动物` 特征（有 `叫声` 方法），为 `猫` 和 `狗` 实现。创建一个列表并遍历打印叫声。

<details>
<summary>参考答案</summary>

```rust
特征 动物 {
    函数 叫声(&自我) -> &文本;
}

结构体 猫;
结构体 狗;

实现 动物 对于 猫 {
    函数 叫声(&自我) -> &文本 { "喵~" }
}

实现 动物 对于 狗 {
    函数 叫声(&自我) -> &文本 { "汪!" }
}

函数 主函数() {
    让 动物园: 向量<盒子<动态 动物>> = 向量![
        盒子::新建(猫),
        盒子::新建(狗),
        盒子::新建(猫),
    ];
    对于 动物 在 动物园 {
        打印行!("{}", 动物.叫声());
    }
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| 特征 | 岗位说明书——定义"能做什么" |
| 实现特征 | 应聘上岗——证明自己"会做" |
| `&实现 特征` | 参数接受任何实现了该特征的类型 |
| 特征对象 | 混合水果篮——不同类型放同一个列表 |
| `#[派生(...)]` | 自动实现常用特征，不用手写 |
