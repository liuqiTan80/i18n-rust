# 第十一章：泛型

上一章学了枚举——一个值只能是几种情况之一。但如果我想写一个函数，它**不限定类型**，整数能用，文字也能用，该怎么办？

你可以为每种类型写一遍。但那样太累了。

**泛型**就是解决这个问题的——写一次代码，适用于所有类型。

---

## 11.1 为什么需要泛型

> **生活类比**：泛型就像一个**万能榨汁机**。你不用为苹果买一个榨汁机、为橙子再买一个。同一个机器，放什么水果就榨什么汁。泛型让你写一个函数，传什么类型就处理什么类型。

假设你要写一个"找最大值"的函数：

> ✨ **先看懂两个小语法**（都是第三章、第七章学过的）：
> - `&[整数]` 表示"整数数组的切片引用"——把数组**借**给函数看，函数只读不改
> - `列表[0]` 取第一个元素；`*项` 是"解引用"——把借来的值取出来用

```rust
// 没有泛型，你得写好多遍：
函数 找最大_整数版(列表: &[整数]) -> 整数 {
    让 可变 最大 = 列表[0];
    对于 项 在 列表 {
        如果 *项 > 最大 { 最大 = *项; }
    }
    最大
}

// 浮点数版？再写一遍。
// 文字版？再写一遍。
// 太累了！
```

**为什么要用泛型？** 因为逻辑完全一样，只是类型不同。写一遍就够了。

---

## 11.2 泛型函数

用**尖括号**写一个"类型占位符"——"先占个位置，以后确定是什么类型"：

```rust
// T 就是那个占位符——"某种类型"
函数 找最大<T>(列表: &[T]) -> T
哪里 T: 可排序 + 可复制
{
    让 可变 当前最大 = &列表[0];
    对于 项 在 列表 {
        如果 项 > 当前最大 { 当前最大 = 项; }
    }
    *当前最大  // 从引用中复制一份返回，所以要求 T 能复制
}

函数 主函数() {
    让 整数列表 = [3, 1, 4, 1, 5, 9];
    打印行!("整数最大：{}", 找最大(&整数列表));  // 9

    让 浮点列表 = [3.1, 4.1, 2.7, 1.5];
    打印行!("浮点最大：{}", 找最大(&浮点列表));  // 4.1
}
```

逐行解释：

- 第 2 行：**`<T>`** 写了一个占位符 `T`，意思是"某种类型，我还不确定是哪种"
- 第 3 行：**`哪里 T: 可排序 + 可复制`** 告诉编译器——"T 必须是一种能比较大小、还能复制的类型"。不是所有东西都能比大小（比如"颜色"怎么比大小？），所以要加这个限制。**`+`** 表示"并且"：两个条件都要满足。`可复制`（英文 `Copy`）是说 T 要能"复印"自己一份——整数、浮点数这些简单数据都能复制
- 第 5 行：**`&列表[0]`** 取第一个元素的引用，作为比较的起点
- 第 6-8 行：逐个比较。**`项`** 是"借来的元素"（引用），直接拿它和当前最大比较；找到更大的就更新 `当前最大`
- 第 10 行：**`*当前最大`** 把引用里的值**复制**一份出来作为返回值——这正是需要 `可复制` 约束的原因
- 第 14 行：传入整数列表时，`T` 自动变成"整数"
- 第 17 行：传入浮点列表时，`T` 自动变成"浮点数"

> ✨ **小提示**：`列表: &[T]` 里的 `&` 表示"借用"——函数只**看**数据，不**拿走**数据。所以调用时写 `找最大(&整数列表)` 而不是 `找最大(整数列表)`（不写 `&` 会把整个数组送进函数，之后就用不了了）。

**泛型是怎么工作的？** 编译时，编译器会为每个用到的类型各生成一份专属代码——你用整数调用 `找最大`，它就生成整数版；用浮点调用，就生成浮点版。运行速度和不写泛型完全一样，但你只需要写一遍。

```
万能榨汁机的工作方式：

榨汁机<T>（T = 能榨汁的东西）
    │
    ├── 放入苹果 → 苹果汁 ✅
    ├── 放入橙子 → 橙汁   ✅
    └── 放入石头 → ❌ 编译器拒绝！石头不能榨汁
```

## 11.3 类型约束

> **生活类比**：你不能随便什么类型都传给泛型函数。就像榨汁机有要求——"能榨汁的东西"才行。类型约束就是告诉编译器：**"T 不是随便什么类型，它必须满足某些条件。"**

### 常见的约束

| 约束名称 | 意思是 | 能做什么 |
|---------|--------|---------|
| `可排序` | 能比大小 | 用 `>` `<` `>=` `<=` |
| `相等` | 能判断相等 | 用 `==` `!=` |
| `可显示` | 能打印出来 | 用 `打印行!("{}", ...)` |
| `可克隆` | 能复制 | 用 `.克隆()` |

> **`哪里` 是什么意思？** 它对应英文的 `where`（"在……条件下"）。`哪里 T: 可排序` 读作"在 **T 必须能比大小** 的条件下"。就像招聘要求——"在应聘者必须有驾照的条件下，才可以当司机"。

```rust
// ❌ 没有约束，不能比较大小
函数 找最大<T>(列表: &[T]) -> T {
    // 编译器不知道 T 能不能比大小，报错！
}

// ✅ 加上约束：T 必须能比大小
函数 找最大<T>(列表: &[T]) -> T
哪里 T: 可排序
{
    // 现在可以放心比较了
}
```

### 多个约束

如果 T 需要同时满足多个条件：

```rust
// 可显示 特征不在 Rust 的预导入里，用之前要先把它引入（就像借书前先办借书证）
使用 标准库::格式化::显示;

// T 必须能比大小，还能打印、还能复制
函数 找最大并打印<T>(列表: &[T]) -> T
哪里 T: 可排序 + 可显示 + 可复制
{
    让 可变 当前最大 = &列表[0];
    对于 项 在 列表 {
        如果 项 > 当前最大 { 当前最大 = 项; }
    }
    打印行!("最大值是：{}", 当前最大);
    *当前最大
}
```

## 11.4 泛型结构体

结构体也可以用泛型——"这个结构体的某个字段，类型先占个位"：

```rust
// T 是类型占位符
结构体 坐标<T> {
    横: T,
    纵: T,
}

函数 主函数() {
    // 整数坐标
    让 整数坐标 = 坐标 { 横: 10, 纵: 20 };
    打印行!("整数：{}, {}", 整数坐标.横, 整数坐标.纵);

    // 浮点坐标
    让 浮点坐标 = 坐标 { 横: 3.14, 纵: 2.71 };
    打印行!("浮点：{}, {}", 浮点坐标.横, 浮点坐标.纵);
}
```

逐行解释：

- 第 2 行：**`坐标<T>`** 表示"坐标"这个结构体有一个类型占位符
- 第 3-4 行：`横` 和 `纵` 都是 `T` 类型——它们**必须是同一种类型**
- 第 9 行：创建时传入整数，编译器自动推断 `T` = 整数
- 第 13 行：传入浮点数，`T` = 浮点数

```
坐标<整数>：
┌──────────────┐
│ 横: 10 (整数) │
│ 纵: 20 (整数) │
└──────────────┘

坐标<浮点数>：
┌──────────────────┐
│ 横: 3.14 (浮点)  │
│ 纵: 2.71 (浮点)  │
└──────────────────┘
```

### 多个类型参数

一个结构体可以有多个占位符：

```rust
// 两个占位符：钥匙类型和内容类型
结构体 键值对<钥匙, 内容> {
    名称: 钥匙,
    内容: 内容,
}

函数 主函数() {
    // 钥匙是整数，内容是文字
    让 键值对1 = 键值对 { 名称: 1, 内容: "苹果" };
    打印行!("名称={}，内容={}", 键值对1.名称, 键值对1.内容);

    // 钥匙是文字，内容是浮点数
    让 键值对2 = 键值对 { 名称: "温度", 内容: 36.5 };
    打印行!("名称={}，内容={}", 键值对2.名称, 键值对2.内容);
}
```

## 11.5 泛型枚举

枚举也可以带泛型。你已经见过两个了：

```
选项<T>：
┌────────────────────┐
│ 有些(值)           │  ← 值是什么类型？T 说了算
│ 无                 │
└────────────────────┘

结果<T, E>：
┌────────────────────┐
│ 成功(值)           │  ← 值类型 T
│ 错误(原因)         │  ← 错误类型 E
└────────────────────┘
```

`选项<整数>` 表示"可能有整数，也可能没有"。
`选项<文本>` 表示"可能有文字，也可能没有"。

> 📌 **回顾**：`选项` 是"快递箱"——要么 `有些(东西)`，要么 `无`；`结果` 是"银行回执"——要么 `成功(值)`，要么 `错误(原因)`。它们俩是第十章详细讲过的枚举，**本身自带泛型**！所以 `选项<整数>` 才能表示"装整数的快递箱"。

这就是泛型的威力——**同一个定义，不同的类型**。

## 11.6 泛型方法

给泛型结构体写方法时，也要带上类型占位符：

```rust
结构体 坐标<T> {
    横: T,
    纵: T,
}

// 注意这里也要写 <T>
实现<T> 坐标<T> {
    函数 获取横(&自我) -> &T {
        &自我.横
    }
}

// 为特定类型写专门的方法
实现 坐标<整数> {
    函数 到浮点(&自我) -> 坐标<浮点数> {
        坐标 {
            横: 自我.横 作为 浮点数,
            纵: 自我.纵 作为 浮点数,
        }
    }
}

函数 主函数() {
    让 点 = 坐标 { 横: 10, 纵: 20 };
    打印行!("横 = {}", 点.获取横());

    让 点2 = 点.到浮点();
    打印行!("浮点横 = {}", 点2.横);
}
```

逐行解释：

- 第 7 行：**`实现<T> 坐标<T>`** 表示"对所有类型的坐标"都适用的方法
- 第 8-10 行：`获取横` 方法返回横的引用。`&自我` 是"借自己"（第九章方法讲过）
- 第 14 行：**`实现 坐标<整数>`** 表示"只对整数坐标"适用的方法——注意它没有 `<T>`，因为类型已经写死了
- 第 15-20 行：`到浮点` 把整数坐标转成浮点坐标。`自我.横 作为 浮点数` 是"类型转换"（第三章讲过 `作为`）
- 第 25 行：调用通用方法
- 第 27 行：调用整数专属方法

> ✨ **小提示**：`实现<T> 坐标<T>` 里的第一个 `<T>` 是"先准备一个类型占位符"，第二个 `<T>` 是"把这个占位符用在这个结构体上"。就像先拿出一张空白名片（`<T>`），再填上职位（`坐标<T>`）。

## 常见错误

### 忘记加类型约束

```rust
// ❌ 没有约束，不能比较
函数 比较<T>(甲: T, 乙: T) -> 布尔 {
    甲 > 乙  // 编译器报错：T 不一定能比大小
}

// ✅ 加上约束
函数 比较<T>(甲: T, 乙: T) -> 布尔
哪里 T: 可排序
{
    甲 > 乙  // ✅
}
```

### 混用不同类型

```rust
结构体 坐标<T> { 横: T, 纵: T }

函数 主函数() {
    // ❌ 横 是整数，纵 是文字——但 T 只能是一种类型
    // 让 点 = 坐标 { 横: 10, 纵: "你好" };

    // ✅ 用两个类型参数
    // 结构体 自由坐标<横, 纵> { 横: 横, 纵: 纵 }
    // 让 点 = 自由坐标 { 横: 10, 纵: "你好" };
}
```

## 练习题

### 练习 1：泛型最大值

写一个泛型函数 `取较大值<T>(列表: &[T]) -> T`，能处理整数和浮点数列表。

> 💡 **提示**：这次返回值是"拥有的值"（`T`）而不是引用，所以需要 `T: 可克隆` 来复制列表里的元素；比较大小还需要 `可排序`。

<details>
<summary>参考答案</summary>

```rust
函数 取较大值<T>(列表: &[T]) -> T
哪里 T: 可排序 + 可克隆
{
    让 可变 当前最大 = 列表[0].克隆();
    对于 项 在 列表 {
        如果 *项 > 当前最大 { 当前最大 = 项.克隆(); }
    }
    当前最大
}

函数 主函数() {
    打印行!("整数最大：{}", 取较大值(&[3, 1, 4, 1, 5]));  // 5
    打印行!("浮点最大：{}", 取较大值(&[3.1, 4.1, 2.7]));  // 4.1
}
```
</details>

### 练习 2：泛型结构体

定义一个 `礼物<T>` 结构体（T 是类型占位符），有一个 `打开` 方法打印内容。

<details>
<summary>参考答案</summary>

```rust
使用 标准库::格式化::显示;  // 可显示 需要先引入才能用

结构体 礼物<T> {
    内容: T,
}

实现<T> 礼物<T>
哪里 T: 可显示
{
    函数 打开(&自我) {
        打印行!("打开礼物：{}", 自我.内容);
    }
}

函数 主函数() {
    让 礼物1 = 礼物 { 内容: "一本书" };
    让 礼物2 = 礼物 { 内容: 42 };
    礼物1.打开();  // 打开礼物：一本书
    礼物2.打开();  // 打开礼物：42
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| 泛型 | 万能榨汁机——写一次代码，适用于多种类型 |
| `<T>` | 类型占位符——"某种类型，以后确定" |
| `哪里 T: 约束` | 告诉编译器 T 必须满足什么条件 |
| 泛型结构体 | 结构体的某些字段类型先占位 |
| 泛型方法 | 给泛型结构体写方法时也要带占位符 |

**下一章**：你将学习**特征**——定义类型"能做什么"的岗位说明书。
