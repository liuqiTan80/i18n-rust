# 第十章：结构体

## 10.0 学习目标

读完这一章，你将能够：

1. 用**档案卡**比喻解释结构体的作用；
2. 定义结构体、造**实例**、用点号读写字段；
3. 用 **`实现`** 块给结构体装方法（第六章伏笔正式回收）；
4. 用 **`#[派生(Debug)]`** 让结构体可以 `{:?}` 打印；
5. 写**元组结构体**；
6. 用 **`..旧实例`** 更新语法快速造新实例；
7. 用结构体数组管理一批数据。

---

## 10.1 为什么需要结构体：散装数据的烦恼

假设要记录一个学生的信息：姓名、年龄、分数。用前面学的知识，只能这样：

```rust
让 姓名甲 = "小华";
让 年龄甲 = 12;
让 分数甲 = 95;

让 姓名乙 = "小刚";
让 年龄乙 = 13;
让 分数乙 = 76;
```

问题很明显：三个变量靠**命名约定**（都带"甲"）勉强算一组。学生一多，变量满天飞，谁和谁是一对全靠眼神。

💡 **比喻**：这就像全班同学的材料**散落在地上**——姓名纸一张、年龄条一张、分数单一张。我们需要的是**档案卡**：每个同学一张卡，卡上三个格子，各归各位。

📖 **结构体（Struct）**：自定义的"档案卡"类型，把相关数据打包在一起。对应英文关键字 `struct`（structure，结构）。

## 10.2 定义结构体

```rust
结构体 学生 {
    姓名: 字符串,
    年龄: 整数,
    分数: 整数,
}
```

读法："有一种新类型叫 `学生`，它有三栏：姓名（字符串）、年龄（整数）、分数（整数）。"

📖 **字段（Field）**：结构体里的每一栏数据。`学生` 有三个字段。

> ⚠️ **小心**：定义结构体只是**设计了卡片样式**，还没有任何真实数据。就像印刷厂做好了档案卡的模板——卡上还没有写任何人的信息。

## 10.3 造实例：填写一张卡

📖 **实例（Instance）**：按结构体样式造出来的具体一份数据——填好了内容的一张卡。

### 方式一：字面量直接填

```rust
让 小华 = 学生 {
    姓名: 字符串::从("小华"),
    年龄: 12,
    分数: 95,
};
```

格式：`类型名 { 字段名: 值, 字段名: 值, ... }`。**每个字段都必须填**，漏一个就报错（E0063）。

### 方式二：关联函数（构造器）

第六章见过：`实现` 块里没有 `自我` 的函数叫关联函数，专门用来造实例：

```rust
实现 学生 {
    函数 创建(姓名: 字符串, 分数: 整数) -> 学生 {
        学生 { 姓名: 姓名, 年龄: 12, 分数: 分数 }
    }
}

// 用起来：
让 小华 = 学生::创建(字符串::从("小华"), 95);
```

好处：造实例的逻辑（比如默认年龄）集中在一个地方，主函数里干干净净一行。

## 10.4 读写字段：点号

```rust
// 读
打印行!("{}今年{}岁", 小华.姓名, 小华.年龄);

// 写（实例必须是 让 可变）
让 可变 小华 = 学生 { ... };
小华.分数 = 100;
```

> ⚠️ **小心**：Rust 没有"只让某一个字段可变"的写法——要改任何字段，整个实例必须声明 `让 可变`。

## 10.5 方法：给档案卡装功能

`实现` 块里带 `自我` 参数的函数就是**方法**。现在正式收编第六章的伏笔：

```rust
实现 学生 {
    // 只读方法
    函数 是否及格(&自我) -> 布尔 {
        自我.分数 >= 60
    }

    // 修改方法
    函数 加分(&mut 自我, 加多少: 整数) {
        自我.分数 = 自我.分数 + 加多少;
    }
}

// 调用：
小华.加分(5);
打印行!("{}", 小华.是否及格());
```

方法比普通函数好在哪？**数据和行为在一起**。"及格判断"写在学生类型自己身上，而不是散落在某个角落的 `判断及格(某某学生)`。

## 10.6 调试打印：`{:?}` 和派生

试试直接打印结构体：

```rust
打印行!("{}", 小华);   // ❌ 报错：学生 类型不支持 {} 显示
```

`{}` 需要类型实现"显示"能力，结构体默认没有。两个办法，初学用第一个：

**贴 `Debug` 贴纸，用 `{:?}` 打印**：

```rust
#[派生(Debug)]
结构体 学生 { ... }

打印行!("{:?}", 小华);
```

输出：

```
学生 { 姓名: "小华", 年龄: 12, 分数: 95 }
```

`{:?}` 是**调试格式**——把所有字段一览无余，调试时的神器。字段多时想要多行展示，用 `{:#?}`：

```rust
打印行!("{:#?}", 天空蓝);
```

```
彩色 {
    红: 0,
    绿: 191,
    蓝: 255,
}
```

> 📖 **派生（Derive）**：让编译器自动为类型生成某些能力的实现，写作 `#[派生(...)]`。`Debug` 是调试打印能力。**注意：括号里用英文**（`Debug`、`Clone`），中文映射暂不覆盖派生宏。

## 10.7 元组结构体：不带字段名的打包

有时数据简单到不值得给每栏起名：

```rust
结构体 坐标(整数, 整数);

函数 主函数() {
    让 点 = 坐标(3, 5);
    打印行!("横：{}，纵：{}", 点.0, 点.1);
}
```

输出：`横：3，纵：5`

用 `.0`、`.1` 按位置访问（和第四章的元组一样）。适合两个字段以内、含义不言自明的场景（坐标、颜色……）。大多数情况还是用带字段名的普通结构体，可读性好。

## 10.8 更新语法：改几栏，抄其余

想基于旧卡造一张**大部分相同**的新卡：

```rust
让 小华二号 = 学生 { 分数: 88, ..小华 };
```

读法："新卡的分数是 88，**其余字段照抄小华**。"

> ⚠️ **所有权提醒**：`..小华` 会把旧卡里的字段**移动**到新卡（回忆第七章）。如果字段是 `字符串` 这类堆数据，`小华` 从此失效。想让两张卡都能用，先 `小华.克隆()`。

## 10.9 完整示例：班级花名册

结构体 + 方法 + 数组 + 循环，管理一个班级：

```rust
#[派生(Debug, Clone)]
结构体 学生 {
    姓名: 字符串,
    分数: 整数,
}

实现 学生 {
    函数 创建(姓名: 字符串, 分数: 整数) -> 学生 {
        学生 { 姓名: 姓名, 分数: 分数 }
    }

    函数 是否及格(&自我) -> 布尔 {
        自我.分数 >= 60
    }
}

函数 主函数() {
    // 数组里装三个学生实例
    让 班级 = [
        学生::创建(字符串::从("小华"), 95),
        学生::创建(字符串::从("小刚"), 58),
        学生::创建(字符串::从("小丽"), 88),
    ];

    // 打印花名册
    对于 下标 在 0..3 {
        打印行!("{:?}，及格：{}", 班级[下标], 班级[下标].是否及格());
    }

    // 找最高分
    让 可变 最高 = 0;
    让 可变 冠军 = 学生::创建(字符串::从("无"), 0);
    对于 下标 在 0..3 {
        如果 班级[下标].分数 > 最高 {
            最高 = 班级[下标].分数;
            冠军 = 班级[下标].克隆();
        }
    }
    打印行!("冠军是{}，{}分", 冠军.姓名, 冠军.分数);
}
```

## 10.10 逐行解释

- **第 1 行**：同时派生两个能力——`Debug`（能 `{:?}` 打印）和 `Clone`（能 `.克隆()`），逗号隔开。
- **第 2–5 行**：`学生` 结构体两个字段。
- **第 8–10 行**：关联函数 `创建`，一行造实例。
- **第 12–14 行**：只读方法 `是否及格`。
- **第 19–23 行**：**结构体数组**——每个元素都是一张学生卡。数组写法还是第三章那套 `[元素, 元素, ...]`。
- **第 26–28 行**：循环打印。`{:?}` 直接吐出整张卡的内容。
- **第 31–32 行**：`冠军` 先放一个"无"占位，防止空跑。
- **第 33–38 行**：经典"打擂台"找最大值。`班级[下标]` 从数组里拿卡；数组是只读的（没声明可变），不能把卡**拿走**，所以用 `.克隆()` 复制一份给 `冠军`。
- **第 40 行**：`冠军.姓名` 点号取字段。

## 10.11 运行结果

```
学生 { 姓名: "小华", 分数: 95 }，及格：true
学生 { 姓名: "小刚", 分数: 58 }，及格：false
学生 { 姓名: "小丽", 分数: 88 }，及格：true
冠军是小华，95分
```

## 10.12 常见错误与解决

### 错误一：E0063 漏填字段

```
错误[E0063]: 结构体 `{结构名}` 缺少字段 `{字段名}`
💡 初始化结构体时必须为所有字段赋值。
```

**解决**：补齐字段，或用 `..旧实例` 让其余字段抄旧的。

### 错误二：`{}` 打印结构体报错

`打印行!("{}", 小华)` 报"学生未实现显示特征"。**解决**：贴 `#[派生(Debug)]` 改用 `{:?}`；或打印具体字段 `小华.姓名`。

### 错误三：给不可变实例的字段赋值

```rust
小华.分数 = 100;   // ❌ 小华 不是 让 可变
```

报错 E0594。**解决**：声明处加 `可变`：`让 可变 小华 = ...`。

### 错误四：更新语法后旧实例失踪

`..小华` 抄走了字段，`小华` 里的 `字符串` 字段被移动，再用 `小华` 报 E0382。**解决**：先 `小华.克隆()` 再更新，或调整使用顺序。

### 错误五：派生写中文

`#[派生(调试)]` 找不到宏。**解决**：派生括号里用英文：`Debug`、`Clone`。

## 10.13 本章术语表

| 术语 | 一句话解释 |
|---|---|
| 结构体 | 自定义的打包类型，英文 struct |
| 字段 | 结构体里的每一栏数据 |
| 实例 | 按结构体造出的具体一份数据 |
| 关联函数 | 实现块里没有自我参数的函数，常用来造实例 |
| 构造器 | 见「关联函数」 |
| 方法 | 带自我参数、挂在类型上的函数 |
| 派生 | 让编译器自动生成特征实现，写作 `#[派生(...)]` |
| 调试输出 | `{:?}` 格式，配合 Debug 派生打印结构体 |
| 元组结构体 | 不带字段名、按位置访问的结构体 |
| 更新语法 | `..旧实例` 抄其余字段快速造新实例 |

> 📖 **提醒**：遇到不懂的词，随时回查全书开头的《总术语表》。

## 10.15 常见问题（FAQ）

**问：结构体和第四章的元组有什么区别？**

答：都是打包。元组字段**没名字**（`.0`、`.1` 访问），适合临时小组合；结构体字段**有名字**，适合正式的数据模型。元组结构体介于两者之间。

**问：结构体里能装结构体吗？**

答：能。比如 `班级` 结构体里装一个学生数组。数据可以层层嵌套，就像档案柜里套档案卡。第十五章学向量（能变长的集合）后会更灵活。

**问：`自我` 到底传的是什么？**

答：就是调用方法的那个实例。`小华.是否及格()` 里，`自我` = `小华`。写 `&自我` 是借用，写 `自我` 是拿走（消耗）。第八章的知识在这里全面复用。

**问：为什么造实例推荐用关联函数而不是字面量？**

答：两个好处——① 可以设默认值（比如 `创建` 里固定年龄）；② 可以加校验（比如页数不能为负）。项目大了，构造逻辑统一放关联函数里维护。

**问：`派生(Debug)` 的贴纸会影响程序速度吗？**

答：几乎不会。它只是编译期生成的打印代码，运行时你不用 `{:?}` 它就不执行。

**问：以后学的枚举（第十一章）和结构体什么关系？**

答：结构体是"**且**"——一张卡同时有姓名、年龄、分数；枚举是"**或**"——一个值只能是几种情况之一（及格/不及格/缺考）。下一章见分晓。

## 下一章预告

结构体解决了"多种数据打包"（且），但很多场景是"二选一、三选一"（或）：成绩等级要么优、要么良、要么差；硬币要么正面、要么反面。

第十一章 **《枚举与模式匹配》** 教你：

- 用 `枚举` 定义"多选一"类型；
- 给每个选项附带数据；
- `匹配` 的完全体：解构枚举、提取数据；
- `选项`（Option）——Rust 对付"可能没有值"的标准答案。
