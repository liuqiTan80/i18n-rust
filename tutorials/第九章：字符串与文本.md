# 第九章：字符串与文本

## 9.0 学习目标

读完这一章，你将能够：

## 9.1 两种文字类型

Rust 里"一段文字"有两种类型，初学者最容易在这里迷糊。

💡 **比喻**：
- **字符串引用**像**刻在石碑上的字**——出厂就定死，谁也不能改；
- **字符串**（String）像**写在笔记本上的字**——想加就加，想改就改（但本子得声明"可变"）。

| 类型 | 中文写法 | 英文 | 特点 | 住在哪里 |
|---|---|---|---|---|
| 字符串引用 | `字符串引用`（&文本） | &str | 不可变，写死的文字 | 石碑（程序内置区） |
| 字符串 | `字符串` | String | 可增长、可修改 | 仓库（堆） |

```rust
让 石碑 = "刻死的字";                 // 类型：字符串引用
让 可变 笔记本 = 字符串::从("可写的字"); // 类型：字符串
```

📖 **字符串（String）**：可以变长的文字类型，存在堆上，英文 String。
📖 **字符串引用（&str）**：借来的、不可变的文字，字符串字面量（双引号直接写的）就是它。

### 怎么选？

- 写死不变的（提示语、菜单项）→ 字面量即可（字符串引用）；
- 会变的、要拼接的（用户输入、程序组装的文本）→ `字符串`。

---

## 9.2 石碑不能改

试试修改字面量：

```rust
让 可变 石碑 = "刻死的字";
石碑.推入('！');   // ❌ 编译错误
```

报错大意：不能对 `字符串引用` 调用 `推入`。石碑就是石碑，`可变` 也救不了它——**类型决定能力**。想要能改的文字，用 `字符串::从("...")` 把碑文**抄到笔记本上**。

---

## 9.3 字符串的创建与长大

```rust
// 从字面量造一个字符串
让 可变 日记 = 字符串::从("今天我学了字符串");

// 推入：末尾加一个字符（单引号！）
日记.推入('，');

// 推入字符串：末尾加一段文字
日记.推入字符串("真好玩！");

打印行!("日记：{}", 日记);
```

输出：`日记：今天我学了字符串，真好玩！`

三个要点：

| 写法 | 含义 |
|---|---|
| `'，'` 单引号 | **一个字符**（字符类型） |
| `"..."` 双引号 | 一段文字（字符串引用） |
| `字符串::从("...")` | 把文字抄成可变的字符串 |

> ⚠️ **小心**：单引号和双引号不能混用。`推入` 收单个字符用单引号；`推入字符串` 收一段文字用双引号。

---

## 9.4 拼接：`格式化!` 一把梭

📖 **格式化!（format!）**：把值和模板拼成一个新字符串的宏。模板里的 `{}` 会被依次替换。它和 `打印行!` 长得几乎一样，区别是：**`打印行!` 显示到屏幕，`格式化!` 返回字符串**。

```rust
让 名字 = "小明";
让 问候 = 格式化!("你好，{}！", 名字);
打印行!("{}", 问候);
```

输出：`你好，小明！`

拼接文字就记住这一招，够用 90% 的场景。

---

## 9.5 查询

```rust
让 日记 = 字符串::从("今天我学了字符串，真好玩！");

打印行!("字节长度：{}", 日记.长度());
打印行!("包含'字符串'吗：{}", 日记.包含("字符串"));
打印行!("以'今天'开头吗：{}", 日记.以开头("今天"));
打印行!("以'！'结尾吗：{}", 日记.以结尾("！"));
```

输出：

```
字节长度：39
包含'字符串'吗：true
以'今天'开头吗：true
以'！'结尾吗：true
```

| 方法 | 英文 | 作用 | 返回 |
|---|---|---|---|
| `长度()` | len | 字节数（注意不是字数！） | 整数 |
| `包含(小段)` | contains | 里面有没有这段 | 布尔 |
| `以开头(小段)` | starts_with | 是不是以它开头 | 布尔 |
| `以结尾(小段)` | ends_with | 是不是以它结尾 | 布尔 |
| `查找(小段)` | find | 第一次出现的位置（字节号） | 选项（第十六章讲） |

## 9.6 字节 vs 字符：中文的大坑

看一个反直觉的数字："今天我学了字符串，真好玩！"数一数明明是 **13 个字**，`长度()` 却返回 **39**。

📖 **字节（Byte）**：计算机存储文字的最小单位，一个小盒子。
📖 **字符（Character）**：人眼看到的"一个字"。

💡 **比喻**：电脑用 UTF-8 编码存文字——英文字母 1 个盒子就够，**汉字要 3 个盒子**。`长度()` 数的是**盒子数（字节）**，不是字数。13 个汉字 × 3 盒子 = 39。

### 为什么这很危险：切片恐慌

第三章学过切片 `&数组[0..3]`。字符串也能切，但切的是**字节**：

```rust
让 句子 = "你好世界";
让 前半 = &句子[0..6];    // 前 6 字节 = 前两个汉字，✅
打印行!("前半：{}", 前半);
```

输出：`前半：你好`

但如果切到**汉字中间**：

```rust
让 句子 = "你好";
让 半个字 = &句子[0..1];   // ❌ 切开了"你"的第 1 个盒子
```

运行时恐慌：

```
thread 'main' panicked:
byte index 1 is not a char boundary; it is inside '你' (bytes 0..3) of `你好`
```

（"字节位置 1 不在字符边界上，它在'你'字内部"——半个盒子拼不成完整的字，Rust 宁可恐慌也不给你乱码。）

> ⚠️ **规则**：对中文字符串用下标切片，边界必须落在**完整汉字的缝隙**（每个汉字占 3 字节，所以 0、3、6、9… 是安全的缝）。拿不准就用 9.8 的 `逐字符()`。

## 9.7 加工：替换、裁剪、分割

```rust
// 替换：把甲段换成乙段，返回新字符串
让 原句 = 字符串::从("猫很可爱");
让 新句 = 原句.替换("猫", "熊猫");
打印行!("{}", 新句);          // 熊猫很可爱

// 裁剪：去掉首尾的空白
让 脏数据 = "  苹果,香蕉  ";
打印行!("[{}]", 脏数据.裁剪());   // [苹果,香蕉]

// 分割：按分隔符切成一段段
对于 项 在 "苹果,香蕉,橘子".分割(",") {
    打印行!("[{}]", 项);
}
```

输出：

```
熊猫很可爱
[苹果,香蕉]
[苹果]
[香蕉]
[橘子]
```

| 方法 | 英文 | 作用 |
|---|---|---|
| `替换(旧, 新)` | replace | 所有匹配处都换掉，返回新的 |
| `裁剪()` | trim | 去掉首尾空白（空格、换行等） |
| `分割(分隔符)` | split | 切成片段，配合 `对于` 逐个处理 |

> ✨ **裁剪 + 分割**是处理用户输入的黄金搭档：先洗掉首尾空白，再按逗号/空格切开。

## 9.8 逐字符遍历

想一个字一个字处理，用 `逐字符()`（英文 chars）：

```rust
对于 字 在 "Rust语言".逐字符() {
    打印行!("一个字：{}", 字);
}
```

输出：

```
一个字：R
一个字：u
一个字：s
一个字：t
一个字：语
一个字：言
```

英文、汉字一视同仁，每次吐一个完整字符——**永远不会切开汉字**，这是它比下标切片安全的地方。

---

## 9.9 完整示例：日记小助手

```rust
函数 主函数() {
    // —— 用 格式化! 拼文字 ——
    让 名字 = "小明";
    让 问候 = 格式化!("你好，{}！", 名字);
    打印行!("{}", 问候);

    // —— 可变字符串能长大 ——
    让 可变 日记 = 字符串::从("今天我学了字符串");
    日记.推入('，');
    日记.推入字符串("真好玩！");
    打印行!("日记：{}", 日记);

    // —— 查询 ——
    打印行!("字节长度：{}", 日记.长度());
    让 可变 字数 = 0;
    对于 _ 在 日记.逐字符() {
        字数 = 字数 + 1;
    }
    打印行!("字符个数：{}", 字数);
    打印行!("包含'字符串'吗：{}", 日记.包含("字符串"));

    // —— 裁剪 + 分割 ——
    让 脏数据 = "  苹果,香蕉,橘子  ";
    让 干净数据 = 脏数据.裁剪();
    对于 项 在 干净数据.分割(",") {
        打印行!("[{}]", 项);
    }

    // —— 逐字符 ——
    对于 字 在 "Rust语言".逐字符() {
        打印行!("一个字：{}", 字);
    }
}
```

## 9.10 逐行解释

- **第 3–5 行**：`格式化!` 把 `名字` 填进模板，返回**新的字符串**存进 `问候`。
- **第 8–10 行**：`字符串::从` 造可变字符串；`推入` 加单引号字符，`推入字符串` 加双引号文字。
- **第 14 行**：`长度()` 数**字节**：13 个汉字 × 3 = 39。
- **第 15–18 行**：数**字符**的办法——`逐字符()` 迭代，每吐一个 `字数` 加一。对比第 14 行，正好看清字节和字符的差别。
- **第 22–26 行**：先 `裁剪()` 洗掉首尾空格，再 `分割(",")` 按逗号切开，`对于` 逐个打印。
- **第 29–31 行**：`逐字符()` 混合英文和汉字也能正确一个个吐出。

```
你好，小明！
日记：今天我学了字符串，真好玩！
字节长度：39
字符个数：13
包含'字符串'吗：true
[苹果]
[香蕉]
[橘子]
一个字：R
一个字：u
一个字：s
```

重点对照：**字节长度 39 vs 字符个数 13**——同一个字符串，两种数法。

## 9.12 常见错误与解决

### 错误一：字面量不能改

对 `"..."` 调用 `推入` 等修改方法报错。**解决**：`字符串::从("...")` 抄一份可变的再改。

### 错误二：E0308 类型不匹配：期望 `字符串`，得到 `字符串引用`

```rust
函数 收下(话: 字符串) { }
收下("你好");   // ❌ 字面量是字符串引用
```

**解决**：`收下(字符串::从("你好"))`，或把函数参数改成 `字符串引用`（只读场景推荐后者，更省事）。

### 错误三：切片恐慌（byte index is not a char boundary）

切片位置落在汉字中间，运行时恐慌。**解决**：边界用 3 的倍数（对汉字），或改用 `逐字符()` 遍历。

### 错误四：单双引号混用

`推入("！")` 报错（收了字符却给了文字）；`推入字符串('！')` 同理。**解决**：字符单引号、文字双引号。

### 错误五：以为 `长度()` 是字数

中文场景下 `长度()` 是字节数。数汉字请用 `逐字符()` 计数。

## 9.13 本章术语表

| 术语 | 一句话解释 |
|---|---|
| 字符串 | 可增长、可修改的文字类型，英文 String |
| 字符串引用 | 借来的不可变文字，字面量就是它，英文 &str |
| 字符 | 人眼看到的一个字，单引号表示，英文 char |

| 推入字符串 | 末尾加一段文字，英文 push_str |
| 替换 | 所有匹配处换新内容，英文 replace |
| 裁剪 | 去掉首尾空白，英文 trim |
| 分割 | 按分隔符切成片段，英文 split |
| 逐字符 | 一次吐一个字符的迭代，英文 chars |

## 9.15 常见问题（FAQ）

**问：为什么 Rust 要搞两种文字类型，一种不行吗？**

答：各司其职省资源。石碑（字面量）编译时就刻进程序，不占仓库；笔记本（String）灵活但要花钱维护。只读场景用引用，零开销；需要加工才造 String。

**问：`字符串引用` 和第八章的"引用"是什么关系？**

答：`字符串引用`（&str）就是**引用**的一种——对一段文字的只读借用。第八章的 `&字符串` 是"对 String 的引用"，`字符串引用` 是"对文字本身的引用"。它们能互相配合：`&字符串` 传进需要 `字符串引用` 的地方通常也能用（自动转换）。

**问：怎么把数字变成文字？**

答：`格式化!("{}", 数字)` 最万能。第十五章学集合、第十六章学错误处理时，还会见到 `解析()`（文字变数字）的更多用法。

**问：切片这么危险，还要学吗？**

答：要。处理纯英文文本、协议数据时切片又快又常用。规则只有一条：**边界必须在字符缝上**。中文字符串拿不准就 `逐字符()`。

**问：单引号 `'你'` 占几个字节？**

答：字符类型本身固定 4 字节（能装下世界上任何一个字符），但存成 UTF-8 文本时，"你"占 3 字节。初学不用纠结这个细节。

**问：`分割` 出来的片段能直接存起来以后用吗？**

答：它们都是对原字符串的**借用**（字符串引用），原字符串活着它们才能用。要长期保存，需转成独立字符串（下章之后的技巧）。先学会"边分割边处理"的用法。
