# 第一章：你好，世界

欢迎来到中文 Rust 的世界！在这一章里，你将完成一件了不起的事——**用中文写出一个真正能运行的程序**。

如果你从来没写过代码，完全不用担心。这一章会从"什么是电脑""什么是键盘"讲起。

---

## 1.0 学习目标

读完这一章，你将能够：

1. 用大白话说清楚"编程"是什么。
2. 在电脑上安装好所有需要的工具。
3. 写出并运行你的第一个中文 Rust 程序。
4. 看懂程序报错时最常见的三种提示。

## 1.1 什么是编程

### 给机器人写纸条

想象你面前有一个机器人。它很听话，但很笨——它只会**一个字一个字地照你说的做**，不会猜你的心思。

比如你对它说"给我倒杯水"。如果没说"先拿杯子"，它可能就站在那里发呆。

**编程，就是给机器人写纸条**，把每一步都写得清清楚楚：先拿杯子，再走到饮水机前，按下出水键，水满后关掉……

> 💡 **比喻**：编程就像写一份超级详细的做菜步骤。你不能写"做碗面"，而要写"第一步：打开水龙头；第二步：接半锅水；第三步……"

你写的每张纸条，叫做一段**源码**。

> 📖 **源码**：就是"源代码"的简称，意思是你写给计算机看的文字。源头的源，代码的码。

写源码用的语言，叫做**编程语言**。

> 📖 **编程语言**：人和计算机沟通用的语言。就像人类有中文、英文、日文，编程语言也有很多种，各有各的特点。

### 为什么要有中文 Rust

大多数编程语言的关键字都是英文的。

> 📖 **关键字**：一门编程语言里**提前预留好**的、有特殊含义的词。就像学校的教室是"预留好"的，你不能把教室搬回家。编程语言里的关键字也是预留好的，它们各自有固定的任务。

比如英文 Rust 里的 `let`（创建变量）、`if`（如果）。对英语母语的人来说，这些词很自然。但对中文母语的人来说，一边要学编程逻辑，一边还要记英文单词，就像**同时学两门外语**，难度翻倍了。

**中文 Rust 就是来解决这个问题的。** 它让你用中文关键字写代码：

| 中文关键字  | 英文原名 | 含义                      | 生活中的类比                          |
|------------|----------|--------------------------|---------------------------------------|
| `函数`     | fn       | 定义一段可以反复使用的指令 | 给一套动作起个名字，喊名字就能做整套动作 |
| `让`       | let      | 创建一个"盒子"来存放数据   | 拿一个盒子，贴上标签，把东西放进去      |
| `如果`     | if       | 根据条件决定做不做某事     | 如果下雨，就带伞                       |
| `对于`     | for      | 对每个东西重复做某事       | 对于篮子里的每个苹果，都洗一遍          |
| `打印行`   | println  | 在屏幕上显示文字           | 对着屏幕"喊话"                        |

你写的代码看起来就像中文句子，但它是**真正可以运行的程序**：

```rust
函数 主函数() {
    打印行!("你好，世界！");
}
```

> ✨ **小提示**：先不用看懂上面这段代码的每个细节，1.6 节会一个字一个字地讲。现在你只需要知道：这几行中文，就是计算机能读懂的程序。

> ✨ **小提示**：在中文 Rust 中，宏（带感叹号的工具，马上会解释）后面的感叹号可以不写，工具会自动帮你补上。写 `打印行("你好")` 和 `打印行!("你好")` 都可以。本书统一写感叹号，方便你认出来。

## 1.2 先认识你的电脑

在写代码之前，我们先花几分钟认识一下电脑里的几个基本概念。如果你都已经熟悉，可以直接跳到 1.3。

### 文件：电脑里的"纸"

> 📖 **文件**：电脑里保存信息的基本单位，就像一张张纸。一张纸上可以写文章，也可以画图；一个文件里可以存文字，也可以存图片。

每个文件都有一个**文件名**，比如 `作文.txt`。点号后面的 `txt` 叫**扩展名**，表示这个文件是什么类型。

> 📖 **扩展名**：文件名里最后一个点后面的部分，告诉电脑"这是什么类型的文件"。比如 `.txt` 是普通文字文件，`.jpg` 是图片文件。我们这本书里写的代码文件，扩展名是 `.zh`（中文的"中"的拼音缩写）。

### 文件夹：电脑里的"抽屉"

> 📖 **文件夹**：用来装文件的"抽屉"，有的地方也叫"目录"。你可以把很多文件放进一个文件夹，就像把很多张纸放进抽屉里，方便整理。

### 键盘上最重要的几个键

写代码主要用键盘。这几个键你一定会用到：

| 键                    | 位置           | 作用                                                |
|-----------------------|----------------|-----------------------------------------------------|
| `Enter`（回车键）      | 主键盘区右边   | 换一行；在命令行里表示"执行这条命令"                   |
| `空格键`               | 最下面最长的键 | 输入一个空格                                         |
| `Backspace`（退格键）  | 回车键上方     | 删除光标前面的一个字                                  |
| `Shift`               | 左右各一个      | 按住它再按字母键，可以输入大写字母和键面上半部分的符号 |
| `Ctrl`                | 左右各一个      | 组合键用，比如 `Ctrl+S` 保存文件                     |

> ⚠️ **小心**：写代码要用**英文输入法**状态下的标点符号！中文输入法的逗号是 `，`，英文的是 `,`。代码里必须用英文标点。（引号里的中文文字可以用中文标点，因为那是显示给人看的。）

### 保存文件

你在编辑器里写的代码，一开始只存在于"记忆"里，关机就没了。必须**保存**，它才会写进硬盘。

> 📖 **保存**：把正在编辑的内容写入硬盘，让它不会丢失。在绝大多数软件里，按 `Ctrl+S`（macOS 上是 `Cmd+S`）就能保存。

> ✨ **小提示**：养成好习惯——每写完几行就按一次 `Ctrl+S`。

## 1.3 认识你的开发工具

写代码需要三样工具。就像做饭需要厨房、锅铲和菜谱。

### 工具一：命令行窗口——和电脑对话的窗口

> 📖 **命令行窗口**：一个纯文字的窗口。你在里面用打字的方式下命令，电脑执行后把结果也用文字告诉你。它也叫"终端"。

💡 **比喻**：命令行窗口就像一个只接受文字订单的服务员。你说"给我一杯水"，他就端来一杯水，并用文字告诉你"水来了"。

怎么打开它：

- **Windows**：点击屏幕左下角，搜索"PowerShell"，回车打开。
- **macOS**：按 `Cmd+空格`，输入"终端"，回车打开。
- **Linux**：按 `Ctrl+Alt+T`。

打开后，你会看到一个一闪一闪的竖线——那叫**光标**，表示"轮到你输入了"。

> 📖 **命令**：你在命令行窗口里敲的一行指令。敲完按回车，电脑就照着做。比如输入 `rzc --help` 再按回车，就是让 rzc 显示帮助信息。

### 工具二：编译器——你的翻译官

你写的源码是人类可读的文字，但计算机只懂**二进制**。

> 📖 **二进制**：只用 0 和 1 两个数字来表示一切信息的方式。就像电灯只有"开"和"关"两种状态，计算机内部也只有"有电"和"没电"，分别记作 1 和 0。

所以需要一个**翻译官**，把源码翻译成计算机能执行的指令。

> 📖 **编译器**：就是一个翻译官程序。它读入你写的源码，检查有没有写错，然后翻译成机器能执行的指令。

> 📖 **编译**：翻译官翻译代码的这个过程。"把代码编译一下"就是"让翻译官翻译一下"。

```
你写的源码（人类看得懂的文字）
    ↓  编译器翻译
机器码（01010101……计算机看得懂）
    ↓  计算机执行
输出结果（屏幕上显示出来）
```

中文 Rust 有**两个**翻译官接力工作：

```
中文源码（.zh 文件）
    ↓  第一个翻译官 rzc：中文 → 英文
标准 Rust 源码（.rs 文件）
    ↓  第二个翻译官 rustc：英文 → 机器码
可执行程序
    ↓  运行
输出结果
```

第一个翻译官叫 **rzc**（读作"r-z-c"，三个字母分开读）。它是我们这个项目的中文编译器，负责把中文关键字换成英文。

第二个翻译官叫 **rustc**，是 Rust 官方的编译器，负责把英文代码变成机器码。

你不用分别指挥它们。只要喊一声 `rzc run`，两步会自动完成。

> ✨ **小提示**：rzc 名字里的 "r" 代表 Rust，"zc" 是"中文"拼音的首字母。

### 工具三：文本编辑器——你的作文本

> 📖 **编辑器**：用来写文字的软件。写代码用的编辑器叫"代码编辑器"，它会给代码涂上不同颜色，让你看得更清楚。

这本书推荐 **VS Code**（读作"V-S-Code"），它免费、功能强大，全世界的程序员都在用。

> 📖 **扩展**：给编辑器"加装"的小功能，就像给自行车装个车篮。VS Code 有专门的中文 Rust 扩展，装上之后中文代码会有漂亮的颜色高亮，还能自动帮你排版。

## 1.4 安装工具

这一节是一步一步的操作指南。请打开命令行窗口，跟着做。

### 第一步：安装 Rust

rzc 需要 Rust 官方编译器（rustc）配合工作，所以先装 Rust。

#### win系统：
浏览器访问：https://rust-lang.org/zh-CN/learn/get-started/  
选择对应的安装包下载，根据提示安装即可

#### Linux系统/Mac系统：

在命令行窗口输入这一行，然后按回车：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

> 📖 这一行命令的意思是：从网上下载一个安装程序并运行它。`curl` 是"下载工具"的名字，后面的网址是安装程序所在的地方。你不需要理解它的每个部分，照着输入即可。

安装过程中它会问你选项，**直接按回车**选默认项就行。整个过程取决于网速，通常几分钟。

> ⚠️ **小心**：安装完成后，必须**关闭命令行窗口，重新打开一个**。新装的软件要重新开窗才能被找到。

重新打开窗口，输入下面的命令验证：

```bash
rustc --version
```

> 📖 `--version` 的意思是"告诉我你的版本号"。版本号就是软件的生日编号，比如 1.85.0。

如果看到类似 `rustc 1.85.0` 的输出，说明安装成功。版本号不完全一样也没关系。

> **遇到问题？** 如果提示"找不到命令"，多半是窗口没重新打开。关掉再开一次。还不行就重启电脑再试。

### 第二步：安装 rzc

rzc 发布在 crates.io——这是 Rust 世界的"官方软件仓库"，就像一个巨大的应用商店。

> 📖 **crates.io**：Rust 官方的软件仓库网站，全世界的 Rust 程序员把自己的工具放在这里供人下载。"crate"英文是"板条箱"的意思，Rust 用板条箱比喻一个个软件包。

Rust 自带一个叫 **cargo** 的软件管家，用它一条命令就能安装 rzc：

> 📖 **cargo**：Rust 自带的"软件管家"（包管理工具），负责下载、安装、管理软件。"cargo"英文是"货物"的意思，和"板条箱"是配套的名字。

```bash
cargo install rzc
```

这条命令会下载并安装 rzc，第一次需要几分钟。安装完成后验证：

```bash
rzc --help
```

> 📖 `--help` 的意思是"告诉我怎么用你"。几乎所有命令都支持它。

如果屏幕上出现一大段帮助文字，恭喜，rzc 装好了！

> ✨ **小提示**：rzc 的语言包已经内置在程序里，安装完立刻就能用，不需要额外配置。以后想升级到最新版，运行 `cargo install rzc --force`（`--force` 是"强制重装"的意思）。

### 第三步：安装 VS Code 和中文 Rust 扩展

1. **下载 VS Code**：用浏览器打开 VS Code 官网（code.visualstudio.com），点下载按钮，按提示安装。安装就是"一路点下一步"。
> ✨ **小提示**：安装国内基于**VScode** 二次开发的AI编辑器可能体验更好。

2. **安装扩展**：打开 VS Code，点左边竖排图标里像"四个方块"的那个，再点击搜索框右上角的...弹出菜单，选择从VXIS安装。
> ✨ **小提示**：如果离线环境装不了扩展，也可以从项目的 Releases 页下载 `.vsix` 文件手动安装。`.vsix` 是 VS Code 扩展的安装包格式，就像安卓的 `.apk`。在扩展商店页面右上角的"…"菜单里选择"从 VSIX 安装"即可。

> 📖 **i18n**：是"国际化"（internationalization）的缩写——首字母 i + 中间 18 个字母 + 末尾 n。i18n-rust 就是"让 Rust 国际化"的项目，也就是中文 Rust。

装好后，你写的中文代码就会自动带上颜色。

## 1.5 创建你的第一个项目

### 什么是项目

> 📖 **项目**：一个文件夹，里面装着完成一件事所需的全部文件。我们要写程序，就先创建一个项目文件夹。

在命令行窗口输入：

```bash
rzc init 你好世界
```

> 📖 拆解这条命令：`rzc` 是喊翻译官出来干活；`init` 是英文 initialize（初始化，意思是"从头布置好"）的缩写，表示"创建一个新项目"；`你好世界` 是你给项目起的名字。

这条命令会自动创建一个叫 `你好世界` 的文件夹，里面的结构是：

```
你好世界/
├── Cargo.toml          ← 项目档案卡（记录项目名称等信息）
├── rust-toolchain.toml ← 记录需要的 Rust 版本
├── README.md           ← 项目说明文件
└── src/
    └── main.zh         ← 你的源码文件（写代码的地方）
```

> 📖 **目录树**：上面这种用线条画出文件夹层级关系的图，叫目录树。竖线和横线表示"包含"关系，就像家族谱系图。`src/` 后面的斜杠表示它是一个文件夹。

这张图的意思是：`你好世界` 文件夹里有四个东西，其中 `src` 是个文件夹，它里面装着 `main.zh`。

你只需要关心 **`src/main.zh`**——这是你写代码的地方。其他文件是工具自动管理的，暂时不用管。

### 用 VS Code 打开项目

1. 打开 VS Code。
2. 点左上角"文件"菜单 → "打开文件夹"。
3. 找到刚创建的 `你好世界` 文件夹，点"确定"。
4. 在左侧文件列表里点开 `src` 文件夹，再点 `main.zh`，代码就出现在中间的大区域里了。

## 1.6 第一个程序：逐字逐句讲解

### 完整代码

打开 `src/main.zh`，输入下面三行（`main.zh` 里已经有一些自动生成的代码，你可以全部删掉再输入）：

```rust
函数 主函数() {
    打印行!("你好，世界！");
}
```

> ⚠️ **小心**：输入时注意——
> 1. `函数` 和 `主函数` 之间有一个**空格**。
> 2. `()`、`{}`、`""`、`!`、`;` 都必须在**英文输入法**下输入，**中文输入也可以默认自动转换成英文的**。
> 3. 引号里的"你好，世界！"是给人看的文字，中文标点没问题。

### 逐行、逐字解释

**第 1 行：`函数 主函数() {`**

这一行的意思是："我要定义一段叫'主函数'的指令，它不需要任何输入，指令的内容从 `{` 之后开始。"

一个字一个字拆开看：

| 代码     | 是什么                     | 作用                                                      | 生活类比                                   |
|----------|---------------------------|-----------------------------------------------------------|-------------------------------------------|
| `函数`   | 关键字（英文原名 fn）       | 告诉计算机"下面要定义一段指令"                             | 就像说"注意，下面是一套动作"                |
| 空格     | 分隔符                     | 把两个词分开，计算机靠空格分辨词与词                        | 就像中文里"我爱学习"要写成"我 爱 学习"才清楚 |
| `主函数` | 函数的名字（英文原名 main） | 这段指令的名字。程序永远从"主函数"开始执行                  | 就像一本书的"第一章"，必须从这里读起         |
| `()`     | 一对圆括号                 | 括号里放"参数"（函数需要的输入）。这里是空的，表示不需要输入 | 就像说"这套动作不需要任何道具"              |
| `{`      | 左花括号                   | 表示"指令内容从这里开始"                                   | 就像说"开始！"                             |

> 📖 **参数**：函数需要的输入。就像榨汁机需要水果才能工作——水果就是榨汁机的参数。我们的主函数不需要输入，所以括号里是空的。这个词在第六章会详细讲。

> 📖 **花括号**：`{` 和 `}` 这两个符号。它们总是成对出现，用来圈住一段内容。`{` 是开始，`}` 是结束。

**第 2 行：`    打印行!("你好，世界！");`**

这一行的意思是："在屏幕上显示'你好，世界！'这几个字。"

| 代码            | 是什么                            | 作用                                 | 生活类比               |
|-----------------|----------------------------------|--------------------------------------|-----------------------|
| 开头的 4 个空格  | 缩进                             | 表示这一行"属于"主函数内部             | 就像作文里新段落空两格 |
| `打印行`        | 内置工具的名字（英文原名 println） | 在屏幕上显示文字，显示完自动换到下一行  | 对着屏幕"喊话"        |
| `!`             | 感叹号                           | 表示这个工具是**宏**                   | 宏的专属标记          |
| `(...)`         | 圆括号                           | 括号里放要显示的内容                   | 喊话的内容            |
| `"你好，世界！"` | 字符串                           | 双引号圈起来的一串文字                 | 纸条上写的字          |
| `;`             | 分号                             | 表示这一条指令结束                     | 就像中文的句号"。"    |

> 📖 **宏**：一种特殊的内置工具，名字后面带感叹号 `!`。你现在只需要记住：**看到感叹号，就知道它是宏**。宏和普通函数的区别要到第二十三章才详细讲，现在完全不用深究。

> 📖 **字符串**：一串文字。英文是 string，意思是"一串"。用双引号 `"` 圈起来表示"这是一段文字"，就像用引号圈住别人说的话。

> ⚠️ **小心**：`打印行` 里的"行"读 háng，意思是"打印一行"。它打印完会自动**换行**——下次打印的内容会出现在下一行。

**第 3 行：`}`**

| 代码  | 是什么  | 作用                | 生活类比       |
|------|----------|--------------------|---------------|
| `}`  | 右花括号 | 主函数的内容到此结束 | 就像说"结束！" |

> ⚠️ **小心**：`{` 和 `}` 必须**成对出现**。有开始就必须有结束。漏掉一个是新手最常见的错误之一（1.10 节会讲）。

### 保存并运行

1. 按 `Ctrl+S` 保存文件。
2. 在命令行窗口，先确认你在 `你好世界` 文件夹里。输入：

```bash
cd 你好世界
```

> 📖 `cd` 是英文 change directory 的缩写，意思是"走进某个文件夹"。就像你走进自己的卧室，之后的操作都在卧室里进行。

3. 然后运行：

```bash
rzc run src/main.zh
```

> 📖 拆解：`rzc` 喊翻译官；`run` 是英文"运行"；`src/main.zh` 是告诉它"翻译并运行这个文件"。

如果一切顺利，你会看到：

```
你好，世界！
```

**恭喜！你已经成功运行了第一个中文 Rust 程序。** 全世界的程序员学任何语言，第一个程序都是这句"你好，世界"——你现在正式加入这个传统了。

> ✨ **小提示**：以后每次改完代码，都可以再敲一次 `rzc run src/main.zh` 看新结果。命令窗口按键盘的**上方向键**，可以调出上一次敲过的命令，不用重新打字。

## 1.7 幕后揭秘：中文代码是怎么跑起来的

你可能好奇：计算机又不懂中文，中文代码是怎么跑起来的？

当你敲下 `rzc run` 后，背后自动发生了三步：

```
┌──────────────────────────────────┐
│ ① 你的中文源码 main.zh            │
│    函数 主函数() { ... }          │
└────────────┬─────────────────────┘
             │ rzc 把中文关键字换成英文
             ▼
┌──────────────────────────────────┐
│ ② 标准 Rust 源码                  │
│    fn main() { ... }             │
└────────────┬─────────────────────┘
             │ rustc 把英文代码变成机器码
             ▼
┌──────────────────────────────────┐
│ ③ 机器码（0 和 1）→ 执行 → 输出   │
│    屏幕上显示：你好，世界！        │
└──────────────────────────────────┘
```

1. **翻译**：rzc 查一张"中英对照表"，把 `函数` 换成 `fn`，把 `打印行` 换成 `println`。
2. **编译**：rustc 把英文代码翻译成机器码。
3. **运行**：计算机执行机器码，屏幕显示结果。

> 📖 **映射表**：上面说的"中英对照表"，正式名字叫映射表——中文词映射到英文词的一张表。这张表就在项目的语言包里，附录 A 收录了完整内容。

整个过程是自动的，你只管写 `.zh` 文件。

### 好奇翻译结果？用 eject 看一眼

想亲眼看看翻译后的英文代码长什么样，可以运行：

```bash
rzc eject src/main.zh
```

> 📖 `eject` 英文是"弹出、导出"的意思。这条命令会生成一个 `src/main.rs` 文件（`.rs` 是标准 Rust 的扩展名），里面就是翻译后的英文代码：

```rust
fn main() {
    println!("你好，世界！");
}
```

> ✨ **小提示**：注意——字符串引号里的中文"你好，世界！"**没有**被翻译。rzc 只翻译关键字和标识符（代码里有特殊含义的词），引号里的文字原样保留。

> ✨ **小提示**：`main.rs` 只是给你看看的，平时不用管它。你继续改 `main.zh` 就好。

## 1.8 动手实验

学编程最好的方式是**动手改代码**。下面三个实验，请每个都做一遍。

### 实验 1：改变输出内容

**目的**：让你亲眼看到"改代码 → 输出跟着变"。

把 `main.zh` 改成：

```rust
函数 主函数() {
    打印行!("你好，我是小明！");
    打印行!("我正在学中文 Rust。");
}
```

逐行解释：

- 第 1 行：定义主函数，程序从这里开始。
- 第 2 行：在屏幕上显示"你好，我是小明！"，然后自动换行。
- 第 3 行：在下一行显示"我正在学中文 Rust。"，然后再换行。
- 第 4 行：主函数结束。

保存后运行，屏幕显示：

```
你好，我是小明！
我正在学中文 Rust。
```

> **观察**：两行字分两行显示，因为 `打印行` 每次都会自动换行。指令从上到下一条条执行，先写的先执行。

### 实验 2：不换行打印

**目的**：理解"换行"和"不换行"的区别。

```rust
函数 主函数() {
    打印!("你好，");
    打印!("世界！");
}
```

逐行解释：

- 第 2 行：`打印!`（英文原名 print）和 `打印行!` 唯一的区别是——**打印完不换行**。
- 第 3 行：紧接在上次打印的位置继续显示。

运行后屏幕显示：

```
你好，世界！
```

两段文字连成一行，因为中间没有换行。

### 实验 3：在文字中插入数据

**目的**：学会让程序"记住"数据，并在需要时拿出来用。

```rust
函数 主函数() {
    让 名字 = "小明";
    让 年龄 = 20;
    打印行!("我叫{}，今年{}岁。", 名字, 年龄);
}
```

逐行解释：

- 第 2 行：`让` 是关键字（英文原名 let），意思是"创建一个盒子"。这行的意思是：拿一个盒子，贴上"名字"标签，把"小明"放进去。
- 第 3 行：同样，拿一个盒子贴上"年龄"标签，把 20 放进去。
- 第 4 行：`{}` 是**占位符**（预先留好的空位）。`打印行!` 会把括号后面列出的数据依次填进空位。

> 📖 **变量**：贴了标签的盒子。标签是名字，盒子里装的是数据。`让 名字 = "小明"` 就创建了一个叫"名字"的变量。第三章会详细讲。

> 📖 **占位符**：预先留好的空位，等着被填上。`{}` 就是占位符，像表格里的空格等着被填内容。

填入过程图示：

```
"我叫{}，今年{}岁。"     ← 模板，有两个空位
      ↑        ↑
    名字      年龄        ← 按顺序填入
"小明"      20
      ↓        ↓
"我叫小明，今年20岁。"   ← 最终结果
```

运行后屏幕显示：

```
我叫小明，今年20岁。
```

## 1.9 代码风格

代码不仅要能运行，还要让人看得舒服。就像作文要字迹工整、分段清楚。

### 缩进：4 个空格

花括号里面的代码要向右缩进 4 个空格，表示"属于"外面的函数。

```rust
函数 主函数() {
    打印行!("正确缩进");  // ✅ 缩进 4 个空格
}
```

为什么要缩进？缩进让代码的层次一目了然。就像写信时段落开头空两格——为了让人一眼看出结构。

> ✨ **小提示**：不用数空格。装好 VS Code 扩展后，在代码里**点右键 → 格式化**，编辑器会自动帮你排好。

### 命名

| 类别   | 风格              | 例子                       |
|--------|-------------------|---------------------------|
| 函数名 | 中文动词或动宾短语  | `计算总和`、`获取用户输入` |
| 变量名 | 中文名词           | `名字`、`年龄`、`数量`     |
| 类型名 | 中文名词           | `学生信息`、`图书`         |

> ⚠️ **小心**：名字不要和关键字撞车。比如不能把变量起名叫 `结果`，因为 `结果` 是语言包里的保留词（英文 Result 的中文名，第十一章会讲）。取名时选具体一点的名词最安全，比如 `总和`、`问候语`。

### 注释：写给人看的说明

> 📖 **注释**：代码里写给人看的说明文字，编译器会直接忽略它。单行注释以 `//` 开头（两个斜杠，英文输入法下输入）。

```rust
// 这是单行注释，编译器会忽略

函数 主函数() {
    打印行!("你好"); // 行尾也可以写注释
    // 让 名字 = "小明";  // 被注释掉的代码不会执行
}
```

为什么要写注释？代码告诉计算机"做什么"，注释告诉人"为什么这么做"。过几天回来看自己的代码，注释能帮你快速回忆起当时的想法。

## 1.10 常见错误与解决

写代码一定会犯错，这非常正常。把编译器想象成一位**严格但热心的老师**：它批改作业时会告诉你**哪里错、为什么错、怎么改**。

> 📖 **报错**：编译器发现问题时给出的提示文字。报错不是批评，是帮你找错。

先学一个只检查不运行的命令：

```bash
rzc check src/main.zh
```

> 📖 `check` 英文是"检查"。这条命令只做翻译和检查，不真正运行程序。就像交作业前先自查一遍。

### 错误 1：漏掉括号

```rust
函数 主函数() {
    打印行!("你好"   // ❌ 少了右括号 ) 和分号
}
```

运行 `rzc check` 报错：

```
错误: mismatched closing delimiter: `}`
  --> main.zh:3:1
```

**怎么读这个报错**：

- `mismatched closing delimiter`：英文意思是"收尾符号对不上"——括号没关好。
- `-->` 后面是位置：`main.zh` 第 3 行第 1 列。
- 这类**语法错误**（写法规则错误）没有错误码，显示的是英文原文。

**修法**：数一数左右括号是否成对。口诀：**左括号开了口，右括号要收尾**。

### 错误 2：拼错工具名

```rust
函数 主函数() {
    打应行!("世界");  // ❌ "打应行"不存在，应该是"打印行"
}
```

报错：

```
错误: cannot find macro `打应行` in this scope
  --> main.zh:2:5
```

**怎么读这个报错**：`cannot find` 是"找不到"；`macro` 是"宏"。连起来：**在当前范围里找不到叫 `打应行` 的宏**。八成是拼错了。

**修法**：对照本章的工具名核对，改回 `打印行!`。

### 错误 3：类型不匹配（最常见）

```rust
函数 主函数() {
    让 数量 = 10;        // 数量装的是数字
    让 数量 = "你好";    // ❌ 想把文字塞进装数字的盒子
}
```

报错：

```
错误[E0308]: 类型不匹配：期望 `整数`，实际得到 `字符串引用`
💡 请检查变量类型是否与上下文要求一致。
```

**怎么读这个报错**：

- `错误[E0308]`：方括号里是**错误码**。每个错误码对应一类常见错误。有错误码的报错会被翻译成中文。
- `类型不匹配`：问题的本质——把不同种类的东西混在一起了。
- `💡` 后面是修复建议。

> 📖 **类型**：数据的"种类"。数字是一种类型，文字是另一种类型。盒子贴了什么标签就只能装什么种类的东西。第三章详细讲。

**记住这句话**：数字是数字，文字是文字，不能混着用。就像盒子贴着"装苹果"，就不能硬塞香蕉。

> 📖 更多错误码的人话解释，见**附录 C：常见错误信息字典**。

## 1.13 常见问题（FAQ）

**问 1：我的屏幕提示"rzc 不是内部或外部命令"怎么办？**

答：命令行窗口找不到 rzc。先关掉窗口重新打开；还不行就重启电脑；再不行说明没装成功，回到 1.4 重新执行 `cargo install rzc`。

**问 2：为什么我写的是中文，计算机能懂？**

答：计算机其实不懂中文。rzc 先把你写的中文关键字换成英文（查映射表），再由 rustc 编译成机器码。你看到的"中文代码"只是写给你的友好界面，跑的是翻译后的英文代码。

**问 3：引号里的中文会被翻译吗？**

答：不会。引号里的文字原样保留。rzc 只翻译代码本身的关键字和标识符。

**问 4：`打印` 和 `打印行` 有什么区别？**

答：`打印行!` 打印完自动换行，`打印!` 不换行。想让两段文字连成一行就用 `打印!`。

**问 5：感叹号 `!` 是必须的吗？**

答：可以省略——工具会自动补上。但建议写出来，因为看到感叹号就知道"这是宏"。

**问 6：我能不能不用 VS Code，用记事本写代码？**

答：能写，但不推荐。记事本没有颜色高亮、没有自动排版、不能一键运行，写起来很累。工欲善其事，必先利其器。

**问 7：代码写错了会把电脑弄坏吗？**

答：绝对不会。代码错误最多就是程序运行失败，改过来就好。放心大胆地试。

**问 8：这一章的单词记不住怎么办？**

答：不用背！术语表就是给你随时查的。用着用着就熟了，就像学骑自行车，不用背"先迈左脚"。
