# 第一章：你好，世界

欢迎来到中文 Rust 的世界！

在这一章里，你将完成一件了不起的事——用中文写一段能运行的程序。

> 如果你从来没写过代码，完全不用担心。本章会从最基础的概念讲起。想象你从没下过厨——我们先认识厨房，再认识食材，最后才动手做菜。
> ✨ **小提示**：学编程要多动手，因为脑子学会了，手不一定**也**学会了
---

## 1.1 什么是编程

### 给机器人写纸条

想象你面前有一个机器人。它很听话，但很笨——你说的话它只会**字面理解**。

编程，就是**给机器人写纸条**，告诉它"先做这个，再做那个"。

你写的每张纸条，叫做一段**源码**。写源码用的语言，叫做**编程语言**。

就像人类有中文、英文、俄语，编程语言也有很多种。它们各有特点，但核心思想一样——**用文字告诉计算机该做什么**。

### 为什么要有中文 Rust

大多数编程语言的关键字都是英文的。对英语母语者来说，这些词很自然。但对中文母语者来说，一边学编程逻辑，一边还要记英文单词，就像**同时学两门外语**，难度翻倍了。

**中文 Rust 就是来解决这个问题的。**

它让你用中文关键字写代码：

| 中文关键字 | 含义 | 生活中的类比 |
|-----------|------|-------------|
| `函数` | 定义一段可以反复使用的指令 | 给一套动作起个名字，喊名字就能做整套动作 |
| `让` | 创建一个"盒子"来存放数据 | 拿一个盒子，贴上标签，把东西放进去 |
| `如果` | 根据条件决定做不做某事 | 如果下雨，就带伞 |
| `对于` | 重复做某事 | 对于篮子里的每个苹果，都洗一遍 |
| `打印行!` | 在屏幕上显示文字 | 对着屏幕"喊话" |

你写的代码看起来就像中文句子，但它是**真正可以运行的程序**。

```rust
函数 主函数() {
    打印行!("你好，世界！");
}
```

> ✨ **小提示**：在中文 Rust 中，所有宏名字后面**不需要手动加感叹号**。工具会自动帮你补上。你只需要写 `打印行("你好，世界！")` 就行。当然，写了 `!` 也没错——两种写法都支持。

> **核心理念**：编程是一种**思维方式**，不应该被语言门槛挡住。Rust 编程语言只是一种工具。

## 1.2 认识你的开发工具

在开始写代码之前，你需要准备几样工具。就像做饭需要锅碗瓢盆，写代码也需要工具。

### 命令行窗口

命令行窗口是一个**纯文字界面**。你在里面输入命令，计算机执行后返回结果。
> ✨ **小提示**：常用的操作系统主要有这三种，第四种 HarmonyOS 也在快速发展中。

- **macOS**：按 `Cmd + 空格`，输入"终端"
- **Linux**：按 `Ctrl + Alt + T`
- **Windows**：搜索"PowerShell"

打开后，你会看到一个闪烁的光标——那就是你和计算机对话的入口。

### 编译器——你的翻译官

你写的源码是**人类可读的文字**。但计算机只懂**二进制**（一堆 0 和 1）——就像灯只有"开"和"关"两种状态，计算机的世界里只有 0 和 1 两个数字。

编译器就是一个**翻译官**——把你的源码翻译成计算机能执行的指令。

```
你写的源码（人类看得懂的文字）
    ↓  翻译官（编译器）翻译
机器码（01010101...）
    ↓  计算机执行
输出结果
```

中文 Rust 的翻译官叫 **rzc**（中文编译器）。它分两步工作：

```
中文源码（.zh 文件）
    ↓  rzc 翻译成标准 Rust
标准 Rust 源码（.rs 文件）
    ↓  Rust 编译器翻译成机器码
可执行程序
    ↓  运行
输出结果
```

### 文本编辑器

你需要一个工具来写代码。推荐使用 **VS Code**——它免费、功能强大。安装 **i18n-rust** 扩展后，你的中文代码会有彩色高亮，看起来更清楚。

## 1.3 安装编译器

### 第一步：安装 Rust

rzc 依赖 Rust 编译器。打开命令行窗口，输入：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

> 这行命令会从网上下载并安装 Rust。安装过程中它会提示你选择，通常情况下直接回车就可以了，整个过程取决于你的网速，通常可能只要几分钟。

安装完成后，**关闭并重新打开命令行窗口**（这一步很重要！），然后验证：

```bash
rustc --version
```

如果看到类似 `rustc 1.85.0` 的输出，说明安装成功。
> 可能版本号不一样，不过不用担心，这个不影响。
> **遇到问题？** 如果提示"命令未找到"，可能是路径没更新。试试关闭命令行窗口重新打开。

### 第二步：安装 rzc（一条命令）

rzc 已经发布到 crates.io（Rust 的官方软件仓库），一条命令就能装好：

```bash
cargo install rzc
```

> `cargo` 是 Rust 自带的包管理工具（就是"软件管家"）。`install` 表示安装，`rzc` 是中文编译器的名字。这条命令会下载、编译并安装 rzc，第一次可能需要几分钟。

安装完成后，验证一下：

```bash
rzc --help
```

如果看到帮助信息，恭喜，安装完成！之后在任何目录下输入 `rzc` 都能使用，**无需任何额外配置**——语言包已内置在 rzc 里。

> ✨ **小提示**：如果你已经装过旧版本，想升级到最新版，运行 `cargo install rzc --force` 即可。

## 1.4 第一个程序
> ✨ **小提示**：学编程要多动手，因为脑子学会了，手不一定**也**学会了
现在，让我们写第一个程序。这是每个程序员的"成人礼"——不管学什么语言，第一个程序永远是打印"你好，世界"。

### 创建项目

```bash
rzc init 你好世界
```
> 使用rzc 初始化一个项目，项目名称：你好世界
这条命令会创建一个文件夹，结构如下：

```
你好世界/
├── Cargo.toml          ← 项目档案卡（记录项目名称、依赖等）
├── rust-toolchain.toml ← 锁定 Rust 版本
├── README.md           ← 项目说明文件
└── src/
    └── main.zh         ← 你的源码文件（在这里写代码）
```

> 你只需要关心 `src/main.zh`——这是你写代码的地方。其他文件是项目自动管理的。语言包已经内置在 rzc 里，项目里不需要它。

### 编写代码

打开 `src/main.zh`，输入：

```rust
函数 主函数() {
    打印行!("你好，世界！");
}
```
>你肯定很好奇，为什么是这样的格式？这是 Rust 官方设计的代码格式，我们照着写就行。
>你也不用特意去对齐，我们的 VS Code 插件支持右键格式化代码，他会自动帮你对齐——对齐是为了让我们自己看着美观，代码更清楚。
让我们**逐字逐句**理解这段代码。就像拆解一个句子，每个词都要搞懂：

| 代码 | 作用 | 生活类比 |
|------|------|---------|
| `函数` | 告诉计算机："我要定义一段指令" | 就像在说"注意，下面是一套动作" |
| `主函数` | 这段指令的名字。程序必须从"主函数"开始执行 | 就像一本书的"第一章"，必须从这里开始读 |
| `()` | 括号里放"参数"——函数需要的输入。这里为空，表示不需要输入 | 就像说"这套动作不需要任何道具" |
| `{` | 函数体开始——接下来是具体的指令 | 就像说"开始！" |
| `打印行!` | 一个内置工具，作用是在屏幕上显示文字 | 就像对屏幕"喊话" |
| `!` | 感叹号表示这是**宏**（一种特殊的内置工具） | 感叹号是宏的标记，表示"这是特殊工具，不是普通指令" |
| `("你好，世界！")` | 括号里是要显示的内容。双引号包裹的文字叫做**字符串**（就是一串文字的意思） | 就像在纸条上写"你好，世界！" |
| `;` | 分号表示一条指令结束 | 就像中文的句号"。" |
| `}` | 函数体结束 | 就像说"结束！" |

### 运行程序

保存文件后，在命令行窗口执行：

```bash
rzc run src/main.zh
```

你会看到：

```
你好，世界！
```

**恭喜！你已经成功运行了第一个中文 Rust 程序。**

## 1.5 编译流程：中文代码是怎么跑起来的

你可能好奇：中文代码是怎么变成可执行程序的？

当你执行 `rzc run` 时，背后发生了三步：

```
┌─────────────────────┐
│  你的中文源码         │  你写的：函数 主函数() { ... }
│  (main.zh)          │
└─────────┬───────────┘
          │ ① rzc 翻译
          ▼
┌─────────────────────┐
│  标准 Rust 源码      │  翻译后：fn main() { ... }
│  (main.rs)          │
└─────────┬───────────┘
          │ ② Rust 编译器翻译
          ▼
┌─────────────────────┐
│  机器码              │  计算机能执行的 0 和 1
│  (可执行文件)        │
└─────────┬───────────┘
          │ ③ 运行
          ▼
┌─────────────────────┐
│  输出结果            │  屏幕上显示：你好，世界！
└─────────────────────┘
```

1. **翻译**：rzc 把中文关键字替换为英文（`函数` → `fn`，`打印行` → `println`）
2. **编译**：Rust 编译器把英文代码翻译成机器码
3. **运行**：执行编译好的程序

> 整个过程是自动的。你只需要写 `.zh` 文件，其他的不需要操心。

### 查看翻译后的代码

好奇翻译后的英文长什么样？

```bash
rzc eject src/main.zh
```

这会生成 `src/main.rs`：

```rust
fn main() {
    println!("你好，世界！");
}
```

> 注意：字符串里的中文**不会**被翻译——只有关键字和标识符会被替换。

## 1.6 动手实验

学习编程最好的方式就是**动手改代码**。

### 实验 1：改变输出内容

**为什么要做这个实验？** 让你看到：改代码 → 改输出，代码和输出是对应的。

```rust
函数 主函数() {
    打印行!("你好，我是小明！");
    打印行!("我正在学中文 Rust。");
}
```

逐行解释：
- 第 1 行：定义主函数（程序的入口）
- 第 2 行：在屏幕上显示"你好，我是小明！"，然后换行
- 第 3 行：在屏幕上显示"我正在学中文 Rust。"，然后换行
- 第 4 行：主函数结束

运行后：

```
你好，我是小明！
我正在学中文 Rust。
```

> **观察**：每条 `打印行!` 都会自动换行。

### 实验 2：不换行打印

**为什么要做这个实验？** 让你理解"换行"和"不换行"的区别。

```rust
函数 主函数() {
    打印!("你好，");
    打印!("世界！");
}
```

逐行解释：
- 第 2 行：`打印!` 和 `打印行!` 的区别是——它**不会自动换行**
- 第 3 行：紧接着上一行继续显示

运行后：

```
你好，世界！
```

两个 `打印!` 的内容连在了一起，因为没有换行。

### 实验 3：在文字中插入数据

**为什么要做这个实验？** 让你学会让程序"记住"数据，并在需要的时候拿出来用。

```rust
函数 主函数() {
    让 名字 = "小明";
    让 年龄 = 20;
    打印行!("我叫{}，今年{}岁。", 名字, 年龄);
}
```

逐行解释：
- 第 2 行：拿一个盒子，贴上"名字"标签，把"小明"放进去
- 第 3 行：拿一个盒子，贴上"年龄"标签，把 20 放进去
- 第 4 行：`{}` 是**占位符**（预留的空位）。`打印行!` 会把后面的参数依次填入空位

```
"我叫{}，今年{}岁。"
      ↓       ↓
    名字     年龄
      ↓       ↓
"我叫小明，今年20岁。"
```

> `让` 是中文 Rust 的关键字，用来创建**变量**。变量就是"贴了标签的盒子"——标签是名字，盒子里装的是数据。下一章会详细讲。

## 1.7 读懂报错信息

写代码时难免犯错。Rust 编译器以"严格"著称——它会在编译阶段就帮你发现很多潜在问题。

把编译器想象成一个**严格的老师**。它批改作业时，会告诉你**哪里错了**、**为什么错**、**怎么改**。

### 常见错误 1：漏掉括号

```rust
函数 主函数() {
    打印行!("你好"   // ❌ 少了右括号 )
}
```

运行检查：

```bash
rzc check src/main.zh
```

报错：

```
错误: mismatched closing delimiter: `}`
  --> main.zh:3:1
   | }
```

**怎么读这个报错**：
- 第 1 行：错误类型——右括号 `}` 和左括号 `{` 不匹配（因为括号没关好）
- `-->` 后面是位置：第 3 行第 1 列
- 这类**语法错误** rustc 没有错误码，会直接显示 rustc 的原文（英文）

### 常见错误 2：拼错关键字

```rust
函数 主函数() {
    打印行!("你好");
    打应行!("世界");  // ❌ "打应行"不是关键字
}
```

报错：

```
错误: cannot find macro `打应行` in this scope
  --> main.zh:3:5
   |     打应行!("世界");
```

> 编译器的意思是：在作用域里找不到叫 `打应行` 的工具。检查一下是不是拼错了？

### 常见错误 3：类型不匹配（最常见的错误之一）

```rust
函数 主函数() {
    让 数量 = 10;        // 数量是数字
    数量 = "你好";       // ❌ 想把文字塞进数字里
    打印行!(数量);
}
```

报错：

```
错误[E0308]: 类型不匹配：期望 `整数`，实际得到 `字符串引用`
  --> main.zh:3:10
   |     数量 = "你好";
💡 请检查变量类型是否与上下文要求一致。尝试使用 `作为` 进行类型转换。
```

**怎么读这个报错**：
- `错误[E0308]`：错误码。每个错误码对应一类常见错误，**有错误码的错误会翻译成中文**
- `类型不匹配`：问题的本质——把不同种类的东西混在一起了
- 期望 `整数`：`数量` 是数字（整数），只能装数字
- 实际得到 `字符串引用`：你却想往里装文字
- `💡` 后面是修复建议

> **记住**：数字是数字，文字是文字，不能混着用。这就像盒子上贴着"装苹果"，你却硬塞香蕉。

---

> **好习惯**：每次修改代码后，先用 `rzc check` 检查（就像交作业前先自己检查一遍），再运行。

## 1.8 代码风格

虽然中文 Rust 让你用中文写代码，但仍有一些约定需要遵守。就像写作文有格式要求，代码也有格式约定。

### 缩进

使用 **4 个空格**缩进。花括号内的代码要缩进，表示"属于"这个函数。

```rust
函数 主函数() {
    打印行!("正确缩进");  // ✅ 4 个空格
}
```

**为什么要缩进？** 缩进让代码的层次结构一目了然。就像写信时，正文要空两格——不是为了好看，而是为了让人一眼看出哪里是新段落的开始。

### 命名

| 类别 | 风格 | 例子 |
|------|------|------|
| 函数名 | 中文动词或动宾短语 | `计算总和`、`获取用户输入` |
| 变量名 | 中文名词 | `名字`、`年龄`、`数量` |
| 类型名 | 中文名词 | `整数`、`字符串`、`学生信息` |

### 注释

注释是给**人**看的说明文字，编译器会忽略它。用 `//` 写单行注释：

```rust
// 这是单行注释，编译器会忽略

函数 主函数() {
    打印行!("你好"); // 行尾注释
    // 让 名字 = "小明";  // 被注释掉的代码不会执行
}
```

**为什么要写注释？** 代码告诉计算机"做什么"，注释告诉人"为什么这么做"。过几天回来看代码，注释能帮你快速回忆当时的想法。

1. **编程**就是给计算机写指令
2. **中文 Rust** 让你用中文关键字写代码，降低学习门槛
3. **安装工具**：Rust + rzc + 文本编辑器
4. **第一个程序**：`函数 主函数() { 打印行!("..."); }`
5. **编译流程**：中文源码 → 翻译 → 标准 Rust → 编译 → 运行
6. **读报错**：看行号、看错误类型、看修复建议
7. **代码风格**：4 空格缩进、中文命名、用注释解释

你现在已经具备了运行中文 Rust 程序的能力。记住：**动手实验是最好的学习方式**。多改代码，多看输出，多问"如果……会怎样"。
