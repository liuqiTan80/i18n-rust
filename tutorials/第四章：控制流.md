# 第四章：控制流

到目前为止，我们的程序都是"从上往下"一行行执行的。就像读一本书——从第一页读到最后一页。

但真正的程序需要**做决策**。比如，天气热就开空调，天气冷就开暖气。又比如，把一筐苹果逐个检查一遍，烂的扔掉，好的留下。

这一章，我们学习控制程序流程的三大工具：

```
控制流三大工具
┌────────────────────────────────────────────┐
│ 条件分支  │ 根据条件选择走哪条路             │
│ 匹配      │ 把值和多个情况逐一对照           │
│ 循环      │ 重复执行某段代码                │
└────────────────────────────────────────────┘
```

---

## 4.1 如果 / 否则

### 生活类比

想象你早上出门前看天气：

```
如果 下雨 {
    带伞
} 否则 {
    戴墨镜
}
```

这就是**条件分支**——根据条件决定做哪件事。你每天都在做这样的事：如果饿了就吃饭，如果困了就睡觉。程序也一样。

### 最简单的条件

**为什么要用条件？** 因为程序需要根据不同的情况做不同的事。比如，只有年龄够了才能看某个电影。

```rust
函数 主函数() {
    让 年龄 = 18;

    如果 年龄 >= 18 {
        打印行!("你已经成年了。");
    }
}
```

逐行解释：

- 第 2 行：拿一个盒子叫 `年龄`，放入 18
- 第 4 行：**如果** `年龄 >= 18` 这个条件成立（也就是年龄大于或等于 18），就执行花括号里的代码
- 第 5 行：在屏幕上显示"你已经成年了"
- 第 6 行：花括号结束

> **花括号 `{}`** 就像一个大括号——把"要做的事"包在一起。条件后面的花括号里装的是"条件成立时才做的事"。

流程图——看看程序是怎么"走"的：

```
        ┌─────────────┐
        │ 年龄 >= 18 ? │    ← 先判断条件
        └──────┬──────┘
          真 ↙    ↘ 假
    ┌────────┐   ┌────────┐
    │ 显示    │   │ 跳过    │    ← 真就走左边，假就走右边
    │ "已成年"│   │ 什么都不做│
    └────────┘   └────────┘
```

### 加上"否则"

**为什么需要"否则"？** 因为有时候你需要做两件事中的一件。不是这个就是那个。

```rust
函数 主函数() {
    让 温度 = 35;

    如果 温度 > 30 {
        打印行!("好热啊！");
    } 否则 {
        打印行!("还行。");
    }
}
```

逐行解释：

- 第 2 行：拿一个盒子叫 `温度`，放入 35
- 第 4 行：检查温度是否大于 30
- 第 5 行：如果大于 30，显示"好热啊"
- 第 6 行：**否则**——也就是温度不大于 30 的时候
- 第 7 行：显示"还行"

流程图：

```
        ┌─────────────┐
        │ 温度 > 30 ?  │
        └──────┬──────┘
          真 ↙    ↘ 假
    ┌────────┐   ┌────────┐
    │ "好热" │   │ "还行" │    ← 两条路，一定走一条
    └────────┘   └────────┘
```

### 多个条件：否则 如果

**为什么要用多个条件？** 因为现实世界往往不是非黑即白。成绩分优秀、良好、及格、不及格——四种情况，需要三个条件来区分。

```rust
函数 主函数() {
    让 分数 = 85;

    如果 分数 >= 90 {
        打印行!("优秀！");
    } 否则 如果 分数 >= 80 {
        打印行!("良好。");
    } 否则 如果 分数 >= 60 {
        打印行!("及格。");
    } 否则 {
        打印行!("不及格。");
    }
}
```

逐行解释：

- 第 2 行：拿一个盒子叫 `分数`，放入 85
- 第 4 行：先看分数是否 >= 90——85 不够 90，不成立
- 第 6 行：再看分数是否 >= 80——85 够了 80，成立！显示"良好"
- 第 8-10 行：后面的都不再检查了
- 第 11-13 行：最后的"否则"是兜底——前面所有条件都不成立时才走这里

执行过程——像下楼梯一样，逐个检查：

```
分数 = 85
  │
  ├─ >= 90? → 不满足 → 往下看一步
  ├─ >= 80? → 满足！→ 显示 "良好" → 结束
  │  （后面的不再检查）
  ├─ >= 60? → 不看了
  └─ 否则   → 不看了
```

> **重要**：条件从上到下逐个检查。一旦某个条件满足，就执行对应的代码，**后面的全部跳过**。就像比赛淘汰赛——赢了就晋级，不用跟剩下的人比了。

### 条件也能返回值

在 Rust 中，"如果/否则"不只是做动作——它还能**返回一个值**。

**为什么这很重要？** 因为你可以用条件来决定一个变量的值，而不需要先写一个变量再改它。

```rust
函数 主函数() {
    让 分数 = 85;
    让 等级 = 如果 分数 >= 60 { "及格" } 否则 { "不及格" };
    //              ↑ 条件满足时，这个值就是 "及格"
    //                              ↑ 条件不满足时，这个值就是 "不及格"

    打印行!("成绩：{}", 等级);
}
```

逐行解释：

- 第 2 行：拿一个盒子叫 `分数`，放入 85
- 第 3 行：拿一个盒子叫 `等级`。里面放什么？看条件：85 >= 60 成立，所以放入"及格"
- 第 6 行：显示"成绩：及格"

> **注意**：两个分支返回的类型必须一致。不能一个返回整数，另一个返回文字。就像盒子的形状不能变——说好了装文字，两个分支都得装文字。

## 4.2 匹配

### 生活类比

想象一台**自动售货机**——你按不同的按钮，出来不同的饮料：

```
按钮 1 → 可乐
按钮 2 → 雪碧
按钮 3 → 果汁
其他   → 矿泉水（默认）
```

**匹配**就是这样的多分支选择。和"如果/否则"相比，匹配更适合"一个值有好几种可能"的情况。

**为什么用匹配而不是很多个"否则如果"？** 因为当情况很多时，匹配写起来更清楚，而且编译器会帮你检查——你有没有漏掉某种情况。

### 基本用法

```rust
函数 主函数() {
    让 数字 = 3;

    匹配 数字 {
        1 => 打印行!("一"),
        2 => 打印行!("二"),
        3 => 打印行!("三"),    // ← 匹配到了！执行这行
        _ => 打印行!("其它"),
    }
}
```

逐行解释：

- 第 2 行：拿一个盒子叫 `数字`，放入 3
- 第 4 行：**匹配** `数字`——意思是"看看数字是几"
- 第 5 行：是 1 吗？不是，跳过
- 第 6 行：是 2 吗？不是，跳过
- 第 7 行：是 3 吗？是的！显示"三"
- 第 8 行：`_` 是**通配符**——匹配所有其他情况。就像售货机上的"其他"按钮

> **`_` 下划线**是"万能钥匙"——什么都能匹配。它的作用是兜底，确保不管数字是几，都有对应的处理。

### 匹配范围

**为什么要匹配范围？** 因为有时候你不想一个个列举。比如分数在 90 到 100 之间都算"优秀"——你不想写 11 个分支。

```rust
函数 主函数() {
    让 分数 = 85;

    匹配 分数 {
        90..=100 => 打印行!("优秀"),
        80..=89  => 打印行!("良好"),
        60..=79  => 打印行!("及格"),
        _        => 打印行!("不及格"),
    }
}
```

逐行解释：

- 第 4 行：看看 `分数` 是多少
- 第 5 行：`90..=100` 表示从 90 到 100 的范围（包含 90 和 100）。85 不在这个范围
- 第 6 行：`80..=89` 表示从 80 到 89。85 在这个范围！显示"良好"
- 第 7-8 行：后面的不再检查了

> **`..=`** 表示"从...到...，两头都包含"。所以 `90..=100` 包含 90 和 100。

### 匹配也能返回值

```rust
函数 主函数() {
    让 数字 = 7;
    让 描述 = 匹配 数字 {
        1 => "一",
        2 => "二",
        3 => "三",
        _ => "其它",
    };

    打印行!("{} 是 {}", 数字, 描述);
}
```

逐行解释：

- 第 2 行：拿一个盒子叫 `数字`，放入 7
- 第 3 行：拿一个盒子叫 `描述`。里面放什么？看匹配结果
- 第 4-7 行：7 不是 1、2、3，所以走 `_`，值是"其它"
- 第 9 行：显示"7 是 其它"

## 4.3 循环

### 三种循环一览

**为什么需要循环？** 因为你不想把同样的代码写很多遍。比如你要打印 1 到 100——你不想写 100 行打印语句。

```
┌──────────────────────────────────────────────────┐
│ 循环类型  │ 什么时候用         │ 类比              │
├──────────────────────────────────────────────────┤
│ 循环      │ 不确定要执行多少次  │ "一直做，直到我说停"│
│ 当        │ 条件为真时重复     │ "只要下雨就带伞"    │
│ 对于      │ 遍历一组数据       │ "把每封信都读一遍"  │
└──────────────────────────────────────────────────┘
```

### "循环"——一直做，直到你说停

**为什么用"循环"？** 当你不知道要重复多少次，但知道"什么时候该停"的时候。

```rust
函数 主函数() {
    让 可变 计数 = 0;

    循环 {
        如果 计数 >= 5 {
            中断;  // 跳出循环——到此为止
        }
        打印行!("计数：{}", 计数);
        计数 += 1;  // 计数加 1
    }
}
```

逐行解释：

- 第 2 行：拿一个盒子叫 `计数`，放入 0。`可变` 表示以后要改它
- 第 4 行：**循环** 的意思是"反复执行花括号里的代码"
- 第 5 行：每次循环先检查——计数是否 >= 5？
- 第 6 行：如果 >= 5，就 **中断**——跳出循环，不再重复了
- 第 8 行：显示当前计数
- 第 9 行：计数加 1（0 变 1，1 变 2...）

> **`中断`** 就像紧急刹车——不管循环条件是什么，立刻停下来。

输出：

```
计数：0
计数：1
计数：2
计数：3
计数：4
```

### "当"——只要条件满足就继续

**为什么用"当"？** 当你有一个明确的条件，条件满足就一直做，不满足就停。就像"只要还下着雨，就继续等"。

```rust
函数 主函数() {
    让 可变 计数 = 0;

    当 计数 < 5 {
        打印行!("计数：{}", 计数);
        计数 += 1;
    }
}
```

逐行解释：

- 第 2 行：拿一个盒子叫 `计数`，放入 0
- 第 4 行：**当** `计数 < 5` 为真时，反复执行花括号里的代码
- 第 5 行：显示当前计数
- 第 6 行：计数加 1

执行过程——每次循环都先检查条件：

```
计数 = 0 → 0 < 5? 是 → 显示 0 → 计数变成 1
计数 = 1 → 1 < 5? 是 → 显示 1 → 计数变成 2
计数 = 2 → 2 < 5? 是 → 显示 2 → 计数变成 3
计数 = 3 → 3 < 5? 是 → 显示 3 → 计数变成 4
计数 = 4 → 4 < 5? 是 → 显示 4 → 计数变成 5
计数 = 5 → 5 < 5? 否 → 停止！不再执行
```

### "对于"——逐个处理（最常用）

**为什么用"对于"？** 因为你有一组东西，你想对每一个都处理一遍。比如老师要逐个念每个学生的名字。

```rust
函数 主函数() {
    让 水果 = ["苹果", "香蕉", "橘子"];

    对于 水果 在 水果 {
        打印行!("我喜欢吃{}", 水果);
    }
}
```

逐行解释：

- 第 2 行：创建一个数组叫 `水果`，里面有三个元素
- 第 4 行：**对于...在...** 的意思是"对于数组里的每一个元素"。每次循环，`水果` 变量会依次变成"苹果"、"香蕉"、"橘子"
- 第 5 行：显示当前水果名

输出：

```
我喜欢吃苹果
我喜欢吃香蕉
我喜欢吃橘子
```

> **这是最常用的循环方式。** 以后你会经常用到它。

### 范围遍历

**为什么要用范围？** 因为有时候你不需要数组，只想重复某件事一定的次数。比如"把这段话说 5 遍"。

```rust
函数 主函数() {
    // 0..5 表示 0, 1, 2, 3, 4（不包含 5）
    对于 i 在 0..5 {
        打印行!("i = {}", i);
    }

    打印行!("---");

    // 1..=5 表示 1, 2, 3, 4, 5（包含 5）
    对于 i 在 1..=5 {
        打印行!("i = {}", i);
    }
}
```

逐行解释：

- 第 3 行：`0..5` 是一个范围——从 0 到 4（不包含 5）。`i` 依次变成 0、1、2、3、4
- 第 8 行：打印分隔线
- 第 11 行：`1..=5` 是另一个范围——从 1 到 5（包含 5）。`i` 依次变成 1、2、3、4、5

> **记忆技巧**：`..` 是"到但不包括"（像电梯——按 5 楼不会停在 4 和 5 之间），`..=` 是"到且包括"。

### "继续"——跳过这一次

**为什么要跳过？** 因为有时候你遍历一组数据时，遇到某些特殊的值想直接跳过，不处理它。

**`继续`** 的意思是：这一次不做了，直接进入下一次循环：

```rust
函数 主函数() {
    对于 i 在 0..10 {
        如果 i % 2 == 0 {
            继续;  // 跳过偶数，进入下一次
        }
        打印行!("奇数：{}", i);
    }
}
```

逐行解释：

- 第 2 行：`i` 从 0 到 9 逐个取值
- 第 3 行：检查 `i % 2 == 0`——`i` 除以 2 的余数是否为 0（也就是是否为偶数）
- 第 4 行：如果是偶数，**继续**——跳过这一次，直接进入下一个 `i`
- 第 6 行：只有奇数才会执行到这里

输出：

```
奇数：1
奇数：3
奇数：5
奇数：7
奇数：9
```

## 4.4 嵌套控制流

控制流可以互相嵌套——就像俄罗斯套娃，一个套一个。

**为什么要嵌套？** 因为现实世界经常需要"在每种情况下再做判断"。比如打印一个表格——每一行有多列，每个格子要根据位置决定内容。

```rust
函数 主函数() {
    对于 行 在 1..=3 {
        对于 列 在 1..=3 {
            如果 行 == 列 {
                打印!("* ");
            } 否则 {
                打印!(". ");
            }
        }
        打印行!();  // 每行结束后换行
    }
}
```

逐行解释：

- 第 2 行：外层循环——`行` 从 1 到 3
- 第 3 行：内层循环——对于每一行，`列` 从 1 到 3
- 第 4 行：如果行号等于列号（对角线位置），打印星号
- 第 6 行：否则打印点号
- 第 9 行：每一行的三列都打印完后，换行

输出：

```
* . .
. * .
. . *
```

执行过程（逐行逐列）：

```
行=1: 列=1(行==列)→*  列=2(行≠列)→.  列=3(行≠列)→.   → "* . ."
行=2: 列=1(行≠列)→.  列=2(行==列)→*  列=3(行≠列)→.   → ". * ."
行=3: 列=1(行≠列)→.  列=2(行≠列)→.  列=3(行==列)→*  → ". . *"
```

## 4.5 常见错误

### 错误 1：忘记花括号

```rust
如果 真
    打印行!("你好");  // ❌ 缺少花括号
```

**为什么会报错？** 因为 Rust 需要用花括号来明确"条件成立时要做哪些事"。没有花括号，编译器不知道你的代码块从哪里开始、哪里结束。

**修复**：加上 `{}` → `如果 真 { 打印行!("你好"); }`

### 错误 2：匹配没有覆盖所有情况

```rust
让 数字 = 3;
匹配 数字 {
    1 => 打印行!("一"),
    2 => 打印行!("二"),
    // ❌ 缺少 _ 通配符或其他分支覆盖 3
}
```

**为什么会报错？** 因为 Rust 要求匹配必须覆盖所有可能的值。数字可能是任何整数——你只写了 1 和 2，那 3、4、5... 怎么办？

**修复**：加上 `_ => ...`

### 错误 3：无限循环忘记中断

```rust
循环 {
    打印行!("你好");
    // ❌ 没有 中断; → 永远停不下来
}
```

**为什么会出问题？** 因为没有退出条件，程序会永远运行下去。就像一辆没有刹车的车。

**修复**：加上退出条件 → `如果 某条件 { 中断; }`

## 4.6 动手实验

### 实验 1：猜数字游戏

**为什么要做这个实验？** 因为它综合运用了条件分支和循环——程序需要反复猜数字，每次判断大了还是小了。

```rust
函数 主函数() {
    让 答案 = 7;
    让 猜测 = [3, 5, 7, 9];

    对于 猜 在 猜测 {
        打印行!("猜了 {}", 猜);
        如果 猜 < 答案 {
            打印行!("太小了！");
        } 否则 如果 猜 > 答案 {
            打印行!("太大了！");
        } 否则 {
            打印行!("恭喜，猜对了！");
        }
    }
}
```

逐行解释：

- 第 2 行：答案固定为 7
- 第 3 行：猜测列表是 [3, 5, 7, 9]
- 第 5 行：对于列表中的每一个猜测
- 第 6 行：先显示猜了什么
- 第 7-13 行：用条件分支判断——小于答案是"太小"，大于答案是"太大"，等于答案是"猜对了"

### 实验 2：打印乘法表

**为什么要做这个实验？** 因为它展示了嵌套循环的威力——外层控制行，内层控制列。

```rust
函数 主函数() {
    对于 i 在 1..=9 {
        对于 j 在 1..=i {
            打印!("{}×{}={} ", j, i, i * j);
        }
        打印行!();
    }
}
```

### 实验 3：用匹配判断季节

**为什么要做这个实验？** 因为它展示了匹配范围的实际用法。

```rust
函数 主函数() {
    让 月份 = 8;

    匹配 月份 {
        3..=5  => 打印行!("春天"),
        6..=8  => 打印行!("夏天"),
        9..=11 => 打印行!("秋天"),
        _      => 打印行!("冬天"),
    }
}
```

## 4.7 练习题

### 练习 1：成绩评级

写一个程序，根据分数输出等级：
- 90-100: A
- 80-89: B
- 70-79: C
- 60-69: D
- 0-59: F

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 分数 = 85;
    让 等级 = 匹配 分数 {
        90..=100 => "A",
        80..=89  => "B",
        70..=79  => "C",
        60..=69  => "D",
        _        => "F",
    };

}
```

### 练习 2：FizzBuzz

输出 1 到 30，但是：
- 3 的倍数输出 "Fizz"
- 5 的倍数输出 "Buzz"
- 既是 3 又是 5 的倍数输出 "FizzBuzz"

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    对于 i 在 1..=30 {
        如果 i % 15 == 0 {
            打印行!("FizzBuzz");
        } 否则 如果 i % 3 == 0 {
            打印行!("Fizz");
        } 否则 如果 i % 5 == 0 {
            打印行!("Buzz");
        } 否则 {
            打印行!("{}", i);
        }
    }
}
```

</details>

### 练习 3：打印菱形

用嵌套循环输出一个菱形：

```
  *
 ***
*****
 ***
  *
```

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    // 上半部分（含中间最宽行）
    对于 i 在 0..3 {
        对于 _ 在 0..(2 - i) {
            打印!(" ");
        }
        对于 _ 在 0..(2 * i + 1) {
            打印!("*");
        }
        打印行!();
    }
    // 下半部分
    对于 i 在 0..2 {
        对于 _ 在 0..(i + 1) {
            打印!(" ");
        }
        对于 _ 在 0..(3 - 2 * i) {
            打印!("*");
        }
        打印行!();
    }
}
```

</details>

## 本章小结

1. **`如果`/`否则 如果`/`否则`** —— 条件分支。也可以返回值
2. **`匹配`** —— 多模式匹配。必须覆盖所有情况，支持范围 `..=`
3. **`循环`** —— 无限重复，用 `中断` 跳出
4. **`当`** —— 条件循环，条件不满足时停止
5. **`对于 ... 在 ...`** —— 遍历循环，最常用的循环方式
6. **`继续`** —— 跳过当前这一次
