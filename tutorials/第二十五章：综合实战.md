## 25.1 需求：记账本

我们写一个命令行记账本：

> 输入若干条账目（如"餐饮 25 午饭"），程序逐条入账；遇到格式或类别错误就跳过并说明；最后输出**总花费**和**分类统计**。

麻雀虽小五脏俱全——文本解析、错误处理、集合、迭代器，全要上场。

## 25.2 第一步：设计数据

先想"账目长什么样"。类别是有限选项 → **枚举**（第十一章）；一条账目有类别、金额、备注 → **结构体**（第十章）：

```rust
枚举 类别 {
    餐饮,
    交通,
    娱乐,
    其他,
}

结构体 记账条目 {
    类别: 类别,
    金额: 整数,
    备注: 字符串,
}
```

> 💡 **设计心得**：数据模型先行。模型想清楚，函数只是围绕它干活。

## 25.3 第二步：解析——把文字变数据

一行 `"餐饮 25 午饭"` 要过三关：切成三段 → 类别名转枚举 → 金额转数字。任何一关失败都返回**`结果` 的错误**（第十六章）：

```rust
函数 解析类别(名: &文本) -> 结果<类别, 字符串> {
    匹配 名 {
        "餐饮" => 成功(类别::餐饮),
        "交通" => 成功(类别::交通),
        "娱乐" => 成功(类别::娱乐),
        "其他" => 成功(类别::其他),
        别的 => 错误(格式化!("未知类别：{}", 别的)),
    }
}

函数 解析条目(行: &文本) -> 结果<记账条目, 字符串> {
    让 各段: 向量<&文本> = 行.分割(' ').收集();
    如果 各段.长度() != 3 {
        返回 错误(格式化!("格式应为'类别 金额 备注'：{}", 行));
    }
    让 类 = 解析类别(各段[0])?;
    让 金额 = 各段[1].解析::<整数>().解包();
    成功(记账条目 {
        类别: 类,
        金额: 金额,
        备注: 字符串::从(各段[2]),
    })
}
```

注意 `解析类别(各段[0])?`——一个 `?` 就把"类别不认得"的错误接力上去了（第十六章 16.4）。

## 25.4 第三步：统计——哈希映射 + 条目套路

分类累计就是第十五章的**词频套路**：

```rust
函数 分类统计(条目们: &[记账条目]) -> 哈希映射<&文本, 整数> {
    让 可变 统计 = 哈希映射::新建();
    对于 条 在 条目们 {
        让 键 = 匹配 条.类别 {
            类别::餐饮 => "餐饮",
            类别::交通 => "交通",
            类别::娱乐 => "娱乐",
            类别::其他 => "其他",
        };
        让 累计 = 统计.条目(键).或插入(0);
        *累计 = *累计 + 条.金额;
    }
    统计
}
```

枚举转文字键用了一个小技巧：`匹配` 本身是表达式，可以直接赋值（第四章伏笔回收）。

## 25.5 完整代码

```rust
使用 标准库::集合::哈希映射;

// —— 数据设计 ——
枚举 类别 {
    餐饮,
    交通,
    娱乐,
    其他,
}

结构体 记账条目 {
    类别: 类别,
    金额: 整数,
    备注: 字符串,
}

// —— 类别名转枚举（带错误处理） ——
函数 解析类别(名: &文本) -> 结果<类别, 字符串> {
    匹配 名 {
        "餐饮" => 成功(类别::餐饮),
        "交通" => 成功(类别::交通),
        "娱乐" => 成功(类别::娱乐),
        "其他" => 成功(类别::其他),
        别的 => 错误(格式化!("未知类别：{}", 别的)),
    }
}

// —— 一行文本 -> 记账条目："餐饮 25 午饭" ——
函数 解析条目(行: &文本) -> 结果<记账条目, 字符串> {
    让 各段: 向量<&文本> = 行.分割(' ').收集();
    如果 各段.长度() != 3 {
        返回 错误(格式化!("格式应为'类别 金额 备注'：{}", 行));
    }
    让 类 = 解析类别(各段[0])?;
    让 金额 = 各段[1].解析::<整数>().解包();
    成功(记账条目 {
        类别: 类,
        金额: 金额,
        备注: 字符串::从(各段[2]),
    })
}

// —— 统计各类总额 ——
函数 分类统计(条目们: &[记账条目]) -> 哈希映射<&文本, 整数> {
    让 可变 统计 = 哈希映射::新建();
    对于 条 在 条目们 {
        让 键 = 匹配 条.类别 {
            类别::餐饮 => "餐饮",
            类别::交通 => "交通",
            类别::娱乐 => "娱乐",
            类别::其他 => "其他",
        };
        让 累计 = 统计.条目(键).或插入(0);
        *累计 = *累计 + 条.金额;
    }
    统计
}

函数 主函数() {
    让 原始账本 = [
        "餐饮 25 午饭",
        "交通 4 地铁",
        "餐饮 18 奶茶",
        "娱乐 60 电影",
        "买菜 30 超市",
        "交通 2 公交",
    ];

    让 可变 账本 = 向量::新建();
    对于 行 在 原始账本 {
        匹配 解析条目(行) {
            成功(条) => {
                打印行!("入账：{}元（{}）", 条.金额, 条.备注);
                账本.推入(条);
            }
            错误(原因) => 打印行!("跳过（{}）", 原因),
        }
    }

    // 迭代器一步算总额
    让 总花费: 整数 = 账本.迭代().映射(|条| 条.金额).求和();
    打印行!("共 {} 条记录，总花费 {} 元", 账本.长度(), 总花费);

    // 分类统计
    让 统计 = 分类统计(&账本);
    对于 (类, 额) 在 &统计 {
        打印行!("{} 类共 {} 元", 类, 额);
    }
}
```

## 25.6 逐行解释

- **数据区（第 4–16 行）**：枚举圈定四种合法类别；结构体装一条账目的三要素。
- **`解析类别`（第 19–28 行）**：文字 → 枚举。最后一个臂 `别的` 兜住所有未知输入，给出具体原因。
- **`解析条目`（第 31–42 行）**：三关解析。`分割(' ')` 切段、长度校验、`?` 接力类别错误、`解析::<整数>` 转数字、最后组装结构体。
- **`分类统计`（第 45–60 行）**：借词频套路累计每类金额；返回哈希映射给调用方。
- **主函数第一段（第 63–71 行）**：原始数据故意埋一条坏账（"买菜"不是合法类别）。
- **主函数第二段（第 73–82 行）**：逐条解析——成功就打印入账并推入账本，失败就打印跳过原因。**程序没有因为一条坏数据崩溃**——这就是错误处理的价值。
- **主函数第三段（第 85–86 行）**：迭代器链 `迭代 → 映射 → 求和` 一行算出总额（第二十二章）。
- **主函数第四段（第 89–92 行）**：遍历统计表输出。

## 25.9 常见错误与解决（本项目实录）

### 错误一：字段定义了却没用

`备注` 只存不读，编译器提醒"字段从未被读取"。**解决**：要么真用起来（我们在入账打印中用上了），要么删掉。**警告不是噪音，是提醒**。

### 错误二：`解析::<整数>` 忘了尖括号

不知道要转成什么类型就报推断失败。**解决**：永远写全 `解析::<整数>`。

### 错误三：统计遍历顺序"乱"了

以为程序出错了？不是——哈希映射不保证顺序（第十五章）。**解决**：需要有序换 `有序映射`。

## 25.11 毕业挑战

> 🚀 不给答案的升级任务，由易到难。

1. **加测试**：给 `解析条目` 写三条测试（正常行、段数错、类别错）——第二十一章；
2. **拆模块**：把"数据"、"解析"、"统计"拆成三个模块——第十七章；
3. **支持小数金额**：`金额` 改小数类型，输出保留两位——第二章；
4. **读真实文件**：从 `账本.文本` 读入账目——需要标准库文件模块，官方文档见 `std::fs`；
5. **交互式**：循环读取用户输入（需要引入输入库），输 `退出` 结束；
6. **加月份维度**：条目加"月份"字段，统计改成"每月每类"——哈希映射的值再装哈希映射。
