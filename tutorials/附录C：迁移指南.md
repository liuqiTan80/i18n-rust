# 附录C：迁移指南

中文 Rust 是学习工具，但最终你需要过渡到标准 Rust——因为实际的 Rust 项目都是英文的。

好消息是：**你已经学会了 Rust 的核心概念**。迁移只是把中文关键字换成英文。就像你已经学会了做菜，现在只是把中文菜谱翻译成英文菜谱——做法完全一样。

---

## C.1 为什么需要迁移？

1. **实际项目都是英文的**——开源社区、公司代码库都用标准 Rust
2. **文档和错误信息是英文的**——标准 Rust 的学习资源更丰富
3. **团队协作**——团队成员可能不熟悉中文方言

---

## C.2 迁移步骤

### 第一步：导出为标准 Rust

用 `rzc eject` 把中文文件翻译成标准 Rust 文件：

```bash
rzc eject src/main.zh
```

这会生成 `src/main.rs`，内容是标准 Rust。

### 第二步：对照理解

打开生成的 `.rs` 文件，对照映射表（附录 A）理解每行代码：

```rust
// 中文 Rust
函数 主函数() {
    让 名字 = "小明";
    打印行!("你好，{}", 名字);
}

// 标准 Rust
fn main() {
    let 名字 = "小明";
    println!("你好，{}", 名字);
}
```

逐行解释：

- `函数` → `fn`：定义函数的关键字换了
- `让` → `let`：创建变量的关键字换了
- `打印行!` → `println!`：打印宏换了
- 其他部分（变量名、字符串）完全不变

### 第三步：验证标准 Rust 项目

现在你的项目已经是标准 Rust 项目了，直接用 `cargo` 运行验证：

```bash
cargo run
```

能正常运行，说明迁移成功。此时可以把项目里的 `rust-toolchain.toml` 删掉——它锁定的是中文 Rust 工具链要求的编译器版本（1.85），标准项目用你自己安装的 rustc 即可。

> ℹ️ 语言包内置在 `rzc` 程序里，项目目录中本来就没有它，所以**不需要**清理任何语言包文件。

### 第四步：检查项目结构

`rzc init` 生成的项目只有四个文件：`Cargo.toml`、`src/main.zh`、`rust-toolchain.toml` 和 `README.md`。经过前三步：

1. `main.zh` 已用 `rzc eject` 导出成 `main.rs` ✅
2. `rust-toolchain.toml` 已删除 ✅
3. `Cargo.toml` 和 `README.md` 本来就是标准内容 ✅

剩下的就是标准 Rust 项目结构，没有其他需要清理的配置。

## C.3 对照速查表

下面是最常用的关键字对照。不用一次全记住——用多了自然就记住了。

| 中文 Rust | 标准 Rust | 记忆提示 |
|-----------|-----------|---------|
| `函数` | `fn` | 英文"function"的缩写 |
| `让` | `let` | 最短的条件词 |
| `可变` | `mut` | 英文"mutable"的缩写 |
| `如果` | `if` | 最短的条件词 |
| `如果让` | `if let` | 简化版匹配：只关心"是不是这一种情况" |
| `否则` | `else` | 和"如果"配对 |
| `匹配` | `match` | 匹配模式 |
| `循环` | `loop` | 循环 |
| `当` | `while` | 条件循环 |
| `当让` | `while let` | 循环版匹配：只要还是这种情况就重复 |
| `对于` | `for` | 遍历循环 |
| `返回` | `return` | 返回 |
| `结构体` | `struct` | 英文"structure"的缩写 |
| `枚举` | `enum` | 英文"enumeration"的缩写 |
| `实现` | `impl` | 英文"implementation"的缩写 |
| `特征` | `trait` | 特征 |
| `派生` | `derive` | 自动实现特征 |
| `哪里` | `where` | 泛型约束 |
| `模块` | `mod` | 英文"module"的缩写 |
| `公开` | `pub` | 英文"public"的缩写 |
| `使用` | `use` | 使用 |
| `宏规则` | `macro_rules` | 声明宏 |
| `真` | `true` | 真 |
| `假` | `false` | 假 |

## C.4 心态调整

迁移时最重要的不是记住英文关键字，而是理解：

1. **概念不变**——所有权、借用、特征、生命周期……这些概念在两种方言中完全相同
2. **语法几乎不变**——只是关键字换了名字，语法结构一模一样
3. **你已经有了优势**——你理解了 Rust 的核心，现在只需要学"词汇"

### 建议的过渡计划

| 阶段 | 时间 | 内容 |
|------|------|------|
| 第 1 周 | 对照翻译 | 用 `rzc eject` 对照中英文 |
| 第 2 周 | 混合编写 | 尝试直接用英文写简单代码 |
| 第 3 周 | 全英文 | 完全使用标准 Rust |
| 第 4 周 | 阅读源码 | 阅读开源 Rust 项目 |

---

## C.5 推荐资源

迁移到标准 Rust 后，推荐以下学习资源：

1. **官方教程** —— 最权威的学习资料
2. **通过示例学习** —— 看代码学语言
3. **小练习** —— 动手做练习题
4. **官方文档** —— 最全面的参考

---

> **记住**：中文 Rust 不是"玩具"，它是你通往 Rust 世界的桥梁。你已经走过了最难的部分——理解概念。现在，只是换个名字而已。
