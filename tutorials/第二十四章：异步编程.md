# 第二十三章：异步编程

现代程序经常需要同时做多件"等待"的事——下载文件、查询数据库、等待用户输入。

**同步**方式是一个接一个等。**异步**方式是同时开始所有等待，哪个先完成就先处理哪个。

---

## 23.1 同步和异步的区别

> **生活类比**：
> - **同步**：你在餐厅点了 3 道菜，服务员一道一道上——做完第一道才做第二道。
> - **异步**：你同时点了 3 道菜，厨房同时做，哪道好了先上哪道。

```
同步（一个接一个）：
时间线 ──────────────────────────────→
  下载A: ████████████
  下载B:              ████████████
  下载C:                           ████████████
  总耗时：30 秒

异步（同时进行）：
时间线 ──────────────────────────────→
  下载A: ████████████
  下载B: ████████████
  下载C: ████████████
  总耗时：10 秒
```

**为什么要用异步？** 因为快。如果三件事都是"等待"（等网络、等磁盘），同时开始比一个一个等快得多。

### 为什么不用多线程？

多线程也能同时做多件事，但每个线程占用很多内存（约 2-8MB）。如果你需要同时处理 10 万个连接，多线程方案需要 200GB 内存。

异步任务只需要几百字节——10 万个异步任务只需几十 MB。

| 对比 | 多线程 | 异步 |
|------|--------|------|
| 内存 | 大（每个 MB 级） | 小（每个 KB 级） |
| 适合 | 大量计算 | 大量等待（网络、文件） |
| 并发量 | 千级 | 十万级 |

## 23.2 异步函数

> **生活类比**：异步函数就像**外卖订单**——你下单后不会立刻拿到食物，而是拿到一个"取餐号"（代表"将来某个时刻能取到"）。你可以继续做别的事，等叫号了再去取。

用 **`异步`** 标记一个函数为异步函数：

> 注意：下面代码里的 `睡眠` 是 tokio 库提供的函数，完整的可运行写法见 23.4 节。这里先看语法。

```rust
// 异步函数返回一个"未来"（取餐号）
异步 函数 获取用户信息(用户ID: 整数) -> 字符串 {
    // 模拟网络请求（需要等待）
    睡眠(持续时间::从秒(1)).等待;
    格式化!("用户{}的信息", 用户ID)
}
```

逐行解释：

- 第 2 行：**`异步 函数`** 表示这是一个异步函数——"不会立刻给你结果"
- 第 4 行：**`睡眠(...).等待`** 模拟网络延迟——"等一秒钟"。`睡眠` 是"睡一会"的函数，`.等待` 是"等到它完成"（下面会详讲）
- 第 5 行：返回结果

异步函数不会立即执行，它返回一个**`未来`**——代表"将来某个时刻会完成的值"。就像外卖订单给你一个取餐号——"将来凭这个号取餐"。

### 等待关键字

用 **`.等待`** 等待一个异步操作完成——"等到取餐号对应的食物做好"。注意写法：**`操作.等待`**——在要等待的操作后面加一个 `.等待`（Rust 的 `await` 就是这么写的）：

```rust
异步 函数 主函数() {
    打印行!("开始下载...");

    让 页面 = 下载页面("https://example.com").等待;

    打印行!("下载完成：{} 字节", 页面.长度());
}
```

逐行解释：

- 第 2 行：打印提示信息
- 第 4 行：**`下载页面(...).等待`** 开始下载并等待结果——"等外卖做好"
- 第 4 行：`.等待` 不会"卡住"程序——它让出控制权，让程序去处理其他任务
- 第 6 行：下载完成后才能走到这里

## 23.3 同时做多个异步任务

### 顺序执行（慢）

```rust
异步 函数 主函数() {
    // ❌ 一个接一个，总耗时 = A + B
    让 a = 任务A().等待;  // 等 3 秒
    让 b = 任务B().等待;  // 再等 3 秒
    打印行!("总耗时 6 秒");
}
// 假设 任务A()、任务B() 是两个异步函数
```

### 并发执行（快）

```rust
异步 函数 主函数() {
    // ✅ 同时开始，总耗时 = 最慢的那个
    让 (a, b) = tokio::连接!(任务A(), 任务B());
    打印行!("总耗时 3 秒");
}
// 假设 任务A()、任务B() 是两个异步函数
```

> 📌 **注意**：`tokio::连接!`（对应 Rust 的 `tokio::join!`）是 tokio 提供的"同时开始"宏——它自己会等所有任务完成，所以**后面不用再加 `.等待`**。

```
顺序执行：
任务A: ████████████
任务B:              ████████████
总计: 6 秒

并发执行：
任务A: ████████████
任务B: ████████████
总计: 3 秒
```

**为什么要同时执行？** 因为如果两个任务互不依赖（A 的结果不影响 B），同时开始可以节省一半时间。

## 23.4 异步运行时

Rust 标准库**不包含**异步运行时——它只定义了"未来"的概念。你需要选择一个"调度员"来管理异步任务：

| 运行时 | 特点 | 适合 |
|--------|------|------|
| **tokio** | 最流行，功能全面 | 网络服务 |
| **async-std** | 模仿标准库风格 | 喜欢标准库风格 |
| **smol** | 极简轻量 | 小型项目 |

本教程以 **tokio** 为例。在配置文件中添加依赖：

```toml
[依赖]
tokio = { 版本 = "1", 特征 = ["full"] }
```

### 使用 tokio

```rust
// tokio 提供的标记，把主函数变成异步的
使用 tokio::time::持续时间;

#[tokio::主函数]
异步 函数 主函数() {
    打印行!("你好，异步世界！");

    // 生成异步任务
    让 任务句柄 = tokio::生成异步(异步 {
        tokio::time::睡眠(持续时间::从秒(1)).等待;
        打印行!("任务完成！");
        42
    });

    让 页面 = 任务句柄.等待.解包();
    打印行!("结果：{}", 页面);  // 42
}
```

逐行解释：

- 第 1 行：**`使用 tokio::time::持续时间;`** 把 tokio 的 `持续时间`（时长）类型导进来
- 第 3 行：**`#[tokio::主函数]`** 把主函数变成异步的——"tokio 调度员来管理主函数"
- 第 7 行：**`tokio::生成异步(异步 { ... })`** 创建一个异步任务——"派一个工人去做这件事"
- 第 8 行：异步任务内部等待 1 秒（`.等待` 就是上一节说的"等它完成"）
- 第 12 行：**`任务句柄.等待.解包()`** 等待异步任务完成并拿到结果——`.解包()` 是"取出成功的结果"（第十五章讲过）。注意变量名用 `任务句柄`，因为 `任务` 在映射表里是关键字（对应 `task`），不能当普通变量名

## 23.5 超时处理

> **生活类比**：等外卖不能无限等——超过 30 分钟没到就取消订单。**超时**就是这个意思——"最多等这么久，等不到就算了"。

```rust
使用 tokio::time::{超时, 持续时间};

#[tokio::主函数]
异步 函数 主函数() {
    让 超时结果 = 超时(持续时间::从秒(5), 慢速请求()).等待;

    匹配 超时结果 {
        成功(内容) => 打印行!("成功：{:?}", 内容),
        错误(_) => 打印行!("超时了！"),
    }
}

异步 函数 慢速请求() -> 字符串 {
    tokio::time::睡眠(持续时间::从秒(10)).等待;  // 模拟慢请求
    "数据".转字符串()
}
```

逐行解释：

- 第 6 行：**`超时(5秒, 慢速请求())`** 意思是"最多等 5 秒"
- 第 8-9 行：如果 5 秒内完成，返回 `成功(结果)`；超时则返回 `错误(超时信息)`（这里用 `_` 表示"不管超时信息是什么"，第十章讲过下划线 = 忽略）
- 第 13 行：慢速请求需要 10 秒，但超时只等 5 秒——所以会超时

## 常见错误

### 在异步中使用同步阻塞

```rust
使用 标准库::线程::线程休眠;

// ❌ 这会卡住整个异步系统！
异步 函数 坏例子() {
    线程休眠(持续时间::从秒(5));  // 同步阻塞！
}

// ✅ 用异步睡眠
异步 函数 好例子() {
    tokio::time::睡眠(持续时间::从秒(5)).等待;  // 不卡住
}
```

**为什么？** 因为同步阻塞会让整个异步系统停下来——所有其他任务都等着。异步睡眠只让当前任务等，其他任务照常运行。

### 忘记移动

```rust
让 数据 = 向量![1, 2, 3];
tokio::生成异步(异步 {
    // ❌ 编译器报错：数据可能被释放
    打印行!("{:?}", 数据);
});

// ✅ 用"移动"获取所有权
tokio::生成异步(异步 move {
    打印行!("{:?}", 数据);
});
```

写一个异步程序，同时"下载" 3 个页面，计算总耗时。

异步 函数 下载页面(名字: &文本, 延迟秒: 无符号长整数) -> 字符串 {

## 本章小结

| 概念 | 一句话 |
|------|--------|
| 同步 vs 异步 | 一个一个等 vs 同时开始所有等待 |
| `异步 函数` | 外卖订单——不会立刻给你结果 |
| `未来` | 取餐号——代表"将来能拿到的值" |
| `.等待` | 等到食物做好——但不卡住其他人 |
| `tokio::连接!` | 同时开始多个任务 |
| `超时` | 最多等这么久，等不到就算了 |
