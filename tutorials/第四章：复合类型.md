# 第四章：复合类型

前两章，每个盒子只装一样东西。这一章，我们学"打包"——把好几样东西装进一个包里。

---

## 4.0 学习目标

读完这一章，你将能够：

1. 用**元组**把几样不同的东西打包在一起，并能拆开取用。
2. 用**数组**存放一排同类的数据，并用编号取出任何一个。
3. 用**切片**只借用数组的一段，而不复制整排数据。
4. 说出"索引从 0 开始"的原因，不再被它绊倒。

---

## 4.1 为什么需要打包

### 生活故事：转学的档案袋

想象你要转学。学校给你的不是一个盒子，而是一个**档案袋**：里面有姓名、年龄、成绩……很多张不同的纸，装在一个袋子里，走到哪带到哪。

编程也一样。一个学生的信息有好几项：

- 姓名（文字）
- 年龄（数字）
- 是否住宿（真或假）

如果每项都用单独的盒子，盒子一多就乱。更好的办法是**打包**。

本章学三种打包方式：

| 打包方式 | 比喻       | 适合装什么                     |
|----------|-----------|--------------------------------|
| 元组     | 礼物盒     | 几样**不同**的东西捆在一起 |
| 数组     | 一排储物柜 | 一排**相同种类**的东西，数量固定 |
| 切片     | 一扇窗户   | 不搬走整排柜子，只看其中一段 |

## 4.2 元组：一个礼物盒，装几样不同的东西

### 创建元组

用圆括号把几样东西括起来，中间用逗号分开，就是一个元组：

```rust
让 学生 = ("小华", 12, 真);
```

逐字解释：

- `("小华", 12, 真)`：一个礼物盒，里面装了**三样东西**——一段文字、一个数字、一个布尔值。三样东西种类不同，完全没关系，元组就是能混装。
- 这三样东西叫做元组的**元素**（就是"成员"的意思）。这个元组有 3 个元素。

> 📖 **元组**：英文 tuple（读作"图婆"）。把几个值打包成一组的复合类型。元素之间可以种类不同。

### 取用元组里的东西：编号从 0 开始

想拿出元组里的某一样，在元组名字后面写 `.编号`：

```rust
函数 主函数() {
    让 学生 = ("小华", 12, 真);
    打印行!("第一项：{}", 学生.0);
    打印行!("第二项：{}", 学生.1);
    打印行!("第三项：{}", 学生.2);
}
```

运行结果：

```
第一项：小华
第二项：12
第三项：true
```

> ⚠️ **小心**：**编号从 0 开始，不是从 1 开始！** 第一个元素的编号是 0，第二个是 1，第三个是 2。

这是全编程世界通用的规矩。为什么？下一章讲数组时一起解释，现在先记住：**数编号时，第一个数"0"**。

> 📖 **索引**：就是这里的"编号"。正式名字叫索引，意思是"查东西用的号码"。全书两个词通用，看到索引就想到编号。

### 一口气拆开元组：解构

如果三样东西都想拿出来，可以一次拆包：

```rust
函数 主函数() {
    让 学生 = ("小华", 12, 真);
    让 (姓名, 岁数, 是否住宿) = 学生;
    打印行!("{}今年{}岁", 姓名, 岁数);
    打印行!("住宿吗？{}", 是否住宿);
}
```

逐行解释：

- 第 3 行：`让 (姓名, 岁数, 是否住宿) = 学生;` —— 等号左边也写一个括号形状，表示"把包拆成三份"。计算机按位置一一对应：第 1 样给 `姓名`，第 2 样给 `岁数`，第 3 样给 `是否住宿`。
- 拆完后，三个名字各自成为独立的盒子。

> 📖 **解构**：把打包的数据按形状拆开、分别取出的写法。英文 destructure。"解"是解开，"构"是结构。

> 💡 **比喻**：解构就像拆快递——包裹里有三件东西，你准备三个篮子，一次全分好。

运行结果：

```
小华今年12岁
住宿吗？true
```

### 打印整个元组：`{:?}`

想把整个元组一次打印出来，占位符要写成 `{:?}`（花括号里多一个冒号和问号）：

```rust
函数 主函数() {
    让 学生 = ("小华", 12, 真);
    打印行!("整个元组：{:?}", 学生);
}
```

运行结果：

```
整个元组：("小华", 12, true)
```

> 📖 **调试打印**：`{:?}` 是"调试用"的打印方式，会把东西的内部结构原样展示出来（连引号、括号都印出来）。普通 `{}` 打印的是给人看的干净样子。调试打印的完整故事在第十章讲。

> ⚠️ **小心**：用普通 `{}` 直接打印元组会报错。元组必须用 `{:?}`。

## 4.3 数组：一排编号固定的储物柜

### 创建数组

想象学校走廊里有一排储物柜，每个柜子大小一样，都用来放同一种东西（比如都放分数）。这就是**数组**。

用**方括号**创建数组，元素之间用逗号：

```rust
让 分数 = [88, 95, 76, 90, 82];
```

这个数组装了一周五天的分数，一共 5 个元素。

> 📖 **数组**：一排**固定长度**、**同一种类**的数据。英文 array。方括号 `[ ]` 是数组的标志。

> ⚠️ **小心**：方括号 `[ ]` 和圆括号 `( )` 别搞混——方括号是数组（一排同类），圆括号是元组（几样不同）。

### 快速创建重复数组

如果一排柜子要放同样的东西，有简写：

```rust
让 五个零 = [0; 5];
```

> 📖 这个写法读作"0 重复 5 次"：分号前面是内容，后面是个数。相当于 `[0, 0, 0, 0, 0]`。

```rust
打印行!("{:?}", 五个零);   // [0, 0, 0, 0, 0]
```

### 用索引取柜子：编号从 0 开始

```rust
函数 主函数() {
    让 分数 = [88, 95, 76, 90, 82];
    打印行!("第一天：{}", 分数[0]);
    打印行!("第三天：{}", 分数[2]);
    打印行!("最后一天：{}", 分数[4]);
}
```

运行结果：

```
第一天：88
第三天：76
最后一天：82
```

画图看最清楚：

```
柜子:  [ 88 ]  [ 95 ]  [ 76 ]  [ 90 ]  [ 82 ]
索引:     0       1       2       3       4
```

5 个柜子，索引却是 0 到 4。想要第 N 个，索引要写 N-1。

### 为什么从 0 开始？

给你一个能说服自己的理由：

索引的意思是"**从开头往前走多少步**"。

- 第 1 个柜子：从开头走 **0** 步就到 → 索引 0。
- 第 2 个柜子：从开头走 **1** 步 → 索引 1。
- 第 5 个柜子：走 **4** 步 → 索引 4。

> 💡 **比喻**：就像量身高——尺子的"0 刻度"贴着地面。第一个厘米的刻度是 0，不是 1。索引就是"距离起点多少步"。

### 数组的两个常用本领

**本领一：`长度()`——数一数有几个柜子**

```rust
打印行!("共{}天", 分数.长度());   // 共5天
```

> 📖 **`长度()`**：方法名，英文原名 len（length 的缩写）。点号后面跟方法，括号里不装东西，它返回元素个数。"方法"是什么？第六章详细讲，现在先把 `.长度()` 当成一个固定口诀来用。

**本领二：`包含()`——查一查某个值在不在**

```rust
打印行!("有95分吗？{}", 分数.包含(&95));   // 有95分吗？true
```

> 📖 **`包含()`**：方法名，英文原名 contains。检查数组里有没有某个值，返回布尔值。括号里的 `&95` 先照抄——`&` 是"借用"记号，第八章详细讲，现在知道"查包含要加 &"就行。

### 越界：够不存在的柜子会出大事

数组只有 5 个柜子（索引 0–4），如果你硬要第 6 个：

```rust
函数 主函数() {
    让 分数 = [88, 95, 76, 90, 82];
    打印行!("{}", 分数[5]);   // ❌ 越界！
}
```

Rust 会立刻**恐慌**，程序当场停止。

> 📖 **恐慌**：英文 panic。程序遇到无法挽回的错误时，大喊一声"出事了！"然后立刻停止，绝不带病运行。就像火警警报一响，大家立刻停止手头的事撤离。第十六章详细讲。

恐慌时会显示这样的话：

```
thread 'main' panicked at ...:
index out of bounds: the len is 5 but the index is 5
```

翻译过来就是："索引越界了：长度是 5，可你要的编号是 5。"（编号最大只能是 4！）

> ✨ **小提示**：如果你写的是**固定的**越界编号（比如直接写 `分数[5]`），运行 `rzc run` 时编译器会在编译阶段就拦下来，显示"this operation will panic at runtime"（这个操作运行时会恐慌），程序根本跑不起来。只有编号来自外部、编译时猜不到的情况，才会真的运行时恐慌。总之 Rust 绝不会让你悄悄拿到错误的数据。
>
> ⚠️ **小心**：`rzc check` 只做翻译检查，拦不住这种越界。要发现它，得真正运行 `rzc run`。

> 📖 **索引越界**：访问了超出范围的编号。英文说 index out of bounds。bounds 是"边界"的意思。

## 4.4 切片：一扇看数组的窗户

### 不想搬走整排柜子，只想看其中几个？

假设你只想看前三天的分数。把前三个复制一份到新数组，太浪费。**切片**提供更聪明的办法：不复制，只"指"着原数组的一段。

> 📖 **切片**：对数组中**一段连续元素**的引用。英文 slice，本义就是"切片"——像切香肠，切下来一片，但香肠本体还在。

写法：在数组后面写 `[开始..结束]`，前面加 `&`：

```rust
函数 主函数() {
    让 分数 = [88, 95, 76, 90, 82];
    让 前三天 = &分数[0..3];
    打印行!("前三天：{:?}", 前三天);
    打印行!("切片长度：{}", 前三天.长度());
}
```

运行结果：

```
前三天：[88, 95, 76]
切片长度：3
```

逐字解释 `&分数[0..3]`：

| 部分 | 意思 |
|---|---|
| `&` | 借用（不拿走本体，第八章详讲） |
| `分数` | 被切的数组 |
| `[0..3]` | 从索引 0 开始，到索引 3 **之前**结束——即包含 0、1、2 三个 |

> ⚠️ **小心**：`0..3` 是"**含头不含尾**"——包含 0，不包含 3。数一数正好 3 个元素。这个规矩全书通用。

> 📖 **范围**：`开始..结束` 这种写法叫范围，英文 range。意思是"从几到几"。

### 省略写法

```rust
让 从头到第三 = &分数[..3];    // 开头省略 = 从 0 开始
让 从第三到底 = &分数[2..];    // 结尾省略 = 一直到最后一个
让 全部 = &分数[..];           // 两头都省略 = 整段
```

```rust
打印行!("{:?} {:?} {:?}", 从头到第三, 从第三到底, 全部);
// [88, 95, 76] [76, 90, 82] [88, 95, 76, 90, 82]
```

### 文字也能切

字符串也可以切（字符串的详细内容第九章讲，这里先见个面）：

```rust
让 问候 = &"你好世界"[0..6];
打印行!("{}", 问候);   // 你好
```

> ⚠️ **小心**：这里写 0..6 而不是 0..2，因为中文每个字在计算机里占 3 个"字节"（存储的小格子），"你好"两个字占 6 格。字节是什么？第九章详细讲。现在照抄 0..6 就好。

## 4.5 完整示例：一周成绩管理

### 完整代码

```rust
函数 主函数() {
    // 一周的分数（周一到周五）
    让 一周分数 = [88, 95, 76, 90, 82];

    // 把一周切成两半看
    让 前两天 = &一周分数[0..2];
    让 后三天 = &一周分数[2..5];

    打印行!("一周分数：{:?}", 一周分数);
    打印行!("共{}天", 一周分数.长度());
    打印行!("前两天：{:?}", 前两天);
    打印行!("后三天：{:?}", 后三天);

    // 手动求总分和平均分
    让 总分 = 一周分数[0] + 一周分数[1] + 一周分数[2] + 一周分数[3] + 一周分数[4];
    让 总分为小数 = 总分 作为 浮点数;
    让 平均分 = 总分为小数 / 5.0;
    打印行!("总分：{} 平均分：{}", 总分, 平均分);

    // 学生信息用元组打包
    让 学生 = ("小华", 12, 真);
    让 (姓名, 岁数, 是否住宿) = 学生;
    打印行!("{}今年{}岁，住宿：{}", 姓名, 岁数, 是否住宿);
    打印行!("元组第二项：{}", 学生.1);
}
```

### 逐行解释

- 第 3 行：创建数组装五天分数。方括号 = 数组。
- 第 6 行：切出索引 0、1 两个元素（含头不含尾）。
- 第 7 行：切出索引 2、3、4 三个元素，正好是剩下的三天。
- 第 9 行：`{:?}` 调试打印整个数组，会带上中括号。
- 第 10 行：`.长度()` 返回 5。
- 第 11–12 行：打印两个切片。
- 第 15 行：把 5 个元素逐个取出相加 = 431。（第五章学循环后，一行就能搞定，不用这么笨地写五个。）
- 第 16 行：转成小数（拆成两行写，避开 `作为` 的优先级坑，第三章讲过）。
- 第 17 行：431.0 除以 5.0 = 86.2。
- 第 20 行：创建三元组：文字、数字、布尔混装。
- 第 21 行：解构，三个名字按位置各取一样。
- 第 22 行：用解构出来的三个盒子打印。
- 第 23 行：用 `.1` 直接取元组第二项（编号从 0 开始，所以 `.1` 是第二项 12）。

### 运行结果

```
一周分数：[88, 95, 76, 90, 82]
共5天
前两天：[88, 95]
后三天：[76, 90, 82]
总分：431 平均分：86.2
小华今年12岁，住宿：true
元组第二项：12
```

## 4.6 常见错误与解决

### 错误 1：索引越界

数组 5 个元素，最大索引是 4。写 `分数[5]` 就越界。

**修法**：最大索引永远是 `长度() - 1`。拿不准就先打印 `.长度()` 看看。

### 错误 2：编号从 1 开始数

想取第一个却写 `分数[1]`，拿到的是第二个。

**修法**：背口诀——"**第一个是 0**"。

### 错误 3：元组用方括号取

```rust
让 学生 = ("小华", 12, 真);
打印行!("{}", 学生[0]);   // ❌ 元组不用方括号
```

**修法**：元组用**点**：`学生.0`。数组才用方括号。口诀：**元组点，数组方**。

### 错误 4：`包含` 忘写 `&`

```rust
分数.包含(95)    // ❌ 报错
分数.包含(&95)   // ✅ 正确
```

**修法**：照抄 `&`，原理第八章讲。

### 错误 5：数组元素种类混搭

```rust
让 混合 = [1, "二", 3];   // ❌ 数组必须同一种类
```

**修法**：想混装就用元组 `(1, "二", 3)`；数组只装同一种类。

### 超前实验：亲眼看看越界恐慌（选做）

下面这个例子用到了"环境变量"等后面的知识，每一行都给你注释，照着做就能看到真实的恐慌信息：

```rust
使用 标准库::环境::环境变量;

函数 主函数() {
    让 分数 = [88, 95, 76];
    // 从电脑的环境变量里读一个叫 idx 的值（相当于程序外的"传话"）
    让 文字 = 环境变量("idx").期望("请设置环境变量");
    // 裁剪掉首尾的空白
    让 干净文字 = 文字.裁剪();
    // 把文字变成数字。: 无符号机器整数 表示"专门用来数数的整数"
    让 下标: 无符号机器整数 = 干净文字.解析().期望("要数字");
    打印行!("分数是：{}", 分数[下标]);
}
```

Linux / macOS 上运行（先输入编号 5，故意越界）：

```bash
idx=5 rzc run src/main.zh
```

你会看到真实的恐慌信息：

```
thread 'main' panicked at ...:
index out of bounds: the len is 3 but the index is 5
```

再试合法的编号：

```bash
idx=1 rzc run src/main.zh
```

输出：`分数是：95`。

> ✨ **小提示**：Windows PowerShell 里设置环境变量要写 `$env:idx="5"` 再运行。这个实验里的 `环境变量`、`裁剪`、`解析`、`期望` 都会在后面章节正式学到，现在只是让你提前见见恐慌的样子。

### 练习 2：拆包

把练习 1 的元组用解构拆成三个变量，再用一句话打印：`北京有2189万人，是首都`。

### 练习 3：数组取数

创建数组 `气温`，装七天温度：`[22, 25, 27, 24, 23, 26, 28]`。打印第一天、第四天、最后一天的温度，以及数组长度。

### 练习 4：切片

用练习 3 的气温数组，切出"周末"（最后两天）和"工作日"（前五天），分别打印。

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 气温 = [22, 25, 27, 24, 23, 26, 28];
    让 工作日 = &气温[0..5];
    让 周末 = &气温[5..7];

    打印行!("周末：{:?}", 周末);

```

周末也可以写成 `&气温[5..]`（省略结尾 = 到底）。

</details>

### 练习 5（挑战）：找错

下面的代码运行会出什么事？怎么改？

```rust
函数 主函数() {
    让 三个数 = [1, 2, 3];
    打印行!("{}", 三个数[3]);
}
```

<details>
<summary>参考答案</summary>

数组只有 3 个元素，索引最大是 2。`三个数[3]` 越界。因为写的是固定编号，`rzc run` 时编译器会在编译阶段直接拦截，提示"this operation will panic at runtime"（运行时会恐慌）。改成 `三个数[2]` 就能拿到 3。

</details>

## 4.9 常见问题（FAQ）

**问 1：元组和数组到底什么时候用哪个？**

答：看装的东西。几样**不同种类**的信息捆一起（姓名+年龄+标志）→ 元组。一排**同种类**的数据（五天分数）→ 数组。

**问 2：为什么索引从 0 开始这么反直觉？**

答：因为索引的本义是"从起点走几步"。第一个元素一步都不用走，所以是 0。全世界的主流语言（Rust、C、Java、Python……）都这样，习惯后你会发现"含头不含尾"的范围写法也变得很自然。

**问 3：数组长度定好了还能变吗？**

答：不能。数组长度是固定的。想要"能变长的收纳盒"，那是**向量**，第十五章的主角。

**问 4：`{:?}` 里的 `:?` 是什么意思？**

答：`?` 表示"调试格式"。`{}` 是给人看的漂亮样子，`{:?}` 是给程序员检查用的完整结构。第十章会讲它们背后的机制。

**问 5：切片的 `&` 一定要写吗？**

答：要。切片是对原数组的"借用"，`&` 就是借用的记号。不写 `&` 会报错。第八章讲透。

**问 6：`[0..3]` 到底包含 3 吗？**

答：不包含。含头不含尾：包含 0、1、2。想包含 3 就写 `[0..4]`。口诀：**终点永远差一步**。

## 本章小结

1. **元组**：圆括号打包，种类可不同，`.0`、`.1` 取用，解构一次拆包。
2. **数组**：方括号一排同类，长度固定，索引起于 0。
3. **切片**：`&数组[开始..结束]`，含头不含尾，只借不搬。
4. `.长度()` 数个数，`{:?}` 调试打印，越界必出事、Rust 必拦截。
