# Глава 1: Настройка редактора

## 1.0 Цели главы

К концу этой главы вы сможете:

1. Объяснить, что такое **редактор кода** и почему «Блокнота» мало;
2. Установить **VS Code**, расширение **rust-analyzer** и расширение **i18n-rust**;
3. Создать папку для практики и первый файл `.ru`;
4. Установить компилятор **rzc** — сердце обучения на родном языке;
5. Знать, где искать любую команду позже — палитра команд.

> ✨ Эта глава не требует знаний программирования — только клики мышью. В каждом разделе есть блок «попробуйте»; пройдите его один раз — и он ваш.

## 1.1 Зачем вообще редактор

### Чистый лист и наклейки

💡 **Метафора**: писать код в «Блокноте» — как писать сочинение пальцем на песке. Можно, но мучительно. **Редактор кода** — это блокнот, специально устроенный для кода: он раскрашивает слова, подсвечивает ошибки на лету и запускает программы одной кнопкой.

Редактор этой книги — **VS Code**: бесплатный, мощный, самый популярный в мире.

📖 **Расширение**: небольшая надстройка для редактора — как корзинка на велосипед. Сам по себе VS Code — хороший блокнот; расширения обучают его новым трюкам.

Для этой книги важны два расширения:

- **rust-analyzer** — официальное расширение Rust: подсветка синтаксиса, волнистые линии под ошибками, автодополнение. Незаменимо.
- **i18n-rust** — расширение этого проекта: переводит сообщения об ошибках Rust на 10 языков с учебными подсказками и добавляет объяснения с помощью ИИ. **Для тех, кто пишет на русском, оно обязательно**: именно оно понимает файлы `.ru` и переводит ошибки на русский.

## 1.2 Установка инструментов

### Шаг первый: установите VS Code

1. Зайдите на https://code.visualstudio.com и скачайте установщик для своей системы;
2. Установите (настройки по умолчанию подойдут) и откройте.

Вы увидите страницу приветствия. Пока не обращайте внимания.

### Шаг второй: установите расширение rust-analyzer

1. Нажмите на значок **Расширения** в левой панели (четыре квадратика);
2. Введите в поиске `rust-analyzer`;
3. Нажмите **Установить** у расширения от «The Rust Programming Language» (или «rust-lang»).

### Шаг третий: установите инструментарий Rust

Расширению нужен компилятор Rust. Если ещё не установили — установите сейчас (подробное описание в Главе 2, раздел 2.4):

- **Linux / macOS**: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
- **Windows**: скачайте rustup-init с https://rustup.rs и запустите.

После установки **закройте и снова откройте** VS Code (свежие инструменты находят только новые процессы), затем проверьте:

1. Откройте встроенный терминал VS Code: меню **Терминал → Создать терминал**;
2. Введите `rustc --version` и нажмите Enter — номер версии означает успех.

### Шаг четвёртый: i18n-rust и rzc

Писать на русском — значит писать **на своём родном языке**. Для этого нужны два элемента этого проекта:

Расширение **i18n-rust** ставится из маркетплейса так же, как rust-analyzer: поиск `i18n-rust`, кнопка **Install**. Оно делает три вещи: подсвечивает файлы `.ru`, переводит сообщения об ошибках на русский с учебными подсказками и даёт ИИ-объяснения (со своим ключом).

Компилятор **rzc** ставится из терминала:

```bash
cargo install rzc
```

rzc — это переводчик-компилятор: он превращает русские ключевые слова в стандартный Rust и передаёт обычному rustc. Каждую программу этой книги вы будете запускать именно им.

## 1.3 Первое знакомство с подсветкой синтаксиса

📖 **Подсветка синтаксиса**: редактор раскрашивает разные части кода разными цветами. Как учебник с **жирными терминами** и **красными словечками** — глаз сразу отделяет структуру.

### Попробуйте

Создайте тренировочный файл:

1. Нажмите `Ctrl + N` — новый пустой файл;
2. Нажмите `Ctrl + S`, назовите его `test.ru`, сохраните в папке для практики (**расширение обязательно `.ru`**);
3. Наберите эту программу (по буквам — полезная практика):

```rust
функция главная() {
    пусть имя = "Ваня";
    пусть возраст = 20;
    печатай_строку!("Меня зовут {}, мне {} лет.", имя, возраст);
}
```

Сохраните (`Ctrl + S`) и обратите внимание:

- `функция`, `пусть` — **ключевые слова** одного цвета;
- `"Меня зовут..."` — **строки** другого;
- `20` — **числа** третьего.

Точная палитра зависит от темы оформления — но точно **больше не всё белое**.

> 💡 Зачем цвет? Настоящий код длинный; цвет показывает «ключевое слово или содержимое» с одного взгляда. Как карта с зелёными парками и синими реками — читать куда легче серой.

### Расширение `.ru` важно

i18n-rust работает только с распознанными файлами `.ru`. Если файл называется `test.txt` — ни цветов, ни волнистых линий.

**Как проверить**: имя файла кончается на `.ru`? В правом нижнем углу написано `Rust`?

## 1.4 Запуск программ: три способа

Запустить программу можно тремя способами — начните с самого простого, а потом выберите любимый.

### Способ первый: кнопка ▶

Откройте `test.ru` и посмотрите **правый верхний угол вкладки редактора**: кнопки ▶ (запуск) и ✓ (проверка) — их даёт расширение i18n-rust.

- ▶ = запустить программу (rzc переводит, компилирует и выполняет);
- ✓ = только проверить.

Вывод появится в **панели терминала** внизу.

> 📖 **Панель терминала**: терминал, встроенный в низ VS Code, — чёрное окно командной строки, перенесённое внутрь, чтобы не переключать окна.

### Способ второй: контекстное меню

**Щёлкните правой кнопкой** по коду: в меню будут «Run», «Check» и команды форматирования.

### Способ третий: терминал (честный способ)

Один файл — одна команда:

```bash
rzc run test.ru
```

> 📖 **Горячая клавиша**: сочетание клавиш, выполняющее действие без мыши. Как знание таблицы умножения — быстрее долгого сложения.

### Попробуйте: сломайте нарочно, увидьте красную волнистую линию

Добавьте в код строку:

```rust
// 预期错误: E0308
пусть возраст: целое = "двадцать";
```

После сохранения под строкой появится **красная волнистая линия**; наведите мышь — всплывёт причина: несоответствие типов. Ошибка видна, даже ничего не запуская.

> 📖 **Диагностика**: проверка ошибок в реальном времени, нарисованная волнистыми линиями. Как красные пометки во врачебном заключении.

> ⚠️ **Внимание**: волнистые линии требует, чтобы работал языковой сервер (i18n-rust / rust-analyzer). Если через несколько секунд после открытия файла их нет — см. раздел 1.9.

### Ошибки, по которым можно кликнуть: панель «Проблемы»

Нажмите `Ctrl + Shift + M` — откроется **панель «Проблемы»** со всеми ошибками и предупреждениями файла. Кликните по ошибке — курсор прыгнет на сломанную строку.

## 1.5 Форматирование одной клавишей: бардак сам собой убирается

📖 **Форматирование**: автоматическое выравнивание **отступов и пробелов** в коде — единообразно и аккуратно. Как учитель, выравнивающий ваши абзацы: **ни слова не меняется, меняется только вид**.

### Попробуйте

Нарочно испортите код в `test.ru` (уберите отступы, добавьте случайные пробелы):

```rust
функция главная() {
пусть имя = "Ваня";
        печатай_строку!("Привет, {}!", имя);
}
```

Затем:

- **Правая кнопка → Format Document**; или
- `Shift + Alt + F` (Mac: `Shift + Option + F`).

Код мгновенно вернётся к аккуратным отступам:

```rust
функция главная() {
    пусть имя = "Ваня";
    печатай_строку!("Привет, {}!", имя);
}
```

> 💡 **Метафора**: форматирование — как уборка на столе. Книги те же (код не менялся), но всё вернулось на свои места — искать легче, смотреть приятнее.

> ✨ **Хорошая привычка**: нажимайте форматирование после каждого куска кода. Аккуратный код легче отлаживать и читать — в том числе вам будущему.

## 1.6 Автодополнение: редактор договаривает за вас

📖 **Автодополнение**: пока вы печатаете, редактор подсказывает, что вы могли иметь в виду. Введите `печа` внутри `главная` — выпадет список с `печатай_строку!`; нажмите `Tab` или `Enter` — допишется целиком, со скобками.

### Попробуйте

Внутри `главная` введите `печа` и посмотрите на список. Выберите `печатай_строку!` стрелками, нажмите Enter и впишите «Привет» в кавычки.

> 💡 **Метафора**: автодополнение — как внимательный ассистент, договаривающий фразы: вы говорите первый слог, он знает остальное. rust-analyzer знает всю стандартную библиотеку и подсказывает то, чего вы ещё не учили: читайте маленькую документацию рядом со списком.

## 1.7 Палитра команд: все команды в одном ящике

`Ctrl + Shift + P` открывает **палитру команд** — введите имя любой команды, чтобы выполнить. Три нужные сейчас:

| Команда | Что делает |
|---|---|
| Format Document | Выровнять код (раздел 1.5) |
| Problems: Focus on Problems View | Панель ошибок (раздел 1.4) |
| Rust Analyzer: Restart Server | Когда пропали волнистые линии или дополнение |

> ✨ Заучивать не надо: нажмите `Ctrl + Shift + P` и введите первые буквы того, что хотите.

## 1.8 Пример полного рабочего цикла

Соберём главу в один процесс — это ваш **стандартный рабочий цикл** с сегодняшнего дня:

1. **Откройте проект**: VS Code → Файл → Открыть папку;
2. **Откройте код**: кликните `src/main.ru` в дереве файлов;
3. **Пишите**: пользуйтесь автодополнением; следите за красными волнистыми линиями;
4. **Сохраните**: `Ctrl + S`;
5. **Причешите**: `Shift + Alt + F`;
6. **Запустите**: кнопка ▶ или `rzc run src/main.ru` в терминале;
7. **Увидьте результат**: панель терминала;
8. **Если ошибка**: `Ctrl + Shift + M` открывает панель «Проблемы»; кликните — прыгните к месту, исправьте, вернитесь к шагу 4.

> 💡 Шаги 4 → 8 повторяются много-много раз. Это и есть программирование: **написал чуть-чуть → проверил → запустил → исправил → написал ещё** — снежный ком, катящийся с горы.

## 1.9 Частые ошибки и как их исправить

### Ошибка первая: на файле `.ru` нет ни цветов, ни волнистых линий

**Причина**: расширение неактивно или файл не распознан как Rust.

**Исправление, по порядку**:

1. Проверьте правый нижний угол: там должно быть написано `Rust`. Если нет — кликните и выберите вручную;
2. Убедитесь, что расширение действительно `.ru` (Windows умеет прятать расширения — файл может тайно зваться `test.ru.txt`; включите «показывать расширения» в Проводнике);
3. Нажмите `Ctrl + Shift + P`, введите `Reload Window`, Enter.

### Ошибка вторая: волнистых линий нет, ошибки пропускаются

**Причина**: языковой сервер не запустился — чаще всего потому, что **rustc не установлен или не найден**.

**Исправление, по порядку**:

1. Откройте встроенный терминал и введите `rustc --version`:
   - «команда не найдена» → rustc не установлен или не в PATH; повторите шаг третий из 1.2 и снова откройте VS Code;
2. `Ctrl + Shift + P` → **Rust Analyzer: Restart Server**;
3. Всё ещё пусто? `Reload Window`.

> 📖 **PATH**: «список папок» операционной системы для поиска команд. Если команды в списке нет — терминал её не найдёт.

### Ошибка третья: кнопка запуска пишет «rustc not found»

Корень тот же, что и у второй. Проверьте, что rustup встал правильно (1.2, шаг третий).

### Ошибка четвёртая: форматирование ничего не делает

**Причина**: файл не распознан как Rust. Сначала выполните шаги из ошибки первой.

### Ошибка пятая: горячая клавиша ничего не делает

**Вероятная причина**: сочетание перехватила другая программа или раскладка.

**Исправление**: пользуйтесь меню — поведение то же. Или перенастройте в Settings → Keyboard Shortcuts.

## 1.12 Частые вопросы

**В: Расширение меняет мои файлы? Код будет изменён?**

Нет. rust-analyzer только **раскрашивает, проверяет и дополняет**. Ваш `.ru`-файл остаётся ровно таким, каким вы его написали. Форматирование меняет только пробелы.

**В: Можно и кнопкой, и терминалом в одном проекте? Результаты будут разными?**

Нет, одинаково. Кнопки запускают те же команды rzc/rustc — просто избавляют от набора.

**В: Что делает rzc, если я пишу русскими словами?**

rzc — сердце всей схемы: он по таблице соответствий превращает `функция` в `fn`, `печатай_строку` в `println!` и передаёт код настоящему компилятору rustc. Именно rzc также переводит сообщения об ошибках на русский с учебными подсказками.

**В: Почему ничего не происходит при нажатии функций ИИ-чата?**

Функции ИИ требуют собственного ключа и адреса ИИ-службы — это отдельная необязательная дорожка. Новичкам они не нужны вовсе; без них написание и запуск кода не меняются.

**В: После обновления расширения код внезапно завален ошибками?**

Сначала «Rust Analyzer: Restart Server», затем `Reload Window`. Не помогло? Проверьте инструментарий (`rustc --version`).
