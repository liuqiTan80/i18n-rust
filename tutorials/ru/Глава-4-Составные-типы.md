# Глава 4: Составные типы

В двух прошлых главах каждая коробочка хранила ровно одну вещь. В этой главе вы научитесь **упаковывать** — класть несколько вещей в один свёрток.

---

## 4.0 Цели главы

К концу этой главы вы сможете:

1. **Кортежем** упаковать несколько *разных* вещей и разобрать его обратно.
2. Сложить однотипные данные в ряд — **массив** — и доставать элементы по номеру.
3. Взять в долг часть массива, не копируя его целиком, — **срез**.
4. Объяснить, «почему счёт с нуля», и больше не спотыкаться.

---

## 4.1 Зачем упаковывать

### История из жизни: папка новенького

Вообразите: вы переходите в новую школу. Школа выдаёт не одну коробочку, а целую **папку**: имя, возраст, оценки… много разных бумаг собраны в один пакет, который удобно носить с собой.

В программировании так же: информация об ученике состоит из нескольких частей:

- имя (текст)
- возраст (число)
- живёт в интернате (истина или ложь)

Держать каждую часть в отдельной коробочке — быстро получится бардак. Лучший способ — **упаковать**.

Три способа упаковки из этой главы:

| Способ | Аналогия | Для чего |
|---|---|---|
| Кортеж | подарочная коробка | несколько **разных** вещей одним свёртком |
| Массив | ряд одинаковых шкафчиков | **однотипные** вещи в ряд, число мест фиксировано |
| Срез | окошко | подсмотреть часть ряда, не трогая его |

---

## 4.2 Кортеж: подарочная коробка с разными вещами

### Собираем кортеж

Несколько вещей в круглых скобках, через запятую — вот и кортеж:

```rust
пусть ученик = ("Саша", 12, истина);
```

По частям:

- `("Саша", 12, истина)` — подарочная коробка с тремя вещами: текст, число, логическое значение. Разные виды вперемешку — так и задумано; именно для этого существует кортеж.
- Три вещи — **элементы** кортежа («члены»). У этого кортежа их 3.

> 📖 **Кортеж (кортеж, «тьюпл»)**: составной тип, упаковывающий несколько значений в одно. Элементы могут быть разных типов.

### Достаём содержимое: счёт с нуля

Чтобы взять один элемент, пишите после имени кортежа `.номер`:

```rust
функция главная() {
    пусть ученик = ("Саша", 12, истина);
    печатай_строку!("Первый: {}", ученик.0);
    печатай_строку!("Второй: {}", ученик.1);
    печатай_строку!("Третий: {}", ученик.2);
}
```

Вы увидите:

```
Первый: Саша
Второй: 12
Третий: true
```

> ⚠️ **Внимание**: **счёт начинается с 0, а не с 1!** Номер первого элемента — 0, второго — 1, третьего — 2.

Это правило всего программирования. Почему — объясним на массивах в следующем разделе; пока запомните: «считая позиции, первый номер — „0“».

> 📖 **Индекс**: официальное имя этого «номера» — адрес вещи в наборе. В книге оба слова используются одинаково.

### Разобрать весь кортеж разом

Нужны все три? Разбираем одним махом:

```rust
функция главная() {
    пусть ученик = ("Саша", 12, истина);
    пусть (имя, возраст, интернат) = ученик;
    печатай_строку!("{} — {} лет", имя, возраст);
    печатай_строку!("В интернате? {}", интернат);
}
```

По строкам:

- Строка 3: `пусть (имя, возраст, интернат) = ученик;` — слева от `=` тоже стоит форма со скобками, означающая «раздели свёрток на три части». Компьютер сопоставляет по позициям: первая — в `имя`, вторая — в `возраст`, третья — в `интернат`.
- После разбора три имени становятся самостоятельными коробочками.

> 📖 **Разбор (деструктуризация)**: разваливать упакованные данные по форме и доставать по одной. Как развязать узел и разложить части на столе.

> 💡 **Метафора**: разбор — как вскрыть доставку: внутри посылки три вещи, вы приготовили три ячейки — и одним движением всё разложено.

Вы увидите:

```
Саша — 12 лет
В интернате? true
```

### Печать всего кортежа: `{:?}`

Чтобы напечатать кортеж целиком, заполнитель — `{:?}` (в фигурных скобках двоеточие и вопрос):

```rust
функция главная() {
    пусть ученик = ("Саша", 12, истина);
    печатай_строку!("Весь кортеж: {:?}", ученик);
}
```

Вы увидите:

```
Весь кортеж: ("Саша", 12, true)
```

> 📖 **Отладочная печать**: `{:?}` — печать «для отладки»: показывает внутренности вещи как есть (и кавычки, и скобки). Обычный `{}` печатает по-человечески красиво. Об отладочной печати — вся Глава 10.

> ⚠️ **Внимание**: печатать кортеж обычным `{}` — ошибка. Для кортежа обязательно `{:?}`.

## 4.3 Массив: ряд пронумерованных шкафчиков

### Собираем массив

Вообразите школьный коридор со шкафчиками — все одного размера, все для одного вида вещей (например оценок). Это **массив**.

Массив создаётся **квадратными скобками**, элементы через запятую:

```rust
пусть оценки = [88, 95, 76, 90, 82];
```

Этот массив хранит оценки за неделю — всего 5 элементов.

> 📖 **Массив**: ряд данных **фиксированной длины** **одного вида**. Квадратные скобки `[ ]` — знак массива.

> ⚠️ **Внимание**: не путайте `[ ]` и `( )` — квадратные для массива (однотипный ряд), круглые для кортежа (несколько разных вещей).

### Короткая запись для повторов

Если во все шкафчики кладётся одно и то же, есть сокращение:

```rust
пусть пять_нулей = [0; 5];
```

> 📖 Читается «ноль пять раз»: до точки с запятой — содержимое, после — сколько раз. То же, что `[0, 0, 0, 0, 0]`.

```rust
печатай_строку!("{:?}", пять_нулей);   // [0, 0, 0, 0, 0]
```

### Достаём шкафчик по индексу: счёт с нуля

```rust
функция главная() {
    пусть оценки = [88, 95, 76, 90, 82];
    печатай_строку!("День первый: {}", оценки[0]);
    печатай_строку!("День третий: {}", оценки[2]);
    печатай_строку!("День последний: {}", оценки[4]);
}
```

Вы увидите:

```
День первый: 88
День третий: 76
День последний: 82
```

Лучше всего это видно на картинке:

```
Шкафчики:  [ 88 ]  [ 95 ]  [ 76 ]  [ 90 ]  [ 82 ]
Индексы:      0       1       2       3       4
```

Шкафчиков 5, а индексы от 0 до 4. У N-го элемента индекс N−1.

### Почему счёт с нуля

Одна убедительная причина:

Индекс — это « **сколько шагов от начала** ».

- Первый шкафчик: от начала **0** шагов → индекс 0.
- Второй: **1** шаг → индекс 1.
- Пятый: **4** шага → индекс 4.

> 💡 **Метафора**: как ростомер — «нулевое деление» стоит на полу. Первые сантиметры размечены от 0, а не от 1. Индекс — «расстояние от начала».

### Два повседневных приёма массивов

**Приём первый: `.длина()` — сосчитать шкафчики**

```rust
печатай_строку!("Всего дней: {}", оценки.длина());   // Всего дней: 5
```

> 📖 **`.длина()`**: метод, возвращающий число элементов. После точки — метод, скобки пустые. Что такое «метод» — Глава 6; пока обращайтесь с `.длина()` как с заклинанием.

**Приём второй: `.содержит()` — есть ли такое значение**

```rust
печатай_строку!("Есть 95? {}", оценки.содержит(ссылка 95));   // Есть 95? true
```

> 📖 **`.содержит()`**: метод, проверяющий, есть ли значение в массиве, и отвечающий логическим значением. Пока переписывайте `ссылка 95` дословно — `ссылка` это знак «взять в долг», подробно в Главе 8. Сейчас достаточно: «для проверки содержимого нужна ссылка».

### За границей: тянуться к несуществующему шкафчику плохо кончается

В массиве 5 шкафчиков (индексы 0–4). Попробуете шестой:

```rust
// 预期行为: 运行失败
функция главная() {
    пусть оценки = [88, 95, 76, 90, 82];
    печатай_строку!("{}", оценки[5]);   // ❌ за границей!
}
```

Rust немедленно **паникует** — программа останавливается на месте.

> 📖 **Паника**: когда программа встречает неисправимую ошибку, она кричит «что-то не так!» и немедленно останавливается. Сломанной она никогда не продолжит работу. Как пожарная сигнализация: все бросают дела и эвакуируются. Подробнее — в Главе 16.

Сообщение паники выглядит так:

```
thread 'main' panicked at ...:
index out of bounds: the len is 5 but the index is 5
```

Переводим: «индекс за границей: длина 5, а запрошен 5-й». (Законный максимум — 4!)

> ✨ **Подсказка**: если выйти за границу **константой** (например `оценки[5]`), компилятор поймает это ещё на компиляции — «эта операция запаникует при выполнении», программа даже не запустится. Настоящая паника при выполнении случится, только если номер приходит извне и при компиляции неизвестен. Так или иначе, Rust никогда не даст тайком прочитать чужую память.

>
> ⚠️ **Внимание**: `rzc check` только переводит и проверяет — это он не ловит. Чтобы увидеть, запустите программу по-настоящему.

> 📖 **Индекс за границей**: обращение к номеру сверх диапазона. Английское имя — "index out of bounds", буквально «за пределами границы».

## 4.4 Срез: окошко в массив

### Посмотреть на часть ряда, не переставляя шкафчики?

Например, нужны только оценки за первые три дня. Копировать их в новый массив — расточительство. **Срез** умнее: ничего не копирует, лишь «указывает» на часть исходного ряда.

> 📖 **Срез**: ссылка на **непрерывный ряд элементов** массива — буквально "slice": отрезать кусок колбасы, не трогая саму колбасу.

После массива пишется `[начало..конец]`, а перед ним — `ссылка`:

```rust
функция главная() {
    пусть оценки = [88, 95, 76, 90, 82];
    пусть первые_три = ссылка оценки[0..3];
    печатай_строку!("Первые три дня: {:?}", первые_три);
    печатай_строку!("Длина среза: {}", первые_три.длина());
}
```

Вы увидите:

```
Первые три дня: [88, 95, 76]
Длина среза: 3
```

`ссылка оценки[0..3]` по частям:

| Часть | Смысл |
|---|---|
| `ссылка` | взять в долг (исходное не забираем — Глава 8) |
| `оценки` | массив, который режем |
| `[0..3]` | индексы от 0 **до трёх не включая** — то есть 0, 1, 2 |

> ⚠️ **Внимание**: `0..3` — « **голову включаем, хвост — нет** »: 0 входит, 3 — нет. Посчитайте: ровно 3 элемента. Это правило действует по всей книге.

> 📖 **Диапазон**: форма `начало..конец` называется диапазоном — «отсюда досюда».

### Короткие формы

```rust
пусть с_начала_по_третий = ссылка оценки[..3];    // начало опущено = от 0
пусть с_третьего_до_конца = ссылка оценки[2..];  // конец опущен = до последнего
пусть всё = ссылка оценки[..];              // оба опущены = целиком
```

```rust
печатай_строку!("{:?} {:?} {:?}", с_начала_по_третий, с_третьего_до_конца, всё);
// [88, 95, 76] [76, 90, 82] [88, 95, 76, 90, 82]
```

### Строки тоже режутся

Строки тоже можно резать (подробности — Глава 9; здесь первое знакомство):

```rust
пусть привет = ссылка "Привет"[0..4];
печатай_строку!("{}", привет);   // При
```

> ⚠️ **Внимание**: `0..4`, а не `0..2` — русские буквы, как и любые не-ASCII, занимают по 2 «байта» (маленькие ячейки памяти); «При» — 4 ячейки. Что такое байт — Глава 9. Пока перепишите `0..4` дословно.

## 4.5 Полный пример: оценки за неделю

### Полный код

```rust
функция главная() {
    // оценки за неделю (пн–пт)
    пусть недельные = [88, 95, 76, 90, 82];

    // режем неделю на первую и вторую половины
    пусть первая = ссылка недельные[0..2];
    пусть вторая = ссылка недельные[2..5];

    печатай_строку!("Оценки за неделю: {:?}", недельные);
    печатай_строку!("Всего дней: {}", недельные.длина());
    печатай_строку!("Первые два дня: {:?}", первая);
    печатай_строку!("Последние три: {:?}", вторая);

    // сумма вручную
    пусть сумма = недельные[0] + недельные[1] + недельные[2] + недельные[3] + недельные[4];
    пусть сумма_вещественное = сумма как вещественное;
    пусть среднее = сумма_вещественное / 5.0;
    печатай_строку!("Сумма: {}, среднее: {}", сумма, среднее);

    // информация об ученике — в кортеж
    пусть ученик = ("Саша", 12, истина);
    пусть (имя, возраст, интернат) = ученик;
    печатай_строку!("{} — {} лет, интернат: {}", имя, возраст, интернат);
    печатай_строку!("Второй элемент кортежа: {}", ученик.1);
}
```

### По строкам

- Строка 3: массив оценок за пять дней. Квадратные скобки = массив.
- Строка 6: срез индексов 0 и 1 (голова входит, хвост нет).
- Строка 7: срез индексов 2, 3, 4 — ровно оставшиеся три дня.
- Строка 9: `{:?}` печатает весь массив со скобками — отладочная печать.
- Строка 10: `.длина()` — 5.
- Строки 11–12: печать двух срезов.
- Строка 15: пять элементов складываем вручную = 431. (После циклов из Главы 5 это станет одной строкой — пять писать не придётся.)
- Строка 16: преобразуем в вещественное (две строки — чтобы обойти ловушку приоритета `как` из Главы 3).
- Строка 17: 431.0 ÷ 5.0 = 86.2.
- Строка 20: кортеж из трёх элементов: текст, число, логическое — мешать можно.
- Строка 21: разбор — три имени, каждое по своей позиции.
- Строка 22: печатаем с помощью трёх разобранных коробочек.
- Строка 23: `.1` достаёт второй элемент кортежа напрямую (счёт с нуля: `.1` — второй; 12).

### Вы увидите

```
Оценки за неделю: [88, 95, 76, 90, 82]
Всего дней: 5
Первые два дня: [88, 95]
Последние три: [76, 90, 82]
Сумма: 431, среднее: 86.2
Саша — 12 лет, интернат: true
Второй элемент кортежа: 12
```

## 4.6 Частые ошибки и как их исправить

### Ошибка первая: индекс за границей

Элементов 5, максимальный индекс 4. `оценки[5]` — за границей.

**Исправление**: законный максимум всегда `.длина() - 1`. Сомневаетесь — сначала напечатайте `.длина()`.

### Ошибка вторая: считать с единицы

Захотели первый элемент, написали `оценки[1]` — получили второй.

**Исправление**: пароль — « **первый — это 0** ».

### Ошибка третья: квадратные скобки у кортежа

```rust
// 预期错误: E0608
пусть ученик = ("Саша", 12, истина);
печатай_строку!("{}", ученик[0]);   // ❌ кортеж не использует квадратные скобки
```

**Исправление**: у кортежа — **точка**: `ученик.0`. Квадратные скобки — для массивов. Пароль: **кортеж — точка, массив — квадратные скобки**.

### Ошибка четвёртая: `.содержит()` без `ссылка`

```rust
оценки.содержит(95)    // ❌ ошибка
оценки.содержит(ссылка 95)   // ✅ верно
```

**Исправление**: переписывайте `ссылка` — почему, узнаете в Главе 8.

### Ошибка пятая: разные типы в одном массиве

```rust
// 预期错误: E0308
пусть смесь = [1, "два", 3];   // ❌ массив — один вид
```

**Исправление**: хотите смешать — возьмите кортеж `(1, "два", 3)`; массив — только один вид.

### Бонус-эксперимент: увидеть настоящую панику (по желанию)

Этот пример использует «переменные среды» и другие будущие понятия — у каждой строки есть комментарий, так что следуйте и увидите настоящую панику:

```rust
используй стандарт::среда::переменная_среды;

функция главная() {
    пусть оценки = [88, 95, 76];
    // читаем из переменных среды компьютера значение INDEX
    // («послание» извне программы)
    пусть текст = переменная_среды("INDEX").ожидай("Задайте переменную INDEX");
    // срезаем пробелы по краям
    пусть чистый = текст.обрежь();
    // превращаем текст в число. машинное_натуральное — «число для счёта»
    пусть номер: машинное_натуральное = чистый.разбери().ожидай("Нужно число");
    печатай_строку!("Оценка: {}", оценки[номер]);
}
```

В Linux / macOS (нарочно задаём INDEX=5 за границей):

```bash
INDEX=5 rzc run src/main.ru
```

Вы увидите настоящую панику:

```
thread 'main' panicked at ...:
index out of bounds: the len is 3 but the index is 5
```

Законный номер:

```bash
INDEX=1 rzc run src/main.ru
```

Вывод: `Оценка: 95`.

> ✨ **Подсказка**: в Windows PowerShell перед запуском задайте переменную: `$env:INDEX="5"`. Использованные здесь `переменная_среды`, `.обрежь()`, `.разбери()`, `.ожидай()` будут по-настоящему представлены в следующих главах — этот эксперимент лишь заранее показывает лицо паники.

Из массива упражнения 3 вырежьте «выходные» (последние два дня) и «будни» (первые пять), напечатайте оба.

<details>
<summary>🔍 Ответ</summary>


### Упражнение 5 (вызов): найдите ошибку

Что случится при запуске этого кода? Как исправить?

```rust
функция главная() {
    пусть три_числа = [1, 2, 3];
    печатай_строку!("{}", три_числа[3]);
}
```

<details>
<summary>🔍 Ответ</summary>

В массиве 3 элемента; максимальный индекс — 2. `три_числа[3]` — за границей. Число фиксированное, поэтому компилятор ещё при сборке поймает: «эта операция запаникует при выполнении». Исправьте на `три_числа[2]` — получите 3.

</details>

## 4.9 Частые вопросы

**В1: Кортеж или массив — что выбрать?**

Посмотрите на содержимое. Несколько **разных видов** информации в одном месте (имя + возраст + флаг) → кортеж. **Однотипные** данные в ряд (оценки за пять дней) → массив.

**В2: Почему счёт с нуля так непривычен?**

Потому что индекс буквально означает «сколько шагов от начала». У первого элемента 0 шагов — значит 0. Все основные языки (Rust, C, Java, Python…) устроены так; привыкнете — и запись диапазонов «голова входит, хвост нет» станет естественной.

**В3: Длина массива меняется после создания?**

Нет. Длина массива фиксирована. Нужна «коробочка», которая растёт, — это **вектор**, герой Главы 15.

**В4: Что значит `?` в `{:?}`?**

`?` — знак «отладочного формата». `{}` — красиво, по-человечески; `{:?}` — вся структура, как смотрит инженер. Как это устроено — Глава 10.

**В5: `ссылка` в срезе действительно обязательна?**

Да. Срез «берёт в долг» у исходного массива, и `ссылка` — знак этого долга. Без неё — ошибка. Подробно — Глава 8.

**В6: Входит ли 3 в `[0..3]`?**

Нет. Голова входит, хвост нет: 0, 1, 2. Нужно и 3 — пишите `[0..4]`. Пароль: **конечная точка всегда на единицу меньше**.

## Итог главы

1. **Кортеж**: круглые скобки, виды могут быть разными, достаём `.0`/`.1`, разбираем разбором.
2. **Массив**: квадратные скобки, один вид, длина фиксирована, индексы с нуля.
3. **Срез**: `ссылка массив[начало..конец]`, голова входит хвост нет, берём в долг без перестановки.
4. `.длина()` считает, `{:?}` печатает для отладки, за границей всегда плохо кончается — и Rust всегда это ловит.
