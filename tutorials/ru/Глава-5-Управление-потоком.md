# Глава 5: Управление потоком

Программы прошлых глав выполнялись «прямой линией сверху вниз». В этой главе программа осваивает три умения: **выбирать**, **повторять** и **распределять по обстоятельствам**.

---

## 5.0 Цели главы

Прочитав главу, вы сможете:

1. Словами `если / иначе` отправить программу по разным дорогам в зависимости от условия.
2. Составлять сложные условия из знаков сравнения и логических знаков.
3. Словом `матч` перечислить все возможные случаи значения разом.
4. Словами `цикл`, `пока`, `для … в` поручить компьютеру повторения, управляя ритмом через `прерви` и `продолжи`.

---

## 5.1 «Шаги» программы

Пока ваши программы исполнялись вот так — строка за строкой, сверху вниз:

```
Строка 1 → Строка 2 → Строка 3 → конец
```

Это **последовательное выполнение**. Но настоящая жизнь — не прямая линия:

- **Если** дождь — берём зонт; **иначе** — надеваем шапку. → Это **выбор**.
- Обежать пять кругов по стадиону. → Это **повторение**.
- Красный — стоим, зелёный — идём, жёлтый — сбавляем шаг. → Это **распределение по обстоятельствам**.

> 📖 **Управление потоком**: общее имя для инструкций, управляющих «шагами» программы. `если`, `матч`, `цикл`, `пока`, `для` этой главы — всё они.

## 5.2 Если / иначе: развилка

### Самый простой выбор: если

```rust
функция главная() {
    пусть температура = 32;
    если температура > 30 {
        печатай_строку!("Жарко! Мороженое!");
    }
    печатай_строку!("Программа закончилась");
}
```

По строкам:

- Строка 3: `если температура > 30 {` — проверяем, правда ли утверждение «температура больше 30». Правда — выполняем содержимое фигурных скобок; ложь — пропускаем их целиком.
- Условие истинно (32 действительно больше 30) — печатается «Жарко! Мороженое!».
- Последняя строка — вне скобок, выполнится в любом случае.

Вывод:

```
Жарко! Мороженое!
Программа закончилась
```

> 📖 **Условие**: утверждение, которое бывает истинным или ложным, например `температура > 30`. После `если` обязательно стоит условие.

> ⚠️ **Внимание**: условие **нельзя** обхватывать круглыми скобками. `если (температура > 30)` — манера других языков, Rust выдаст ошибку. Пишите прямо: `если температура > 30`.

### Две дороги: если / иначе

> 📖 **`иначе`**: ключевое слово, «если условие не сбылось — вот эта дорога».

```rust
функция главная() {
    пусть температура = 15;
    если температура > 30 {
        печатай_строку!("Мороженое");
    } иначе {
        печатай_строку!("Надень куртку");
    }
}
```

15 не больше 30 — условие ложно, идём дорогой `иначе`:

```
Надень куртку
```

> ⚠️ **Внимание**: `иначе` стоит вплотную к предыдущей фигурной скобке — `} иначе {`. Между ними только пробел; переносить строку и писать `иначе` отдельно нельзя.

### Несколько дорог: иначе если

Двух дорог мало? Наращивайте условия через `иначе если`:

```rust
функция главная() {
    пусть температура = 25;
    если температура > 30 {
        печатай_строку!("Очень жарко");
    } иначе если температура > 20 {
        печатай_строку!("Комфортно");
    } иначе если температура > 10 {
        печатай_строку!("Прохладно");
    } иначе {
        печатай_строку!("Холодно");
    }
}
```

Правило исполнения — как **рамка безопасности в аэропорту**: проверяем сверху вниз, вошли в **первую** верную дверь — все последующие даже не смотрим.

- 25 > 30? Ложь. Дальше.
- 25 > 20? Истина! Входим, печатаем «Комфортно». Всё остальное пропущено.

```
Комфортно
```

> 💡 **Метафора**: цепочка `иначе если` — как кнопки торгового автомата: жмёшь сверху вниз, первый зажжённый срабатывает, дальше — всё равно.

### Развилка внутри развилки: вложенность

Внутрь `если` можно вложить ещё один `если`:

```rust
функция главная() {
    пусть уроки_сделаны = истина;
    пусть хорошая_погода = истина;
    если уроки_сделаны {
        если хорошая_погода {
            печатай_строку!("Гуляем!");
        } иначе {
            печатай_строку!("Читаем дома");
        }
    } иначе {
        печатай_строку!("Сначала уроки");
    }
}
// 预期输出: Гуляем!
```

Вывод: `Гуляем!`. Вложенность допустима, но слишком глубокая кружит голову — держитесь двух уровней.

## 5.3 Сравнение и логика: сложные условия

### Шесть знаков сравнения

| Знак | Читается | Пример | Результат |
|---|---|---|---|
| `==` | равно | `5 == 5` | истина |
| `!=` | не равно | `5 != 3` | истина |
| `>` | больше | `5 > 3` | истина |
| `<` | меньше | `5 < 3` | ложь |
| `>=` | больше или равно | `5 >= 5` | истина |
| `<=` | меньше или равно | `5 <= 4` | ложь |

> ⚠️ **Внимание**: для проверки «равно» — **два** знака равенства `==`. Один `=` — присваивание (положить в коробочку), Глава 3. Перепутаете — беда: `если балл = 90` будет ошибкой.

> ⚠️ **Внимание**: типы с двух сторон должны совпадать. `5 == 5.0` — ошибка: целое и дробное напрямую не сравниваются.

### Три логических знака

Собрать несколько условий вместе помогают логические знаки. **Это знаки, а не слова**:

| Знак | Читается | Смысл | Житейский пример |
|---|---|---|---|
| `&&` | и | истинно, лишь когда истинны обе стороны | уроки сделаны **и** погода хорошая — гуляем |
| `\|\|` | или | истинно, если хотя бы одна сторона истинна | автобусом **или** метро — оба довезут |
| `!` | не (отрицание) | истину сделать ложью и наоборот | **не** дождь |

```rust
функция главная() {
    пусть уроки_сделаны = истина;
    пусть хорошая_погода = ложь;

    если уроки_сделаны && хорошая_погода {
        печатай_строку!("Гуляем");        // не напечатается: погода — ложь
    }
    если уроки_сделаны || хорошая_погода {
        печатай_строку!("Хотя бы одно выполнено");   // напечатается: уроки — истина
    }
    если !хорошая_погода {
        печатай_строку!("Погода нехорошая");       // напечатается: отрицание лжи — истина
    }
}
```

Вывод:

```
Хотя бы одно выполнено
Погода нехорошая
```

> ⚠️ **Внимание**: `&&` и `||` пишутся **только английскими знаками**. Написать по-русски «и» — ошибка. На клавиатуре: `&&` — `Shift+7` дважды; `||` — вертикальная черта `Shift+\` дважды.

> ✨ **Подсказка**: у `&&` есть ленивый талант — если левая сторона ложна, правую даже не смотрят (результат всё равно решён). Например `если тарелок != 0 && всего / тарелок > 5`: когда тарелок 0, деление не выполняется — авария «деление на ноль» предотвращена.

## 5.4 Сюрприз: если может работать как «значение»

У Rust есть редкий у других языков фокус: вся конструкция `если` может **вычислить значение** — и его сразу кладут в коробочку.

```rust
функция главная() {
    пусть балл = 87;
    пусть оценка = если балл >= 90 { "отлично" } иначе если балл >= 80 { "хорошо" } иначе { "удовлетворительно" };
    печатай_строку!("Оценка: {}", оценка);
}
```

Вывод: `Оценка: хорошо`.

Смысл строки 3: по баллу вычислить результат и положить его в `оценка`. Балл 87 — попадаем во вторую ветку, так что в `оценка` лежит `"хорошо"`.

За этим — два важных понятия:

> 📖 **Инструкция**: выполняет дело, значения не рождает; заканчивается точкой с запятой. Например `печатай_строку!(...);`
>
> 📖 **Выражение**: запись, вычисляющая значение. Число `5` — выражение (значение 5), `2 + 3` — выражение (значение 5), и даже `если...{...} иначе {...}` — выражение.

> ⚠️ **Внимание: точка с запятой «проглатывает» значение!** В последней строке фигурных скобок **точка с запятой не ставится** — тогда её значение становится значением всего `если`; поставите — станет инструкцией, и значение исчезнет:

```rust
пусть оценка = если балл >= 90 { "отлично"; } иначе { "удовлетворительно"; };   // ❌ ошибка!
```

Смысл ошибки: ожидался текст, получено «пусто». Точка с запятой проглотила `"отлично"`, и в скобках ничего не осталось.

Правило одной фразой: **хотите, чтобы скобки отдали значение, — не ставьте точку с запятой в последней строке.**

> 💡 **Метафора**: выражение — «ответ на вопрос», инструкция — «сделанное действие». Вы спрашиваете у `если`: «каков результат?» — и оно протягивает вам последнюю строку скобок (без точки с запятой).

## 5.5 Матч: торговый автомат

У значения много возможных вариантов, и для каждого — своё дело? Используйте `матч`.

> 📖 **`матч`**: ключевое слово. Берём значение, сверяем со списком, попали в строку — выполняем её.

```rust
функция главная() {
    пусть место = 2;
    матч место {
        1 => печатай_строку!("Золотая медаль"),
        2 | 3 => печатай_строку!("Пьедестал"),
        _ => печатай_строку!("Продолжай стараться"),
    }
}
```

По строкам:

- `матч место {`: значение `место` сверяется со списком ниже.
- `1 => печатай_строку!("Золотая медаль"),`: если значение 1 — выполняется то, что после стрелки. Каждая строка называется **рукой матча**.
- `2 | 3 => ...`: вертикальная черта `|` читается «или»; значение 2 или 3 попадает в эту руку.
- `_ => ...`: подчёркивание `_` означает «все остальные» — страховка снизу.

Место — 2, вывод:

```
Пьедестал
```

> 📖 **Шаблон-подхват**: здесь это `_` — «что бы это ни было, остальное — моё».

> 📖 **Исчерпывающе (полность)**: список `матч` обязан покрыть **все возможности** — либо перечислить каждую, либо подстелить `_`. Пропустили одну — компилятор выдаст ошибку. Так Rust заставляет вас «продумать всё».

### Матч тоже вычисляет значение

`матч`, как и `если`, — выражение:

```rust
пусть балл = 95;
пусть оценка = матч балл {
    90..=100 => "отлично",
    80..=89 => "хорошо",
    70..=79 => "удовлетворительно",
    60..=69 => "сдал",
    _ => "не сдал",
};
```

> 📖 `90..=100`: запись диапазона; `..=` означает **включая оба края** (90 до 100 включительно). Помните срез с его «голова входит, хвост нет»? Равенство добавили — «и хвост тоже забираем».

> ⚠️ **Внимание**: стрелка каждой руки — `=>` (равно + больше), не перепутайте с `->`.

## 5.6 Цикл: неутомимое повторение

### Цикл: самое «силовое» повторение

> 📖 **`цикл`**: ключевое слово; повторяет кусок кода снова и снова, пока вы не крикнете «стоп».

```rust
функция главная() {
    пусть изменяемый раз = 0;
    цикл {
        раз += 1;
        печатай_строку!("Проход {}", раз);
        если раз == 3 {
            прерви;
        }
    }
    печатай_строку!("Готово");
}
```

Вывод:

```
Проход 1
Проход 2
Проход 3
Готово
```

> 📖 **`прерви`**: ключевое слово, «немедленно выпрыгнуть из цикла». Без него `цикл` будет бежать до скончания веков (бесконечный цикл).

### Цикл тоже может отдать значение

После `прерви` можно поставить значение — оно отдаётся всему циклу:

```rust
функция главная() {
    пусть изменяемый счёт = 0;
    пусть удвоенный = цикл {
        счёт += 1;
        если счёт == 5 {
            прерви счёт * 2;
        }
    };
    печатай_строку!("Удвоенный: {}", удвоенный);
}
```

По строкам: цикл прибавляет по единице; досчитав до пяти, кричит «прерви» — и заодно выбрасывает наружу `5 * 2 = 10`. Значение всего `цикл {...}` — 10, оно и попадает в `удвоенный`.

Вывод: `Удвоенный: 10`.

## 5.7 Пока: повторять, лишь пока условие истинно

> 📖 **`пока`**: ключевое слово, «пока условие истинно — повторяй». Условие стало ложным — остановка автоматическая.

```rust
функция главная() {
    пусть изменяемый отсчёт = 3;
    пока отсчёт > 0 {
        печатай_строку!("Обратный отсчёт: {}", отсчёт);
        отсчёт -= 1;
    }
    печатай_строку!("Поехали!");
}
```

Вывод:

```
Обратный отсчёт: 3
Обратный отсчёт: 2
Обратный отсчёт: 1
Поехали!
```

Ход исполнения: перед каждым заходом проверяется `отсчёт > 0`. Для 3, 2, 1 — истинно; на нуле условие стало ложным, цикл закончился сам.

> ⚠️ **Внимание**: ни в коем случае не забудьте внутри цикла двигать условие «к лжи» (здесь — `отсчёт -= 1`). Забудете — условие вечно истинно, программа закостенеет в цикле; это зовётся **бесконечным циклом**. Закостенели — жмите `Ctrl+C` (держа Ctrl, нажать C) для принудительной остановки.

`пока` и `цикл + если + прерви` умеют почти одно и то же, но у `пока` условие стоит в начале — «когда остановимся» видно сразу, яснее.

## 5.8 Для … в: очередь — по одному

Число повторов известно или есть ряд вещей для обработки по одной — проще всего `для … в`.

> 📖 **`для`** и **`в`**: ключевые слова; читаются «для каждого X в некотором наборе — делать по порядку».

### С диапазоном: повторить фиксированное число раз

```rust
функция главная() {
    для номер в 1..6 {
        печатай_строку!("Круг {}", номер);
    }
}
```

`1..6` — диапазон: **от 1 до 5** (помните: `..` — голова входит, хвост нет). Хотите включить 6 — пишите `1..=6`.

Вывод:

```
Круг 1
Круг 2
Круг 3
Круг 4
Круг 5
```

### С массивом: обработать каждый элемент

Помните, в Главе 4 пять оценок складывались пятью строками? Теперь — одна:

```rust
функция главная() {
    пусть оценки = [88, 95, 76, 90, 82];
    пусть изменяемый сумма = 0;
    для отметка в оценки {
        сумма += отметка;
    }
    печатай_строку!("Сумма: {}", сумма);
}
```

`для отметка в оценки` означает: по очереди вынимаем из массива каждый элемент, каждый раз кладём его в коробочку `отметка` и выполняем тело цикла. После пяти проходов сумма = 431.

```
Сумма: 431
```

> 💡 **Метафора**: `для … в` — перекличка в классе: «каждый ученик из списка, по очереди, отвечает „здесь“». Цикл идёт сам, вам считать не нужно.

## 5.9 Продолжи: этот круг пропускаем, следующий начинаем

> 📖 **`продолжи`**: ключевое слово, «остаток этого круга не делать — сразу следующий».

```rust
функция главная() {
    пусть список_оценок = [88, 55, 76, 42, 90];
    пусть изменяемый сдало = 0;
    для отметка в список_оценок {
        если отметка < 60 {
            продолжи;      // несдавших пропускаем, не считаем
        }
        сдало += 1;
    }
    печатай_строку!("Сдали {} предметов", сдало);
}
```

Встретив 55 и 42, `продолжи` отправляет программу мимо счётчика — прямо к следующей оценке. Вывод:

```
Сдали 3 предмета
```

`прерви` против `продолжи`: `прерви` — «весь цикл больше не нужен», `продолжи` — «этот круг не нужен, следующий продолжается».

## 5.10 Полный пример: программа оценок

### Полный код

```rust
функция главная() {
    пусть список_оценок = [88, 55, 76, 42, 90];

    // первый проход: ставим каждому оценку
    печатай_строку!("--- Оценки ---");
    для балл_предмета в список_оценок {
        пусть оценка = матч балл_предмета {
            90..=100 => "отлично",
            80..=89 => "хорошо",
            70..=79 => "удовлетворительно",
            60..=69 => "сдал",
            _ => "не сдал",
        };
        печатай_строку!("{} баллов → {}", балл_предмета, оценка);
    }

    // второй проход: считаем сдавших и максимум
    пусть изменяемый сдало = 0;
    пусть изменяемый максимум = список_оценок[0];
    для балл_предмета в список_оценок {
        если балл_предмета >= 60 {
            сдало += 1;
        }
        если балл_предмета > максимум {
            максимум = балл_предмета;
        }
    }
    печатай_строку!("Сдали {} человек(а), максимум {}", сдало, максимум);
}
// 预期输出: --- Оценки ---
// 88 баллов → хорошо
// 55 баллов → не сдал
// 76 баллов → удовлетворительно
// 42 баллов → не сдал
// 90 баллов → отлично
// Сдали 3 человек(а), максимум 90
```

### По строкам

- Строка 2: оценки пяти предметов — в массив.
- Строка 5: `для … в` вынимает оценки по одной, каждый раз кладёт в `балл_предмета`.
- Строки 6–12: `матч` в роли оценщика. Шаблон диапазона `90..=100` включает оба края; `_` подхватывает всё остальное (0–59). Весь `матч` вычисляет текст и кладёт его в `оценка`.
- Строка 13: печать «баллы → оценка».
- Строка 17: счётчик сдавших, изменяемый, начинается с 0.
- Строка 18: сначала считаем максимальной первую оценку, дальше сравниваем по одной.
- Строки 19–26: ещё один проход по массиву — от 60 считаем; выше текущего максимума — обновляем максимум.
- Строка 27: печатаем итог.

### Вы увидите

```
--- Оценки ---
88 баллов → хорошо
55 баллов → не сдал
76 баллов → удовлетворительно
42 баллов → не сдал
90 баллов → отлично
Сдали 3 человек(а), максимум 90
```

## 5.11 Частые ошибки и как их исправить

### Ошибка 1: матч не покрывает все случаи (неисчерпанность)

```rust
матч место {
    1 => печатай_строку!("Золотая медаль"),
    2 => печатай_строку!("Серебряная"),
}   // ❌ место может быть и 3, и 4, и 5…
```

Смысл ошибки: матч неисчерпан, покрыты не все возможности.

**Исправление**: допишите остальные случаи или подстелите `_ => ...`.

### Ошибка 2: точка с запятой проглотила значение если

```rust
пусть оценка = если балл >= 90 { "отлично"; } иначе { "удовлетворительно"; };   // ❌
```

**Исправление**: уберите точку с запятой в последней строке скобок: `{ "отлично" } иначе { "удовлетворительно" }`.

### Ошибка 3: логика написана словами

```rust
если а и б { }   // ❌ ошибка: ожидалось `{`, найдено `и`
```

**Исправление**: знаками: `если а && б`.

### Ошибка 4: одно «равно» вместо двойного

```rust
если балл = 90 { }   // ❌ это присваивание, будет ошибка
```

**Исправление**: `если балл == 90`. Считалка: **сравниваешь — двойное, кладёшь — одинарное**.

### Ошибка 5: бесконечный цикл

В `пока` или `цикл` забыли двигать условие — программа вертится вечно.

**Исправление**: проверьте, есть ли в теле цикла инструкция, «толкающая условие к концу»; закостенели — `Ctrl+C`.

## 5.12 Словарик главы

| Термин | Значение |
|---|---|
| пока | цикл, повторяющийся лишь пока условие истинно; слово `пока` |
| для … в | цикл, вынимающий элементы набора по одному |
| Диапазон | запись `начало..конец` или `начало..=конец` |
| Рука матча | строка списка матча: «попал — сделай» |
| Управление потоком | общее имя инструкций, определяющих порядок исполнения |
| Исчерпывающе | матч обязан покрыть все возможности |
| Условие | утверждение, истинное или ложное |
| Шаблон-подхват | `_` в матче — «все остальные» |
| продолжи | пропустить этот круг, начать следующий |
| Бесконечный цикл | цикл, который не остановится никогда |
| Выражение | запись, вычисляющая значение |
| цикл | бесконечное повторение до прерви; слово `цикл` |
| матч | распределение по случаям значения; слово `матч` |
| Вложенность | конструкция управления потоком внутри такой же конструкции |
| если | выбор пути по условию; слово `если` |
| иначе | дорога, когда условие не сбылось; слово `иначе` |
| Инструкция | действие, значения не рождающее |
| прерви | немедленно выпрыгнуть из цикла; слово `прерви` |

## 5.13 Упражнения

> 💪 Сначала попробуйте сами, потом подглядывайте.

### Упражнение 1: совет по температуре

Напишите программу: температура 28. Больше 30 — печатай «Жарко», больше 20 — «Комфортно», иначе — «Холодно».

<details>
<summary>🔍 Ответ</summary>

```rust
функция главная() {
    пусть температура = 28;
    если температура > 30 {
        печатай_строку!("Жарко");
    } иначе если температура > 20 {
        печатай_строку!("Комфортно");
    } иначе {
        печатай_строку!("Холодно");
    }
}
// 预期输出: Комфортно
```

Вывод: `Комфортно`.

</details>

### Упражнение 2: перевести дни недели через матч

Создайте переменную `номер_дня` = 3 и через `матч` выведите соответствующий день «понедельник»…«воскресенье»; прочие номера — «неверно».

<details>
<summary>🔍 Ответ</summary>

```rust
функция главная() {
    пусть номер_дня = 3;
    пусть имя = матч номер_дня {
        1 => "понедельник",
        2 => "вторник",
        3 => "среда",
        4 => "четверг",
        5 => "пятница",
        6 => "суббота",
        7 => "воскресенье",
        _ => "неверно",
    };
    печатай_строку!("{}", имя);
}
// 预期输出: среда
```

Вывод: `среда`.

</details>

### Упражнение 3: накопить сумму

Через `для … в` найдите сумму чисел от 1 до 100.

<details>
<summary>🔍 Ответ</summary>

```rust
функция главная() {
    пусть изменяемый итог = 0;
    для число в 1..=100 {
        итог += число;
    }
    печатай_строку!("Итог: {}", итог);
}
// 预期输出: Итог: 5050
```

Вывод: `Итог: 5050`. Используйте `1..=100`, чтобы 100 тоже вошло.

</details>

### Упражнение 4: найдите чётные

Напечатайте все чётные числа от 1 до 10 (подсказка: `%` даёт остаток; делится на 2 без остатка — чётное).

<details>
<summary>🔍 Ответ</summary>

```rust
функция главная() {
    для число в 1..=10 {
        если число % 2 == 0 {
            печатай_строку!("{}", число);
        }
    }
}
```

Вывод: 2, 4, 6, 8, 10 — каждое на своей строке. `число % 2 == 0` означает «остаток от деления на 2 равен нулю».

</details>

### Упражнение 5 (вызов): найдите ошибку

Этот код хочет напечатать 1, 2, 3 и остановиться, но что-то не так. Найдите:

```rust
функция главная() {
    пусть изменяемый число = 1;
    цикл {
        печатай_строку!("{}", число);
        число += 1;
    }
}
```

<details>
<summary>🔍 Ответ</summary>

В цикле нет `прерви` — он будет бежать вечно (бесконечный цикл). Добавьте условие:

```rust
функция главная() {
    пусть изменяемый число = 1;
    цикл {
        печатай_строку!("{}", число);
        число += 1;
        если число > 3 {
            прерви;
        }
    }
}
```

Или проще переписать через `для число в 1..=3 { печатай_строку!("{}", число); }`.

</details>

## 5.14 Частые вопросы

**В1: Если, матч, цикл — как понять, что применить?**

Смотрите на сцену. **Выбрать одну дорогу из двух/нескольких** → `если`; **одному значению соответствует много случаев** → `матч`; **повторить** → цикл. Из тройки циклов: известно число или есть набор — `для`; сложное условие остановки — `пока`; нужно «чтобы цикл отдал значение» — `цикл`.

**В2: Почему `1..6` всё-таки не включает 6?**

Есть большой плюс: длина диапазона ровно `6 − 1 = 5`, и конец одного диапазона совпадает с началом следующего (`1..4` и `4..6` — без наложений и дыр). На этом стоят срезы и разбивка на страницы. Привыкнете — будет удобно.

**В3: Можно ли писать в `матч` сложные условия?**

На старте используйте `матч` для «равно чему / в какой отрезок попадает», а сложные условия отдавайте `если`. У `матч` есть приёмы постарше (разбирать данные внутри перечислений) — увидим в Главе 11.

**В4: Можно вложить цикл в цикл?**

Можно. Таблица умножения — классика двух циклов: внешний ведёт строки, внутренний — столбцы. Можете потренироваться на упражнениях.

**В5: Программа замерла — подозреваю бесконечный цикл. Что делать?**

Нажмите в окне терминала `Ctrl+C` — принудительная остановка. Затем осмотрите тело цикла: есть ли инструкция, двигающая условие «к концу»? Станет ли условие `пока` когда-нибудь ложным?

**В6: В `если` нет `иначе` — что случится при ложном условии?**

Ничего: скобки пропускаются, исполнение идёт дальше. `иначе` необязателен.

## Итог главы

1. **`если / иначе если / иначе`**: развилка по условию; условие — без скобок.
2. **Логические знаки**: `&&` (и), `||` (или), `!` (не) — только знаками, слова нельзя.
3. **Выражение**: и `если`, и `матч` вычисляют значение; точки с запятой в последней строке быть не должно.
4. **`матч`**: торговый автомат; `|` объединяет случаи, `..=` диапазон, `_` страховка, покрытие обязательно.
5. **Тройка циклов**: `цикл` (может вернуть значение), `пока` (условие в начале), `для … в` (по одному).
6. **`прерви`** выпрыгивает из всего цикла, **`продолжи`** пропускает только текущий круг.
