# Глава 9: Строки и текст

## 9.0 Цели главы

К концу этой главы вы сможете:

1. Различать два текстовых типа — **ссылка_на_строку** и **строка**;
2. Создавать, дополнять и склеивать строки;
3. Запрашивать текст методами `длина()`, `содержит()`, `начинается_с()`, `найди()`;
4. Объяснять разницу **байтов** и **символов** и знать, почему срез русской строки паникует;

> ✨ Всю книгу мы были должны главу про «текст» — сегодня расплачиваемся. Строки — самый ходовой тип повседневного программирования; эту главу стоит читать не спеша.

## 9.1 Два текстовых типа

В Rust «цепочка текста» бывает двух видов — здесь новички путаются чаще всего.

💡 **Метафора**:
- **ссылка_на_строку** — как **высеченные в камне буквы**:出厂 застыли, менять не вправе никто;
- **строка** — как **записи в блокноте**: хочешь — допиши, хочешь — исправь (но блокнот объявь «изменяемым»).

| Тип | Запись | Особенность | Где живёт |
|---|---|---|---|
| ссылка_на_строку | `ссылка_на_строку` (&str) | неизменяемый, высеченный текст | камень (встроенная область программы) |
| строка | `строка` | растёт и меняется | склад (куча) |

```rust
пусть камень = "высеченный текст";                 // тип: ссылка_на_строку
пусть изменяемый блокнот = строка::Из("пишущийся текст"); // тип: строка
```

📖 **строка**: растущий и меняющийся текстовый тип, живёт в куче.
📖 **ссылка_на_строку**: заимствованный неизменяемый текст; строковый литерал (написанный в двойных кавычках) — именно он.

### Как выбрать?

- Заранее заданное и неизменное (подсказки, пункты меню) → литерала достаточно (ссылка_на_строку);
- Меняющееся, собираемое из кусков (ввод пользователя, собранный программой текст) → `строка`.

---

## 9.2 Камень не вырезаешь заново

Попробуем изменить литерал:

```rust
// 预期错误: E0599
пусть изменяемый камень = "высеченный текст";
камень.добавь('!');   // ❌ ошибка компиляции
```

Смысл ошибки: у `ссылка_на_строку` нельзя вызвать `добавь`. Камень — это камень, и даже `изменяемый` его не спасёт — **тип определяет способности**. Хотите меняемый текст — `строка::Из("...")` перепишет надпись **в блокнот**.

---

## 9.3 Рождаем и растим строку

```rust
// строим строку из литерала
пусть изменяемый дневник = строка::Из("сегодня я учил строки");

// добавь: добавить один символ в конец (одинарные кавычки!)
дневник.добавь(',');

// добавь_строку: добавить цепочку текста в конец
дневник.добавь_строку(" это интересно!");

печатай_строку!("Дневник: {}", дневник);
// 预期输出: Дневник: сегодня я учил строки, это интересно!
```

Вывод: `Дневник: сегодня я учил строки, это интересно!`

Три момента:

| Запись | Смысл |
|---|---|
| `','` одинарные кавычки | **один символ** (тип «символ») |
| `"..."` двойные кавычки | цепочка текста (ссылка_на_строку) |
| `строка::Из("...")` | переписать текст в меняющуюся строку |

> ⚠️ **Внимание**: одинарные и двойные кавычки не смешиваются. `добавь` берёт один символ — одинарные; `добавь_строку` берёт цепочку — двойные.

---

## 9.4 Склейка: `формат!` одним махом

📖 **формат!**: макрос, собирающий значения и шаблон в новую строку. Каждое `{}` в шаблоне подставляется по порядку. Он почти близнец `печатай_строку!`, разница одна: **`печатай_строку!` показывает на экране, `формат!` возвращает строку**.

```rust
пусть имя = "Саша";
пусть приветствие = формат!("Привет, {}!", имя);
печатай_строку!("{}", приветствие);
// 预期输出: Привет, Саша!
```

Вывод: `Привет, Саша!`

Для склейки текста запомните этот один приём — хватит для девяти случаев из десяти.

## 9.5 Запросы

```rust
пусть дневник = строка::Из("сегодня я учил строки, это интересно!");

печатай_строку!("Байтов: {}", дневник.длина());
печатай_строку!("Содержит «строки»? {}", дневник.содержит("строки"));
печатай_строку!("Начинается с «сегодня»? {}", дневник.начинается_с("сегодня"));
печатай_строку!("Заканчивается на «!»? {}", дневник.заканчивается_на("!"));
```

Вывод:

```
Байтов: 67
Содержит «строки»? true
Начинается с «сегодня»? true
Заканчивается на «!»? true
```

> 📖 **О показе**: результат проверки — логическое значение. В коде пишется `истина`, но печатается английское `true`.

| Метод | Делает | Возвращает |
|---|---|---|
| `длина()` | число байтов (не букв!) | целое |
| `содержит(кусок)` | есть ли такой кусок внутри | логическое |
| `начинается_с(кусок)` | начинается ли с него | логическое |
| `заканчивается_на(кусок)` | заканчивается ли им | логическое |
| `найди(кусок)` | позиция первого появления (номер байта) | опция (Глава 16) |

## 9.6 Байты и символы: большой капкан русских текстов

Противоестественное число: «сегодня я учил строки, это интересно!» — посчитайте, тут **37 символов**, а `длина()` возвращает **67**.

📖 **Байт**: минимальная ячейка хранения текста в компьютере.
📖 **Символ**: «одна буква», как её видит человек.

💡 **Метафора**: компьютер хранит текст в кодировке UTF-8 — латинской букве хватает 1 ячейки, а **русской букве нужно 2** (китайской — 3). `длина()` считает **ячейки (байты)**, а не буквы: 32 русские буквы × 2 + 5 простых знаков (пробелы, запятая, восклицательный) = 67.

### Почему это опасно: паника среза

В Главе 3 был срез `ссылка массив[0..3]`. Строки тоже режутся, но режутся **байты**:

```rust
пусть фраза = "Привет мир";
пусть начало = ссылка фраза[0..6];    // первые 6 байтов = три русские буквы, ✅
печатай_строку!("Начало: {}", начало);
// 预期输出: Начало: При
```

Вывод: `Начало: При`

Но если резать **посреди буквы**:

```rust
// 预期行为: 运行失败
пусть фраза = "Привет";
пусть половинка = ссылка фраза[0..1];   // ❌ отрезали 1-ю ячейку буквы «П»
```

Во время выполнения — паника:

```
thread 'main' panicked at ...:
byte index 1 is not a char boundary; it is inside 'П' (bytes 0..2) of `Привет`
```

(«Байтовая позиция 1 — не граница символа: она внутри „П“». Полбуквы букву не собирают — Rust лучше запаникует, чем отдаст вам абракадабру.)

> ⚠️ **Правило**: режа русскую строку по индексам, границы обязаны падать в **щели между целыми буквами** (русская буква занимает 2 байта, безопасные щели — 0, 2, 4, 6…; но внутри слова бывает «й» из двух частей — ещё коварнее). Сомневаетесь — берите `по_символам()` из 9.8.

## 9.7 Обработка: замени, обрежь, раздели

```rust
// замени: меняем кусок а на кусок б, возвращает новую строку
пусть исходная = строка::Из("кот очень мил");
пусть новая = исходная.замени("кот", "котёнок");
печатай_строку!("{}", новая);          // котёнок очень мил

// обрежь: снять пробелы по краям
пусть грязные = "  яблоко,банан  ";
печатай_строку!("[{}]", грязные.обрежь());   // [яблоко,банан]

// раздели: нарезать по разделителю
для кусочек в "яблоко,банан,апельсин".раздели(",") {
    печатай_строку!("[{}]", кусочек);
}
```

Вывод:

```
котёнок очень мил
[яблоко,банан]
[яблоко]
[банан]
[апельсин]
```

| Метод | Делает |
|---|---|
| `замени(старый, новый)` | меняет все совпадения, возвращает новое |
| `обрежь()` | снимает пробелы по краям (пробелы, переводы строк…) |
| `раздели(разделитель)` | нарезает на куски; с `для` обрабатываете по одному |

> ✨ **обрежь + раздели** — золотая пара обработки ввода: сначала смыть края, потом нарезать по запятым/пробелам.

---

## 9.8 Проход по символам

Обрабатывать по одной букве — `по_символам()`:

```rust
для буква в "Привет".по_символам() {
    печатай_строку!("Буква: {}", буква);
}

```
Вывод:

```
Буква: П
Буква: р
Буква: и
Буква: в
Буква: е
Буква: т
```

Каждый знак равен, каждый раз выдаётся **целый символ** — русские буквы **никогда не режутся пополам**. В этом его безопасность против индексных срезов.

## 9.9 Полный пример: помощник дневника

```rust
функция главная() {
    // —— формат! собирает текст ——
    пусть имя = "Саша";
    пусть приветствие = формат!("Привет, {}!", имя);
    печатай_строку!("{}", приветствие);

    // —— изменяемая строка растёт ——
    пусть изменяемый дневник = строка::Из("сегодня я учил строки");
    дневник.добавь(',');
    дневник.добавь_строку(" это интересно!");
    печатай_строку!("Дневник: {}", дневник);

    // —— запросы ——
    печатай_строку!("Байтов: {}", дневник.длина());
    пусть изменяемый счётчик = 0;
    для _ в дневник.по_символам() {
        счётчик += 1;
    }
    печатай_строку!("Символов: {}", счётчик);
    печатай_строку!("Содержит «строки»? {}", дневник.содержит("строки"));

    // —— обрежь + раздели ——
    пусть грязные = "  яблоко,банан,апельсин  ";
    пусть чистые = грязные.обрежь();
    для кусочек в чистые.раздели(",") {
        печатай_строку!("[{}]", кусочек);
    }

    // —— по символам ——
    для буква в "Привет".по_символам() {
        печатай_строку!("Буква: {}", буква);
    }
}
// 预期输出: Привет, Саша!
// Дневник: сегодня я учил строки, это интересно!
// Байтов: 67
// Символов: 37
// Содержит «строки»? true
// [яблоко]
// [банан]
// [апельсин]
// Буква: П
// Буква: р
// Буква: и
// Буква: в
// Буква: е
// Буква: т
```

## 9.10 По строкам

- **Строки 3–5**: `формат!` подставляет `имя` в шаблон и возвращает **новую строку** — в `приветствие`.
- **Строки 8–10**: `строка::Из` строит изменяемую строку; `добавь` — символ в одинарных кавычках, `добавь_строку` — текст в двойных.
- **Строка 14**: `длина()` считает **байты**: 37 символов, из них 32 русские × 2 + 5 простых = 67.
- **Строки 15–18**: как считать **символы** — `по_символам()` идёт по тексту, каждый выданный — плюс один. Рядом со строкой 14 отлично видна разница байтов и символов.
- **Строки 22–26**: сперва `обрежь()` смывает края, потом `раздели(",")` нарезает по запятым, `для` печатает по одному.
- **Строки 29–31**: `по_символам()` правильно выдаёт каждую букву по одной.

## 9.12 Частые ошибки и как их исправить

### Ошибка 1: литерал неизменяем

Вызов `добавь` и прочих меняющих методов у `"..."` — ошибка. **Решение**: `строка::Из("...")` переписать в изменяемую копию и менять её.

### Ошибка 2: E0308 несоответствие типов: ожидалось `строка`, получено `ссылка_на_строку`

```rust
// 预期错误: E0308
функция прими(фраза: строка) { }
прими("Привет");   // ❌ литерал — это ссылка_на_строку
```

**Решение**: `прими(строка::Из("Привет"))` или смените параметр функции на `ссылка_на_строку` (в сценариях только-читать рекомендуют второе — куда проще).

### Ошибка 3: паника среза (байтовая позиция не на границе символа)

Граница среза упала посреди буквы — паника при выполнении. **Решение**: границы кратно длине буквы (2 для русских), либо переходите на `по_символам()`.

### Ошибка 4: перепутаны кавычки

`добавь("!")` — ошибка (ждём символ, дали текст); `добавь_строку('!')` — зеркально. **Решение**: символ — одинарные, цепочка — двойные.

### Ошибка 5: считаете `длина()` буквами

Для русских текстов `длина()` — байты. Считать буквы — через счётчик с `по_символам()`.

## 9.15 Частые вопросы

**В: Зачем Rust два текстовых типа — неужели одним не обойтись?**

Разделение труда экономит ресурсы. Камень (литерал) врезается в программу ещё при компиляции и склад не занимает; блокнот (строка) гибок, но обслуживание стоит денег. Только читать — берите ссылку, ноль расходов; понадобилась обработка — вот тогда стройте строку.

**В: `ссылка_на_строку` и «ссылка» из Главы 8 — как связаны?**

`ссылка_на_строку` — одна из **ссылок**: читающее заимствование самого текста. `ссылка строка` — «ссылка на строку», `ссылка_на_строку` — «ссылка на текст как есть». Они отлично сотрудничают: `ссылка строка` обычно можно передать туда, где ждут `ссылка_на_строку` (автопревращение).

**В: Как число превратить в текст?**

Всесильный `формат!("{}", число)`. В Главе 15 (коллекции) и 16 (ошибки) вы встретите и `разбери()` (текст → число) в разных ролях.

**В: Срезы так опасны — их вообще учить надо?**

Надо. На чисто английском тексте и данных протоколов срезы быстры и ходовы. Правило одно: **граница обязана лежать на шве между символами**. С русским текстом сомневаетесь — `по_символам()`.

**В: Сколько байтов занимает `'П'` в одинарных кавычках?**

Тип «символ» всегда 4 байта (влезает любой знак мира), но в тексте UTF-8 «П» занимает 2 байта. На старте в эту тонкость можно не вникать.

**В: Куски из `раздели` можно сохранить на потом?**

Они все — **заимствования** исходной строки (ссылка_на_строку): жива исходная — живы куски. Надолго сохранить — нужно превратить в независимые строки (приёмы из будущих глав). Пока освойте стиль «режу — и тут же обрабатываю».

## Что дальше

До сих пор данные жили «россыпью»: имя, возраст, балл… А в реальном мире они принадлежат **одной учётной карточке**.

**Глава 10 «Структуры»** научит упаковывать связанные данные:

- Определить собственный тип: `структура Ученик { ... }`;
- Построить экземпляр, читать и менять поля;
- Блоком `реализация` прикрутить методы (вернём долг Главы 6);
- `#[производи(отладочный)]` — и структуру можно печатать напрямую.
