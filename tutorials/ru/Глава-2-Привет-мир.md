## 2.1 Что такое программирование

### Записки для робота

Представьте робота перед вами. Он очень послушный — и очень глупый. Он делает **ровно то, что вы сказали, слово в слово**, и никогда не догадывается, что вы имели в виду.

Скажите «принеси стакан воды» — и он может застыть в растерянности, если вы не сказали «сначала возьми стакан».

**Программирование — это записки для такого робота**: расписать каждый шаг — взять стакан, подойти к кулеру, нажать кнопку, закрыть кран, когда стакан полон…

> 💡 **Метафора**: программирование — как сверхподробный рецепт. Нельзя написать «свари макароны» — нужно писать «Шаг 1: открой кран. Шаг 2: налей кастрюлю наполовину. Шаг 3: …»

Каждая записка называется **исходным кодом**.

> 📖 **Исходный код**: текст, который вы пишете для чтения компьютером.

Язык, на котором пишут исходный код, называется **языком программирования**.

> 📖 **Язык программирования**: язык, на котором люди разговаривают с компьютерами. Как у людей есть русский, английский и китайский, так и языков программирования много, у каждого свой характер.

### Язык, который вы учите: Rust

Язык этой книги — **Rust**, один из самых популярных языков программирования мира.

Но в этой книге вы пишете Rust **русскими словами**:

| Ключевое слово | Что означает | Житейская аналогия |
|---|---|---|
| `функция` | Определить набор инструкций, который можно переиспользовать | Назвать последовательность действий по имени, чтобы вызывать |
| `пусть` | Создать «коробочку» для данных | Взять коробку, наклеить ярлык, положить внутрь |
| `если` | Сделать что-то только при условии | Если дождь — взять зонт |
| `для` | Повторить действие для каждого предмета | Для каждого яблока в корзине — помыть |
| `печатай_строку!` | Показать текст на экране | «Крикнуть» на экран |

Ваш код выглядит как русские предложения — но это **программа, которая реально запускается**:

```rust
функция главная() {
    печатай_строку!("Привет, мир!");
}
```

> ✨ **Подсказка**: не переживайте о деталях этого кода — раздел 2.6 разберёт его слово за словом. Пока нужно знать одно: эти строки — программа, которую может прочитать компьютер.

> 🌍 **Замечание для многоязычного класса**: русские ключевые слова — это лишь одно из десяти «наречий» Rust. Китайцы пишут `函数 主函数()`, японцы — `関数 主関数()`, англичане — `fn main()`. Все они — **один и тот же Rust**; переводчик rzc сводит их к стандартному виду. Русскоязычному читателю этот учебник даёт родную дорожку: писать на своём языке с первого дня.

## 2.2 Сначала — знакомство с компьютером

Перед написанием кода потратим несколько минут на основы. Если всё это вы знаете — сразу к 2.3.

### Файлы: «листочки» внутри компьютера

> 📖 **Файл**: базовая единица хранения в компьютере — как лист бумаги. На листе можно хранить сочинение или рисунок; в файле — текст или картинки.

У каждого файла есть **имя файла**, например `сочинение.txt`. Частица `txt` после точки — **расширение**: оно говорит, какого типа этот файл.

> 📖 **Расширение**: часть имени файла после последней точки; она сообщает компьютеру, что это за файл. `.txt` — простой текст, `.jpg` — картинка. Файлы с исходным кодом этой книги используют расширение **`.ru`**.

### Папки: «ящики» компьютера

> 📖 **Папка**: «ящик», в котором лежат файлы (иначе — каталог). В одну папку можно положить много файлов — как много листов в один ящик — чтобы не было бардака.

### Самые важные клавиши клавиатуры

Написание кода — это в основном набор текста. Эти клавиши вы точно будете использовать:

| Клавиша | Где | Что делает |
|---|---|---|
| `Enter` | Справа от основного блока | Новая строка; в терминале означает «выполни команду» |
| `Пробел` | Самая длинная клавиша внизу | Один пробел |
| `Backspace` | Над `Enter` | Удалить один символ перед курсором |
| `Shift` | По одной с каждой стороны | Держать при нажатии букв для заглавных |
| `Ctrl` | По одной с каждой стороны | Для сочетаний, например `Ctrl+S` — сохранить |

> ⚠️ **Внимание**: код набирается **английской пунктуацией**! Русская запятая — `,`; английская — `,`. Сам код всегда на английской пунктуации. (Знаки *внутри кавычек* следуют языку текста.)

### Сохранение файлов

Набранный в редакторе код сначала живёт только в «памяти» — выключите машину, и он исчез. Нужно **сохранить**, чтобы записать на диск.

> 📖 **Сохранить**: записать редактируемое на диск, чтобы не потерять. Почти в каждой программе сохраняет `Ctrl+S` (`Cmd+S` на macOS).

> ✨ **Подсказка**: заведите привычку — жать `Ctrl+S` каждые несколько строк.

## 2.3 Знакомство с инструментами

Для кода нужны три инструмента — как для готовки: кухня, лопатка и рецепт.

### Инструмент первый: терминал — окно для разговора с компьютером

> 📖 **Терминал**: окно только для текста. Вы вводите команды, компьютер выполняет и отвечает текстом. Также называется «командной строкой».

💡 **Метафора**: терминал — как официант, принимающий только письменные заказы. Вы пишете «один стакан воды», он приносит воду и записывает «пожалуйста».

Как открыть:

- **Windows**: щёлкните левый нижний угол, найдите «PowerShell», нажмите Enter.
- **macOS**: `Cmd+Пробел`, введите «Терминал», Enter.
- **Linux**: `Ctrl+Alt+T`.

Вы увидите мигающую вертикальную черту — **курсор** — значит «теперь ваша очередь печатать».

> 📖 **Команда**: одна строка инструкции, введённая в терминал. Нажали Enter — компьютер выполнил. Набрать `rzc --version` и нажать Enter — попросить rzc показать версию.

### Инструмент второй: компилятор — ваш переводчик

Исходный код — текст, читаемый человеком; но компьютер понимает только **двоичный код**.

> 📖 **Двоичный код**: изображать всё через 0 и 1 — как выключатель, который либо включён, либо выключен. Внутри компьютера это «есть ток» / «нет тока», записывается 1 и 0.

Нужен **переводчик**, превращающий исходный код в машинные инструкции.

> 📖 **Компилятор**: программа-переводчик. Он читает исходный код, проверяет его на ошибки и переводит в машинные инструкции.

> 📖 **Компиляция**: процесс перевода кода. «Скомпилируй» = «пусть переводчик сделает своё дело».

```
Ваш исходный код (текст, читаемый человеком)
    ↓  компилятор переводит
Машинный код (01010101… — то, что читает компьютер)
    ↓  компьютер выполняет
Вывод (появляется на экране)
```

Компилятор Rust называется **rustc** — но напрямую вы его почти не зовёте. В обычном Rust этим занимается дворецкий **cargo**. В этой книге между вами и rustc стоит ещё один герой — **rzc**:

```
Ваш русский код (функция главная() { … })
    ↓  rzc переводит русские слова в английские
Стандартный Rust (fn main() { … })
    ↓  rustc компилирует
Машинный код → выполнение → вывод на экран
```

> 📖 **Таблица соответствий (маппинг)**: «русско-английский словарик», по которому rzc переводит. `функция` → `fn`, `печатай_строку` → `println!`… Полный словарик — в Приложении A. Он лежит в языковом пакете проекта.

### Инструмент третий: текстовый редактор — ваша тетрадь

> 📖 **Редактор**: программа для написания текста. Разновидность для кода — «редактор кода»: он раскрашивает код, чтобы легче читать.

Эта книга рекомендует **VS Code** + расширение **i18n-rust**: подсветка файлов `.ru`, живая проверка ошибок и перевод диагностики на русский.

## 2.4 Установка инструментов

Этот раздел — пошаговое руководство. Откройте терминал и следуйте за текстом.

### Шаг первый: установите Rust (rustup)

rzc нужен настоящий компилятор Rust (rustc), так что сначала ставим Rust.

#### Windows:
Откройте https://rust-lang.org/learn/get-started/ в браузере,
скачайте установщик для своей системы и следуйте подсказкам.

#### Linux / macOS:

Введите в терминале эту строку и нажмите Enter:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

> 📖 Что означает эта строка: скачать установщик из интернета и запустить. `curl` — имя программы для скачивания; адрес — где живёт установщик. Понимать каждую часть не обязательно — просто введите.

Установщик задаст вопросы — **просто жмите Enter**, выбирая настройки по умолчанию. В зависимости от сети это занимает несколько минут.

> ⚠️ **Внимание**: после установки нужно **закрыть терминал и открыть новый**. Свежеустановленное ПО находят только новые окна.

Откройте терминал заново и проверьте:

```bash
rustc --version
```

> 📖 `--version` означает «скажите свой номер версии». Номер версии — как день рождения программы, например 1.85.0.

Если увидели что-то вроде `rustc 1.85.0` — установка удалась. Точное совпадение не важно.

> **Проблемы?** Если написано «команда не найдена» — окно, скорее всего, не переоткрыли. Закройте и откройте заново. Всё равно пусто? Перезагрузите компьютер и повторите.

### Шаг второй: установите rzc

rzc ставится одной командой (это обычный пакет Rust):

```bash
cargo install rzc
```

Проверьте:

```bash
rzc --version
```

Если видите номер версии (например `rzc 0.7.0`) — готово.

### Шаг третий: создайте первый проект

Проект создаётся командой rzc:

```bash
rzc init Привет-мир --lang ru
```

> 📖 Разбираем команду: `rzc` — вызов переводчика; `init` — сокращение «инициализация», то есть «подготовить заново»; `Привет-мир` — имя проекта. `--lang ru` — «на русском языке» (если язык системы русский, можно опустить — определится само).

Команда сама создаст папку `Привет-мир`, внутри:

```
Привет-мир/
├── Cargo.toml          ← визитная карточка проекта (имя и прочее)
├── rust-toolchain.toml ← запись о нужной версии Rust
├── README.md           ← описание проекта
└── src/
    └── main.ru         ← ваш исходный файл (место для кода)
```

> 📖 **Дерево каталогов**: такая картинка с линиями, показывающая слои папок. Косая черта после `src` — знак «это папка».

Внимание на **`src/main.ru`** — только здесь вы пишете код. Остальные файлы инструменты ведут автоматически, сейчас их не трогаем.

### Шаг четвёртый (необязательно): расширение VS Code

Откройте `Привет-мир` в VS Code: **Файл → Открыть папку** → выберите `Привет-мир`. Расширение i18n-rust включит подсветку и волнистые линии для `main.ru`.

### Запустите!

Убедитесь, что вы в папке `Привет-мир`, и выполните:

```bash
rzc run src/main.ru
```

> 📖 Разбираем: `rzc` — вызов переводчика; `run` — «запусти»; `src/main.ru` — «этот файл переведи и запусти».

В файле уже написан шаблон:

```rust
функция главная() {
    печатай_строку!("Привет, мир!");
}
```

Если всё прошло хорошо, вы увидите:

```
Привет, мир!
```

**Поздравляем — вы только что запустили свою первую программу на русском Rust.** Программисты всех языков начинают с «Hello, World». Теперь вы в этой традиции.

> ✨ **Подсказка**: после каждого изменения снова запускайте `rzc run src/main.ru`. Нажатие **стрелки вверх** в терминале вызывает прошлую команду — перепечатывать не надо.

## 2.5 Первая программа — слово за словом

Программа, которую написал rzc, — целый урок. Разберём её по кусочкам:

**Строка 1: `функция главная() {`**

Эта строка означает: «Я определяю набор инструкций с именем „главная“; входных данных нет, инструкции начинаются после `{`.»

| Код | Что это | Что делает | Житейская аналогия |
|---|---|---|---|
| `функция` | Ключевое слово | Говорит компьютеру «ниже определяется набор инструкций» | «Внимание: сейчас будет алгоритм» |
| пробел | Разделитель | Разделяет два слова — компьютер отличает слова по пробелам | Как писать «я·люблю·учиться» для ясности |
| `главная` | Имя функции | Имя этого набора. Программа всегда начинает с «главная» | «Глава 1» книги — чтение начинается отсюда |
| `()` | Пара скобок | Место для «параметров» (входных данных). Пусто — входа нет | «Этот номер без реквизита» |
| `{` | Левая фигурная скобка | «Инструкции начинаются здесь» | «На старт… внимание!» |

> 📖 **Параметр**: вход, который нужен функции. Соковыжималке нужны фрукты — фрукты и есть её параметр. Наша главная функция входа не требует, потому скобки пусты. Подробно — в Главе 6.

> 📖 **Фигурные скобки**: два символа `{` и `}`. Всегда парой, оборачивают кусок содержимого. `{` открывает, `}` закрывает.

**Строка 2: `    печатай_строку!("Привет, мир!");`**

Эта строка означает: «Покажи на экране текст „Привет, мир!“.»

| Код | Что это | Что делает | Житейская аналогия |
|---|---|---|---|
| 4 пробела впереди | Отступ | Показывает, что строка внутри главной функции | Красная строка в сочинении |
| `печатай_строку` | Имя встроенного инструмента | Показывает текст и переходит на новую строку | «Крикнуть» на экран |
| `!` | Восклицательный знак | Помечает инструмент как **макрос** | Значок макроса |
| `(...)` | Круглые скобки | Держат содержимое для показа | Что кричим |
| `"Привет, мир!"` | Строка | Текст в двойных кавычках | Слова на записке |
| `;` | Точка с запятой | Конец этой инструкции | Точка в конце предложения |

> 📖 **Макрос**: особый встроенный инструмент, чьё имя кончается `!`. Пока запомните: **увидели восклицательный знак — это макрос**. Чем макрос отличается от обычной функции — вопрос Главы 23.

> 📖 **Строка (string)**: цепочка символов — «string» буквально «нить». Двойные кавычки `"` означают «это текст», как кавычки при чьей-то прямой речи.

> ⚠️ **Внимание**: `строку` в `печатай_строку` намекает на «строку» — печать **строкой** с автоматическим переходом на следующую.

**Строка 3: `}`**

| Код | Что это | Что делает | Житейская аналогия |
|---|---|---|---|
| `}` | Правая фигурная скобка | Здесь главная функция кончается | «Сцена!» |

> ⚠️ **Внимание**: `{` и `}` ходят **парой**. Каждое открытие требует закрытия. Пропущенная скобка — самая частая ошибка новичка (раздел 2.9).

### Сохраните и запустите

1. Нажмите `Ctrl+S`.
2. В терминале (внутри папки проекта) выполните:

```bash
rzc run src/main.ru
```

> ✨ **Подсказка**: после каждого изменения запускайте снова — и смотрите новый результат. **Стрелка вверх** в терминале возвращает прошлую команду.

## 2.6 За кулисами: как русский код выполняется?

Компьютер не понимает русского — так почему же русский код работает?

Когда вы нажимаете `rzc run`, за кулисами автоматически проходят три этапа:

```
┌────────────────────────────────────┐
│ ① Ваш русский исходник main.ru      │
│    функция главная() { ... }        │
└──────────────┬─────────────────────┘
               │ rzc заменяет русские слова английскими
               ▼
┌────────────────────────────────────┐
│ ② Стандартный Rust                  │
│    fn main() { ... }                │
└──────────────┬─────────────────────┘
               │ rustc переводит английский код в машинный
               ▼
┌────────────────────────────────────┐
│ ③ Машинный код (0 и 1) → выполнение │
│    На экране: Привет, мир!          │
└────────────────────────────────────┘
```

1. **Перевод**: rzc заглядывает в «русско-английский словарик» и заменяет `функция` на `fn`, `печатай_строку` на `println!`.
2. **Компиляция**: rustc переводит английский код в машинный.
3. **Выполнение**: компьютер исполняет машинный код, экран показывает результат.

Всё автоматически. Вы просто редактируете `src/main.ru`.

### Хотите увидеть перевод? Команда eject

Если хотите своими глазами увидеть английский код:

```bash
rzc eject src/main.ru
```

> 📖 `eject` — «извлечь». Команда создаёт `src/main.rs` (`.rs` — расширение стандартного Rust) — тот самый переведённый английский код:

```
fn main() {
    println!("Привет, мир!");
}
```

> ✨ **Подсказка**: текст в кавычках — «Привет, мир!» — **не переводится**. rzc переводит только ключевые слова и идентификаторы (слова с особым смыслом в коде); содержимое кавычек остаётся как есть.

> ✨ **Подсказка**: `main.rs` — файл для просмотра. Работайте по-прежнему в `main.ru`.

## 2.7 Практические эксперименты

Лучший способ учиться программированию — **менять код самому**. Сделайте все три эксперимента.

### Эксперимент 1: измените вывод

**Цель**: своими глазами увидеть «изменил код → изменился вывод».

Измените `src/main.ru` так:

```rust
функция главная() {
    печатай_строку!("Привет, я Ваня!");
    печатай_строку!("Я изучаю Rust.");
}
```

По строкам:

- Строка 1: определяем главную функцию; программа начинается здесь.
- Строка 2: показываем «Привет, я Ваня!» и переходим на новую строку.
- Строка 3: показываем «Я изучаю Rust.» на следующей строке.
- Строка 4: главная функция кончается.

Сохраните и запустите; на экране:

```
Привет, я Ваня!
Я изучаю Rust.
```

> **Наблюдение**: две строки появились на двух строках, потому что `печатай_строку!` всегда переносит строку. Инструкции выполняются сверху вниз — кто раньше написан, тот раньше выполнен.

### Эксперимент 2: печать без перехода строки

**Цель**: понять разницу «с переносом» и «без».

```rust
функция главная() {
    печатай!("Привет, ");
    печатай!("мир!");
}
```

По строкам:

- Строка 2: `печатай!` отличается от `печатай_строку!` ровно одним — **нет перехода на новую строку**.
- Строка 3: продолжает ровно там, где остановилась прошлой печати.

На экране:

```
Привет, мир!
```

Два куска склеились в одну строку, потому что между ними никто не переносил строку.

### Эксперимент 3: вставьте данные в текст

**Цель**: научить программу «запоминать» данные и пользоваться ими.

```rust
функция главная() {
    пусть имя = "Ваня";
    пусть возраст = 12;
    печатай_строку!("Меня зовут {}, мне {} лет.", имя, возраст);
}
```

По строкам:

- Строка 2: `пусть` — ключевое слово «создай коробочку». Строка говорит: возьми коробочку, наклей ярлык «имя», положи внутрь «Ваня».
- Строка 3: так же, коробочка с ярлыком «возраст» и числом 12 внутри.
- Строка 4: `{}` — это **заполнитель** (место, зарезервированное заранее). `печатай_строку!` заполняет места данными, перечисленными после скобок, по порядку.

> 📖 **Переменная**: коробочка с ярлыком. Ярлык — имя, коробочка держит данные. `пусть имя = "Ваня"` создаёт переменную «имя». Полностью — в Главе 3.

> 📖 **Заполнитель**: зарезервированное место, ждущее заполнения. `{}` — заполнитель, как пустая графа в анкете.

Как работает заполнение:

```
"Меня зовут {}, мне {} лет."   ← шаблон с двумя окошками
              ↑                ↑
            имя             возраст     ← заполняются по порядку
           "Ваня"              12
              ↓                ↓
"Меня зовут Ваня, мне 12 лет."   ← окончательный результат
```

После запуска на экране:

```
Меня зовут Ваня, мне 12 лет.
```

## 2.8 Стиль кода

Код должен не только работать — он должен быть приятен для чтения. Как аккуратно переписанное сочинение с ясными абзацами.

### Отступы: 4 пробела

Код внутри фигурных скобок сдвигается на 4 пробела вправо — пометка «принадлежит» функции.

```rust
функция главная() {
    печатай_строку!("правильный отступ");  // ✅ 4 пробела
}
```

Зачем отступы? Отступ делает структуру кода очевидной с первого взгляда — как красная строка в каждом абзаце письма.

> ✨ **Подсказка**: пробелы считать не надо. С активным расширением код форматируется автоматически при сохранении (или правая кнопка → Format Document).

### Имена

| Вид | Стиль | Примеры |
|---|---|---|
| Имена функций | Глаголы или глагольные фразы | `подсчитай_итог`, `получи_ввод` |
| Имена переменных | Существительные | `имя`, `возраст`, `счёт` |

> ⚠️ **Внимание**: не сталкивайтесь с ключевыми словами. Нельзя назвать переменную `функция` или `пусть` — они зарезервированы. Берите конкретные существительные — `итог`, `приветствие` — и вы в безопасности.

### Комментарии: записки для людей

> 📖 **Комментарий**: текст внутри кода, написанный для людей; компилятор полностью его игнорирует. Однострочный комментарий начинается с `//` (две косые черты).

```rust
// это однострочный комментарий; компилятор его игнорирует

функция главная() {
    печатай_строку!("Привет"); // комментарий может стоять и в конце строки
    // пусть имя = "Ваня";  // закомментированный код никогда не выполнится
}
```

Зачем комментарии? Код говорит компьютеру «что делать»; комментарии говорят людям «почему». Через несколько дней, перечитывая свой код, комментарии вернут вам ход мыслей.

## 2.9 Частые ошибки и как их исправить

Пишете код — будете ошибаться, и это совершенно нормально. Представьте компилятора **строгим, но добрым учителем**: проверяя работу, он говорит **где ошибка, почему она ошибка и как исправить**.

Сначала выучите команду «только проверить»:

```bash
rzc check src/main.ru
```

> 📖 `check` означает «проверь, не запуская» — как вычитать домашку перед сдачей. Быстрее, чем `run`.

### Ошибка 1: пропущена скобка

```rust
функция главная() {
    печатай_строку!("Привет"   // ❌ нет закрывающей ) и ;
}
```

`rzc check` сообщит:

```
ошибка: несогласованная закрывающая скобка: `}`
 --> src/main.ru:2:22
```

**Как читать**:

- `несогласованная закрывающая скобка`: «закрывающий символ не сходится» — скобка не закрыта;
- после `-->` — место: `src/main.ru`, строка 2, колонка 22;
- у такой **синтаксической ошибки** (нарушено правило письма) нет кода — просто сообщение.

**Исправление**: пересчитайте скобки, слева и справа. Правило: **каждая открытая скобка обязана закрыться**.

### Ошибка 2: имя инструмента написано с опечаткой

```rust
функция главная() {
    печатай_строу!("мир!");  // ❌ «печатай_строу» не существует — надо печатай_строку
}
```

Сообщение:

```
ошибка: макрос `печатай_строу` не найден в этой области
 --> src/main.ru:2:5
```

**Как читать**: «макрос не найден» = **макроса с таким именем здесь нет**. Почти наверняка опечатка.

**Исправление**: сверьтесь с именами из этой главы и исправьте на `печатай_строку!`.

### Ошибка 3: несоответствие типов (самая частая)

```rust
функция главная() {
    пусть счёт: целое = 10;      // счёт держит число
    счёт = "Привет";          // ❌ попытка затолкать текст в числовую коробочку
}
```

Сообщение:

```
Ошибка[E0308]: Несоответствие типов: ожидается `целое`, получено `ссылка_на_строку`
```

**Как читать**:

- `Ошибка[E0308]`: в скобках — **код ошибки**. Каждый код покрывает одно семейство частых ошибок;
- `Несоответствие типов`: суть проблемы — перепутаны разные виды вещей;
- строки-подсказки ниже объясняют и предлагают.

> 📖 **Тип**: «вид» данных. Числа — один вид, текст — другой. Коробочка с ярлыком для одного вида держит только его. Подробно — в Главе 3.

**Запомните**: числа — это числа, текст — это текст, не смешивайте. Как коробочка с ярлыком «яблоки», в которую нельзя совать бананы.

> 📖 С расширением i18n-rust эти же сообщения приходят на русском с учебными подсказками — так rzc делает подарок изучающим на родном языке.

## 2.12 Частые вопросы

**В: На экране «rzc не является командой». Что делать?**

Терминал не нашёл rzc. Закройте и снова откройте терминал; не помогло — перезагрузите компьютер; всё равно не работает — установка не удалась, вернитесь к 2.4 и переустановите.

**В: Я пишу русскими словами — как компьютер поймёт?**

Компьютер сам ничего не понимает. rzc сначала сверяет ваш код с правилами, переводя русские слова в стандартный Rust; затем rustc переводит его в машинный код. Дружелюбный русский текст — интерфейс для вас; исполняется переведённый машинный код.

**В: Текст в кавычках будет переведён?**

Нет. Текст внутри кавычек остаётся ровно как написан. Компилятор обрабатывает только сам код — ключевые слова и идентификаторы.

**В: Чем `печатай!` отличается от `печатай_строку!`?**

`печатай_строку!` после печати переходит на новую строку; `печатай!` — нет. Хотите два куска текста в одной строке — используйте `печатай!`.

**В: Восклицательный знак `!` обязателен?**

Для `печатай_строку!`/`печатай!` — да: это макросы, а макросы носят `!`. Позже встретите вызовы без восклицательного знака (например `имя.длина()`).

**В: Можно обойтись без VS Code и писать в Блокноте?**

Можно, но не рекомендуется. Блокнот без подсветки, форматирования и запуска кнопкой — это мучение. Мастеру нужны хорошие инструменты.

**В: Может ли ошибка в коде сломать компьютер?**

Ни в коем случае. Худшее, что делает ошибка кода, — программа не запускается; исправили и пошли дальше. Экспериментируйте смело.

**В: Я не запомню все слова этой главы!**

Ничего заучивать не надо! Словарик существует, чтобы заглядывать. Пользуйтесь словами — они сами запомнятся, как велосипед: никто не зубрит «сначала оттолкнуться левой ногой».

## Итог главы

1. **Программирование** = записка компьютеру с максимально подробными инструкциями.
2. **Rust по-русски** = `функция`, `пусть`, `печатай_строку!` — а rzc переводит их в стандартный Rust.
3. **Три инструмента**: терминал (команды), компилятор-переводчик (rzc + rustc) и редактор VS Code (письмо).
4. **Первая программа**: `функция главная() { печатай_строку!("Привет, мир!"); }`.
5. **Команда запуска**: `rzc run src/main.ru`; команда проверки: `rzc check src/main.ru`.
6. **Чтение ошибки в три шага**: место (какая строка) → вид (что сломано) → совет (как исправить).

> 📖 Если что-то в главе осталось непонятным — загляните в словарик главы выше или в общий словарь в начале книги.
