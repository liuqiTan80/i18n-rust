# Учебник i18n-rust (русский) — «Пиши на Rust по-русски»

Добро пожаловать! Это русская версия учебника проекта i18n-rust.

Здесь вы учитесь писать настоящий Rust **светскими русскими словами**: `функция главная()`, `пусть`, `печатай_строку!` — а понятные английские сообщения об ошибках компилятор переводит вам на русский с учебными подсказками.

## Как устроена книга

- **Глава 1. Настройка редактора** — VS Code, rust-analyzer, расширение i18n-rust и компилятор rzc.
- **Глава 2. Привет, мир** — первая программа, первый запуск, первое чтение ошибок.
- Дальше — по порядку: переменные, управление потоком, функции, владение, ссылки…

Каждый пример кода в книге **реально компилируется и запускается** через rzc; база непрерывной проверки (CI) подтверждает это при каждом изменении.

## Краткая шпаргалка

```bash
# установить rzc (компилятор-переводчик)
cargo install rzc

# создать первый проект на русском
rzc init Привет-мир --lang ru

# запуск
rzc run src/main.ru
```

Подробности — в Главе 2.
