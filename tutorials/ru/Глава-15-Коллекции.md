# Глава 15: Коллекции

## 15.0 Цели главы

К концу этой главы вы сможете:

1. Назвать три отличия **коллекций** от массивов (куча, переменная длина, один тип);
2. Хранить цепочку однотипных данных в **векторе**: создать, добавить, извлечь, взять по индексу, удалить, обойти;
3. Искать значение по ключу в **словаре**: вставить, получить, проверить наличие ключа, обойти пары;
4. Написать классический приём подсчёта частот через **`запись().или_вставь()`**;
5. Понять **владение** коллекций: коллекция владеет данными внутри;
6. Обойти конфликт заимствований «иду по коллекции — и тут же меняю её».

---

## 15.1 Коллекции: склад, который растёт

У массива из Главы 3 железное правило: **длина вбита намертво**. Объявили `[целое; 3]` — ровно 3 ячейки, ни больше ни меньше.

💡 **Метафора**: массив — ряд **шкафчиков с фиксированным числом ячеек**: сколько купили, столько и есть; **коллекция** — **склад, который сам удлиняется**: пришёл товар — расширился, увезли — сжался.

📖 **Коллекция**: структура данных, живущая **в куче** (большая память, берётся по мере надобности); длина меняется. Три отличия:

| | Массив | Коллекция |
|---|---|---|
| Где живёт | стек (мал, быстр, постоянен) | куча (велик, гибок) |
| Длина | вбита при компиляции | меняется на ходу |
| Тип элементов | один — и только | один — и только |

Два героя главы: **вектор** (упорядоченная цепочка) и **словарь** (телефонная книга «ключ → значение»).

## 15.2 Вектор: массив, который растёт

📖 **Вектор**: упорядоченная, растяжимая цепочка элементов одного типа.

### Создание

```rust
// способ один: сперва пустой склад, потом складываем
пусть изменяемый баллы = вектор::новый();      // тип выведется по первому добавь

// способ два: всё сразу
пусть цвета = макрос_вектора!["красный", "жёлтый", "синий"];
```

> ⚠️ Чтобы складывать в вектор, он обязан быть **`изменяемый`** (склад же достраиваем).

### Добавь и извлеки

```rust
баллы.добавь(88);   // в конец
баллы.добавь(95);
баллы.добавь(76);

// извлеки: забрать из хвоста, возвращает опцию
if let некоторое(цвет) = цвета.извлеки() {
    печатай_строку!("Извлекли: {}", цвет);
}
```

📖 **извлеки**: вынимает последний элемент и укорачивает вектор. Склад может быть и пуст — потому возвращается `опция<тип>`: `некоторое(значение)` или `ничто`; удобнее всего разбирать через `if let`.

### Чтение элементов

```rust
печатай_строку!("Первый: {}", баллы[0]);          // по индексу: за границей — паника!
матч баллы.получи(0) {                      // безопасно: возвращает опцию
    некоторое(значение) => печатай_строку!("Взяли: {}", значение),
    ничто => печатай_строку!("Такой позиции нет"),
}
```

Выбор между двумя способами: **индекс точно законный** — `[индекс]` (быстро); **не уверены** — `получи`: мягко вернёт `ничто` вместо паники.

### Удаление и длина

```rust
баллы.удали(1);              // забрать элемент с индексом 1, остальные подвинулись
печатай_строку!("Длина: {}", баллы.длина());
```

### Обход

```rust
для элемент в ссылка баллы {          // обход по заимствованию: только смотрим
    печатай_строку!("Оценка: {}", элемент);
}
```

`ссылка баллы` означает «одолжить каждый элемент» — ни вектор, ни элементы никуда не уходят.

## 15.3 Владение вектора: склад владеет товаром

Вектор **владеет** каждым элементом внутри: вектор освобождается — освобождаются все элементы.

```rust
{
    пусть фрукты = макрос_вектора!["яблоки", "бананы"];
    // фрукты прописаны в этом блоке
}
// блок кончился: фрукты освобождены, элементы исчезли все
```

Класть в вектор **строку** (данные во владении) — без проблем; класть `ссылка_на_строку` (расписку) — придётся аннотировать времена жизни (Глава 14). Новичкам: кладите `строка`.

## 15.4 Словарь: телефонная книга «ключ → значение»

📖 **Словарь** (HashMap): хранит кучу пар «ключ → значение»; по ключу значение находится мгновенно.

💡 **Метафора**: телефонная книга — «имя → номер». Не надо листать с первой страницы: назвали имя — страница открылась.

### Сперва «подключите»

Словарь, в отличие от целых, надо сперва подключить:

```rust
используй стандарт::коллекции::словарь;
```

(`используй` = use, `стандарт` = std, `коллекции` = collections. Смысл: «принесите телефонную книгу в текущий файл».)

### Вставка и получение

```rust
пусть изменяемый телефонная_книга = словарь::новый();
телефонная_книга.вставь("Соня", 100);    // ключ -> значение
телефонная_книга.вставь("Гриша", 95);

матч телефонная_книга.получи("Соня") {
    некоторое(значение) => печатай_строку!("Балл Сони: {}", значение),
    ничто => печатай_строку!("Такого ученика нет"),
}

печатай_строку!("Есть ли Гриша: {}", телефонная_книга.содержит_ключ("Гриша"));
```

Обратите внимание: `получи` возвращает `опция<ссылка значения>` — ключа может не быть, потому разбираем `матч`-ем или `if let`. Хотите только знать «есть ли», без значения — `содержит_ключ`.

### Обход пар

```rust
для (ключ, значение) в ссылка телефонная_книга {
    печатай_строку!("{} -> {}", ключ, значение);
}
```

> ⚠️ Порядок обхода словаря **не гарантирован** — от запуска к запуску может меняться. Нужен порядок — берите `дерево_карта` (из 15.5).

### Подсчёт частот: `запись().или_вставь()`

Посчитать, сколько раз встречается каждое слово, — классический приём словаря:

```rust
пусть слова = ["яблоки", "бананы", "яблоки", "апельсины", "яблоки", "бананы"];
пусть изменяемый частота = словарь::новый();

для слово в слова {
    // запись: встали у «двери» слова; или_вставь: нет — сперва положи 0
    пусть счёт = частота.запись(слово).или_вставь(0);
    *счёт = *счёт + 1;
}
```

Чтение: `запись(слово)` встаёт у «двери» этого слова; `или_вставь(0)` говорит «если нет — положи сперва 0»; затем получаем **изменяемую ссылку на место значения** и `*счёт`-ом прибавляем единицу прямо на месте. Слово пришло впервые: 0 + 1 = 1; каждый следующий раз — ещё +1.

## 15.5 Больше коллекций

Кроме вектора и словаря, в стандартной библиотеке — целый ящик ходовых коллекций. В этом разделе — четыре новых друга и один приём, ускоряющий вектор.

### Хеш-множество: помнит только «есть или нет»

💡 **Метафора**: словарь — телефонная книга «имя → номер»; **хеш-множество** — **журнал посетителей у входа**: записано лишь, кто приходил.

📖 **Хеш-множество** (HashSet): набор **неповторяющихся** элементов; проверка «есть ли» — молниеносная.

Сперва подключите (`коллекции` = collections):

```rust
используй стандарт::коллекции::хэш_множество;
```

Демонстрация «авто-дедупликация + проверка наличия»:

```rust
используй стандарт::коллекции::хэш_множество;

функция главная() {
    пусть изменяемый гости = хэш_множество::новый();
    гости.вставь("Аня");
    гости.вставь("Боря");
    гости.вставь("Аня");
    печатай_строку!("Гостей: {}", гости.длина());
    печатай_строку!("Аня здесь? {}", гости.содержит("Аня"));
    печатай_строку!("Вера здесь? {}", гости.содержит("Вера"));
    для имя в ссылка гости {
        печатай_строку!("Гость: {}", имя);
    }
}
```

Вывод:

```
Гостей: 2
Аня здесь? true
Вера здесь? false
Гость: Аня
Гость: Боря
```

Повторная `вставь("Аня")` сработала как **авто-дедупликация** — в журнале Аня занимает одну строку, гостей по-прежнему 2. Порядок двух последних строк **не гарантирован**: как и словарь, хеш-множество не обещает порядок вставки (Аня и Боря могут поменяться местами).

### Двусторонняя очередь: вход и выход с обоих концов

У вектора `добавь`/`извлеки` работают с одного конца (хвоста). **Двусторонняя очередь** пускает и спереди, и сзади — идеально для «очереди с вызовом по номеру»:

```rust
используй стандарт::коллекции::двусторонняя_очередь;

функция главная() {
    пусть изменяемый очередь = двусторонняя_очередь::новый();
    очередь.добавь_в_конец(1);
    очередь.добавь_в_начало(0);
    очередь.добавь_в_конец(2);
    печатай_строку!("Спереди: {}", очередь.извлеки_спереди().разверни_опцию());
    печатай_строку!("Сзади: {}", очередь.извлеки_с_конца().разверни_опцию());
}
```

Вывод:

```
Спереди: 0
Сзади: 2
```

Четыре метода: `добавь_в_конец` (push_back), `добавь_в_начало` (push_front), `извлеки_спереди` (pop_front), `извлеки_с_конца` (pop_back). Очередь сейчас `0 → 1 → 2`: сперва вышли спереди 0, потом сзади 2, посередине осталась 1.

### Двоичная куча: всегда извлекает максимум

**Двоичная куча** (BinaryHeap) — «автоматически сортирующийся мешок»: что ни бросишь внутрь, `извлеки()` всегда отдаёт **текущий максимум**:

```rust
используй стандарт::коллекции::двоичная_куча;

функция главная() {
    пусть изменяемый куча = двоичная_куча::новый();
    куча.добавь(3);
    куча.добавь(9);
    куча.добавь(5);
    печатай_строку!("Максимум: {}", куча.извлеки().разверни_опцию());
    печатай_строку!("Следующий: {}", куча.извлеки().разверни_опцию());
}
```

Вывод:

```
Максимум: 9
Следующий: 5
```

📖 **Максимальная куча**: структура, сперва отдающая наибольшее. Годится для «сначала самое срочное» (планировщики задач).

### Дерево-карта: по ключу по порядку

Словарь не гарантирует порядок; нужен **обход по порядку ключей** — берите **дерево-карту** (BTreeMap):

```rust
используй стандарт::коллекции::дерево_карта;

функция главная() {
    пусть изменяемый цены = дерево_карта::новый();
    цены.вставь("апельсины", 5);
    цены.вставь("яблоки", 3);
    цены.вставь("бананы", 2);
    для (товар, цена) в ссылка цены {
        печатай_строку!("{} -> {}", товар, цена);
    }
}
```

Вывод:

```
апельсины -> 5
яблоки -> 3
бананы -> 2
```

Пользование то же, что у словаря (`новый`, `вставь`, `получи`), разница одна: при обходе элементы стоят **отсортированными по ключу** (здесь — по кодам символов). Цена — вставка и поиск чуть-чуть медленнее; берите, только когда нужен порядок.

### Вместимость вектора и резервирование

Вектор **растёт автоматически**: места мало — просит кусок побольше и переезжает. Переезды стоят денег, потому вектор заранее резервирует место:

📖 **Вместимость**: сколько ячеек вектор **зарезервировал** сейчас; не обязательно заполненных. `длина()` — сколько уже стоит; `вместимость()` — сколько влезает.

```rust
функция главная() {
    пусть изменяемый список = вектор::новый();
    список.зарезервируй(100);
    печатай_строку!("Вместимость после резерва: {}", список.вместимость());
    список.добавь(1);
    список.добавь(2);
    печатай_строку!("Длина: {}, вместимость: {}", список.длина(), список.вместимость());
}
```

Вывод:

```
Вместимость после резерва: 100
Длина: 2, вместимость: 100
```

`зарезервируй(100)` арендует 100 ячеек разом; добавили 2 — вместимость не дрогнула (ещё 98 в запасе). **Приём предварительного резервирования**: примерно знаете объём — сперва `зарезервируй`, потом `добавь`; переезды отменяются.

### Частая ошибка: индекс у хеш-множества

Хеш-множество хранится не по позициям — запись `гости[0]` не скомпилируется:

```rust
// 预期错误: E0608
используй стандарт::коллекции::хэш_множество;

функция главная() {
    пусть изменяемый гости = хэш_множество::новый();
    гости.вставь("Аня");
    гости.вставь("Боря");
    печатай_строку!("Первый: {}", гости[0]);
}
```

```
Ошибка[E0608]: невозможно применить индекс к типу хэш_множество<строка>
 --> строка 7: гости[0]
```

**Решение**: хеш-множество отвечает только на «есть или нет» (метод `содержит`), «какой по счёту» у него не спрашивают. Нужен порядок — вектор или дерево-множество (BTreeSet); нужен лишь обход — `для имя в ссылка гости`.

## 15.6 Полный пример: журнал оценок

Вектор и словарь в одной упряжке — собрать серию оценок, посчитать сумму, затем частоты:

```rust
используй стандарт::коллекции::словарь;

функция главная() {
    // —— вектор: собираем оценки класса ——
    пусть изменяемый баллы = вектор::новый();
    баллы.добавь(88);
    баллы.добавь(95);
    баллы.добавь(76);
    баллы.добавь(88);
    баллы.добавь(95);

    // сумма
    пусть изменяемый итог = 0;
    для элемент в ссылка баллы {
        итог = итог + *элемент;
    }
    печатай_строку!("Всего {} человек, сумма {}", баллы.длина(), итог);

    // —— словарь: сколько раз встречается каждая оценка ——
    пусть изменяемый частота = словарь::новый();
    для элемент в ссылка баллы {
        пусть счёт = частота.запись(*элемент).или_вставь(0);
        *счёт = *счёт + 1;
    }
    для (балл, раз) в ссылка частота {
        печатай_строку!("{} баллов — {} раз(а)", балл, раз);
    }

    // —— извлечём последнего ——
    if let некоторое(конец) = баллы.извлеки() {
        печатай_строку!("Оценка последнего: {}", конец);
        печатай_строку!("Осталось {} человек", баллы.длина());
    }
}
// 预期输出: Всего 5 человек, сумма 442
// 88 баллов — 2 раз(а)
// 95 баллов — 2 раз(а)
// 76 баллов — 1 раз(а)
// Оценка последнего: 95
// Осталось 4 человек
```

## 15.7 По строкам

- **Строки 5–10**: пустой вектор, пять `добавь` — склад растёт сам, предварительной переклички не нужно.
- **Строки 13–16**: обход по заимствованию (`ссылка баллы`); `элемент` — это `ссылка целое`, значение достаём `*элемент`.
- **Строки 20–24**: приём частот — `запись(*элемент)` у «двери» оценки, `или_вставь(0)` подстилает ноль, `*счёт` копит. `*элемент` разбирает заимствованное целое в ключ.
- **Строки 25–27**: обход таблицы частот. Ключ — оценка, значение — сколько раз.
- **Строки 30–33**: `извлеки` забирает последнюю оценку; `if let` страхует «а вдруг пусто».

## 15.8 Вывод

```
Всего 5 человек, сумма 442
88 баллов — 2 раз(а)
95 баллов — 2 раз(а)
76 баллов — 1 раз(а)
Оценка последнего: 95
Осталось 4 человек
```

(Три строки таблицы частот могут идти в другом порядке — словарь не гарантирует порядок обхода; это нормально.)

## 15.9 Частые ошибки и как их исправить

### Ошибка 1: разные типы в одном векторе

```
Ошибка: несоответствие типов
```

`макрос_вектора![1, "привет"]` — нельзя: коллекция держит **один** тип. Хотите мешать — упакуйте типы в перечисление из Главы 11.

### Ошибка 2: добавление в неизменяемый вектор

```
Ошибка: нельзя заимствовать как изменяемое
```

`добавь`, `удали`, `извлеки` требуют **`изменяемый`**. Пишите `пусть изменяемый список = ...`.

### Ошибка 3: править коллекцию во время обхода

```
Ошибка: нельзя одновременно держать изменяемое и неизменяемое заимствования
```

Внутри `для элемент в ссылка баллы` написать `баллы.добавь(...)` — столкновение с железным правилом Главы 8. **Решение**: соберите добавляемое заранее и добавьте после обхода.

### Ошибка 4: паника за границей индекса

```
поток 'главная' запаниковал: индекс за границей
```

`баллы[99]`, а вектор короче. **Решение**: не уверены в длине — `получи(индекс)` + `матч`.

### Ошибка 5: забыли подключить словарь

Ошибка «не найден `словарь`». **Решение**: вверху файла `используй стандарт::коллекции::словарь;`.

## 15.10 Словарик главы

| Термин | Значение одной строкой |
|---|---|
| Коллекция | Структура данных в куче с переменной длиной |
| Вектор | Упорядоченная растяжимая цепочка однотипных элементов |
| макрос_вектора | `макрос_вектора![...]` — построить вектор разом |
| добавь | Добавить элемент в хвост вектора |
| извлеки | Вынуть и убрать хвостовой элемент, возвращает опцию |
| получи | Безопасное чтение по индексу, возвращает опцию |
| удали | Забрать элемент по индексу, остальные сдвигаются |
| Словарь | Коллекция пар «ключ → значение» |
| запись | «Дверь» словаря; с или_вставь даёт «нет — инициализируй» |
| или_вставь | Нет ключа — вставить значение по умолчанию, вернуть изменяемую ссылку |
| содержит_ключ | Есть ли такой ключ, возвращает логическое |
| Дерево-карта | Словарь, отсортированный по ключу |

> 📖 **Напоминание**: незнакомое слово — загляните в «Общий словарь» в начале книги.

### Упражнение 1: список покупок

Соберите вектор строк, добавьте три товара, напечатайте количество и последний, затем извлеките один и напечатайте.

<details>
<summary>🔍 Ответ</summary>

```rust
функция главная() {
    пусть изменяемый список = вектор::новый();
    список.добавь(строка::Из("молоко"));
    список.добавь(строка::Из("хлеб"));
    список.добавь(строка::Из("яйца"));
    печатай_строку!("Всего {} шт, последний: {}", список.длина(), список[2]);
    if let некоторое(забрали) = список.извлеки() {
        печатай_строку!("Извлекли: {}", забрали);
    }
}
```

</details>

Соберите словарь «английское слово → перевод по-русски»; найдите `"apple"` и `"moon"`: для первого напечатайте перевод, для второго — «не найдено».

<details>

```rust
    }
    матч англо_русский.получи("moon") {
        некоторое(перевод) => печатай_строку!("moon -> {}", перевод),
        ничто => печатай_строку!("Не найдено"),
    }
}
```

</details>

### Упражнение 3: подсчёт голосов

Массив `["Аня", "Боря", "Аня", "Вера", "Боря", "Аня"]` — результаты голосования; через `запись().или_вставь()` посчитайте голоса каждого.

<details>
<summary>🔍 Ответ</summary>

```rust
используй стандарт::коллекции::словарь;

функция главная() {
    пусть бюллетени = ["Аня", "Боря", "Аня", "Вера", "Боря", "Аня"];
    пусть изменяемый голоса = словарь::новый();
    для человек в бюллетени {
        пусть счёт = голоса.запись(человек).или_вставь(0);
        *счёт = *счёт + 1;
    }
    для (человек, число) в ссылка голоса {
        печатай_строку!("{} — {} голос(ов)", человек, число);
    }
}
```

</details>

## 15.12 Частые вопросы

**В: Почему вектор живёт в куче — стек ведь быстрее?**

На стеке мало места, и размер обязан быть известен при компиляции. Вектор «умеет расти» — влезает и 10, и 100 тысяч элементов; такая упругость доступна только куче. Скорость доступа к элементам одинакова (внутри вектора — тоже сплошной кусок памяти).

**В: Что будет, когда вектор заполнится?**

«Заполнится» не бывает. Места мало — сам просит кусок побольше и переезжает, всё автоматически. Это и есть «склад, который растёт».

**В: Каким должен быть ключ словаря?**

Умеющим **сравниваться на равенство** и **вычислять хеш** — целые, логические, строки подходят. Своя структура в роли ключа требует двух наклеек: `#[производи(ЧастичноРавно, Равно, Хэш)]`.

**В: `баллы[0]` или `баллы.получи(0)` — как выбрать?**

На олимпиаде, где индекс точно законный, — первое (короче); индекс от пользователя, уверенности нет, — второе (никогда не паникует).

**В: Хочу обходить словарь и менять значения — как?**

`для (ключ, значение) в ссылка_изменяемая словарь` — `значение` станет изменяемой ссылкой, меняйте. Но добавлять/убирать ключи одновременно нельзя (опять железное правило заимствований) — это в два захода.

**В: Можно вложить коллекцию в коллекцию?**

Можно. `вектор<вектор<целое>>` (таблица), вектор в роли значения словаря — всё работает. Типы читайте изнутри наружу.
