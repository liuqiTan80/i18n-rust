# Глава 8: Ссылки и заимствование

## 8.0 Цели главы

К концу этой главы вы сможете:

1. Объяснить связь **ссылки** и **заимствования** (одно — вещь, другое — действие);
2. Делать читающее заимствование знаком **`&`** и изменяющее — **`изменяемая_ссылка`**;
3. Произнести железное правило заимствования: **«либо один изменяемый, либо много читающих»**;
4. Прочитать и исправить **E0502** (конфликт заимствований) и **E0596** (нельзя взять изменяемым);
5. Делать **разыменование** знаком `*` — доставать原 значение из расписки;
6. Знать: «заимствование живёт до последнего использования».

---

## 8.1 Задача, оставленная прошлой главой

В Главе 7 говорилось: строка, переданная в функцию, **переезжает**, прежняя переменная недействительна. Но чаще всего мы хотим, чтобы функция лишь **взглянула**, а не подарить вещь:

```rust
функция покажи(фраза: строка) {   // по значению: фраза переезжает, использована — уничтожена
    печатай_строку!("{}", фраза);
}

функция главная() {
    пусть привет = строка::Из("Привет");
    покажи(привет);
    // привет больше нет; ещё раз? Ни за что
}
```

Забрать оригинал ради одного взгляда — слишком деспотично. Решение реального мира — **одолжить**.

## 8.2 Ссылка: одна расписка

💡 **Метафора**: одноклассник хочет посмотреть ваш внеклассный учебник. Вы не **переоформляете** книгу, а говорите «возьми почитать». У него в руках — **читательская расписка**: по ней книгу найти можно, но хозяин — вы.

📖 **Ссылка**: «расписка», указывающая на значение; пишется `&значение`. `&` читается «возьми ссылку». Ссылка — не само значение, она лишь помнит «где оно».
📖 **Заимствование**: действие — временно пользоваться чужими данными через ссылку. Взяли — верните: ссылка не меняет владение.

### Читающее заимствование

```rust
// тип параметра ссылка строка: одолжить посмотреть
функция покажи(фраза: ссылка строка) {
    печатай_строку!("{}", фраза);
}

функция главная() {
    пусть привет = строка::Из("Привет");
    покажи(ссылка привет);     // вручаем расписку
    покажи(ссылка привет);     // одолжить ещё раз — можно
    печатай_строку!("Жив: {}", привет);   // оригинал цел
}
```

Вывод:

```
Привет
Привет
Жив: Привет
```

`ссылка привет` составляет расписку и передаёт функции. Функция посмотрела — расписка погашена, `привет` по-прежнему хозяин. Занимать сколько угодно раз.

## 8.3 Изменяемое заимствование: одолжить и поправить

Иногда хочется не только смотреть, но и **править** — как делать пометки на полях книги. Нужно **изменяемое заимствование** `изменяемая_ссылка`:

```rust
функция допиши(книга: изменяемая_ссылка строка, пометка: ссылка_на_строку) {
    книга.добавь_строку(пометка);   // добавь_строку: добавить текст в конец
}

функция главная() {
    пусть изменяемый книга = строка::Из("Три богатыря");
    допиши(изменяемая_ссылка книга, " (детское)");
    печатай_строку!("{}", книга);
}
// 预期输出: Три богатыря (детское)
```

Вывод: `Три богатыря (детское)`

Два новых требования:

| Требование | Запись | Причина |
|---|---|---|
| Одолженное значение объявлено изменяемым | `пусть изменяемый книга = ...` | Неизменяемое нельзя дать «под правку» |
| При выдаче писать `изменяемая_ссылка` | `допиши(изменяемая_ссылка книга, ...)` | Явно заявить: «это изменяемое заимствование» |

> 📖 **добавь_строку**: метод строки, добавляет текст в конец. Родня — `добавь` (один символ).

## 8.4 Железное правило заимствования: выбор из двух

У заимствований в Rust одно железное правило:

> **В один момент — либо сколько угодно читающих заимствований, либо одно изменяемое. Одновременно — никак.**

💡 **Метафора**: правила библиотеки —
- **читающее заимствование** = несколько человек **одновременно читают в читальном зале**: читателей много, всё в порядке;
- **изменяемое заимствование** = кто-то забрал книгу **переплести заново**: тут — монополия, никому не показывать;
- Оба **не могут случиться разом**: пока читают, вырвать книгу на переплёт — у читателей страницы съедут.

Нарушили правило — получите **E0502**:

```rust
// 预期错误: E0502
пусть изменяемый лозунг = строка::Из("Вперёд");
пусть взгляд = ссылка лозунг;        // читающее заимствование в силе
пусть правка = изменяемая_ссылка лозунг;    // ❌ разом изменяемое
печатай_строку!("{}", взгляд);     // взгляд понадобится и дальше — заимствование обязано дожить до этой строки
```

Реальная ошибка:

```
Ошибка[E0502]: `лозунг` нельзя взять изменяемым, так как он также взят неизменяемым
📌 Переменная `лозунг` взята в заимствование в строке 3 и всё ещё используется в строке 5.
💡 В Rust изменяемое и неизменяемое заимствования не могут существовать одновременно. Сузьте область неизменяемого заимствования.
```

### Почему так строго?

Допустим, «читать и править разом» разрешено: функция А держит расписку и читает строку, функция Б вдруг дописывает буквы — строке на складе может понадобиться **комната побольше** (перевыделение памяти) — и расписка А мгновенно укажет в **пустую** комнату. Крах. Железное правило душит такие аварии ещё на компиляции.

### Заём за займом — без проблем

Правило следит за « **одновременно** ». Первый заимствование отработало, второе пришло — полностью законно:

```rust
пусть изменяемый книга = строка::Из("Три богатыря");
покажи(ссылка книга);                    // первое читающее, отработало — погашено
допиши(изменяемая_ссылка книга, " (детское)"); // изменяемое, отработало — погашено
покажи(ссылка книга);                    // снова читающее — без проблем
```

### «Срок жизни» заимствования

Срок жизни заимствования = **от рождения до последнего использования**. Отработало — правило его больше не трогает:

```rust
пусть изменяемый лозунг = строка::Из("Вперёд");
пусть взгляд = ссылка лозунг;
печатай_строку!("{}", взгляд);    // последнее использование взгляда
// здесь срок жизни взгляда закончился
пусть правка = изменяемая_ссылка лозунг;    // ✅ без проблем: читающее заимствование истекло
правка.добавь_строку("!");
```

> ✨ Это умная сторона компилятора: он смотрит не на то, как долго расписка «лежала на полке», а на то, **где вы ею реально пользовались**.

## 8.5 Читающее заимствование менять нельзя: E0596

Параметр объявлен `ссылка строка` (только чтение), а в функции хочется менять — получите **E0596**:

```rust
// 预期错误: E0596
функция своевольничай(книга: ссылка строка) {
    книга.добавь_строку("!");    // ❌
}
```

Реальная ошибка:

```
Ошибка[E0596]: нельзя взять как изменяемое, так как это не объявлено изменяемым
💡 Изменяемое заимствование (`изменяемая_ссылка`) доступно лишь изменяемым переменным. Объявите переменную через `пусть изменяемый` или добавьте `изменяемый` параметру.
```

**Решение**: менять — так смените параметр на `изменяемая_ссылка строка` и убедитесь, что переменная вызывающего объявлена `пусть изменяемый`.

## 8.6 Разыменование: достать原 значение из расписки

📖 **Разыменование**: достать из ссылки значение, на которое она указывает; знак `*`.

```rust
пусть балл = 95;
пусть расписка = ссылка балл;
пусть списанная = *расписка;      // * идёт по расписке к原 значению и списывает его
печатай_строку!("Списанное значение: {}", списанная);
// 预期输出: Списанное значение: 95
```

Вывод: `Списанное значение: 95`

`&` — «написать расписку», `*` — «получить по расписке» — направления противоположные.

> ✨ В повседневном коде вручную разыменовывают редко — при вызове методов компилятор сам идёт по ниточке (`(&книга).длина()` можно писать просто `книга.длина()`). Достаточно знать, что `*` существует, и уметь читать ошибки.

## 8.7 А целое ссылкой одолжить можно?

Можно. Ссылка и копирование не конфликтуют:

```rust
пусть балл = 95;
пусть расписка = ссылка балл;
печатай_строку!("Расписка указывает на: {}", расписка);
печатай_строку!("Оригинал жив: {}", балл);   // целое и так копируется, цело и невредимо
```

Просто целые маленькие и копируются даром — передавайте значением, одалживать незачем. Ссылки по-настоящему блистают на «крупном»: **строки, векторы, структуры**.

## 8.8 Полный пример: библиотечная система

Читающее, изменяемое, параллельное и последовательное заимствования — в одной программе:

```rust
// читающее заимствование: посмотрел — вернул
функция покажи(книга: ссылка строка) {
    печатай_строку!("Содержимое: {}", книга);
}

// изменяемое заимствование: поправил — вернул
функция допиши(книга: изменяемая_ссылка строка, пометка: ссылка_на_строку) {
    книга.добавь_строку(пометка);
}

// два читающих заимствования разом: без проблем
функция сравни_длины(а: ссылка строка, б: ссылка строка) {
    если а.длина() > б.длина() {
        печатай_строку!("Первая длиннее");
    } иначе {
        печатай_строку!("Вторая не короче");
    }
}

функция главная() {
    пусть изменяемый книга = строка::Из("Три богатыря");
    покажи(ссылка книга);                       // читающее
    допиши(изменяемая_ссылка книга, " (детское)");    // изменяемое
    покажи(ссылка книга);                       // читающее

    пусть другая = строка::Из("Путешествие на Запад");
    сравни_длины(ссылка книга, ссылка другая);           // два читающих параллельно

    печатай_строку!("Оригинал жив: {}", книга);
}
// 预期输出: Содержимое: Три богатыря
// Содержимое: Три богатыря (детское)
// Первая длиннее
// Оригинал жив: Три богатыря (детское)
```

## 8.9 По строкам

- **Строки 2–4**: `покажи` принимает `ссылка строка` — только заимствует. После вызова оригинал на месте.
- **Строки 7–9**: `допиши` принимает `изменяемая_ссылка строка`; `добавь_строку` дописывает в конец.
- **Строки 12–18**: `сравни_длины` держит два читающих заимствования разом — правило разрешает «много читающих параллельно». `длина()` возвращает **байты** (русская буква — 2 байта; «Три богатыря» — 24 байта).
- **Строка 21**: `пусть изменяемый` — дальше изменяемое заимствование, без изменяемости нельзя.
- **Строки 22–24**: три заимствования происходят **последовательно**, каждое гаснет, отработав, — конфликтов нет.
- **Строка 26**: обе «книги» заимствованы читающе одновременно.
- **Строка 28**: все долги возвращены, оригинал цел — печатается.

## 8.10 Вывод

```
Содержимое: Три богатыря
Содержимое: Три богатыря (детское)
Первая длиннее
Оригинал жив: Три богатыря (детское)
```

«Три богатыря (детское)» длиннее «Путешествия на Запад» в байтах — потому «Первая длиннее».

## 8.11 Частые ошибки и как их исправить

### Ошибка 1: E0502 конфликт заимствований (изменяемое + читающее разом)

```
Ошибка[E0502]: `лозунг` нельзя взять изменяемым, так как он также взят неизменяемым
```

**Решение**: разведите два заимствования **по времени** — сперва доведите до конца читающее (израсходуйте его), потом начинайте изменяемое; либо клонируйте и правьте копию.

### Ошибка 2: E0596 менять читающее заимствование

```
Ошибка[E0596]: нельзя взять как изменяемое, так как это не объявлено изменяемым
```

**Решение**: проверьте три места разом — ① исходная переменная `пусть изменяемый`? ② на месте вызова написано `изменяемая_ссылка`? ③ тип параметра — `изменяемая_ссылка тип`? Одного не хватает — не работает.

### Ошибка 3: забыли `пусть изменяемый`

Написать `изменяемая_ссылка а` у неизменяемой переменной — тот же E0596. **Решение**: добавьте `изменяемый` в объявление.

### Ошибка 4: ссылка пережила своего владельца

```rust
// 预期错误: E0597
функция главная() {
    пусть расписка;
    {
        пусть короткая = строка::Из("короткий век");
        расписка = ссылка короткая;
    }
    печатай_строку!("{}", расписка);   // ❌ короткой больше нет — расписка стала бумажкой без покрытия
}
```

Ошибка скажет «заимствованное значение живёт недостаточно долго». **Решение**: срок жизни расписки не может превысить жизнь оригинала. Пусть оригинал живёт дольше расписки.

> 📖 **Висячая ссылка**: ссылка на уже исчезнувшие данные. Rust запрещает её появление ещё на компиляции — это стержень безопасности ссылок.

## 8.12 Словарик главы

| Термин | Значение одной строкой |
|---|---|
| Ссылка | «Расписка», указывающая на значение; пишется `&значение` |
| Заимствование | Временно пользоваться чужими данными через ссылку, не меняя владение |
| Читающее заимствование | `&значение`; может быть сколько угодно одновременно |
| Изменяемое заимствование | `изменяемая_ссылка значение`; только одно в один момент |
| Железное правило | Либо много читающих, либо одно изменяемое; вместе — нельзя |
| Разыменование | Достать `*`-ом原 значение из ссылки |
| E0502 | Код ошибки конфликта изменяемого и читающего заимствований |
| E0596 | Код ошибки «взять изменяемым не удалось» |
| Висячая ссылка | Ссылка на исчезнувшие данные (запрещена на компиляции) |
| добавь_строку | Метод, дописывающий текст в конец строки |

> 📖 **Напоминание**: незнакомое слово — загляните в «Общий словарь» в начале книги.

### Упражнение 2: изменяемое заимствование

<details>
<summary>🔍 Ответ</summary>

```rust
функция удвой_фразу(фраза: изменяемая_ссылка строка) {
    пусть копия = фраза.клонируй();
    фраза.добавь_строку(ссылка копия);
}

функция главная() {
    пусть изменяемый лозунг = строка::Из("Вперёд");
    удвой_фразу(изменяемая_ссылка лозунг);

// 预期输出: ВперёдВперёд
```

Вывод: `ВперёдВперёд`

(Написать прямо `фраза.добавь_строку(фраза)` — конфликт: одной стороной мы изменяемо заимствуем `фразу`, другой — читаем её. Клон в обход спасает.)

### Упражнение 3: верно или неверно

Какие из строк скомпилируются?

```rust
пусть изменяемый тетрадь = строка::Из("математика");
пусть первая = ссылка тетрадь;
пусть вторая = ссылка тетрадь;
пусть третья = изменяемая_ссылка тетрадь;
```

<details>
<summary>🔍 Ответ</summary>

Строки `первая`, `вторая` — без проблем (много читающих параллельно); строка `третья` — **в таком виде тоже пройдёт**: `первая` и `вторая` после этого ни разу не используются, их срок жизни уже истёк. Добавьте ниже использование `первой` или `второй` — и появится E0502. Это практика правила «срок жизни — до последнего использования».

</details>

## 8.14 Частые вопросы

**В: `ссылка строка` и `ссылка_на_строку` из Главы 7 — одно и то же?**

Братья, но не близнецы. `ссылка строка` — «ссылка на строка» (на String); `ссылка_на_строку` — «заимствование самого текста». Строковый литерал `"Привет"` — это `ссылка_на_строку`. Оба умеют «читать текст без права записи», методы по большей части общие. Различия и превращения — в Главе 9.

**В: Почему нельзя два изменяемых заимствования?**

Оба заявляют «менять буду я» — порядок изменений разный, результат разный, данные — каша. Одно изменяемое заимствование — и кто, что и когда поменял, видно как на ладони.

**В: Проверка заимствований тормозит программу?**

Нет. Всё происходит на компиляции; во время выполнения цена — ноль. Это «безопасность нулевой стоимости» Rust.

**В: Вечно путаю правила заимствования. Есть скороговорка?**

Запомните одну: **«читать — можно толпой, писать — только в одиночку, а вместе — ни-ни»**.

**В: Параметру функции — значение или ссылка?**

Эмпирика — **смотреть: `&`; менять: `изменяемая_ссылка`; по-настоящему забрать: значение**. Мелочь вроде целых можно и значением (копирование дёшево).

**В: `&себя` и `изменяемая_ссылка себя` методов — это то же, что `&` и `изменяемая_ссылка` этой главы?**

Ровно то же. `&себя` метода из Главы 6 — «метод читающе заимствует экземпляр», `изменяемая_ссылка себя` — «изменяемо заимствует». Теперь вы понимаете их насквозь.
