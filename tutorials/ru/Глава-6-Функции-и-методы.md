# Глава 6: Функции и методы

## 6.0 Цели главы

К концу этой главы вы сможете:

1. Объяснить на примере **волшебной коробочки**, что такое функция;
2. Самим писать функции **с параметрами и возвращаемым значением**;
3. Различать **инструкции** и **выражения**, знать, как точка с запятой «проглатывает» результат;
4. Словом **`верни`** отдать результат заранее;
5. Писать **рекурсивные** функции (функция вызывает сама себя);
6. Блоком **`реализация`** прикреплять к типам **методы**; знать три формы слова **`себя`**;
7. Знать **пустой тип** `()`.

## 6.1 Что такое функция: волшебная коробочка

💡 **Метафора**: представьте, что у вас есть **волшебная коробочка**:

- Сверху через **вход** вы кладёте внутрь вещи (это **параметры**);
- Внутри коробочка сама суетится (это **тело функции**);
- Потом снизу из **выхода** выплёвывает результат (это **возвращаемое значение**).

Например коробочка-«соковыжималка»: кладёте яблоко (параметр), она внутри отжимает (тело функции), выдаёт яблочный сок (возвращаемое значение).

📖 **Функция**: поименованный набор инструкций, который можно использовать снова и снова. По-русски пишется **`функция`**.

На самом деле вы уже пользовались функцией — `печатай_строку!` — это она (особый «макрос», о значении восклицательного знака говорили во 2-й главе). Теперь вы учитесь **строить коробочки сами**.

### Зачем нужны функции

Допустим, нужно напечатать одну и ту же фигурку из звёздочек в трёх местах. Не зная функций, вам пришлось бы **переписать один и тот же код трижды**. Три переписки — две беды:

1. **Утомительно**: три раза писать — трата времени;
2. **Трудно править**: захотите изменить фигурку — правьте в трёх местах; пропустите одно — ошибка в программе (на жаргоне — «баг»).

С функцией: складываем код фигурки в коробочку и даём имя. Когда нужно — **зовём по имени**; правим — в единственном месте внутри коробочки.

> 💡 **Одной фразой**: функция = поименованный блок кода, чтобы **меньше переписывать и легче править**.

## 6.2 Самая простая функция

Сначала — функция без параметров и без возвращаемого значения:

```rust
функция поприветствуй() {
    печатай_строку!("Привет!");
}

функция главная() {
    поприветствуй();
    поприветствуй();
}
```

Вывод:

```
Привет!
Привет!
```

Разбираем пять частей:

| Часть | Пример | Пояснение |
|---|---|---|
| Ключевое слово `функция` | `функция` | Сообщает компьютеру «здесь будет построена коробочка» |
| Имя функции | `поприветствуй` | Имя коробочки — любое (лучше глагол) |
| Круглые скобки | `()` | Место для параметров; сейчас их нет, поэтому пусто |
| Фигурные скобки | `{ }` | «Тело» коробочки, внутри конкретные инструкции |
| Вызов | `поприветствуй();` | Имя + скобки + точка с запятой — коробочка работает |

> ⚠️ **Внимание**: **определить** функцию (построить коробочку) и **вызвать** её (заставить работать) — разные вещи. Только определение без вызова — коробочка никогда не заработает. Вход в программу — всегда `главная`.

## 6.3 Параметры: кладём вещи в коробочку

📖 **Параметр**: вход, который принимает функция; имя, записанное при определении.
📖 **Аргумент**: значение, реально передаваемое при вызове.

💡 **Метафора**: в инструкции к соковыжималке написано «положите **фрукты**» — «фрукты» это **параметр** (имя-заглушка); а яблоко, которое вы реально положили, — **аргумент**.

### Один параметр

```rust
функция поздоровайся(имя: ссылка_на_строку) {
    печатай_строку!("Привет, {}!", имя);
}

функция главная() {
    поздоровайся("Саша");
    поздоровайся("Маша");
}
```

> 📖 **ссылка_на_строку**: заимствованный текст, например литерал `"..."`. Подробно — Глава 9; сейчас достаточно знать: текст в двойных кавычках принадлежит этому типу.

Форма параметра — **`имя: тип`** — Rust требует **явно указывать тип** каждого параметра, ни один нельзя пропустить.

### Несколько параметров

Несколько параметров разделяются **запятой**:

```rust
функция сумма(а: целое, б: целое) -> целое {
    а + б
}

функция главная() {
    пусть итог = сумма(3, 7);
    печатай_строку!("Сумма: {}", итог);
}
// 预期输出: Сумма: 10
```

Вывод: `Сумма: 10`

Обратите внимание на новый знак **`->`** (дефис + больше; означает «указывает на»):

- `-> целое` значит «то, что коробочка выплёвывает, — целое число»;
- функция без `->` ничего не выплёвывает (строго говоря, выплёвывает «пусто», раздел 6.8).

> ⚠️ **Внимание**: **число и порядок** аргументов при вызове обязаны совпадать с параметрами. `сумма(3)` — одного не хватает; `сумма("три", 7)` — тип не тот; обе — ошибки.

## 6.4 Возвращаемое значение: коробочка выплёвывает результат

Три способа отдать результат.

### Способ первый: выражение в конце (без точки с запятой)

Если **последняя строка** тела функции — **выражение** (то, что вычисляет значение), и в её конце **нет точки с запятой**, её значение и есть возвращаемое:

```rust
функция квадрат(число: целое) -> целое {
    число * число
}
```

`число * число` без точки с запятой → его значение «выплёвывается».

### Способ второй: ключевое слово `верни`

📖 **Верни**: немедленно отдать значение; функция на этом заканчивается.

```rust
функция максимум(а: целое, б: целое) -> целое {
    если а > б {
        верни а;
    }
    б
}
```

Чтение: «если а больше — **немедленно** отдать а; иначе дойти до последней строки и отдать б».

`верни` часто используют для **раннего выхода**: условие выполнено — отдали ответ и ушли, дальше не выполняем.

### Способ третий: блочное выражение

В Главе 5 говорилось: фигурный блок сам — выражение; его последняя строка (без точки с запятой) — значение блока:

```rust
пусть итог_блока = {
    пусть а = 10;
    пусть б = 20;
    а + б
};
печатай_строку!("Значение блока: {}", итог_блока);
// 预期输出: Значение блока: 30
```

Вывод: `Значение блока: 30`

### ⚠️ Ловушка точки с запятой: самая частая ошибка

Что будет, если к `число * число` **добавить точку с запятой**?

```rust
// 预期错误: E0308
функция квадрат(число: целое) -> целое {
    число * число;    // ❌ лишняя точка с запятой
}
```

Ошибка: **E0308 несоответствие типов: ожидалось `целое`, получено `()`**.

💡 **Метафора**: точка с запятой — как точка в конце предложения: она превращает фразу в «сообщение о сделанном» (сделали — и всё, ничего не осталось). Функция обещала выплюнуть целое, а выплёвывает лишь «сообщение» (пустоту `()`); компилятор, конечно, протестует.

**Считалка**: **хочешь вернуть значение — в последней строке нет точки с запятой.**

## 6.5 Функции можно писать в любом порядке

`главная` может стоять первой, а вызываемая функция — после неё:

```rust
функция главная() {
    печатай_строку!("Площадь: {}", площадь_прямоугольника(3, 4));
}

функция площадь_прямоугольника(длина: целое, ширина: целое) -> целое {
    длина * ширина
}
// 预期输出: Площадь: 12
```

Вывод: `Площадь: 12`

В отличие от `если` и `цикл` из пятой главы — те обязаны появиться до использования, а **функциям порядок безразличен**. Компилятор сначала «перепишет в список» все функции, а потом их можно звать откуда угодно.

## 6.6 Рекурсия: функция вызывает сама себя

📖 **Рекурсия**: функция вызывает сама себя внутри своего тела.

💡 **Метафора**: вы спрашиваете у папы «как решить эту проблему?», папа говорит «спроси дедушку», дедушка — «спроси прадедушку»…询问 доходит до самого старшего, и он сразу даёт ответ; ответ передаётся обратно по цепочке.

Классика: **факториал**. Факториал 5 = 5 × 4 × 3 × 2 × 1 = 120. Закономерность: `факториал(5) = 5 × факториал(4)`, и так далее до `факториал(1) = 1`.

```rust
функция факториал(число: целое) -> целое {
    если число <= 1 {
        верни 1;          // дошли до дна, отдаём ответ сразу
    }
    число * факториал(число - 1)    // ещё не дно — спросим «себя на единицу меньше»
}

функция главная() {
    печатай_строку!("Факториал: {}", факториал(5));
}
// 预期输出: Факториал: 120
```

Вывод: `Факториал: 120`

> ⚠️ **Внимание**: у рекурсии обязано быть **условие остановки** (здесь `число <= 1`). Рекурсия без остановки будет спрашивать вечно, и программа рухнет. Как в истории, где никто не даёт ответа, — вопрос не заканчивается никогда.

> ✨ Если рекурсия пока не ясна — не страшно: цикл (Глава 5) решает большинство задач, а рекурсия — «приём продвинутых», она ещё встретится.

## 6.7 Методы: функции, прикреплённые к типу

Построенные ранее коробочки были «универсальными» — подходили всем. Есть и коробочки **принадлежащие конкретной вещи** — как пульт принадлежит телевизору. Функция, прикреплённая к типу, называется **методом**.

📖 **Метод**: функция, прикреплённая к какому-то типу. Как кнопка, встроенная в игрушку: чтобы нажать, сперва нужна сама игрушка.

**Структуры** (самодельные типы) мы по-настоящему выучим в Главе 10. Здесь одолжим простейшую структуру, чтобы посмотреть на методы:

```rust
структура Табло {
    очки: целое,
    раунды: целое,
}
```

(Чтение: у типа «Табло» два поля данных — очки и раунды.)

### Блок `реализация`

Чтобы прикрепить методы к типу, нужен **`реализация`** («реализовать, снабдить функциями»):

```rust
реализация Табло {
    // ассоциированная функция: без параметра себя — «создать новую»
    функция создать() -> Табло {
        Табло { очки: 0, раунды: 0 }
    }

    // метод: &себя = читаем одалживаем себя
    функция среднее(&себя) -> целое {
        если себя.раунды == 0 {
            верни 0;
        }
        себя.очки / себя.раунды
    }

    // метод: изменяемая_ссылка себя = можно менять себя
    функция запиши_партию(изменяемая_ссылка себя, очки_партии: целое) {
        себя.очки = себя.очки + очки_партии;
        себя.раунды = себя.раунды + 1;
    }
}
```

Появились два новых слова:

📖 **себя**: параметр метода, означающий «сам этот экземпляр». `среднее` — метод табло; `себя` внутри метода — «то самое табло, которое вызвало».

📖 **Ассоциированная функция**: функция внутри блока `реализация`, **без параметра `себя`**. Она не про существующий экземпляр, её обычно зовут **строить новые экземпляры**; потому её зовут ещё **конструктором**.

### Три формы `себя`

| Форма | Смысл | Метафора |
|---|---|---|
| `&себя` | читаемое одалживание: посмотреть, не менять | взять у друга книгу полистать, не писать в ней |
| `изменяемая_ссылка себя` | изменяемое одалживание: можно менять | взять у друга ручку, написать, вернуть |
| `себя` | забрать себе (потребить) | съесть это яблоко — яблока больше нет |

В Главах 7 «Владение» и 8 «Ссылки и заимствование» «заимствование» будет разобрано подробно. Пока запомните: **метод меняет себя — `изменяемая_ссылка себя`; только читает — `&себя`**.

### Вызов метода: точка

```rust
пусть изменяемый лист = Табло::создать();   // ассоциированную функцию зовут двойным двоеточием
лист.запиши_партию(80);                 // метод зовут точкой
лист.запиши_партию(95);
лист.запиши_партию(76);
печатай_строку!("Среднее: {}", лист.среднее());
```

Вывод: `Среднее: 83`

Сравнение двух способов вызова:

| Способ | Пример | Для чего |
|---|---|---|
| `Тип::имя()` | `Табло::создать()` | ассоциированная функция (без `себя`) |
| `экземпляр.имя()` | `лист.среднее()` | метод (первый параметр `себя`, передаётся автоматически) |

> ⚠️ **Осторожно с именами**: называя ассоциированную функцию, **не** берите слова, уже занятые таблицами соответствий (например `новый` — зарезервированное соответствие стандартной библиотеки; определение и вызов могут перевестись по-разному, и получится ошибка «метод не найден»). Самое надёжное — собственное имя (например `создать`). То же с переменными: избегайте `результат` (это слово соответствия типа «результат»).

## 6.8 Пустой тип: не выплёвывает ничего

Функция без `->` на самом деле выплёвывает особое значение: **пусто**, записывается `()`.

📖 **Пусто (юнит-тип)**: тип, не держащий ничего; записывается `()`. Он существует, чтобы «у всех функций было возвращаемое значение»; думать о нём почти не нужно.

```rust
пусть ничего: пусто = ();
печатай_строку!("Пусто: {:?}", ничего);
// 预期输出: Пусто: ()
```

Вывод: `Пусто: ()`

Помните ловушку точки с запятой из 6.4? Ошибка говорила «ожидалось `целое`, получено `()`» — вот это `()` и есть пусто. Теперь вы с ним знакомы.

### Расходящиеся функции и тип «никогда не вернётся» (`!`)

Кроме «пустоты, не выплёвывающей ничего», есть функции постраннее: **расходящиеся** — у них даже само «выплёвывание» не случится, ведь до конца они не доходят, «уходя навсегда».

📖 **Расходящаяся функция**: функция, которая никогда не вернётся обычным путём; тип возвращаемого — `!`. Она либо зациклится, либо запаникует, либо оборвёт программу.

```rust
функция никогда_не_остановлюсь() -> ! {
    цикл {
        печатай_строку!("Я снова здесь!");
    }
}

функция наверняка_пропаду() -> ! {
    паника!("это функция-самоубийца");
}
```

У типа `!` есть волшебное свойство: **он годится вместо любого типа**. Например, если одна рука `матч` возвращает `!`, тип результата всего матча решают остальные руки — компилятор позволяет, ведь рука `!` никогда по-настоящему значения не родит:

```rust
функция опиши(может_быть_значение: опция<целое>) -> строка {
    матч может_быть_значение {
        некоторое(значение) => значение.в_строку_метод(),
        ничто => паника!("здесь значения быть не должно"),   // тип этой руки — ! (никогда не вернётся), годится вместо любого типа
    }
}
```

Типы «уходов заранее» — `паника!`, `задел!`, `верни` — все равны `!`, поэтому могут стоять в любом месте выражения, где требуется какой угодно тип.

💡 **Метафора**: `()` — «отдать получателю пустую коробочку»; `!` — «курьер пропал по дороге» — коробочка никогда не дойдёт, так что не важно, что в ней должно было лежать.

## 6.9 Полный пример: анализатор оценок по трём предметам

Всё, что выучили: обычные функции (параметры, возврат, ранний выход) + методы структуры (ассоциированная функция, `&себя`, `изменяемая_ссылка себя`):

```rust
// ============ Обычные функции ============

// сумма: два параметра, одно возвращаемое
функция сумма(а: целое, б: целое) -> целое {
    а + б
}

// максимум: с ранним верни
функция максимум(а: целое, б: целое) -> целое {
    если а > б {
        верни а;
    }
    б
}

// поприветствуй: без возвращаемого, с циклом из 5-й главы
функция поприветствуй(раз: целое) {
    для _ в 0..раз {
        печатай_строку!("Привет!");
    }
}

// ============ Структура + методы ============

структура Табло {
    очки: целое,
    раунды: целое,
}

реализация Табло {
    // ассоциированная функция: совсем новое табло
    функция создать() -> Табло {
        Табло { очки: 0, раунды: 0 }
    }

    // метод: записать партию (меняем себя, потому изменяемая_ссылка себя)
    функция запиши_партию(изменяемая_ссылка себя, очки_партии: целое) {
        себя.очки = себя.очки + очки_партии;
        себя.раунды = себя.раунды + 1;
    }

    // метод: среднее (только читаем, значит &себя)
    функция среднее(&себя) -> целое {
        если себя.раунды == 0 {
            верни 0;    // партий не было — отдаём 0, чтобы не делить на ноль
        }
        себя.очки / себя.раунды
    }

    // метод: отчёт (метод может звать другие методы)
    функция отчёт(&себя) {
        печатай_строку!("Всего {} партий, очков {}, среднее {}", себя.раунды, себя.очки, себя.среднее());
    }
}

// ============ Главная функция ============

функция главная() {
    печатай_строку!("Сумма: {}", сумма(3, 7));
    печатай_строку!("Больше: {}", максимум(5, 9));
    поприветствуй(2);

    пусть изменяемый лист = Табло::создать();
    лист.запиши_партию(80);
    лист.запиши_партию(95);
    лист.запиши_партию(76);
    лист.отчёт();
    печатай_строку!("Среднее: {}", лист.среднее());

    пусть ничего: пусто = ();
    печатай_строку!("Пусто: {:?}", ничего);
}
// 预期输出: Сумма: 10
// Больше: 9
// Привет!
// Привет!
// Всего 3 партий, очков 251, среднее 83
// Среднее: 83
// Пусто: ()
```

## 6.10 По строкам

- **Строки 4–6**: `сумма` принимает два целых; последняя строка `а + б` без точки с запятой — её значение и возвращается.
- **Строки 9–14**: в `максимум` если `а > б` — `верни а;` и ранний выход; иначе идём дальше и отдаём `б`.
- **Строки 17–21**: у `поприветствуй` нет `->`, возвращается пусто. `для _ в 0..раз`: `_` (подчёркивание) — «переменная цикла не нужна, лень называть».
- **Строки 25–28**: определяем структуру `Табло`, оба поля — целые.
- **Строки 32–34**: ассоциированная функция `создать` без `себя` возвращает новое «0 очков, 0 партий».
- **Строки 37–40**: `запиши_партию` с `изменяемая_ссылка себя` — потому что меняем оба своих поля.
- **Строки 43–48**: `среднее` сперва защищается от деления на ноль (`раунды == 0` — ранний выход с 0), потом целочисленное деление.
- **Строки 51–53**: в `отчёт` вызов `себя.среднее()` — пример **метода, зовущего метод**.
- **Строки 58–60**: вызовы трёх обычных функций.
- **Строка 62**: `пусть изменяемый` — дальше зовём метод с `изменяемая_ссылка себя`, изменяемость обязательна.
- **Строки 63–65**: вызов методов точкой; внутренние данные табло обновляются.
- **Строка 68**: демонстрация пустого типа `()`, печать отладочным форматом `{:?}`.

## 6.12 Частые ошибки и как их исправить

### Ошибка 1: E0308 несоответствие возвращаемого типа

```rust
// 预期错误: E0308
функция удвой(число: целое) -> целое {
    "стало больше"
}
```

Ошибка:

```
Ошибка[E0308]: несоответствие типов: ожидалось `целое`, получено `ссылка_на_строку`
```

**Причина**: обещали целое, а отдали текст. **Решение**: сверить возвращаемое значение с типом после `->`. Обычно два случая: тип написан неверно или точка с запятой лишняя/пропущена (см. следующую ошибку).

### Ошибка 2: забыли убрать точку с запятой (E0308 + `()`)

```rust
// 预期错误: E0308
функция квадрат(число: целое) -> целое {
    число * число;
}
```

Ошибка: `несоответствие типов: ожидалось целое, получено ()`.

**Решение**: удалить точку с запятой в строке возврата. Видите в ошибке `()` — первым делом подозревайте точку с запятой.

### Ошибка 3: у параметра не указан тип

```rust
функция квадрат(число) -> целое {   // ❌ после числа нет «: целое»
```

Ошибка подскажет о пропущенной аннотации типа. **Решение**: в Rust **тип параметра обязателен**, ни один не пропускается: `(число: целое)`.

### Ошибка 4: аргументы не совпали

`сумма(3)` — один аргумент лишний раз не передан; `сумма(3, 7, 9)` — один передан сверх; обе дают ошибку «функция принимает N аргументов». **Решение**: посчитайте параметры в определении и передайте столько же.

### Ошибка 5: деление на ноль не вызывает ошибку?

Если в `среднее` не защищаться от `раунды == 0`, программа **запаникует** при первом же запуске (авария во время выполнения, видели в Главе 3). Целочисленное деление на ноль в Rust — ошибка времени выполнения, компилятор заранее не остановит. **Решение**: перед делением всегда проверяйте делитель на ноль.

### Ошибка 6: метод не найден (столкновение имён)

Назвав свою функцию `новый`, можно получить разнобой «в определении не переведено, при вызове переведено в `new`», и ошибку E0599 «метод не найден у типа». **Решение**: для собственных функций и переменных избегайте слов соответствий (`новый`, `результат` и т. п.) — придумывайте свои.

## 6.13 Словарик главы

| Термин | Значение одной строкой |
|---|---|
| Функция | Поименованный блок инструкций для многократного использования |
| Параметр | Входное имя при определении функции; тип обязателен |
| Аргумент | Значение, реально передаваемое при вызове |
| Возвращаемое значение | Результат, который функция отдаёт после работы |
| Верни | Отдать результат заранее и закончить функцию |
| Выражение | Запись, вычисляющая значение (последняя строка без точки с запятой = возврат) |
| Инструкция | Команда, завершающаяся точкой с запятой; значения не рождает |
| Рекурсия | Функция зовёт себя; обязательно условие остановки |
| Метод | Функция, прикреплённая к типу |
| Реализация | Блок, снабжающий тип методами |
| Себя | Параметр метода, означающий «сам экземпляр» |
| Ассоциированная функция | Функция в блоке реализации без параметра себя; обычно строит экземпляры |
| Конструктор | См. «ассоциированная функция» |
| Пусто (юнит-тип) | Тип, не держащий ничего; записывается () |
| Паника | Аварийный выход при ошибке (во время выполнения) |

> 📖 **Напоминание**: незнакомое слово — загляните в «Общий словарь» в начале книги.

## 6.15 Частые вопросы

**В: Можно ли давать функциям русские имена? Какие ограничения?**

Можно, вся книга так и делает. Советуйте **начинать с глагола** (`сумма`, `печатай`, `проверь`) — сразу ясно, что делает коробочка. Не берите слова из таблиц соответствий (`новый`, `печатай_строку`) — будет столкновение.

**В: Как функции связаны с `матч` и `цикл` из Главы 5?**

`если`, `цикл` — это **управление потоком** (порядок исполнения); функция — **организация кода** (упаковать инструкции и назвать). В теле функции можно свободно пользоваться управлением потоком, и наоборот, из потока можно звать функции. Они — напарники.

**В: Может ли функция вернуть несколько значений?**

Строго — только **одно**. Но несколько значений можно упаковать в **кортеж** (Глава 4) и вернуть вместе: `-> (целое, целое)`. После Главы 10 сможете возвращать и структуру.

**В: `верни` или выражение в последней строке — что лучше?**

Для простых вычислений — выражение в конце (короче); когда нужно **уйти заранее** (условие выполнено — дальше не считаем) — `верни`. Оба способа ходовые.

**В: Что означает `&` в `&себя` метода?**

«Заимствование»: метод лишь **берёт в долг** экземпляр — посмотреть или поправить, а потом возвращает, не съедая. Глава 7 «Владение» и Глава 8 «Ссылки и заимствование» посвятят этому целые две главы. Пока запомните как фиксированную форму.

**В: Что быстрее — рекурсия или цикл?**

В большинстве случаев цикл быстрее и экономнее по памяти. Рекурсия выигрывает изяществом и понятностью (особенно на «многослойных» задачах). На старте важно уметь оба; о производительности не думайте.

**В: Почему в `поприветствуй` переменная цикла — `_`?**

`_` означает «это значение мне не нужно». Цикл повторяет `раз` раз, но «какой это по счёту» — неважно; `_` пропускает именование. Заодно исчезает предупреждение «переменная определена, но не используется».

## Что дальше

Коробочек у вас всё больше. Но у данных в коробочках есть большой вопрос: **кто их хозяин? Кто убирает после использования?**

В **Главе 7 «Владение»** вы встретите самое уникальное правило Rust:

- У каждого значения есть единственный **хозяин** (владелец);
- Хозяин ушёл — значение **убирается** автоматически (освобождается);
- Отдал значение другому — сам **больше не можешь** им пользоваться (перемещение);
- `клонируй` умеет делать независимую копию.

Это самое непохожее на другие языки место Rust и его секретное оружие памяти. До встречи в следующей главе!
