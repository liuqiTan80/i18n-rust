## 3.1 Что такое переменная

### История из жизни: коробочка с ярлыком

Представьте: вы наводите порядок в комнате. Берёте коробочку, наклеиваете ярлык «игрушки» и складываете внутрь игрушки.

Потом, когда игрушки понадобятся, достаточно крикнуть «дай коробочку „игрушки“» — и вы получите её содержимое.

Можно и переклеить ярлык, и заменить содержимое.

**Переменная — это и есть такая коробочка**:

- коробочка → маленький участок памяти компьютера
- ярлык → имя переменной (например `имя`, `возраст`)
- содержимое → значение переменной (например `"Саша"`, `12`)

> 💡 **Метафора**: при работе программа трогает много данных. Данные нельзя сваливать в кучу — их раскладывают по подписанным коробочкам; когда нужно — окликаешь по ярлыку.

### Создаём переменную словом `пусть`

В русском Rust переменная создаётся ключевым словом `пусть`.

> 📖 **`пусть`**: ключевое слово; буквально «пусть такое-то имя означает такое-то значение». Например `пусть возраст = 12` читается «пусть имя „возраст“ означает 12».

```rust
функция главная() {
    пусть возраст = 12;
    печатай_строку!("Мне {} лет", возраст);
}
```

По строкам:

- Строка 1: определяем главную функцию.
- Строка 2: `пусть возраст = 12;` — берём коробочку, клеим ярлык «возраст», кладём внутрь число 12. Точка с запятой в конце — знак окончания инструкции.
- Строка 3: содержимое коробочки «возраст» (12) подставляется в заполнитель `{}`, на экране — «Мне 12 лет».
- Строка 4: главная функция кончается.

Вывод:

```
Мне 12 лет
```

> ⚠️ **Внимание**: `пусть` — это «создать новую коробочку». Поговорим позже об `изменяемый`, и вы увидите: «заменить содержимое старой коробочки» — совсем другая история.

### Знак `=` — это не «равно»

На уроке математики `=` означает «обе стороны равны». В программировании `=` — это **действие**:

> 📖 **Присваивание**: положить значение справа в коробочку слева. Читается «положи … в …».

```rust
пусть балл = 100;
```

Читается: «положи 100 в коробочку по имени „балл“».

Это не вопрос «равен ли балл сотне?», а **приказ**: «положи!»

> ✨ **Подсказка**: для проверки «равно ли» есть другой знак — `==` (двойное равенство); встретимся с ним в Главе 5.

### Коробочек может быть много

```rust
функция главная() {
    пусть имя = "Саша";
    пусть возраст = 12;
    пусть класс = "6 «Б»";
    печатай_строку!("Всем привет, я {}, мне {} лет, из {}", имя, возраст, класс);
}
```

По строкам:

- Строки 2–4: созданы три коробочки — текст, число, текст.
- Строка 5: три `{}` заполняются по порядку: `имя`, `возраст`, `класс`.

Вывод:

```
Всем привет, я Саша, мне 12 лет, из 6 «Б»
```

### Правила имён

Наклеивая ярлык (давая имя), соблюдайте правила:

| Правило | Верно | Неверно | Причина |
|---|---|---|---|
| Нельзя использовать ключевое слово как имя | `пусть балл = 1;` | `пусть пусть = 1;` | `пусть` — зарезервировано |
| Нельзя начинать имя с цифры | `пусть класс_2 = 2;` | `пусть 2класс = 2;` | Имя с цифры будет прочитано как число |
| Можно буквы, цифры, подчёркивание, родной язык | `пусть номер_01 = 1;` | | Всё это законно |

> 📖 **Подчёркивание**: символ `_` на клавиатуре (`Shift` + дефис). Похож на короткую чёрточку, им соединяют слова: `мой_балл`.

> ⚠️ **Внимание**: не называйте переменные словами из таблицы соответствий языкового пакета — например `результат`, `строка`, `тип`. Эти слова заняты другими ролями и вызовут путаницу. Берите конкретные имена: `итог`, `приветствие`, `число_учеников`.

## 3.2 Неизменяемое и изменяемое

### Особое правило Rust: коробочки по умолчанию «под замком»

В Rust переменную после создания **по умолчанию менять нельзя**.

```rust
// 预期错误: E0384
функция главная() {
    пусть балл = 90;
    балл = 100;   // ❌ ошибка!
}
```

`rzc check` сообщит:

```
Ошибка[E0384]: Невозможно дважды присвоить значение неизменяемой переменной `балл`
💡 Если нужно изменить значение переменной, объявите её через `пусть изменяемый`.
```

> 📖 **Неизменяемый**: раз определено — больше не меняется. Rust делает это нарочно; почему — узнаете в следующей главе. Коротко: неизменяемые данные безопаснее, в них меньше путаницы.

### Открываем замок словом `изменяемый`

Если содержимое коробочки действительно нужно менять — при создании добавьте ключевое слово `изменяемый`:

> 📖 **`изменяемый`**: ключевое слово, означает «можно изменять». Ставится после `пусть`: содержимое этой коробочки в будущем можно заменить.

```rust
функция главная() {
    пусть изменяемый балл = 90;
    печатай_строку!("Первая контрольная: {} баллов", балл);
    балл = 100;               // ✅ есть «изменяемый» — можно заменить
    печатай_строку!("Вторая контрольная: {} баллов", балл);
}
```

По строкам:

- Строка 2: создаём коробочку «балл», кладём 90 и объявляем её изменяемой.
- Строка 3: печатаем 90.
- Строка 4: заменяем 90 на 100. Внимание: **при замене `пусть` не пишется** — `пусть` только для создания новой коробочки.
- Строка 5: печатаем 100.

Вывод:

```
Первая контрольная: 90 баллов
Вторая контрольная: 100 баллов
```

> 💡 **Метафора**: `пусть` — купить новую коробочку с замком; `изменяемый` — поставить защёлку, чтобы потом открыть и заменить содержимое; снова написать `пусть` — купить ещё одну новую коробочку.

> ✨ **Подсказка**: когда ставить `изменяемый`? Для данных, меняющихся по ходу работы (счётчики, накопители суммы) — да; для постоянных данных (имя, число пи) — нет.

## 3.3 Константа: коробочка, которую нельзя менять никогда

Есть значения, которые не меняются никогда — например «в году 12 месяцев». Для них есть **константы**:

> 📖 **`константа`**: ключевое слово, «постоянное, неизменное значение». Константу после определения менять нельзя никогда, и её тип нужно указать явно.

```rust
функция главная() {
    константа максимум_учеников: целое = 45;
    печатай_строку!("В классе максимум {} человек", максимум_учеников);
}
```

По строкам:

- Строка 2: `константа максимум_учеников: целое = 45;` — определяем константу, всегда равную 45. `: целое` между именем и `=` — **аннотация типа**, о ней в следующем разделе.
- Строка 3: печать.

> ⚠️ **Внимание**: константа и неизменяемая переменная различаются в трёх пунктах:
> 1. Константе нельзя ставить `изменяемый`, она не меняется никогда.
> 2. У константы обязана быть аннотация типа (`: целое`), переменная может обойтись без неё.
> 3. Константу принято размещать вне функций (доступна всей программе) — увидите в следующем разделе.

## 3.4 Типы: «виды» данных

### Зачем делить на виды

Что можно положить в коробочку, зависит от помеченного вида. Коробочка для чисел не принимает текст — это и есть **тип**.

> 📖 **Тип**: «вид» данных. Как товары в магазине делятся на «продукты», «канцелярию», «игрушки», так данные делятся на числа, текст, истину/ложь и прочее. Тип определяет, какие операции допустимы: числа можно складывать, а текст нельзя «прибавить единицу».

> 📖 **Аннотация типа**: запись `: имя_типа` после имени — явное указание компилятору, какой вид данных лежит в коробочке. Как заранее наклеенный ярлык «яблоки».

Русский Rust переводит типы на русский. Знакомимся по одному.

### Тип первый: целые — числа без точки

> 📖 **Целое**: число без дробной части: 3, −8, 0. Тип целого по умолчанию в русском Rust так и называется — `целое`.

```rust
пусть число_учеников = 45;        // по умолчанию тип «целое»
пусть температура = -8;        // отрицательные тоже можно
```

На самом деле у Rust целое семейство целых типов; различия — «сколько влезает» и «влезает ли отрицательное»:

| Русское имя | Английское оригинал | Диапазон | Особенность |
|---|---|---|---|
| `микро_целое` | i8 | от −128 до 127 | самое маленькое |
| `короткое_целое` | i16 | примерно ±30 тысяч | |
| `целое` | i32 | примерно ±2,1 млрд | **по умолчанию, самое ходовое** |
| `длинное_целое` | i64 | огромный | влезают астрономические числа |
| `натуральное` | u32 | от 0 до ~4,2 млрд | отрицательных нет |

> 📖 **Без знака (натуральное)**: «знак» — это плюс/минус. «Без знака» значит «без минуса» — только 0 и положительные. Выгода: тот же размер вмещает больше положительных значений.

> ✨ **Подсказка**: новичку достаточно помнить `целое`. Буква i в английском имени означает «integer — целое», число после неё — сколько «битов» (маленьких двоичных ячеек) используется. Ячеек больше — влезает больше.

### Тип второй: вещественные — числа с точкой

> 📖 **Вещественное**: число с дробной частью: 3.14, −0.5. Тип по умолчанию — `вещественное` (f в английском имени — от «floating», дробная точка «плавает»).

```rust
пусть число_пи = 3.14;
пусть температура_тела = 36.5;
```

> ⚠️ **Внимание**: целое, делённое на целое, даёт целое — дробная часть **отрезается**:

```rust
пусть итог_деления = 7 / 2;
печатай_строку!("{}", итог_деления);   // покажет 3, а не 3.5!
```

Хотите дробный результат — пусть хотя бы одна сторона вещественное:

```rust
пусть итог_деления = 7.0 / 2.0;
печатай_строку!("{}", итог_деления);   // покажет 3.5
```

> 📖 **Остаток**: знак `%` вычисляет «остаток от деления». 7 % 2 = 1 (7 = 2×3 + 1). Особенно полезен для проверки чётности: делится на 2 без остатка — число чётное.

### Тип третий: логический — только истина и ложь

> 📖 **Логическое**: тип всего с двумя возможными значениями — `истина` или `ложь`, назван в честь математика Буля. Отвечает на вопросы «да или нет».

```rust
пусть уроки_сделаны = истина;
пусть сегодня_дождь = ложь;
```

> 📖 **`истина`** и **`ложь`**: ключевые слова — единственные два значения логического типа, в них нельзя ошибиться ни буквой.

Логические значения засияют в проверках `если` из Главы 5: «**если** сегодня_дождь **есть** `истина` — взять зонт».

### Тип четвёртый: символ — один знак

> 📖 **Символ**: одиночный знак, обрамляется **одинарными** кавычками `'` (не двойными!).

```rust
пусть оценка = 'о';
пусть значок = '★';
```

> ⚠️ **Внимание**: разница символа и строки — `'о'` это один символ, `"отлично"` это строка (цепочка). Одинарные кавычки — один, двойные — цепочка. Строки подробно — в Главе 9.

### Шпаргалка по всем типам

| Русское имя | Английское оригинал | Пример | Как запомнить |
|---|---|---|---|
| `целое` | i32 | `45` | без точки |
| `длинное_целое` | i64 | `9999999999` | большие числа |
| `вещественное` | f64 | `3.14` | с точкой |
| `логическое` | bool | `истина` / `ложь` | да или нет |
| `символ` | char | `'о'` | одинарные кавычки, один знак |
| `строка` | String | `"Привет"` | двойные кавычки, цепочка (Глава 9) |

### Компилятор сам угадывает тип

Вы пишете `пусть возраст = 12;` — без `: целое`, откуда компилятор знает, что это целое?

Он **автоматически выводит тип**: увидел 12 без точки — догадался про `целое`; увидел 3.14 — `вещественное`; увидел кавычки — строку.

> 📖 **Вывод типа**: способность компилятора определять тип по виду значения. Вам легче, ему надёжно. Но аннотацию типа писать можно всегда; написанная — яснее.

## 3.5 Заставим программу считать: операторы

> 📖 **Оператор**: символ, выполняющий операцию. Сложение, вычитание, умножение, деление — всё операторы.

### Пять базовых арифметических операторов

```rust
функция главная() {
    пусть а = 10;
    пусть б = 3;
    печатай_строку!("Сумма: {}", а + б);     // 13
    печатай_строку!("Разность: {}", а - б);   // 7
    печатай_строку!("Произведение: {}", а * б); // 30
    печатай_строку!("Частное: {}", а / б);     // 3 (целочисленное деление, дробь отрезана)
    печатай_строку!("Остаток: {}", а % б);     // 1 (остаток)
}
```

| Знак | Имя | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `10 + 3` | 13 |
| `-` | вычитание | `10 - 3` | 7 |
| `*` | умножение | `10 * 3` | 30 |
| `/` | деление | `10 / 3` | 3 |
| `%` | остаток | `10 % 3` | 1 |

> ⚠️ **Внимание**: оба участника операции должны быть **одного типа**. `целое + вещественное` — ошибка. Нужно смешать — используйте `как` (сейчас расскажем).

### Составное присваивание: короткая запись «изменить себя»

```rust
пусть изменяемый балл = 90;
балл += 5;    // то же, что балл = балл + 5; теперь 95
балл -= 10;   // то же, что балл = балл - 10; теперь 85
балл *= 2;    // 85 × 2 = 170
```

> 📖 **Составное присваивание**: знаки `+=`, `-=`, `*=`, `/=` означают «вычислить с собой и положить обратно». `балл += 5` читается «прибавь к баллу 5 и положи обратно».

### Маленький приём вместо инкремента

В Rust **нет** знака `++`. Прибавить единицу:

```rust
счётчик += 1;
```

### Преобразование типов: `как`

> 📖 **`как`**: ключевое слово, «временно считать значение типом другого вида».

```rust
функция главная() {
    пусть число_учеников = 7;
    пусть число_вещественное = число_учеников как вещественное;   // сначала 7 станет 7.0
    пусть среднее = число_вещественное / 2.0;          // затем делим на 2.0 — получаем 3.5
    печатай_строку!("Среднее: {}", среднее);           // 3.5
}
```

По строкам:

- Строка 2: `число_учеников` — целое 7.
- Строка 3: `число_учеников как вещественное` временно считает 7 значением 7.0 и кладёт в новую коробочку. Старая семёрка не изменилась.
- Строка 4: 7.0 ÷ 2.0 = 3.5.

> ⚠️ **Внимание**: если в операции участвует вещественное, второй операнд тоже пишется с точкой (`2.0`). `число_вещественное / 2` — ошибка: целое и дробное напрямую не делятся.

> ⚠️ **Внимание**: не утрамбовывайте `как` и другие операции в одну строку — например `число_учеников как вещественное / 2`. Порядок, в котором это поймёт компьютер, может не совпасть с вашим. Две строки — надёжнее.

> 💡 **Метафора**: `как` — как маска на балу: целое число надевает «маску вещественного» и временно гостит на его вечеринке; маска снята — оно снова целое.

## 3.6 Полный пример: программа «Карточка ученика»

### Полный код

```rust
// Программа «Карточка ученика»
константа максимальный_балл: целое = 100;

функция главная() {
    // основная информация (неизменяемая, после создания не трогаем)
    пусть имя = "Саша";
    пусть возраст = 12;

    // оценки (математику обновим — только она изменяемая)
    пусть русский = 88;
    пусть изменяемый математика = 95;

    // сначала запишем прежнюю оценку
    печатай_строку!("Математика была: {} баллов", математика);

    // по математике — максимальный балл, обновляем
    математика = максимальный_балл;

    // считаем сумму и среднее
    пусть сумма = русский + математика;
    пусть сумма_вещественное = сумма как вещественное;
    пусть среднее = сумма_вещественное / 2.0;

    // печатаем карточку
    печатай_строку!("====== Карточка ученика ======");
    печатай_строку!("Имя: {}", имя);
    печатай_строку!("Возраст: {}", возраст);
    печатай_строку!("Русский: {} баллов", русский);
    печатай_строку!("Математика: {} баллов", математика);
    печатай_строку!("Сумма: {} баллов", сумма);
    печатай_строку!("Среднее: {}", среднее);
    печатай_строку!("Отлично ли: {}", среднее >= 90.0);
}
```

### По строкам

- Строка 1: комментарий — что делает программа.
- Строка 2: константа `максимальный_балл`, тип `целое`, значение 100. Стоит на самом верхнем уровне, вне функций — доступна всей программе.
- Строки 6–7: две неизменяемые коробочки для имени и возраста — эти данные меняться не будут.
- Строки 10–11: две коробочки для оценок. Русский не изменится — без `изменяемый`; математику сейчас обновим — с `изменяемый`.
- Строка 14: сначала печатаем прежнюю оценку 95. Этот шаг «использует» 95 — поэтому в следующей строке можно спокойно заменить его.
- Строка 17: заменяем `математика` на `максимальный_балл` (100). Без `пусть` — это замена содержимого, а не новая коробочка.
- Строка 20: `русский + математика` = 88 + 100 = 188 — в новую коробочку `сумма`.
- Строка 21: превращаем 188 в 188.0 и кладём в `сумма_вещественное`.
- Строка 22: 188.0 ÷ 2.0 = 94.0. Две строки — чтобы обойти ловушку «длинная строка, компьютер понял порядок иначе».
- Строки 25–32: печатаем карточку построчно. Каждый `{}` заполняется значением соответствующей коробочки.
- Строка 32: `среднее >= 90.0` — сравнение, результат логический: `истина` или `ложь`. `>=` значит «больше или равно», подробности в Главе 5. При сравнении с дробью 90 тоже пишется как 90.0.
- Строка 33: главная функция кончается.

### Вывод

```
Математика была: 95 баллов
====== Карточка ученика ======
Имя: Саша
Возраст: 12
Русский: 88 баллов
Математика: 100 баллов
Сумма: 188 баллов
Среднее: 94
Отлично ли: true
```

> ⚠️ **Внимание**: в последней строке видно `true` — так печатается логическое значение (даже если в коде написано `истина`). На работу программы это не влияет; после Главы 11 вы научитесь оформлять вывод как хотите.

## 3.7 Затенение: новая коробочка с тем же именем накрывает старую

В Rust есть любопытное явление: можно снова написать `пусть` с тем же именем — новая коробочка «накроет» старую:

```rust
функция главная() {
    пусть число = 5;
    пусть число = число + 1;    // новая коробочка накрыла старую, внутри 6
    пусть число = число * 2;    // ещё одна новая, внутри 12
    печатай_строку!("{}", число);   // 12
}
```

> 📖 **Затенение**: когда вы создаёте словом `пусть` переменную с тем же именем, новая переменная затеняет старую — окликнув имя, вы найдёте новую коробочку. Старая никуда не делась, просто «спряталась в тени» — дотянуться нельзя.

> 💡 **Метафора**: как акробатическая пирамида — новая коробочка встала на плечи старой; окликнешь имя — отзовётся верхняя.

Затенение и `изменяемый` — в чём разница:

| | Затенение | Изменяемый |
|---|---|---|
| Запись | Каждый раз пишем `пусть` | Один раз `пусть`, дальше просто присваивание |
| Коробочка | Каждый раз новая | Одна и та же |
| Тип | Можно сменить на совершенно другой | Только значение того же типа |

## 3.8 Частые ошибки и как их исправить

### Ошибка 1: замена значения у неизменяемой переменной

```rust
// 预期错误: E0384
пусть балл = 90;
балл = 100;   // ❌
```

Ошибка: `Ошибка[E0384]: Невозможно дважды присвоить значение неизменяемой переменной`, совет предлагает «объявите через `пусть изменяемый`».

**Исправление**: если менять действительно нужно — добавьте `изменяемый` при создании.

### Ошибка 2: использована несозданная коробочка

```rust
печатай_строку!("{}", рост);   // ❌ «пусть рост = ...» нигде не было
```

Ошибка примерно такая: не найдено ничего по имени `рост`.

**Исправление**: проверьте опечатки; убедитесь, что сначала создание, потом использование.

### Ошибка 3: смешаны разные типы

```rust
// 预期错误: E0277
пусть а = 10;          // целое
пусть б = 3.5;         // вещественное
пусть сумма = а + б;   // ❌ целое и вещественное напрямую не складываются
```

**Исправление**: преобразуйте одну из сторон словом `как`, и **разбейте на две строки**:

```rust
пусть а_вещественное = а как вещественное;
пусть сумма = а_вещественное + б;
```

### Ошибка 4: русская пунктуация в коде

```rust
пусть имя = "Саша"；   // ❌ в конце русская точка с запятой；
```

Ошибка обычно указывает на эту строку: неизвестный символ.

**Исправление**: переключитесь на английскую раскладку и замените `；` на `;`. Запомните заклинание: **скелет кода — английский, внутри кавычек — родной язык**.

## 3.9 Словарик главы

| Слово | Значение |
|---|---|
| Присваивание | Положить значение справа в коробочку слева; знак `=` |
| Логическое | Тип всего с двумя значениями: `истина`/`ложь` |
| Неизменяемый | После создания не меняется; свойство переменных Rust по умолчанию |
| Константа | Значение, которое нельзя менять никогда; слово `константа` |
| Вещественное | Число с точкой; тип по умолчанию `вещественное` |
| Составное присваивание | `+=`, `-=` и прочие — «вычислить и положить обратно» |
| Изменяемый | Ключевое слово, разрешающее заменять содержимое коробочки |
| Тип | Вид данных |
| Аннотация типа | `: имя_типа` после имени |
| Вывод типа | Компилятор сам определяет тип по значению |
| Остаток | Операция `%` — остаток от деления |
| Без знака | Не может быть отрицательным, как `натуральное` |
| Подчёркивание | Символ `_`, годится для имён |
| Оператор | Символ, выполняющий операцию: `+`, `-` |
| Целое | Число без точки; тип по умолчанию `целое` |
| Символ | Одиночный знак в одинарных кавычках |
| Затенение | Новая переменная с тем же именем накрывает старую |
| истина/ложь | Два значения логического типа |
| как | Ключевое слово, временное преобразование типа |

<details>

## 3.11 Частые вопросы

**В1: Почему Rust по умолчанию запрещает менять переменные? В других языках меняют свободно.**

Это безопасностный дизайн Rust. Большинство данных менять не нужно; замок по умолчанию защищает от поломок из-за «случайно изменил». Если менять действительно надо — добавьте `изменяемый`: так «я буду это менять» записано явно.

**В2: `константа` и переменная без `изменяемый` — когда что использовать?**

Значения, неизменные от начала до конца и нужные всей программе (максимальный балл, число пи) — константа; значения внутри одной функции, которые и так не меняются, — обычная переменная.

**В3: Слишком большое число сломает программу?**

Да. `целое` вмещает примерно ±2,1 млрд; больше — ошибка или переполнение. Для больших чисел есть `длинное_целое`: `пусть большое: длинное_целое = 9999999999;`

**В4: `истина` и `"истина"` — одно и то же?**

Нет. `истина` — логическое значение (без кавычек); `"истина"` — строка (в кавычках, просто слово). Как число 5 и слово «пять» — не одно и то же.

**В5: Вывод типа такой умный — можно никогда не писать аннотацию?**

Почти всегда можно. Но у констант она обязательна; к тому же написанная аннотация делает код яснее — лишнее пояснение в сочинении ещё никому не вредило.

**В6: Почему логические значения печатаются как `true`/`false`?**

Таков встроенный способ печати Rust: даже когда в коде пишется `истина`, на экране английское `true`. Хотите полностью русский вывод — в следующих главах будут приёмы форматирования. На логику программы это не влияет.
