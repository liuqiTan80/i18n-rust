# 第七章：引用与借用

上一章我们学了所有权——赋值会转移所有权，函数传参也会。这带来一个问题：如果我们只是想"看看"一个值，不想夺走它怎么办？

答案是**引用**——就像借书，你不需要拥有这本书，只需要知道它在图书馆的哪个位置。

---

## 7.1 生活类比：借书 vs 买书

```
买书（转移所有权）：
  你 → 把钱给书店 → 书店把书给你 → 书是你的了
  代价：花了很多钱（复制数据的开销）

借书（引用）：
  你 → 去图书馆 → 看图书馆里的书 → 书还是图书馆的
  代价：几乎为零（只传一个地址）
```

**为什么引用更高效？** 因为引用就是数据的**地址**。它很小（8 字节），传递很快，而且不转移所有权。就像告诉朋友"书在图书馆三楼 A 区第 5 个架子"——你不需要把整本书搬给他。

---

## 7.2 引用（不可变借用）

**引用**用 **`&`** 创建，表示"借用"一个值，不转移所有权：

**为什么用引用？** 因为上一章我们看到，把字符串传给函数会失去所有权。用引用就可以"只借不送"。

```rust
函数 计算长度(句子: &字符串) -> 整数 {
    句子.长度() 作为 整数
}

函数 主函数() {
    让 句子 = "你好世界".转字符串();
    让 长度 = 计算长度(&句子);  // 传入引用，不转移所有权

    打印行!("'{}' 的长度是 {}", 句子, 长度);  // ✅ 句子 仍然有效
}
```

逐行解释：

- 第 1 行：函数参数 `句子: &字符串`——`&` 表示"我不拥有这个字符串，我只是借用它"
- 第 2 行：通过引用调用方法
- 第 5 行：调用时 `&句子` 表示"把句子的引用传过去"——句子还是我的
- 第 7 行：句子仍然有效——因为只是借出去了，没有送出去

图解：

```
调用前：
句子 ──→ [堆上的字符串 "你好世界"]

调用 计算长度(&句子) 时：
句子 ──→ [堆上的字符串 "你好世界"]  ← 句子仍然拥有数据
         ↑
引用 ──┘  ← 函数只是"看"了一下，没有拿走

调用后：
句子 ──→ [堆上的字符串 "你好世界"]  ← 句子完好无损
```

> **`&` 就是"借用"**——你只是临时使用，用完归还。

---

## 7.3 可变引用

默认引用是**不可变的**——你不能通过引用修改原始值。就像借了图书馆的书，你不能在上面写字。

**为什么默认不可变？** 因为"只看不改"更安全。如果你只需要读数据，就不应该有能力改它。

如果需要修改，用 **`可变引用`**：

```rust
函数 添加后缀(内容: 可变引用 字符串) {
    内容.推入字符串("，世界！");
}

函数 主函数() {
    让 可变 句子 = "你好".转字符串();
    添加后缀(可变引用 句子);  // 传入可变引用——允许修改

    打印行!("{}", 句子);  // 输出：你好，世界！
}
```

逐行解释：

- 第 1 行：参数 `内容: 可变引用 字符串`——表示"我借用了字符串，而且我要修改它"
- 第 2 行：通过可变引用修改原始字符串
- 第 5 行：变量本身需要写成 **`让 可变`**——你得先同意"这个盒子以后可以改"
- 第 6 行：传参时用 **`可变引用 句子`** 表示"我借给你，你可以改"

要点：
- 变量本身需要写成 **`让 可变`**
- 传参时用 **`可变引用`** 表示可变引用
- 函数参数类型是 **`可变引用 字符串`**

## 7.4 借用规则

Rust 有两条严格的借用规则。

**为什么要有这些规则？** 因为它们能防止"数据竞争"——两个代码同时操作同一个数据，导致结果不可预测。

### 规则一：同一时间只能有一个可变引用

```rust
函数 主函数() {
    让 可变 句子 = "你好".转字符串();

    让 引用1 = 可变引用 句子;  // ✅ 第一个可变引用
    // 让 引用2 = 可变引用 句子;  // ❌ 报错！不能同时有两个可变引用

    打印行!("{}", 引用1);
}
```

> **为什么？** 如果两个引用都能修改同一个值，就可能产生**数据竞争**——两个人同时在一本书上做笔记，结果一团糟。

### 规则二：有不可变引用时，不能有可变引用

```rust
函数 主函数() {
    让 句子 = "你好".转字符串();

    让 引用1 = &句子;   // ✅ 不可变引用
    让 引用2 = &句子;   // ✅ 可以有多个不可变引用——多个人同时看，没问题
    // 让 引用3 = 可变引用 句子;  // ❌ 报错！有人在"看"的时候不能"改"

    打印行!("{} {}", 引用1, 引用2);
}
```

> **为什么？** 如果一个人在读书（不可变引用），另一个人在书上做笔记（可变引用），读到的内容可能不一致。

### 总结表

```
┌──────────────────────────────────────────────────┐
│ 组合              │ 允许？ │ 类比                  │
├──────────────────────────────────────────────────┤
│ 多个不可变引用     │ ✅    │ 多个人同时看书         │
│ 一个可变引用       │ ✅    │ 一个人在书上做笔记     │
│ 不可变 + 可变     │ ❌    │ 有人看书，有人做笔记   │
│ 多个可变引用       │ ❌    │ 多人同时做笔记         │
└──────────────────────────────────────────────────┘
```

## 7.5 悬垂引用

Rust 编译器会阻止你创建**悬垂引用**——指向已释放数据的引用。

**为什么悬垂引用很危险？** 就像你拿着一张图书馆的借书条，但那本书已经被销毁了——你拿着条子去找书，什么都找不到。

```rust
// 函数 获取引用() -> &整数 {
//     让 数 = 42;
//     &数  // ❌ 报错！数 在函数结束时被释放，引用变成悬垂
// }
```

图解：

```
函数内：
数 ──→ [42]  ← 数 在栈上
引用 ──┘

函数结束后：
数 被销毁 → [??]  ← 数据没了
引用 ──┘          ← 悬垂引用！指向不存在的数据
```

正确做法是返回值，而不是返回引用：

```rust
函数 获取值() -> 整数 {
    让 数 = 42;
    数  // 返回值，所有权转移——数据跟着值走，不会丢失
}
```

## 7.6 引用的生命周期

引用的**生命周期**从创建开始，到**最后一次使用**结束。

**为什么生命周期重要？** 因为 Rust 需要确保引用在使用期间始终有效。如果引用在用完之前就失效了，就会出问题。

```rust
函数 主函数() {
    让 可变 句子 = "你好".转字符串();

    让 引用1 = &句子;       // 引用1 生命周期开始
    让 引用2 = &句子;       // 引用2 生命周期开始
    打印行!("{} {}", 引用1, 引用2);
    // 引用1, 引用2 到这里不再使用 → 生命周期结束

    让 引用3 = 可变引用 句子;   // ✅ 现在可以有可变引用——因为 引用1、引用2 已经不用了
    引用3.推入字符串("！");
    打印行!("{}", 引用3);
    // 引用3 生命周期结束
}
```

逐行解释：

- 第 4-5 行：创建两个不可变引用
- 第 6 行：使用它们
- 第 7 行：最后一次使用之后，引用1 和 引用2 的生命周期结束
- 第 9 行：现在可以创建可变引用了——因为不可变引用已经"过期"

## 7.7 常见错误

### 错误 1：同时有不可变和可变引用

```rust
让 可变 句子 = "你好".转字符串();
让 引用1 = &句子;
让 引用2 = 可变引用 句子;  // ❌ 引用1 还在使用中
打印行!("{}", 引用1);
```

**修复**：确保不可变引用不再使用后，再创建可变引用。

### 错误 2：通过不可变引用修改

```rust
函数 添加(内容: &字符串) {
    内容.推入字符串("!");  // ❌ 不可变引用不能修改
}
```

**修复**：参数改为 `内容: 可变引用 字符串`。

### 错误 3：返回局部变量的引用

```rust
函数 获取引用() -> &整数 {
    让 数 = 42;
    &数  // ❌ 数 会被销毁
}
```

**修复**：返回值而不是引用 → `数`。

## 7.8 练习题

### 练习 1：用引用传递

修改以下代码，使用引用而不是移动：

```rust
函数 打印文本(内容: 字符串) {
    打印行!("{}", 内容);
}

函数 主函数() {
    让 句子 = "你好".转字符串();
    打印文本(句子);
    打印行!("{}", 句子);  // ❌ 句子已移动
}
```

<details>
<summary>参考答案</summary>

```rust
函数 打印文本(内容: &字符串) {
    打印行!("{}", 内容);
}

函数 主函数() {
    让 句子 = "你好".转字符串();
    打印文本(&句子);
    打印行!("{}", 句子);  // ✅ 句子仍然有效
}
```

</details>

### 练习 2：用可变引用修改

写一个函数 `翻倍(列表: 可变引用 向量<整数>)`，把向量中每个元素乘以 2。

<details>
<summary>参考答案</summary>

```rust
函数 翻倍(列表: 可变引用 向量<整数>) {
    对于 编号 在 0..列表.长度() {
        列表[编号] = 列表[编号] * 2;
    }
}

函数 主函数() {
    让 可变 数据 = 向量![1, 2, 3, 4, 5];
    翻倍(可变引用 数据);
    打印行!("{:?}", 数据);  // [2, 4, 6, 8, 10]
}
```

</details>

## 本章小结

1. **`&`** 创建不可变借用，不转移所有权
2. **`可变引用`** 创建可变借用，可以修改原始值
3. 同一时间：要么多个不可变引用，要么一个可变引用，**不能混合**
4. Rust 编译器阻止**悬垂引用**——指向已释放数据的引用
5. 引用的生命周期从创建到**最后一次使用**结束
