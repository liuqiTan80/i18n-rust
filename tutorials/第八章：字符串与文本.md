# 第八章：字符串与文本

在 Rust 中，"字符串"比你想象的要复杂。其他语言可能只有一种字符串类型，但 Rust 有两种：**`字符串`**（`String`）和**`文本`**（`&str`，也叫字符串切片）。

**为什么有两种？** 因为它们用途不同。一种可以修改，一种不能修改但更轻量。

---

## 8.1 两种字符串类型

### 生活类比

```
文本（&str）—— 像一张照片
  → 你拍了一张照片，不能修改照片里的内容
  → 只能看，不能改

字符串（String）—— 像一块画板
  → 你可以在画板上画画、修改
  → 但画板需要占地方（堆内存）
```

**为什么要区分？** 因为很多时候你只需要"看"文字，不需要改它。用照片（`文本`）比用画板（`字符串`）更省资源。

### `文本`（`&str`）—— 只能看不能改

`文本` 是对一段已有字符串的**引用**。它不能修改，只能"看"。

```rust
函数 主函数() {
    让 问候 = "你好世界";  // 这是 &str（字符串字面量）
    打印行!("{}", 问候);
}
```

逐行解释：

- 第 2 行：直接写在代码里的文字叫**字面量**——它被硬编码到程序中，不可修改。就像刻在石头上的字

### `字符串`（`String`）—— 可以修改的字符串

`字符串` 是存储在堆上的、可以修改的字符串：

```rust
函数 主函数() {
    让 可变 s = 字符串::新建();  // 创建空字符串（在堆上）
    s.推入字符串("你好");          // 添加内容
    s.推入字符串("世界");          // 再添加

    打印行!("{}", s);  // 你好世界
}
```

逐行解释：

- 第 2 行：`字符串::新建()` 创建一个空的可修改字符串
- 第 3 行：`.推入字符串()` 在末尾添加文字
- 第 4 行：再添加"世界"——现在 s 变成了"你好世界"

## 8.2 创建字符串

**为什么要学多种创建方式？** 因为不同场景需要不同的创建方法。

```rust
函数 主函数() {
    // 方式一：从字面量创建
    让 s1 = "你好".转字符串();

    // 方式二：使用构造函数——创建空字符串
    让 s2 = 字符串::新建();

    // 方式三：从格式化创建——把变量拼成字符串
    让 名字 = "小明";
    让 s3 = 格式化!("你好，{}", 名字);

    打印行!("s1 = {}", s1);
    打印行!("s2 = '{}'", s2);
    打印行!("s3 = {}", s3);
}
```

逐行解释：

- 第 3 行：把"你好"这个字面量转换成可修改的 `字符串`
- 第 6 行：创建一个空的 `字符串`
- 第 9-10 行：`格式化!` 把变量嵌入到文字模板中，生成新的字符串

## 8.3 字符串操作

### 追加内容

**为什么需要追加？** 因为你经常需要逐步构建一个字符串——比如拼接用户输入。

```rust
函数 主函数() {
    让 可变 s = "你好".转字符串();

    s.推入字符串("世界");     // 在末尾追加一段文字
    s.推('！');            // 在末尾追加一个字符

    打印行!("{}", s);  // 你好世界！
}
```

逐行解释：

- 第 2 行：创建可修改的字符串
- 第 4 行：在末尾追加"世界"
- 第 5 行：在末尾追加单个字符'！'

### 拼接字符串

```rust
函数 主函数() {
    让 s1 = "你好".转字符串();
    让 s2 = "世界".转字符串();

    让 s3 = s1 + &s2;  // 拼接（注意：s1 被移动了）

    打印行!("{}", s3);  // 你好世界
    // 打印行!("{}", s1);  // ❌ s1 已经无效
    打印行!("{}", s2);  // ✅ s2 仍然有效
}
```

逐行解释：

- 第 5 行：`+` 把 s1 和 s2 拼接在一起。但 s1 被"消耗"了——它的所有权转移给了 s3
- 第 7 行：s1 已经无效了
- 第 8 行：s2 仍然有效——因为 `+` 只消耗左边的

> **注意**：`+` 操作符会"消耗"左边的字符串。如果想保留两者，用 `格式化!`。

### 使用格式化拼接

```rust
函数 主函数() {
    让 s1 = "你好".转字符串();
    让 s2 = "世界".转字符串();

    让 s3 = 格式化!("{}{}", s1, s2);  // 不消耗 s1 和 s2

    打印行!("s1 = {}", s1);  // ✅ 仍然有效
    打印行!("s2 = {}", s2);  // ✅ 仍然有效
    打印行!("s3 = {}", s3);
}
```

> **为什么推荐 `格式化!`？** 因为它不会消耗任何变量，而且可以同时拼接多个字符串。

### 替换与查找

```rust
函数 主函数() {
    让 s = "我喜欢猫，猫很可爱".转字符串();

    让 替换后 = s.替换("猫", "狗");
    打印行!("{}", 替换后);  // 我喜欢狗，狗很可爱

    打印行!("包含'猫'：{}", s.包含("猫"));  // 真
    打印行!("长度：{}", s.长度());  // 字节长度
}
```

逐行解释：

- 第 4 行：`.替换()` 把所有"猫"替换成"狗"，生成新字符串
- 第 6 行：`.包含()` 检查字符串中是否包含某段文字
- 第 7 行：`.长度()` 返回字节数（不是字符数）

## 8.4 遍历字符串

Rust 的字符串是 UTF-8 编码的，所以不能直接用索引访问字符。

**为什么不能直接用索引？** 因为中文字符占 3 个字节，英文占 1 个字节。如果按"第几个字节"来找，可能找到一个字符的中间——那就没有意义了。

### 遍历字符

```rust
函数 主函数() {
    让 s = "你好Rust";

    对于 c 在 s.逐字符() {
        打印!("{} ", c);
    }
    打印行!();
    // 输出：你 好 R u s t
}
```

逐行解释：

- 第 4 行：`.逐字符()` 把字符串拆成一个一个字符，逐个遍历

### 遍历行

```rust
函数 主函数() {
    让 文本 = "第一行\n第二行\n第三行";

    对于 行 在 文本.逐行() {
        打印行!("> {}", 行);
    }
}
```

## 8.5 UTF-8 编码

Rust 的字符串是 UTF-8 编码的。这意味着：

- 英文字符占 **1 个字节**
- 中文字符占 **3 个字节**
- emoji 占 **4 个字节**

**为什么这很重要？** 因为如果你用 `.长度()` 获取的是字节数，不是字符数。要获取字符数，需要用 `.逐字符().计数()`。

```rust
函数 主函数() {
    让 英文 = "hello";
    让 中文 = "你好";

    打印行!("英文字节数：{}", 英文.长度());  // 5
    打印行!("中文字节数：{}", 中文.长度());  // 6（每个汉字 3 字节）

    打印行!("英文字符数：{}", 英文.逐字符().计数());  // 5
    打印行!("中文字符数：{}", 中文.逐字符().计数());  // 2
}
```

## 8.6 字符串切片

你可以用切片获取字符串的一部分：

```rust
函数 主函数() {
    让 s = "你好世界".转字符串();

    // 注意：切片按字节索引，不是字符索引
    让 切片 = &s[0..6];  // 前 6 个字节 = 前 2 个中文字符
    打印行!("{}", 切片);  // 你好
}
```

> **警告**：如果切片的字节边界不在字符边界上，程序会崩溃。所以对于中文，建议用 `.逐字符()` 遍历。

## 8.7 常见错误

### 错误 1：用索引访问中文字符

```rust
让 s = "你好";
打印行!("{}", s[0]);  // ❌ 不能直接用索引访问字符
```

**修复**：用 `.逐字符()` → `s.逐字符().第0个()`

### 错误 2：切片边界不在字符边界

```rust
让 s = "你好";
让 切片 = &s[0..2];  // ❌ 2 不是字符边界（中文占 3 字节）
```

**修复**：用字符遍历代替字节切片。

### 错误 3：拼接后使用已移动的字符串

```rust
让 s1 = "你好".转字符串();
让 s2 = "世界".转字符串();
让 s3 = s1 + &s2;
打印行!("{}", s1);  // ❌ s1 已被移动
```

**修复**：用 `格式化!` → `格式化!("{}{}", s1, s2)`

## 8.8 `字符串` vs `文本`

什么时候用哪个？

| 特性 | `字符串`（String） | `文本`（&str） |
|------|-------------------|----------------|
| 可以修改 | ✅ | ❌ |
| 存储在 | 堆上 | 任意位置 |
| 拥有数据 | ✅ 拥有 | ❌ 借用 |
| 性能 | 需要分配内存 | 零成本引用 |

**经验法则**：
- 函数参数尽量用 **`&文本`**（`&str`）—— 更灵活，`String` 和 `&str` 都能传入
- 需要修改或存储字符串时用 **`字符串`**（`String`）

```rust
// ✅ 推荐：参数用 &文本
函数 打招呼(名字: &文本) {
    打印行!("你好，{}！", 名字);
}

函数 主函数() {
    让 s = "小明".转字符串();
    打招呼(&s);       // String 可以当 &str 用
    打招呼("小红");    // &str 直接用
}
```

## 本章小结

1. **`字符串`**（`String`）：可修改、存储在堆上、拥有数据
2. **`文本`**（`&str`）：不可修改、引用、零成本
3. 用 `.推入字符串()` 追加，用 `+` 或 `格式化!` 拼接
4. 用 `.逐字符()` 遍历字符，用 `.逐行()` 遍历行
5. Rust 字符串是 UTF-8 编码，中文占 3 字节
6. 函数参数推荐用 `&文本`（`&str`）
