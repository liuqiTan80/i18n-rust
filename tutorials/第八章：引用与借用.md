# 第八章：引用与借用

## 8.0 学习目标

读完这一章，你将能够：

1. 解释**引用**和**借用**的关系（一个是东西，一个是动作）；
2. 用 **`&`** 做只读借用，用 **`&mut`** 做可变借用；
3. 说出借用铁律："**要么一个可变，要么多个只读**"；
4. 看懂 **E0502**（借用冲突）和 **E0596**（无法借用为可变）并修复；
5. 用 **`*`** 解引用，从借据取出原值；
6. 知道"借用的有效期到最后一次使用为止"。

---

## 8.1 上章留下的难题

第七章说过：字符串传进函数就**搬家**了，原变量失效。可很多时候我们只想让函数**看一眼**，不想把东西送人：

```rust
函数 展示(句子: 字符串) {   // 传值：句子搬进来，用完销毁
    打印行!("{}", 句子);
}

函数 主函数() {
    让 问候 = 字符串::从("你好");
    展示(问候);
    // 问候 没了，想再用？没门
}
```

看一眼就把原件收走，这也太霸道了。现实世界的解法是——**借**。

## 8.2 引用：一张借据

💡 **比喻**：同学想看你的课外书。你不会把书的所有权**过户**给他，而是说"借你看"。他手里拿的其实是**借书凭证**——凭它能找到书，但书的主人还是你。

📖 **引用（Reference）**：指向某个值的"借据"，写作 `&值`。`&` 读作"取引用"。引用不是值本身，它只记录"值在哪儿"。
📖 **借用（Borrowing）**：用引用临时使用别人数据的**动作**。借了要还——引用不改变所有权。

### 只读借用

```rust
// 参数类型 &字符串：借来看看
函数 展示(句子: &字符串) {
    打印行!("{}", 句子);
}

函数 主函数() {
    让 问候 = 字符串::从("你好");
    展示(&问候);     // 递出借据
    展示(&问候);     // 再借一次也行
    打印行!("还在：{}", 问候);   // 原件完好
}
```

输出：

```
你好
你好
还在：你好
```

`&问候` 制造一张借据递给函数。函数看完，借据作废，`问候` 依然是主人。想借几次借几次。

## 8.3 可变借用：借来改一改

有时不光想看，还想**改**。比如给书的空白处加批注。这需要**可变借用** `&mut`：

```rust
函数 加批注(书: &mut 字符串, 批注: 字符串引用) {
    书.推入字符串(批注);   // 推入字符串 = push_str，往末尾加文字
}

函数 主函数() {
    让 可变 书 = 字符串::从("三国演义");
    加批注(&mut 书, "（青少版）");
    打印行!("{}", 书);
}
```

输出：`三国演义（青少版）`

两个新要求：

| 要求 | 写法 | 原因 |
|---|---|---|
| 被借的值必须声明为可变 | `让 可变 书 = ...` | 不可变的東西不能借出去改 |
| 借出时写 `&mut` | `加批注(&mut 书, ...)` | 明示"这次是可变借用" |

> 📖 **推入字符串（push_str）**：字符串的方法，把一段文字追加到末尾。类似的还有 `推入`（push，追加一个字符）。

## 8.4 借用铁律：二选一

Rust 对借用有一条铁律：

> **同一时刻，要么有任意多个只读借用，要么有一个可变借用。两者不能同时存在。**

💡 **比喻**：图书馆的规矩——
- **只读借用** = 几个人同时**在阅览室里看书**，可以有很多读者，没问题；
- **可变借用** = 有人要把书拿去**重新装订**，这时必须独占，谁也不许看。
- 两件事**不能同时发生**：别人正看着呢，你把书抽走重订，读者手里的页码就全乱了。

违反铁律会报 **E0502**：

```rust
让 可变 口号 = 字符串::从("加油");
让 看一眼 = &口号;        // 只读借用生效
让 改一下 = &mut 口号;    // ❌ 同时可变借用
```

真实报错：

```
错误[E0502]: 无法借用 `口号` 为可变，因为它同时也被不可变借用
📌 变量 `口号` 在第 4 行被借用，第 6 行仍在被使用。
💡 Rust 不允许同时存在可变借用和不可变借用。尝试缩小不可变借用的作用范围。
```

### 为什么这么严？

假设允许"一边读一边改"：函数 A 正拿着借据读字符串，函数 B 突然往里加字，字符串在仓库里可能要**换更大的房间**（重新分配内存）——A 手里的借据瞬间指向一间**已经搬空**的房间。程序崩溃。铁律把这种事故在编译期就掐死。

### 先后借用没问题

铁律管的是"**同时**"。前一个借用用完了，下一个再来，完全合法：

```rust
让 可变 书 = 字符串::从("三国演义");
展示(&书);                    // 第一次只读借用，用完作废
加批注(&mut 书, "（青少版）"); // 可变借用，用完作废
展示(&书);                    // 又一次只读借用，没问题
```

### 借用的"有效期"

借用的有效期 = **从诞生到最后一次被使用**。用完了，铁律就不再管它：

```rust
让 可变 口号 = 字符串::从("加油");
让 看一眼 = &口号;
打印行!("{}", 看一眼);    // 看一眼 最后一次使用
// 到这里 看一眼 的有效期结束
让 改一下 = &mut 口号;    // ✅ 没问题：只读借用已经过期
改一下.推入('!');
```

> ✨ 这是编译器聪明的一面：它不看你把借据"存在"了多久，只看你**实际用到哪里**。

## 8.5 只读借用上不能改：E0596

参数声明成 `&字符串`（只读），却想在函数里修改，会报 **E0596**：

```rust
函数 乱改(书: &字符串) {
    书.推入('!');    // ❌
}
```

真实报错：

```
错误[E0596]: 无法借用为可变
💡 只有可变变量才能被可变借用（`&mut`）。
```

**解决**：要改就把参数改成 `&mut 字符串`，并保证调用方的变量是 `让 可变`。

## 8.6 解引用：从借据取出原值

📖 **解引用（Dereference）**：从引用取出它指向的值，符号 `*`。

```rust
让 分数 = 95;
让 借据 = &分数;
让 抄一份 = *借据;      // * 顺着借据找到原值，抄出来
打印行!("抄出来的值：{}", 抄一份);
```

输出：`抄出来的值：95`

`&` 是"写借据"，`*` 是"凭借据取东西"，方向相反。

> ✨ 日常写代码很少手动解引用——调用方法时编译器会自动顺藤摸瓜（`(&书).长度()` 直接写成 `书.长度()` 就行）。了解 `*` 的存在，看懂报错就够了。

## 8.7 引用能借整数吗

能。引用和复制不冲突：

```rust
让 分数 = 95;
让 借据 = &分数;
打印行!("借据指向：{}", 借据);
打印行!("原值还在：{}", 分数);   // 整数本来就会复制，安然无恙
```

只是整数本身又小又复制，直接传值就好，很少需要借。引用真正大显身手的是**字符串、向量、结构体**这些"大件"。

## 8.8 完整示例：图书馆借书系统

把只读借用、可变借用、多借用、先后借用全串起来：

```rust
// 只读借用：看看就还
函数 展示(书: &字符串) {
    打印行!("书的内容：{}", 书);
}

// 可变借用：修改后归还
函数 加批注(书: &mut 字符串, 批注: 字符串引用) {
    书.推入字符串(批注);
}

// 两个只读借用同时存在：没问题
函数 比较长短(甲: &字符串, 乙: &字符串) {
    如果 甲.长度() > 乙.长度() {
        打印行!("甲更长");
    } 否则 {
        打印行!("乙不短");
    }
}

函数 主函数() {
    让 可变 书 = 字符串::从("三国演义");
    展示(&书);                       // 只读借用
    加批注(&mut 书, "（青少版）");    // 可变借用
    展示(&书);                       // 只读借用

    让 另一本 = 字符串::从("西游记");
    比较长短(&书, &另一本);           // 两个只读借用并行

    打印行!("原书还在：{}", 书);
}
```

## 8.9 逐行解释

- **第 2–4 行**：`展示` 接收 `&字符串`——只借不拿。调用后原件不动。
- **第 7–9 行**：`加批注` 接收 `&mut 字符串`，`推入字符串` 在末尾追加文字。
- **第 12–18 行**：`比较长短` 同时持有两个只读借用——铁律允许"多个只读并行"。`长度()` 返回**字节数**（中文一字占 3 字节，"三国演义"是 12 字节）。
- **第 21 行**：`让 可变`——后面要可变借用，必须声明可变。
- **第 22–24 行**：三次借用**先后**发生，每次用完即止，互不冲突。
- **第 26 行**：两本"书"同时被只读借用。
- **第 28 行**：所有借都还完了，原书完好，还能打印。

## 8.10 运行结果

```
书的内容：三国演义
书的内容：三国演义（青少版）
甲更长
原书还在：三国演义（青少版）
```

"三国演义（青少版）"比"西游记"字节多，所以"甲更长"。

## 8.11 常见错误与解决

### 错误一：E0502 借用冲突（可变 + 只读同时）

```
错误[E0502]: 无法借用 `口号` 为可变，因为它同时也被不可变借用
```

**解决**：让两种借用**错开**——先把只读借用的事办完（用掉它），再开始可变借用；或者干脆克隆一份改副本。

### 错误二：E0596 只读借用上想修改

```
错误[E0596]: 无法借用为可变
```

**解决**：三处同时检查——① 原变量是 `让 可变` 吗；② 调用处写的是 `&mut` 吗；③ 函数参数类型是 `&mut 类型` 吗。少一处都不行。

### 错误三：忘记 `让 可变`

对不可变变量写 `&mut 甲`，同样报 E0596。**解决**：声明处加 `可变`。

### 错误四：引用比自己活得久

```rust
让 借据;
{
    让 临时 = 字符串::从("短命");
    借据 = &临时;
}
打印行!("{}", 借据);   // ❌ 临时已经没了，借据成了空头支票
```

报错提示"临时值过早被释放"。**解决**：借据的有效期不能超过原值。让原值活得比借据久。

> 📖 **悬垂引用**：指向已消失数据的引用。Rust 在编译期就禁止它出现——这是引用安全的核心保证。

## 8.12 本章术语表

| 术语 | 一句话解释 |
|---|---|
| 引用 | 指向值的"借据"，写作 `&值` |
| 借用 | 用引用临时使用别人数据，不改变所有权 |
| 只读借用 | `&值`，可以同时有很多个 |
| 可变借用 | `&mut 值`，同一时刻只能有一个 |
| 借用铁律 | 要么多个只读，要么一个可变，不可同时 |
| 解引用 | 用 `*` 从引用取出原值 |
| E0502 | 可变借用与只读借用冲突的错误码 |
| E0596 | 想可变借用却借不到的错误码 |
| 悬垂引用 | 指向已消失数据的引用（Rust 编译期禁止） |
| 推入字符串 | 往字符串末尾追加文字的方法，英文 push_str |

> 📖 **提醒**：遇到不懂的词，随时回查全书开头的《总术语表》。

### 练习二：可变借用

写函数 `翻倍话(话: &mut 字符串)`，把字符串末尾再追加一遍自己（提示：先克隆再推入，否则会遇到自己借自己的冲突）。

<details>
<summary>🔍 查看答案</summary>

```rust
函数 翻倍话(话: &mut 字符串) {
    让 副本 = 话.克隆();
    话.推入字符串(&副本);
}

函数 主函数() {
    让 可变 口号 = 字符串::从("加油");
    翻倍话(&mut 口号);
    打印行!("{}", 口号);
}
```

输出：`加油加油`

（直接写 `话.推入字符串(话)` 会借用冲突：一边可变借用着 `话`，一边又读它。克隆一份再追加就避开了。）

下面哪些行能编译通过？

```rust
让 可变 笔记 = 字符串::从("数学");
让 甲 = &笔记;
让 乙 = &笔记;
让 丙 = &mut 笔记;
```

<details>
<summary>🔍 查看答案</summary>

</details>

## 8.14 常见问题（FAQ）

**问：`&字符串` 和第七章提到的 `字符串引用`（`&文本`）是一回事吗？**

答：像兄弟但不完全相同。`&字符串` 是"对 String 的引用"；`字符串引用`（&str）是"对一段文字本身的借用"。字符串字面量 `"你好"` 就是 `字符串引用`。两者都能"只读看文字"，方法大多通用。第九章会讲清它们的区别和转换。

**问：为什么不能有两个可变借用？**

答：两个都声称"我要改"，改的顺序不同结果就不同，数据就乱套了。只留一个可变借用，谁改的、改了什么，一清二楚。

**问：借用的检查会增加运行速度负担吗？**

答：不会。全部在编译期完成，运行时零开销。这就是 Rust 的"零成本安全"。

**问：我总把借用规则搞混，有速记法吗？**

答：记住一句话：**"读可以群读，写必须独写，读写不同席。"**

**问：函数参数到底该用传值还是借用？**

答：经验法则——**只看用 `&`，要改用 `&mut`，真要拿走才传值**。整数等小东西直接传值也无所谓（复制很便宜）。

**问：方法调用的 `&自我`、`&mut 自我` 和这章的 `&`、`&mut` 是一回事吗？**

答：完全是一回事。第六章方法里的 `&自我` 就是"这个方法只读借用实例"，`&mut 自我` 就是"可变借用实例"。现在你应该彻底看懂了。
