# 第 4 章：複合型

この二章では、すべての箱がちょうど一つのものを入れていました。この章では **まとめて包む** ことを学びます——いくつかのものを一つの荷物に入れるのです。

---

## 4.0 この章の目標

この章を終えると、あなたは次のことができるようになります：

1. **タプル** でいくつかの *違う* ものを一緒に包み、また解体して取り出せる。
2. **配列** に同じ種類のデータを一列にしまい、番号で好きな要素を取り出せる。
3. 配列の全体をコピーせずに、一部だけを **スライス** して借りられる。
4. 「数え始めは 0 から」なぜかを説明し、もうつまずかない。

---

## 4.1 なぜ包むのか

### 生活の物語：転校生のフォルダ

新しい学校に転校することを想像してください。学校は一つの箱を渡すのではなく、一つの **フォルダ** を渡します：名前、年齢、成績…… 多くの違う用紙が、一つの袋にまとめられ、どこへでも持ち運べます。

プログラミングも同じです。一人の生徒の情報にはいくつかの部分があります：

- 名前（文字）
- 年齢（数値）
- 寮に住むか（真か偽か）

それぞれ別の箱ではすぐに散らかります。より良い方法は **包む** ことです。

この章の三つの包み方：

| 方法 | たとえ | 向いているもの |
|---|---|---|
| タプル | 贈り物箱 | いくつかの **違う** ものを一束に |
| 配列 | ロッカーが並んだ廊下 | **同じ種類** のものが並んだ一列、個数は固定 |
| スライス | 窓 | ロッカー列を動かさず、その一部だけを見る |

---

## 4.2 タプル：一つの贈り物箱、いくつかの違うもの

### タプルを作る

いくつかのものを括弧で囲み、カンマで区切る——それがタプルです：

```rust
宣言 学生 = ("花子", 12, 真);
```

一つずつ：

- `("花子", 12, 真)`：三つのもの——文字、数値、ブール値——を入れた贈り物箱。違う種類が混ざっていてもまったく問題ありません；それこそがタプルの役割です。
- 三つのものがタプルの **要素**（「メンバー」）です。このタプルは要素が 3 つ。

> 📖 **タプル**：いくつかの値を一つの組に包む複合型（「トゥープル」と読みます）。要素は種類が違っても構いません。

### 中身を取り出す：数え始めは 0

一つの要素を取り出すには、タプル名の後ろに `.数字` と書きます：

```rust
関数 主関数() {
    宣言 学生 = ("花子", 12, 真);
    表示行!("一つ目：{}", 学生.0);
    表示行!("二つ目：{}", 学生.1);
    表示行!("三つ目：{}", 学生.2);
}
```

見えるはずのもの：

```
一つ目：花子
二つ目：12
三つ目：真
```

> ⚠️ **注意**：**数え始めは 0 で、1 ではない！** 一つ目の要素の番号は 0、二つ目は 1、三つ目は 2 です。

これはプログラミング全体のルールです。なぜかは次節の配列で説明します——とりあえず覚えて：「位置を数えるとき、一番目の番号は『0』」。

> 📖 **添字（インデックス）**：この「番号」の正式な名前——物を探すときの住所。本書では両方の言葉を同じ意味で使います。

### タプルごと一度に解体する

三つ全部が欲しい？ 一度に解体します：

```rust
関数 主関数() {
    宣言 学生 = ("花子", 12, 真);
    宣言 (名前, 年齢, 寮) = 学生;
    表示行!("{} は {} 歳です", 名前, 年齢);
    表示行!("寮か？ {}", 寮);
}
```

一行ずつ：

- 3 行目：`宣言 (名前, 年齢, 寮) = 学生;` —— `=` の左側にも括弧の形があり、「荷物を三つに分けよ」を意味します。コンピュータは位置で合わせます：1 番目は `名前` へ、2 番目は `年齢` へ、3 番目は `寮` へ。
- 解体後、三つの名前はそれぞれ独立した箱になります。

> 📖 **解体（デストラクチャリング）**：包まれたデータを形でばらばらに分け、一つずつ取り出すこと。結び目を解いて部品を広げるようなもの。

> 💡 **たとえ**：解体は配達を開封するようなもの——包みの中に三つ、用意した籠も三つ、一度に仕分け完了。

見えるはずのもの：

```
花子 は 12 歳です
寮か？ 真
```

### タプル全体を印刷：`{:?}`

タプル全部を一度に印刷するには、プレースホルダは `{:?}` です（中括弧の中にコロンと疑問符）：

```rust
関数 主関数() {
    宣言 学生 = ("花子", 12, 真);
    表示行!("タプル全体：{:?}", 学生);
}
```

見えるはずのもの：

```
タプル全体：("花子", 12, 真)
```

> 📖 **デバッグ印刷**：`{:?}` は「デバッグ用」の印刷——物の内部構造をそのまま（引用符も括弧も全部）表示します。普通の `{}` は人間向けにきれいに印刷します。デバッグ印刷の全体話は第 10 章。

> ⚠️ **注意**：タプルを普通の `{}` で印刷するとエラーです。タプルは `{:?}` を使わねばなりません。

## 4.3 配列：番号付きロッカーが並んだ一列

### 配列を作る

学校のロッカーが並んだ廊下を想像してください——すべて同じ大きさで、同じ種類のもの（例えば点数）専用。それが **配列** です。

配列は **角括弧** で作り、要素をカンマで区切ります：

```rust
宣言 得点 = [88, 95, 76, 90, 82];
```

この配列は一週間の点数を入れ——要素は全部で 5 つ。

> 📖 **配列**：**長さ固定** で、**同じ種類** のデータが並んだ一列。角括弧 `[ ]` が配列の印です。

> ⚠️ **注意**：角括弧 `[ ]` と丸括弧 `( )` を混同しないで——角は配列（同じ種類が並ぶ）、丸はタプル（違うものがいくつか）。

### 繰り返し値の短縮記法

すべてのロッカーに同じものが入るなら、省略法があります：

```rust
宣言 五つの零 = [0; 5];
```

> 📖 「0 を 5 回繰り返す」と読みます：セミコロンの前が内容、後ろが回数。`[0, 0, 0, 0, 0]` と同じ。

```rust
表示行!("{:?}", 五つの零);   // [0, 0, 0, 0, 0]
```

### 添字でロッカーを取り出す：数え始めは 0

```rust
関数 主関数() {
    宣言 得点 = [88, 95, 76, 90, 82];
    表示行!("一日目：{}", 得点[0]);
    表示行!("三日目：{}", 得点[2]);
    表示行!("最終日：{}", 得点[4]);
}
```

見えるはずのもの：

```
一日目：88
三日目：76
最終日：82
```

図にすると一番分かりやすい：

```
ロッカー:  [ 88 ]  [ 95 ]  [ 76 ]  [ 90 ]  [ 82 ]
添字:        0       1       2       3       4
```

ロッカーは 5 つだが、添字は 0 から 4 まで。N 番目の添字は N-1 です。

### なぜ 0 から始めるか

自分に納得できる理由を一つ：

添字とは「**始まりから何歩目か**」です。

- 1 番目のロッカー：始まりから **0** 歩 → 添字 0。
- 2 番目： **1** 歩 → 添字 1。
- 5 番目： **4** 歩 → 添字 4。

> 💡 **たとえ**：身長を測るようなもの——物差しの「0 目盛り」は床に置く。最初の 1 センチの目盛りは 0 であり 1 ではない。添字は「始点からの距離」なのです。

### 二つの日常的な配列技

**技その一：`.長さ()` —— ロッカーを数える**

```rust
表示行!("全日数：{}", 得点.長さ());   // 全日数：5
```

> 📖 **`.長さ()`**：要素数を返すメソッド。ドットの後ろにメソッド、括弧は空のまま。「メソッド」とは何かは第 6 章で説明——とりあえず `.長さ()` を決まり文句として扱ってください。

**技その二：`.含む()` —— その値が入っているか**

```rust
表示行!("95 はある？ {}", 得点.含む(参照 95));   // 95 はある？ 真
```

> 📖 **`.含む()`**：配列がその値を含むかを調べ、ブール値を返すメソッド。とりあえず `参照 95` をそのまま写して——`参照` は「借用」の印、詳しくは第 8 章。今は「含むには参照が要る」とだけ。

### 範囲外：存在しないロッカーに手を伸ばすと末は悪い

配列にはロッカーが 5 つ（添字 0〜4）。6 番を強要すると：

```rust
// 预期行为: 运行失败
関数 主関数() {
    宣言 得点 = [88, 95, 76, 90, 82];
    表示行!("{}", 得点[5]);   // ❌ 範囲外！
}
```

Rust は即座に **パニック** します——プログラムはその場で止まります。

> 📖 **パニック**：プログラムが回復不可能なエラーに遭うと、「何かおかしい！」と叫んで即座に止まること。壊れたまま動くことは決してない。火災報知器のよう——皆が手を止めて避難する。第 16 章で扱います。

パニックのメッセージはこうです：

```
thread 'main' panicked at ...:
index out of bounds: the len is 5 but the index is 5
```

訳すと：「添字が範囲外：長さは 5 だが、求めたのは 5 番。」（合法な最大番号は 4 だ！）

> ✨ **ヒント**：**定数** で範囲外の番号を直接書くと（例 `得点[5]`）、コンパイラが「この操作は実行時にパニックする」とコンパイル時に止めてくれます——プログラムは実行すらされません。番号が外から来てコンパイル時に分からないときだけ、本当のパニックが実行時に起きます。いずれにせよ、Rust は間違ったデータをこっそり読ませることは決してありません。
>
> ⚠️ **注意**：`rzc check` は翻訳とチェックだけ——これを捕捉できません。見るには実際にプログラムを動かしてください。

> 📖 **添字範囲外（インデックスアウトオブバウンズ）**：範囲を超えた番号に触れること。原文は "index out of bounds"——文字通り「境界の外」。

## 4.4 スライス：配列への窓

### ロッカー列全体を動かさず、少しだけ覗きたい？

例えば最初の三日分の点数だけが欲しい。新しい配列にコピーするのは無駄です。 **スライス** は賢い：コピーせず、元の列の一部を「指し示す」だけです。

> 📖 **スライス**：配列内の **連続する要素の一列への参照**——文字通り "slice"：ソーセージを切り取るが、ソーセージ本体はそのまま。

配列の後ろに `[始め..終わり]` を書き、その前に `参照` を付けます：

```rust
関数 主関数() {
    宣言 得点 = [88, 95, 76, 90, 82];
    宣言 前三日 = 参照 得点[0..3];
    表示行!("最初の三日：{:?}", 前三日);
    表示行!("スライス長：{}", 前三日.長さ());
}
```

見えるはずのもの：

```
最初の三日：[88, 95, 76]
スライス長：3
```

`参照 得点[0..3]` 一つずつ：

| 部分 | 意味 |
|---|---|
| `参照` | 借用（元を取らない——第 8 章） |
| `得点` | スライスする配列 |
| `[0..3]` | 添字 0 から **3 の手前まで**——即ち 0, 1, 2 |

> ⚠️ **注意**：`0..3` は「**頭を含み、尻尾を除く**」——0 を含み、3 を除く。数えてみ：ちょうど 3 要素。この規則は本書全体で通用します。

> 📖 **範囲（レンジ）**：`始め..終わり` の形を範囲と呼びます——「ここからあそこまで」。

### 短い形

```rust
宣言 始めから三番目まで = 参照 得点[..3];    // 始め省略 = 0 から
宣言 三番目から終わりまで = 参照 得点[2..];  // 終わり省略 = 最後まで
宣言 すべて = 参照 得点[..];              // 両方省略 = 全体
```

```rust
表示行!("{:?} {:?} {:?}", 始めから三番目まで, 三番目から終わりまで, すべて);
// [88, 95, 76] [76, 90, 82] [88, 95, 76, 90, 82]
```

### 文字列もスライスできる

文字列もスライスできます（詳細は第 9 章——ここでは初対面）：

```rust
宣言 挨拶 = 参照 "こんにちは"[0..6];
表示行!("{}", 挨拶);   // こん
```

> ⚠️ **注意**：`0..6` であって `0..2` ではありません——一つの日本語の文字はコンピュータの中で 3 つの「バイト」（小さな記憶枡）を占めるので、「こん」は 6 枡です。バイトとは何かは第 9 章。とりあえず `0..6` を写してください。

## 4.5 総合例：一週間の得点管理

### 全体のコード

```rust
関数 主関数() {
    // 一週間の得点（月〜金）
    宣言 週得点 = [88, 95, 76, 90, 82];

    // 一週間を前半と後半に切る
    宣言 前半 = 参照 週得点[0..2];
    宣言 後半 = 参照 週得点[2..5];

    表示行!("一週間の得点：{:?}", 週得点);
    表示行!("全日数：{}", 週得点.長さ());
    表示行!("最初の二日：{:?}", 前半);
    表示行!("最後の三日：{:?}", 後半);

    // 合計を手動で足す
    宣言 合計 = 週得点[0] + 週得点[1] + 週得点[2] + 週得点[3] + 週得点[4];
    宣言 浮動の合計 = 合計 として 浮動小数点数;
    宣言 平均 = 浮動の合計 / 5.0;
    表示行!("合計：{}、平均：{}", 合計, 平均);

    // 生徒情報をタプルに包む
    宣言 学生 = ("花子", 12, 真);
    宣言 (名前, 年齢, 寮) = 学生;
    表示行!("{} は {} 歳、寮：{}", 名前, 年齢, 寮);
    表示行!("タプルの二つ目：{}", 学生.1);
}
```

### 一行ずつ

- 3 行目：五日分の得点配列を作る。角括弧 = 配列。
- 6 行目：添字 0 と 1 をスライス（頭入り尻尾抜き）。
- 7 行目：添字 2, 3, 4 をスライス——残りの三日ちょうど。
- 9 行目：`{:?}` が配列全体を括弧付きでデバッグ印刷。
- 10 行目：`.長さ()` は 5。
- 11〜12 行目：二つのスライスを印刷。
- 15 行目：五要素を手動で足す = 431。（第 5 章の繰り返しのあと一行になり、五つ書かなくて済む。）
- 16 行目：浮動小数点数に変換（二行、第 3 章の `として` 優先順位の罠を避ける）。
- 17 行目：431.0 ÷ 5.0 = 86.2。
- 20 行目：三要素タプルを作る：文字、数値、ブール値、混ぜて可。
- 21 行目：解体——三つの名前、一つずつ位置で。
- 22 行目：解体した三箱を使って印刷。
- 23 行目：`.1` でタプルの二つ目を直接取り出し（0 から数え、`.1` は二つ目：12）。

### 見えるはずのもの

```
一週間の得点：[88, 95, 76, 90, 82]
全日数：5
最初の二日：[88, 95]
最後の三日：[76, 90, 82]
合計：431、平均：86.2
花子 は 12 歳、寮：真
タプルの二つ目：12
```

## 4.6 よくある失敗と直し方

### 失敗一：添字が範囲外

要素 5 つ、最大添字 4。`得点[5]` は範囲外です。

**直し方**：合法な最大添字は常に `.長さ() - 1`。不安ならまず `.長さ()` を印刷。

### 失敗二：1 から数える

一番目が欲しくて `得点[1]` と書くと二つ目が来ます。

**直し方**：合言葉——「**一番目は 0**」。

### 失敗三：タプルに角括弧

```rust
// 预期错误: E0608
宣言 学生 = ("花子", 12, 真);
表示行!("{}", 学生[0]);   // ❌ タプルは角括弧を使わない
```

**直し方**：タプルは **ドット** を使います：`学生.0`。角括弧は配列用。合言葉：**タプルはドット、配列は角括弧**。

### 失敗四：`.含む()` に `参照` がない

```rust
得点.含む(95)    // ❌ エラー
得点.含む(参照 95)   // ✅ 正しい
```

**直し方**：`参照` を写す——理由は第 8 章。

### 失敗五：配列に種類を混ぜる

```rust
// 预期错误: E0308
宣言 混在 = [1, "二", 3];   // ❌ 配列は一種類
```

**直し方**：混ぜたいならタプル `(1, "二", 3)` を使う；配列は一種類だけ。

### おまけ実験：本物のパニックを見る（任意）

この例は「環境変数」などあとの概念を使います——各行に注釈があるので、追って本物のパニックを見られます：

```rust
使用 標準ライブラリ::環境::環境変数;

関数 主関数() {
    宣言 得点 = [88, 95, 76];
    // コンピュータの環境変数から INDEX という値を読む
    // （プログラム外部から渡されたメッセージ）
    宣言 本文 = 環境変数("INDEX").期待("INDEX 変数を設定してください");
    // 両端の空白を取る
    宣言 綺麗 = 本文.トリム();
    // 文字を数値に変える。無符号機械整数は「数えるための整数」
    宣言 添字: 無符号機械整数 = 綺麗.解析().期待("数値が必要です");
    表示行!("得点：{}", 得点[添字]);
}
```

Linux / macOS で（わざと範囲外の INDEX=5 を設定）：

```bash
INDEX=5 rzc run
```

本物のパニックが見えます：

```
thread 'main' panicked at ...:
index out of bounds: the len is 3 but the index is 5
```

合法な番号なら：

```bash
INDEX=1 rzc run
```

出力：`得点：95`。

> ✨ **ヒント**：Windows PowerShell では、実行前に `$env:INDEX="5"` で変数を設定。ここで使った `環境::変数`、`.トリム()`、`.解析()`、`.期待()` はいずれもあとの章でちゃんと紹介されます——この実験はパニックの姿を早めに見るだけです。

## 4.8 練習問題

> 💪 まず自分で試してから、答えを覗いてください。

### 練習一：タプルに会う

### 練習三：配列から取り出す

七日分の配列 `気温`：`[22, 25, 27, 24, 23, 26, 28]` を作り、一日目、四日目、最終日と、配列の長さを印刷。

<details>
<summary>🔍 参考解答</summary>

```rust
関数 主関数() {
    宣言 気温 = [22, 25, 27, 24, 23, 26, 28];

    表示行!("四日目：{}", 気温[3]);
```

最終日の添字は 6 であり 7 ではないことに注意——要素 7 つなら添字は 0 から 6。

### 練習四：スライス

練習三の配列から、「週末」（最後の二日）と「平日」（最初の五日）をスライスし、両方印刷。

<details>
<summary>🔍 参考解答</summary>

```rust
関数 主関数() {
    宣言 気温 = [22, 25, 27, 24, 23, 26, 28];
    宣言 平日 = 参照 気温[0..5];
    宣言 週末 = 参照 気温[5..7];
    表示行!("平日：{:?}", 平日);
    表示行!("週末：{:?}", 週末);

```

週末は `参照 気温[5..]` とも書けます（終わり省略 = 最後まで）。

</details>

### 練習五（発展）：バグを見つける

このコードを実行するとどうなる？ どう直す？

```rust
関数 主関数() {
    宣言 三数 = [1, 2, 3];
    表示行!("{}", 三数[3]);
}
```

<details>
<summary>🔍 参考解答</summary>

配列は要素 3 つ；最大添字は 2。`三数[3]` は範囲外。固定された数なので、コンパイラが「この操作は実行時にパニックする」と構築時に遮断します。`三数[2]` に直して 3 を得てください。

</details>

## 4.9 よくある質問

**Q1：タプルか配列か——どちらを使う？**

中身を見てください。いくつかの **違う種類** の情報を一つに（名前＋年齢＋フラグ）→ タプル。 **同じ種類** のデータが並ぶ（五日分の点数）→ 配列。

**Q2：なぜ 0 から数えるのは不自然なの？**

添字は文字通り「始まりから何歩目か」だからです。一番目の要素は 0 歩なので 0。主流の言語（Rust、C、Java、Python…）はすべてそう——慣れれば頭入り尻尾抜きの範囲記法も自然になります。

**Q3：配列の長さは設定後に変わる？**

いいえ。配列の長さは固定。伸びる「箱」が欲しければ、それが **ベクタ**——第 15 章の主役です。

**Q4：`{:?}` の `?` は何？**

`?` は「デバッグ形式」の印。`{}` はきれいな人間向け、`{:?}` は技術者が調べる全体構造。その仕組みは第 10 章。

**Q5：スライスの `参照` は本当に必要？**

はい。スライスは元の配列から「借用」し、`参照` がその印。省略するとエラー。詳しくは第 8 章。

**Q6：`[0..3]` に 3 は含まれる？**

いいえ。頭入り尻尾抜き：0, 1, 2 を含む。3 も含めたければ `[0..4]`。合言葉：**終点はいつも一つ短い**。

## この章のまとめ

1. **タプル**：丸括弧、種類は違ってよく、`.0`/`.1` で取り出し、解体でばらばらに。
2. **配列**：角括弧、一種類、長さ固定、添字は 0 から。
3. **スライス**：`参照 配列[始め..終わり]`、頭入り尻尾抜き、動かさず借用。
4. `.長さ()` は数え、`{:?}` はデバッグ印刷、範囲外はいつも末は悪い——そして Rust はいつもそれを捕捉する。
