# 日本語チュートリアル（日本語方言コード付き）

rzc チュートリアルの日本語版。**コードはすべて日本語方言で書かれています** —
`関数 主関数() { 表示行!("こんにちは、世界！"); }` のように、日本語話者が
自分の言葉で Rust を書けるのがこのプロジェクトの中核です。

## 翻訳原則

- **コードは読者の母語で**: 各コードブロックは ja 言語パックの対応表に基づく
  日本語キーワード（`関数`/`宣言`/`可変`/`表示行!`/`もし`/`マッチ`…）で書かれ、
  説明文も日本語の技術書として自然な文体で再執筆しています（直訳ではありません）。
- **全コードブロックが検証済み**: `tools/verify-tutorials.py --dir tutorials/ja
  --lang ja` が各コードブロックを一時プロジェクトで実際にコンパイルし、
  壊れたサンプルは CI で遮断されます。
- マーカーコメント（`// 预期输出:` など）は検証ツール側の約束事のため
  中国語のまま残しています（学習者の読書体験には影響しません）。
