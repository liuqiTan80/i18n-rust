# 第 3 章：変数と型

前の章では、プログラムに「話す」こと（文字を表示すること）を教えました。この章では、「覚える」ことと「計算する」ことを教えます。

---

## 3.0 この章の目標

この章を終えると、あなたは次のことができるようになります：

1. `宣言` で変数を作り、変数とは何かを説明できる。
2. Rust の変数が既定で変更できない理由と、`可変` でどう解錠するかを説明できる。
3. 四つの基本型——整数・浮動小数点数・ブール値・文字——を、それぞれの例とともに挙げられる。
4. コードで足し算・引き算・掛け算・割り算ができる。

---

## 3.1 変数とは何か

### 生活の物語：ラベルを貼った箱

部屋の片付けを想像してください。箱を一つ取り、「おもちゃ」と書いたラベルを貼り、中におもちゃを入れます。

あとでおもちゃが欲しくなったら、「『おもちゃ』の箱を渡して」と言えば、そこにあります。

ラベルを剥がして新しいのを貼り替えたり、中身を別のものと取り替えたりもできます。

**変数とは、まさにその箱**です：

- 箱 → コンピュータの中の小さな記憶場所
- ラベル → 変数の名前（例：`名前` や `年齢`）
- 中身 → 変数の値（例：`"花子"` や `12`）

> 💡 **たとえ**：動いているプログラムは多くのデータを使います。データをあちこちに散らかしてはいけません——ラベルを貼った箱に入れ、必要なときにラベルを呼べば出てきます。

### `宣言` で変数を作る

Rust では、キーワード `宣言` で変数を作ります。

> 📖 **`宣言`**：文字通り「この名前がこの値を表すようにする」という意味のキーワード。`宣言 年齢 = 12;` は「『年齢』という名前が 12 を表すようにせよ」と読みます。

```rust
関数 主関数() {
    宣言 年齢 = 12;
    表示行!("私は {} 歳です", 年齢);
}
```

一行ずつ：

- 1 行目：主関数を定義。
- 2 行目：`宣言 年齢 = 12;` —— 箱を取り、「年齢」とラベルを貼り、中に数値 12 を入れる。セミコロンで指示を終える。
- 3 行目：`{}` の穴に「年齢」箱の中身（12）を入れる——画面に「私は 12 歳です」と出る。
- 4 行目：主関数の終わり。

見えるはずのもの：

```
私は 12 歳です
```

> ⚠️ **注意**：`宣言` は「新しい箱を作る」という意味です。あとで `可変` に出会いますが、「古い箱の中身を取り替える」のとは別のことです。

### `=` は「等しい」ではない

数学の授業では、`=` は「両辺が等しい」を意味します。プログラミングでは、`=` は **動作** です：

> 📖 **代入**：右側の値を左側の箱に入れること。「……を……に入れよ」と読みます。

```rust
宣言 点数 = 100;
```

「点数という箱に 100 を入れよ」と読みます。

「点数は 100 と等しいか？」とは問いません——**命令** です：「入れろ！」

> ✨ **ヒント**：「等しいか？」を問うには別の記号 `==`（等号二つ）を使います——制御フローの第 5 章で出てきます。

### 一つのプログラムに箱はいくつでも

```rust
関数 主関数() {
    宣言 名前 = "花子";
    宣言 年齢 = 12;
    宣言 組 = "6 年 2 組";
    表示行!("皆さんこんにちは、私は {}、{} 歳で、{} の者です", 名前, 年齢, 組);
}
```

一行ずつ：

- 2〜4 行目：三つの箱を作る——文字、数値、文字をそれぞれ持つ。
- 5 行目：三つの `{}` に `名前`、`年齢`、`組` が順に入る。

見えるはずのもの：

```
皆さんこんにちは、私は 花子、12 歳で、6 年 2 組 の者です
```

### 変数名の規則

箱にラベルを貼る（名前を付ける）には、いくつか規則があります：

| 規則 | 正しい | 間違い | 理由 |
|---|---|---|---|
| 予約語を名前にしない | `宣言 点数 = 1;` | `宣言 宣言 = 1;` | `宣言` は予約語 |
| 数字で始めない | `宣言 組_2 = 2;` | `宣言 2組 = 2;` | 先頭の数字は数値と読まれる |
| 文字・数字・下線は可 | `宣言 出席番号_01 = 1;` | | すべて合法 |

> 📖 **下線（アンダースコア）**：キーボードの `_` 記号（`Shift` ＋ マイナスキー）。短い横線のように見え、単語をつなぐことが多い（`私の点数` のように）。

> ⚠️ **注意**：`文字列型` や `オプション` のようなく標準ライブラリの言葉を変数名にしてはいけません——それらの型には別の役割があり、混乱を招きます。具体的な名前が一番安全です：`合計点`、`挨拶`、`人数`。

## 3.2 不変と可変

### Rust の特別な規則：箱は既定で錠が掛かっている

Rust では、変数を作ったら **既定では変更できません**。

```rust
// 预期错误: E0384
関数 主関数() {
    宣言 点数 = 90;
    点数 = 100;   // ❌ エラー！
}
```

`rzc check` の報告：

```
エラー[E0384]: 不変変数 `点数` に二度代入できません
```

> 📖 **不変（イミュータブル）**：一度決めると変えられない。Rust はこれを意図的に行います——理由は第 8 章で説明します。要するに、変わらないデータの方が安全で、驚きが少ないのです。

### `可変` で解錠する

本当に箱の中身を取り替えたいなら、作るときにキーワード `可変` を付けます：

> 📖 **`可変`（ミュータブル）**：「変更可能」という意味のキーワード。`宣言` の後ろに置き、この箱の中身はあとで取り替えてよいと宣言します。

```rust
関数 主関数() {
    宣言 可変 点数 = 90;
    表示行!("一回目の試験：{}", 点数);
    点数 = 100;               // ✅ 可変なら取り替え可
    表示行!("二回目の試験：{}", 点数);
}
```

一行ずつ：

- 2 行目：「点数」箱を作り 90 を入れ、変更可能と宣言。
- 3 行目：90 を表示。
- 4 行目：90 を 100 に取り替え。注意：**取り替えるときは `宣言` を書かない**——`宣言` は新しい箱を作るだけだから。
- 5 行目：100 を表示。

見えるはずのもの：

```
一回目の試験：90
二回目の試験：100
```

> 💡 **たとえ**：`宣言` は新しい箱を買って錠を掛ける；`可変` は箱に留め金を付け、あとで開けられるようにする；もう一度 `宣言` すると、また別の新しい箱を買う。

> ✨ **ヒント**：いつ `可変` を使うべき？ 実行中に変わるデータ（カウンタ、得点の累計）には使います。変わらないデータ（名前、円周率）には使いません。

## 3.3 定数：決して変わらない箱

「一年は 12 か月」のように、決して変わらない値があります——それが **定数** です：

> 📖 **`定数`（コンスタント）**：「永久に変わらない値」という意味のキーワード。一度定義したら決して変わらず、その型を書き出さねばなりません。

```rust
関数 主関数() {
    定数 上限: 整数 = 45;
    表示行!("このクラスは最大 {} 人までです", 上限);
}
```

一行ずつ：

- 2 行目：`定数 上限: 整数 = 45;` —— 永久に 45 である定数を定義。`上限` と `=` の間の `: 整数` は **型注釈** です——次節で説明します（定数は慣習的にすべて大文字で命名します）。
- 3 行目：表示。

> ⚠️ **注意**：定数と不変変数は三つの点で異なります：
> 1. 定数は `可変` を取れない——決して変わらない。
> 2. 定数は型注釈（`: 整数`）が必須；変数は不要。
> 3. 定数は慣習的に関数の外（プログラム全体が使える場所）に置く——次節の例ですぐ見られます。

## 3.4 型：データの「種類」

### なぜ種類が重要か

箱が何を入れられるかは、そこに書かれた種類によります。数値用の箱に文字は入りません——それが **型** です。

> 📖 **型**：データの「種類」。「食料」「文房具」「おもちゃ」とラベルされたスーパーの棚のように、データにも種類があります——数値、文字、真偽。型がそのデータにできる操作を決めます：数値は足せるが、文字は「プラス 1」できません。

> 📖 **型注釈**：名前の後ろに `: 型名` と書き、コンパイラに箱がどの種類のデータか正確に教えること——あらかじめ箱に「りんご」とラベルを貼るようなもの。

Rust の型は名前がそのまま英語です。一つずつ会いましょう。

### 型その一：整数——小数点のない数

> 📖 **整数**：小数点以下のない数、例えば 3、-8、0。Rust の既定の整数型は `整数`（i32）です。

```rust
宣言 数 = 45;        // 既定で 整数
宣言 温度 = -8;  // 負の数も可
```

実は Rust の整数には「大きさ」と「負の数を許すか」で違う種類がそろっています：

| 名前 | 範囲 | 備考 |
|---|---|---|
| `微整数` | -128 から 127 | 最小 |
| `短整数` | 約 ±33,000 | |
| `整数` | 約 ±21 億 | **既定、最もよく使う** |
| `長整数` | 天文学的に大きい | 巨大な数を保持 |
| `無符号整数` | 0 から約 42 億 | 負の数は不可 |

> 📖 **符号なし（アンサインド）**：「符号」とはプラスマイナスです。符号なしとは「符号がない」——0 と正の数だけ。利点：同じ枠でより大きな正の数が入る。

> ✨ **ヒント**：初心者は `整数` だけ覚えれば十分。「i」は integer（整数）、数字はそれを記憶するビット（小さな二分の箱）の数。箱が多いほど大きな数。

### 型その二：浮動小数点——小数点のある数

> 📖 **浮動小数点**：小数点のある数、例えば 3.14 や -0.5。既定の型は `浮動小数点数`（f64）です（「f」は float、「浮動」する小数点）。

```rust
宣言 円周率 = 3.14;
宣言 体温 = 36.5;
```

> ⚠️ **注意**：整数同士の割り算はやはり整数——小数点以下は **切り捨て** られます：

```rust
宣言 商 = 7 / 2;
表示行!("{}", 商);   // 3.5 ではなく 3 が出る！
```

小数の結果が欲しいなら、少なくとも片方が浮動小数点数でなければなりません：

```rust
宣言 商 = 7.0 / 2.0;
表示行!("{}", 商);   // 3.5 が出る
```

> 📖 **剰余**：`%` 記号は「割り算の余り」を計算します。7 % 2 = 1（7 ÷ 2 は 3 余り 1）。奇数・偶数の判定に便利：余り 0 は偶数。

### 型その三：ブール値——真と偽だけ

> 📖 **ブール値**：ちょうど二つの値しか取れない型——`真` か `偽` か——数学者ブールにちなんで名付けられました。Yes/No の問いに答えます。

```rust
宣言 宿題完了 = 真;
宣言 今日雨 = 偽;
```

> 📖 **`真`** と **`偽`**：キーワード——ブール値の取る唯二つの値。一文字も狂いは許されません。

ブール値は第 5 章の `もし` 判定で輝きます：「**もし** 今日雨 **が** `真` **なら**、傘をさす」。

### 型その四：文字——一つの文字

> 📖 **文字**：一つの文字記号、**一重引用符** `'` で囲む（二重引用符ではない）。

```rust
宣言 評価 = 'A';
宣言 記号 = '★';
```

> ⚠️ **注意**：文字と文字列——`'A'` は一文字（一つの文字）；`"優秀"` は文字列（文字の列）。一重引用符は一つ、二重引用符は列を入れます。文字列は独立した章——第 9 章——で扱います。

### 型の家族を一望

| 名前 | 例 | 覚え方 |
|---|---|---|
| `整数` | `45` | 小数点なし |
| `長整数` | `9999999999` | 大きな数 |
| `浮動小数点数` | `3.14` | 小数点あり |
| `ブール` | `真` / `偽` | はいかいいえか |
| `文字` | `'A'` | 一重引用符、一文字 |
| `文字列型` | `"こんにちは"` | 二重引用符、文字の列（第 9 章） |

### コンパイラが型を推測してくれる

`宣言 年齢 = 12;` と書いても `: 整数` と書きませんでした——コンパイラはどうやって整数と分かるのでしょう？

コンパイラが **推論** するからです：小数点のない 12 を見て `整数` と推測し、3.14 なら `浮動小数点数`、引用符なら文字列と推測します。

> 📖 **型推論**：コンパイラが値の形から型を判断する力。あなたの打鍵が減り、なお信頼できます。でも注釈を書いても構いません——分かりやすくなります。

## 3.5 プログラムに計算させる：演算子

> 📖 **演算子**：操作を行う記号。`+`、`-`、`*`、`/` はすべて演算子です。

### 五つの基本演算子

```rust
関数 主関数() {
    宣言 値1 = 10;
    宣言 値2 = 3;
    表示行!("和：{}", 値1 + 値2);         // 13
    表示行!("差：{}", 値1 - 値2);  // 7
    表示行!("積：{}", 値1 * 値2);  // 30
    表示行!("商：{}", 値1 / 値2);  // 3（整数割り算、小数切り捨て）
    表示行!("余り：{}", 値1 % 値2);   // 1（剰余）
}
```

| 記号 | 名前 | 例 | 結果 |
|---|---|---|---|
| `+` | 足し算 | `10 + 3` | 13 |
| `-` | 引き算 | `10 - 3` | 7 |
| `*` | 掛け算 | `10 * 3` | 30 |
| `/` | 割り算 | `10 / 3` | 3 |
| `%` | 剰余 | `10 % 3` | 1 |

> ⚠️ **注意**：演算する二つの数は **同じ型** でなければなりません。`整数 + 浮動小数点数` はエラーになります。混ぜるときは `として` で変換します（すぐ下）。

### 複合代入：自分を変える短縮記法

```rust
宣言 可変 点数 = 90;
点数 += 5;    // 点数 = 点数 + 5 と同じ——95 に
点数 -= 10;   // 点数 = 点数 - 10 と同じ——85 に
点数 *= 2;    // 85 × 2 = 170
```

> 📖 **複合代入**：`+=`、`-=`、`*=`、`/=` は「自分で演算し、結果を戻す」を意味します。`点数 += 5` は「点数に 5 を足して戻せ」と読みます。

### 小さな技：`++` はない

Rust に `++` 演算子は **ありません**。1 を足すにはこう書きます：

```rust
カウンタ += 1;
```

### 型変換：`として`

> 📖 **`として`（as）**：値を一時的に「別の型として」扱うキーワード。

```rust
関数 主関数() {
    宣言 数 = 7;
    宣言 浮動の数 = 数 として 浮動小数点数;   // まず 7 を 7.0 に
    宣言 平均 = 浮動の数 / 2.0;  // それから 2.0 で割る → 3.5
    表示行!("平均：{}", 平均);    // 3.5
}
```

一行ずつ：

- 2 行目：`数` は整数の 7。
- 3 行目：`数 として 浮動小数点数` は 7 を一時的に 7.0 として扱い、新しい箱に入れる。元の 7 はそのまま。
- 4 行目：7.0 ÷ 2.0 = 3.5。

> ⚠️ **注意**：浮動小数点数が演算に加わるとき、もう一方も浮動小数点数で書かねばなりません（例：`2.0`）。`浮動の数 / 2` はエラー——整数と小数は直接割れません。

> ⚠️ **注意**：`として` を長い行に無理に押し込んではいけません（例：`数 として 浮動小数点数 / 2`）——コンピュータはあなたの予想と違う順序で読むかもしれません。二行に分けるのが一番安全。

> 💡 **たとえ**：`として` は仮面を付けるようなもの——整数が「浮動小数点数の仮面」を付けて小数たちの宴に出る；仮面を外せば同じ整数のまま。

## 3.6 総合例：生徒情報カード

### 全体のコード

```rust
// 生徒情報カード プログラム
定数 満点: 整数 = 100;

関数 主関数() {
    // 基本情報（不変、作ったら変えない）
    宣言 名前 = "花子";
    宣言 年齢 = 12;

    // 成績（数学はあとで更新するので、数学だけに「可変」）
    宣言 国語 = 88;
    宣言 可変 数学 = 95;

    // 元の数学の点数を一度記録
    表示行!("数学（元）：{}", 数学);

    // 数学が満点だったので更新
    数学 = 満点;

    // 合計と平均を計算
    宣言 合計 = 国語 + 数学;
    宣言 浮動の合計 = 合計 として 浮動小数点数;
    宣言 平均 = 浮動の合計 / 2.0;

    // カードを表示
    表示行!("====== 生徒情報カード ======");
    表示行!("名前：{}", 名前);
    表示行!("年齢：{}", 年齢);
    表示行!("国語：{} 点", 国語);
    表示行!("数学：{} 点", 数学);
    表示行!("合計：{} 点", 合計);
    表示行!("平均：{}", 平均);
    表示行!("優秀：{}", 平均 >= 90.0);
}
```

### 一行ずつ

- 2 行目：定数 `満点` を `整数` 注釈で値 100 に定義。関数の外、プログラム全体が使える場所に置く。
- 6〜7 行目：名前と年齢の二つの不変箱——この情報は変わらない。
- 10〜11 行目：成績の二つの箱。`国語` は変わらないので `可変` なし；`数学` は更新するので `可変`。
- 14 行目：元の数学の点数 95 を表示。この「95 の消費」で次の行が安全に取り替えられる。
- 17 行目：`数学` を `満点`（100）に置き換え。注意：`宣言` は書かない——これは取り替えであり新しい箱の作成ではない。
- 20 行目：`国語 + 数学` = 88 + 100 = 188 を新しい箱 `合計` へ。
- 21 行目：188 を 188.0 に変換し新しい箱 `浮動の合計` へ。
- 22 行目：188.0 ÷ 2.0 = 94.0。二行に分け、「長い一行、順序読み違え」の罠を避ける。
- 25〜32 行目：カードを一行ずつ表示。各 `{}` は対応する箱で埋まる。
- 32 行目：`平均 >= 90.0` はブール値を生む比較——`真` か `偽`。`>=` は「以上」——第 5 章で扱う。浮動小数点数と比べるときは 90 を 90.0 と書く。
- 33 行目：主関数の終わり。

### 見えるはずのもの

```
数学（元）：95
====== 生徒情報カード ======
名前：花子
年齢：12
国語：88 点
数学：100 点
合計：188 点
平均：94
優秀：true
```

> ⚠️ **注意**：最後の行は `true` と出ます——コードでは `真` と書いても、表示は Rust 本来の英語表記になります。プログラムには影響しません；第 11 章のあとで、好きな形に表示する方法を学びます。

## 3.7 シャドーイング：同じ名前の新しい箱が古い箱を覆う

Rust には奇妙な性質があります：`宣言` を同じ名前で再び使うと、新しい箱が古い箱を「覆います」：

```rust
関数 主関数() {
    宣言 数値 = 5;
    宣言 数値 = 数値 + 1;    // 新しい箱が古い箱を覆い、6 を保持
    宣言 数値 = 数値 * 2;    // また別の新しい箱、12 を保持
    表示行!("{}", 数値);     // 12
}
```

> 📖 **シャドーイング**：既存の名前の下に `宣言` で新しい変数を作ること——新しい変数が古い変数を覆い（shadow）、名前を呼ぶと今は新しい箱が見つかる。古い箱はまだ存在するが、ただ「影の後ろに」隠れ、手が届かない。

> 💡 **たとえ**：箱を積み重ねるようなもの——後から同じ名前の箱が古い箱の肩の上に立ち、名前を呼ぶと一番上の箱が答える。

シャドーイングと `可変`：

| | シャドーイング | `可変` |
|---|---|---|
| 書き方 | 毎回 `宣言` | 一度 `宣言`、あとはそのまま代入 |
| 箱 | 毎回 **新しい箱** を作る | 常に **同じ箱** |
| 型 | 全く別の型に切り替え可 | 同じ型の値だけ |

## 3.8 よくある失敗と直し方

### 失敗一：不変変数を取り替える

```rust
// 预期错误: E0384
関数 主関数() {
    宣言 点数 = 90;
    点数 = 100;   // ❌
}
```

報告：`エラー[E0384]: 不変変数 '点数' に二度代入できません`。

**直し方**：本当に変わるなら、作るときに `可変` を付ける。

### 失敗二：作ったことのない箱を使う

```rust
関数 主関数() {
    表示行!("{}", 身長);   // ❌ 「宣言 身長 = ...」など一度もなかった
}
```

報告は、だいたい「`身長` というものが見つからない」という内容です。

**直し方**：タイポを確認；作るのが使うより先にあるか確認。

### 失敗三：演算で型を混ぜる

```rust
// 预期错误: E0277
関数 主関数() {
    宣言 値1 = 10;          // 整数
    宣言 値2 = 3.5;         // 浮動小数点数
    宣言 合計 = 値1 + 値2;   // ❌ 整数と浮動小数点数は直接足せない
}
```

**直し方**：一方を `として` で変換し、**二行に書く**：

```rust
宣言 浮動の値1 = 値1 として 浮動小数点数;
宣言 合計 = 浮動の値1 + 値2;
```

### 失敗四：全角句読点がコードに紛れ込む

```rust
宣言 名前 = "花子"；   // ❌ 末尾は全角セミコロン
```

報告はたいていその行を指し、未知の記号だと文句を言います。

**直し方**：英数入力に切り替え、`；` を `;` に変える。合言葉を覚えて：**コードの骨格は英語（の方言）；引用符の中だけが母語**。

このコードには一つ間違いがあります。見つけて直してください：

```rust
関数 主関数() {
    宣言 可変 カウンタ = 0;
    宣言 カウンタ = カウンタ + 1;
    表示行!("{}", カウンタ);
}
```

<details>
<summary>🔍 参考解答</summary>

3 行目に余分な `宣言` があります。既存の箱の中身を取り替えるときは `宣言` を再び書いてはいけません（書くと新しい箱を作る——それがシャドーイングです）。次のように直します：

```rust
カウンタ = カウンタ + 1;
// より簡潔に：カウンタ += 1;
```

（小注：元のコードは実際には動きます——しかし 3 行目の `宣言` が古い箱を覆う新しい箱を作るので、`可変` が無意味になります。この練習の狙いは「取り替えに `宣言` は要らない」を見抜くことでした。）

### 練習五（発展）：平均点

三つの点数——92、85、78。平均（小数付き）を計算して表示してください。

<details>
<summary>🔍 参考解答</summary>

```rust
関数 主関数() {
    宣言 国語 = 92;
    宣言 数学 = 85;
    宣言 英語 = 78;
    宣言 合計 = 国語 + 数学 + 英語;
    宣言 浮動の合計 = 合計 として 浮動小数点数;
    宣言 平均 = 浮動の合計 / 3.0;
    表示行!("平均：{}", 平均);
}
```

合計は 255、255.0 / 3.0 = 85 です。これは偶然割り切れます；合計が 256 なら、変換を省略すると小数が切り捨てられます——だからこそ `として 浮動小数点数` があるのです。

</details>

## 3.11 よくある質問

**Q1：なぜ Rust は変数を既定で変えられなくしているの？ 他の言語はみんなできるのに。**

安全のための設計です。ほとんどのデータは変わる必要がありません；既定で錠を掛けることで「うっかり変えてしまった」バグを防ぎます。本当に変える必要があるときは `可変` を付けます——それは「私はこれを変えるつもりだ」を明記するのと同じです。

**Q2：`定数` と `可変` のない普通の変数、どちらを使う？**

プログラム全体で絶対に固定の値（満点、円周率）は定数です。一つの関数内だけで使い、どうせ変わらない値は普通の変数で構いません。

**Q3：数が大きすぎたら？**

問題です。`整数` は約 21 億が限界——それを超えるとエラーかオーバーフローになります。`長整数` を使いましょう：`宣言 大きな数: 長整数 = 9999999999;`

**Q4：`真` と `"真"` は同じ？**

違います。`真` はブール値（引用符なし）；`"真"` は文字列（引用符付き、五文字）。数値の 5 と言葉の「五」のようなもの——別物です。

**Q5：型推論がそんなに優秀なら、注釈を書くことはない？**

たいていはその通り。でも定数には必須；そして書けばコードが分かりやすくなります——作文に説明の一文を足すようなもの。害はありません。

**Q6：ブール値を表示すると `true`/`false` になるのはなぜ？**

コードでは `真`/`偽` と書けますが、印刷の表示は Rust 本来の `true`/`false` です。母語の表示が欲しければ、あとの章で書式の技法を学びます。プログラムの論理には影響しません。

## この章のまとめ

1. **変数** はラベルを貼った箱、`宣言` で作る。
2. Rust の変数は既定で **不変**；変えるには `可変` を付ける。
3. **定数** は決して変わらず、型注釈が必須。
4. 四つの基本型：**整数**（45）、**浮動小数点数**（3.14）、**ブール値**（真/偽）、**文字**（'A'）。
5. 演算：`+ - * / %`；自分を変えるには `+=`；変換には `として`。
6. 整数割り算は小数を切り捨て；小数が欲しければ浮動小数点数を使う。
