# 第 5 章：制御フロー

前三章のプログラムは「上から下へ一本道」でした。この章では、プログラムが三つの力を身につけます：**選ぶ**、**繰り返す**、**場合分けして振り分ける**。

---

## 5.0 この章の目標

この章を終えると、あなたは次のことができるようになります：

1. `もし / そうでなければ` で、条件に応じて違う道を歩ませられる。
2. 比較記号と論理記号を組み合わせて、複雑な条件を書ける。
3. `マッチ` で、一つの値の可能性をすべて一気に列挙できる。
4. `ループ`、`間`、`各 … 中` で繰り返しをさせ、`中断`、`続行` でリズムを制御できる。

---

## 5.1 プログラムの「足跡」

これまでのプログラムの実行は、こうでした——一行ずつ、上から下へ：

```
1行目 → 2行目 → 3行目 → 終わり
```

これは**順次実行**と呼ばれます。しかし現実の生活は一本道ではありません：

- **もし**雨が降ったら傘を持つ；**そうでなければ**帽子をかぶる。→ これが**選択**。
- 校庭を 5 周走る。→ これが**繰り返し**。
- 信号は赤で止まり、青で進み、黄で減速する。→ これが**場合分け**。

> 📖 **制御フロー**：プログラムの「実行の足跡」を制御する文の総称。本章の `もし`、`マッチ`、`ループ`、`間`、`各` はすべて制御フローの文です。

---

## 5.2 もし / そうでなければ：分かれ道

### 最も簡単な選択：もし

```rust
関数 主関数() {
    宣言 気温 = 32;
    もし 気温 > 30 {
        表示行!("あつい！アイスを食べよう！");
    }
    表示行!("プログラム終了");
}
```

一行ずつ：

- 3 行目：`もし 気温 > 30 {` —— 「気温は 30 より大きい」という主張が真か偽かを調べます。真なら波括弧の中を実行し、偽なら波括弧全体をスキップします。
- 条件は真（32 は確かに 30 より大きい）なので、「あつい！アイスを食べよう！」と表示されます。
- 最終行は波括弧の外なので、どんな場合でも実行されます。

見えるはずのもの：

```
あつい！アイスを食べよう！
プログラム終了
```

> 📖 **条件**：結果が真か偽かになる判断文——例えば `気温 > 30`。`もし` の後ろには必ず条件が一つ続きます。

> ⚠️ **注意**：条件を **丸括弧で囲んではいけません**。`もし (気温 > 30)` は他の言語の書き方で、Rust はエラーを出します。素直に `もし 気温 > 30` と書いてください。

### 二つの道：もし / そうでなければ

> 📖 **`そうでなければ`**：キーワード。「条件が成立しなかったらこちらを通る」という意味です。

```rust
関数 主関数() {
    宣言 気温 = 15;
    もし 気温 > 30 {
        表示行!("アイスを食べる");
    } そうでなければ {
        表示行!("上着を着る");
    }
}
```

気温 15 は 30 より大きくない——条件は偽なので、`そうでなければ` の道を通ります：

```
上着を着る
```

> ⚠️ **注意**：`そうでなければ` は直前の波括弧にくっつけて `} そうでなければ {` と書きます。間には空白しか入らず、改行して単独の `そうでなければ` にしてはいけません。

### 三つ以上の道：そうでなければ もし

二つの道では足りない？ `そうでなければ もし` で条件をどんどんつなげましょう：

```rust
関数 主関数() {
    宣言 気温 = 25;
    もし 気温 > 30 {
        表示行!("とても暑い");
    } そうでなければ もし 気温 > 20 {
        表示行!("過ごしやすい");
    } そうでなければ もし 気温 > 10 {
        表示行!("少し肌寒い");
    } そうでなければ {
        表示行!("寒い");
    }
}
```

実行ルールは **空港のセキュリティゲート** のようです：上から下へ一つずつ調べ、**最初に**真になったゲートに入ったら、後のゲートは全部見ません。

- 25 > 30？ 偽。次へ。
- 25 > 20？ 真！ ここに入り「過ごしやすい」と表示。以後は全部スキップ。

```
過ごしやすい
```

> 💡 **たとえ**：`そうでなければ もし` の連鎖は自動販売機のボタンのようなもの——上から順に押していき、最初に光ったボタンだけが効きます。後はお構いなし。

### 分かれ道の中の分かれ道：ネスト

`もし` の中にさらに `もし` を入れられます：

```rust
関数 主関数() {
    宣言 宿題おわり = 真;
    宣言 いい天気 = 真;
    もし 宿題おわり {
        もし いい天気 {
            表示行!("遊びに出よう！");
        } そうでなければ {
            表示行!("家で本を読む");
        }
    } そうでなければ {
        表示行!("まず宿題");
    }
}
// 预期输出: 遊びに出よう！
```

出力：`遊びに出よう！`。ネストは使えますが、深くなると頭がくらくらします——多くても二層までにしましょう。

## 5.3 比較と論理：条件を組み立てる

### 六つの比較記号

| 記号 | 読み方 | 例 | 結果 |
|---|---|---|---|
| `==` | 等しい | `5 == 5` | 真 |
| `!=` | 等しくない | `5 != 3` | 真 |
| `>` | より大きい | `5 > 3` | 真 |
| `<` | より小さい | `5 < 3` | 偽 |
| `>=` | 以上 | `5 >= 5` | 真 |
| `<=` | 以下 | `5 <= 4` | 偽 |

> ⚠️ **注意**：「等しい」の判定には等号が **二つ** の `==`。等号一つの `=` は代入（箱に物を入れる）で、第 3 章で学びました。書き間違えると厄介です：`もし 得点 = 90` はエラーになります。

> ⚠️ **注意**：両辺の型は同じでなければなりません。`5 == 5.0` はエラー——整数と小数はそのままでは比べられません。

### 三つの論理記号

条件をいくつかつなげるときは論理記号を使います。**記号であって、日本語の単語ではありません**：

| 記号 | 読み方 | 意味 | 生活の例 |
|---|---|---|---|
| `&&` | かつ | 両辺とも真のときだけ真 | 宿題がすみ**かつ**天気がいいときだけ遊びに行ける |
| `\|\|` | または | 少なくとも片方が真なら真 | バス**または**地下鉄、どちらでも着く |
| `!` | でない（反転） | 真は偽に、偽は真に | **雨が降ってい**ない |

```rust
関数 主関数() {
    宣言 宿題おわり = 真;
    宣言 いい天気 = 偽;

    もし 宿題おわり && いい天気 {
        表示行!("遊びに出る");        // 表示されない：いい天気が偽
    }
    もし 宿題おわり || いい天気 {
        表示行!("どちらかは満たす");   // 表示される：宿題おわりは真
    }
    もし !いい天気 {
        表示行!("天気がよくない");     // 表示される：偽の反転は真
    }
}
```

見えるはずのもの：

```
どちらかは満たす
天気がよくない
```

> ⚠️ **注意**：`&&` と `||` は **英字記号** で書きます。日本語で「かつ」と書くとエラーです。キーボードでは：`&&` は `Shift+7` を二回；`||` は Backspace キーの近くの縦棒キー `Shift+\` を二回。

> ✨ **ヒント**：`&&` にはサボりの特技があります——左辺が偽なら右辺はまったく見ません（どうせ結果は決まっているので）。例えば `もし 皿 != 0 && 合計 / 皿 > 5` は、皿が 0 のとき割り算を実行しないので「ゼロ除算」の事故を避けられます。

## 5.4 驚き：もし は「値」として使える

Rust には他ではめったに見ない不思議な特技があります：`もし` の全体が **一つの値を計算** でき、そのまま箱にしまうのです。

```rust
関数 主関数() {
    宣言 得点 = 87;
    宣言 評価 = もし 得点 >= 90 { "優" } そうでなければ もし 得点 >= 80 { "良" } そうでなければ { "可" };
    表示行!("評価：{}", 評価);
}
```

見えるはずのもの：`評価：良`。

3 行目の意味：得点から結果を計算し、その結果を `評価` にしまいます。得点は 87 なので二つ目の分岐に入り、`評価` に入るのは `"良"` です。

この背後には二つの大事な概念があります：

> 📖 **文**：物事をひとつ実行するだけで、値を生み出さない命令。末尾にセミコロンが付きます。例：`表示行!(...);`
>
> 📖 **式**：値を一つ計算できる書き方。数字の `5` は式（値は 5）、`2 + 3` も式（値は 5）、さらには `もし...{...} そうでなければ {...}` さえも式です。

> ⚠️ **注意：セミコロンは値を「飲み込む」！** 波括弧の中の **最終行にセミコロンを付けない** と、その行の値が `もし` 全体の値になります。付けると文になってしまい、値は消えます：

```rust
宣言 評価 = もし 得点 >= 90 { "優"; } そうでなければ { "可"; };   // ❌ エラー！
```

エラーの大意：文字を期待したが「空」が得られた——セミコロンが `"優"` を飲み込み、波括弧の中に何も残らなかったからです。

ルールを一言で：**波括弧に値を渡してほしければ、最終行にセミコロンを付けない。**

> 💡 **たとえ**：式は「質問への答え」、文は「済ませた動作」のようなもの。あなたが `もし` に「結果は何？」と尋ねると、波括弧の中の最終行（セミコロンなし）を手渡してくれます。

## 5.5 マッチ：自動販売機

一つの値に可能性がたくさんあって、それぞれで違うことをしたい？ `マッチ` を使いましょう。

> 📖 **`マッチ`**：キーワード。一つの値をリストに照らし合わせ、当たった項目を実行します。

```rust
関数 主関数() {
    宣言 順位 = 2;
    マッチ 順位 {
        1 => 表示行!("金メダル"),
        2 | 3 => 表示行!("表彰台"),
        _ => 表示行!("これからも頑張ろう"),
    }
}
```

一行ずつ：

- `マッチ 順位 {`：`順位` の値を下のリストに照らします。
- `1 => 表示行!("金メダル"),`：値が 1 なら矢印の後ろを実行。各項目を **マッチ腕** と呼びます。
- `2 | 3 => ...`：縦棒 `|` は「または」。値が 2 でも 3 でもこの項目に当たります。
- `_ => ...`：下線 `_` は「その他すべて」——どん底を受け止める存在です。

順位は 2 なので、出力は：

```
表彰台
```

> 📖 **ワイルドカード**：ここでの `_` は「何であろうと、残りは全部私が引き受ける」という意味です。

> 📖 **網羅（窮尽）**：`マッチ` のリストは **すべての可能性** を覆わなければなりません——一つずつ列挙するか、`_` で受けるか。一つでも漏れるとコンパイラがエラーを出します。Rust が「考え漏らし」を許さない設計です。

### マッチも値を計算できる

`マッチ` は `もし` と同じく式です：

```rust
宣言 得点 = 95;
宣言 評価 = マッチ 得点 {
    90..=100 => "優秀",
    80..=89 => "良好",
    70..=79 => "普通",
    60..=69 => "ぎり合格",
    _ => "不合格",
};
```

> 📖 `90..=100`：範囲の書き方。`..=` は **両端を含みます**（90 から 100 まで全部）。スライスの `..` は「頭入り尻尾抜き」でしたね——等号を付けると「尻尾もちょうだい」という意味になります。

> ⚠️ **注意**：各マッチ腕の矢印は `=>`（等号＋大于号……ではなく、等号＋大きなり）です。`->` と書かないように。

## 5.6 ループ：疲れを知らない繰り返し

### ループ：最も「ゴリラ」な繰り返し

> 📖 **`ループ`**：キーワード。コードの切れ端を、あなたが「止め！」と叫ぶまで何度でも繰り返します。

```rust
関数 主関数() {
    宣言 可変 回数 = 0;
    ループ {
        回数 += 1;
        表示行!("{}周目", 回数);
        もし 回数 == 3 {
            中断;
        }
    }
    表示行!("お開き");
}
```

見えるはずのもの：

```
1周目
2周目
3周目
お開き
```

> 📖 **`中断`**：キーワード。「すぐにループから飛び出す」という意味。これがないと `ループ` は地獄の底まで（無限ループで）走り続けます。

### ループも返り値を渡せる

`中断` の後ろに値を付ければ、ループ全体にその値を渡せます：

```rust
関数 主関数() {
    宣言 可変 カウント = 0;
    宣言 倍結果 = ループ {
        カウント += 1;
        もし カウント == 5 {
            中断 カウント * 2;
        }
    };
    表示行!("倍結果：{}", 倍結果);
}
```

一行ずつ：ループが順に 1 を加え、5 になったところで「中断！」と叫び、同時に `5 * 2 = 10` を外へ投げます。`ループ {...}` 全体の値は 10 となり、`倍結果` にしまわれます。

見えるはずのもの：`倍結果：10`。

## 5.7 間：条件が真の間だけ繰り返す

> 📖 **`間`**：キーワード。「条件が真である間、ずっと繰り返す」。条件が偽になったら自動的に止まります。

```rust
関数 主関数() {
    宣言 可変 カウントダウン = 3;
    間 カウントダウン > 0 {
        表示行!("カウントダウン{}", カウントダウン);
        カウントダウン -= 1;
    }
    表示行!("出発！");
}
```

見えるはずのもの：

```
カウントダウン3
カウントダウン2
カウントダウン1
出発！
```

実行の流れ：毎回の始まりに必ず `カウントダウン > 0` を調べます。3、2、1 は成立；0 まで減ると条件が偽になり、ループは自動的に終わります。

> ⚠️ **注意**：ループの中で条件を「偽へ向かわせる」ことを忘れないでください（ここでは `カウントダウン -= 1`）。忘れると条件は永遠に真で、プログラムはループの中で凍りつきます——これを **無限ループ（死の環）** と呼びます。凍りついたら `Ctrl+C`（Ctrl を押しながら C）で強制停止できます。

`間` と `ループ＋もし＋中断` でできることはほぼ同じですが、`間` は条件を先頭に書くので「いつ止まるか」が一目で分かり、より明快です。

## 5.8 各 … 中：列に並んで一つずつ

回数が決まっている、または一列に並んだ物を順に処理したいなら、`各 … 中` が一番楽です。

> 📖 **`各`** と **`中`**：キーワード。「ある集まりの中の、一つひとつ X について、順に何々をする」と読みます。

### 範囲と組み合わせる：決まった回数の繰り返し

```rust
関数 主関数() {
    各 番号 中 1..6 {
        表示行!("{}周目", 番号);
    }
}
```

`1..6` は範囲：**1 から 5 まで**（覚えていますか？ `..` は頭入り尻尾抜き）。6 も含めたければ `1..=6` と書きます。

見えるはずのもの：

```
1周目
2周目
3周目
4周目
5周目
```

### 配列と組み合わせる：要素を一つずつ処理する

第 4 章で五つの得点を手で足すのに五行書いたのを覚えていますか？ 今は一行で済みます：

```rust
関数 主関数() {
    宣言 得点 = [88, 95, 76, 90, 82];
    宣言 可変 合計 = 0;
    各 点 中 得点 {
        合計 += 点;
    }
    表示行!("合計点：{}", 合計);
}
```

`各 点 中 得点` の意味：配列から要素を順に一つ取り出し、そのたびに `点` という箱に入れ、ループの中身を一度実行する。五回終われば、合計 = 431。

```
合計点：431
```

> 💡 **たとえ**：`各 … 中` は先生の点呼のようなもの——「名簿の各生徒について、教室の中で、順に返事をして」。ループは自動で進むので、あなたが数える必要はありません。

## 5.9 続行：この回だけスキップ、次の回へ

> 📖 **`続行`**：キーワード。「この回の残りはやめて、すぐ次の回へ」という意味です。

```rust
関数 主関数() {
    宣言 得点表 = [88, 55, 76, 42, 90];
    宣言 可変 合格数 = 0;
    各 点 中 得点表 {
        もし 点 < 60 {
            続行;      // 不合格は飛ばして、数えない
        }
        合格数 += 1;
    }
    表示行!("合格{}科目", 合格数);
}
```

55 と 42 に出会うと、`続行` が後ろの計数を飛ばさせ、直接次の得点へ進みます。出力：

```
合格3科目
```

`中断` vs `続行`：`中断` は「ループ全体もうおしまい」、`続行` は「この回だけおしまい、次の回は続く」。

## 5.10 総合例：成績評価プログラム

### 全体のコード

```rust
関数 主関数() {
    宣言 得点表 = [88, 55, 76, 42, 90];

    // 一周目：各得点を評価する
    表示行!("--- 評価 ---");
    各 科目得点 中 得点表 {
        宣言 評価 = マッチ 科目得点 {
            90..=100 => "優秀",
            80..=89 => "良好",
            70..=79 => "普通",
            60..=69 => "ぎり合格",
            _ => "不合格",
        };
        表示行!("{}点 → {}", 科目得点, 評価);
    }

    // 二周目：合格者数と最高点を数える
    宣言 可変 合格数 = 0;
    宣言 可変 最高点 = 得点表[0];
    各 科目得点 中 得点表 {
        もし 科目得点 >= 60 {
            合格数 += 1;
        }
        もし 科目得点 > 最高点 {
            最高点 = 科目得点;
        }
    }
    表示行!("合格{}人、最高点{}", 合格数, 最高点);
}
// 预期输出: --- 評価 ---
// 88点 → 良好
// 55点 → 不合格
// 76点 → 普通
// 42点 → 不合格
// 90点 → 優秀
// 合格3人、最高点90
```

### 一行ずつ

- 2 行目：五科目の得点を配列にしまいます。
- 5 行目：`各 … 中` が得点を順に取り出し、そのたび `科目得点` に入れます。
- 6〜12 行目：`マッチ` を評価器として使う。範囲パターン `90..=100` は両端を含みます；`_` は残りすべて（0〜59）を受け止める。`マッチ` 全体が文字の値を計算し、`評価` にしまわれます。
- 13 行目：「得点 → 評価」を印刷。
- 17 行目：合格カウンター。可変で、0 から開始。
- 18 行目：まず最初の得点を最高と仮定し、後で順に比べます。
- 19〜26 行目：配列をもう一周——60 以上なら計数；現在の最高より高ければ最高点を更新。
- 27 行目：統計結果を印刷。

### 見えるはずのもの

```
--- 評価 ---
88点 → 良好
55点 → 不合格
76点 → 普通
42点 → 不合格
90点 → 優秀
合格3人、最高点90
```

## 5.11 よくある失敗と直し方

### 失敗一：マッチが場合を漏らす（網羅性エラー）

```rust
マッチ 順位 {
    1 => 表示行!("金メダル"),
    2 => 表示行!("銀メダル"),
}   // ❌ 順位は 3、4、5……の可能性もある
```

エラーの大意：マッチが網羅的でなく、すべての可能性を覆っていない。

**直し方**：残りの場合を補うか、`_ => ...` を受け皿に加えます。

### 失敗二：セミコロンが もし の値を飲み込んだ

```rust
宣言 評価 = もし 得点 >= 90 { "優"; } そうでなければ { "可"; };   // ❌
```

**直し方**：波括弧の中の最終行からセミコロンを取る：`{ "優" } そうでなければ { "可" }`。

### 失敗三：論理語を日本語で書いた

```rust
もし 甲 かつ 乙 { }   // ❌ エラー：`{` を期待したが `かつ` を発見
```

**直し方**：記号を使う：`もし 甲 && 乙`。

### 失敗四：等しいの判定に等号が一つ

```rust
もし 得点 = 90 { }   // ❌ これは代入で、エラーになる
```

**直し方**：`もし 得点 == 90`。合言葉：**判定は双等号、しまうのは単等号**。

### 失敗五：無限ループ

`間` や `ループ` で条件を変化させ忘れると、プログラムはぐるぐる回り続けます。

**直し方**：ループの中に「条件を終わりへ向かわせる」文があるか確認する；凍りついたら `Ctrl+C`。

## 5.12 章末用語集

| 用語 | 意味 |
|---|---|
| 間 | 条件が真の間だけ繰り返すループ。キーワード 間 |
| 各 … 中 | 集合の要素を一つずつ取り出すループ |
| 範囲 | `始め..終わり` または `始め..=終わり` の書き方 |
| マッチ腕 | マッチ のリストの一項目「当たったら何々をする」 |
| 制御フロー | プログラムの実行順を決める文の総称 |
| 網羅 | マッチ がすべての可能性を覆わねばならないこと |
| 条件 | 結果が真か偽かになる判断文 |
| ワイルドカード | `_`、マッチ における「その他すべて」 |
| 続行 | この回を飛ばして次の回へ |
| 無限ループ | 永遠に止まらないループ |
| 式 | 値を計算できる書き方 |
| ループ | 中断されるまで無限に繰り返す。キーワード ループ |
| マッチ | 値の場合に応じて振り分ける。キーワード マッチ |
| ネスト | 制御フロー構造の中にさらに制御フロー構造を入れること |
| もし | 条件で道を選ぶ。キーワード `もし` |
| そうでなければ | 条件が成立しないときの道。キーワード `そうでなければ` |
| 文 | 動作を済ませるだけで値を生まない命令 |
| 中断 | すぐにループから飛び出す。キーワード `中断` |

## 5.13 練習問題

> 💪 まず自分で試してから、答えを覗いてください。

### 練習一：気温アドバイス

プログラムを書いてください：気温 28。30 より大きければ「暑い」、20 より大きければ「過ごしやすい」、そうでなければ「寒い」と表示。

<details>
<summary>🔍 参考解答</summary>

```rust
関数 主関数() {
    宣言 気温 = 28;
    もし 気温 > 30 {
        表示行!("暑い");
    } そうでなければ もし 気温 > 20 {
        表示行!("過ごしやすい");
    } そうでなければ {
        表示行!("寒い");
    }
}
// 预期输出: 過ごしやすい
```

出力：`過ごしやすい`。

</details>

### 練習二：マッチ で曜日を翻訳

変数 `曜日番号` = 3 を作り、`マッチ` で対応する「月曜日」から「日曜日」を表示。それ以外の番号は「無効」と表示。

<details>
<summary>🔍 参考解答</summary>

```rust
関数 主関数() {
    宣言 曜日番号 = 3;
    宣言 名前 = マッチ 曜日番号 {
        1 => "月曜日",
        2 => "火曜日",
        3 => "水曜日",
        4 => "木曜日",
        5 => "金曜日",
        6 => "土曜日",
        7 => "日曜日",
        _ => "無効",
    };
    表示行!("{}", 名前);
}
// 预期输出: 水曜日
```

出力：`水曜日`。

</details>

### 練習三：足し合わせる

`各 … 中` で 1 から 100 までの総和を求めてください。

<details>
<summary>🔍 参考解答</summary>

```rust
関数 主関数() {
    宣言 可変 総和 = 0;
    各 数 中 1..=100 {
        総和 += 数;
    }
    表示行!("総和：{}", 総和);
}
// 预期输出: 総和：5050
```

出力：`総和：5050`。`1..=100` と書いて 100 も含めるのを忘れずに。

</details>

### 練習四：偶数を見つける

1 から 10 までの偶数をすべて表示してください（ヒント：`%` で余りを取り、2 で割り切れるか判定）。

<details>
<summary>🔍 参考解答</summary>

```rust
関数 主関数() {
    各 数 中 1..=10 {
        もし 数 % 2 == 0 {
            表示行!("{}", 数);
        }
    }
}
```

2、4、6、8、10 が各行に表示されます。`数 % 2 == 0` は「2 で割った余りが 0」という意味です。

</details>

### 練習五（発展）：バグを見つける

このコードは 1、2、3 と表示して止まるはずですが、問題があります。見つけてください：

```rust
関数 主関数() {
    宣言 可変 数 = 1;
    ループ {
        表示行!("{}", 数);
        数 += 1;
    }
}
```

<details>
<summary>🔍 参考解答</summary>

ループの中に `中断` がないので、永遠に走り続けます（無限ループ）。条件を補いましょう：

```rust
関数 主関数() {
    宣言 可変 数 = 1;
    ループ {
        表示行!("{}", 数);
        数 += 1;
        もし 数 > 3 {
            中断;
        }
    }
}
```

または `各 数 中 1..=3 { 表示行!("{}", 数); }` に書き換えれば、もっと簡単です。

</details>

## 5.14 よくある質問

**Q1：もし、マッチ、ループ——どれをいつ使う？**

場面で判断します。**二つの道/いくつかの道から一本選ぶ** → `もし`；**一つの値に多くの場合がある** → `マッチ`；**繰り返す** → ループ。ループ三兄弟では：回数や集合が決まっているなら `各`；停止条件が複雑なら `間`；「ループが値を渡す」必要があれば `ループ`。

**Q2：`1..6` はなぜ 6 を含まないの？**

こうすると大きな利点があります：範囲の長さがちょうど `6 - 1 = 5` になり、前の範囲の終点が次の範囲の起点とぴったり重なる（`1..4` の次に `4..6`、重なりも漏れもなし）。スライスもページ分割もこの性質のおかげです。慣れればとても快適。

**Q3：`マッチ` に複雑な条件を書ける？**

入門のうちは、`マッチ` は「値が何に等しいか/どの範囲に落ちるか」に使い、複雑な条件は `もし` に任せましょう。`マッチ` の上級技（列挙型の中のデータを取り出す）は第 11 章で。

**Q4：ループの中にさらにループを入れられる？**

入れられます。九九の表を印刷するのは二層ループの代表例——外側が行、内側が列を担当します。本章の練習で挑戦してみてください。

**Q5：プログラムが固まった。無限ループかも？**

コマンドラインで `Ctrl+C` を押して強制停止します。そのうえでループの中身を確認：条件を「終わりへ向かわせる」文はあるか？ `間` の条件は最終的に偽になるか？

**Q6：`もし` に `そうでなければ` を書かなかったら、条件が偽のときは？**

何も起きません。波括弧をスキップしてそのまま下へ進みます。`そうでなければ` は省略可能です。

## この章のまとめ

1. **`もし / そうでなければ もし / そうでなければ`**：条件の分かれ道。条件に括弧は付けない。
2. **論理記号**：`&&`（かつ）、`||`（または）、`!`（でない）——必ず記号で書き、単語は不可。
3. **式**：`もし` も `マッチ` も値を計算できる。波括弧の最終行のセミコロンを取らないと値がない。
4. **`マッチ`**：自動販売機。`|` で場合を併合、`..=` で範囲、`_` で受け皿、そして必ず網羅。
5. **ループ三兄弟**：`ループ`（値を返せる）、`間`（条件が先頭）、`各 … 中`（一つずつ）。
6. **`中断`** はループ全体から飛び出し、**`続行`** はこの回だけ飛ばす。
