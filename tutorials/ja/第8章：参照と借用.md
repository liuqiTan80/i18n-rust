# 第 8 章：参照と借用

## 8.0 この章の目標

この章を終えると、あなたは次のことができるようになります：

1. **参照** と **借用** の関係を説明できる（一つは物、一つは動作）；
2. **`&`** で不変借用（読み取り専用）をし、**`可変参照`** で可変借用をする；
3. 借用の鉄律を言える： **「可変は一つまで、または不変はいくつでも」** ；
4. **E0502**（借用の衝突）と **E0596**（可変借用できない）を読んで直せる；
5. **`*`** で逆参照し、借用証から原値を取り出せる；
6. 「借用の寿命は最後の使用まで」という決まりを知っている。

---

## 8.1 前章が残した難問

第 7 章で学んだとおり：文字列を関数に渡すと **引っ越し** てしまい、元の変数は無効になります。しかし多くの場合、関数に **一瞥** させるだけで、物をあげたいわけではありません：

```rust
関数 展示(文: 文字列型) {   // 値渡し：文が引っ越してきて、使い終わると消える
    表示行!("{}", 文);
}

関数 主関数() {
    宣言 挨拶 = 文字列型::から("こんにちは");
    展示(挨拶);
    // 挨拶 はもうない。まだ使いたい？ 無理
}
```

一目見ただけで原本を取り上げるのは、あまりに強横です。現実世界の解決法は—— **借りる** です。

## 8.2 参照：一枚の借用証

💡 **たとえ**：同級生があなたの読みたい本を見たがっています。本の所有権を **名義変更** するのではなく、「貸してあげる」と言います。その手元にあるのは実は **借用証** ——これで本を探せるけれど、本の主人はまだあなたです。

📖 **参照**：ある値を指し示す「借用証」。`&値` と書きます。`&` は「参照を取る」と読みます。参照は値そのものではなく、「値はどこにあるか」を記録するだけです。
📖 **借用**：参照を使って他人のデータを一時的に使う **動作**。借りたら返す——参照は所有権を変えません。

### 不変借用（読み取り専用）

```rust
// 引数型 &文字列型：借りて眺める
関数 展示(文: &文字列型) {
    表示行!("{}", 文);
}

関数 主関数() {
    宣言 挨拶 = 文字列型::から("こんにちは");
    展示(&挨拶);     // 借用証を渡す
    展示(&挨拶);     // もう一度借りてもよい
    表示行!("まだ健在：{}", 挨拶);   // 原本は無傷
}
```

出力：

```
こんにちは
こんにちは
まだ健在：こんにちは
```

`&挨拶` が借用証を一枚作って関数に手渡します。関数が読み終わると借用証は無効になり、`挨拶` は依然として主人です。何度借りても構いません。

## 8.3 可変借用：借りて書き加える

眺めるだけでなく **変更** もしたいときがあります。本の余白に書き込むようなもの。これには **可変借用** `可変参照` が要ります：

```rust
関数 書き加える(本: 可変参照 文字列型, 注記: 文字列参照) {
    本.文字列追加(注記);   // 文字列追加：末尾に文字を足す
}

関数 主関数() {
    宣言 可変 本 = 文字列型::から("三国志演義");
    書き加える(可変参照 本, "（青年版）");
    表示行!("{}", 本);
}
// 预期输出: 三国志演義（青年版）
```

出力：`三国志演義（青年版）`

新しい要件が二つ：

| 要件 | 書き方 | 理由 |
|---|---|---|
| 借りられる値は可変と宣言済みであること | `宣言 可変 本 = ...` | 不変の物は「改めて返す」ように貸せない |
| 貸し出すとき `可変参照` と書く | `書き加える(可変参照 本, ...)` | 「今回は可変借用」と明示する |

> 📖 **文字列追加**：文字列のメソッドで、末尾に一節の文字を追加します。似たものに `追加`（文字を一つ追加）があります。

## 8.4 借用の鉄律：二択

Rust の借用には一つの鉄律があります：

> **同じ瞬間に、不変借用はいくつでも、または可変借用は一つだけ。両者は同時に存在できない。**

💡 **たとえ**：図書館の規則です——
- **不変借用** = 何人もが同時に **閲覧室で本を読む**。読者は大勢いても問題なし；
- **可変借用** = 誰かが本を **製本し直す** ために持ち去る。このときは独占必須で、誰にも見せられない；
- 二つは **同時に起きられない**：読んでいる最中に本を引き抜いて綴じ直したら、読者の手元のページ番号はめちゃくちゃになる。

鉄律を破ると **E0502** が出ます：

```rust
宣言 可変 スローガン = 文字列型::から("頑張れ");
宣言 覗き見 = &スローガン;        // 不変借用が効力中
宣言 変更要 = 可変参照 スローガン;    // ❌ 同時に可変借用
表示行!("{}", 覗き見);     // 覗き見 はこの後も使う。借用はこの瞬間まで生きていなければならない
```

実際のエラー：

```
エラー[E0502]: `スローガン` は不変借用中のため可変借用できません
📌 変数 `スローガン` は 4 行目で借用され、5 行目でまだ使用されています。
💡 Rustでは可変借用と不変借用を同時に持てません。不変借用のスコープを狭めましょう。
```

### なぜこんなに厳しい？

「読みながら書き換える」ことを許したとします：関数 A が借用証を持って文字列を読んでいる最中に、関数 B が突然文字を足す——文字列は倉庫の中で **もっと広い部屋への引っ越し**（メモリの再確保）が必要になるかもしれません。A の手の借用証が指すのは、一瞬にして **もぬけの殻** の部屋。プログラムは崩壊します。鉄律はこの事故をコンパイルの時点で根絶するのです。

### 先後順なら問題なし

鉄律が取り締まるのは「 **同時** 」です。前の借用を使い終わってから次を借りるのは、まったくの合法です：

```rust
宣言 可変 本 = 文字列型::から("三国志演義");
展示(&本);                    // 一回目の不変借用、使い終わったら無効
書き加える(可変参照 本, "（青年版）"); // 可変借用、使い終わったら無効
展示(&本);                    // また不変借用、問題なし
```

### 借用の「寿命」

借用の寿命 = **生まれてから最後に使われるまで** 。使い終わったら、鉄律はもうそれに構いません：

```rust
宣言 可変 スローガン = 文字列型::から("頑張れ");
宣言 覗き見 = &スローガン;
表示行!("{}", 覗き見);    // 覗き見 の最後の使用
// ここで 覗き見 の寿命は終わり
宣言 変更要 = 可変参照 スローガン;    // ✅ 問題なし：不変借用はすでに期限切れ
変更要.文字列追加("！");
```

> ✨ これはコンパイラの賢い一面です：借用証を「保管して」いた期間ではなく、 **実際にどこまで使ったか** だけを見ます。

## 8.5 不変借用は変更できない：E0596

引数を `&文字列型`（不変）と宣言したのに、関数の中で変更しようとすると **E0596** が出ます：

```rust
// 预期错误: E0596
関数 勝手に変更(本: &文字列型) {
    本.文字列追加("！");    // ❌
}
```

実際のエラー：

```
エラー[E0596]: 可変として宣言されていないため可変借用できません
💡 可変借用（`可変参照`）できるのは可変変数のみです。変数を `宣言 可変` で宣言するか、パラメータに `可変` を付けましょう。
```

**解決**：変更したいなら引数を `可変参照 文字列型` に変え、呼び出し側の変数が `宣言 可変` であることを保証する。

## 8.6 逆参照：借用証から原値を取り出す

📖 **逆参照（デリファレンス）**：参照からその指す先の値を取り出す操作。記号は `*`。

```rust
宣言 得点 = 95;
宣言 借用証 = &得点;
宣言 写し = *借用証;      // * は借用証をたどって原値を見つけ、写し取る
表示行!("写し取った値：{}", 写し);
// 预期输出: 写し取った値：95
```

出力：`写し取った値：95`

`&` は「借用証を書く」、`*` は「借用証で受け取る」——方向が正反対です。

> ✨ 普段のコードで手動の逆参照はめったにありません——メソッド呼び出しではコンパイラが自動でつるをたどってくれます（`(&本).長さ()` はそのまま `本.長さ()` と書けます）。`*` の存在を知って、エラーが読めれば十分です。

## 8.7 参照は整数も借りられる？

借りられます。参照と複製は衝突しません：

```rust
宣言 得点 = 95;
宣言 借用証 = &得点;
表示行!("借用証の指す先：{}", 借用証);
表示行!("原値は健在：{}", 得点);   // 整数はもともと複製されるので、無事
```

ただ、整数はもともと小さくて複製も安いので、値を直接渡せばよく、借りる必要はほとんどありません。参照が真価を発揮するのは **文字列、ベクタ、構造体** といった「大きな物」です。

## 8.8 総合例：図書館貸出システム

不変借用、可変借用、並行借用、先後借用をすべてつなげます：

```rust
// 不変借用：見て返すだけ
関数 展示(本: &文字列型) {
    表示行!("本の中身：{}", 本);
}

// 可変借用：変更して返す
関数 書き加える(本: 可変参照 文字列型, 注記: 文字列参照) {
    本.文字列追加(注記);
}

// 二つの不変借用が同時存在：問題なし
関数 長さ比べ(甲: &文字列型, 乙: &文字列型) {
    もし 甲.長さ() > 乙.長さ() {
        表示行!("甲のほうが長い");
    } そうでなければ {
        表示行!("乙も短くない");
    }
}

関数 主関数() {
    宣言 可変 本 = 文字列型::から("三国志演義");
    展示(&本);                       // 不変借用
    書き加える(可変参照 本, "（青年版）");    // 可変借用
    展示(&本);                       // 不変借用

    宣言 もう一冊 = 文字列型::から("西遊記");
    長さ比べ(&本, &もう一冊);           // 不変借用が二つ並行

    表示行!("原本は健在：{}", 本);
}
// 预期输出: 本の中身：三国志演義
// 本の中身：三国志演義（青年版）
// 甲のほうが長い
// 原本は健在：三国志演義（青年版）
```

## 8.9 一行ずつ

- **2〜4 行目**：`展示` は `&文字列型` を受け取る——借りるだけで取らない。呼び出し後も原本はそのまま。
- **7〜9 行目**：`書き加える` は `可変参照 文字列型` を受け取り、`文字列追加` で末尾に文字を足します。
- **12〜18 行目**：`長さ比べ` は不変借用を二つ同時に保持——鉄律は「不変の並行」を許します。`長さ()` が返すのは **バイト数**（日本語一文字は 3 バイト。「三国志演義」は 15 バイト）。
- **21 行目**：`宣言 可変`——この後可変借用するので、可変と宣言が必須。
- **22〜24 行目**：三回の借用は **先後** して起こり、毎回使い終わると同時に効力を失い、互いに衝突しません。
- **26 行目**：二冊の「本」が同時に不変借用されます。
- **28 行目**：すべての借用が返済済み。原本は無傷で、まだ印刷できます。

## 8.10 見えるはずのもの

```
本の中身：三国志演義
本の中身：三国志演義（青年版）
甲のほうが長い
原本は健在：三国志演義（青年版）
```

「三国志演義（青年版）」は「西遊記」よりバイト数が多いので、「甲のほうが長い」になります。

## 8.11 よくある失敗と直し方

### 失敗一：E0502 借用の衝突（可変＋不変の同時）

```
エラー[E0502]: `スローガン` は不変借用中のため可変借用できません
```

**解決**：二種の借用を **時間でずらす** ——先に不変借用の用事を済ませ（使い切って）、それから可変借用を始める。あるいはいっそクローンして複製のほうを変更する。

### 失敗二：E0596 不変借用を変更しようとした

```
エラー[E0596]: 可変として宣言されていないため可変借用できません
```

**解決**：三つの場所を同時に確認——① 元の変数は `宣言 可変` か；② 呼び出し側は `可変参照` と書いているか；③ 関数の引数型は `可変参照 型` か。一つでも欠けたらだめです。

### 失敗三：`宣言 可変` を忘れた

不変の変数に `可変参照 甲` と書いても、同じく E0596 が出ます。**解決**：宣言のところに `可変` を足す。

### 失敗四：参照が元値より長生き

```rust
// 预期错误: E0597
関数 主関数() {
    宣言 借用証;
    {
        宣言 短命 = 文字列型::から("はかない命");
        借用証 = &短命;
    }
    表示行!("{}", 借用証);   // ❌ 短命 はもうない。借用証は不渡り手形
}
```

エラーは「借用した値の寿命が十分でありません」と教えてくれます。**解決**：借用証の寿命は元値を超えてはならない。元値を借用証より長生きさせる。

> 📖 **宙ぶらりん参照（ダングリングリファレンス）**：すでに消滅したデータを指す参照。Rust はコンパイルの時点でこれを禁止します——これが参照安全の中核の保証です。

## 8.12 章末用語集

| 用語 | 一言でいうと |
|---|---|
| 参照 | 値を指し示す「借用証」。`&値` と書く |
| 借用 | 参照で他人のデータを一時的に使うこと。所有権は変わらない |
| 不変借用 | `&値`。同時にいくつあってもよい |
| 可変借用 | `可変参照 値`。同じ瞬間に一つだけ |
| 借用の鉄律 | 不変はいくつでも、または可変は一つ。同時は不可 |
| 逆参照 | `*` で参照から原値を取り出すこと |
| E0502 | 可変借用と不変借用が衝突したエラーコード |
| E0596 | 可変借用しようとしたができなかったエラーコード |
| 宙ぶらりん参照 | 消滅済みのデータを指す参照（Rust はコンパイル期に禁止） |
| 文字列追加 | 文字列の末尾に文字を追加するメソッド |

> 📖 **お知らせ**：分からない言葉が出たら、いつでも本の冒頭の《総用語表》に戻って引いてください。

## 8.13 練習問題

> 💪 まず自分で試してから、答えを覗いてください。

### 練習一：不変借用

関数 `長さ報告(話: &文字列型)` を書いてください。「この文はNバイトです」と表示。主関数で同じ文字列に対して二回呼び出し、原値が取り上げられていないことを証明します。

<details>
<summary>🔍 参考解答</summary>

```rust
関数 長さ報告(話: &文字列型) {
    表示行!("この文は{}バイトです", 話.長さ());
}

関数 主関数() {
    宣言 話 = 文字列型::から("勉強三昧");
    長さ報告(&話);
    長さ報告(&話);
    表示行!("原値：{}", 話);
}
```

出力（「勉強三昧」は計 12 バイト）：

```
この文は12バイトです
この文は12バイトです
原値：勉強三昧
```

</details>

### 練習二：可変借用

関数 `二倍話(話: 可変参照 文字列型)` を書いてください：文字列の末尾に自分自身をもう一度追加する（ヒント：先にクローンしてから追加。でないと「自分が自分を借用する」衝突に遭遇します）。

<details>
<summary>🔍 参考解答</summary>

```rust
関数 二倍話(話: 可変参照 文字列型) {
    宣言 複製 = 話.クローン();
    話.文字列追加(&複製);
}

関数 主関数() {
    宣言 可変 スローガン = 文字列型::から("頑張れ");
    二倍話(可変参照 スローガン);
    表示行!("{}", スローガン);
}
// 预期输出: 頑張れ頑張れ
```

出力：`頑張れ頑張れ`

（`話.文字列追加(話)` と直接書くと借用の衝突：片方で `話` を可変借用しながら、もう片方で読んでいる。クローンしてから追加すれば回避できます。）

</details>

### 練習三：正誤判定

次の各行のうち、コンパイルが通るのはどれ？

```rust
宣言 可変 ノート = 文字列型::から("数学");
宣言 甲 = &ノート;
宣言 乙 = &ノート;
宣言 丙 = 可変参照 ノート;
```

<details>
<summary>🔍 参考解答</summary>

`甲`、`乙` の二行は問題なし（不変の並行は合法）；`丙` の行は——このままでも **実は通ります** ：`甲`、`乙` はその後一度も使われていないので、寿命はすでに終わり。ここで `甲` や `乙` をあとで使う行を足すと、E0502 が出ます。これが「寿命は最後の使用まで」の実践です。

</details>

## 8.14 よくある質問

**Q：`&文字列型` と第 7 章で出た `文字列参照` は同じもの？**

似た兄弟ですが完全一致ではありません。`&文字列型` は「 `文字列型` への参照」；`文字列参照` は「文字そのものへの借用」。文字列リテラル `"こんにちは"` は `文字列参照` です。両者とも「文字を読み取り専用で見る」ことができ、メソッドはたいてい共通です。第 9 章で区別と変換をきちんとやります。

**Q：なぜ可変借用は二つ持てないの？**

二つとも「私が変えます」と主張したら、変える順番で結果が変わり、データがめちゃくちゃになります。可変借用を一つに限れば、誰が何を変えたかが一目瞭然です。

**Q：借用の検査は実行速度の負担になる？**

なりません。全部コンパイル時に終わっていて、実行時の負担はゼロ。これが Rust の「ゼロコスト安全」です。

**Q：借用ルールをいつも混同する。速記法はある？**

これだけ覚えてください： **「読みは群れで読め、書きは独りで書け、読みと書きは同席せず」** 。

**Q：関数の引数は値渡しと借用、どちらを使うべき？**

経験則—— **見るだけなら `&`、変えるなら `可変参照`、本当に持ち去るなら値渡し** 。整数などの小さな物は値渡しでも構いません（複製は安いので）。

**Q：メソッドの `&自己`、`可変参照 自己` は、この章の `&`、`可変参照` と同じもの？**

完全に同じです。第 6 章のメソッド内の `&自己` は「このメソッドは実体を不変借用する」、`可変参照 自己` は「実体を可変借用する」という意味でした。今なら完全に読み解けたはずです。
