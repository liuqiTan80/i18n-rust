# 第十五章：错误处理

程序不可能永远顺利。文件可能不存在，网络可能断开，用户可能输入了奇怪的东西。

Rust 处理错误的方式和其他语言不同——它不用"异常"（一种特殊的错误处理机制），而是用**类型**来处理错误。错误和正常值一样，都是类型系统的一部分。

---

## 15.1 恐慌——火灾警报

> **生活类比**：`恐慌!` 就像**火灾警报**——一旦触发，整栋楼立刻疏散（程序立刻停止运行）。它用于"不可能恢复"的严重错误。

```rust
函数 主函数() {
    恐慌!("出了大问题！");
}
```

恐慌会打印错误信息，然后终止程序。程序直接停了，后面的代码都不会执行。

### 什么时候用恐慌？

当你确定错误**不可能发生**，但编译器不这么认为时：

```rust
函数 主函数() {
    让 v = 向量![1, 2, 3];
    // v[99] 会恐慌——因为只有 3 个元素，你却要第 100 个
}
```

**为什么要恐慌？** 因为有些错误太严重了，程序没法继续运行。比如你要读一个配置文件，但文件损坏了——程序不知道该怎么继续，不如直接停下来。

---

## 15.2 可恢复错误——天气预报

> **生活类比**：如果 `恐慌!` 是火灾警报，那 `结果` 就是**天气预报**——它告诉你"可能下雨（出错），也可能晴天（成功）"，你根据预报决定带不带伞。

大多数错误不需要程序崩溃，而是需要**优雅处理**。比如文件不存在？那就创建一个新文件。网络超时？那就重试一次。

Rust 用 `结果` 枚举表示可恢复的错误：

```
结果 就像天气预报：

┌────────────────────────┐
│ 成功(返回值)           │  ← 晴天 ☀️
│ 错误(错误信息)         │  ← 下雨 🌧️
└────────────────────────┘
```

### 使用结果

```rust
函数 打开文件(路径: &文本) -> 结果<字符串, 字符串> {
    如果 路径 == "存在.txt" {
        结果::成功("文件内容".转字符串())
    } 否则 {
        结果::错误("文件不存在".转字符串())
    }
}

函数 主函数() {
    匹配 打开文件("存在.txt") {
        结果::成功(内容) => 打印行!("读到：{}", 内容),
        结果::错误(原因) => 打印行!("失败：{}", 原因),
    }

    匹配 打开文件("不存在.txt") {
        结果::成功(内容) => 打印行!("读到：{}", 内容),
        结果::错误(原因) => 打印行!("失败：{}", 原因),
    }
}
```

逐行解释：

- 第 1 行：函数返回类型是 `结果<字符串, 字符串>`——成功时返回字符串（文件内容），失败时也返回字符串（错误信息）
- 第 3 行：文件存在时，返回 `结果::成功(内容)`
- 第 5 行：文件不存在时，返回 `结果::错误(信息)`
- 第 9-12 行：用 `匹配` 处理两种情况——成功就打印内容，失败就打印原因

```
执行流程：

打开文件("存在.txt")
    │
    ├── 成功("文件内容") → 打印"读到：文件内容"
    └── 错误("...")     → 打印"失败：..."

打开文件("不存在.txt")
    │
    ├── 成功(...)       → 不会走到这里
    └── 错误("文件不存在") → 打印"失败：文件不存在"
```

## 15.3 问号运算符——偷懒写法

每次都用 `匹配` 处理错误太麻烦了。Rust 提供了一个快捷方式——**`?`**（问号运算符）：

> **生活类比**：`?` 就像一个**自动检查站**——遇到错误就立刻返回，成功就取出值继续走。你不用每次都写"如果出错就返回，成功就取值"了。

```rust
函数 读取文件(路径: &文本) -> 结果<字符串, 字符串> {
    让 内容 = 打开文件(路径)?;  // 如果失败，直接返回错误
    打印行!("读到 {} 字节", 内容.长度());
    结果::成功(内容)
}
```

逐行解释：

- 第 2 行：**`打开文件(路径)?`** 的意思是：
  - 如果 `打开文件` 返回 `成功(内容)`，就把内容取出来赋给 `内容`
  - 如果返回 `错误(原因)`，就**立刻**把错误返回给调用者
- 第 3-4 行：只有成功时才会执行到这里

```
问号运算符的流程：

打开文件(路径)?
    │
    ├── 成功(内容) → 取出内容，继续往下走 ✅
    └── 错误(原因) → 立刻返回错误，后面的代码不执行 ❌
```

### 问号运算符展开

为了让你理解 `?` 到底做了什么，下面是等价的展开写法：

```rust
// 用 ? 的简洁写法：
函数 读取文件(路径: &文本) -> 结果<字符串, 字符串> {
    让 内容 = 打开文件(路径)?;
    结果::成功(内容)
}

// 不用 ? 的等价写法（更啰嗦）：
函数 读取文件_展开(路径: &文本) -> 结果<字符串, 字符串> {
    让 内容 = 匹配 打开文件(路径) {
        结果::成功(v) => v,           // 成功就取值
        结果::错误(e) => 返回 结果::错误(e),  // 失败就返回
    };
    结果::成功(内容)
}
```

**为什么要用 `?`？** 因为两段代码做的事情完全一样，但 `?` 版本更短更清晰。当你要连续处理多个可能出错的操作时，差别更明显。

### 链式调用

```rust
函数 解析并翻倍(s: &文本) -> 结果<整数, 字符串> {
    让 n = s.解析::<整数>()?;  // 解析失败就返回错误
    结果::成功(n * 2)
}

函数 主函数() {
    打印行!("{:?}", 解析并翻倍("21"));   // 成功(42)
    打印行!("{:?}", 解析并翻倍("abc"));  // 错误(...)
}
```

逐行解释：

- 第 2 行：`s.解析::<整数>()` 尝试把文字转成整数。如果文字不是数字（比如 "abc"），会返回错误
- 第 2 行：`?` 遇到错误就立刻返回
- 第 3 行：只有解析成功时，才会把数字翻倍

## 15.4 常用的结果方法

| 方法 | 作用 | 比喻 |
|------|------|------|
| `.解包()` | 成功时取值，失败时恐慌 | "我确定不会出错，直接打开" |
| `.期望("消息")` | 同上，但恐慌时显示自定义消息 | "我确定不会出错，否则就报这个错" |
| `.取值或(默认值)` | 失败时用默认值 | "出错就用备用的" |
| `.映射(\|x\| ...)` | 变换成功值 | "把成功的东西加工一下" |
| `?` | 失败时提前返回 | "出错就走人" |

### 取值或——用默认值

```rust
函数 主函数() {
    // "42" 能解析成整数
    让 n = "42".解析::<整数>().取值或(0);
    打印行!("{}", n);  // 42

    // "abc" 不能解析，用默认值 0
    让 n = "abc".解析::<整数>().取值或(0);
    打印行!("{}", n);  // 0
}
```

逐行解释：

- 第 3 行：`"42".解析::<整数>()` 返回 `成功(42)`，`.取值或(0)` 取出 42
- 第 7 行：`"abc".解析::<整数>()` 返回 `错误(...)`，`.取值或(0)` 返回默认值 0

## 15.5 自定义错误类型

> **生活类比**：内置的错误类型太笼统了——就像医院只分"病了"和"没病"。自定义错误就像医院分科室——"骨折"、"感冒"、"过敏"，每种情况处理方式不同。

```rust
枚举 我的错误 {
    未找到,
    格式错误(字符串),
    网络错误(整数),
}

函数 处理数据(输入: &文本) -> 结果<整数, 我的错误> {
    如果 输入.是空() {
        返回 结果::错误(我的错误::未找到);
    }
    匹配 输入.解析::<整数>() {
        结果::成功(n) => 结果::成功(n),
        结果::错误(_) => 结果::错误(我的错误::格式错误(输入.转字符串())),
    }
}

函数 主函数() {
    匹配 处理数据("42") {
        结果::成功(n) => 打印行!("结果：{}", n),
        结果::错误(我的错误::未找到) => 打印行!("输入为空"),
        结果::错误(我的错误::格式错误(s)) => 打印行!("格式错误：{}", s),
        结果::错误(我的错误::网络错误(码)) => 打印行!("网络错误码：{}", 码),
    }
}
```

逐行解释：

- 第 1-5 行：用枚举定义三种错误情况——"未找到"、"格式错误"（附带出错的数据）、"网络错误"（附带错误码）
- 第 7 行：函数返回 `结果<整数, 我的错误>`——成功时返回整数，失败时返回自定义错误
- 第 8-9 行：输入为空时，返回"未找到"错误
- 第 10-13 行：尝试解析整数——成功就返回值，失败就返回"格式错误"
- 第 17-21 行：用 `匹配` 针对每种错误做不同的处理

```
自定义错误的好处：

处理数据("42")    → 成功(42)         → 打印结果
处理数据("")      → 错误(未找到)     → 打印"输入为空"
处理数据("abc")   → 错误(格式错误)   → 打印"格式错误：abc"
处理数据(网络断)  → 错误(网络错误)   → 打印"网络错误码：..."

每种错误有不同的处理方式！
```

## 常见错误

### 对结果直接取值

```rust
函数 主函数() {
    让 结果 = "42".解析::<整数>();
    // ❌ 不能直接当普通值用——它是"结果"类型
    // 打印行!("{}", 结果);

    // ✅ 方法一：用匹配
    匹配 结果 {
        结果::成功(n) => 打印行!("{}", n),
        结果::错误(e) => 打印行!("出错了：{}", e),
    }

    // ✅ 方法二：用 .解包()（确定不会出错时）
    打印行!("{}", "42".解析::<整数>().解包());
}
```

### 滥用 .解包()

```rust
// ❌ 生产代码中不要随便用 .解包()
函数 危险() -> 整数 {
    "abc".解析::<整数>().解包()  // 恐慌！因为 "abc" 不是数字
}
// ✅ 修复：用匹配或 ? 优雅处理
```

### 在不该用 ? 的地方用 ?

```rust
// ❌ 主函数返回 ()，不是结果类型
// 函数 主函数() {
//     让 n = "42".解析::<整数>()?;  // 编译器报错！
// }
// ✅ 修复：让函数返回结果类型，或用匹配
```

## 练习题

### 练习 1：安全除法

写一个函数 `安全除法(甲: 整数, 乙: 整数) -> 结果<整数, 字符串>`，除数为零时返回错误。

<details>
<summary>参考答案</summary>

```rust
函数 安全除法(甲: 整数, 乙: 整数) -> 结果<整数, 字符串> {
    如果 乙 == 0 {
        结果::错误("除数不能为零".转字符串())
    } 否则 {
        结果::成功(甲 / 乙)
    }
}

函数 主函数() {
    打印行!("{:?}", 安全除法(10, 3));   // 成功(3)
    打印行!("{:?}", 安全除法(10, 0));   // 错误("除数不能为零")
}
```
</details>

### 练习 2：链式解析

写一个函数 `双倍解析(s: &文本) -> 结果<整数, 字符串>`，把文字解析为整数后乘以 2。

<details>
<summary>参考答案</summary>

```rust
函数 双倍解析(s: &文本) -> 结果<整数, 字符串> {
    让 n = s.解析::<整数>()
        .或_else(|_| 结果::错误(格式化!("无法解析 '{}'", s)))?;
    结果::成功(n * 2)
}

函数 主函数() {
    打印行!("{:?}", 双倍解析("21"));  // 成功(42)
    打印行!("{:?}", 双倍解析("abc")); // 错误("无法解析 'abc'")
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| `恐慌!` | 火灾警报——不可恢复的致命错误 |
| `结果` | 天气预报——可能成功，也可能出错 |
| `?` | 自动检查站——出错就走人，成功就取值 |
| `.解包()` | 简单粗暴取值（出错会恐慌） |
| `.取值或(默认值)` | 出错就用备用的 |
| 自定义错误 | 用枚举分科室，每种错误不同处理 |
