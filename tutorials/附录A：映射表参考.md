# 附录A：映射表参考

本附录列出所有中文 Rust 关键字与标准 Rust 的对应关系。

当你以后需要从中文 Rust 过渡到标准 Rust 时，这张表就是你的"翻译词典"。

---

## A.1 关键字映射

### 定义与控制流

| 中文关键字 | 英文关键字 | 意思是 |
|-----------|-----------|--------|
| `函数` | `fn` | 定义一段代码的"菜谱" |
| `让` | `let` | 创建一个"贴了标签的盒子" |
| `可变` | `mut` | 标记盒子"可以换东西" |
| `常量` | `const` | 永远不变的固定值 |
| `静态` | `static` | 全局共享的固定值 |
| `派生` | `derive` | 让编译器自动实现特征 |
| `如果` | `if` | 看条件决定走哪条路 |
| `如果让` | `if let` | 判断"是不是某一种情况"，是就取出里面的值 |
| `否则` | `else` | 条件不满足时走的路 |
| `匹配` | `match` | 自动售货机——按按钮出对应结果 |
| `循环` | `loop` | 不停重复 |
| `当` | `while` | 条件满足时重复 |
| `当让` | `while let` | 只要还是某一种情况，就一直取出值并重复 |
| `对于` | `for` | 逐个处理 |
| `在` | `in` | 遍历操作符 |
| `中断` | `break` | 跳出循环 |
| `继续` | `continue` | 跳过本次，继续下一次 |
| `返回` | `return` | 结束函数并带回结果 |

### 类型与结构

| 中文关键字 | 英文关键字 | 意思是 |
|-----------|-----------|--------|
| `结构体` | `struct` | 信息登记表——把多个数据打包 |
| `枚举` | `enum` | 售货机按钮——只能选一种 |
| `实现` | `impl` | 为类型添加方法 |
| `特征` | `trait` | 岗位说明书——定义"能做什么" |
| `类型` | `type` | 给类型起别名 |
| `作为` | `as` | 类型转换 |
| `哪里` | `where` | 泛型约束——"在 T 必须满足某些条件的情况下" |

### 模块与可见性

| 中文关键字 | 英文关键字 | 意思是 |
|-----------|-----------|--------|
| `模块` | `mod` | 部门——把代码分门别类 |
| `公开` | `pub` | 对外可见 |
| `使用` | `use` | 引入外部功能 |
| `包` | `crate` | 当前项目/库 |
| `超级` | `super` | 父模块 |
| `自我` | `self` | 自身 |
| `自身` | `Self` | 当前类型 |

### 内存与不安全

| 中文关键字 | 英文关键字 | 意思是 |
|-----------|-----------|--------|
| `移动` | `move` | 把东西彻底送给别人 |
| `引用` | `&` | 借——不拥有，只是借用 |
| `可变引用` | `&mut` | 可修改的借用 |
| `解引用` | `*` | 从"取货单"取出实际数据 |
| `不安全` | `unsafe` | 绕过安全检查的代码块 |
| `外部` | `extern` | 与其他语言交互 |
| `动态` | `dyn` | 运行时才确定类型 |

### 异步

| 中文关键字 | 英文关键字 | 意思是 |
|-----------|-----------|--------|
| `异步` | `async` | 不会立刻完成的操作 |
| `.等待` | `.await` | 等到完成（但不卡住其他人）——注意是**后缀**写法：`操作.等待` |

### 特殊值

| 中文关键字 | 英文关键字 | 意思是 |
|-----------|-----------|--------|
| `真` | `true` | 是 |
| `假` | `false` | 否 |
| `空` | `()` | 没有值 |
| `主函数` | `main` | 程序的入口 |

## A.2 类型映射

| 中文类型 | 英文类型 | 意思是 |
|---------|---------|--------|
| `整数` | `i32` | 有正负的整数（最常用） |
| `微整数` | `i8` | 最小的有符号整数（-128~127） |
| `短整数` | `i16` | 较短的有符号整数 |
| `长整数` | `i64` | 较长的有符号整数 |
| `无符号整数` | `u32` | 没有负号的整数 |
| `无符号微整数` | `u8` | 很小的无符号整数（0~255） |
| `无符号短整数` | `u16` | 较短的无符号整数 |
| `无符号长整数` | `u64` | 较长的无符号整数 |
| `字节` | `u8` | 一个字节（0~255），常用来表示二进制数据 |
| `浮点数` | `f64` | 有小数点的数字（双精度） |
| `单精度浮点数` | `f32` | 精度较低的小数 |
| `布尔` | `bool` | 真或假 |
| `字符` | `char` | 单个字符 |
| `文本` | `str` | 不能修改的文字 |
| `字符串` | `String` | 可以修改的文字 |
| `字符串引用` | `&str` | 文字的"借阅卡"（只读借用） |
| `向量` | `Vec` | 可伸缩的列表 |
| `哈希映射` | `HashMap` | 电话簿——按键查值 |
| `选项` | `Option` | 可能有值，也可能没有 |
| `有些` | `Some` | 有值 |
| `无` | `None` | 没有值 |
| `结果` | `Result` | 操作的结果——成功或失败 |
| `成功` | `Ok` | 操作成功 |
| `错误` | `Err` | 操作失败 |
| `盒子` | `Box` | 堆上数据的取货单 |

## A.3 宏映射

| 中文宏 | 英文宏 | 意思是 |
|--------|--------|--------|
| `宏规则` | `macro_rules` | 声明一个宏——宏的"配方"（注意：声明形式不带感叹号，调用时才带 `!`） |
| `打印行!` | `println!` | 打印一行文字并换行 |
| `打印!` | `print!` | 打印文字不换行 |
| `错误打印行!` | `eprintln!` | 打印错误信息 |
| `错误打印!` | `eprint!` | 打印错误信息不换行 |
| `格式化!` | `format!` | 拼接文字模板 |
| `向量!` | `vec!` | 快速创建向量 |
| `断言!` | `assert!` | 检查条件是否为真 |
| `断言相等!` | `assert_eq!` | 检查两个值是否相等 |
| `断言不等!` | `assert_ne!` | 检查两个值是否不相等 |
| `恐慌!` | `panic!` | 触发致命错误 |
| `待完成!` | `todo!` | 标记还没写完的代码 |
| `未实现!` | `unimplemented!` | 标记还没实现的代码 |
| `不可达!` | `unreachable!` | 标记不会执行到的代码 |
| `写入格式化行!` | `writeln!` | 写入文件并换行 |
| `写入格式化!` | `write!` | 写入文件 |
| `包含文件!` | `include!` | 把文件内容当代码包含进来 |
| `包含字符串!` | `include_str!` | 把文件内容当文字包含进来 |
| `包含字节!` | `include_bytes!` | 把文件内容当字节包含进来 |
| `字符串化!` | `stringify!` | 把代码变成文字 |
| `配置` | `cfg` | 条件编译——只在满足条件时才编译这段代码（常见写法：`#[配置(测试)]`） |

---

> 📚 **完整映射**：本表只列常用条目，完整映射见项目源码 `crates/engine/lang-packs/zh/` 目录下的 `keywords.toml`（宏映射表中的宏名在实际使用时**可省略感叹号**，rzc 会自动补全，如 `打印行("你好")` 会自动补成 `println!("你好")`；但 `宏规则` 声明形式本身不带感叹号）。
