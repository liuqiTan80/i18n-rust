# 第十四章：集合类型

前面学过了数组——固定大小的"一排储物柜"。但生活中，你经常需要更灵活的数据容器。

比如：
- 不确定会有多少个元素，需要能自动伸缩
- 需要通过名字快速找到对应的东西（像查电话簿一样）

这就是**集合**的用处。

---

## 14.1 向量——可伸缩的收纳盒

> **生活类比**：数组是固定大小的储物柜——买了几格就只能放几格的东西。**向量**则是一个**可伸缩的收纳盒**——东西多了它会自动变大，东西少了会自动缩小。

### 为什么需要向量？

数组创建后大小就固定了。但很多时候你不知道会有多少数据——用户可能输入 3 个名字，也可能输入 300 个。向量就是为这种情况准备的。

### 创建向量

> ✨ **小提示**：`向量::新建()` 里的 `::` 和第九章讲的关联函数一样——"向向量类型要一个制造函数"。`新建()` 就是"造一个空向量"。

```rust
函数 主函数() {
    // 创建一个空的整数向量（类型标注：向量<整数>）
    让 可变 数字们: 向量<整数> = 向量::新建();

    // 往里面添加数字
    数字们.推(1);
    数字们.推(2);
    数字们.推(3);

    打印行!("{:?}", 数字们);  // [1, 2, 3]

    // 也可以用快捷写法创建（向量! 是宏，不用自己加感叹号）
    让 水果们 = 向量!["苹果", "香蕉", "橘子"];
    打印行!("{:?}", 水果们);  // ["苹果", "香蕉", "橘子"]
}
```

> ✨ **宏调用提示**：在中文 Rust 中，所有宏名后面**不需要手动加感叹号**。工具会自动帮你补上。你只需要写 `向量("苹果", "香蕉")` 即可。当然，写了 `!` 也没错。

逐行解释：

- 第 3 行：**`向量::新建()`** 创建一个空向量——`可变` 是因为后面要往里加东西。`: 向量<整数>` 是类型标注："这个向量装的是整数"
- 第 6-8 行：**.推(值)** 往向量末尾添加一个元素——收纳盒多放一件东西
- 第 10 行：`{:?}` 用调试格式打印整个向量（第五章讲过）
- 第 13 行：**`向量![...]`** 是快捷写法——直接创建并填入初始值。如果不想写类型标注，编译器会从 `[1, 2, 3]` 自动推断出这是"装整数的向量"

```
向量的伸缩过程：

初始：[]              ← 空的
推(1)：[1]            ← 变大了
推(2)：[1, 2]         ← 又变大了
推(3)：[1, 2, 3]      ← 继续变大
```

### 访问向量中的元素

```rust
函数 主函数() {
    让 水果们 = 向量!["苹果", "香蕉", "橘子"];

    // 方法一：用索引访问（和数组一样）
    打印行!("第一个：{}", 水果们[0]);  // 苹果
    打印行!("第二个：{}", 水果们[1]);  // 香蕉

    // 方法二：用 .获取() 安全访问
    匹配 水果们.获取(2) {
        有些(水果) => 打印行!("第三个：{}", 水果),  // 橘子
        无 => 打印行!("不存在"),
    }

    // 方法三：遍历所有元素
    对于 水果 在 &水果们 {
        打印行!("我有：{}", 水果);
    }
}
```

逐行解释：

- 第 4-5 行：用 `[0]`、`[1]` 访问——和数组一样。但如果索引超出范围，程序会崩溃
- 第 8-11 行：**`.获取(2)`** 是安全的访问方式。如果索引不存在，不会崩溃，而是返回 `无`
- 第 14-16 行：遍历向量中的每个元素

```
两种访问方式的区别：

水果们[99]      → 💥 程序崩溃！（索引不存在）
水果们.获取(99) → 返回 无（安全，不会崩溃）
```

### 修改向量

```rust
函数 主函数() {
    让 可变 购物车 = 向量!["苹果", "香蕉"];

    // 添加
    购物车.推("橘子");
    打印行!("{:?}", 购物车);  // ["苹果", "香蕉", "橘子"]

    // 删除最后一个
    购物车.弹出();
    打印行!("{:?}", 购物车);  // ["苹果", "香蕉"]

    // 删除指定位置
    购物车.移除(0);
    打印行!("{:?}", 购物车);  // ["香蕉"]

    // 查看长度
    打印行!("购物车有 {} 件商品", 购物车.长度());
}
```

逐行解释：

- 第 4 行：`.推()` 在末尾添加
- 第 8 行：`.弹出()` 删除并返回最后一个元素
- 第 12 行：`.移除(0)` 删除第 0 个元素，后面的元素自动往前补
- 第 16 行：`.长度()` 查看有多少个元素

## 14.2 哈希映射——电话簿

> **生活类比**：向量像一排储物柜，你得知道柜子的编号（索引）才能找到东西。**哈希映射**则像一本**电话簿**——你通过名字（键）找到电话号码（值），不用记编号。

```
哈希映射（电话簿）：

┌────────────────────────────┐
│  键（名字）  │  值（电话）  │
├──────────────┼─────────────┤
│  小明        │  1234567    │
│  小红        │  7654321    │
│  小刚        │  1112222    │
└────────────────────────────┘

查找：告诉我"小明"→ 找到 1234567
不用记"小明在第几行"，直接按名字查
```

### 创建哈希映射

```rust
使用 标准库::集合::哈希映射;

函数 主函数() {
    // 创建一个空的哈希映射（类型标注：键和值都是文字引用）
    让 可变 电话簿: 哈希映射<&文本, &文本> = 哈希映射::新建();

    // 添加联系人
    电话簿.插入("小明", "1234567");
    电话簿.插入("小红", "7654321");
    电话簿.插入("小刚", "1112222");

    打印行!("{:?}", 电话簿);
}
```

逐行解释：

- 第 1 行：先引入哈希映射——标准库的"集合"工具箱里的"哈希映射"。**`标准库` 是 `std`（标准库）的中文名，`集合` 是 `collections` 模块**
- 第 5 行：**`哈希映射<&文本, &文本>`** 类型标注：尖括号里两个类型，第一个是**键**的类型（名字），第二个是**值**的类型（电话号）
- 第 6 行：**`哈希映射::新建()`** 创建空的哈希映射
- 第 9-11 行：**.插入(键, 值)** 添加一对"键-值"关系
- 第 13 行：打印整个映射

### 查找

```rust
使用 标准库::集合::哈希映射;

函数 主函数() {
    让 可变 电话簿 = 哈希映射::新建();
    电话簿.插入("小明", "1234567");
    电话簿.插入("小红", "7654321");

    // 查找小明
    匹配 电话簿.获取("小明") {
        有些(电话) => 打印行!("小明的电话：{}", 电话),
        无 => 打印行!("查无此人"),
    }

    // 查找不存在的人
    匹配 电话簿.获取("小李") {
        有些(电话) => 打印行!("电话：{}", 电话),
        无 => 打印行!("查无此人"),  // 会走这里
    }
}
```

逐行解释：

- 第 9 行：**`.获取("小明")`** 通过键（名字）查找值（电话）。返回的是 `有些(值)` 或 `无`
- 第 10-11 行：如果找到了，打印电话
- 第 15-18 行：查找不存在的人，返回 `无`

> ✨ **小提示**：`.获取()` 返回 `选项`（第十章讲过：快递箱）——所以必须用 `匹配` 拆开箱子，看看里面是 `有些(值)` 还是 `无`。

```
查找过程：

电话簿.获取("小明")
    │
    ├── "小明" 在电话簿里？
    │   ├── 是 → 有些("1234567")  ✅
    │   └── 否 → 无              ❌
```

### 修改和删除

```rust
使用 标准库::集合::哈希映射;

函数 主函数() {
    让 可变 成绩表 = 哈希映射::新建();
    成绩表.插入("小明", 90);
    成绩表.插入("小红", 85);

    // 修改（覆盖原来的值）
    成绩表.插入("小明", 95);
    打印行!("小明新成绩：{}", 成绩表.获取("小明").解包());  // 95

    // 删除
    成绩表.移除("小红");
    打印行!("小红还在？{}", 成绩表.包含键("小红"));  // 假

    // 遍历
    对于 (名字, 成绩) 在 &成绩表 {
        打印行!("{}：{}分", 名字, 成绩);
    }
}
```

逐行解释：

- 第 9 行：`.插入()` 如果键已存在，会**覆盖**旧值
- 第 12 行：**`.解包()`** 的意思是"我确定有值，直接取出来"——如果取不到，程序会恐慌（第十五章会详细讲）。这里刚插入过"小明"，所以肯定有值
- 第 13 行：`.移除()` 删除一个键值对
- 第 14 行：`.包含键()` 检查某个键是否存在，返回布尔值
- 第 17-19 行：遍历所有键值对。**`&成绩表`** 表示"借来看一遍，不拿走"——所以循环里拿到的是 (键, 值) 的引用

## 14.3 切片——窗口

> **生活类比**：切片就像在一段文字上放一个**窗口**——你只能看到窗口里的那部分，但文字本身还在那里。窗口不能比文字本身活得更久。

在第三章你已经见过切片了。这里再复习一下：

```rust
函数 主函数() {
    让 水果们 = 向量!["苹果", "香蕉", "橘子", "葡萄", "西瓜"];

    // 取第 1 到第 3 个元素（不含第 3 个）
    让 窗口 = &水果们[1..3];
    打印行!("{:?}", 窗口);  // ["香蕉", "橘子"]

    // 字符串切片
    让 文字 = "你好世界";
    让 前半 = &文字[0..6];  // 前 6 个字节 = 前 2 个汉字（每个汉字 3 字节）
    打印行!("{}", 前半);  // 你好
}
```

> ⚠️ **警告**：字符串切片按**字节**算，不按"第几个字"算。`[0..2]` 会切在"你"（占 3 字节）的中间，程序一运行就崩溃（第八章详细讲过）。所以中文切片要么是 3 的倍数，要么改用 `.逐字符()` 遍历。

切片不拥有数据——它只是"看"数据的一部分。就像窗口不拥有窗外的风景，你只是通过窗口看到一部分。

## 常见错误

### 向量越界

```rust
函数 主函数() {
    让 v = 向量![1, 2, 3];
    // 打印行!("{}", v[99]);  // ❌ 索引越界，程序崩溃！

    // ✅ 用 .获取() 安全访问
    匹配 v.获取(99) {
        有些(值) => 打印行!("{}", 值),
        无 => 打印行!("索引不存在"),
    }
}
```

### 忘记引入哈希映射

```rust
// ❌ 忘记引入
// 让 m = 哈希映射::新建();  // 编译器不认识"哈希映射"

// ✅ 先引入
使用 标准库::集合::哈希映射;
让 m = 哈希映射::新建();
```

### 在向量中混放不同类型

```rust
函数 主函数() {
    // ❌ 向量里只能放同一种类型
    // 让 v = 向量![1, "你好", 3.14];

    // ✅ 用枚举可以放"同一种分类下的不同情况"
    枚举 数值 {
        整数(整数),
        文字(字符串),
        浮点(浮点数),
    }
    让 v = 向量![数值::整数(1), 数值::文字("你好".转字符串()), 数值::浮点(3.14)];
}
```

## 练习题

### 练习 1：向量统计

写一个程序，用向量存储一组成绩，计算平均分。

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 成绩 = 向量![90, 85, 78, 92, 88];
    让 可变 总分 = 0;

    对于 成绩 在 &成绩 {
        总分 += *成绩;  // *成绩：把借来的成绩取出来再加
    }

    让 平均 = 总分 作为 浮点数 / 成绩.长度() 作为 浮点数;
    打印行!("平均分：{}", 平均);  // 86.6
}
```

> ✨ **小提示**：`对于 成绩 在 &成绩` 里，循环拿到的 `成绩` 是"借来的"（引用）。`*成绩` 中的 `*` 是解引用——把借来的成绩**取出来**变成真正的数字，才能加到 `总分` 上（第七章讲过）。
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| 向量 | 可伸缩的收纳盒——元素个数不固定 |
| `.推()` / `.弹出()` | 添加 / 删除末尾元素 |
| `.获取()` | 安全访问——越界不会崩溃 |
| 哈希映射 | 电话簿——通过名字（键）找电话（值） |
| `.插入()` / `.获取()` / `.移除()` | 添加 / 查找 / 删除 |
| 切片 | 窗口——只看数据的一部分 |
