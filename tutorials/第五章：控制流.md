# 第五章：控制流

前三章的程序都是"从头到尾一条直线"地执行。这一章，程序学会三样本领：**做选择**、**重复干活**、**按情况分发**。

---

## 5.0 学习目标

读完这一章，你将能够：

1. 用 `如果 / 否则` 让程序根据条件走不同的路。
2. 用比较符号和逻辑符号组合出复杂条件。
3. 用 `匹配` 把一个值的各种可能情况一次列全。
4. 用 `循环`、`当`、`对于…在` 让程序重复做事，并用 `中断`、`继续` 控制节奏。

---

## 5.1 程序的"脚印"

到目前为止，你写的程序执行起来像这样——一行接一行，从上到下：

```
第1行 → 第2行 → 第3行 → 结束
```

这叫**顺序执行**。但真实生活不是直线的：

- **如果**下雨，就带伞；**否则**，戴帽子。→ 这是**选择**。
- 绕操场跑 5 圈。→ 这是**重复**。
- 看红灯停、绿灯行、黄灯慢。→ 这是**按情况分发**。

> 📖 **控制流**：控制程序"执行脚步"的语句统称。英文 control flow。本章的 `如果`、`匹配`、`循环`、`当`、`对于` 都是控制流语句。

---

## 5.2 如果 / 否则：岔路口

### 最简单的选择：如果

```rust
函数 主函数() {
    让 温度 = 32;
    如果 温度 > 30 {
        打印行!("好热，吃冰棍！");
    }
    打印行!("程序结束");
}
```

逐行解释：

- 第 3 行：`如果 温度 > 30 {` —— 检查"温度大于 30"这个说法是真是假。为真，就执行花括号里的内容；为假，就跳过整个花括号。
- 条件为真（32 确实大于 30），所以打印"好热，吃冰棍！"。
- 最后一行不在花括号里，无论如何都会执行。

运行结果：

```
好热，吃冰棍！
程序结束
```

> 📖 **条件**：一个结果为真或假的判断句，比如 `温度 > 30`。`如果` 后面必须跟一个条件。

> ⚠️ **小心**：条件**不能**用圆括号包起来。`如果 (温度 > 30)` 是别的语言的写法，Rust 会报错。直接写 `如果 温度 > 30`。

### 两条路：如果 / 否则

> 📖 **`否则`**：关键字，英文原名 else。意思是"条件不成立就走这边"。

```rust
函数 主函数() {
    让 温度 = 15;
    如果 温度 > 30 {
        打印行!("吃冰棍");
    } 否则 {
        打印行!("穿外套");
    }
}
```

温度 15 不大于 30，条件为假，走 `否则` 那条路：

```
穿外套
```

> ⚠️ **小心**：`否则` 必须紧挨着前一个花括号，写成 `} 否则 {`。它们之间只隔空格，不能换行后单独写 `否则`。

### 多条路：否则如果

两条路不够？用 `否则 如果` 接更多条件：

```rust
函数 主函数() {
    让 温度 = 25;
    如果 温度 > 30 {
        打印行!("很热");
    } 否则 如果 温度 > 20 {
        打印行!("舒服");
    } 否则 如果 温度 > 10 {
        打印行!("有点凉");
    } 否则 {
        打印行!("冷");
    }
}
```

执行规则像**过安检门**：从上往下一个一个检查，**第一个**为真的门进去后，后面的门全部不看。

- 25 > 30？假。往下。
- 25 > 20？真！进去，打印"舒服"。后面全部跳过。

```
舒服
```

> 💡 **比喻**：`否则 如果` 链就像自动售货机的按钮——从上往下按，第一个亮起来的按钮生效，之后就不管了。

### 岔路口里还有岔路口：嵌套

`如果` 里面可以再套 `如果`：

```rust
函数 主函数() {
    让 完成作业 = 真;
    让 天气好 = 真;
    如果 完成作业 {
        如果 天气好 {
            打印行!("出去玩！");
        } 否则 {
            打印行!("在家看书");
        }
    } 否则 {
        打印行!("先写作业");
    }
}
```

输出：`出去玩！`。嵌套可以用，但套太多会让人头晕，一般不超过两层。

## 5.3 比较与逻辑：把条件写复杂

### 六个比较符号

| 符号 | 读法 | 例子 | 结果 |
|---|---|---|---|
| `==` | 等于 | `5 == 5` | 真 |
| `!=` | 不等于 | `5 != 3` | 真 |
| `>` | 大于 | `5 > 3` | 真 |
| `<` | 小于 | `5 < 3` | 假 |
| `>=` | 大于或等于 | `5 >= 5` | 真 |
| `<=` | 小于或等于 | `5 <= 4` | 假 |

> ⚠️ **小心**：判断"相等"用**两个**等号 `==`。一个等号 `=` 是赋值（放东西进盒子），第三章讲过。写错会很麻烦：`如果 分数 = 90` 会报错。

> ⚠️ **小心**：两边类型要一样。`5 == 5.0` 会报错——整数和小数不能直接比。

### 三个逻辑符号

把几个条件拼在一起，要用逻辑符号。**它们是符号，不是中文词**：

| 符号 | 读法 | 意思 | 生活例子 |
|---|---|---|---|
| `&&` | 而且 | 两边都真才真 | 作业做完**而且**天气好，才出去玩 |
| `\|\|` | 或者 | 至少一边真就真 | 坐公交**或者**坐地铁，都能到 |
| `!` | 非（取反） | 真变假，假变真 | **不**下雨 |

```rust
函数 主函数() {
    让 完成作业 = 真;
    让 天气好 = 假;

    如果 完成作业 && 天气好 {
        打印行!("出去玩");        // 不会打印：天气好是假
    }
    如果 完成作业 || 天气好 {
        打印行!("至少满足一个");   // 会打印：完成作业是真
    }
    如果 !天气好 {
        打印行!("天气不好");       // 会打印：假取反是真
    }
}
```

运行结果：

```
至少满足一个
天气不好
```

> ⚠️ **小心**：`&&` 和 `||` 必须用英文符号写。写中文"而且"会报错。键盘位置：`&&` 是 `Shift+7` 两次；`||` 是回车键上方那个竖线键 `Shift+\` 两次。

> ✨ **小提示**：`&&` 有个偷懒本领——左边为假时，右边根本不看（反正结果已定）。比如 `如果 盘子 != 0 && 总数 / 盘子 > 5`，盘子是 0 时不会真的去除，避免了"除以零"的事故。

## 5.4 惊喜：如果 能当一个"值"来用

Rust 有个别处少见的神奇本领：`如果` 整个结构可以**算出一个值**，直接装进盒子。

```rust
函数 主函数() {
    让 分数 = 87;
    让 等级 = 如果 分数 >= 90 { "优" } 否则 如果 分数 >= 80 { "良" } 否则 { "中" };
    打印行!("等级：{}", 等级);
}
```

运行结果：`等级：良`。

第 3 行的意思：根据分数算出一个结果，把结果装进 `等级`。分数 87，走到第二个分支，所以 `等级` 装的是 `"良"`。

这背后是两个重要概念：

> 📖 **语句**：做一件事、不产生值的指令，结尾有分号。比如 `打印行!(...);`。
>
> 📖 **表达式**：能算出一个值的写法。数字 `5` 是表达式（值是 5），`2 + 3` 是表达式（值是 5），连 `如果...{...} 否则 {...}` 也是表达式。

> ⚠️ **小心：分号会"吞掉"值！** 花括号里最后一行**不加分号**，那一行的值就是整个 `如果` 的值；加了分号就变成语句，值没了：

```rust
让 等级 = 如果 分数 >= 90 { "优"; } 否则 { "中"; };   // ❌ 报错！
```

报错大意：期望得到文字，实际得到"空"。因为分号把 `"优"` 吞了，花括号里什么都没剩下。

规则一句话：**想让花括号交出值，最后一行别加分号。**

> 💡 **比喻**：表达式像"回答问题的答案"，语句像"做完一个动作"。你问 `如果`："结果是什么？"它把花括号里最后一行（不带分号）递给你。

## 5.5 匹配：自动售货机

一个值有很多种可能，每种可能做不同的事？用 `匹配`。

> 📖 **`匹配`**：关键字，英文原名 匹配。拿一个值去对照一张清单，命中哪一条就执行哪一条。

```rust
函数 主函数() {
    让 名次 = 2;
    匹配 名次 {
        1 => 打印行!("金牌"),
        2 | 3 => 打印行!("领奖台"),
        _ => 打印行!("继续加油"),
    }
}
```

逐行解释：

- `匹配 名次 {`：拿 `名次` 的值去对照下面的清单。
- `1 => 打印行!("金牌"),`：如果值是 1，执行箭头后面的内容。每一条叫一个**匹配臂**。
- `2 | 3 => ...`：竖线 `|` 读作"或"，值等于 2 或 3 都命中这条。
- `_ => ...`：下划线 `_` 是"其余所有"的意思，兜底用。

名次是 2，输出：

```
领奖台
```

> 📖 **通配符**：这里的 `_`。意思是"不管是什么，剩下全归我"。英文 wildcard。

> 📖 **穷尽**：`匹配` 的清单必须把**所有可能**都覆盖——要么一条条列全，要么用 `_` 兜底。漏了一种可能，编译器会报错。这是 Rust 逼你"想周全"的设计。

### 匹配也能算值

`匹配` 和 `如果` 一样是表达式：

```rust
让 分数 = 95;
让 等级 = 匹配 分数 {
    90..=100 => "优秀",
    80..=89 => "良好",
    70..=79 => "中等",
    60..=69 => "及格",
    _ => "不及格",
};
```

> 📖 `90..=100`：范围写法，`..=` 表示**两头都包含**（90 到 100 都算）。还记得切片的 `..` 含头不含尾吗？加了等号就是"连尾巴也要"。

> ⚠️ **小心**：每个匹配臂的箭头 `=>`（等于号+大于号）不要写成 `->`。

## 5.6 循环：不知疲倦的重复

### 循环：最"蛮"的重复

> 📖 **`循环`**：关键字，英文原名 循环。让一段代码一遍一遍重复执行，直到你喊停。

```rust
函数 主函数() {
    让 可变 次数 = 0;
    循环 {
        次数 += 1;
        打印行!("第{}遍", 次数);
        如果 次数 == 3 {
            中断;
        }
    }
    打印行!("收工");
}
```

运行结果：

```
第1遍
第2遍
第3遍
收工
```

> 📖 **`中断`**：关键字，英文原名 break。意思是"立刻跳出循环"。没有它，`循环` 会跑到天荒地老（无限循环）。

### 循环还能交出返回值

`中断` 后面可以跟一个值，把它交给整个循环：

```rust
函数 主函数() {
    让 可变 计数 = 0;
    让 翻倍结果 = 循环 {
        计数 += 1;
        如果 计数 == 5 {
            中断 计数 * 2;
        }
    };
    打印行!("翻倍结果：{}", 翻倍结果);
}
```

逐行解释：循环一遍遍加 1，数到 5 时喊"中断"，同时把 `5 * 2 = 10` 抛出来。整个 `循环 {...}` 的值就是 10，装进 `翻倍结果`。

运行结果：`翻倍结果：10`。

## 5.7 当：满足条件才重复

> 📖 **`当`**：关键字，英文原名 当。"当条件为真时，一直重复"。条件变假，自动停止。

```rust
函数 主函数() {
    让 可变 倒数 = 3;
    当 倒数 > 0 {
        打印行!("倒数{}", 倒数);
        倒数 -= 1;
    }
    打印行!("出发！");
}
```

运行结果：

```
倒数3
倒数2
倒数1
出发！
```

执行过程：每遍开始前先检查 `倒数 > 0`。3、2、1 都成立；减到 0 时条件为假，循环自动结束。

> ⚠️ **小心**：千万别忘了在循环里让条件"走向假"（这里是 `倒数 -= 1`）。忘了的话条件永远为真，程序就卡死在循环里，这叫**死循环**。卡住了按 `Ctrl+C`（按住 Ctrl 再按 C）可以强制停止程序。

`当` 和 `循环+如果+中断` 能做的事差不多，但 `当` 把条件写在开头，一眼就能看出"什么时候停"，更清楚。

## 5.8 对于…在：排队一个个来

数好了次数、或者有一排东西要逐个处理，用 `对于…在` 最省事。

> 📖 **`对于`** 和 **`在`**：关键字，英文原名 for 和 in。读作"对于每一个 X，在某个集合里，依次做某事"。

### 配范围用：重复固定次数

```rust
函数 主函数() {
    对于 编号 在 1..6 {
        打印行!("第{}圈", 编号);
    }
}
```

`1..6` 是范围：**1 到 5**（还记得吗？`..` 含头不含尾）。想包含 6 就写 `1..=6`。

运行结果：

```
第1圈
第2圈
第3圈
第4圈
第5圈
```

### 配数组用：逐个处理每个元素

还记得第四章手动加五个分数要写五行吗？现在一行搞定：

```rust
函数 主函数() {
    让 分数 = [88, 95, 76, 90, 82];
    让 可变 总和 = 0;
    对于 单科 在 分数 {
        总和 += 单科;
    }
    打印行!("总分：{}", 总和);
}
```

`对于 单科 在 分数` 的意思是：从数组里依次取出每个元素，每次放进 `单科` 这个盒子，然后执行一遍循环体。五遍之后，总和 = 431。

```
总分：431
```

> 💡 **比喻**：`对于…在` 就像老师点名——"对于名单上的每个同学，在教室里，依次答到"。循环自动进行，你不用数数。

## 5.9 继续：这一轮跳过，下一轮接着来

> 📖 **`继续`**：关键字，英文原名 continue。意思是"本轮剩下的不做了，直接开始下一轮"。

```rust
函数 主函数() {
    让 分数表 = [88, 55, 76, 42, 90];
    让 可变 及格数 = 0;
    对于 分 在 分数表 {
        如果 分 < 60 {
            继续;      // 不及格的直接跳过，不数
        }
        及格数 += 1;
    }
    打印行!("及格{}门", 及格数);
}
```

遇到 55 和 42 时，`继续` 让程序跳过后面的计数，直接进入下一个分数。输出：

```
及格3门
```

`中断` vs `继续`：`中断` 是"整个循环不玩了"，`继续` 是"这一轮不玩了，下一轮继续"。

## 5.10 完整示例：成绩评级程序

### 完整代码

```rust
函数 主函数() {
    让 分数表 = [88, 55, 76, 42, 90];

    // 第一遍：给每个分数评级
    打印行!("--- 评级 ---");
    对于 单科分数 在 分数表 {
        让 等级 = 匹配 单科分数 {
            90..=100 => "优秀",
            80..=89 => "良好",
            70..=79 => "中等",
            60..=69 => "及格",
            _ => "不及格",
        };
        打印行!("{}分 → {}", 单科分数, 等级);
    }

    // 第二遍：统计及格人数和最高分
    让 可变 及格数 = 0;
    让 可变 最高分 = 分数表[0];
    对于 单科分数 在 分数表 {
        如果 单科分数 >= 60 {
            及格数 += 1;
        }
        如果 单科分数 > 最高分 {
            最高分 = 单科分数;
        }
    }
    打印行!("及格{}人，最高分{}", 及格数, 最高分);
}
```

### 逐行解释

- 第 2 行：五门课的分数装进数组。
- 第 5 行：`对于…在` 逐个取出分数，每次装进 `单科分数`。
- 第 6–12 行：`匹配` 当评级器。范围模式 `90..=100` 两头都包含；`_` 兜底剩下的一切（0–59）。整个 `匹配` 算出一个文字值装进 `等级`。
- 第 13 行：打印"分数 → 等级"。
- 第 17 行：及格计数器，可变，从 0 开始。
- 第 18 行：先假设第一个分数最高，之后逐个比。
- 第 19–26 行：再走一遍数组——够 60 就计数；比当前最高还高就更新最高分。
- 第 27 行：打印统计结果。

### 运行结果

```
--- 评级 ---
88分 → 良好
55分 → 不及格
76分 → 中等
42分 → 不及格
90分 → 优秀
及格3人，最高分90
```

## 5.11 常见错误与解决

### 错误 1：匹配漏情况（穷尽性报错）

```rust
匹配 名次 {
    1 => 打印行!("金牌"),
    2 => 打印行!("银牌"),
}   // ❌ 名次还可能是 3、4、5……
```

报错大意：匹配不够穷尽，没覆盖所有可能。

**修法**：把剩下的情况补上，或加 `_ => ...` 兜底。

### 错误 2：分号吞掉了 如果 的值

```rust
让 等级 = 如果 分数 >= 90 { "优"; } 否则 { "中"; };   // ❌
```

**修法**：花括号里最后一行去掉分号：`{ "优" } 否则 { "中" }`。

### 错误 3：逻辑词写成中文

```rust
如果 甲 而且 乙 { }   // ❌ 报错：expected `{`, found `而且`
```

**修法**：用符号：`如果 甲 && 乙`。

### 错误 4：判断相等只写一个等号

```rust
如果 分数 = 90 { }   // ❌ 这是赋值，会报错
```

**修法**：`如果 分数 == 90`。口诀：**判断用双等，装东西用单等**。

### 错误 5：死循环

`当` 或 `循环` 忘了让条件变化，程序转个不停。

**修法**：检查循环体里有没有"推动条件走向结束"的语句；卡住了按 `Ctrl+C`。

| 条件 | 结果为真或假的判断句 |
| 通配符 | `_`，匹配里的"其余所有" |
| 继续 | 跳过本轮进入下一轮，关键字 continue |
| 死循环 | 永远停不下来的循环 |
| 表达式 | 能算出值的写法 |
| 循环 | 无限重复直到中断，关键字 循环 |
| 匹配 | 按值的各种情况分发，关键字 匹配 |
| 嵌套 | 控制流结构里再套控制流结构 |
| 如果 | 按条件选择执行路径，关键字 if |
| 否则 | 条件不成立时走的路，关键字 else |
| 语句 | 做动作、不产生值的指令 |
| 中断 | 立刻跳出循环，关键字 break |

### 练习 1：温度建议

写程序：温度 28。大于 30 打印"热"，大于 20 打印"舒适"，否则打印"冷"。

创建变量 `星期编号` = 3，用 `匹配` 输出对应的"星期一"到"星期日"，其余编号输出"无效"。

        1 => "星期一",

        3 => "星期三",
        4 => "星期四",
        5 => "星期五",

### 练习 5（挑战）：找错

这段代码想打印 1、2、3 就停，但有问题。找出来：

```rust
函数 主函数() {
    让 可变 数 = 1;
    循环 {
        打印行!("{}", 数);
        数 += 1;
    }
}
```

<details>
<summary>参考答案</summary>

循环里没有 `中断`，会永远跑下去（死循环）。补上条件：

```rust
函数 主函数() {
    让 可变 数 = 1;
    循环 {
        打印行!("{}", 数);
        数 += 1;
        如果 数 > 3 {
            中断;
        }
    }
}
```

或者干脆改用 `对于 数 在 1..=3 { 打印行!("{}", 数); }`，更简单。

</details>

## 5.14 常见问题（FAQ）

**问 1：如果、匹配、循环，怎么知道该用哪个？**

答：看场景。**两条路/几条路选一条** → `如果`；**一个值对应很多种情况** → `匹配`；**重复做事** → 循环。循环三兄弟里：次数或集合是现成的用 `对于`；停止条件复杂的用 `当`；需要"循环交出值"的用 `循环`。

**问 2：`1..6` 为什么偏偏不含 6？**

答：这样有个大好处：范围的长度正好是 `6 - 1 = 5`，而且上一个的终点正好是下一个的起点（`1..4` 接 `4..6`，不重不漏）。切片、分页都靠这个性质。习惯了就很顺。

**问 3：`匹配` 里能写复杂条件吗？**

答：初学阶段把 `匹配` 用于"值等于什么/落在哪段"，把复杂条件交给 `如果`。`匹配` 还有更高级的本领（拆开枚举里的数据），第十一章见。

**问 4：循环里能再套循环吗？**

答：能。比如打印九九乘法表就是两层循环：外层管行，内层管列。本章练习里你可以挑战一下。

**问 5：我的程序卡住了，怀疑死循环，怎么办？**

答：在命令行窗口按 `Ctrl+C` 强制停止。然后检查循环体：有没有让条件"走向结束"的语句？`当` 的条件最终会变假吗？

**问 6：`如果` 不写 `否则`，条件为假时会发生什么？**

答：什么都不会发生，直接跳过花括号继续往下走。`否则` 是可选的。

## 本章小结

1. **`如果 / 否则 如果 / 否则`**：条件的岔路口；条件不带括号。
2. **逻辑符号**：`&&`（而且）、`||`（或者）、`!`（非）——必须用符号，不能写中文词。
3. **表达式**：`如果` 和 `匹配` 都能算出值；花括号最后一行不加分号才有值。
4. **`匹配`**：自动售货机，`|` 合并情况，`..=` 范围，`_` 兜底，必须穷尽。
5. **循环三兄弟**：`循环`（能返回值）、`当`（条件开头）、`对于…在`（逐个来）。
6. **`中断`** 跳出整个循环，**`继续`** 只跳过本轮。
