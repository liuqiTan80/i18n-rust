# 第六章：函数与方法

## 6.0 学习目标

读完这一章，你将能够：

1. 用**魔法盒子**的说法解释什么是函数；
2. 自己写出**带参数、带返回值**的函数；
3. 分清**语句**和**表达式**，知道分号怎么"吞掉"返回值；
4. 用 **`返回`** 关键字提前交出结果；
5. 写出**递归**函数（函数自己调用自己）；
6. 用 **`实现`** 块给类型挂上**方法**，认识 **`自我`** 的三种写法；
7. 认识**空类型** `()`。

---

## 6.1 函数是什么：魔法盒子

💡 **比喻**：想象你有一个**魔法盒子**：

- 你从上面的**入口**塞进去一些东西（这叫**参数**）；
- 盒子内部自己忙活一阵（这叫**函数体**）；
- 然后从下面的**出口**吐出结果（这叫**返回值**）。

比如一个"榨汁机"盒子：塞进去苹果（参数），它内部榨汁（函数体），吐出苹果汁（返回值）。

📖 **函数（Function）**：一段起了名字、可以反复使用的指令。对应英文关键字 `函数`（function 的缩写）。中文写作 **`函数`**。

你其实早就用过函数了——`打印行!` 就是一个（它是特殊的"宏"函数，第一章讲过感叹号的区别）。现在你要学的是**自己造盒子**。

### 为什么需要函数

假设你要在三个地方打印同样的五角星图案。不学函数，你得把同样的代码**抄三遍**。抄三遍有两个坏处：

1. **累**：写三遍浪费时间；
2. **难改**：想改图案，得改三个地方，漏一个就出 bug（程序里的错误，读作"巴格"）。

有了函数：把图案代码装进一个盒子里，起个名字。要用时**喊名字**就行，改的时候只改盒子里那一份。

> 💡 **一句话**：函数 = 起名字的代码块，用来**少抄代码、方便修改**。

---

## 6.2 最简单的函数

先看一个没有参数、没有返回值的函数：

```rust
函数 打招呼() {
    打印行!("你好！");
}

函数 主函数() {
    打招呼();
    打招呼();
}
```

运行结果：

```
你好！
你好！
```

拆开看五个部分：

| 部分 | 例子 | 说明 |
|---|---|---|
| `函数` 关键字 | `函数` | 告诉计算机"这里要造一个盒子" |
| 函数名 | `打招呼` | 盒子的名字，你随便起（建议用动词） |
| 小括号 | `()` | 装参数的地方，现在没有参数，所以是空的 |
| 花括号 | `{ }` | 盒子的"身体"，里面是具体指令 |
| 调用 | `打招呼();` | 喊名字 + 小括号 + 分号，让盒子干活 |

> ⚠️ **小心**：**定义**函数（造盒子）和**调用**函数（让盒子干活）是两回事。只写定义不调用，盒子永远不会开工。程序的入口永远是 `主函数`。

---

## 6.3 参数：往盒子里塞东西

📖 **参数（Parameter）**：函数接收的输入。定义函数时写的名字。
📖 **实参（Argument）**：调用函数时真正塞进去的值。

💡 **比喻**：榨汁机的说明书上写"请放入**水果**"——"水果"是**参数**（一个占位的名字）；你真的放进去的那个苹果，是**实参**。

### 一个参数

```rust
函数 问候(名字: 字符串引用) {
    打印行!("你好，{}！", 名字);
}

函数 主函数() {
    问候("小明");
    问候("小红");
}
```

> 📖 **字符串引用**：借来的文字，写作 `"..."` 这样的字面量。第九章详细讲，现在只要知道：双引号里的文字就属于这个类型。

参数写法是 **`名字: 类型`**——Rust 要求每个参数**必须写类型**，一个都不能省。

### 多个参数

多个参数用**逗号**隔开：

```rust
函数 求和(甲: 整数, 乙: 整数) -> 整数 {
    甲 + 乙
}

函数 主函数() {
    让 和 = 求和(3, 7);
    打印行!("和：{}", 和);
}
```

输出：`和：10`

注意新符号 **`->`**（减号 + 大于号，意思是"指向"）：

- `-> 整数` 表示"这个盒子吐出来的东西是整数"；
- 不写 `->` 的函数不吐出东西（严格说吐出"空"，6.8 节讲）。

> ⚠️ **小心**：调用时实参的**个数和顺序**必须和参数对上。`求和(3)` 少一个、`求和("三", 7)` 类型不对，都会报错。

---

## 6.4 返回值：盒子吐出结果

有三种方式让函数交出结果。

### 方式一：末尾表达式（不带分号）

函数体里**最后一行**如果是一个**表达式**（能算出一个值的东西），而且**结尾没有分号**，它的值就是返回值：

```rust
函数 平方(数: 整数) -> 整数 {
    数 * 数
}
```

`数 * 数` 没有分号 → 它的值被"吐出去"。

### 方式二：`返回` 关键字

📖 **返回（返回）**：立刻把值交出去，函数到此结束。对应英文 `返回`。

```rust
函数 最大值(甲: 整数, 乙: 整数) -> 整数 {
    如果 甲 > 乙 {
        返回 甲;
    }
    乙
}
```

读法："如果甲更大，**立刻**交出甲；否则走到最后一行，交出乙。"

`返回` 常用于**提前结束**：条件满足就交答案走人，不用再往下执行。

### 方式三：块表达式

第五章讲过：花括号块本身也是表达式，它最后一行（不带分号）的值就是块的值：

```rust
让 和值 = {
    让 甲 = 10;
    让 乙 = 20;
    甲 + 乙
};
打印行!("块的值：{}", 和值);
```

输出：`块的值：30`

### ⚠️ 分号陷阱：最常见的错误

给 `数 * 数` **加上分号**会怎样？

```rust
函数 平方(数: 整数) -> 整数 {
    数 * 数;    // ❌ 多了分号
}
```

报错：**E0308 类型不匹配：期望 `整数`，实际得到 `()`**。

💡 **比喻**：分号像一个"句号"，它把一句话变成了"陈述"（做完就完了，什么都没留下）。函数承诺吐出整数，结果只吐出一句"陈述"（空值 `()`），编译器当然要抗议。

**记口诀**：**要返回值，最后一行不写分号。**

## 6.5 函数写在哪里都行

`主函数` 可以写在最前面，被调用的函数写在后面：

```rust
函数 主函数() {
    打印行!("面积：{}", 长方形面积(3, 4));
}

函数 长方形面积(长: 整数, 宽: 整数) -> 整数 {
    长 * 宽
}
```

输出：`面积：12`

和第五章的 `如果`、`循环` 不一样——它们必须在使用前出现，但**函数不讲究顺序**。编译器会先把所有函数"登记一遍"，之后随便调用。

---

## 6.6 递归：函数调用自己

📖 **递归（Recursion）**：函数在自己的身体里调用自己。

💡 **比喻**：你问爸爸"这件事怎么办"，爸爸说"去问爷爷"，爷爷说"去问太爷爷"……一直问到最老的长辈，他直接给出答案，再一层层传回来。

经典例子：**阶乘**。5 的阶乘 = 5 × 4 × 3 × 2 × 1 = 120。规律是：`阶乘(5) = 5 × 阶乘(4)`，一路推下去，推到 `阶乘(1) = 1` 为止。

```rust
函数 阶乘(数: 整数) -> 整数 {
    如果 数 <= 1 {
        返回 1;          // 到底了，直接给答案
    }
    数 * 阶乘(数 - 1)    // 还没到底，问"小一号的自己"
}

函数 主函数() {
    打印行!("阶乘：{}", 阶乘(5));
}
```

输出：`阶乘：120`

> ⚠️ **小心**：递归必须有**停止条件**（上面是 `数 <= 1`）。没有停止条件的递归会永远问下去，程序崩溃。就像故事里没人给出答案，询问永远传不完。

> ✨ 递归现在看不懂没关系，循环（第五章）能解决大部分问题，递归是"高级写法"，后面章节还会再遇到。

## 6.7 方法：挂在类型上的函数

前面造的盒子是"通用"的，谁的都能用。还有一种盒子**专属于某样东西**——比如"遥控器"专属于"电视机"。这种挂在某个类型上的函数叫**方法**。

📖 **方法（Method）**：挂在某个类型上的函数。就像某个玩具自带的功能按钮：按钮装在玩具身上，按之前得先有这个玩具。

第十章才正式学**结构体**（自定义类型）。这里先借用一个最简单的结构体看方法长什么样：

```rust
结构体 记分牌 {
    分数: 整数,
    次数: 整数,
}
```

（读法：记分牌这种类型有两项数据——分数和次数。）

### `实现` 块

给类型挂方法要用 **`实现`**（英文 `实现`，implement 的缩写，"实现、给……装上功能"的意思）：

```rust
实现 记分牌 {
    // 关联函数：没有 自我 参数，用来"造一个新的"
    函数 创建() -> 记分牌 {
        记分牌 { 分数: 0, 次数: 0 }
    }

    // 方法：&自我 = 只读借用自己
    函数 平均分(&自我) -> 整数 {
        如果 自我.次数 == 0 {
            返回 0;
        }
        自我.分数 / 自我.次数
    }

    // 方法：可变引用 自我 = 可以修改自己
    函数 记录一局(可变引用 自我, 得分: 整数) {
        自我.分数 = 自我.分数 + 得分;
        自我.次数 = 自我.次数 + 1;
    }
}
```

出现了两个新词：

📖 **自我（自我）**：方法里代表"这个实例自己"的参数。`平均分` 是记分牌的方法，方法里的 `自我` 就是"调用它的那个记分牌"。

📖 **关联函数**：写在 `实现` 块里、但**没有 `自我` 参数**的函数。它不针对某个已有实例，常用来**造新实例**，所以也叫**构造器**。

### `自我` 的三种写法

| 写法 | 意思 | 比喻 |
|---|---|---|
| `&自我` | 只读借用，看看不改 | 借同学的书翻一翻，不涂写 |
| `可变引用 自我` | 可变借用，可以修改 | 借同学的笔写字，用完还 |
| `自我` | 直接拿走（消耗） | 吃掉这个苹果，苹果没了 |

第七章《所有权》、第八章《引用与借用》会详细解释"借用"。现在只需要记：**方法要改自己就用 `可变引用 自我`，只读就用 `&自我`**。

### 调用方法：点号

```rust
让 可变 牌 = 记分牌::创建();   // 关联函数用 双冒号 调用
牌.记录一局(80);                 // 方法用 点号 调用
牌.记录一局(95);
牌.记录一局(76);
打印行!("平均分：{}", 牌.平均分());
```

输出：`平均分：83`

两种调用方式对比：

| 调用方式 | 例子 | 用于 |
|---|---|---|
| `类型::名字()` | `记分牌::创建()` | 关联函数（没有 `自我`） |
| `实例.名字()` | `牌.平均分()` | 方法（第一个参数是 `自我`，调用时自动传入） |

> ⚠️ **命名提醒**：给关联函数起名时，**不要**用标准库已经占用的映射词（比如 `新建`——它是标准库 `new` 的中文映射，定义处和调用处的转换可能不一致，导致"找不到方法"的错误）。自己起个新名字（比如 `创建`）最保险。同理，变量名避开 `结果`（它是 `结果` 类型的映射词）。

## 6.8 空类型：什么都不吐

不写 `->` 的函数，其实吐出一种特殊的值：**空**，写作 `()`。

📖 **空（单元类型，Unit）**：什么都不装的类型，写作 `()`。英文叫 unit。它存在的意义是"让所有函数都有返回值"，你几乎不用管它。

```rust
让 什么也没有: 空 = ();
打印行!("空：{:?}", 什么也没有);
```

输出：`空：()`

还记得 6.4 的分号陷阱吗？报错说"期望 `整数`，实际得到 `()`"——那个 `()` 就是空。现在你知道它是谁了。

## 6.9 完整示例：三科成绩分析器

把本章学的全部用上：普通函数（参数、返回值、提前返回）+ 结构体方法（关联函数、`&自我`、`可变引用 自我`）：

```rust
// ============ 普通函数 ============

// 求和：两个参数，一个返回值
函数 求和(甲: 整数, 乙: 整数) -> 整数 {
    甲 + 乙
}

// 求较大值：用到提前 返回
函数 最大值(甲: 整数, 乙: 整数) -> 整数 {
    如果 甲 > 乙 {
        返回 甲;
    }
    乙
}

// 打招呼：没有返回值，用到第五章的循环
函数 打招呼(次数: 整数) {
    对于 _ 在 0..次数 {
        打印行!("你好！");
    }
}

// ============ 结构体 + 方法 ============

结构体 记分牌 {
    分数: 整数,
    次数: 整数,
}

实现 记分牌 {
    // 关联函数：造一个全新的记分牌
    函数 创建() -> 记分牌 {
        记分牌 { 分数: 0, 次数: 0 }
    }

    // 方法：记录一局成绩（要改自己，所以用 可变引用 自我）
    函数 记录一局(可变引用 自我, 得分: 整数) {
        自我.分数 = 自我.分数 + 得分;
        自我.次数 = 自我.次数 + 1;
    }

    // 方法：算平均分（只读自己，用 &自我）
    函数 平均分(&自我) -> 整数 {
        如果 自我.次数 == 0 {
            返回 0;    // 一局没玩，直接返回 0 防止除以 0
        }
        自我.分数 / 自我.次数
    }

    // 方法：汇报战况（方法里还能调用别的方法）
    函数 汇报(&自我) {
        打印行!("共{}局，总分{}，平均分{}", 自我.次数, 自我.分数, 自我.平均分());
    }
}

// ============ 主函数 ============

函数 主函数() {
    打印行!("和：{}", 求和(3, 7));
    打印行!("较大的是：{}", 最大值(5, 9));
    打招呼(2);

    让 可变 牌 = 记分牌::创建();
    牌.记录一局(80);
    牌.记录一局(95);
    牌.记录一局(76);
    牌.汇报();
    打印行!("平均分是：{}", 牌.平均分());

    让 什么也没有: 空 = ();
    打印行!("空：{:?}", 什么也没有);
}
```

---

## 6.10 逐行解释

- **第 4–6 行**：`求和` 接收两个整数，最后一行 `甲 + 乙` 不带分号，值就是返回值。
- **第 9–14 行**：`最大值` 里 `如果 甲 > 乙` 成立就 `返回 甲;` 提前结束；不成立就往下走，交出 `乙`。
- **第 17–21 行**：`打招呼` 没有 `->`，返回空。`对于 _ 在 0..次数`：`_`（下划线）表示"循环变量用不上，懒得起名"。
- **第 25–28 行**：定义结构体 `记分牌`，两个字段都是整数。
- **第 32–34 行**：关联函数 `创建` 没有 `自我` 参数，返回一个"0 分 0 局"的新记分牌。
- **第 37–40 行**：`记录一局` 用 `可变引用 自我`，因为要修改自己的两个字段。
- **第 43–48 行**：`平均分` 先防除以 0（`次数 == 0` 就提前返回 0），再做整数除法。
- **第 51–53 行**：`汇报` 里 `自我.平均分()` 展示**方法调用方法**。
- **第 58–60 行**：三个普通函数的调用。
- **第 62 行**：`让 可变`——后面要调 `可变引用 自我` 方法修它，必须可变。
- **第 63–65 行**：点号调用方法，记分牌内部数据被更新。
- **第 68 行**：空类型 `()` 的演示，用 `{:?}` 调试格式打印。

## 6.11 运行结果

把上面代码存进 `src/主函数.zh`，运行（命令行 `rzc run src/主函数.zh` 或右上角 ▶）：

```
和：10
较大的是：9
你好！
你好！
共3局，总分251，平均分83
平均分是：83
空：()
```

逐行对答案：

- `和：10`：3 + 7；
- `较大的是：9`：5 和 9 里较大的是 9；
- 两行 `你好！`：`打招呼(2)` 循环两次；
- `共3局，总分251，平均分83`：80 + 95 + 76 = 251，251 ÷ 3 = 83（整数除法舍掉小数，251 ÷ 3 = 83.66… 取 83）；
- `空：()`：空类型打印出来就是一对括号。

## 6.12 常见错误与解决

### 错误一：E0308 返回类型不匹配

```rust
函数 翻倍(数: 整数) -> 整数 {
    "变大了"
}
```

报错：

```
错误[E0308]: 类型不匹配：期望 `整数`，实际得到 `字符串引用`
```

**原因**：承诺返回整数，实际交出文字。**解决**：检查返回值和 `->` 后面的类型是否一致。多半是两种情况：类型写错了，或者多写/漏写了分号（见下一个）。

### 错误二：忘记去掉分号（E0308 + `()`）

```rust
函数 平方(数: 整数) -> 整数 {
    数 * 数;
}
```

报错：`类型不匹配：期望 整数，实际得到 ()`。

**解决**：把返回值那一行的分号删掉。看到错误里有 `()`，优先怀疑分号。

### 错误三：参数漏写类型

```rust
函数 平方(数) -> 整数 {   // ❌ 数后面缺 ": 整数"
```

报错提示缺少类型标注。**解决**：Rust 里**函数参数必须写类型**，一个都不能省：`(数: 整数)`。

### 错误四：调用时参数对不上

`求和(3)` 少给一个实参、`求和(3, 7, 9)` 多给，都报错"该函数接收 N 个参数"。**解决**：数一数定义处有几个参数，调用时给几个。

### 错误五：除以零不会报错？

`平均分` 里如果不防 `次数 == 0`，第一次运行程序就会**恐慌**（运行时崩溃，第三章见过）。Rust 的整数除以 0 是运行时错误，编译器不提前拦。**解决**：除法前永远先检查除数是不是 0。

### 错误六：方法找不到（命名撞车）

用 `新建` 当自己的函数名，可能出现"定义处没被转换、调用处被转成 `new`"的错位，报 E0599"类型上找不到该方法"。**解决**：自定义函数/变量名避开标准库映射词（`新建`、`结果` 等），起自己的名字。

## 6.15 常见问题（FAQ）

**问：函数名可以起中文吗？有什么限制？**

答：可以，本书全用中文函数名。建议用**动词开头**（`求和`、`打印`、`检查`），一看就知道盒子干什么。别用映射表里已有的词（如 `新建`、`打印行`）当自己的函数名，会撞车。

**问：函数和第五章学的 `匹配`、`循环` 有什么关系？**

答：`如果`、`循环` 是**控制流**（决定执行顺序），函数是**组织代码**（把指令打包起名）。函数身体里可以随便用控制流，反过来控制流里也可以调用函数。它们是配合关系。

**问：一个函数能返回多个值吗？**

答：严格说只能返回**一个**值。但可以把多个值装进**元组**（第四章学过）一起返回，比如 `-> (整数, 整数)`。第十章学结构体后，还可以返回一个结构体。

**问：`返回` 和最后一行表达式，用哪个更好？**

答：简单计算用最后一行表达式（更简洁）；需要**提前走人**（满足条件就不往下算了）时用 `返回`。两种都很常用。

**问：方法里的 `&自我` 那个 `&` 是什么意思？**

答：是"借用"的意思——方法只是**借用**这个实例看一看/改一改，用完还回去，不把它吃掉。第七章《所有权》、第八章《引用与借用》会用整整两章讲清楚。现在先当固定写法记住。

**问：递归和循环哪个快？**

答：大多数情况下循环更快也更省内存。递归胜在代码优雅、好理解（尤其是"层层嵌套"的问题）。初学阶段两种都会写即可，不用纠结性能。

**问：为什么 `打招呼` 里用 `_` 当循环变量？**

答：`_` 表示"这个值我用不上"。循环要重复 `次数` 遍，但不关心当前是第几遍，就用 `_` 跳过起名。这也避免了"定义了变量却没使用"的警告。

你造的盒子越来越多了，但盒子里装的数据有个大问题：**谁拥有它？用完谁收拾？**
