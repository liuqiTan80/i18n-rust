# 第二十二章：闭包与迭代器

## 22.0 学习目标

读完这一章，你将能够：

1. 用**随身小工具**比喻解释闭包；
2. 写出 **`|参数| 表达式`** 形式的闭包；
3. 解释闭包如何**抓住**周围的数据（包括可变数据）；
4. 用**流水线**比喻解释迭代器；
5. 熟练使用 **`迭代`→`过滤`→`映射`→`收集`** 四段链；
6. 用 `求和` 等快捷方法一步到位；
7. 理解迭代器的**懒惰**特性（不收集不开工）。

---

## 22.1 闭包：揣兜里的匿名函数

第六章教过定义函数——得起名字、住在文件顶层。可有时你只想**现场造一个小工具**，用完就扔：

```rust
让 加 = |甲: 整数, 乙: 整数| 甲 + 乙;
打印行!("加(2,3) = {}", 加(2, 3));   // 5
```

📖 **闭包**：没有名字的函数，可以存在变量里、当参数传、从函数返回。语法：

```
|参数1, 参数2| 表达式        // 参数类型常可省略
|| 表达式                    // 无参数
```

💡 **比喻**：正式函数像**挂牌门店**（有地址有招牌）；闭包像**揣兜里的瑞士军刀**——不挂牌，掏出来就用。

第二十章的 `线程::生成(|| { ... })` 传的就是闭包——把一段活打包交给线程。

## 22.2 闭包的背包：抓住环境

闭包最神奇的本事：能**抓住**定义它时周围的数据。

```rust
让 可变 计数 = 0;
让 可变 加一 = || 计数 = 计数 + 1;
加一();
加一();
加一();
打印行!("计数 = {}", 计数);   // 3
```

`加一` 这个闭包没写参数、没写捕获清单，却自动"看见"并抓住了旁边的 `计数`。

💡 **比喻**：闭包出门带个**背包**，把它需要的周围变量装进去随身带走。要改背包里的东西，闭包本身也得 `可变`（`让 可变 加一`）。

三种抓法（编译器自动挑，知道有即可）：借来读（&）、借来改（可变引用）、整个搬走（移动，见第二十章）。

## 22.3 迭代器：数据流水线

处理一串数据，笨办法是 `对于` 循环一步步挪。迭代器给出**流水线**写法：

💡 **比喻**：工厂流水线——原料（数据）上去，每站干一件事（筛选、加工），末端装箱（收集）。**每个站不碰原料本身，只描述加工规则**。

```
数列.迭代().过滤(...).映射(...).收集()
   原料     筛选站     加工站     装箱
```

📖 **迭代器**：一个"知道下一个元素是谁"的传送装置。`迭代()` 把数组、向量变成传送带。

## 22.4 四段链逐站拆解

```rust
让 数列 = [1, 2, 3, 4, 5, 6];
让 偶数放大: 向量<整数> = 数列.迭代()
    .过滤(|数| **数 % 2 == 0)
    .映射(|数| *数 * 10)
    .收集();
```

| 站 | 方法 | 干什么 | 产物 |
|---|---|---|---|
| 原料 | `迭代()` | 把数组上传送带 | 1,2,3,4,5,6 |
| 筛选 | `过滤(闭包)` | 留下闭包说"真"的 | 2,4,6 |
| 加工 | `映射(闭包)` | 每个过一遍变换 | 20,40,60 |
| 装箱 | `收集()` | 传送带末端收成容器 | 向量 [20,40,60] |

两个细节：

- **拆包**：迭代器递出来的是**借用**——`过滤` 的闭包收到 `&&数`（两层借用），要 `**数` 才能得到数本身；`映射` 的闭包收到 `&数`（一层），要 `*数`。
- **`: 向量<整数>`**：`收集` 能装进好几种容器，必须说清楚要哪种——这是新手最常忘的标注。

## 22.5 快捷终点：不止收集

流水线的终点不一定装箱：

```rust
让 总和: 整数 = 数列.迭代().求和();   // 21
```

`求和` 直接把传送带上的数加起来。（`总和: 整数` 的标注同理——说清结果类型。）还有 `折叠`（累加器自定义起点和规则）等，用到再查。

## 22.6 懒惰的流水线

迭代器是**懒惰**的：

```rust
让 带 = 数列.迭代().映射(|数| *数 * 10);
// 此时什么都没算！
```

只搭链子不干活，**直到遇到终点站**（`收集`、`求和`、`对于` 循环消费）才真正启动。好处：中间不产生临时容器，省内存、方便优化。

## 22.7 闭包的三种特征与自定义迭代器

### 闭包的三种特征：借、改、搬

22.2 节说过，闭包抓周围数据有三种抓法：借来读、借来改、整个搬走。每种抓法对应一种**特征**——闭包类型自动实现、你只管用的"能力证书"：

| 抓法 | 特征 | 例子 |
|---|---|---|
| 只读借用 | 函数特征（`Fn`） | 读旁边的变量 |
| 可变借用 | 可变函数特征（`FnMut`） | 修改旁边的变量 |
| 搬走所有权 | 一次性函数特征（`FnOnce`） | 把旁边的值整个拿走 |

三个特征按"改造程度"递增：**函数特征**能反复调用；**可变函数特征**也能反复调用，但每次可能改背包；**一次性函数特征**只能调用一次——东西都搬走了，第二次没得搬。代码里写作 `闭包特征`、`可变闭包特征`、`消费闭包特征`。三个例子一次看齐：

```rust
函数 主函数() {
    // 闭包特征：只读捕获，随叫随到
    让 倍数 = 3;
    让 翻倍 = |数: 整数| 数 * 倍数;
    打印行!("闭包特征 翻倍：{}", 翻倍(4));
    打印行!("闭包特征 再叫一次：{}", 翻倍(5));

    // 可变闭包特征：想改背包里的东西
    让 可变 累计 = 0;
    让 可变 加账 = || 累计 = 累计 + 1;
    加账();
    加账();
    加账();
    打印行!("可变闭包特征 累计：{}", 累计);

    // 消费闭包特征：把东西整个搬走，用完即焚
    让 袋子 = 字符串::从("宝贝");
    让 搬走 = 移动 || 袋子;
    打印行!("消费闭包特征 搬走：{}", 搬走());
}
```

输出：

```
闭包特征 翻倍：12
闭包特征 再叫一次：15
可变闭包特征 累计：3
消费闭包特征 搬走：宝贝
```

怎么选？**默认选函数特征**（最宽松、可反复用）；闭包里要改捕获的变量，编译器会要求可变函数特征（把闭包变量标上 `可变` 就行）；要带着值跑路（比如送进线程，第二十章），用 `移动` + 一次性函数特征。多数时候你**不用管**具体是哪个——编译器自动判定，报错时再对症下药。

### 收闭包的函数怎么写

函数想接收闭包当参数，就在签名里写特征约束（第十二章的泛型语法）：

```rust
// 收一个"只读闭包"，用 闭包特征 约束：能反复调用
函数 唱两遍<动作>(歌: 动作, 词: 整数)
哪里
    动作: 闭包特征(整数) -> 整数,
{
    打印行!("第一遍：{}", 歌(词));
    打印行!("第二遍：{}", 歌(词));
}

函数 主函数() {
    让 倍数 = 10;
    唱两遍(|数| 数 * 倍数, 4);
}
```

输出：

```
第一遍：40
第二遍：40
```

`动作: 闭包特征(整数) -> 整数` 读作："`动作` 必须是这样的闭包：吃一个整数、吐一个整数，而且对捕获的东西只借来读（函数特征）"——所以 `唱两遍` 里能放心调用两次。约束改成可变函数特征、一次性函数特征同理，要求逐步放宽（一次性函数特征最松，但只能用一次）。

### 手写迭代器：实现迭代器特征

22.3 节的流水线都建立在 `迭代()` 上。想让自己定义的类型也上流水线？实现 `迭代器特征` 就行。

📖 **迭代器特征**：只需要实现一个方法 `下一个`——"下一次给我什么"，返回 `选项`：`有值(值)` 表示还有货，`无` 表示传送带空了（`下一个` 会转译成 `next`）。

写一个每次 +2 的计数迭代器：从 1 开始，到 9 为止，每步跳 2：

```rust
结构体 步进 {
    当前: 整数,
    终点: 整数,
}

实现 迭代器特征 对于 步进 {
    类型 货物类型 = 整数;

    函数 下一个(&可变 自我) -> 选项<整数> {
        如果 自我.当前 > 自我.终点 {
            返回 无;
        }
        让 本次 = 自我.当前;
        自我.当前 = 自我.当前 + 2;
        有值(本次)
    }
}

函数 主函数() {
    让 数列: 向量<整数> = 步进 { 当前: 1, 终点: 9 }.收集();
    打印行!("收集：{:?}", 数列);

    让 总和: 整数 = 步进 { 当前: 1, 终点: 9 }.求和();
    打印行!("求和：{}", 总和);
}
```

输出：

```
收集：[1, 3, 5, 7, 9]
求和：25
```

三个要点：

- **`类型 货物类型 = 整数`**：声明"这条传送带上运的是整数"。`货物类型` 会转译成 `Item`——它是 `迭代器特征` 里写死的关联类型名，换个名字编译器不认；
- **`下一个(&可变 自我)`**：每次调用推进一格，所以要可变借用（`下一个` 转译成 `next`）；
- 实现完 `迭代器特征`，`收集`、`求和`、`过滤`、`映射` 整条流水线**全部免费解锁**——传送带一接上，全套加工站跟着能用。

### 常见错误：一次性函数特征只能调一次

把值搬进闭包后，再调第二次就报"值已移动"：

```rust
函数 主函数() {
    让 袋子 = 字符串::从("宝贝");
    让 搬走 = 移动 || 袋子;
    打印行!("{}", 搬走());
    打印行!("{}", 搬走());
}
```

```
错误[E0382]: 使用已移动的值：搬走
 --> 第 5 行: 第二次调用 搬走()
```

**解决**：认清它是"一次性"的。想反复用，别 `移动`，让闭包只借用（函数特征 / 可变函数特征）。

## 22.8 完整示例：数据加工车间

闭包三态 + 迭代器两链，合在一个车间里：

```rust
函数 主函数() {
    // —— 匿名函数，揣兜里随叫随到 ——
    让 加 = |甲: 整数, 乙: 整数| 甲 + 乙;
    打印行!("加(2,3) = {}", 加(2, 3));

    // —— 闭包抓住周围的可变数据 ——
    让 可变 计数 = 0;
    让 可变 加一 = || 计数 = 计数 + 1;
    加一();
    加一();
    加一();
    打印行!("计数 = {}", 计数);

    // —— 迭代器流水线：过滤偶数、放大十倍 ——
    让 数列 = [1, 2, 3, 4, 5, 6];
    让 偶数放大: 向量<整数> = 数列.迭代()
        .过滤(|数| **数 % 2 == 0)
        .映射(|数| *数 * 10)
        .收集();
    打印行!("流水线产物：{:?}", 偶数放大);

    // —— 直接求和 ——
    让 总和: 整数 = 数列.迭代().求和();
    打印行!("总和 = {}", 总和);
}
```

## 22.9 逐行解释

- **第 3–4 行**：现场造 `加`——两个参数、一条表达式，随造随用。
- **第 7–12 行**：`加一` 抓住可变的 `计数`；三次调用，背包里的值真真切切涨了三次。两个 `可变` 缺一不可。
- **第 15–19 行**：四段链一气呵成。`过滤` 里的 `**数 % 2 == 0` 是"偶数判断"；`%` 是取余运算。
- **第 22–23 行**：`求和` 终点站，不装箱直接出总数。

## 22.10 运行结果

```
加(2,3) = 5
计数 = 3
流水线产物：[20, 40, 60]
总和 = 21
```

`{:?}` 打印向量时会带上方括号——这是调试格式（第十章见过）。

## 22.11 常见错误与解决

### 错误一：`收集` 不知道往哪装

```
错误：无法推断收集的目标类型
```

**解决**：给变量标类型 `让 结果: 向量<整数> = ...`。

### 错误二：闭包里改不了捕获的变量

```
错误：无法借用为可变
```

**解决**：被捕获的变量和闭包变量**都要** `可变`。

### 错误三：比较借用和数值

`|数| 数 % 2 == 0` 报类型不匹配——`数` 是借用。**解决**：`*数 % 2 == 0`，或先 `映射(|数| *数)` 统一拆包。

### 错误四：链子搭了没干活

光 `.迭代().映射(...)` 没输出？迭代器是懒惰的。**解决**：补上终点站（`收集`/`求和`/循环消费）。

## 22.14 常见问题

**问：闭包和普通函数有啥实质区别？**

答：闭包能**捕获环境**，函数不能；闭包不用起名、随写随用；闭包的类型是编译器生成的独一份，写不出来也读不出来（所以第二十章用 `移动 ||` 直接传给线程，而不是先存变量传来传去）。

**问：迭代器链比 `对于` 循环快吗？**

答：通常不慢，常常更快。编译器能把链子优化成紧凑的循环，还省了中间容器。可读性上，链式写法把"做什么"一行说清。

**问：`过滤` 里为什么是借用？**

答：因为 `迭代()` 借出元素（不搬走）。想搬走元素用 `消费迭代`——之后原集合就空了，慎用。

**问：链子能写多长？**

答：随便长，每站只是"加一道工序"，不多占内存。实战中三四站最常见；太长就拆开起名，保持可读。

**问：`映射` 和第十章结构体的方法重名吗？**

答：不冲突。方法按类型归属找——`数列.迭代()` 后的对象才认 `映射`；你在结构体上定义叫 `映射` 的方法也互不干扰。

**问：闭包能当函数参数传来传去吗？**

答：能，这正是它的大用途（`线程::生成`、`过滤`、`映射` 都在收闭包）。签名里接收闭包要用特征约束（`实现 Fn(整数) -> 整数`），等你需要时再学不迟。
