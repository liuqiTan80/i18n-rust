# 第二章：用好 VS Code 扩展

## 2.0 学习目标

读完这一章，你将能够：

1. 解释 **扩展（Extension）** 是什么、为什么需要它；
2. 安装并验证 **i18n-rust** 扩展；
3. 用**按钮、右键菜单、快捷键**三种方式运行和检查程序，不再手动敲命令行；
4. 用**一键格式化**让乱糟糟的代码自动排整齐；
5. 用**代码片段**（输入两个字就展开成一段代码）提高打字速度；
6. 知道扩展提供的全部命令，哪些现在用、哪些以后再学。

> ✨ 这一章不需要新知识，只需要动手点鼠标。每个小节都有"动手试试"，跟着做一遍就学会了。

---

## 2.1 扩展是什么

### 空白笔记本 + 贴纸

📖 **VS Code**（第一章讲过）是一个**代码编辑器**——写代码的地方。

💡 **比喻**：刚装好的 VS Code 像一个**崭新的空白笔记本**。它什么都能写，但什么都不认识：你写中文代码，它只当是普通文字，不会给你上色，不会帮你运行，不会帮你检查错误。

**扩展（Extension）** 就是给笔记本贴上的**功能贴纸**。每贴一张贴纸，笔记本就多会一种本事：

- 贴上"中文 Rust"贴纸 → 笔记本认识 `.zh` 文件，会给中文关键字**上色**；
- 这张贴纸还自带**运行按钮**、**格式化功能**、**代码补全**……

我们这本书用的贴纸叫 **i18n-rust**（"i18n" 是 "internationalization（国际化）" 的缩写，意思是"让软件会说各种语言"；"rust" 就是我们学的这门语言）。

> 📖 **扩展（Extension）**：给 VS Code 增加功能的插件。英文 extension，"延伸、扩展"的意思。

### 它到底能帮我做什么

先给你看完整清单，后面一节一个地学：

| 能力            | 一句话说明                           | 哪一节学 |
|-----------------|-------------------------------------|----------|
| 语法高亮        | 中文关键字变成彩色，一眼看出结构       | 2.3      |
| 运行按钮        | 点一下 ▶ 就运行，不用敲命令           | 2.4     |
| 类型检查按钮    | 点一下就检查错误                      | 2.4     |
| 一键格式化      | 乱代码自动排整齐                      | 2.5    |
| 代码片段        | 打"主函数"三个字，Tab 一按展开整段代码 | 2.6    |
| 全角符号自动修正 | 中文括号自动变英文括号                | 2.7   |
| 错误波浪线      | 写错的地方立刻画红线提示               | 2.4  |
| 命令面板        | 更多高级命令的入口                     | 2.8 |

## 2.2 安装扩展

### 离线安装（自行下载 .vsix 文件）

📖 **.vsix 文件**：扩展的"安装包"文件，扩展名是 `.vsix`。就像手机 App 的安装包，不用联网也能装。

1. 打开 VS Code；
2. 按 `Ctrl + Shift + P`（Mac：`Cmd + Shift + P`）打开**命令面板**——先记住这个快捷键，2.8 节还要用；

> 📖 **命令面板（Command Palette）**：VS Code 顶部的一个输入框，输入命令名字就能执行命令。像手机的语音助手：你说出想做的事，它就去做。

3. 输入 **`Install from VSIX`**，选择 **"Extensions: Install from VSIX..."**；
4. 在弹出的文件选择窗口里，找到 `.vsix` 文件（例如 `i18n-rust-0.5.0.vsix`），点确定；
5. 安装完成后，右下角会弹出提示。

### 动手试试：验证安装成功

1. 按 `Ctrl + N` 新建一个空白文件；
2. 按 `Ctrl + S` 保存，文件名输入 `test.zh`（**后缀必须是 `.zh`**），保存到你第一章的项目文件夹里；
3. 看 VS Code **窗口的右下角**：应该显示 **`Rust (中文)`**。

![示意]右下角语言标识

如果显示的是 "Plain Text（纯文本）"，说明扩展没装好或者文件后缀不是 `.zh`——点一下那个文字，在弹出的列表里手动选 **Rust (中文)**。

> ✅ 看到 `Rust (中文)`，说明扩展已经在工作了。

## 2.3 语法高亮：代码变彩色

📖 **语法高亮（Syntax Highlighting）**：编辑器把代码里不同作用的词涂成不同颜色。就像课本里**重点词加粗**、**生词标红**，让眼睛一眼分清结构。

### 动手试试

在刚才的 `test.zh` 文件里输入第一章的程序（一个字一个字敲，正好练手）：

```rust
函数 主函数() {
    让 名字 = "小明";
    让 年龄 = 20;
    打印行!("我叫{}，今年{}岁。", 名字, 年龄);
}
```

保存（`Ctrl + S`）后你会发现：

- `函数`、`让` 等**关键字**是一种颜色；
- `"我叫{}，今年{}岁。"` 这样的**字符串**是另一种颜色；
- `20` 这样的**数字**又是另一种颜色。

颜色方案因人而异（取决于你的主题），但**一定不再是清一色的白字**。

> 💡 为什么要上色？代码一长，彩色能帮你一眼看出"哪里是关键字、哪里是文字内容"。就像地图上用绿色标公园、蓝色标河流——比全是灰色的地图好认多了。

### `.zh` 后缀很重要

扩展只认识 `.zh` 后缀的文件。如果文件叫 `test.txt` 或没有后缀，扩展不会上色，也不会有运行按钮。

**检查方法**：看文件名有没有 `.zh` 结尾；看右下角是不是 `Rust (中文)`。

## 2.4 运行程序：三种方式

第一章我们用命令行 `rzc run` 运行程序。有了扩展，有三种更方便的方式。先用第一章的项目（里面有 `src/main.zh`）练习。

### 方式一：右上角 ▶ 按钮

打开 `src/main.zh` 文件，看**编辑器标签页的右上角**：有一个 ▶（三角形播放）按钮和一个 ✓（对勾）按钮。

- 点 ▶ = 运行程序（等于命令行的 `rzc run`）；
- 点 ✓ = 只做类型检查（等于命令行的 `rzc check`）。

运行结果显示在下方的**终端面板**里。

> 📖 **终端面板（Terminal）**：VS Code 底部内嵌的命令行窗口。相当于把第一章的黑色窗口搬进了 VS Code 里面，不用再切换窗口。

### 方式二：右键菜单

在代码区**单击鼠标右键**，弹出菜单里有：

| 菜单项 | 作用 |
|---|---|
| i18n: 运行 (Run) | 运行程序 |
| i18n: 类型检查 (Check) | 检查错误 |
| i18n: 导出为 Rust 源码 | 生成英文 Rust 文件（第一章 1.7 节见过的 eject） |
| 格式化文档 | 下一节讲 |
| i18n: AI 对话 | AI 辅助功能（需要配置，先不用管） |

### 方式三：快捷键（最快）

| 快捷键（Windows/Linux） | Mac | 作用 |
|---|---|---|
| `Ctrl + Shift + R` | `Cmd + Shift + R` | 运行程序 |
| `Ctrl + Shift + C` | `Cmd + Shift + C` | 类型检查 |

> 📖 **快捷键（Shortcut）**：按几个键直接完成操作，不用动鼠标。就像背熟了乘法口诀，算数比列竖式快。

### 动手试试：故意写错，看红线

在代码里故意写：

```rust
让 年龄: 整数 = "二十";
```

保存后，这行下面会出现**红色波浪线**，鼠标放上去还会显示错误原因——和第一章命令行里的 E0308 是同一个错误，只是现在不用运行就能立刻看到。

> 📖 **诊断（Diagnostic）**：编辑器对错误的实时检查结果，用波浪线标出。就像医生体检报告上的红字。

> ⚠️ **注意**：波浪线检查需要扩展在后台启动一个"语言服务器"程序（叫 `i18n-rust-lsp`）。如果打开项目后等了几秒波浪线还不出现，看 2.9 节的排查方法。

### 错误还能点：问题面板

按 `Ctrl + Shift + M` 打开**问题面板**，里面列出当前文件所有的错误和警告。点某一条，光标自动跳到出错位置。

## 2.5 一键格式化：乱代码自动排整齐

📖 **格式化（Format）**：自动调整代码的**缩进和空格**，让排版整齐统一。就像作文写完后老师帮你把段落对齐、标点摆正——**内容一个字不改，只管排版**。

### 动手试试

把 `test.zh` 里的代码故意打乱（删掉缩进、乱加空格）：

```rust
函数 主函数() {
让 名字 = "小明";
        打印行!("你好，{}！", 名字);
}
```

然后：

- **右键 → 格式化文档**；或
- 快捷键 `Shift + Alt + F`（Mac：`Shift + Option + F`）。

代码瞬间变回整齐的缩进：

```rust
函数 主函数() {
    让 名字 = "小明";
    打印行!("你好，{}！", 名字);
}
```

> 💡 **比喻**：格式化就像整理书桌。书还是那些书（代码内容没变），但每样东西都回到了该在的位置，找起来快、看着舒服。

> ✨ **好习惯**：每次写完一段代码就按一次格式化快捷键。整齐的代码更好检查错误，别人（包括未来的你）也更容易读懂。

## 2.6 代码片段：两个字换一段代码

📖 **代码片段（Snippet）**：预先存好的代码模板。输入一个**短名字**，按 `Tab` 键，就自动展开成完整代码。就像聊天软件里的"快捷回复"：打"地址"两个字，自动变成整段家庭住址。

### 动手试试

新建一行，输入三个字：

```
主函数
```

这时会弹出一个**候选列表**（第一项标着 Snippet，就是代码片段）。按 `Tab` 或 `Enter`，它自动展开成：

```rust
函数 主函数() {
    
}
```

光标还自动停在花括号里面，直接就能接着写。

### 可用的代码片段清单

| 输入什么               | 展开成什么                     |
|------------------------|-------------------------------|
| `主函数`               | 主函数框架                     |
| `打印行`               | `打印行!("...");`              |
| `让变量`               | `让 名字 = 值;`                |
| `让可变变量`           | `让 可变 名字 = 值;`           |
| `如果表达式`           | `如果 条件 { }`                |
| `如果否则`             | `如果 条件 { } 否则 { }`       |
| `对于循环`             | `对于 项 在 集合 中 { }`       |
| `当循环`               | `当 条件 { }`                 |
| `循环`                 | `循环 { }`                    |
| `匹配表达式`           | `匹配 值 { }`                 |
| `结构体定义`           | 结构体框架（第十章学）         |
| `枚举定义`             | 枚举框架（第十一章学）         |
| `特征定义`             | 特征框架（第十三章学）         |
| `实现块`               | 实现块框架（第十章学）         |
| `向量创建`             | 向量创建（第十五章学）         |
| `选项有些` / `选项无`   | 选项类型的两个值（第十六章学） |
| `结果成功` / `结果错误` | 结果类型的两个值（第十六章学） |
| `打印格式化`            | `打印格式化!(...)`            |

> ✨ 后面章节的片段现在不用记，学到那一章自然会用到。

## 2.7 全角符号自动修正：中文输入法的好帮手

第一章说过：代码里必须用**英文（半角）符号**。但用中文输入法打字时，很容易不小心打出**中文（全角）符号**：

| 全角（错的）  | 半角（对的） |
|--------------|--------------|
| `（）`       | `()`         |
| `；`         | `;`          |
| `“ ”`        | `" "`        |
| `｛｝`       | `{}`          |

💡 **比喻**：全角符号像"穿了棉袄的符号"——看起来差不多，但计算机认不出它，一律报错。

i18n-rust 扩展有个贴心功能：在代码区输入全角符号时，**自动帮你换成半角**（这个功能默认开启，设置项叫 `i18n-rust.autoConvertFullWidthSymbols`）。

### 动手试试

确保中文输入法开着，在代码区（不是字符串里）输入一个中文分号 `；`——它会自动变成英文分号 `;`。

> ⚠️ **注意**：字符串 `"..."` 里面的全角符号**不会被转换**——因为字符串里写中文标点是合法的（比如 `打印行!("你好！")` 里的感叹号就该是中文的）。自动修正只发生在代码部分。

## 2.8 命令面板：更多命令

2.2 节学过 `Ctrl + Shift + P` 打开**命令面板**。输入 `i18n`，能看到扩展的全部命令。按"现在要不要学"分成三类：

### 现在就会用的

| 命令 | 作用 | 什么时候用 |
|---|---|---|
| i18n: 运行 (Run) | 运行程序 | 每天用（也有按钮和快捷键） |
| i18n: 类型检查 (Check) | 检查错误 | 每天用 |
| i18n: 导出为 Rust 源码 | 生成英文 Rust 文件 | 想看"翻译结果"时（第一章 1.7 节） |

### 偶尔会用到的

| 命令 | 作用 | 什么时候用 |
|---|---|---|
| i18n: 选择语言包 | 切换写代码用的语言（中文/日文/德文等 10 种） | 想试试用别的语言写 Rust 时 |
| i18n: 重启语言服务器 | 重启后台检查服务 | 波浪线不出现、补全失灵时（2.9 节） |
| i18n: 添加依赖 (cargo add) | 给项目添加第三方库 | 第十七章学包管理时 |

### 以后才学的（现在知道有就行）

| 命令 | 作用 |
|---|---|
| i18n: 校验第三方库映射 (mapping check) | 检查中文库名映射文件写得对不对（附录 D） |
| i18n: 生成新语言翻译脚手架 (mapping scaffold) | 为一种新语言生成翻译模板（附录 D） |
| i18n: 安装语言包 (lang install) | 安装社区提供的语言包（附录 D） |
| i18n: AI 对话 / 选择 AI 提供商 / 获取 AI 模型列表 | AI 辅助功能，需要自己配置 AI 服务（附录 D） |

> ✨ 记不住没关系：需要的时候按 `Ctrl + Shift + P` 输入 `i18n` 看一眼就行。

## 2.9 常见错误与解决

### 错误一：打开 `.zh` 文件没有运行按钮

**原因**：扩展没有识别这个文件。

**解决步骤**（按顺序试）：

1. 看右下角是不是 `Rust (中文)`。如果不是，点它手动选择 `Rust (中文)`；
2. 确认文件后缀真的是 `.zh`（Windows 可能隐藏了后缀，实际叫 `test.zh.txt`——在文件资源管理器里打开"显示文件扩展名"检查）；
3. 按 `Ctrl + Shift + P` 输入 `Reload Window`（重新加载窗口），回车。

### 错误二：没有红色波浪线，错误查不出来

**原因**：后台的语言服务器没启动成功。最常见的原因是**找不到 `rzc` 命令**。

**解决步骤**：

1. 打开 VS Code 内置终端（菜单：终端 → 新建终端），输入 `rzc --version`：
   - 提示"不是内部或外部命令 / command not found" → 说明 rzc 没装好或不在 PATH 里，回到第一章 1.4 重装；
2. rzc 正常的话，按 `Ctrl + Shift + P` 执行 **i18n: 重启语言服务器**；
3. 还不行就重新加载窗口（`Reload Window`）。

> 📖 **PATH**：操作系统查找命令的"目录清单"（第一章提过）。命令不在这份清单里，终端就找不到它。

### 错误三：点运行按钮报错"找不到 rzc"

和错误二同源。如果 rzc 装在特殊位置，可以在设置里手动指定：

1. 按 `Ctrl + ,`（Mac：`Cmd + ,`）打开设置；
2. 搜索 `i18n-rust`；
3. 找到 **i18n-rust.rzcPath**，填入 rzc 的完整路径，例如：
   - Windows：`C:\Users\你的用户名\.cargo\bin\rzc.exe`
   - macOS/Linux：`/home/你的用户名/.cargo/bin/rzc`

（同一设置页还有 `i18n-rust.serverPath`，用于指定语言服务器程序的位置，一般不用改。）

### 错误四：格式化没反应

**原因**：当前文件没被识别为 `Rust (中文)`。

**解决**：先按"错误一"的步骤让文件被识别，再格式化。

### 错误五：快捷键按了没反应

**可能原因**：快捷键被别的软件或输入法抢走了（`Ctrl + Shift + C` 在某些输入法里是"简繁转换"）。

**解决**：换用按钮或右键菜单，功能完全一样；或者在 VS Code 设置 → 键盘快捷方式里给 `i18n-rust.run` 换一个键。

## 2.10 完整操作流程示例

把本章学到的串起来，这是你以后写代码的**标准流程**：

1. **打开项目**：VS Code → 文件 → 打开文件夹 → 选你的项目文件夹；
2. **打开代码**：左侧文件树点 `src/main.zh`；
3. **写代码**：打 `打印行` + Tab 用代码片段，中文标点自动修正；
4. **保存**：`Ctrl + S`，看有没有红色波浪线；
5. **排整齐**：`Shift + Alt + F` 格式化；
6. **运行**：点右上角 ▶（或 `Ctrl + Shift + R`）；
7. **看结果**：底部终端面板显示程序输出；
8. **出错了**：`Ctrl + Shift + M` 打开问题面板，点错误跳转修改，回到第 4 步。

> 💡 第 4 → 8 步会反复循环很多遍。写程序就是这样：**写一点 → 检查 → 运行 → 改错 → 再写一点**，像滚雪球一样越滚越大。

## 2.13 常见问题（FAQ）

**问：扩展会不会"翻译"我的代码？我写的中文代码会被改动吗？**

答：不会。扩展只负责**上色、检查、运行、排版**，你的 `.zh` 文件内容永远是你写的样子。"翻译成英文 Rust"只发生在运行/检查的瞬间（由 rzc 在内存里做），或者你主动用"导出为 Rust 源码"命令时才生成单独的 `.rs` 文件。

**问：同一个项目能用命令行 `rzc run`，也能用扩展按钮，结果一样吗？**

答：一样。扩展按钮背后调用的就是 rzc 命令，只是帮你省了打字。两种方式随便用。

**问：我的同学用英文版 VS Code，菜单名字和我不一样怎么办？**

答：没关系。扩展的命令名（如 "i18n: 运行 (Run)"）在命令面板里是一样的，快捷键也一样。找不到菜单项就用 `Ctrl + Shift + P` 命令面板。

**问：全角符号自动转换能关掉吗？**

答：能。设置里搜索 `i18n-rust.autoConvertFullWidthSymbols`，取消勾选即可。不过建议开着，它能帮你躲掉一大类"中文符号"报错。

**问：代码片段的候选列表没弹出来？**

答：检查两点：① 文件右下角是 `Rust (中文)`；② VS Code 设置里代码补全没被关掉（设置搜索 `suggestOnTriggerCharacters`，确保勾选）。也可以手动触发：按 `Ctrl + 空格`。

**问：扩展支持哪些语言？只有中文吗？**

答：扩展支持 10 种语言：中文、日本語、Deutsch、Español、Français、Português、Русский、한국어、हिन्दी、العربية。用"i18n: 选择语言包"命令切换，对应文件后缀分别是 `.zh`、`.ja` 等。本书只用中文。

**问：为什么有的功能（如 AI 对话）我点了没反应？**

答：AI 功能需要自己配置 AI 服务的密钥和地址，属于选学内容。初学阶段完全用不到，跳过即可，不影响写代码和运行。

**问：升级扩展后代码突然报一堆错？**

答：先执行 "i18n: 重启语言服务器"，再 `Reload Window` 重新加载窗口。还不行就核对 rzc 版本是否也升级了（`rzc --version`）——扩展和 rzc 版本最好保持一致。
