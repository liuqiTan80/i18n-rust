# 附录C：常见错误信息字典

这本字典收录了全书出现过的错误码和常见报错，按错误码排序。

**使用方法**：看到报错先找错误码（方括号里的 `E` 开头编号），翻到对应条目——每条都有"人话翻译 + 常见原因 + 解决办法"。

> 💡 记住编译器的态度：报错不是批评，是**帮你检查作业**。

---

## 错误码条目

### E0004 匹配不完备

- **人话**：你的 `匹配` 漏了某种情况，万一数据是那种情况，程序不知道怎么办。
- **常见原因**：`匹配` 枚举时少写了变体，又没写 `_` 兜底臂。
- **解决**：补上漏掉的变体，或加 `_ => ...` 兜底。（第十一章）

### E0063 结构体缺字段

- **人话**：造结构体时少填了字段——档案卡有空栏。
- **解决**：对照结构体定义补齐字段。（第十章）

### E0072 递归类型大小无限

- **人话**：类型直接包含自己，像套娃没有最里层，编译器算不出它多大。
- **解决**：用 `盒子<>` 间接包含：`节点(整数, 盒子<链表>)`。（第十九章）

### E0106 函数缺少生命周期标注

- **人话**：函数有多个引用参数还返回引用，编译器不知道返回值的有效期跟谁走。
- **解决**：照报错提示补 `<'a>` 标注——参数和返回值都写上。（第十四章）

### E0204 类型不能实现 Copy

- **人话**：你想让某类型"随手复制"，但它里面有不能随手复制的成员（比如 `字符串`）。
- **解决**：去掉 `Copy` 派生，改用 `克隆()`。（第十章）

### E0261 使用了未声明的生命周期

- **人话**：签名里出现了编译器不认识的 `'名字`。
- **解决**：在函数或类型的尖括号里先声明它。（第十四章）

### E0277 特征约束不满足

- **人话**：你让"没有上岗证的类型"去做要求持证的工作。
- **解决**：给该类型实现对应特征，或换已实现的类型。（第十三章）

### E0308 类型不匹配

- **人话**：期望一种类型，实际给了另一种——盒子标签和里面的东西对不上。
- **常见原因**：整数和小数混用、`字符串` 和 `字符串引用` 混用、函数返回值和声明不符。
- **解决**：看报错里的"期望/实际"，用类型转换或换值。（第二章起）

### E0382 值在移动后被使用

- **人话**：东西已经搬家给了别人，你又伸手去拿原来的位置——抽屉已空。
- **解决**：搬之前先 `克隆()` 一份；或改用借用 `&`。（第七章）

### E0405 找不到特征

- **人话**：约束里写的特征名不存在——可能拼错或映射词用错（如把 `可排序` 写成 `偏序`）。
- **解决**：查附录 A 的标准特征映射表。（第十二章）

### E0425 找不到名称

- **人话**：用了一个没定义、没引入的名字。
- **常见原因**：拼写错误；忘记 `使用` 引入；作用域不对。
- **解决**：检查拼写 → 补 `使用` → 检查名字定义在哪一层。（第十五章）

### E0432 / E0433 导入路径解析失败

- **人话**：`使用` 的地址写错了，找不到那个抽屉。
- **解决**：逐段核对路径；模块要先声明；别把类型名写进该写模块名的位置。（第二十章）

### E0502 可变与不可变借用冲突

- **人话**：一边有人正在读，另一边有人想改——读写不同席。
- **解决**：让读和写在时间上错开，或调整借用顺序。（第八章）

### E0507 无法移出借用的内容

- **人话**：借来的东西不能据为己有——图书馆的书不能撕页带走。
- **解决**：克隆后再拿，或把方法改成消耗 `自我`。（第十二章）

### E0508 无法移出数组元素

- **人话**：数组的元素不能单个搬走。
- **解决**：给枚举派生 `Copy`，或克隆元素，或改用向量。（第十一章）

### E0531 未知的元组变体

- **人话**：`匹配` 里写的变体名不对——比如把 `错误(...)` 写成 `失败(...)`。
- **解决**：核对枚举/结果的正确变体名。（第十六章）

### E0573 期望类型但找到了方法

- **人话**：签名里想要一个类型，编译器却在名字里找到了方法（比如把 `自我` 当返回类型）。
- **解决**：返回类型写具体类型名或 `自身`。（第六章）

### E0596 无法借用为可变

- **人话**：你想改一个没标 `可变` 的东西。
- **解决**：声明处加 `可变`；检查借用链是否每一环都可变。（第八章）

### E0597 借用内容未存活足够久

- **人话**：借据想活得比原值还久——原值先被释放了。
- **解决**：把原值挪到更大的作用域；或克隆/造自己的数据。（第十四章）

### E0599 类型上找不到该方法

- **人话**：点号后面的方法这个类型没有——可能是名字拼错、映射词混淆，或忘记引入特征。
- **常见原因**：`推入字符`（应为 `推入`）；忘记 `使用` 引入扩展方法所在特征。
- **解决**：查附录 A 方法映射表；补引入。（第九章）

### E0603 模块是私有的

- **人话**：你伸手进了别人上锁的抽屉。
- **解决**：沿路径每一层都加 `公开`。（第十七章）

## 恐慌（运行时）

### index out of bounds（下标越界）

- **原文**：`index out of bounds: the length is 3 but the index is 9`
- **人话**：数组/向量没有那个位置。
- **解决**：检查下标来源；不确定就用 `截取()`。（第十六章）

### byte index is not a char boundary（切片落进汉字中间）

- **原文**：`byte index 1 is not a char boundary; it is inside '你' (bytes 0..3)`
- **人话**：汉字占 3 个字节，切片必须落在字符边界上。
- **解决**：切片前按字节边界想清楚，或用 `逐字符()` 处理。（第九章）

## 常见警告（不拦你，但值得看）

| 警告 | 人话 | 解决 |
|---|---|---|
| `unused variable: x` | 变量定义了没用 | 用上它，或名字前加 `_` |
| `field ... is never read` | 结构体字段只存不读 | 用起来或删掉 |
| `unused import` | 引入了没用到的东西 | 删掉那行 `使用` |
| `should have a snake case name` | 名字被转译成大写开头的词（撞了映射） | 换个不撞映射的名字 |

## 使用建议

1. **先看 💡 提示**——rzc 翻译后的错误几乎都带修复建议，一半的问题读建议就解决；
2. **再看错误码**——来本字典查人话；
3. **都不行就 `rzc eject`**——看看转译后的英文代码，很多"神秘问题"是映射词撞车，一看便知。
