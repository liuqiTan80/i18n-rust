# 第二章：变量与类型

上一章我们写了第一个程序。但那个程序只是打印了一行文字——它不会"记住"任何东西。

这一章，我们要学习如何让程序**记住数据**。

> ✨ **小提示**：学编程要多动手，因为脑子学会了，不一定手**也**学会了
---

## 2.1 变量是什么

### 贴了标签的盒子

想象你搬家时用的纸箱。你在纸箱外面写上"书"，里面装满书。另一个纸箱写上"衣服"，里面装满衣服。

**变量就是这样的盒子。**

- 标签叫 `名字`，里面放着 `"小明"`
- 标签叫 `年龄`，里面放着 `20`

```
┌──────────┐     ┌──────────┐
│  名字              │     │          年龄      │
│ "小明"             │     │           20       │
└──────────┘     └──────────┘
```

**为什么需要盒子？** 因为程序需要处理数据。数据放在盒子里，贴上标签，以后想用就拿标签去找。

### 用 `让` 创建盒子

在中文 Rust 中，用 **`让`** 来创建一个变量：

```rust
函数 主函数() {
    让 名字 = "小明";
    让 年龄 = 20;
    打印行!("{}今年{}岁。", 名字, 年龄);
}
```

逐行解释：

- 第 1 行：定义主函数（程序的入口，上一章讲过）
- 第 2 行：拿一个盒子，标签叫 `名字`，把 `"小明"` 放进去
- 第 3 行：拿一个盒子，标签叫 `年龄`，把 `20` 放进去
- 第 4 行：把盒子里的东西取出来，依次填入 `{}` 的位置，显示在屏幕上
- 第 5 行：主函数结束

> **等号 `=` 的含义**：在编程中，`=` 不是"两边相等"的意思。它的意思是"把右边的东西，放进左边的盒子"。

运行后：

```
小明今年20岁。
```

## 2.2 不可变与可变

### 默认不可变——封好的盒子不能换

Rust 有一个特别的规则：**盒子一旦封好，就不能换里面的东西**。

```rust
函数 主函数() {
    让 数量 = 10;
    数量 = 20;  // ❌ 报错！
}
```

逐行解释：

- 第 2 行：创建盒子 `数量`，放入 10
- 第 3 行：想把 20 放进 `数量` 盒子——但不行！因为默认不可变

编译器会报错：

```
错误：不能给不可变变量 `数量` 重复赋值
  --> src/main.zh:3:5
   |
3  |     数量 = 20;
   |     ^^^^^^^^^ 不能修改
💡 如果需要修改，试试 `让 可变 数量 = 10;`
```

**为什么默认不可变？** 因为不可变更安全。想象你把一份重要文件锁进保险箱。如果你确定不会改它，那锁起来最安全——谁也改不了。Rust 默认把所有盒子都"锁上"，避免你不小心改错了。

### 用 `可变` 让盒子可以更换

如果你想更换盒子里的东西，需要在创建时加上 `可变`：

```rust
函数 主函数() {
    让 可变 数量 = 10;    // 告诉 Rust：这个盒子"可以更换"
    打印行!("修改前：{}", 数量);

    数量 = 20;            // ✅ 现在可以换了
    打印行!("修改后：{}", 数量);
}
```

逐行解释：

- 第 2 行：创建盒子 `数量`，放入 10。`可变` 两个字告诉 Rust："这个盒子以后要换东西"
- 第 3 行：显示当前值——10
- 第 5 行：把 20 放进 `数量`，替换掉原来的 10。因为加了 `可变`，所以可以换
- 第 6 行：显示新值——20

输出：

```
修改前：10
修改后：20
```

用盒子来理解：

```
第 1 步：让 可变 数量 = 10
┌──────────────┐
│  数量 (可变)  │  →  10
└──────────────┘

第 2 步：数量 = 20
┌──────────────┐
│  数量 (可变)  │  →  20    ← 换了里面的东西
└──────────────┘
```

> **`可变` 的代价**：可变盒子让代码更难理解——你得时刻注意盒子里的东西可能变了。所以 Rust 默认不可变，只有你明确需要时才加 `可变`。就像保险箱——默认锁着，需要时再打开。

## 2.3 常量

如果你有一个值**永远不变**，而且整个程序都要用，用 **`常量`**。

**常量和变量的区别？** 变量像你自己的笔记本——你可以改内容。常量像贴在墙上的公告——写好了就不能改，所有人都能看到。

```rust
常量 最大分数: 整数 = 100;
常量 程序名: &文本 = "我的程序";

函数 主函数() {
    打印行!("欢迎使用{}", 程序名);
    打印行!("最高分：{}", 最大分数);
}
```

逐行解释：

- 第 1 行：创建一个常量叫 `最大分数`，值是 100。`整数` 是类型标注（告诉编译器这是整数）
- 第 2 行：创建一个常量叫 `程序名`，值是 `"我的程序"`。**`&文本`** 表示"文本引用"——现在你只需要记住：双引号写出的文字，标注类型时写作 `&文本` 就行（第八章会详细讲）
- 第 4 行：显示欢迎语
- 第 5 行：显示最高分

常量和变量的对比：

| 特性 | 变量（`让`） | 常量（`常量`） |
|------|-------------|---------------|
| 可以修改 | 加了 `可变` 才可以 | **永远不可以** |
| 必须标注类型 | 不必须（编译器能猜） | **必须** |
| 使用范围 | 当前代码块内 | 创建位置之后，到处都能用 |

## 2.4 基本数据类型

Rust 是一门**强类型语言**——每个值都有类型。就像每个盒子都有一个形状：圆形的盒子装圆形的东西，方形的盒子装方形的东西。你不能把圆形的东西硬塞进方形的盒子。

但好消息是，大多数时候你不需要手动标注类型。编译器看到数据就能**自动推断**类型。

### 整数——没有小数点的数字

整数就是**没有小数点**的数字。比如 1、42、-7、0 都是整数。3.14 不是整数，因为它有小数点。

Rust 有多种整数类型，区别在于**能装多大的数**。就像盒子有大小——小盒子装不了大东西：

```
┌─────────────────────────────────────────────────────┐
│ 类型        │ 能装多大的数                            │
├─────────────────────────────────────────────────────┤
│ 微整数      │ -128 到 127（最小，只占 1 格）           │
│ 字节        │ 0 到 255（占 1 格，不能是负数）          │
│ 短整数      │ -32768 到 32767（占 2 格）              │
│ 整数        │ 约 ±21 亿（占 4 格，★ 默认用这个！）     │
│ 长整数      │ 约 ±922 亿亿（占 8 格）                  │
│ 超长整数    │ 更大（占 16 格）                         │
└─────────────────────────────────────────────────────┘
```
>关于括号中的占几格表示的是在内存中占多大空间，我们现在先不去关注这个细节，等以后有时间了再去扩展知识
> **不知道用哪种？** 直接用 **`整数`**。它是默认类型，能装约 ±21 亿，适合绝大多数情况。

```rust
函数 主函数() {
    让 年龄: 整数 = 25;       // 整数类型（默认）
    让 价格: 无符号整数 = 99;  // 无符号整数（不能是负数）
    让 小数字: 微整数 = 100;   // 微整数：只能装 -128 到 127
    让 字节数: 字节 = 255;     // 字节：只能装 0 到 255

    打印行!("年龄：{}", 年龄);
    打印行!("价格：{}", 价格);
    打印行!("小数字：{}", 小数字);
    打印行!("字节数：{}", 字节数);
}
```

逐行解释：

- 第 2 行：创建整数盒子 `年龄`，放入 25
- 第 3 行：创建无符号整数盒子 `价格`，放入 99（无符号 = 不能是负数）
- 第 4 行：创建微整数盒子 `小数字`，放入 100（微整数最小，范围 -128 到 127）
- 第 5 行：创建字节盒子 `字节数`，放入 255（字节范围 0 到 255）
- 第 7-10 行：分别显示四个值

### 浮点数——有小数点的数字

浮点数就是**有小数点**的数字。比如 3.14、0.5、-2.0。

```rust
函数 主函数() {
    让 圆周率 = 3.14159;             // 默认是浮点数（双精度，更精确）
    让 半径: 浮点数 = 5.0;           // 显式标注：浮点数
    让 面积 = 圆周率 * 半径 * 半径;    // 计算结果自动是浮点数

    打印行!("半径 {} 的圆面积是 {}", 半径, 面积);
}
```

逐行解释：

- 第 2 行：创建浮点数盒子 `圆周率`，放入 3.14159
- 第 3 行：创建浮点数盒子 `半径`，放入 5.0
- 第 4 行：计算面积 = 3.14159 × 5.0 × 5.0 ≈ 78.54，放入 `面积` 盒子
- 第 6 行：显示结果

- **`浮点数`**（双精度）—— 更精确，**默认选择**，本书统一用它
- **`单精度浮点数`**（单精度）—— 占用内存更少，精确度稍低。等你熟练了再了解它

### 布尔——只有"真"和"假"

布尔类型只有两个值：**`真`** 和 **`假`**。就像电灯开关——要么开，要么关，没有中间状态。

```rust
函数 主函数() {
    让 是否成年 = 真;
    让 是否下雨 = 假;

    如果 是否成年 {
        打印行!("你已经成年了。");
    }

    如果 !是否下雨 {
        打印行!("今天没下雨，出去玩吧！");
    }
}
```

逐行解释：

- 第 2 行：创建布尔盒子 `是否成年`，放入 `真`
- 第 3 行：创建布尔盒子 `是否下雨`，放入 `假`
- 第 5-7 行：**如果** `是否成年` 为 `真`，就显示"你已经成年了"
- 第 9-11 行：`!` 是"取反"——`!假` 变成 `真`。所以 `!是否下雨` 为 `真`，显示"没下雨"

> `!` 是"取反"操作——把 `真` 变成 `假`，把 `假` 变成 `真`。

### 字符——一个文字

字符用**单引号**包裹，表示**一个**文字。

```rust
函数 主函数() {
    让 字母: 字符 = 'A';
    让 汉字: 字符 = '中';
    让 表情: 字符 = '😊';

    打印行!("字母：{}", 字母);
    打印行!("汉字：{}", 汉字);
    打印行!("表情：{}", 表情);
}
```

逐行解释：

- 第 2 行：创建字符盒子 `字母`，放入 `'A'`
- 第 3 行：创建字符盒子 `汉字`，放入 `'中'`
- 第 4 行：创建字符盒子 `表情`，放入 `'😊'`

> Rust 的字符支持所有 Unicode 文字。所以中文、日文、表情符号都可以用一个字符表示。

### 文本——一串文字

用**双引号**包裹的一串文字叫**文本**。比如 `"你好"`、`"小明"`。第一章里你已经用过它了！

```rust
函数 主函数() {
    让 问候 = "你好，世界";
    让 名字 = "小明";
    打印行!("{}{}", 问候, 名字);
}
```

逐行解释：

- 第 2 行：创建文本盒子 `问候`，放入 `"你好，世界"`
- 第 3 行：创建文本盒子 `名字`，放入 `"小明"`
- 第 4 行：把两个盒子的内容拼在一起显示："你好，世界小明"

> **注意**：`"..."` 写出来的文本，准确类型叫"文本引用"（写作 `&文本`），它和 `字符串` 的区别在第八章详细讲。现在你只需要知道：**双引号包的就是文本**。

## 2.5 类型标注

大多数时候，编译器能**自动推断**类型——它看到 42 就知道是整数，看到引号就知道是文字：

```rust
让 数量 = 42;       // 编译器看到 42，自动推断为整数
让 名字 = "小明";    // 编译器看到引号，自动推断为文本
```

但有时候编译器推断不出来，或者你想明确指定类型，就需要**类型标注**：

```rust
让 数量: 整数 = 42;       // 明确告诉编译器：这是整数
让 圆周率: 浮点数 = 3.14;  // 明确告诉编译器：这是浮点数
让 标志: 布尔 = 真;        // 明确告诉编译器：这是布尔
```

格式是 `名字: 类型`——冒号后面跟类型名。就像在盒子上多贴一个标签，写明"这个盒子只能装整数"。

> **什么时候需要类型标注？** 当编译器猜不出来的时候。比如创建 `常量` 时必须标注（第 2.3 节讲过）；还有一些特殊情况（比如空值），编译器也无从猜测。记住一条规则：**编译器报错"无法推断类型"时，加上标注就行**。

## 2.6 变量遮蔽

你可以用同一个名字创建一个新的盒子，**盖住**旧的盒子：

```rust
函数 主函数() {
    让 数量 = 5;
    打印行!("第一次：{}", 数量);     // 输出 5

    让 数量 = "五个";               // 新盒子盖住了旧的
    打印行!("第二次：{}", 数量);     // 输出 "五个"
}
```

逐行解释：

- 第 2 行：创建整数盒子 `数量`，放入 5
- 第 3 行：显示 5
- 第 5 行：创建一个**新的**盒子，也叫 `数量`，但里面放的是文字 `"五个"`。新盒子盖住了旧盒子——从此以后用 `数量` 找到的是新盒子
- 第 6 行：显示 "五个"

**遮蔽和 `可变` 有什么区别？**

```
遮蔽：创建了一个全新的盒子，旧盒子还在，只是被挡住了
┌──────────┐     ┌──────────┐
│ 数量 = 5  │     │数量 = "五"│
│ (整数)    │ →   │ (文字)    │     ← 类型可以不同！
└──────────┘     └──────────┘
  旧盒子还在，
  只是被挡住了

可变：在同一个盒子里换东西
┌──────────────┐
│ 数量 (可变)   │  10 → 20 → 30    ← 同一个盒子，类型不变
└──────────────┘
```

> **为什么要用遮蔽？** 有时候你想转换数据的类型，但又不想取新名字。遮蔽让你用同一个名字覆盖旧值。

## 2.7 常见错误

### 错误 1：修改不可变盒子

```rust
让 数量 = 10;
数量 = 20;  // ❌ 不能修改不可变盒子
```

**修复**：加 `可变` → `让 可变 数量 = 10;`

### 错误 2：使用还没放东西的盒子

```rust
让 数量: 整数;
打印行!("{}", 数量);  // ❌ 盒子里还没有东西
```

**修复**：先放东西 → `让 数量: 整数 = 0;`

### 错误 3：类型不匹配

```rust
让 数量: 整数 = "你好";  // ❌ 整数盒子装不了文字
```

**修复**：用正确的类型 → `让 数量: 整数 = 42;`

### 错误 4：数字超出范围

```rust
让 字节数: 字节 = 256;  // ❌ 字节只能装 0 到 255
```

**修复**：用范围更大的类型 → `让 数量: 整数 = 256;`

## 2.8 动手实验

### 实验 1：简单计算器

**为什么要做这个实验？** 让你学会用变量存储数据，并进行数学运算。

```rust
函数 主函数() {
    让 甲: 整数 = 15;
    让 乙: 整数 = 4;

    打印行!("{} + {} = {}", 甲, 乙, 甲 + 乙);
    打印行!("{} - {} = {}", 甲, 乙, 甲 - 乙);
    打印行!("{} × {} = {}", 甲, 乙, 甲 * 乙);
    打印行!("{} ÷ {} = {}", 甲, 乙, 甲 / 乙);
    打印行!("{} 余 {} = {}", 甲, 乙, 甲 % 乙);
}
```

逐行解释：

- 第 2-3 行：创建两个整数盒子 `甲`（15）和 `乙`（4）
- 第 5 行：显示加法。`甲 + 乙` = 15 + 4 = 19
- 第 6 行：显示减法。`甲 - 乙` = 15 - 4 = 11
- 第 7 行：显示乘法。`甲 * 乙` = 15 × 4 = 60
- 第 8 行：显示除法。`甲 / 乙` = 15 ÷ 4 = 3（整数除法自动取整！）
- 第 9 行：显示取余。`甲 % 乙` = 15 除以 4 的余数 = 3

输出：

```
15 + 4 = 19
15 - 4 = 11
15 × 4 = 60
15 ÷ 4 = 3      ← 整数除法自动取整！
15 余 4 = 3
```

> **注意**：整数除法会自动取整。`15 / 4` 的结果是 `3`，不是 `3.75`。如果需要精确结果，用浮点数。

### 实验 2：温度转换

**为什么要做这个实验？** 让你学会用浮点数做数学运算。

```rust
函数 主函数() {
    让 摄氏: 浮点数 = 36.6;
    让 华氏 = 摄氏 * 9.0 / 5.0 + 32.0;

    打印行!("摄氏 {}° = 华氏 {}°", 摄氏, 华氏);
}
```

逐行解释：

- 第 2 行：创建浮点数盒子 `摄氏`，放入 36.6
- 第 3 行：用公式计算华氏温度 = 36.6 × 9.0 ÷ 5.0 + 32.0 = 97.88
- 第 5 行：显示结果

### 实验 3：交换两个盒子

**为什么要做这个实验？** 让你理解"可变变量"和"临时盒子"的用法。

```rust
函数 主函数() {
    让 可变 甲 = 1;
    让 可变 乙 = 2;

    打印行!("交换前：甲={}, 乙={}", 甲, 乙);

    让 临时 = 甲;   // 把甲的值保存到临时盒子
    甲 = 乙;        // 把乙的值放入甲
    乙 = 临时;      // 把临时盒子的值（原来的甲）放入乙

    打印行!("交换后：甲={}, 乙={}", 甲, 乙);
}
```

逐行解释：

- 第 2-3 行：创建两个可变盒子 `甲`（1）和 `乙`（2）
- 第 5 行：显示交换前的值
- 第 7 行：拿一个临时盒子，把甲的值（1）放进去保存
- 第 8 行：把乙的值（2）放入甲。现在甲 = 2
- 第 9 行：把临时盒子的值（1，就是原来的甲）放入乙。现在乙 = 1
- 第 11 行：显示交换后的值

> **为什么要临时盒子？** 想象两杯水（甲和乙），你想把它们互换。如果不先拿一个空杯子（临时）倒一杯水保存，你就没法交换——因为倒掉一杯就没了。

### 练习 1：个人信息卡

创建变量存储你的姓名、年龄、身高，然后输出：

```
姓名：小明
年龄：20
身高：175cm
```

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 姓名 = "小明";
    让 年龄 = 20;
    让 身高 = 175;
    打印行!("姓名：{}", 姓名);
```

### 练习 3：秒转时分秒

创建一个变量 `总秒数 = 3661`，计算并输出对应的时、分、秒。

提示：
- 1 小时 = 3600 秒
- 1 分钟 = 60 秒
- 用 `/` 求商，用 `%` 求余

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 总秒数 = 3661;
    让 时 = 总秒数 / 3600;
    让 分 = (总秒数 % 3600) / 60;
    让 秒 = 总秒数 % 60;
    打印行!("{}秒 = {}时{}分{}秒", 总秒数, 时, 分, 秒);
}
```

</details>

## 本章小结

1. **`让`** 创建变量（"贴了标签的盒子"），默认不可变
2. **`让 可变`** 创建可以修改的变量
3. **`常量`** 创建全局常量，必须标注类型
4. 基本类型：
   - **`整数`** —— 没有小数点的数字（默认选择）
   - **`浮点数`** —— 有小数点的数字
   - **`布尔`** —— 只有 `真` 或 `假`
   - **`字符`** —— 一个文字（支持中文、表情等）
   - **`文本`** —— 双引号包裹的一串文字（细节在第八章）
5. 编译器会自动推断类型，但你可以用 `: 类型` 手动标注
6. **遮蔽**可以用同名创建新盒子，甚至改变类型
