读完这一章，你将能够：

1. 用 `让` 创建变量，并说出变量是什么。

## 3.1 变量是什么

### 生活故事：贴了标签的盒子

想象你在整理房间。你拿出一个盒子，在盒子上贴一张标签，写上"玩具"，然后把玩具放进去。

之后你想拿玩具，只要喊一声"把'玩具'盒子给我"，就能拿到里面的东西。

你还可以撕掉标签换一张，或者把里面的东西换成别的。

**变量就是这样一个盒子**：

- 盒子 → 电脑里的一小块存储空间
- 标签 → 变量的名字（如 `名字`、`年龄`）
- 盒子里的东西 → 变量的值（如 `"小明"`、`12`）

> 💡 **比喻**：程序运行时会用到很多数据。数据不能乱放，要装进贴好标签的盒子——用的时候喊标签名就行。

### 用 `让` 创建变量

在中文 Rust 里，创建变量要用关键字 `让`。

> 📖 **`让`**：关键字，英文原名 let。它的字面意思是"让某个名字代表某个值"。比如 `让 年龄 = 12` 读作"让'年龄'这个名字代表 12"。

```rust
函数 主函数() {
    让 年龄 = 12;
    打印行!("我今年{}岁", 年龄);
}
```

逐行解释：

- 第 1 行：定义主函数。
- 第 2 行：`让 年龄 = 12;` —— 拿一个盒子，贴上"年龄"标签，把数字 12 放进去。末尾的分号表示这条指令结束。
- 第 3 行：把"年龄"盒子里的东西（12）填进 `{}` 占位符，屏幕显示"我今年12岁"。
- 第 4 行：主函数结束。

运行结果：

```
我今年12岁
```

> ⚠️ **小心**：`让` 是"创建新盒子"。后面讲 `可变` 时你会看到"往旧盒子里换东西"是另一回事。

### 赋值符号 `=` 不是"相等"

数学课上 `=` 表示"两边相等"。但在编程里，`=` 是一个**动作**：

> 📖 **赋值**：把右边的值放进左边的盒子。读作"把……放进……"。

```rust
让 分数 = 100;
```

读作："把 100 放进叫'分数'的盒子。"

它不是判断"分数和 100 相等吗"，而是**命令**："放进去！"

> ✨ **小提示**：判断"相等"用的是另一个符号 `==`（两个等号），第五章讲控制流时会遇到。

### 一个程序可以有多个盒子

```rust
函数 主函数() {
    让 名字 = "小华";
    让 年龄 = 12;
    让 班级 = "六（2）班";
    打印行!("大家好，我是{}，今年{}岁，来自{}", 名字, 年龄, 班级);
}
```

逐行解释：

- 第 2–4 行：创建三个盒子，分别装文字、数字、文字。
- 第 5 行：三个 `{}` 按顺序被 `名字`、`年龄`、`班级` 填入。

运行结果：

```
大家好，我是小华，今年12岁，来自六（2）班
```

### 变量名的规矩

给盒子贴标签（起名字）有几条规矩：

| 规矩                         | 对                | 错           | 原因                   |
|------------------------------|-------------------|--------------|-----------------------|
| 不能用关键字当名字            | `让 分数 = 1;`    | `让 让 = 1;`  | `让` 是保留的关键字 |
| 不能以数字开头                | `让 二班 = 2;`    | `让 2班 = 2;` | 以数字开头会被当成数字 |
| 可以用字母、数字、下划线、中文 | `让 学号_01 = 1;` |               | 这些都合法 |

> 📖 **下划线**：键盘上 `_` 这个符号（按 `Shift` + 减号键打出）。它长得像一条短线，常用于连接词语，比如 `我的_分数`。

> ⚠️ **小心**：不要给变量起和语言包映射词一样的名字，比如 `结果`、`字符串`、`类型`——这些词有别的用途，会引起混乱。起具体一点的名字最安全：`总分`、`问候语`、`人数`。

## 3.2 不可变与可变

### Rust 的特殊规矩：盒子默认"上锁"

在 Rust 里，变量创建后**默认不能改**。

```rust
函数 主函数() {
    让 分数 = 90;
    分数 = 100;   // ❌ 报错！
}
```

运行 `rzc check` 会报错：

```
错误[E0384]: 不可变变量 `分数` 被重复赋值
💡 如果需要修改变量的值，请使用 `让 可变` 声明变量。
```

> 📖 **不可变**：一旦确定就不能再改变。Rust 故意这么设计，下一章讲为什么——简单说，不能改的数据更安全，不容易出乱子。

### 用 `可变` 开锁

如果你确实需要修改盒子里的东西，在创建时加上关键字 `可变`：

> 📖 **`可变`**：关键字，英文原名 mut（mutable 的缩写，意思是"可变的"）。加在 `让` 后面，表示这个盒子里的东西以后可以换。

```rust
函数 主函数() {
    让 可变 分数 = 90;
    打印行!("第一次考试：{}分", 分数);
    分数 = 100;               // ✅ 有"可变"，可以换
    打印行!("第二次考试：{}分", 分数);
}
```

逐行解释：

- 第 2 行：创建盒子"分数"，装 90，并声明它可以改。
- 第 3 行：打印 90。
- 第 4 行：把盒子里的 90 换成 100。注意：**换东西时不写 `让`**——`让` 只用于创建新盒子。
- 第 5 行：打印 100。

运行结果：

```
第一次考试：90分
第二次考试：100分
```

> 💡 **比喻**：`让` 是买一个新盒子上锁；`可变` 是给盒子装个活扣，以后能打开换东西；再次用 `让` 则是再买一个新盒子。

> ✨ **小提示**：什么时候该用 `可变`？需要在程序运行过程中改变的数据（如计数器、分数累计）用它；固定不变的数据（如名字、圆周率）不用。

## 3.3 常量：永远不能改的盒子

有些值从始至终绝不能变，比如"一年有 12 个月"。这种值用**常量**：

> 📖 **`常量`**：关键字，英文原名 const（constant 的缩写，意思是"恒定的"）。常量一旦定义，永远不能改，而且必须写明类型。

```rust
函数 主函数() {
    常量 最大人数: 整数 = 45;
    打印行!("班级最多{}人", 最大人数);
}
```

逐行解释：

- 第 2 行：`常量 最大人数: 整数 = 45;` —— 定义一个永远等于 45 的常量。`最大人数` 和 `=` 之间的 `: 整数` 是**类型标注**，下一节讲。
- 第 3 行：打印。

> ⚠️ **小心**：常量和不可变变量有三点不同：
> 1. 常量不能用 `可变`，永远不能改。
> 2. 常量必须写类型标注（`: 整数`），变量可以不写。
> 3. 常量习惯放在函数外面（整个程序都能用），下一节你就能看到。

## 3.4 类型：数据的"种类"

### 为什么要分种类

盒子里能装什么，取决于盒子上标的种类。装数字的盒子不能装文字——这就是**类型**。

> 📖 **类型**：数据的"种类"。就像超市商品分"食品""文具""玩具"，数据也分数字、文字、真假等种类。类型决定了这个数据能参与什么运算：数字能相加，文字不能"加一"。

> 📖 **类型标注**：在名字后面写 `: 类型名`，明确告诉编译器盒子里装什么种类的数据。就像在盒子上提前贴好"装苹果"的标签。

中文 Rust 把 Rust 的类型都翻译成了中文。下面逐个认识。

### 类型一：整数——没有小数点的数

> 📖 **整数**：没有小数部分的数，如 3、-8、0。中文 Rust 默认用英文名为 i32 的整数类型，中文名就叫 `整数`。

```rust
让 人数 = 45;        // 默认就是"整数"类型
让 温度 = -8;        // 负数也可以
```

其实 Rust 有一整个整数家族，区别是"能装多大"和"能不能装负数"：

| 中文名       | 英文原名 | 能装的范围         | 特点             |
|--------------|---------|-------------------|------------------|
| `微整数`     | i8       | -128 到 127       | 最小 |
| `短整数`     | i16      | 约 -3 万到 3 万    | |
| `整数`       | i32      | 约 -21 亿到 21 亿 | **默认，最常用** |
| `长整数`      | i64     | 极大              | 装得下天文数字 |
| `无符号整数`  | u32     | 0 到约 42 亿       | 不能装负数 |

> 📖 **无符号**："符号"指正负号。无符号就是"没有负号"，只能装 0 和正数。好处是同样的大小能装更大的正数。

> ✨ **小提示**：新手只需要记住 `整数`（i32）就够了。名字里的 i 表示 integer（整数），后面的数字表示用多少个"位"（二进制的小格子）来存。格子越多，装得越大。

### 类型二：浮点数——带小数点的数

> 📖 **浮点数**：带小数点的数，如 3.14、-0.5。默认类型叫 `浮点数`（英文 f64，f 是 float"浮动"的缩写）。

```rust
让 圆周率 = 3.14;
让 体温 = 36.5;
```

> ⚠️ **小心**：整数除以整数，结果还是整数，小数部分会被**砍掉**：

```rust
让 结果商 = 7 / 2;
打印行!("{}", 结果商);   // 显示 3，不是 3.5！
```

想要小数结果，至少有一边是浮点数：

```rust
让 结果商 = 7.0 / 2;
打印行!("{}", 结果商);   // 显示 3.5
```

> 📖 **取余**：`%` 符号计算"除法的余数"。7 % 2 = 1（7 除以 2 商 3 余 1）。判断奇偶数时特别有用：能被 2 整除（余数为 0）就是偶数。

### 类型三：布尔——只有真和假

> 📖 **布尔**：只有两个可能值的类型——`真` 或 `假`。英文 bool，以数学家布尔的名字命名。它用来回答"是或否"的问题。

```rust
让 已完成作业 = 真;
让 今天下雨 = 假;
```

> 📖 **`真`** 和 **`假`**：关键字，英文原名 true 和 false。这是布尔类型仅有的两个值，一个字都不能写错。

布尔值在第五章的 `如果` 判断里大显身手："**如果** 今天下雨 **是** `真`，就带伞。"

### 类型四：字符——单个文字

> 📖 **字符**：单个的文字符号，英文 char。用**单引号** `'` 圈起来（注意不是双引号）。

```rust
让 等级 = '优';
让 符号 = '★';
```

> ⚠️ **小心**：字符和字符串的区别——`'优'` 是一个字符（一个字），`"优秀"` 是字符串（一串字）。单引号装一个，双引号装一串。字符串在第九章详细讲。

### 类型全家福速查

| 中文名   | 英文原名 | 例子         | 记法                      |
|----------|---------|--------------|---------------------------|
| `整数`   | i32     | `45`         | 没有小数点 |
| `长整数` | i64     | `9999999999` | 装大数 |
| `浮点数` | f64     | `3.14`       | 有小数点 |
| `布尔`   | bool    | `真` / `假`  | 是或否 |
| `字符`   | char    | `'优'`       | 单引号，一个字 |
| `字符串` | String  | `"你好"`     | 双引号，一串字（第九章详讲） |

### 编译器会自己猜类型

你写 `让 年龄 = 12;` 时，并没有写 `: 整数`，为什么编译器知道它是整数？

因为编译器会**自动推断**：看到 12 没有小数点，就猜它是 `整数`；看到 3.14，就猜 `浮点数`；看到引号，就猜字符串。

> 📖 **类型推断**：编译器根据值的样子自动判断类型的能力。你省事，它靠谱。但类型标注永远可以写，写了更清楚。

## 3.5 让程序算数：运算符

> 📖 **运算符**：执行运算的符号。加减乘除都是运算符。

### 五个基本算术运算符

```rust
函数 主函数() {
    让 甲 = 10;
    让 乙 = 3;
    打印行!("加：{}", 甲 + 乙);     // 13
    打印行!("减：{}", 甲 - 乙);     // 7
    打印行!("乘：{}", 甲 * 乙);     // 30
    打印行!("除：{}", 甲 / 乙);     // 3（整数除法，砍掉小数）
    打印行!("余：{}", 甲 % 乙);     // 1（余数）
}
```

| 符号 | 名字 | 例子 | 结果 |
|------|---|---|---|
| `+` | 加 | `10 + 3` | 13 |
| `-` | 减 | `10 - 3` | 7 |
| `*` | 乘 | `10 * 3` | 30 |
| `/` | 除 | `10 / 3` | 3 |
| `%` | 取余 | `10 % 3` | 1 |

> ⚠️ **小心**：参与运算的两个数必须**类型相同**。`整数 + 浮点数` 会报错。需要混算时，用 `作为` 转换（马上讲）。

### 复合赋值：改自己的简写

```rust
让 可变 分数 = 90;
分数 += 5;    // 等于 分数 = 分数 + 5，现在是 95
分数 -= 10;   // 等于 分数 = 分数 - 10，现在是 85
分数 *= 2;    // 85 乘 2 = 170
```

> 📖 **复合赋值**：`+=`、`-=`、`*=`、`/=` 这些符号，意思是"把自己运算后再放回去"。`分数 += 5` 读作"分数加 5 后放回去"。

### 自增自减的小技巧

Rust **没有** `++` 这种符号。想加 1，写：

```rust
计数 += 1;
```

### 类型转换：`作为`

> 📖 **`作为`**：关键字，英文原名 as。把一个值临时"当作"另一种类型来用。

```rust
函数 主函数() {
    让 人数 = 7;
    让 人数为小数 = 人数 作为 浮点数;   // 先把 7 变成 7.0
    让 平均 = 人数为小数 / 2.0;          // 再除以 2.0，得 3.5
    打印行!("平均：{}", 平均);           // 3.5
}
```

逐行解释：

- 第 2 行：`人数` 是整数 7。
- 第 3 行：`人数 作为 浮点数` 把 7 临时当作 7.0，存进新盒子。原盒子里的 7 没变。
- 第 4 行：7.0 除以 2.0 得 3.5。

> ⚠️ **小心**：浮点数参与运算时，另一个数也要是浮点数写法（如 `2.0`）。`人数为小数 / 2` 会报错，因为整数和小数不能直接相除。

> ⚠️ **小心**：不要把 `作为` 和别的运算挤在一行，比如 `人数 作为 浮点数 / 2`——计算机的理解顺序可能和你想的不一样。拆成两行写最安全。

> 💡 **比喻**：`作为` 就像戴面具——整数戴上"浮点数面具"临时参加浮点数的活动，面具摘下来它还是原来的整数。

## 3.6 完整示例：学生信息卡程序

### 完整代码

```rust
// 学生信息卡程序
常量 满分: 整数 = 100;

函数 主函数() {
    // 基本信息（不可变，创建后不改）
    让 名字 = "小华";
    让 年龄 = 12;

    // 成绩（数学之后要更新，所以只有数学加"可变"）
    让 语文 = 88;
    让 可变 数学 = 95;

    // 先记录一下原来的数学成绩
    打印行!("数学原来：{}分", 数学);

    // 数学考了满分，更新一下
    数学 = 满分;

    // 计算总分和平均分
    让 总分 = 语文 + 数学;
    让 总分为小数 = 总分 作为 浮点数;
    让 平均分 = 总分为小数 / 2.0;

    // 打印信息卡
    打印行!("====== 学生信息卡 ======");
    打印行!("姓名：{}", 名字);
    打印行!("年龄：{}", 年龄);
    打印行!("语文：{}分", 语文);
    打印行!("数学：{}分", 数学);
    打印行!("总分：{}分", 总分);
    打印行!("平均分：{}", 平均分);
    打印行!("是否优秀：{}", 平均分 >= 90.0);
}
```

### 逐行解释

- 第 1 行：注释，说明这个程序是干什么的。
- 第 2 行：定义常量 `满分`，类型标注为 `整数`，值 100。它放在函数外面的最顶层，整个程序都能用。
- 第 6–7 行：创建两个不可变盒子装姓名和年龄——这些信息不会变。
- 第 10–11 行：创建两个盒子装成绩。语文不会变，不加 `可变`；数学等下要更新，加 `可变`。
- 第 14 行：先打印数学的原成绩 95。这一步让 95 被"用过"了，下一行才能放心换掉它。
- 第 17 行：把 `数学` 换成 `满分`（100）。注意没有写 `让`，这是换东西，不是造新盒子。
- 第 20 行：`语文 + 数学` = 88 + 100 = 188，装进新盒子 `总分`。
- 第 21 行：把总分 188 转成小数 188.0，存进新盒子 `总分为小数`。
- 第 22 行：188.0 除以 2.0 得 94.0。拆成两行写是为了避开"一行写太长、计算机理解错顺序"的坑。
- 第 25–32 行：逐行打印信息卡。每个 `{}` 被对应盒子的值填入。
- 第 32 行：`平均分 >= 90.0` 是一个比较，结果是布尔值 `真` 或 `假`。`>=` 意思是"大于或等于"，第五章详讲。和小数比较时，右边的 90 也要写成 90.0。
- 第 33 行：主函数结束。

### 运行结果

```
数学原来：95分
====== 学生信息卡 ======
姓名：小华
年龄：12
语文：88分
数学：100分
总分：188分
平均分：94
是否优秀：true
```

> ⚠️ **小心**：注意最后一行显示的是英文 `true`——因为布尔值的默认打印方式用的是英文原名。这不影响程序运行，第十一章后你会学会让它显示成你想要的样子。

## 3.7 遮蔽：同名新盒子盖住旧盒子

Rust 有个奇特现象：你可以用同一个名字再 `让` 一次，新盒子会"盖住"旧盒子：

```rust
函数 主函数() {
    让 数字 = 5;
    让 数字 = 数字 + 1;    // 新盒子盖住旧盒子，装 6
    让 数字 = 数字 * 2;    // 又一个新盒子，装 12
    打印行!("{}", 数字);   // 12
}
```

> 📖 **遮蔽**：英文 shadowing。用 `让` 创建同名新变量时，新变量遮蔽旧变量，之后喊这个名字找到的是新盒子。旧盒子还在，只是被"挡在影子后面"够不到了。

> 💡 **比喻**：就像叠罗汉——后来的同名盒子站在旧盒子肩上，你喊名字时，最上面那个答应。

遮蔽和 `可变` 的区别：

|      | 遮蔽                  | 可变                       |
|------|-----------------------|----------------------------|
| 写法 | 每次都写 `让`          | 只写一次 `让`，之后直接赋值 |
| 盒子 | 每次创建新盒子          | 始终是同一个盒子          |
| 类型 | 可以换成完全不同的类型  | 只能换同类型的值          |

## 3.8 常见错误与解决

### 错误 1：给不可变变量换值

```rust
让 分数 = 90;
分数 = 100;   // ❌
```

报错：`错误[E0384]: 不可变变量 `分数` 被重复赋值`，建议写着"请使用 `让 可变` 声明变量"。

**修法**：如果确实要改，创建时加 `可变`。

### 错误 2：用了没创建的盒子

```rust
打印行!("{}", 身高);   // ❌ 从来没"让 身高 = ..."过
```

报错大意：找不到叫 `身高` 的东西。

**修法**：检查名字是否拼错；确认先创建后使用。

### 错误 3：不同类型混算

```rust
让 甲 = 10;          // 整数
让 乙 = 3.5;         // 浮点数
让 总和 = 甲 + 乙;   // ❌ 整数和浮点数不能直接加
```

**修法**：用 `作为` 把其中一方转换，并且**拆成两行**写：

```rust
让 甲为小数 = 甲 作为 浮点数;
让 总和 = 甲为小数 + 乙;
```

### 错误 4：中文标点混进代码

```rust
让 名字 = "小华"；   // ❌ 结尾是中文分号；
```

报错通常指向这一行，说不认识的符号。

**修法**：切换到英文输入法，把 `；` 改成 `;`。记住口诀：**代码骨架用英文，引号里面才中文**。

### 练习 4：找错

下面的代码有一处错误，找出来并改正：

```rust
函数 主函数() {

    让 计数器 = 计数器 + 1;
    打印行!("{}", 计数器);
```

<details>
<summary>参考答案</summary>

```rust
计数器 = 计数器 + 1;
// 或者更简洁：计数器 += 1;
```

### 练习 5（挑战）：平均分

<details>
<summary>参考答案</summary>

```rust
    让 总分 = 语文 + 数学 + 英语;

```

</details>

## 3.11 常见问题（FAQ）

**问 1：为什么 Rust 默认不让改变量？别的语言都能改啊。**

答：这是 Rust 的安全设计。大部分数据其实不需要改；默认锁死能防止"不小心改掉"引起的 bug。真需要改时，加个 `可变` 就好，只是把"我要改它"这件事写得明明白白。

**问 2：`常量` 和不加 `可变` 的变量，到底什么时候用哪个？**

答：全程绝对不变、且整个程序都可能用到的值（如满分、圆周率）用常量；只在某个函数里用、本来也不会变的值，用普通变量就行。

**问 3：我写的数字太大会出问题吗？**

答：会。`整数`（i32）最大约 21 亿，超出会报错或溢出。大数用 `长整数`（i64）：`让 大数: 长整数 = 9999999999;`

**问 4：`真` 和 `"真"` 是一回事吗？**

答：不是。`真` 是布尔值（没有引号），`"真"` 是字符串（有引号，就是一个汉字）。就像数字 5 和文字"五"不是一回事。

**问 5：类型推断这么好，我是不是永远不用写类型标注？**

答：大多数时候不用写。但常量必须写；另外写出来能让代码更清楚，就像作文里多写一句解释总没坏处。

**问 6：为什么打印布尔值显示英文 true/false？**

答：Rust 内置的打印方式对布尔值用的就是英文。想让输出完全中文化，后面章节会教你格式化技巧。程序逻辑不受影响。

## 本章小结

1. **变量**是贴了标签的盒子，用 `让` 创建。
2. Rust 变量默认**不可变**；要改就加 `可变`。
3. **常量**永远不能改，必须写类型标注。
4. 四种基本类型：**整数**（45）、**浮点数**（3.14）、**布尔**（真/假）、**字符**（'优'）。
5. 运算：`+ - * / %`；改自己用 `+=`；换类型用 `作为`。
6. 整数除法会砍小数；想要小数结果用浮点数。
