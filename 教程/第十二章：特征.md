# 第十二章：特征

上一章学了泛型——写一次代码适用于多种类型。但泛型函数怎么知道类型 T 能做什么？如果 T 不能比较大小，你怎么写 `a >= b`？

答案是**特征**（trait）——定义类型"能做什么"。

---

## 12.1 什么是特征？

特征定义一组**行为**（方法），类型实现了这些行为，就"拥有"了这个特征。

```rust
特征 可摘要 {
    函数 摘要(&自我) -> 字符串;
}
```

这定义了一个叫 `可摘要` 的特征，要求实现者提供一个 `摘要` 方法。

---

## 12.2 实现特征

```rust
特征 可摘要 {
    函数 摘要(&自我) -> 字符串;
}

结构体 文章 {
    标题: 字符串,
    内容: 字符串,
}

实现 可摘要 对于 文章 {
    函数 摘要(&自我) -> 字符串 {
        格式化!("《{}》：{}...", 自我.标题, &自我.内容[..20.最小(自我.内容.长度())])
    }
}

结构体 推文 {
    用户名: 字符串,
    内容: 字符串,
}

实现 可摘要 对于 推文 {
    函数 摘要(&自我) -> 字符串 {
        格式化!("@{}：{}", 自我.用户名, 自我.内容)
    }
}

函数 主函数() {
    让 文章 = 文章 {
        标题: "Rust入门".转字符串(),
        内容: "Rust是一门注重安全和性能的语言...".转字符串(),
    };
    让 推文 = 推文 {
        用户名: "小明".转字符串(),
        内容: "今天学了 Rust！".转字符串(),
    };

    打印行!("{}", 文章.摘要());
    打印行!("{}", 推文.摘要());
}
```

- **`实现 可摘要 for 文章`** 表示为 `文章` 实现 `可摘要` 特征。
- 不同类型可以有不同的实现方式。

---

## 12.3 特征作为参数

特征最大的作用是**作为函数参数**——接受"任何实现了某特征的类型"：

```rust
特征 可打印 {
    函数 描述(&自我) -> 字符串;
}

结构体 猫;
结构体 狗;

实现 可打印 对于 猫 {
    函数 描述(&自我) -> 字符串 { "喵喵喵".转字符串() }
}

实现 可打印 对于 狗 {
    函数 描述(&自我) -> 字符串 { "汪汪汪".转字符串() }
}

// 参数接受任何实现了 可打印 的类型
函数 让动物说话(动物: &实现 可打印) {
    打印行!("动物说：{}", 动物.描述());
}

函数 主函数() {
    让 小猫 = 猫;
    让 小狗 = 狗;

    让动物说话(&小猫);
    让动物说话(&小狗);
}
```

`&impl 可打印` 读作"任何实现了 `可打印` 的类型的引用"。

---

## 12.4 特征对象

如果你需要在**同一个集合**中存放不同类型，用**特征对象**：

```rust
特征 形状 {
    函数 面积(&自我) -> 浮点数;
}

结构体 圆形 { 半径: 浮点数 }
结构体 方形 { 边长: 浮点数 }

实现 形状 对于 圆形 {
    函数 面积(&自我) -> 浮点数 {
        3.14159 * 自我.半径 * 自我.半径
    }
}

实现 形状 对于 方形 {
    函数 面积(&自我) -> 浮点数 {
        自我.边长 * 自我.边长
    }
}

函数 主函数() {
    // 用 盒子（Box）创建特征对象，存在堆上
    让 图形们: 向量<盒子<动态 形状>> = 向量![
        盒子::新建(圆形 { 半径: 5.0 }),
        盒子::新建(方形 { 边长: 4.0 }),
        盒子::新建(圆形 { 半径: 3.0 }),
    ];

    对于 图形 在 图形们 {
        打印行!("面积：{}", 图形.面积());
    }
}
```

- **`盒子<dyn 形状>`** 是特征对象——"任何实现了 `形状` 的类型"。
- **`dyn`** 表示"动态分发"——运行时才知道具体类型。

---

## 12.5 常用内置特征

Rust 标准库提供了很多有用的特征：

| 特征 | 作用 | 示例 |
|------|------|------|
| `可显示`（`Display`） | 用 `{}` 格式化输出 | 自定义打印格式 |
| `可调试`（`Debug`） | 用 `{:?}` 调试输出 | 开发时打印结构 |
| `可克隆`（`Clone`） | 用 `.克隆()` 深拷贝 | 复制数据 |
| `部分排序`（`PartialOrd`） | 用 `<` `>` 比较 | 排序 |
| `相等`（`PartialEq`） | 用 `==` `!=` 比较 | 判断相等 |

---

## 本章小结

1. **`特征`** 定义一组行为（方法签名）
2. **`实现 特征 for 类型`** 为类型实现特征
3. **`impl 特征`** 作为参数——接受任何实现了该特征的类型
4. **`盒子<dyn 特征>`** 特征对象——在集合中存放不同类型
5. 常用特征：`可显示`、`可调试`、`可克隆`、`部分排序`、`相等`
