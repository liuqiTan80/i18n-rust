# 第十二章：特征

上一章学了泛型——写一次代码适用于多种类型。但泛型函数怎么知道类型 T 能做什么？如果 T 不能比较大小，你怎么写 `a >= b`？

答案是**特征**（trait）——定义类型"能做什么"。

---

## 12.1 什么是特征

> 🎯 **生活类比**：特征就像一张**岗位说明书**。"司机"这个岗位要求你会开车——不管你开的是卡车、轿车还是公交车，只要你会开车，你就是"司机"。特征定义"会做什么"，类型通过**实现**特征来证明自己"会"。

```
┌──── 岗位说明书：可摘要 ────┐
│  要求：                     │
│    函数 摘要(&自我) -> 字符串 │
│                             │
│  谁能应聘？                  │
│  ┌──────┐ ┌──────┐         │
│  │ 文章 │ │ 推文 │  ...    │
│  │ ✅   │ │ ✅   │         │
│  └──────┘ └──────┘         │
└─────────────────────────────┘
```

```rust
特征 可摘要 {
    函数 摘要(&自我) -> 字符串;
}
```

这定义了一个叫 `可摘要` 的特征，要求实现者提供一个 `摘要` 方法。

---

## 12.2 实现特征

```rust
特征 可摘要 {
    函数 摘要(&自我) -> 字符串;
}

结构体 文章 {
    标题: 字符串,
    内容: 字符串,
}

实现 可摘要 对于 文章 {
    函数 摘要(&自我) -> 字符串 {
        格式化!("《{}》：{}...", 自我.标题, &自我.内容[..20.最小(自我.内容.长度())])
    }
}

结构体 推文 {
    用户名: 字符串,
    内容: 字符串,
}

实现 可摘要 对于 推文 {
    函数 摘要(&自我) -> 字符串 {
        格式化!("@{}：{}", 自我.用户名, 自我.内容)
    }
}

函数 主函数() {
    让 文章 = 文章 {
        标题: "Rust入门".转字符串(),
        内容: "Rust是一门注重安全和性能的语言...".转字符串(),
    };
    让 推文 = 推文 {
        用户名: "小明".转字符串(),
        内容: "今天学了 Rust！".转字符串(),
    };

    打印行!("{}", 文章.摘要());
    打印行!("{}", 推文.摘要());
}
```

- **`实现 可摘要 对于 文章`** 表示为 `文章` 实现 `可摘要` 特征。
- 不同类型可以有不同的实现方式——就像卡车司机和公交车司机的"开车方式"不同。

## 12.3 特征作为参数

特征最大的作用是**作为函数参数**——接受"任何实现了某特征的类型"：

```rust
特征 可打印 {
    函数 描述(&自我) -> 字符串;
}

结构体 猫;
结构体 狗;

实现 可打印 对于 猫 {
    函数 描述(&自我) -> 字符串 { "喵喵喵".转字符串() }
}

实现 可打印 对于 狗 {
    函数 描述(&自我) -> 字符串 { "汪汪汪".转字符串() }
}

// 参数接受任何实现了 可打印 的类型
函数 让动物说话(动物: &实现 可打印) {
    打印行!("动物说：{}", 动物.描述());
}

函数 主函数() {
    让 小猫 = 猫;
    让 小狗 = 狗;

    让动物说话(&小猫);  // "喵喵喵"
    让动物说话(&小狗);  // "汪汪汪"
}
```

```
┌── 让动物说话 ──────────────────────┐
│  参数：&实现 可打印                  │
│  含义：任何实现了"可打印"的东西     │
│                                    │
│  传入猫 → 猫实现了可打印 → ✅      │
│  传入狗 → 狗实现了可打印 → ✅      │
│  传入石头 → 石头没实现 → ❌        │
└────────────────────────────────────┘
```

## 12.4 特征对象

如果你需要在**同一个集合**中存放不同类型，用**特征对象**：

```rust
特征 形状 {
    函数 面积(&自我) -> 浮点数;
}

结构体 圆形 { 半径: 浮点数 }
结构体 方形 { 边长: 浮点数 }

实现 形状 对于 圆形 {
    函数 面积(&自我) -> 浮点数 {
        3.14159 * 自我.半径 * 自我.半径
    }
}

实现 形状 对于 方形 {
    函数 面积(&自我) -> 浮点数 {
        自我.边长 * 自我.边长
    }
}

函数 主函数() {
    // 用 盒子（Box）创建特征对象，存在堆上
    让 图形们: 向量<盒子<动态 形状>> = 向量![
        盒子::新建(圆形 { 半径: 5.0 }),
        盒子::新建(方形 { 边长: 4.0 }),
        盒子::新建(圆形 { 半径: 3.0 }),
    ];

    对于 图形 在 图形们 {
        打印行!("面积：{}", 图形.面积());
    }
}
```

```
向量<盒子<动态 形状>>
┌──────────────────────────────────┐
│ [0] 盒子 → 圆形 { 半径: 5.0 }   │  → 面积 = 78.54
│ [1] 盒子 → 方形 { 边长: 4.0 }   │  → 面积 = 16.0
│ [2] 盒子 → 圆形 { 半径: 3.0 }   │  → 面积 = 28.27
└──────────────────────────────────┘
  不同类型可以放在同一个向量里！
  因为它们都"实现了形状特征"
```

- **`盒子<动态 形状>`** 是特征对象——"任何实现了 `形状` 的类型"。
- **`动态`** 表示"动态分发"——运行时才知道具体类型。

## 12.5 常用内置特征

Rust 标准库提供了很多有用的特征：

| 特征 | 作用 | 怎么用 |
|------|------|--------|
| `可显示`（Display） | 用 `{}` 格式化输出 | 自定义打印格式 |
| `可调试`（Debug） | 用 `{:?}` 调试输出 | `#[派生(可调试)]` |
| `可克隆`（Clone） | 用 `.克隆()` 深拷贝 | 复制数据 |
| `部分排序`（PartialOrd） | 用 `<` `>` 比较 | 排序 |
| `相等`（PartialEq） | 用 `==` `!=` 比较 | 判断相等 |

```rust
#[派生(可调试, 可克隆, 相等)]
结构体 点 {
    x: 整数,
    y: 整数,
}

函数 主函数() {
    让 p1 = 点 { x: 1, y: 2 };
    让 p2 = p1.克隆();
    打印行!("{:?}", p1);       // 点 { x: 1, y: 2 }
    打印行!("相等？{}", p1 == p2);  // 真
}
```

## 常见错误

### ❌ 忘记实现特征

```rust
特征 可打招呼 { 函数 你好(&自我); }
结构体 猫;
// 忘记实现！
函数 主函数() {
    让 c = 猫;
    // c.你好();  // ❌ 猫没有实现 可打招呼
}
```

### ❌ 在集合中混放不同类型（不用特征对象）

```rust
结构体 猫; 结构体 狗;
函数 主函数() {
    // 让 动物们 = 向量![猫, 狗];  // ❌ 类型不同不能放一起
    // 修复：用 盒子<动态 特征>
}
```

### ❌ 特征方法签名不匹配

```rust
特征 可摘要 { 函数 摘要(&自我) -> 字符串; }
结构体 文章 { 标题: 字符串 }

实现 可摘要 对于 文章 {
    // 函数 摘要(&自我) -> &文本 { &自我.标题 }  // ❌ 返回类型不对
    // 修复：返回 字符串
    函数 摘要(&自我) -> 字符串 { 自我.标题.克隆() }
}
```

<details>
<summary>参考答案</summary>

```rust
结构体 学生 { 姓名: 字符串, 成绩: 浮点数 }

实现 标准库::fmt::显示 对于 学生 {
    函数 fmt(&自我, f: &可变 标准库::fmt::格式化器) -> 标准库::fmt::结果 {
        写入格式化!(f, "学生({}, {}分)", 自我.姓名, 自我.成绩)
    }

函数 主函数() {
    让 s = 学生 { 姓名: "小明".转字符串(), 成绩: 95.5 };

}
```

### 练习 2：特征对象集合

定义 `动物` 特征（有 `叫声` 方法），为 `猫` 和 `狗` 实现。创建一个 `向量<盒子<动态 动物>>` 并遍历打印叫声。

<details>

```rust
特征 动物 {
    函数 叫声(&自我) -> &文本;

结构体 猫;
结构体 狗;

实现 动物 对于 猫 {
    函数 叫声(&自我) -> &文本 { "喵~" }

        盒子::新建(狗),
        盒子::新建(猫),

    对于 动物 在 动物园 {
        打印行!("{}", 动物.叫声());
```

## 本章小结

| 概念 | 一句话 |
|------|--------|
| `特征` | 定义一组行为（方法签名）——岗位说明书 |
| `实现 特征 对于 类型` | 为类型实现特征——应聘上岗 |
| `&实现 特征` | 参数接受任何实现了该特征的类型 |
| `盒子<动态 特征>` | 特征对象——在集合中存放不同类型 |
| `#[派生(...)]` | 自动实现常用特征 |
