# 第八章：字符串与文本

在 Rust 中，"字符串"比你想象的要复杂。其他语言可能只有一种字符串类型，但 Rust 有两种：**`字符串`**（`String`）和**`文本`**（`&str`，也叫字符串切片）。

这一章，我们彻底搞懂它们。

---

## 8.1 两种字符串类型

### 生活类比

```
文本（&str）—— 像一张照片
  → 你拍了一张照片，不能修改照片里的内容
  → 只能看，不能改

字符串（String）—— 像一块画板
  → 你可以在画板上画画、修改
  → 但画板需要占地方（堆内存）
```

### `文本`（`&str`）—— 字符串切片

`文本` 是对一段已有字符串的**引用**。它不能修改，只能"看"。

```rust
函数 主函数() {
    让 问候 = "你好世界";  // 这是 &str（字符串字面量）
    打印行!("{}", 问候);
}
```

字符串字面量（直接写在代码里的文字）就是 `&str` 类型。它被硬编码到程序中，不可修改。

### `字符串`（`String`）—— 可增长的字符串

`字符串` 是存储在堆上的、可以修改的字符串：

```rust
函数 主函数() {
    让 可变 s = 字符串::新建();  // 创建空字符串
    s.推入字符串("你好");
    s.推入字符串("世界");

    打印行!("{}", s);  // 你好世界
}
```

## 8.2 创建字符串

```rust
函数 主函数() {
    // 方式一：从字面量创建
    让 s1 = "你好".转字符串();

    // 方式二：使用构造函数
    让 s2 = 字符串::新建();

    // 方式三：从格式化创建
    让 名字 = "小明";
    让 s3 = 格式化!("你好，{}", 名字);

    打印行!("s1 = {}", s1);
    打印行!("s2 = '{}'", s2);
    打印行!("s3 = {}", s3);
}
```

> ✨ **宏调用提示**：本章首次出现 `格式化!` 宏。和 `打印行` 一样，你不需要手动写感叹号——`格式化!("...")` 和 `格式化("...")` 都可以，工具会自动补上 `!`。

---

## 8.3 字符串操作

### 追加内容

```rust
函数 主函数() {
    让 可变 s = "你好".转字符串();

    s.推入字符串("世界");     // 追加字符串
    s.推('！');            // 追加单个字符

    打印行!("{}", s);  // 你好世界！
}
```

### 拼接字符串

```rust
函数 主函数() {
    让 s1 = "你好".转字符串();
    让 s2 = "世界".转字符串();

    让 s3 = s1 + &s2;  // 拼接（注意：s1 被移动了）

    打印行!("{}", s3);  // 你好世界
    // 打印行!("{}", s1);  // ❌ s1 已经无效
    打印行!("{}", s2);  // ✅ s2 仍然有效
}
```

> **注意**：`+` 操作符会"消耗"左边的字符串。如果想保留两者，用 `格式化!`。

### 使用格式化拼接

```rust
函数 主函数() {
    让 s1 = "你好".转字符串();
    让 s2 = "世界".转字符串();

    让 s3 = 格式化!("{}{}", s1, s2);  // 不消耗 s1 和 s2

    打印行!("s1 = {}", s1);  // ✅ 仍然有效
    打印行!("s2 = {}", s2);  // ✅ 仍然有效
    打印行!("s3 = {}", s3);
}
```

### 替换与查找

```rust
函数 主函数() {
    让 s = "我喜欢猫，猫很可爱".转字符串();

    让 替换后 = s.替换("猫", "狗");
    打印行!("{}", 替换后);  // 我喜欢狗，狗很可爱

    打印行!("包含'猫'：{}", s.包含("猫"));  // 真
    打印行!("长度：{}", s.长度());  // 字节长度
}
```

## 8.4 遍历字符串

Rust 的字符串是 UTF-8 编码的，所以不能直接用索引访问字符。

### 遍历字符

```rust
函数 主函数() {
    让 s = "你好Rust";

    对于 c 在 s.逐字符() {
        打印!("{} ", c);
    }
    打印行!();
    // 输出：你 好 R u s t
}
```

### 遍历行

```rust
函数 主函数() {
    让 文本 = "第一行\n第二行\n第三行";

    对于 行 在 文本.逐行() {
        打印行!("> {}", 行);
    }
}
```

## 8.5 UTF-8 编码

Rust 的字符串是 UTF-8 编码的。这意味着：

- 英文字符占 **1 个字节**
- 中文字符占 **3 个字节**
- emoji 占 **4 个字节**

```rust
函数 主函数() {
    让 英文 = "hello";
    让 中文 = "你好";

    打印行!("英文字节数：{}", 英文.长度());  // 5
    打印行!("中文字节数：{}", 中文.长度());  // 6（每个汉字 3 字节）

    打印行!("英文字符数：{}", 英文.逐字符().计数());  // 5
    打印行!("中文字符数：{}", 中文.逐字符().计数());  // 2
}
```

> **为什么用字节长度而不是字符数？** 因为 UTF-8 是变长编码，计算字符数需要遍历整个字符串，而字节长度是 O(1) 的。

## 8.6 字符串切片

你可以用切片获取字符串的一部分：

```rust
函数 主函数() {
    让 s = "你好世界".转字符串();

    // 注意：切片按字节索引，不是字符索引
    让 切片 = &s[0..6];  // 前 6 个字节 = 前 2 个中文字符
    打印行!("{}", 切片);  // 你好
}
```

> **警告**：如果切片的字节边界不在字符边界上，程序会崩溃。所以对于中文，建议用 `.逐字符()` 遍历。

## 8.7 常见错误

### 错误 1：用索引访问中文字符

```rust
让 s = "你好";
打印行!("{}", s[0]);  // ❌ 不能直接用索引访问字符
```

**修复**：用 `.逐字符()` → `s.逐字符().第0个()`

### 错误 2：切片边界不在字符边界

```rust
让 s = "你好";
让 切片 = &s[0..2];  // ❌ 2 不是字符边界（中文占 3 字节）
```

**修复**：用字符遍历代替字节切片。

### 错误 3：拼接后使用已移动的字符串

```rust
让 s1 = "你好".转字符串();
让 s2 = "世界".转字符串();
让 s3 = s1 + &s2;
打印行!("{}", s1);  // ❌ s1 已被移动
```

**修复**：用 `格式化!` → `格式化!("{}{}", s1, s2)`

## 8.8 `字符串` vs `文本`

什么时候用哪个？

| 特性 | `字符串`（String） | `文本`（&str） |
|------|-------------------|----------------|
| 可以修改 | ✅ | ❌ |
| 存储在 | 堆上 | 任意位置 |
| 拥有数据 | ✅ 拥有 | ❌ 借用 |
| 性能 | 需要分配内存 | 零成本引用 |

**经验法则**：
- 函数参数尽量用 **`&文本`**（`&str`）—— 更灵活，`String` 和 `&str` 都能传入
- 需要修改或存储字符串时用 **`字符串`**（`String`）

```rust
// ✅ 推荐：参数用 &文本
函数 打招呼(名字: &文本) {
    打印行!("你好，{}！", 名字);
}

函数 主函数() {
    让 s = "小明".转字符串();
    打招呼(&s);       // String 可以当 &str 用
    打招呼("小红");    // &str 直接用
}
```

## 8.9 练习题

### 练习 1：统计字符

写一个程序，统计字符串 "Hello你好世界" 中英文字符和中文字符各有多少个。

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 s = "Hello你好世界";
    让 可变 英文数 = 0;
    让 可变 中文数 = 0;

    对于 c 在 s.逐字符() {
        如果 c.是字母() {
            如果 c.是ascii() {
                英文数 += 1;
            } 否则 {
                中文数 += 1;
            }
        }
    }

    打印行!("英文字符：{}", 英文数);
    打印行!("中文字符：{}", 中文数);
}
```

</details>

### 练习 2：反转字符串

写一个函数，将字符串中的字符顺序反转。

<details>
<summary>参考答案</summary>

```rust
函数 反转(s: &文本) -> 字符串 {
    s.逐字符().收集::<字符串>().chars().rev().收集()
}
```

更简单的方式：

```rust
函数 反转(s: &文本) -> 字符串 {
    让 可变 结果 = 字符串::新建();
    让 字符们: 向量<字符> = s.逐字符().收集();
    对于 i 在 (0..字符们.长度()).rev() {
        结果.推(字符们[i]);
    }
    结果
}
```

</details>

## 本章小结

1. **`字符串`**（`String`）：可修改、存储在堆上、拥有数据
2. **`文本`**（`&str`）：不可修改、引用、零成本
3. 用 `.推入字符串()` 追加，用 `+` 或 `格式化!` 拼接
4. 用 `.逐字符()` 遍历字符，用 `.逐行()` 遍历行
5. Rust 字符串是 UTF-8 编码，中文占 3 字节
6. 函数参数推荐用 `&文本`（`&str`）
