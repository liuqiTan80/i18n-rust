# 第四章：控制流

到目前为止，我们的程序都是"从上往下"一行行执行的。但真正的程序需要**做决策**——根据条件走不同的路，或者重复做某件事。

这一章，我们学习控制程序流程的三大工具：

```
控制流三大工具
┌────────────────────────────────────────────┐
│ 条件分支  │ 根据条件选择走哪条路             │
│ 匹配      │ 把值和多个模式逐一比较           │
│ 循环      │ 重复执行某段代码                │
└────────────────────────────────────────────┘
```

---

## 4.1 如果 / 否则

### 生活类比

想象你早上出门前看天气：

```
如果 下雨 {
    带伞
} 否则 {
    戴墨镜
}
```

这就是**条件分支**——根据条件决定做哪件事。

### 基本语法

```rust
函数 主函数() {
    让 年龄 = 18;

    如果 年龄 >= 18 {
        打印行!("你已经成年了。");
    }
}
```

流程图：

```
        ┌─────────────┐
        │ 年龄 >= 18 ? │
        └──────┬──────┘
          真 ↙    ↘ 假
    ┌────────┐   ┌────────┐
    │ 输出    │   │ 跳过    │
    │ "已成年"│   │        │
    └────────┘   └────────┘
```

### 加上 `否则`

```rust
函数 主函数() {
    让 温度 = 35;

    如果 温度 > 30 {
        打印行!("好热啊！");
    } 否则 {
        打印行!("还行。");
    }
}
```

流程图：

```
        ┌─────────────┐
        │ 温度 > 30 ?  │
        └──────┬──────┘
          真 ↙    ↘ 假
    ┌────────┐   ┌────────┐
    │ "好热" │   │ "还行" │
    └────────┘   └────────┘
```

### 多个条件：`否则 如果`

```rust
函数 主函数() {
    让 分数 = 85;

    如果 分数 >= 90 {
        打印行!("优秀！");
    } 否则 如果 分数 >= 80 {
        打印行!("良好。");
    } 否则 如果 分数 >= 60 {
        打印行!("及格。");
    } 否则 {
        打印行!("不及格。");
    }
}
```

执行过程（像下楼梯一样，逐个检查）：

```
分数 = 85
  │
  ├─ >= 90? → 否 → 下一个
  ├─ >= 80? → 是 → 输出 "良好" → 结束
  │  （后面的不再检查）
  ├─ >= 60? → 不检查了
  └─ 否则   → 不检查了
```

> **重要**：条件从上到下逐个检查，一旦某个条件为真，就执行对应的代码，**后面的全部跳过**。

### 条件也是表达式

在 Rust 中，`如果` 是一个**表达式**——它会返回一个值：

```rust
函数 主函数() {
    让 分数 = 85;
    让 等级 = 如果 分数 >= 60 { "及格" } 否则 { "不及格" };
    //              ↑ 条件为真时返回这个    ↑ 条件为假时返回这个

    打印行!("成绩：{}", 等级);
}
```

> **注意**：两个分支返回的类型必须一致。不能一个返回整数，另一个返回文本。

## 4.2 匹配

### 生活类比

想象自动售货机——你按下不同的按钮，得到不同的饮料：

```
按钮 1 → 可乐
按钮 2 → 雪碧
按钮 3 → 果汁
其他   → 矿泉水（默认）
```

`匹配` 就是这样的多分支选择。

### 基本用法

```rust
函数 主函数() {
    让 数字 = 3;

    匹配 数字 {
        1 => 打印行!("一"),
        2 => 打印行!("二"),
        3 => 打印行!("三"),    // ← 匹配到了！执行这行
        _ => 打印行!("其它"),
    }
}
```

- 每个分支用 `=>` 连接**模式**和**代码**
- **`_`** 是通配符，匹配所有其他情况（类似"其他"按钮）
- `匹配` 要求**穷尽所有可能**——必须覆盖所有情况，否则编译报错

### 匹配范围

```rust
函数 主函数() {
    让 分数 = 85;

    匹配 分数 {
        90..=100 => 打印行!("优秀"),
        80..=89  => 打印行!("良好"),
        60..=79  => 打印行!("及格"),
        _        => 打印行!("不及格"),
    }
}
```

`90..=100` 表示从 90 到 100 的**闭区间**（包含 90 和 100）。

### 匹配返回值

```rust
函数 主函数() {
    让 数字 = 7;
    让 描述 = 匹配 数字 {
        1 => "一",
        2 => "二",
        3 => "三",
        _ => "其它",
    };

    打印行!("{} 是 {}", 数字, 描述);
}
```

## 4.3 循环

### 三种循环一览

```
┌──────────────────────────────────────────────────┐
│ 循环类型  │ 什么时候用         │ 类比              │
├──────────────────────────────────────────────────┤
│ 循环      │ 不确定要执行多少次  │ "一直做，直到我说停"│
│ 当        │ 条件为真时重复     │ "只要下雨就带伞"    │
│ 对于      │ 遍历一组数据       │ "把每封信都读一遍"  │
└──────────────────────────────────────────────────┘
```

### `循环` —— 无限循环

```rust
函数 主函数() {
    让 可变 计数 = 0;

    循环 {
        如果 计数 >= 5 {
            中断;  // 跳出循环
        }
        打印行!("计数：{}", 计数);
        计数 += 1;
    }
}
```

输出：

```
计数：0
计数：1
计数：2
计数：3
计数：4
```

- **`循环`**（`loop`）会无限重复执行代码块
- **`中断`**（`break`）用来跳出循环

### `当` —— 条件循环

```rust
函数 主函数() {
    让 可变 计数 = 0;

    当 计数 < 5 {
        打印行!("计数：{}", 计数);
        计数 += 1;
    }
}
```

执行过程：

```
计数 = 0 → 0 < 5? 是 → 输出 0 → 计数 = 1
计数 = 1 → 1 < 5? 是 → 输出 1 → 计数 = 2
计数 = 2 → 2 < 5? 是 → 输出 2 → 计数 = 3
计数 = 3 → 3 < 5? 是 → 输出 3 → 计数 = 4
计数 = 4 → 4 < 5? 是 → 输出 4 → 计数 = 5
计数 = 5 → 5 < 5? 否 → 停止
```

### `对于` —— 遍历循环（最常用）

```rust
函数 主函数() {
    让 水果 = ["苹果", "香蕉", "橘子"];

    对于 水果 在 水果 {
        打印行!("我喜欢吃{}", 水果);
    }
}
```

输出：

```
我喜欢吃苹果
我喜欢吃香蕉
我喜欢吃橘子
```

- **`对于 ... 在 ...`** 遍历集合中的每个元素
- 这是**最常用**的循环方式

### 范围遍历

```rust
函数 主函数() {
    // 0..5 表示 0, 1, 2, 3, 4（不包含 5）
    对于 i 在 0..5 {
        打印行!("i = {}", i);
    }

    打印行!("---");

    // 1..=5 表示 1, 2, 3, 4, 5（包含 5）
    对于 i 在 1..=5 {
        打印行!("i = {}", i);
    }
}
```

> **记忆技巧**：`..` 是"到但不包括"，`..=` 是"到且包括"。

### `继续` —— 跳过这一次

**`继续`**（`continue`）跳过当前这一次，进入下一次循环：

```rust
函数 主函数() {
    对于 i 在 0..10 {
        如果 i % 2 == 0 {
            继续;  // 跳过偶数，进入下一次
        }
        打印行!("奇数：{}", i);
    }
}
```

输出：

```
奇数：1
奇数：3
奇数：5
奇数：7
奇数：9
```

## 4.4 嵌套控制流

控制流可以互相嵌套——就像俄罗斯套娃：

```rust
函数 主函数() {
    对于 行 在 1..=3 {
        对于 列 在 1..=3 {
            如果 行 == 列 {
                打印!("* ");
            } 否则 {
                打印!(". ");
            }
        }
        打印行!();  // 换行
    }
}
```

输出：

```
* . .
. * .
. . *
```

执行过程（逐行逐列）：

```
行=1: 列=1(==)→*  列=2(≠)→.  列=3(≠)→.   → "* . ."
行=2: 列=1(≠)→.  列=2(==)→*  列=3(≠)→.   → ". * ."
行=3: 列=1(≠)→.  列=2(≠)→.  列=3(==)→*  → ". . *"
```

## 4.5 常见错误

### 错误 1：忘记花括号

```rust
如果 真
    打印行!("你好");  // ❌ 缺少花括号
```

**修复**：加上 `{}` → `如果 真 { 打印行!("你好"); }`

### 错误 2：匹配没有穷尽所有情况

```rust
让 数字 = 3;
匹配 数字 {
    1 => 打印行!("一"),
    2 => 打印行!("二"),
    // ❌ 缺少 _ 通配符或其他分支覆盖 3
}
```

**修复**：加上 `_ => ...`

### 错误 3：无限循环忘记中断

```rust
循环 {
    打印行!("你好");
    // ❌ 没有 中断; → 永远停不下来
}
```

**修复**：加上退出条件 → `如果 某条件 { 中断; }`

## 4.6 动手实验

### 实验 1：猜数字游戏

```rust
函数 主函数() {
    让 答案 = 7;
    让 猜测 = [3, 5, 7, 9];

    对于 猜 在 猜测 {
        打印行!("猜了 {}", 猜);
        如果 猜 < 答案 {
            打印行!("太小了！");
        } 否则 如果 猜 > 答案 {
            打印行!("太大了！");
        } 否则 {
            打印行!("恭喜，猜对了！");
        }
    }
}
```

### 实验 2：打印乘法表

```rust
函数 主函数() {
    对于 i 在 1..=9 {
        对于 j 在 1..=i {
            打印!("{}×{}={} ", j, i, i * j);
        }
        打印行!();
    }
}
```

### 实验 3：用匹配判断季节

```rust
函数 主函数() {
    让 月份 = 8;

    匹配 月份 {
        3..=5  => 打印行!("春天"),
        6..=8  => 打印行!("夏天"),
        9..=11 => 打印行!("秋天"),
        _      => 打印行!("冬天"),
    }
}
```

## 4.7 练习题

### 练习 1：成绩评级

写一个程序，根据分数输出等级：
- 90-100: A
- 80-89: B
- 70-79: C
- 60-69: D
- 0-59: F

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 分数 = 85;
    让 等级 = 匹配 分数 {
        90..=100 => "A",
        80..=89  => "B",
        70..=79  => "C",
        60..=69  => "D",
        _        => "F",
    };
    打印行!("分数 {} 的等级是 {}", 分数, 等级);
}
```

</details>

### 练习 2：FizzBuzz

输出 1 到 30，但是：
- 3 的倍数输出 "Fizz"
- 5 的倍数输出 "Buzz"
- 既是 3 又是 5 的倍数输出 "FizzBuzz"

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    对于 i 在 1..=30 {
        如果 i % 15 == 0 {
            打印行!("FizzBuzz");
        } 否则 如果 i % 3 == 0 {
            打印行!("Fizz");
        } 否则 如果 i % 5 == 0 {
            打印行!("Buzz");
        } 否则 {
            打印行!("{}", i);
        }
    }
}
```

</details>

### 练习 3：打印菱形

用嵌套循环输出一个菱形：

```
  *
 ***
*****
 ***
  *
```

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    // 上半部分（含中间最宽行）
    对于 i 在 0..3 {
        对于 _ 在 0..(2 - i) {
            打印!(" ");
        }
        对于 _ 在 0..(2 * i + 1) {
            打印!("*");
        }
        打印行!();
    }
    // 下半部分
    对于 i 在 0..2 {
        对于 _ 在 0..(i + 1) {
            打印!(" ");
        }
        对于 _ 在 0..(3 - 2 * i) {
            打印!("*");
        }
        打印行!();
    }
}
```

</details>

## 本章小结

1. **`如果`/`否则 如果`/`否则`** —— 条件分支，也是表达式（可以返回值）
2. **`匹配`** —— 多模式匹配，必须穷尽所有情况，支持范围 `..=`
3. **`循环`** —— 无限循环，用 `中断` 跳出
4. **`当`** —— 条件循环，条件为假时停止
5. **`对于 ... 在 ...`** —— 遍历循环，最常用的循环方式
6. **`继续`** —— 跳过当前循环迭代
