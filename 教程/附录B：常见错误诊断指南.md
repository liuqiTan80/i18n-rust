# 附录 B：常见错误诊断指南

学 Rust 的过程中，你会频繁遇到编译错误。别慌——Rust 的编译器以"友好"著称，错误信息非常详细。

本附录帮你快速理解最常见的错误。

---

## B.1 类型不匹配（E0308）

```
错误[E0308]: 类型不匹配
  --> src/main.zh:3:18
   |
3  |     让 x: 整数 = "你好";
   |                  ^^^^^^ 期望 整数，实际得到 &文本
💡 你不能把字符串赋值给整数变量。检查类型标注是否正确。
```

**原因**：变量类型和值的类型不一致。

**解决**：检查类型标注，或者去掉类型标注让编译器推断。

---

## B.2 未找到模块（E0433）

```
错误[E0433]: 未找到模块 `不存在的模块`
  --> src/main.zh:1:5
   |
1  | 使用 不存在的模块::某函数;
   |      ^^^^^^^^^^^^^^^^^^^^
💡 请检查模块名是否拼写正确，以及是否在 Cargo.toml 中添加了依赖。
```

**原因**：模块名拼写错误，或依赖未安装。

**解决**：检查拼写，运行 `cargo build` 确认依赖已下载。

---

## B.3 不可变变量赋值（E0384）

```
错误[E0384]: 不可变变量 数量 被重复赋值
  --> src/main.zh:3:5
   |
2  |     让 数量 = 10;
   |         ----- 首次声明为不可变
3  |     数量 = 20;
   |     ^^^^^^^^ 不能赋值
💡 如果需要修改变量，在声明时加上 `可变`：让 可变 数量 = 10;
```

**原因**：尝试修改不可变变量。

**解决**：在声明时加上 `可变` 关键字。

---

## B.4 移动后使用（E0382）

```
错误[E0382]: 移动后使用 列表1
  --> src/main.zh:4:22
   |
2  |     让 列表1 = 向量![1, 2, 3];
3  |     让 列表2 = 列表1;  // 所有权转移
4  |     打印行!("{:?}", 列表1);  // ❌ 已移动
   |                      ^^^^^ 值已移动
💡 使用 .克隆() 复制数据：让 列表2 = 列表1.克隆();
```

**原因**：值的所有权已转移给另一个变量。

**解决**：用 `.克隆()` 复制，或调整代码顺序在移动前使用。

---

## B.5 借用规则违反（E0502）

```
错误[E0502]: 不能借用 数据 为可变，因为它也被借用为不可变
  --> src/main.zh:5:5
   |
3  |     让 不可变引用 = &数据;
4  |     打印行!("{}", 不可变引用);
5  |     数据.推(4);  // ❌ 有不可变借用时不能修改
💡 确保不可变引用不再使用后，再进行可变操作。
```

**原因**：同时存在不可变借用和可变借用。

**解决**：确保不可变引用的作用域结束后再进行可变操作。

---

## B.6 两个可变借用（E0499）

```
错误[E0499]: 不能同时可变借用 数据 超过一次
  --> src/main.zh:4:18
   |
3  |     让 r1 = &mut 数据;
4  |     让 r2 = &mut 数据;  // ❌
💡 同一时间只能有一个可变引用。
```

**原因**：同时存在多个可变引用。

**解决**：确保前一个可变引用不再使用后，再创建新的。

---

## B.7 特征未实现（E0277）

```
错误[E0277]: 类型 `学生` 没有实现 `可显示` 特征
  --> src/main.zh:5:22
   |
5  |     打印行!("{}", 学生);
   |                      ^^^^ `学生` 不能打印
💡 在结构体上方添加 #[derive(Debug)] 或使用 {:?} 格式。
```

**原因**：类型没有实现所需的特征。

**解决**：为类型实现所需特征，或使用 `#[derive(Debug)]` 自动派生。

---

## B.8 未找到变量（E0425）

```
错误[E0425]: 未找到名称 `变量名`
  --> src/main.zh:3:18
   |
3  |     打印行!("{}", 变量名);
   |                  ^^^^^^^^ 未在此作用域中声明
💡 检查变量名拼写，以及是否在正确的作用域中声明。
```

**原因**：变量名拼写错误或未在作用域中声明。

**解决**：检查拼写和变量声明位置。

---

## B.9 类型推断失败（E0282）

```
错误[E0282]: 无法推断类型
  --> src/main.zh:2:9
   |
2  |     让 x = 默认();
   |         - 需要类型标注
💡 请标注类型：让 x: 整数 = 默认();
```

**原因**：编译器无法推断变量类型。

**解决**：手动添加类型标注。

---

## B.10 缺少 main 函数（E0601）

```
错误[E0601]: 未找到 main 函数
💡 每个可执行程序必须有一个 `函数 主函数()` 作为入口。
```

**原因**：缺少程序入口函数。

**解决**：添加 `函数 主函数() { ... }`。

---

## 通用排查技巧

1. **先读错误信息的 💡 提示**——rzc 会给出中文教学建议
2. **看行号**——错误信息会精确指出哪一行出了问题
3. **看"期望/实际"**——类型不匹配时，编译器会告诉你期望什么类型、实际是什么类型
4. **一次只修一个错误**——Rust 的错误会级联，修好第一个可能后面几个自动消失
5. **用 `rzc check`**——在运行前先检查，更快定位问题
