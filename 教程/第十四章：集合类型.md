# 第十四章：集合类型

到目前为止，我们用过的集合只有数组——固定长度、相同类型。但实际开发中，我们需要更灵活的集合。

这一章学习三种最常用的集合：**向量**、**哈希映射**和**哈希集**。

---

## 14.1 向量（Vec）

> 🎯 **生活类比**：向量就像一列**储物柜**——可以不断加新柜子，每个柜子放同一种东西。你随时可以往末尾加、从末尾取、按编号找。

```
向量: [苹果, 香蕉, 橘子]
       0      1      2     ← 索引
  ↑ 推()                    ↑ 弹()
  从末尾加                   从末尾取
```

> ✨ **宏调用提示**：本章首次出现 `向量!` 宏。记住，你不需要手动写感叹号——`向量![1, 2, 3]` 和 `向量[1, 2, 3]` 都可以，工具会自动补上 `!`。

### 创建向量

```rust
函数 主函数() {
    // 方式一：用宏创建
    让 数字 = 向量![1, 2, 3, 4, 5];

    // 方式二：新建空向量
    让 可变 水果 = 向量::<字符串>::新建();
    水果.推("苹果".转字符串());
    水果.推("香蕉".转字符串());

    打印行!("数字：{:?}", 数字);
    打印行!("水果：{:?}", 水果);
}
```

### 访问元素

```rust
函数 主函数() {
    让 水果 = 向量!["苹果".转字符串(), "香蕉".转字符串(), "橘子".转字符串()];

    // 方式一：用索引（越界会 panic）
    打印行!("第一个：{}", 水果[0]);

    // 方式二：用 get（安全，返回 选项）
    匹配 水果.获取(1) {
        有些(水果名) => 打印行!("第二个：{}", 水果名),
        无 => 打印行!("不存在"),
    }
}
```

### 遍历向量

```rust
函数 主函数() {
    让 可变 数字 = 向量![1, 2, 3];

    // 不可变遍历
    对于 n 在 &数字 {
        打印行!("{}", n);
    }

    // 可变遍历（可以修改）
    对于 n 在 &可变 数字 {
        *n *= 2;
    }

    打印行!("翻倍后：{:?}", 数字);  // [2, 4, 6]
}
```

## 14.2 哈希映射（HashMap）

> 🎯 **生活类比**：哈希映射就像一本**字典**——每个"词条"（键）对应一个"解释"（值）。你通过词条名查找解释，速度极快。

```
┌── 字典（哈希映射）──┐
│  "小明" → 95分      │
│  "小红" → 88分      │
│  "小刚" → 72分      │
└─────────────────────┘
  键         值
  查找 O(1)！
```

```rust
使用 标准库::集合::哈希映射;

函数 主函数() {
    让 可变 成绩 = 哈希映射::新建();
    成绩.插入("小明".转字符串(), 95);
    成绩.插入("小红".转字符串(), 88);
    成绩.插入("小刚".转字符串(), 72);

    // 查找
    匹配 成绩.获取("小明") {
        有些(分数) => 打印行!("小明：{}分", 分数),
        无 => 打印行!("未找到"),
    }

    // 遍历
    对于 (名字, 分数) 在 &成绩 {
        打印行!("{}：{}分", 名字, 分数);
    }
}
```

### 更新哈希映射

```rust
使用 标准库::集合::哈希映射;

函数 主函数() {
    让 可变 计数 = 哈希映射::新建();

    // 插入新键值对
    计数.插入("苹果", 3);

    // 更新已有值
    计数.插入("苹果", 5);  // 覆盖

    // 只在键不存在时插入
    计数.条目("香蕉").或插入(10);

    打印行!("{:?}", 计数);
}
```

## 14.3 迭代器

向量、哈希映射等集合都支持**迭代器**——逐个处理元素的方式：

```rust
函数 主函数() {
    让 数字 = 向量![1, 2, 3, 4, 5];

    // 链式调用：过滤 → 变换 → 收集
    让 偶数平方: 向量<整数> = 数字
        .迭代()
        .过滤(|x| x % 2 == 0)   // 只保留偶数
        .映射(|x| x * x)         // 平方
        .收集();

    打印行!("{:?}", 偶数平方);  // [4, 16]
}
```

> 💡 迭代器是惰性求值的——只有调用 `.收集()` 等消费方法时，整个流水线才会执行。详见第二十一章。

## 常见错误

### ❌ 向量索引越界

```rust
函数 主函数() {
    让 v = 向量![1, 2, 3];
    // 打印行!("{}", v[5]);  // ❌ panic！索引越界
    // 修复：用 .get(5) 返回 选项
    打印行!("{:?}", v.获取(5));  // 无
}
```

### ❌ 向量中放不同类型

```rust
函数 主函数() {
    // 让 v = 向量![1, "二", 3.0];  // ❌ 向量只能放同一种类型
    // 修复：用枚举统一类型
}
```

### ❌ 遍历中修改向量长度

```rust
函数 主函数() {
    让 可变 v = 向量![1, 2, 3];
    // for x 在 &v { v.推(x + 1); }  // ❌ 遍历时不能修改长度
    // 修复：先收集要添加的元素，再统一推入
}
```

用哈希映射统计一段文本中每个单词出现的次数。

    }

    对于 (词, 次) 在 &计数 {
        打印行!("{}: {}次", 词, 次);
    }

### 练习 2：向量去重

给定一个有重复的向量，用哈希集去重后排序。

<details>
<summary>参考答案</summary>

```rust
使用 标准库::集合::哈希集;

函数 主函数() {
    让 数字 = 向量![3, 1, 4, 1, 5, 9, 2, 6, 5, 3];
    让 集合: 哈希集<整数> = 数字.迭代().克隆().收集();
    让 可变 去重: 向量<整数> = 集合.消费迭代().收集();
    去重.排序();
    打印行!("{:?}", 去重);  // [1, 2, 3, 4, 5, 6, 9]
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| 向量 | 动态数组，同类型，可增长 |
| 哈希映射 | 键值对字典，O(1) 查找 |
| 迭代器 | 逐个处理元素的流水线 |
| `.迭代()` | 借用遍历 |
| `.消费迭代()` | 获取所有权遍历 |
