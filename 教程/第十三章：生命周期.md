# 第十三章：生命周期

在第七章我们学了引用——借用数据而不转移所有权。但编译器怎么知道一个引用是否仍然有效？

答案是**生命周期**（lifetime）。生命周期是 Rust 确保引用安全的机制。

---

## 13.1 什么是生命周期

> 🎯 **生活类比**：生命周期就像**借书的期限**。你从图书馆借了一本书，必须在归还日期前看完。如果你把书借给朋友，朋友的借用期限不能超过你的——你不能借给别人一本你已经该还的书。

```
变量生命周期：
时间线 ──────────────────────────→
  x: ┌──────────┐
     │ 活着     │  ← x 的作用域
     └──────────┘
  r:      ┌────────┐
          │ 引用 x │  ← r 引用了 x
          └────────┘
          ↑ x 还在 ↑ x 还在 ✅ 安全！

如果 r 超出 x 的范围：
时间线 ──────────────────────────→
  x: ┌──────┐
     │ 活着 │
     └──────┘
  r:      ┌──────────┐
          │ 引用 x   │  ← ❌ x 已经死了！
          └──────────┘
```

```rust
函数 主函数() {
    让 r;                // r 的生命周期从这里开始
    {
        让 x = 42;       // x 的生命周期从这里开始
        r = &x;          // r 引用了 x
        打印行!("{}", r); // ✅ x 还活着
    }                     // x 的生命周期到此结束
    // 打印行!("{}", r);  // ❌ r 指向了已释放的 x
}
```

---

## 13.2 生命周期标注

用 **`'a`** 这样的语法标注生命周期（读作"生命周期 a"）：

```rust
// &'a 整数 表示"一个引用，它的生命周期是 'a，指向整数"
函数 取较长<'a>(x: &'a 整数, y: &'a 整数) -> &'a 整数 {
    如果 x > y { x } 否则 { y }
}

函数 主函数() {
    让 数字1 = 10;
    让 数字2 = 20;
    让 结果 = 取较长(&数字1, &数字2);
    打印行!("较大值：{}", 结果);
}
```

> 💡 **通俗理解**：生命周期标注**不改变**引用的实际寿命，只是告诉编译器"这些引用的关系是什么"。就像在借书卡上标注日期——标注不改变实际归还时间，但帮助图书管理员检查是否超期。

```
取较长 的签名告诉编译器：
"返回的引用和输入参数活得一样长"

  x: ┌──────────────────────┐
     │     'a               │
  y: ┌──────────────────────┐
     │     'a               │
  返回: └──────────────────┘  ← 返回值的生命周期 ≤ 'a
```

---

## 13.3 生命周期省略规则

大多数时候你不需要手动标注，因为编译器有三条**省略规则**：

1. **每个引用参数都有自己的生命周期**
2. **如果只有一个输入引用，返回值的生命周期和它一样**
3. **如果有 `&自我`，返回值的生命周期和 `自我` 一样**

```rust
// 编译器自动推断（规则 2）：
函数 首词(s: &文本) -> &文本 {
    s
}
// 等价于：
函数 首词<'a>(s: &'a 文本) -> &'a 文本 {
    s
}
```

只有当编译器推断不出来时，才需要手动标注。

| 场景 | 需要标注？ |
|------|-----------|
| 一个引用参数，返回引用 | ❌ 不需要（规则 2） |
| 有 `&自我` 的方法 | ❌ 不需要（规则 3） |
| 两个引用参数，返回引用 | ✅ 需要 |
| 结构体持有引用 | ✅ 需要 |

---

## 13.4 结构体中的生命周期

如果结构体持有引用，**必须**标注生命周期：

```rust
结构体 摘要<'a> {
    文本: &'a 文本,
}

函数 主函数() {
    让 小说 = "很久很久以前...".转字符串();
    让 摘 = 摘要 { 文本: &小说 };

    打印行!("摘要：{}", 摘.文本);
}  // 摘 在 小说 之前被释放，安全
```

```
摘要<'a> 的含义：
┌─────────────────────────────┐
│  摘要 实例不能比它引用的     │
│  文本活得更久               │
│                             │
│  小说: "很久很久以前..."    │
│  摘: 摘要 { 文本: &小说 }  │
│  摘.文本 → "很久很久以前..." │
└─────────────────────────────┘
```

## 13.5 动手实验

### 实验 1：最长子串

```rust
函数 最长子串<'a>(s1: &'a 文本, s2: &'a 文本) -> &'a 文本 {
    如果 s1.长度() >= s2.长度() { s1 } 否则 { s2 }
}

函数 主函数() {
    让 字符串1 = "你好".转字符串();
    {
        让 字符串2 = "你好世界".转字符串();
        让 结果 = 最长子串(&字符串1, &字符串2);
        打印行!("较长的：{}", 结果);
    }
}
```

## 常见错误

### ❌ 返回了局部变量的引用

```rust
函数 危险() -> &整数 {
    让 x = 42;
    &x  // ❌ x 在函数结束时被释放！
}
// 修复：返回值而不是引用，或用 盒子
```

### ❌ 两个引用参数返回引用但未标注

```rust
// 函数 取较长(x: &整数, y: &整数) -> &整数 {  // ❌ 编译器不知道返回的引用来自谁
// 修复：加上生命周期标注
函数 取较长<'a>(x: &'a 整数, y: &'a 整数) -> &'a 整数 {
    如果 x > y { x } 否则 { y }
}
```

### ❌ 结构体持有引用但未标注

```rust
// 结构体 摘要 { 文本: &文本 }  // ❌ 必须标注生命周期
结构体 摘要<'a> { 文本: &'a 文本 }  // ✅
```

## 练习题

### 练习 1：首个单词

写一个函数 `首个单词(s: &文本) -> &文本`，返回字符串中第一个空格前的内容。如果没空格，返回整个字符串。

<details>
<summary>参考答案</summary>

```rust
函数 首个单词<'a>(s: &'a 文本) -> &'a 文本 {
    匹配 s.查找(' ') {
        有些(位置) => &s[..位置],
        无 => s,
    }
}

函数 主函数() {
    打印行!("{}", 首个单词("你好 世界"));  // "你好"
    打印行!("{}", 首个单词("单个词"));     // "单个词"
}
```
</details>

### 练习 2：最长行

写一个函数 `最长行<'a>(s1: &'a 文本, s2: &'a 文本) -> &'a 文本`，返回较长的那个字符串。

<details>
<summary>参考答案</summary>

```rust
函数 最长行<'a>(s1: &'a 文本, s2: &'a 文本) -> &'a 文本 {
    如果 s1.长度() >= s2.长度() { s1 } 否则 { s2 }
}

函数 主函数() {
    打印行!("{}", 最长行("你好", "你好世界"));  // "你好世界"
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| 生命周期 | 引用保持有效的作用域 |
| `'a` | 生命周期标注语法 |
| 省略规则 | 编译器自动推断大多数引用的生命周期 |
| 结构体引用 | 必须标注生命周期 |
| 标注含义 | 不改变实际寿命，只帮助编译器验证安全性 |
