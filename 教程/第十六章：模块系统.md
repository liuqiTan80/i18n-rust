# 第十六章：模块系统

当你的程序越来越大，所有代码都塞在一个文件里会变得无法维护。

Rust 的**模块系统**帮你把代码组织成清晰的层次结构。

---

## 16.1 模块（mod）

用 **`模块`**（`mod`）把相关代码打包在一起：

```rust
模块 数学 {
    公开 函数 加(甲: 整数, 乙: 整数) -> 整数 {
        甲 + 乙
    }

    公开 函数 减(甲: 整数, 乙: 整数) -> 整数 {
        甲 - 乙
    }

    函数 内部辅助() -> 整数 {
        42  // 没有 公开，外部无法访问
    }
}

函数 主函数() {
    打印行!("3 + 5 = {}", 数学::加(3, 5));
    打印行!("10 - 4 = {}", 数学::减(10, 4));
    // 数学::内部辅助();  // ❌ 无法访问，不是公开的
}
```

- **`模块 名字 { ... }`** 定义一个模块。
- **`公开`**（`pub`）让模块内的函数、结构体等对外可见。
- 默认情况下，模块内的东西是**私有的**。

---

## 16.2 使用（use）

每次都用 `模块::函数()` 太长了。用 **`使用`**（`use`）引入：

```rust
模块 数学 {
    公开 函数 加(甲: 整数, 乙: 整数) -> 整数 { 甲 + 乙 }
    公开 函数 乘(甲: 整数, 乙: 整数) -> 整数 { 甲 * 乙 }
}

使用 数学::加;
使用 数学::乘;

函数 主函数() {
    打印行!("{}", 加(3, 5));   // 不需要 数学:: 前缀
    打印行!("{}", 乘(3, 5));
}
```

### 批量引入

```rust
使用 数学::*;  // 引入模块中所有公开项

函数 主函数() {
    打印行!("{}", 加(1, 2));
    打印行!("{}", 乘(3, 4));
}
```

## 16.3 文件模块

实际项目中，模块通常放在单独的文件里：

```
src/
├── main.rs      // 主文件
├── 数学.rs       // 数学模块
└── 图形/
    ├── mod.rs   // 图形模块入口
    ├── 圆形.rs   // 圆形子模块
    └── 方形.rs   // 方形子模块
```

在 `main.rs` 中：

```rust
模块 数学;       // 加载 数学.rs
模块 图形;       // 加载 图形/mod.rs

函数 主函数() {
    打印行!("{}", 数学::加(1, 2));
}
```

## 16.4 包（crate）

**`包`**（`crate`）是整个编译单元。你的项目本身就是一个包。

- **`包::`** 指向当前包的根
- **`超级::`**（`super::`）指向父模块
- **`自我::`**（`self::`）指向当前模块

```rust
模块 外层 {
    公开 函数 外层函数() {
        打印行!("这是外层");
    }

    模块 内层 {
        公开 函数 内层函数() {
            超级::外层函数();  // 调用父模块的函数
            打印行!("这是内层");
        }
    }
}

函数 主函数() {
    外层::内层::内层函数();
}
```

## 16.5 公开性规则

| 关键字 | 可见性 |
|--------|--------|
| 默认 | 仅当前模块内 |
| `公开` | 所有地方 |
| `公开(包)` | 仅当前包内 |
| `公开(超级)` | 父模块 |

```rust
公开 结构体 用户 {
    公开 名字: 字符串,
    年龄: 整数,  // 私有的，外部不能直接访问
}

实现 用户 {
    公开 函数 新建(名字: 字符串, 年龄: 整数) -> 自身 {
        自身 { 名字, 年龄 }
    }

    公开 函数 获取年龄(&自我) -> 整数 {
        自我.年龄
    }
}
```

---

## 本章小结

1. **`模块`** 把相关代码打包
2. **`公开`** 控制可见性
3. **`使用`** 引入模块中的项，简化路径
4. 模块可以放在单独的文件中
5. **`包`**、**`超级`**、**`自我`** 用于模块间导航
