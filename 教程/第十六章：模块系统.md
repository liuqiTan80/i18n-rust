# 第十六章：模块系统

当你的程序越来越大，所有代码都塞在一个文件里会变得无法维护。

Rust 的**模块系统**帮你把代码组织成清晰的层次结构。

---

## 16.1 什么是模块

> 🎯 **生活类比**：模块就像**文件柜的抽屉**。每个抽屉放一类东西——"数学工具"一个抽屉、"图形处理"一个抽屉、"网络通信"一个抽屉。你不需要把螺丝刀和菜谱混在一起。

```
┌── 项目文件柜 ──────────────────────┐
│                                    │
│  ┌── 数学 抽屉 ──┐  ┌── 图形 抽屉 ─┐ │
│  │ 加()  公开    │  │ 圆形  公开   │ │
│  │ 减()  公开    │  │ 方形  公开   │ │
│  │ 内部辅助 私有 │  │ 内部计算 私有│ │
│  └───────────────┘  └──────────────┘ │
│                                    │
│  ┌── 网络 抽屉 ──┐                 │
│  │ 连接() 公开   │                 │
│  │ 断开() 公开   │                 │
│  │ 重试  私有    │                 │
│  └───────────────┘                 │
└────────────────────────────────────┘
```

### 定义模块

```rust
模块 数学 {
    公开 函数 加(甲: 整数, 乙: 整数) -> 整数 {
        甲 + 乙
    }

    公开 函数 减(甲: 整数, 乙: 整数) -> 整数 {
        甲 - 乙
    }

    函数 内部辅助() -> 整数 {
        42  // 没有 公开，外部无法访问
    }
}

函数 主函数() {
    打印行!("3 + 5 = {}", 数学::加(3, 5));
    打印行!("10 - 4 = {}", 数学::减(10, 4));
    // 数学::内部辅助();  // ❌ 无法访问，不是公开的
}
```

- **`模块 名字 { ... }`** 定义一个模块——相当于准备了一个抽屉。
- **`公开`**（`pub`）让模块内的函数、结构体等对外可见——相当于在抽屉上贴标签。
- 默认情况下，模块内的东西是**私有的**——相当于抽屉关上了。

## 16.2 使用（use）

每次都用 `模块::函数()` 太长了。用 **`使用`**（`use`）引入：

```rust
模块 数学 {
    公开 函数 加(甲: 整数, 乙: 整数) -> 整数 { 甲 + 乙 }
    公开 函数 乘(甲: 整数, 乙: 整数) -> 整数 { 甲 * 乙 }
}

使用 数学::加;
使用 数学::乘;

函数 主函数() {
    打印行!("{}", 加(3, 5));   // 不需要 数学:: 前缀
    打印行!("{}", 乘(3, 5));
}
```

### 批量引入

```rust
使用 数学::*;  // 引入模块中所有公开项

函数 主函数() {
    打印行!("{}", 加(1, 2));
    打印行!("{}", 乘(3, 4));
}
```

```
路径导航：
  数学::加        → 数学抽屉里的 加()
  数学::*         → 数学抽屉里的所有公开项
  包::模块::函数  → 从项目根开始的路径
```

## 16.3 文件模块

实际项目中，模块通常放在单独的文件里：

```
src/
├── main.rs      // 主文件
├── 数学.rs       // 数学模块
└── 图形/
    ├── mod.rs   // 图形模块入口
    ├── 圆形.rs   // 圆形子模块
    └── 方形.rs   // 方形子模块
```

在 `main.rs` 中：

```rust
模块 数学;       // 加载 数学.rs
模块 图形;       // 加载 图形/mod.rs

函数 主函数() {
    打印行!("{}", 数学::加(1, 2));
}
```

## 16.4 包（crate）

**`包`**（`crate`）是整个编译单元。你的项目本身就是一个包。

```
┌── 路径系统 ──────────────────────┐
│                                  │
│  包::         → 项目根目录      │
│  超级::       → 父模块（上一层） │
│  自我::       → 当前模块        │
│                                  │
│  类比文件系统：                  │
│  包:: = /                        │
│  超级:: = ../                    │
│  自我:: = ./                     │
└──────────────────────────────────┘
```

```rust
模块 外层 {
    公开 函数 外层函数() {
        打印行!("这是外层");
    }

    模块 内层 {
        公开 函数 内层函数() {
            超级::外层函数();  // 调用父模块的函数
            打印行!("这是内层");
        }
    }
}

函数 主函数() {
    外层::内层::内层函数();
}
```

## 16.5 公开性规则

| 关键字 | 可见性 | 类比 |
|--------|--------|------|
| 默认 | 仅当前模块内 | 抽屉里的私人物品 |
| `公开` | 所有地方 | 贴在抽屉外面的标签 |
| `公开(包)` | 仅当前包内 | 公司内部可见 |
| `公开(超级)` | 父模块 | 只有上级能看到 |

```rust
公开 结构体 用户 {
    公开 名字: 字符串,
    年龄: 整数,  // 私有的，外部不能直接访问
}

实现 用户 {
    公开 函数 新建(名字: 字符串, 年龄: 整数) -> 自身 {
        自身 { 名字, 年龄 }
    }

    公开 函数 获取年龄(&自我) -> 整数 {
        自我.年龄
    }
}
```

> 💡 结构体的字段默认私有——外部必须通过方法访问。这是一种**封装**：你可以控制别人怎么读写你的数据。

## 常见错误

### ❌ 忘记加 `公开`

```rust
模块 工具 {
    函数 辅助() -> 整数 { 42 }  // 默认私有
}
函数 主函数() {
    // 工具::辅助();  // ❌ 无法访问
    // 修复：加 公开 函数 辅助()
}
```

### ❌ 结构体公开但字段私有

```rust
公开 结构体 点 { x: 整数, y: 整数 }  // 结构体公开，字段私有

函数 主函数() {
    // 让 p = 点 { x: 1, y: 2 };  // ❌ 外部不能直接构造
    // 修复：提供 公开 构造函数
}
```

## 练习题

### 练习 1：工具模块

创建一个 `字符串工具` 模块，包含公开函数 `反转(s: &文本) -> 字符串` 和 `是回文(s: &文本) -> 布尔`。

<details>
<summary>参考答案</summary>

```rust
模块 字符串工具 {
    公开 函数 反转(s: &文本) -> 字符串 {
        s.字符().反向().收集()
    }

    公开 函数 是回文(s: &文本) -> 布尔 {
        让 反转 = s.字符().反向().收集::<字符串>();
        s == 反转
    }
}

函数 主函数() {
    打印行!("{}", 字符串工具::反转("你好"));
    打印行!("{}", 字符串工具::是回文("上海自来水来自海上"));
}
```
</details>

### 练习 2：封装结构体

创建一个 `银行账户` 结构体，`余额` 字段私有，提供 `存款`、`取款`（返回 `结果`）、`查询余额` 方法。

<details>
<summary>参考答案</summary>

```rust
结构体 银行账户 {
    余额: 浮点数,
}

实现 银行账户 {
    公开 函数 新建(初始: 浮点数) -> 自身 {
        自身 { 余额: 初始 }
    }

    公开 函数 存款(&可变 自我, 金额: 浮点数) {
        自我.余额 += 金额;
    }

    公开 函数 取款(&可变 自我, 金额: 浮点数) -> 结果<(), 字符串> {
        如果 金额 > 自我.余额 {
            结果::错误("余额不足".转字符串())
        } 否则 {
            自我.余额 -= 金额;
            结果::成功(())
        }
    }

    公开 函数 查询余额(&自我) -> 浮点数 {
        自我.余额
    }
}

函数 主函数() {
    让 可变 账户 = 银行账户::新建(1000.0);
    账户.存款(500.0);
    账户.取款(200.0);
    打印行!("余额：{}", 账户.查询余额());
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| `模块` | 把相关代码打包——文件柜的抽屉 |
| `公开` | 控制可见性——抽屉上的标签 |
| `使用` | 引入模块中的项，简化路径 |
| 文件模块 | 模块可以放在单独的文件中 |
| `包`/`超级`/`自我` | 模块间导航——类似文件路径 |
