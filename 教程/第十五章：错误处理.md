# 第十五章：错误处理

程序不可能永远顺利。文件可能不存在，网络可能断开，用户可能输入了非法数据。

Rust 的错误处理机制非常优雅——它不用异常（exception），而是用**类型系统**来处理错误。

---

## 15.1 恐慌（panic!）

最极端的错误处理方式是**`恐慌!`**（`panic!`）——程序立即崩溃：

```rust
函数 主函数() {
    恐慌!("出了大问题！");
}
```

恐慌会打印错误信息、回溯调用栈，然后终止程序。

### 什么时候用恐慌？

当你确定错误**不可能发生**，但编译器不这么认为时：

```rust
函数 主函数() {
    让 v = 向量![1, 2, 3];
    // v[99] 会 panic，因为索引越界

    // 更安全的方式：
    如果 让 选项::有些(值) = v.获取(99) {
        打印行!("{}", 值);
    } 否则 {
        打印行!("索引不存在");
    }
}
```

---

## 15.2 结果（Result）

大多数错误不应该让程序崩溃。用 **`结果`** 优雅地处理：

```rust
使用 标准库::fs;

函数 主函数() {
    匹配 fs::read_to_string("不存在的文件.txt") {
        结果::成功(内容) => 打印行!("文件内容：{}", 内容),
        结果::错误(e) => 打印行!("读取失败：{}", e),
    }
}
```

`结果` 只有两种情况：
- **`成功(值)`**：操作成功，带返回值
- **`错误(原因)`**：操作失败，带错误信息

---

## 15.3 `?` 操作符

`匹配` 处理错误太冗长了。**`?`** 操作符简化了错误传播：

```rust
使用 标准库::fs;
使用 标准库::io;

函数 读取文件(路径: &文本) -> 结果<字符串, io::错误> {
    让 内容 = fs::read_to_string(路径)?;  // 如果出错，立即返回错误
    结果::成功(内容)
}

函数 主函数() {
    匹配 读取文件("测试.txt") {
        结果::成功(内容) => 打印行!("{}", 内容),
        结果::错误(e) => 打印行!("错误：{}", e),
    }
}
```

`?` 的含义：
- 如果结果是 `成功(值)`，取出 `值` 继续执行
- 如果结果是 `错误(e)`，立即把 `错误(e)` 返回给调用者

### 链式使用

```rust
使用 标准库::fs;
使用 标准库::io;

函数 读取并处理(路径: &文本) -> 结果<整数, io::错误> {
    让 内容 = fs::read_to_string(路径)?;
    让 数字 = 内容.裁剪().解析::<整数>()
        .映射错误(|_| io::错误::新建(io::错误种类::其他, "不是有效整数"))?;
    结果::成功(数字 * 2)
}
```

## 15.4 选项（Option）与 `?`

`?` 也可以用于 `选项`：

```rust
函数 取首字符(文本: &文本) -> 选项<字符> {
    文本.逐字符().next()
}

函数 主函数() {
    如果 让 选项::有些(c) = 取首字符("你好") {
        打印行!("首字符：{}", c);
    }
}
```

---

## 15.5 自定义错误类型

对于复杂程序，你可能需要自定义错误：

```rust
枚举 我的错误 {
    未找到(字符串),
    格式错误(字符串),
}

函数 查找用户(编号: 整数) -> 结果<字符串, 我的错误> {
    如果 编号 <= 0 {
        返回 结果::错误(我的错误::格式错误("编号必须为正数".转字符串()));
    }
    如果 编号 == 1 {
        结果::成功("小明".转字符串())
    } 否则 {
        结果::错误(我的错误::未找到(格式化!("用户{}", 编号)))
    }
}

函数 主函数() {
    匹配 查找用户(1) {
        结果::成功(名字) => 打印行!("找到：{}", 名字),
        结果::错误(我的错误::未找到(谁)) => 打印行!("未找到：{}", 谁),
        结果::错误(我的错误::格式错误(原因)) => 打印行!("格式错误：{}", 原因),
    }
}
```

---

## 本章小结

1. **`恐慌!`** 让程序立即崩溃，用于不可恢复的错误
2. **`结果`**（成功/错误）是可恢复错误的标准处理方式
3. **`?`** 操作符简化错误传播
4. **`选项`** 也可以用 `?`
5. 自定义错误用枚举实现
