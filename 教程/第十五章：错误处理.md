# 第十五章：错误处理

程序不可能永远顺利。文件可能不存在，网络可能断开，用户可能输入了非法数据。

Rust 的错误处理机制非常优雅——它不用异常（exception），而是用**类型系统**来处理错误。

---

## 15.1 恐慌（panic!）

> 🎯 **生活类比**：`恐慌!` 就像**火灾警报**——一旦触发，整栋楼立刻疏散（程序立刻终止）。它用于"不可能恢复"的严重错误。

```rust
函数 主函数() {
    恐慌!("出了大问题！");
}
```

> ✨ **宏调用提示**：本章首次出现 `恐慌!` 宏。同样，你不需要手动写感叹号——`恐慌!("...")` 和 `恐慌("...")` 都可以。

恐慌会打印错误信息、回溯调用栈，然后终止程序。

### 什么时候用恐慌？

当你确定错误**不可能发生**，但编译器不这么认为时：

```rust
函数 主函数() {
    让 v = 向量![1, 2, 3];
    // v[99] 会 panic，因为索引越界
}
```

---

## 15.2 可恢复错误（Result）

> 🎯 **类比**：如果 `恐慌!` 是火灾警报，那 `结果` 就是**天气预报**——它告诉你"可能下雨（错误），也可能晴天（成功）"，你根据预报决定带不带伞。

大多数错误不需要崩溃，而是需要**优雅处理**。Rust 用 `结果` 枚举表示：

```rust
// 结果<T, E> 的定义：
// 枚举 结果<T, E> {
//     成功(T),  // 操作成功，带返回值
//     错误(E),  // 操作失败，带错误信息
// }

函数 打开文件(路径: &文本) -> 结果<字符串, 字符串> {
    // 模拟文件读取
    如果 路径 == "存在.txt" {
        结果::成功("文件内容".转字符串())
    } 否则 {
        结果::错误("文件不存在".转字符串())
    }
}

函数 主函数() {
    匹配 打开文件("存在.txt") {
        结果::成功(内容) => 打印行!("读到：{}", 内容),
        结果::错误(原因) => 打印行!("失败：{}", 原因),
    }
}
```

---

## 15.3 问号运算符 `?`

`?` 是错误处理的**语法糖**——遇到错误就立即返回，成功就取出值继续：

```rust
函数 读取文件(路径: &文本) -> 结果<字符串, 字符串> {
    让 内容 = 打开文件(路径)?;  // 如果失败，直接返回错误
    打印行!("读到 {} 字节", 内容.长度());
    结果::成功(内容)
}

// 等价于：
函数 读取文件_展开(路径: &文本) -> 结果<字符串, 字符串> {
    让 内容 = 匹配 打开文件(路径) {
        结果::成功(v) => v,
        结果::错误(e) => 返回 结果::错误(e),
    };
    打印行!("读到 {} 字节", 内容.长度());
    结果::成功(内容)
}
```

```
问号运算符的流程：
  打开文件(路径)?
      │
      ├── 成功(内容) → 取出 内容，继续往下
      └── 错误(e)   → 立即返回 错误(e)
```

## 15.4 链式错误处理

```rust
函数 解析数字(s: &文本) -> 结果<整数, 字符串> {
    s.解析::<整数>().或_else(|_| 结果::错误(格式化!("无法解析 '{}'", s)))
}

函数 主函数() {
    匹配 解析数字("42") {
        结果::成功(n) => 打印行!("数字：{}", n),
        结果::错误(e) => 打印行!("错误：{}", e),
    }

    匹配 解析数字("abc") {
        结果::成功(n) => 打印行!("数字：{}", n),
        结果::错误(e) => 打印行!("错误：{}", e),
    }
}
```

### 常用 Result 方法

| 方法 | 作用 |
|------|------|
| `.解包()` | 成功时取值，失败时 panic |
| `.期望("消息")` | 同 `.解包()`，但自定义 panic 消息 |
| `.取值或(默认)` | 失败时用默认值 |
| `.映射(\|x\| ...)` | 变换成功值 |
| `?` | 失败时提前返回 |

## 15.5 自定义错误类型

```rust
枚举 我的错误 {
    未找到,
    格式错误(字符串),
    网络错误(整数),
}

函数 处理数据(输入: &文本) -> 结果<整数, 我的错误> {
    如果 输入.是空() {
        返回 结果::错误(我的错误::未找到);
    }
    匹配 输入.解析::<整数>() {
        结果::成功(n) => 结果::成功(n),
        结果::错误(_) => 结果::错误(我的错误::格式错误(输入.转字符串())),
    }
}

函数 主函数() {
    匹配 处理数据("42") {
        结果::成功(n) => 打印行!("结果：{}", n),
        结果::错误(我的错误::未找到) => 打印行!("输入为空"),
        结果::错误(我的错误::格式错误(s)) => 打印行!("格式错误：{}", s),
        结果::错误(我的错误::网络错误(码)) => 打印行!("网络错误：{}", 码),
    }
}
```

## 常见错误

### ❌ 对 Result 直接取值

```rust
函数 主函数() {
    让 结果 = "42".解析::<整数>();
    // 打印行!("{}", 结果);  // ❌ 不能直接打印 Result
    // 修复：用匹配、? 或 .解包()
    打印行!("{}", 结果.解包());  // 42（但如果解析失败会 panic）
}
```

### ❌ 滥用 .解包()

```rust
// ❌ 生产代码中不要随便用 .解包()
函数 危险() -> 整数 {
    "abc".解析::<整数>().解包()  // panic!
}
// 修复：用匹配或 ? 优雅处理
```

### ❌ 在非 Result 函数中使用 ?

```rust
// 函数 主函数() {
//     让 n = "42".解析::<整数>()?;  // ❌ 主函数返回 ()，不是 Result
// }
// 修复：让主函数返回 Result，或用匹配
```

## 练习题

### 练习 1：安全除法

写一个函数 `安全除法(甲: 整数, 乙: 整数) -> 结果<整数, 字符串>`，除数为零时返回错误。

<details>
<summary>参考答案</summary>

```rust
函数 安全除法(甲: 整数, 乙: 整数) -> 结果<整数, 字符串> {
    如果 乙 == 0 {
        结果::错误("除数不能为零".转字符串())
    } 否则 {
        结果::成功(甲 / 乙)
    }
}

函数 主函数() {
    打印行!("{:?}", 安全除法(10, 3));   // 成功(3)
    打印行!("{:?}", 安全除法(10, 0));   // 错误("除数不能为零")
}
```
</details>

### 练习 2：链式解析

写一个函数 `双倍解析(s: &文本) -> 结果<整数, 字符串>`，把字符串解析为整数后乘以 2。

<details>
<summary>参考答案</summary>

```rust
函数 双倍解析(s: &文本) -> 结果<整数, 字符串> {
    让 n = s.解析::<整数>()
        .或_else(|_| 结果::错误(格式化!("无法解析 '{}'", s)))?;
    结果::成功(n * 2)
}

函数 主函数() {
    打印行!("{:?}", 双倍解析("21"));  // 成功(42)
    打印行!("{:?}", 双倍解析("abc")); // 错误("无法解析 'abc'")
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| `恐慌!` | 不可恢复的致命错误 |
| `结果` | 可恢复的错误——`成功` 或 `错误` |
| `?` | 遇到错误就返回，成功就取值 |
| `.解包()` | 简单粗暴取值（失败会 panic） |
| 自定义错误 | 用枚举定义业务错误类型 |
