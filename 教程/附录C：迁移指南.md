# 附录 C：迁移到标准 Rust 的指南

中文 Rust 是学习工具，但最终你需要过渡到标准 Rust——因为实际的 Rust 项目都是英文的。

好消息是：**你已经学会了 Rust 的核心概念**。迁移只是把中文关键字换成英文。

---

## C.1 为什么需要迁移？

1. **实际项目都是英文的**——开源社区、公司代码库都用标准 Rust
2. **文档和错误信息是英文的**——标准 Rust 的学习资源更丰富
3. **团队协作**——团队成员可能不熟悉中文方言

---

## C.2 迁移步骤

### 第一步：导出为标准 Rust

用 `rzc eject` 把 `.zh` 文件翻译成标准 `.rs` 文件：

```bash
rzc eject src/main.zh
```

这会生成 `src/main.rs`，内容是标准 Rust。

### 第二步：逐步替换

打开生成的 `.rs` 文件，对照映射表（附录 A）理解每行代码：

```rust
// 中文 Rust
函数 主函数() {
    让 名字 = "小明";
    打印行!("你好，{}", 名字);
}

// 标准 Rust
fn main() {
    let 名字 = "小明";
    println!("你好，{}", 名字);
}
```

### 第三步：删除语言包

迁移完成后，删除 `语言包/` 目录和 `rust-toolchain.toml`。

### 第四步：更新 Cargo.toml

移除 rzc 相关的构建配置。

## C.4 心态调整

迁移时最重要的不是记住英文关键字，而是理解：

1. **概念不变**——所有权、借用、特征、生命周期……这些概念在两种方言中完全相同
2. **语法几乎不变**——只是关键字换了名字，语法结构一模一样
3. **你已经有了优势**——你理解了 Rust 的核心，现在只需要学"词汇"

### 建议的过渡计划

| 阶段 | 时间 | 内容 |
|------|------|------|
| 第 1 周 | 对照翻译 | 用 `rzc eject` 对照中英文 |
| 第 2 周 | 混合编写 | 尝试直接用英文写简单代码 |
| 第 3 周 | 全英文 | 完全使用标准 Rust |
| 第 4 周 | 阅读源码 | 阅读开源 Rust 项目 |

---

## C.5 推荐资源

迁移到标准 Rust 后，推荐以下学习资源：

1. **The Rust Programming Language**（The Book）—— 官方教程
2. **Rust by Example** —— 通过示例学习
3. **Rustlings** —— 小练习
4. **Rust 官方文档** —— https://doc.rust-lang.org/

---

> **记住**：中文 Rust 不是"玩具"，它是你通往 Rust 世界的桥梁。你已经走过了最难的部分——理解概念。现在，只是换个名字而已。
