# 第六章：所有权

欢迎来到 Rust 最独特的概念——**所有权**。

这是 Rust 区别于其他语言的核心特性。理解了所有权，你就理解了 Rust 的灵魂。

> 这一章的概念可能比较抽象。别急，我会用大量图解和生活类比帮你理解。如果第一遍没看懂，多看几遍——所有权值得你花时间。

---

## 6.1 什么是所有权？

### 生活类比：图书馆借书

想象你在图书馆借了一本书。图书馆有三个规则：

```
┌──────────────────────────────────────────────────┐
│ 规则 1：每本书只有一个借阅者                       │
│   → 每个值只有一个所有者                          │
│                                                  │
│ 规则 2：借阅者可以借给别人或归还                    │
│   → 可以转移所有权                                │
│                                                  │
│ 规则 3：借阅者离开时，书自动归还                    │
│   → 所有者离开作用域，值被释放                      │
└──────────────────────────────────────────────────┘
```

这就是 Rust 的所有权系统。它确保内存安全，不需要垃圾回收器。

### 为什么需要所有权？

在其他语言中，内存管理有两种方式：

```
方式 A：垃圾回收（Java、Python）
  → 有专门的"清洁工"定期清理不用的数据
  → 方便，但有性能开销

方式 B：手动管理（C、C++）
  → 程序员自己申请和释放内存
  → 高效，但容易出错（忘记释放 → 内存泄漏）

方式 C：所有权系统（Rust）✅
  → 编译器在编译时自动插入释放代码
  → 既安全又高效，零运行时开销
```

## 6.2 作用域

先理解**作用域**——一个变量"有效"的范围：

```rust
函数 主函数() {
    // 这里 s 还不存在

    {
        让 s = "你好";  // s 从这里开始有效
        打印行!("{}", s);
    }  // s 的作用域到此结束，s 被销毁

    // 这里 s 已经无效了
    // 打印行!("{}", s);  // ❌ 编译报错
}
```

图解：

```
函数 主函数() {
    ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   ← s 不存在
    {
        ┌─────────────────────┐
        │ s = "你好"          │  ← s 从这里开始有效
        │ 打印行!("{}", s);   │
        └─────────────────────┘
    }                          ← s 到此结束，被销毁
    ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   ← s 不存在
}
```

## 6.3 栈与堆

要理解所有权，先了解**栈**和**堆**——计算机存储数据的两种方式。

### 栈（Stack）

栈像一摞**盘子**——后进先出，只能从顶部放和取：

```
        ┌─────┐
        │  C  │  ← 最后放入，最先取出
        ├─────┤
        │  B  │
        ├─────┤
        │  A  │  ← 最先放入
        └─────┘
          栈
```

特点：
- 数据大小必须**编译时已知**
- 访问速度**非常快**
- 空间有限

### 堆（Heap）

堆像一个**大仓库**——数据散乱存放，需要时再找：

```
        ┌─────────────────────────┐
        │                         │
        │    ┌───┐     ┌───────┐  │
        │    │数据│     │ 数据  │  │
        │    └───┘     └───────┘  │
        │         ┌─────┐         │
        │         │数据 │         │
        │         └─────┘         │
        └─────────────────────────┘
                  堆
```

特点：
- 数据大小可以**运行时动态变化**
- 访问速度**较慢**（需要通过指针找到数据）
- 空间很大

### 什么数据存在哪里？

```
┌────────────────────────────────────────────┐
│ 存在栈上（小、固定）  │ 存在堆上（大、动态） │
├────────────────────────────────────────────┤
│ 整数、浮点数、布尔     │ 字符串（String）    │
│ 字符                   │ 向量（Vec）         │
│ 元组（元素都在栈上时） │ 哈希表（HashMap）   │
└────────────────────────────────────────────┘
```

## 6.4 移动：所有权转移

当你把一个变量赋值给另一个变量时，**所有权会转移**：

### 堆数据的移动

```rust
函数 主函数() {
    让 s1 = "你好".转字符串();
    让 s2 = s1;  // 所有权从 s1 转移到 s2

    // 打印行!("{}", s1);  // ❌ 报错！s1 已经无效
    打印行!("{}", s2);  // ✅ s2 有效
}
```

图解：

```
赋值前：
s1 ──→ [堆上的字符串 "你好"]
        ↑ s1 拥有这块数据

赋值后（让 s2 = s1）：
s1 ──×   （s1 失效，不再指向任何数据）
s2 ──→ [堆上的字符串 "你好"]
        ↑ s2 拥有这块数据（所有权转移了）
```

> **为什么 Rust 要让 s1 失效？** 因为如果 s1 和 s2 都指向同一块数据，当它们离开作用域时，都会尝试释放同一块内存——这会导致**双重释放**错误。Rust 通过让 s1 失效来防止这个问题。

### 栈数据不会移动

```rust
// 栈上的数据：复制，不移动
让 a = 42;
让 b = a;  // 直接复制值（整数在栈上，很小）
打印行!("a = {}, b = {}", a, b);  // ✅ 两个都有效
```

图解：

```
栈数据：
a = 42  →  a: [42]
b = a   →  a: [42]   b: [42]   ← 直接复制，两个独立副本
```

> **规则**：栈上的小数据会自动复制（实现了 `复制` 特征的类型）；堆上的大数据只转移所有权。

## 6.5 克隆：显式复制

如果你确实想复制一份堆上的数据，用 **`.克隆()`**：

```rust
函数 主函数() {
    让 s1 = "你好".转字符串();
    让 s2 = s1.克隆();  // 深拷贝——创建一份完整副本

    打印行!("s1 = {}", s1);  // ✅ 仍然有效
    打印行!("s2 = {}", s2);  // ✅ 也有效
}
```

图解：

```
克隆前：
s1 ──→ [堆上的字符串 "你好"]

克隆后（s2 = s1.克隆()）：
s1 ──→ [堆上的字符串 "你好"]   ← 原始数据
s2 ──→ [堆上的字符串 "你好"]   ← 复制的数据（独立副本）
```

> **`.克隆()` 的代价**：它会完整复制数据。数据量大时，复制会消耗时间和内存。所以只在确实需要两份数据时才用。

## 6.6 函数传参也会移动

```rust
函数 打印文本(文本: 字符串) {
    打印行!("{}", 文本);
}  // 文本 在这里被释放（离开作用域）

函数 主函数() {
    让 s = "你好".转字符串();
    打印文本(s);  // s 的所有权移动到函数参数

    // 打印行!("{}", s);  // ❌ s 已经无效
}
```

图解：

```
调用前：
s ──→ [堆上的字符串 "你好"]

调用 打印文本(s) 时：
s ──×   （s 失效）
文本 ──→ [堆上的字符串 "你好"]   ← 所有权转移到参数

函数结束后：
文本 ──×   （文本离开作用域，数据被释放）
```

## 6.7 返回值可以转移回来

```rust
函数 接收并返回(文本: 字符串) -> 字符串 {
    打印行!("{}", 文本);
    文本  // 返回，所有权转移回去
}

函数 主函数() {
    让 s = "你好".转字符串();
    让 s = 接收并返回(s);  // 拿回所有权
    打印行!("{}", s);  // ✅ 有效
}
```

> 但这太笨拙了。下一章我们会学更好的方式——**引用与借用**。

## 6.8 所有权规则总结

```
┌──────────────────────────────────────────────────────┐
│ 规则 1：每个值有且只有一个所有者                       │
│ 规则 2：所有者离开作用域时，值被释放                    │
│ 规则 3：赋值或传参会转移所有权（移动）                  │
│ 规则 4：栈上的小数据自动复制，不受移动影响              │
│ 规则 5：用 .克隆() 显式复制堆数据                      │
└──────────────────────────────────────────────────────┘
```

## 6.9 常见错误

### 错误 1：移动后继续使用

```rust
让 s1 = "你好".转字符串();
让 s2 = s1;
打印行!("{}", s1);  // ❌ s1 已移动
```

**修复**：用 `.克隆()` → `让 s2 = s1.克隆();`

### 错误 2：函数参数移动

```rust
函数 处理(文本: 字符串) { ... }
让 s = "你好".转字符串();
处理(s);
打印行!("{}", s);  // ❌ s 已移动到函数参数
```

**修复**：传引用（下一章学）→ `处理(&s);`

### 错误 3：循环中移动

```rust
让 可变 列表 = 向量!["你好".转字符串()];
对于 项 在 列表 {
    打印行!("{}", 项);
}
// ❌ 列表已移动（被消费迭代）
```

**修复**：用引用遍历 → `对于 项 在 &列表 {`

## 6.10 动手实验

### 实验 1：观察移动

```rust
函数 主函数() {
    让 列表1 = 向量![1, 2, 3];
    让 列表2 = 列表1;

    // 打印行!("{:?}", 列表1);  // ❌ 已移动
    打印行!("{:?}", 列表2);  // ✅ 有效
}
```

### 实验 2：使用克隆

```rust
函数 主函数() {
    让 列表1 = 向量![1, 2, 3];
    让 列表2 = 列表1.克隆();

    打印行!("列表1：{:?}", 列表1);  // ✅ 有效
    打印行!("列表2：{:?}", 列表2);  // ✅ 有效
}
```

### 实验 3：栈数据自动复制

```rust
函数 主函数() {
    让 a = 42;
    让 b = a;

    打印行!("a = {}, b = {}", a, b);  // ✅ 两个都有效

    让 c = 真;
    让 d = c;
    打印行!("c = {}, d = {}", c, d);  // ✅ 布尔也是栈数据
}
```

## 6.11 练习题

### 练习 1：判断哪些代码能编译

不运行代码，判断以下哪些能通过编译：

```rust
// A
让 s1 = "你好".转字符串();
让 s2 = s1;
打印行!("{}", s1);

// B
让 s1 = "你好".转字符串();
让 s2 = s1.克隆();
打印行!("{} {}", s1, s2);

// C
让 a = 42;
让 b = a;
打印行!("{} {}", a, b);
```

<details>
<summary>答案</summary>

- **A** ❌ 不能编译——s1 已移动
- **B** ✅ 可以编译——克隆后两个都有效
- **C** ✅ 可以编译——整数是栈数据，自动复制

</details>

### 练习 2：修复代码

以下代码不能编译，请修复：

```rust
函数 打印两次(文本: 字符串) {
    打印行!("第一次：{}", 文本);
    打印行!("第二次：{}", 文本);
}

函数 主函数() {
    让 s = "你好".转字符串();
    打印两次(s);
    打印行!("原始：{}", s);
}
```

<summary>参考答案</summary>

```rust
打印两次(s.克隆());
```

</details>

## 本章小结

1. **所有权** 是 Rust 内存安全的核心机制
2. 每个值有且只有一个所有者，所有者离开作用域时值被释放
3. 赋值/传参会**移动**堆上的数据，原变量失效
4. 用 **`.克隆()`** 显式复制数据
5. 栈上的小数据（整数、布尔等）自动复制，不受移动影响
6. **栈**：小、快、固定大小；**堆**：大、慢、动态大小
