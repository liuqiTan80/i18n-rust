# 第二章：变量与类型

上一章我们写了第一个程序。但那个程序只是打印了一行文字——它不会"记住"任何东西。

这一章，我们要学习如何让程序**记住数据**。

---

## 2.1 变量是什么？

### 用"盒子"理解变量

想象你有一堆**盒子**，每个盒子上贴着标签，里面放着东西。

- 一个盒子贴着 `名字`，里面放着 `"小明"`
- 一个盒子贴着 `年龄`，里面放着 `20`

在编程中，这些盒子就叫**变量**（variable）。"变量"的意思是——盒子里的东西**可以变**。

```
┌──────────┐     ┌──────────┐
│  名字     │     │  年龄     │
│ "小明"    │     │   20     │
└──────────┘     └──────────┘
```

### 用 `让` 创建盒子

在中文 Rust 中，用 **`让`** 来创建一个变量：

```rust
函数 主函数() {
    让 名字 = "小明";
    让 年龄 = 20;
    打印行!("{}今年{}岁。", 名字, 年龄);
}
```

逐行理解：

| 代码 | 做了什么 |
|------|---------|
| `让 名字 = "小明"` | 创建一个盒子，标签叫 `名字`，放入 `"小明"` |
| `让 年龄 = 20` | 创建一个盒子，标签叫 `年龄`，放入 `20` |
| `打印行!(...)` | 把盒子里的东西取出来，填入 `{}` 的位置 |

> **等号 `=` 的含义**：在编程中，`=` 不是"相等"，而是"把右边的东西放进左边的盒子"。

## 2.2 不可变与可变

### 默认不可变

Rust 有一个特别的规则：**盒子一旦封好，就不能换里面的东西**。

```rust
函数 主函数() {
    让 数量 = 10;
    数量 = 20;  // ❌ 报错！
}
```

编译器会报错：

```
错误：不能给不可变变量 `数量` 重复赋值
  --> src/main.zh:3:5
   |
3  |     数量 = 20;
   |     ^^^^^^^^^ 不能修改
💡 如果需要修改，试试 `让 可变 数量 = 10;`
```

> 为什么默认不可变？因为**不可变更安全**。当你确定一个值不会改变时，代码更容易理解，也不容易出 bug。

### 用 `可变` 让盒子可以更换

如果你想更换盒子里的东西，需要在创建时声明：

```rust
函数 主函数() {
    让 可变 数量 = 10;    // 声明这个盒子"可以更换"
    打印行!("修改前：{}", 数量);

    数量 = 20;            // ✅ 现在可以换了
    打印行!("修改后：{}", 数量);
}
```

输出：

```
修改前：10
修改后：20
```

用盒子来理解：

```
第 1 步：让 可变 数量 = 10
┌──────────────┐
│  数量 (可变)  │  →  10
└──────────────┘

第 2 步：数量 = 20
┌──────────────┐
│  数量 (可变)  │  →  20    ← 换了里面的东西
└──────────────┘
```

> **`可变` 的代价**：可变变量让代码更难推理——你不确定它什么时候会被改。所以 Rust 默认不可变，只有你明确需要时才加 `可变`。

## 2.3 常量

如果你有一个值**永远不会变**，而且希望整个程序都能用，用 **`常量`**：

```rust
常量 最大分数: 整数 = 100;
常量 程序名: &文本 = "我的程序";

函数 主函数() {
    打印行!("欢迎使用{}", 程序名);
    打印行!("最高分：{}", 最大分数);
}
```

常量 vs 变量：

| 特性 | 变量（`让`） | 常量（`常量`） |
|------|-------------|---------------|
| 可以修改 | 加了 `可变` 才可以 | **永远不可以** |
| 必须标注类型 | 不必须（编译器推断） | **必须** |
| 作用域 | 当前代码块 `{}` 内 | 声明位置之后全局 |
| 命名风格 | 中文即可 | 建议用中文全称 |

## 2.4 基本数据类型

Rust 是一门**强类型语言**——每个值都有类型。但好消息是，大多数时候你不需要手动标注类型，编译器会自动推断。

### 整数

整数就是**没有小数点**的数字。

```
整数：  -3, -2, -1, 0, 1, 2, 3, 100, -999
不是整数：3.14, -0.5, 2.0（这些有小数点，是浮点数）
```

Rust 有多种整数类型，区别在于**能装多大的数**：

```
┌─────────────────────────────────────────────────────┐
│ 类型        │ 范围                                   │
├─────────────────────────────────────────────────────┤
│ 微整数(u8)  │ 0 ~ 255                               │  最小，只占 1 字节
│ 短整数(i16) │ -32768 ~ 32767                        │  占 2 字节
│ 整数(i32)   │ -2147483648 ~ 2147483647              │  占 4 字节（默认！）
│ 长整数(i64) │ 约 ±922 亿亿                          │  占 8 字节
│ 超长整数    │ 更大                                   │  占 16 字节
└─────────────────────────────────────────────────────┘
```

> **小贴士**：如果你不确定用哪种，直接用 **`整数`**（i32），它是默认类型，能装约 ±21 亿，适合绝大多数场景。

```rust
函数 主函数() {
    让 年龄: 整数 = 25;       // 有符号 32 位
    让 价格: 无符号整数 = 99;  // 无符号 32 位（不能是负数）
    让 字节: 字节 = 255;       // 8 位无符号（0~255）

    打印行!("年龄：{}", 年龄);
    打印行!("价格：{}", 价格);
    打印行!("字节：{}", 字节);
}
```

### 浮点数

浮点数就是**有小数点**的数字：

```rust
函数 主函数() {
    让 圆周率 = 3.14159;        // 默认是 f64（双精度）
    让 半径: 浮点数 = 5.0;      // f64
    让 面积: 单精度浮点数 = 3.14 * 半径 * 半径;  // f32

    打印行!("半径 {} 的圆面积是 {}", 半径, 面积);
}
```

- **`浮点数`**（f64）—— 双精度，更精确，**默认选择**
- **`单精度浮点数`**（f32）—— 单精度，占用内存更少

### 布尔

布尔类型只有两个值：**`真`** 和 **`假`**。

```rust
函数 主函数() {
    让 是否成年 = 真;
    让 是否下雨 = 假;

    如果 是否成年 {
        打印行!("你已经成年了。");
    }

    如果 !是否下雨 {
        打印行!("今天没下雨，出去玩吧！");
    }
}
```

> `!` 是"取反"——`!真` = `假`，`!假` = `真`。

### 字符

字符用**单引号**包裹，表示**一个** Unicode 字符：

```rust
函数 主函数() {
    让 字母: 字符 = 'A';
    让 中文: 字符 = '中';
    让 表情: 字符 = '😊';

    打印行!("字母：{}", 字母);
    打印行!("中文：{}", 中文);
    打印行!("表情：{}", 表情);
}
```

> Rust 的字符是 Unicode 的，所以中文、日文、emoji 都可以用一个字符表示。

## 2.5 类型标注

大多数时候，编译器能**自动推断**类型：

```rust
让 数量 = 42;       // 编译器看到 42，推断为整数
让 名字 = "小明";    // 编译器看到引号，推断为文本
```

但有时候编译器推断不出来，或者你想明确指定类型，就需要**类型标注**：

```rust
让 数量: 整数 = 42;       // 明确告诉编译器：这是整数
让 圆周率: 浮点数 = 3.14;  // 明确告诉编译器：这是浮点数
让 标志: 布尔 = 真;        // 明确告诉编译器：这是布尔
```

格式是 `变量名: 类型`，冒号后面跟类型名。

> **什么时候需要类型标注？** 当编译器无法确定类型时。比如 `让 空 = "";`——编译器不知道你要什么类型，需要标注。

## 2.6 变量遮蔽

你可以用同一个名字创建一个新的盒子，**遮蔽**（shadow）旧的盒子：

```rust
函数 主函数() {
    让 数量 = 5;
    打印行!("第一次：{}", 数量);     // 输出 5

    让 数量 = "五个";               // 新盒子遮蔽了旧的
    打印行!("第二次：{}", 数量);     // 输出 "五个"

    让 数量 = 数量.长度();           // 又遮蔽了
    打印行!("第三次：{}", 数量);     // 输出 3（"五个"有2个字符... 不对，"五个"长度是2）
}
```

遮蔽和 `可变` 的区别：

```
遮蔽：创建了一个全新的盒子
┌──────────┐     ┌──────────┐     ┌──────────┐
│ 数量 = 5  │     │数量 = "五"│     │数量 = 2  │
│ (整数)    │ →   │ (文本)    │ →   │ (整数)   │
└──────────┘     └──────────┘     └──────────┘
  旧盒子还在，      又一个新的盒子，
  只是被挡住了      类型可以不同

可变：在同一个盒子里换东西
┌──────────────┐
│ 数量 (可变)   │  10 → 20 → 30    ← 同一个盒子，类型不变
└──────────────┘
```

## 2.7 常见错误

### 错误 1：修改不可变变量

```rust
让 数量 = 10;
数量 = 20;  // ❌ 不能修改不可变变量
```

**修复**：加 `可变` → `让 可变 数量 = 10;`

### 错误 2：使用未初始化的变量

```rust
让 数量: 整数;
打印行!("{}", 数量);  // ❌ 数量还没有值
```

**修复**：先赋值 → `让 数量: 整数 = 0;`

### 错误 3：类型不匹配

```rust
让 数量: 整数 = "你好";  // ❌ 整数类型不能放字符串
```

**修复**：用正确的类型 → `让 数量: 整数 = 42;`

### 错误 4：使用超出范围的数字

```rust
让 字节: 字节 = 256;  // ❌ 字节(u8) 范围是 0~255
```

**修复**：用范围更大的类型 → `让 数量: 整数 = 256;`

## 2.8 动手实验

### 实验 1：简单计算器

```rust
函数 主函数() {
    让 甲: 整数 = 15;
    让 乙: 整数 = 4;

    打印行!("{} + {} = {}", 甲, 乙, 甲 + 乙);
    打印行!("{} - {} = {}", 甲, 乙, 甲 - 乙);
    打印行!("{} × {} = {}", 甲, 乙, 甲 * 乙);
    打印行!("{} ÷ {} = {}", 甲, 乙, 甲 / 乙);
    打印行!("{} 余 {} = {}", 甲, 乙, 甲 % 乙);
}
```

输出：

```
15 + 4 = 19
15 - 4 = 11
15 × 4 = 60
15 ÷ 4 = 3      ← 整数除法自动取整！
15 余 4 = 3
```

> **注意**：整数除法会自动取整。`15 / 4` 的结果是 `3`，不是 `3.75`。如果需要精确结果，用浮点数。

### 实验 2：温度转换

```rust
函数 主函数() {
    让 摄氏: 浮点数 = 36.6;
    让 华氏 = 摄氏 * 9.0 / 5.0 + 32.0;

    打印行!("摄氏 {}° = 华氏 {}°", 摄氏, 华氏);
}
```

### 实验 3：交换变量

```rust
函数 主函数() {
    让 可变 甲 = 1;
    让 可变 乙 = 2;

    打印行!("交换前：甲={}, 乙={}", 甲, 乙);

    让 临时 = 甲;   // 把甲的值保存到临时盒子
    甲 = 乙;        // 把乙的值放入甲
    乙 = 临时;      // 把临时盒子的值（原来的甲）放入乙

    打印行!("交换后：甲={}, 乙={}", 甲, 乙);
}
```

## 2.9 练习题

### 练习 1：个人信息卡

声明变量存储你的姓名、年龄、身高，然后输出：

```
姓名：小明
年龄：20
身高：175cm
```

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 姓名 = "小明";
    让 年龄 = 20;
    让 身高 = 175;
    打印行!("姓名：{}", 姓名);
    打印行!("年龄：{}", 年龄);
    打印行!("身高：{}cm", 身高);
}
```

</details>

### 练习 2：计算圆面积

声明一个变量 `半径`，计算并输出圆的面积（面积 = π × r²）。

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 半径: 浮点数 = 5.0;
    让 面积 = 3.14159 * 半径 * 半径;
    打印行!("半径为 {} 的圆，面积是 {:.2}", 半径, 面积);
}
```

</details>

### 练习 3：秒转时分秒

声明一个变量 `总秒数 = 3661`，计算并输出对应的时、分、秒。

提示：
- 1 小时 = 3600 秒
- 1 分钟 = 60 秒
- 用 `/` 求商，用 `%` 求余

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 总秒数 = 3661;
    让 时 = 总秒数 / 3600;
    让 分 = (总秒数 % 3600) / 60;
    让 秒 = 总秒数 % 60;
    打印行!("{}秒 = {}时{}分{}秒", 总秒数, 时, 分, 秒);
}
```

</details>

## 本章小结

1. **`让`** 创建变量（"数据盒子"），默认不可变
2. **`让 可变`** 创建可以修改的变量
3. **`常量`** 声明全局常量，必须标注类型
4. 基本类型：
   - **`整数`**（i32）—— 没有小数点的数字
   - **`浮点数`**（f64）—— 有小数点的数字
   - **`布尔`**（bool）—— `真` 或 `假`
   - **`字符`**（char）—— 一个 Unicode 字符
5. 编译器会自动推断类型，但你可以用 `: 类型` 手动标注
6. **遮蔽**可以用同名创建新盒子，甚至改变类型
