# 第十章：枚举与模式匹配

上一章学了结构体——把多个数据打包在一起。但有时候，一个值**只能是几种情况之一**。

比如一个方向：只能是东、南、西、北中的一个。或者一个选项：要么有值，要么没有。

这就是**枚举**的用武之地。

---

## 10.1 什么是枚举

> 🎯 **生活类比**：枚举就像一个**自动售货机的按钮面板**——你只能按"可乐"、"雪碧"、"矿泉水"中的一个。每个按钮对应一种确定的选择，没有"半个可乐"这种模糊状态。枚举让你的代码**不可能表示非法的值**。

```
┌──── 售货机按钮 ────┐
│  ○ 可乐            │  ← 方向::东
│  ○ 雪碧            │  ← 方向::南
│  ○ 矿泉水          │  ← 方向::西
│  ○ 果汁            │  ← 方向::北
└────────────────────┘
  只能选一个，不能选"半个可乐"
```

### 定义枚举

```rust
枚举 方向 {
    东,
    南,
    西,
    北,
}

函数 主函数() {
    让 朝向 = 方向::北;

    匹配 朝向 {
        方向::东 => 打印行!("向东走"),
        方向::南 => 打印行!("向南走"),
        方向::西 => 打印行!("向西走"),
        方向::北 => 打印行!("向北走"),
    }
}
```

- **`枚举 方向 { ... }`** 定义了四个可能的值——就像售货机的四个按钮。
- 用 **`方向::北`** 访问枚举值（`::` 表示"属于这个类型"）。
- 用 **`匹配`** 处理每种情况——就像逐一检查每个按钮。

```
匹配的执行流程：

朝向 = 方向::北
    │
    ├── 是东？── 否
    ├── 是南？── 否
    ├── 是西？── 否
    └── 是北？── 是 → 执行 "向北走"
```

## 10.2 带数据的枚举

枚举的每个变体可以**携带数据**——这是枚举比 C/Java 强大的地方：

```rust
枚举 消息 {
    退出,                          // 无数据
    移动 { x: 整数, y: 整数 },     // 类似结构体
    写(字符串),                    // 类似元组
    改颜色(整数, 整数, 整数),      // 多个值
}
```

```
┌── 消息 ──────────────────────────────────┐
│                                          │
│  退出 ─────────────── 无数据             │
│                                          │
│  移动 { x, y } ───── 命名数据（像结构体） │
│                                          │
│  写(文本) ────────── 位置数据（像元组）   │
│                                          │
│  改颜色(r, g, b) ─── 多个值              │
│                                          │
└──────────────────────────────────────────┘
```

```rust
函数 主函数() {
    让 消息1 = 消息::退出;
    让 消息2 = 消息::移动 { x: 10, y: 20 };
    让 消息3 = 消息::写("你好".转字符串());
    让 消息4 = 消息::改颜色(255, 0, 0);

    处理消息(&消息1);
    处理消息(&消息2);
    处理消息(&消息3);
    处理消息(&消息4);
}

函数 处理消息(msg: &消息) {
    匹配 msg {
        消息::退出 => 打印行!("退出"),
        消息::移动 { x, y } => 打印行!("移动到 ({}, {})", x, y),
        消息::写(文本) => 打印行!("写入：{}", 文本),
        消息::改颜色(r, g, b) => 打印行!("颜色 RGB({},{},{})", r, g, b),
    }
}
```

## 10.3 最重要的两个枚举

Rust 标准库有两个极其重要的枚举，你会天天用到：

### `选项`（Option）—— "有还是没有？"

> 🎯 **类比**：你打开一个**快递箱**——要么里面有东西（`有些(物品)`），要么是空的（`无`）。Rust 没有 `null`，用 `选项` 安全地表示"可能没有值"。

```rust
// 选项<T> 的定义（内置在标准库中）：
// 枚举 选项<T> {
//     有些(T),   // 箱子里有东西
//     无,        // 箱子是空的
// }

函数 查找用户(编号: 整数) -> 选项<字符串> {
    如果 编号 == 1 {
        选项::有些("小明".转字符串())
    } 否则 {
        选项::无
    }
}

函数 主函数() {
    让 用户 = 查找用户(1);

    匹配 用户 {
        选项::有些(名字) => 打印行!("找到：{}", 名字),
        选项::无 => 打印行!("未找到"),
    }
}
```

### `结果`（Result）—— "成功还是失败？"

> 🎯 **类比**：你去银行办事——要么**办成了**（`成功(结果)`），要么**被拒绝了**（`错误(原因)`）。Rust 不用异常，用 `结果` 让每个可能失败的操作都明确告诉你结果。

```rust
// 结果<T, E> 的定义：
// 枚举 结果<T, E> {
//     成功(T),  // 办成了，带返回值
//     错误(E),  // 被拒了，带错误原因
// }

函数 安全除法(甲: 浮点数, 乙: 浮点数) -> 结果<浮点数, 字符串> {
    如果 乙 == 0.0 {
        结果::错误("除数不能为零".转字符串())
    } 否则 {
        结果::成功(甲 / 乙)
    }
}

函数 主函数() {
    匹配 安全除法(10.0, 3.0) {
        结果::成功(值) => 打印行!("结果：{}", 值),
        结果::错误(原因) => 打印行!("错误：{}", 原因),
    }
}
```

## 10.4 如果让（if let）

当你只关心一种情况时，用 **`如果让`** 比 `匹配` 更简洁：

```rust
函数 主函数() {
    让 值 = 选项::有些(42);

    // 用匹配（完整但冗长）
    匹配 值 {
        选项::有些(n) => 打印行!("值是 {}", n),
        _ => (),  // 其他情况什么都不做
    }

    // 用如果让（简洁）
    如果让 选项::有些(n) = 值 {
        打印行!("值是 {}", n);
    }
}
```

`如果让` 就是"如果匹配成功就执行，否则跳过"。

```
匹配：穷尽所有情况        如果让：只关心一种情况
┌──────────────┐         ┌──────────────┐
│ 匹配 值 {    │         │ 如果让 选项  │
│   有些(n)=>… │         │   ::有些(n)  │
│   _ => ()   │         │   = 值 {     │
│ }           │         │   …          │
└──────────────┘         │ }           │
  必须处理所有情况        └──────────────┘
                           只处理关心的
```

### 加上 `否则`

```rust
函数 主函数() {
    让 值 = 选项::无;

    如果让 选项::有些(n) = 值 {
        打印行!("值是 {}", n);
    } 否则 {
        打印行!("没有值");
    }
}
```

## 10.5 当让（while let）

**`当让`** 在匹配成功时持续循环：

```rust
函数 主函数() {
    让 可变 栈 = 向量![1, 2, 3];

    当让 选项::有些(顶部) = 栈.弹() {
        打印行!("弹出：{}", 顶部);
    }
    打印行!("栈已空");
}
```

输出：

```
弹出：3
弹出：2
弹出：1
栈已空
```

`栈.弹()` 返回 `选项`——有值时是 `有些(值)`，空时是 `无`。`当让` 在有值时循环，无值时停止。

## 10.6 模式匹配语法大全

`匹配` 不仅能匹配枚举，还能匹配各种模式：

| 模式 | 匹配什么 | 示例 |
|------|---------|------|
| 字面量 | 具体的值 | `1`、`"你好"`、`真` |
| 变量名 | 绑定变量 | `x` |
| 通配符 | 任何东西（忽略） | `_` |
| 范围 | 一个区间 | `1..=5` |
| 解构枚举 | 枚举变体 | `选项::有些(x)` |
| `\|` | 多种情况 | `1 \| 2 \| 3` |
| 守卫 | 附加条件 | `n 如果 n > 0` |

```rust
函数 主函数() {
    让 x = 3;

    匹配 x {
        1 => 打印行!("一"),
        2 => 打印行!("二"),
        3..=5 => 打印行!("三到五"),   // 范围
        n 如果 n > 0 => 打印行!("正数：{}", n),  // 守卫
        _ => 打印行!("其他"),
    }
}
```

## 常见错误

### ❌ 匹配没有穷尽所有情况

```rust
枚举 颜色 { 红, 绿, 蓝 }

函数 主函数() {
    让 c = 颜色::红;
    匹配 c {
        颜色::红 => 打印行!("红色"),
        // ❌ 漏了 绿 和 蓝！编译器报错
    }
    // 修复：加上其他分支，或用 _ 兜底
}
```

### ❌ 忘记用 `::` 访问枚举值

```rust
函数 主函数() {
    // 让 d = 方向::北;  // ✅ 正确
    让 d = 北;           // ❌ 编译器不知道"北"是什么
}
```

### ❌ 对 `选项` 直接取值

```rust
函数 主函数() {
    让 值 = 选项::有些(42);
    // 打印行!("{}", 值);  // ❌ 不能直接打印 选项
    // 修复：先匹配取出里面的值
    如果让 选项::有些(n) = 值 {
        打印行!("{}", n);  // ✅
    }
}
```

### 练习 1：交通信号灯

定义一个 `信号灯` 枚举（红、黄、绿），写一个函数返回每种灯对应的动作（"停"、"注意"、"行"）。

<details>
<summary>参考答案</summary>

```rust
枚举 信号灯 { 红, 黄, 绿 }

函数 动作(灯: &信号灯) -> &文本 {
    匹配 灯 {
        信号灯::红 => "停",
        信号灯::黄 => "注意",
        信号灯::绿 => "行",
    }
}

函数 主函数() {
    打印行!("红灯：{}", 动作(&信号灯::红));
    打印行!("黄灯：{}", 动作(&信号灯::黄));
    打印行!("绿灯：{}", 动作(&信号灯::绿));
}
```

### 练习 2：简单计算器

用枚举表示四则运算（加、减、乘、除），写一个 `计算` 函数，返回 `选项<浮点数>`（除零时返回 `无`）。

<details>
<summary>参考答案</summary>

```rust
枚举 运算 {
    加(浮点数, 浮点数),
    减(浮点数, 浮点数),
    乘(浮点数, 浮点数),
    除(浮点数, 浮点数),
}

函数 计算(op: 运算) -> 选项<浮点数> {
    匹配 op {
        运算::加(a, b) => 选项::有些(a + b),
        运算::减(a, b) => 选项::有些(a - b),
        运算::乘(a, b) => 选项::有些(a * b),
        运算::除(a, b) => {
            如果 b == 0.0 { 选项::无 }
            否则 { 选项::有些(a / b) }
        }
    }
}

函数 主函数() {
    打印行!("{:?}", 计算(运算::加(10.0, 5.0)));  // 有些(15)
    打印行!("{:?}", 计算(运算::除(10.0, 0.0)));  // 无
}
```
</details>

### 练习 3：链式调用选项

写一个函数 `取第一个字符(文本: &文本) -> 选项<字符>`，如果文本为空返回 `无`。然后链式调用：先取第一个字符，再判断是否是元音字母。

<details>
<summary>参考答案</summary>

```rust
函数 取第一个字符(s: &文本) -> 选项<字符> {
    s.字符().下一个()
}

函数 是否元音(c: 字符) -> 布尔 {
    匹配 c {
        'a' | 'e' | 'i' | 'o' | 'u' => 真,
        _ => 假,
    }
}

函数 主函数() {
    让 文本 = "你好";
    如果让 选项::有些(首字) = 取第一个字符(文本) {
        如果 是否元音(首字) {
            打印行!("{} 是元音", 首字);
        } 否则 {
            打印行!("{} 不是元音", 首字);
        }
    }
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| `枚举` | 定义一个值的多种可能情况 |
| 带数据变体 | 每个变体可以携带不同类型和数量的数据 |
| `匹配` | 处理枚举的主要方式，必须穷尽所有情况 |
| `选项` | `有些(值)` / `无` —— 表示"有值或没有" |
| `结果` | `成功(值)` / `错误(原因)` —— 表示"成功或失败" |
| `如果让` | 简化只关心一种情况的匹配 |
| `当让` | 在匹配成功时持续循环 |
