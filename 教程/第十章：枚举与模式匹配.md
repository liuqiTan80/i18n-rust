# 第十章：枚举与模式匹配

上一章学了结构体——把多个数据打包在一起。但有时候，一个值**只能是几种情况之一**。

比如一个方向：只能是东、南、西、北中的一个。或者一个选项：要么有值，要么没有。

这就是**枚举**的用武之地。

---

## 10.1 定义枚举

```rust
枚举 方向 {
    东,
    南,
    西,
    北,
}

函数 主函数() {
    让 朝向 = 方向::北;

    匹配 朝向 {
        方向::东 => 打印行!("向东走"),
        方向::南 => 打印行!("向南走"),
        方向::西 => 打印行!("向西走"),
        方向::北 => 打印行!("向北走"),
    }
}
```

- **`枚举 方向 { ... }`** 定义了四个可能的值。
- 用 **`方向::北`** 访问枚举值（`::` 表示"属于这个类型"）。
- 用 **`匹配`** 处理每种情况。

---

## 10.2 带数据的枚举

枚举的每个变体可以**携带数据**：

```rust
枚举 消息 {
    退出,
    移动 { x: 整数, y: 整数 },
    写(字符串),
    改颜色(整数, 整数, 整数),
}

函数 主函数() {
    让 消息1 = 消息::退出;
    让 消息2 = 消息::移动 { x: 10, y: 20 };
    让 消息3 = 消息::写("你好".转字符串());
    让 消息4 = 消息::改颜色(255, 0, 0);

    处理消息(&消息1);
    处理消息(&消息2);
    处理消息(&消息3);
    处理消息(&消息4);
}

函数 处理消息(msg: &消息) {
    匹配 msg {
        消息::退出 => 打印行!("退出"),
        消息::移动 { x, y } => 打印行!("移动到 ({}, {})", x, y),
        消息::写(文本) => 打印行!("写入：{}", 文本),
        消息::改颜色(r, g, b) => 打印行!("颜色 RGB({},{},{})", r, g, b),
    }
}
```

- **`退出`**：无数据
- **`移动 { x, y }`**：类似结构体的命名数据
- **`写(字符串)`**：类似元组的位置数据
- **`改颜色(整数, 整数, 整数)`**：多个值

## 10.3 最重要的两个枚举

Rust 标准库有两个极其重要的枚举，你会天天用到：

### `选项`（Option）

表示"可能有值，也可能没有"：

```rust
// 选项<T> 的定义（内置在标准库中）：
// 枚举 选项<T> {
//     有些(T),   // 有值
//     无,        // 没有值
// }

函数 查找用户(编号: 整数) -> 选项<字符串> {
    如果 编号 == 1 {
        选项::有些("小明".转字符串())
    } 否则 {
        选项::无
    }
}

函数 主函数() {
    让 用户 = 查找用户(1);

    匹配 用户 {
        选项::有些(名字) => 打印行!("找到：{}", 名字),
        选项::无 => 打印行!("未找到"),
    }
}
```

### `结果`（Result）

表示"操作成功，或者出错"：

```rust
// 结果<T, E> 的定义：
// 枚举 结果<T, E> {
//     成功(T),  // 成功，带返回值
//     错误(E),  // 失败，带错误信息
// }

函数 安全除法(甲: 浮点数, 乙: 浮点数) -> 结果<浮点数, 字符串> {
    如果 乙 == 0.0 {
        结果::错误("除数不能为零".转字符串())
    } 否则 {
        结果::成功(甲 / 乙)
    }
}

函数 主函数() {
    匹配 安全除法(10.0, 3.0) {
        结果::成功(值) => 打印行!("结果：{}", 值),
        结果::错误(原因) => 打印行!("错误：{}", 原因),
    }

    匹配 安全除法(10.0, 0.0) {
        结果::成功(值) => 打印行!("结果：{}", 值),
        结果::错误(原因) => 打印行!("错误：{}", 原因),
    }
}
```

## 10.4 如果让（if let）

当你只关心一种情况时，用 **`如果让`**（`if let`）比 `匹配` 更简洁：

```rust
函数 主函数() {
    让 值 = 选项::有些(42);

    // 用匹配（完整但冗长）
    匹配 值 {
        选项::有些(n) => 打印行!("值是 {}", n),
        _ => (),
    }

    // 用如果让（简洁）
    如果让 选项::有些(n) = 值 {
        打印行!("值是 {}", n);
    }
}
```

`如果让` 就是"如果匹配成功就执行，否则跳过"。

### 加上 `否则`

```rust
函数 主函数() {
    让 值 = 选项::无;

    如果让 选项::有些(n) = 值 {
        打印行!("值是 {}", n);
    } 否则 {
        打印行!("没有值");
    }
}
```

## 10.5 当让（while let）

**`当让`**（`while let`）在匹配成功时持续循环：

```rust
函数 主函数() {
    让 可变 栈 = 向量![1, 2, 3];

    当让 选项::有些(顶部) = 栈.弹() {
        打印行!("弹出：{}", 顶部);
    }
    打印行!("栈已空");
}
```

输出：

```
弹出：3
弹出：2
弹出：1
栈已空
```

`栈.弹()` 返回 `选项`——有值时是 `有些(值)`，空时是 `无`。`当让` 在有值时循环，无值时停止。

## 10.6 动手实验

### 实验 1：简单计算器

```rust
枚举 运算 {
    加(浮点数, 浮点数),
    减(浮点数, 浮点数),
    乘(浮点数, 浮点数),
    除(浮点数, 浮点数),
}

函数 计算(op: 运算) -> 选项<浮点数> {
    匹配 op {
        运算::加(a, b) => 选项::有些(a + b),
        运算::减(a, b) => 选项::有些(a - b),
        运算::乘(a, b) => 选项::有些(a * b),
        运算::除(a, b) => {
            如果 b == 0.0 {
                选项::无
            } 否则 {
                选项::有些(a / b)
            }
        }
    }
}

函数 主函数() {
    让 操作 = [
        运算::加(10.0, 5.0),
        运算::除(10.0, 0.0),
        运算::乘(3.0, 4.0),
    ];

    对于 op 在 操作 {
        匹配 计算(op) {
            选项::有些(结果) => 打印行!("结果：{}", 结果),
            选项::无 => 打印行!("计算错误"),
        }
    }
}
```

## 本章小结

1. **`枚举`** 定义一个值的多种可能情况
2. 每个变体可以携带不同类型和数量的数据
3. **`匹配`** 是处理枚举的主要方式，必须穷尽所有情况
4. **`选项`**（有些/无）表示"有值或没有"
5. **`结果`**（成功/错误）表示"成功或失败"
6. **`如果让`** 简化只关心一种情况的匹配
7. **`当让`** 在匹配成功时持续循环
