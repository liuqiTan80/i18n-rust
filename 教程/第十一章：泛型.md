# 第十一章：泛型

假设你要写一个函数，找出两个数中较大的那个。但如果你也需要比较字符串、字符呢？难道要写三个几乎一样的函数？

**泛型**让你写一次代码，适用于多种类型。

---

## 11.1 什么是泛型

> 🎯 **生活类比**：泛型就像一个**万能模具**。普通函数只能处理一种材料（比如只能压铁），泛型模具能压任何材料——铁、铝、铜都行，只要材料"能被压"（满足某个条件）。

```
普通函数：只能处理整数          泛型函数：能处理任何可比较的类型
┌───────────────────┐          ┌───────────────────────────┐
│ 函数 取较大整数    │          │ 函数 取较大值<T: 可比较>  │
│   (a:整数,b:整数) │          │   (a:T, b:T) -> T        │
│   -> 整数         │          │                           │
│                   │          │ 可以传入：整数、浮点数、   │
│ 只能传入整数       │          │ 字符、字符串……任何可比较的 │
└───────────────────┘          └───────────────────────────┘
```

### 泛型函数

```rust
函数 取较大值<T: 部分排序>(a: T, b: T) -> T {
    如果 a >= b { a } 否则 { b }
}

函数 主函数() {
    打印行!("较大整数：{}", 取较大值(3, 5));        // T = 整数
    打印行!("较大浮点：{}", 取较大值(3.14, 2.71));  // T = 浮点数
    打印行!("较大字符：{}", 取较大值('a', 'z'));    // T = 字符
}
```

- **`<T: 部分排序>`** 表示"对于任何实现了 `部分排序`（可比较大小）的类型 T"。
- `T` 是一个**类型参数**——调用时由编译器自动推断。
- **`部分排序`** 是一个**特征**（trait），表示"可以比较大小"。

> 💡 **通俗理解**：`T: 部分排序` 读作"T 必须能比较大小"。这是给万能模具设的**门槛**——不是所有东西都能往里塞，至少得能比较大小。

## 11.2 泛型结构体

```rust
结构体 点<T> {
    x: T,
    y: T,
}

函数 主函数() {
    让 整数点 = 点 { x: 5, y: 10 };       // T = 整数
    让 浮点点 = 点 { x: 1.0, y: 4.0 };    // T = 浮点数

    打印行!("整数点：({}, {})", 整数点.x, 整数点.y);
    打印行!("浮点点：({}, {})", 浮点点.x, 浮点点.y);
}
```

```
┌── 点<T> ──────────────────────────────┐
│                                        │
│  点<整数>  →  点 { x: 5, y: 10 }     │
│  点<浮点>  →  点 { x: 1.0, y: 4.0 }  │
│  点<字符>  →  点 { x: 'a', y: 'b' }  │
│                                        │
│  注意：x 和 y 必须是同一种类型！       │
└────────────────────────────────────────┘
```

### 多个类型参数

```rust
结构体 键值对<K, V> {
    键: K,
    值: V,
}

函数 主函数() {
    让 条目 = 键值对 {
        键: "名字",
        值: "小明",
    };
    打印行!("{} = {}", 条目.键, 条目.值);
}
```

## 11.3 泛型枚举

你已经见过泛型枚举了——`选项` 和 `结果` 就是泛型枚举：

```rust
// 选项<T> 可以是任何类型的"有值或无"
让 数字: 选项<整数> = 选项::有些(42);
让 文本: 选项<字符串> = 选项::无;

// 结果<T, E> 有两个类型参数
让 成功: 结果<整数, 字符串> = 结果::成功(200);
让 失败: 结果<整数, 字符串> = 结果::错误("出错了".转字符串());
```

## 11.4 特征约束

特征约束限制泛型必须满足的条件：

```rust
// 单个约束：T 必须能比较大小
函数 取较大值<T: 部分排序>(a: T, b: T) -> T {
    如果 a >= b { a } 否则 { b }
}

// 多个约束：T 必须能比较 + 能复制
函数 取较大并复制<T: 部分排序 + 可克隆>(a: T, b: T) -> (T, T) {
    如果 a >= b { (a.克隆(), a.克隆()) } 否则 { (b.克隆(), b.克隆()) }
}

// where 语法（约束太多时更清晰）
函数 复杂函数<T, U>(t: T, u: U) -> 字符串
其中
    T: 可显示 + 可克隆,
    U: 可调试,
{
    格式化!("{} {:?}", t, u)
}
```

| 写法 | 适用场景 |
|------|---------|
| `<T: 特征>` | 约束简单，一个就够 |
| `<T: 特征A + 特征B>` | 多个约束，简短 |
| `其中 T: 特征` | 约束多或类型参数多 |

## 11.5 动手实验

### 实验 1：泛型容器

```rust
结构体 容器<T> {
    内容: T,
}

实现<T> 容器<T> {
    函数 新建(内容: T) -> 自身 {
        自身 { 内容 }
    }

    函数 获取(&自我) -> &T {
        &自我.内容
    }
}

函数 主函数() {
    让 数字容器 = 容器::新建(42);
    让 文本容器 = 容器::新建("你好".转字符串());

    打印行!("数字：{}", 数字容器.获取());
    打印行!("文本：{}", 文本容器.获取());
}
```

## 常见错误

### ❌ 泛型参数未使用约束

```rust
函数 打印<T>(x: T) {
    // 打印行!("{}", x);  // ❌ T 没有实现 可显示
    // 修复：函数 打印<T: 可显示>(x: T)
}
```

### ❌ 不同类型用了同一个 T

```rust
结构体 点<T> { x: T, y: T }

函数 主函数() {
    // 让 p = 点 { x: 1, y: 2.0 };  // ❌ x 是整数，y 是浮点数，但 T 只能是一种
    // 修复：用两个类型参数 结构体 点<T, U> { x: T, y: U }
}
```

## 练习题

### 练习 1：泛型最大值函数

写一个泛型函数 `最大值`，接受一个 `&[T]` 切片（`T: 部分排序 + 复制`），返回 `选项<T>`（空切片返回 `无`）。

<details>
<summary>参考答案</summary>

```rust
函数 最大值<T: 部分排序 + 复制>(切片: &[T]) -> 选项<T> {
    如果 切片.是空() {
        返回 选项::无;
    }
    让 可变 最大 = 切片[0];
    对于 &项 在 &切片[1..] {
        如果 项 > 最大 {
            最大 = 项;
        }
    }
    选项::有些(最大)
}

函数 主函数() {
    打印行!("{:?}", 最大值(&[3, 1, 4, 1, 5]));  // 有些(5)
    打印行!("{:?}", 最大值(&[3.14, 2.71]));       // 有些(3.14)
}
```
</details>

### 练习 2：泛型栈

用泛型结构体实现一个 `栈<T>`，支持 `推入`、`弹出`、`查看顶部` 方法。

<details>
<summary>参考答案</summary>

```rust
结构体 栈<T> {
    元素: 向量<T>,
}

实现<T> 栈<T> {
    函数 新建() -> 自身 { 自身 { 元素: 向量::新建() } }

    函数 推入(&可变 自我, 值: T) {
        自我.元素.推(值);
    }

    函数 弹出(&可变 自我) -> 选项<T> {
        自我.元素.弹()
    }

    函数 查看顶部(&自我) -> 选项<&T> {
        自我.元素.最后()
    }
}

函数 主函数() {
    让 可变 s = 栈::新建();
    s.推入(1);
    s.推入(2);
    s.推入(3);
    打印行!("顶部：{:?}", s.查看顶部());  // 有些(3)
    打印行!("弹出：{:?}", s.弹出());       // 有些(3)
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| 泛型 | 写一次代码，适用于多种类型 |
| `<T>` | 类型参数，调用时由编译器推断 |
| 特征约束 | `T: 特征` 限制泛型必须满足的条件 |
| 泛型结构体 | `结构体 名字<T> { 字段: T }` |
| 泛型枚举 | `选项<T>`、`结果<T, E>` 就是泛型 |
