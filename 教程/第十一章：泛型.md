# 第十一章：泛型

假设你要写一个函数，找出数组中最大的数。但如果你也需要找出最大的字符串呢？难道要写两个几乎一样的函数？

**泛型**让你写一次代码，适用于多种类型。

---

## 11.1 泛型函数

```rust
函数 取较大值<T: 部分排序>(a: T, b: T) -> T {
    如果 a >= b { a } 否则 { b }
}

函数 主函数() {
    打印行!("较大整数：{}", 取较大值(3, 5));
    打印行!("较大浮点：{}", 取较大值(3.14, 2.71));
    打印行!("较大字符：{}", 取较大值('a', 'z'));
}
```

- **`<T: 部分排序>`** 表示"对于任何实现了 `部分排序`（`PartialOrd`）的类型 T"。
- `T` 是一个**类型参数**——调用时由编译器推断具体类型。
- **`部分排序`** 是一个**特征**（trait），表示"可以比较大小"。

> **通俗理解**：泛型就像"万能钥匙"——一把钥匙开多种锁。`部分排序` 就是"能比较大小的东西"的条件。

## 11.2 泛型结构体

```rust
结构体 点<T> {
    x: T,
    y: T,
}

函数 主函数() {
    让 整数点 = 点 { x: 5, y: 10 };       // T = 整数
    让 浮点点 = 点 { x: 1.0, y: 4.0 };    // T = 浮点数

    打印行!("整数点：({}, {})", 整数点.x, 整数点.y);
    打印行!("浮点点：({}, {})", 浮点点.x, 浮点点.y);
}
```

`点<T>` 中的 `x` 和 `y` 必须是**同一种类型**。

### 多个类型参数

```rust
结构体 键值对<K, V> {
    键: K,
    值: V,
}

函数 主函数() {
    让 条目 = 键值对 {
        键: "名字",
        值: "小明",
    };
    打印行!("{} = {}", 条目.键, 条目.值);
}
```

## 11.3 泛型枚举

你已经见过泛型枚举了——`选项` 和 `结果` 就是泛型枚举：

```rust
// 选项<T> 可以是任何类型的"有值或无"
让 数字: 选项<整数> = 选项::有些(42);
让 文本: 选项<字符串> = 选项::无;

// 结果<T, E> 有两个类型参数
让 成功: 结果<整数, 字符串> = 结果::成功(200);
让 失败: 结果<整数, 字符串> = 结果::错误("出错了".转字符串());
```

## 11.4 动手实验

### 实验 1：泛型容器

```rust
结构体 容器<T> {
    内容: T,
}

实现<T> 容器<T> {
    函数 新建(内容: T) -> 自身 {
        自身 { 内容 }
    }

    函数 获取(&自我) -> &T {
        &自我.内容
    }
}

函数 主函数() {
    让 数字容器 = 容器::新建(42);
    让 文本容器 = 容器::新建("你好".转字符串());

    打印行!("数字：{}", 数字容器.获取());
    打印行!("文本：{}", 文本容器.获取());
}
```

---

## 本章小结

1. **泛型** 让代码适用于多种类型
2. **`<T>`** 是类型参数，调用时由编译器推断
3. 泛型结构体：`结构体 名字<T> { 字段: T }`
4. 泛型枚举：`选项<T>`、`结果<T, E>` 就是泛型
5. **特征约束**（如 `T: 部分排序`）限制泛型必须满足的条件
