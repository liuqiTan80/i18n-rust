# 第十七章：包管理与构建

这一章我们学习如何用 **Cargo**（Rust 的包管理器和构建工具）管理项目，以及 rzc 如何与 Cargo 协作。

---

## 17.1 Cargo.toml

每个 Rust 项目都有一个 `Cargo.toml` 文件，描述项目信息和依赖：

```toml
[package]
name = "我的项目"
version = "0.1.0"
edition = "2021"

[dependencies]
serde = "1"
tokio = { version = "1", features = ["full"] }
```

- **`[package]`**：项目基本信息
- **`[dependencies]`**：第三方依赖

---

## 17.2 添加依赖

### 手动添加

直接编辑 `Cargo.toml`：

```toml
[dependencies]
rand = "0.8"
```

### 使用命令

```bash
cargo add rand
```

### 使用中文别名

在中文 Rust 项目中，你可以在 `use` 语句中使用中文别名：

```rust
使用 随机数::线程随机数生成器;
```

rzc 会自动把 `随机数` 替换为 `rand`。

---

## 17.3 Cargo 常用命令

| 命令 | 作用 |
|------|------|
| `cargo build` | 编译项目 |
| `cargo run` | 编译并运行 |
| `cargo check` | 只检查，不编译 |
| `cargo test` | 运行测试 |
| `cargo clean` | 清除编译产物 |
| `cargo update` | 更新依赖 |

---

## 17.4 rzc 构建流程

rzc 在 Cargo 的基础上增加了翻译步骤：

```
rzc run src/main.zh
    ↓
1. 读取 main.zh（中文源码）
    ↓
2. 翻译为 main.rs（标准 Rust）
    ↓
3. 调用 cargo run（编译并运行）
    ↓
4. 输出结果
```

### rzc 命令一览

| 命令 | 作用 |
|------|------|
| `rzc init 项目名` | 创建新项目 |
| `rzc run 文件.zh` | 翻译并运行 |
| `rzc check 文件.zh` | 翻译并检查错误 |
| `rzc eject 文件.zh` | 导出为标准 Rust |

---

## 17.5 项目结构

一个典型的中文 Rust 项目结构：

```
我的项目/
├── Cargo.toml
├── rust-toolchain.toml
├── 语言包/
│   └── 中文/
│       ├── 关键字.toml
│       ├── 标准库.toml
│       ├── 错误消息.toml
│       ├── 模块路径.toml
│       └── 第三方库/
└── src/
    ├── main.zh
    └── lib.zh（可选）
```

---

## 本章小结

1. **`Cargo.toml`** 管理项目信息和依赖
2. **`cargo build/run/check/test`** 是常用构建命令
3. **rzc** 在 Cargo 基础上增加了中文翻译步骤
4. 项目结构包含语言包目录和 `.zh` 源码文件
