# 第十七章：包管理与构建

这一章我们学习如何用 **Cargo**（Rust 的包管理器和构建工具）管理项目，以及 rzc 如何与 Cargo 协作。

---

## 17.1 Cargo.toml

> 🎯 **生活类比**：`Cargo.toml` 就像一份**快递单**——告诉快递公司（编译器）你是谁、你要寄什么、需要哪些配件。

```
┌── Cargo.toml ──────────────────────┐
│  [package]                         │
│  名字 = "我的项目"                  │  ← 你是谁
│  版本 = "0.1.0"                    │  ← 版本号
│  版本集 = "2021"                    │  ← 用哪套规则
│                                    │
│  [dependencies]                    │
│  serde = "1"                       │  ← 需要哪些第三方库
│  tokio = { version = "1", ... }    │
└────────────────────────────────────┘
```

```toml
[package]
name = "我的项目"
version = "0.1.0"
edition = "2021"

[dependencies]
serde = "1"
tokio = { version = "1", features = ["full"] }
```

- **`[package]`**：项目基本信息——快递单上的发件人。
- **`[dependencies]`**：第三方依赖——你需要哪些配件。

## 17.2 添加依赖

### 手动添加

直接编辑 `Cargo.toml`：

```toml
[dependencies]
rand = "0.8"
```

### 使用命令

```bash
cargo add rand
```

### 使用中文别名

在中文 Rust 项目中，你可以在 `use` 语句中使用中文别名：

```rust
使用 随机数::线程随机数生成器;
```

rzc 会自动把 `随机数` 替换为 `rand`。

## 17.3 Cargo 常用命令

| 命令 | 作用 | 类比 |
|------|------|------|
| `cargo build` | 编译项目 | 把材料组装好 |
| `cargo run` | 编译并运行 | 组装好并启动 |
| `cargo check` | 只检查，不编译 | 检查图纸有没有错 |
| `cargo test` | 运行测试 | 质量检验 |
| `cargo clean` | 清除编译产物 | 清空工作台 |
| `cargo update` | 更新依赖 | 更换新配件 |

```
cargo check  vs  cargo build
┌──────────────┐    ┌──────────────┐
│ check        │    │ build        │
│ 检查语法     │    │ 检查语法     │
│ 检查类型     │    │ 检查类型     │
│ ✅ 到此为止  │    │ 生成二进制   │
│              │    │ ✅ 可以运行  │
└──────────────┘    └──────────────┘
  更快（不生成）       较慢（生成文件）
```

## 17.4 rzc 构建流程

rzc 在 Cargo 的基础上增加了翻译步骤：

```
rzc run src/main.zh
    ↓
1. 读取 main.zh（中文源码）
    ↓
2. 翻译为 main.rs（标准 Rust）
    ↓
3. 调用 cargo run（编译并运行）
    ↓
4. 输出结果
```

```
┌── rzc 构建流程 ──────────────────────┐
│                                      │
│  中文源码 (.zh)                       │
│      ↓                               │
│  ┌─────────────┐                     │
│  │ 词法翻译器   │  中文关键字 → 英文  │
│  └─────────────┘                     │
│      ↓                               │
│  标准 Rust 源码 (.rs)                 │
│      ↓                               │
│  ┌─────────────┐                     │
│  │ cargo build  │  编译为二进制       │
│  └─────────────┘                     │
│      ↓                               │
│  可执行文件                           │
│                                      │
└──────────────────────────────────────┘
```

### rzc 命令一览

| 命令 | 作用 |
|------|------|
| `rzc init 项目名` | 创建新项目 |
| `rzc run 文件.zh` | 翻译并运行 |
| `rzc check 文件.zh` | 翻译并检查错误 |
| `rzc eject 文件.zh` | 导出为标准 Rust |

## 17.5 项目结构

一个典型的中文 Rust 项目结构：

```
我的项目/
├── Cargo.toml          ← 项目配置
├── rust-toolchain.toml ← 编译器版本
├── 语言包/              ← 中文翻译规则
│   └── 中文/
│       ├── 关键字.toml
│       ├── 标准库.toml
│       ├── 错误消息.toml
│       ├── 模块路径.toml
│       └── 第三方库/
└── src/
    ├── main.zh         ← 你的中文代码
    └── lib.zh（可选）   ← 库代码
```

## 常见错误

### ❌ 忘记写 Cargo.toml

```bash
cargo build
# ❌ error: could not find `Cargo.toml`
# 修复：先用 cargo init 或 rzc init 初始化项目
```

### ❌ 依赖版本冲突

```toml
# 两个库依赖同一个库的不同版本
# 修复：用 cargo tree 查看冲突，或用 cargo update 解决
```
