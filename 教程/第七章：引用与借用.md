# 第七章：引用与借用

上一章我们学了所有权——赋值会转移所有权，函数传参也会。这带来一个问题：如果我们只是想"看看"一个值，不想夺走它怎么办？

答案是**引用**——就像借书，你不需要拥有这本书，只需要知道它在图书馆的哪个位置。

---

## 7.1 生活类比：借书 vs 买书

```
买书（转移所有权）：
  你 → 把钱给书店 → 书店把书给你 → 书是你的了
  代价：花了很多钱（复制数据的开销）

借书（引用）：
  你 → 去图书馆 → 看图书馆里的书 → 书还是图书馆的
  代价：几乎为零（只传一个地址）
```

引用就是数据的**地址**。它很小（8 字节），传递很快，而且不转移所有权。

---

## 7.2 引用（不可变借用）

**引用**用 **`&`** 创建，表示"借用"一个值，不转移所有权：

```rust
函数 计算长度(s: &字符串) -> 整数 {
    s.长度() 作为 整数
}

函数 主函数() {
    让 s = "你好世界".转字符串();
    让 长度 = 计算长度(&s);  // 传入引用，不转移所有权

    打印行!("'{}' 的长度是 {}", s, 长度);  // ✅ s 仍然有效
}
```

图解：

```
调用前：
s ──→ [堆上的字符串 "你好世界"]

调用 计算长度(&s) 时：
s ──→ [堆上的字符串 "你好世界"]  ← s 仍然拥有数据
         ↑
引用 ──┘  ← 函数只是"看"了一下，没有拿走

调用后：
s ──→ [堆上的字符串 "你好世界"]  ← s 完好无损
```

> **`&` 就是"借用"**——你只是临时使用，用完归还。

---

## 7.3 可变引用

默认引用是**不可变的**——你不能通过引用修改原始值。如果需要修改，用 **`可变引用`**（`&mut`）：

```rust
函数 添加后缀(文本: 可变引用 字符串) {
    文本.推入字符串("，世界！");
}

函数 主函数() {
    让 可变 s = "你好".转字符串();
    添加后缀(可变引用 s);  // 传入可变引用

    打印行!("{}", s);  // 输出：你好，世界！
}
```

要点：
- 变量本身需要声明为 **`让 可变`**
- 传参时用 **`可变引用`** 表示可变引用
- 函数参数类型是 **`可变引用 字符串`**

---

## 7.4 借用规则

Rust 有两条严格的借用规则：

### 规则一：同一时间只能有一个可变引用

```rust
函数 主函数() {
    让 可变 s = "你好".转字符串();

    让 r1 = 可变引用 s;  // ✅ 第一个可变引用
    // 让 r2 = 可变引用 s;  // ❌ 报错！不能同时有两个可变引用

    打印行!("{}", r1);
}
```

> **为什么？** 如果两个引用都能修改同一个值，就可能产生**数据竞争**——两个代码同时修改同一个数据，结果不可预测。

### 规则二：有不可变引用时，不能有可变引用

```rust
函数 主函数() {
    让 s = "你好".转字符串();

    让 r1 = &s;   // ✅ 不可变引用
    让 r2 = &s;   // ✅ 可以有多个不可变引用
    // 让 r3 = 可变引用 s;  // ❌ 报错！有不可变引用时不能有可变引用

    打印行!("{} {}", r1, r2);
}
```

> **为什么？** 如果一个人在读（不可变引用），另一个人在改（可变引用），读到的内容可能不一致。

### 总结表

```
┌──────────────────────────────────────────────────┐
│ 组合              │ 允许？ │ 类比                  │
├──────────────────────────────────────────────────┤
│ 多个不可变引用     │ ✅    │ 多个人同时看书         │
│ 一个可变引用       │ ✅    │ 一个人在书上做笔记     │
│ 不可变 + 可变     │ ❌    │ 有人看书，有人做笔记   │
│ 多个可变引用       │ ❌    │ 多人同时做笔记         │
└──────────────────────────────────────────────────┘
```

## 7.5 悬垂引用

Rust 编译器会阻止你创建**悬垂引用**——指向已释放数据的引用：

```rust
// 函数 获取引用() -> &整数 {
//     让 x = 42;
//     &x  // ❌ 报错！x 在函数结束时被释放，引用变成悬垂
// }
```

图解：

```
函数内：
x ──→ [42]  ← x 在栈上
引用 ──┘

函数结束后：
x 被销毁 → [??]  ← 数据没了
引用 ──┘          ← 悬垂引用！指向不存在的数据
```

正确做法是返回值，而不是返回引用：

```rust
函数 获取值() -> 整数 {
    让 x = 42;
    x  // 返回值，所有权转移
}
```

## 7.6 引用的生命周期

引用的**生命周期**（lifetime）从创建开始，到**最后一次使用**结束：

```rust
函数 主函数() {
    让 可变 s = "你好".转字符串();

    让 r1 = &s;       // r1 生命周期开始
    让 r2 = &s;       // r2 生命周期开始
    打印行!("{} {}", r1, r2);
    // r1, r2 到这里不再使用 → r1, r2 生命周期结束

    让 r3 = 可变引用 s;   // ✅ 现在可以有可变引用
    r3.推入字符串("！");
    打印行!("{}", r3);
    // r3 生命周期结束
}
```

## 7.7 常见错误

### 错误 1：同时有不可变和可变引用

```rust
让 可变 s = "你好".转字符串();
让 r1 = &s;
让 r2 = 可变引用 s;  // ❌ r1 还在使用中
打印行!("{}", r1);
```

**修复**：确保不可变引用不再使用后，再创建可变引用。

### 错误 2：通过不可变引用修改

```rust
函数 添加(s: &字符串) {
    s.推入字符串("!");  // ❌ 不可变引用不能修改
}
```

**修复**：参数改为 `s: 可变引用 字符串`。

### 错误 3：返回局部变量的引用

```rust
函数 获取引用() -> &整数 {
    让 x = 42;
    &x  // ❌ x 会被销毁
}
```

**修复**：返回值而不是引用 → `x`。

```rust

函数 主函数() {
    让 s = "你好".转字符串();
    打印文本(s);
    打印行!("{}", s);  // ❌ s 已移动
```

### 练习 2：用可变引用修改

写一个函数 `翻倍(列表: 可变引用 向量<整数>)`，把向量中每个元素乘以 2。

<summary>参考答案</summary>

```rust
    }

函数 主函数() {
    让 可变 数据 = 向量![1, 2, 3, 4, 5];
```

## 本章小结

1. **`&`** 创建不可变借用，不转移所有权
2. **`可变引用`** 创建可变借用，可以修改原始值
3. 同一时间：要么多个不可变引用，要么一个可变引用，**不能混合**
4. Rust 编译器阻止**悬垂引用**——指向已释放数据的引用
5. 引用的生命周期从创建到**最后一次使用**结束
