# 第二十章：测试与文档

写代码只是工作的一半。另一半是确保代码**正确**并且**易于理解**。

这一章学习 Rust 的测试框架和文档系统。

---

## 20.1 单元测试

用 **`#[测试]`**（`#[test]`）标记测试函数：

```rust
函数 加(甲: 整数, 乙: 整数) -> 整数 {
    甲 + 乙
}

函数 减(甲: 整数, 乙: 整数) -> 整数 {
    甲 - 乙
}

#[cfg(测试)]
模块 测试 {
    使用 超级::*;

    #[测试]
    函数 测试加() {
        断言相等!(加(2, 3), 5);
        断言相等!(加(0, 0), 0);
        断言相等!(加(-1, 1), 0);
    }

    #[测试]
    函数 测试减() {
        断言相等!(减(5, 3), 2);
        断言相等!(减(0, 0), 0);
    }
}
```

- **`#[cfg(测试)]`** 表示"只在测试时编译这个模块"。
- **`使用 超级::*`** 引入父模块的所有内容。
- **`#[测试]`** 标记一个函数为测试用例。
- **`断言相等!`** 检查两个值是否相等，不等则测试失败。

### 运行测试

```bash
cargo test
```

### 更多断言宏

```rust
#[测试]
函数 测试示例() {
    断言!(真);              // 断言条件为真
    断言相等!(2 + 2, 4);   // 断言相等
    断言不等!(2, 3);        // 断言不等
}
```

## 20.2 集成测试

集成测试放在 `tests/` 目录下，测试整个包的公共 API：

```
我的项目/
├── src/
│   └── lib.zh
└── tests/
    └── 集成测试.zh
```

`tests/集成测试.zh`：

```rust
使用 我的项目::加;

#[测试]
函数 测试公共接口() {
    断言相等!(加(1, 2), 3);
}
```

集成测试只能访问 `公开` 的 API，就像外部用户一样。

## 20.3 文档注释

用 **`///`** 写文档注释——它们会被工具解析为文档：

```rust
/// 计算两个整数的和。
///
/// # 示例
///
/// ```
/// 让 结果 = 加(2, 3);
/// 断言相等!(结果, 5);
/// ```
函数 加(甲: 整数, 乙: 整数) -> 整数 {
    甲 + 乙
}
```

### 文档注释的常用段落

```rust
/// 从字符串中解析整数。
///
/// # 参数
///
/// * `输入` - 要解析的字符串
///
/// # 返回
///
/// 成功时返回 `成功(整数)`，失败时返回 `错误(解析错误)`
///
/// # 示例
///
/// ```
/// 让 数字 = 解析("42").解包();
/// 断言相等!(数字, 42);
/// ```
///
/// # 错误
///
/// 如果字符串不是有效整数，返回错误。
函数 解析(输入: &文本) -> 结果<整数, 解析错误> {
    输入.解析::<整数>()
}
```

---

## 20.4 文档测试

Rust 会**运行文档中的代码示例**作为测试：

```bash
cargo test
```

如果文档中的代码示例不能编译或运行结果不对，测试会失败。

这确保你的文档始终是**准确的**。

## 20.5 动手实验

### 实验 1：为函数写测试

```rust
函数 阶乘(n: 整数) -> 整数 {
    如果 n <= 1 {
        返回 1;
    }
    n * 阶乘(n - 1)
}

#[cfg(测试)]
模块 测试 {
    使用 超级::*;

    #[测试]
    函数 测试阶乘() {
        断言相等!(阶乘(0), 1);
        断言相等!(阶乘(1), 1);
        断言相等!(阶乘(5), 120);
        断言相等!(阶乘(10), 3628800);
    }
}

函数 主函数() {
    打印行!("5! = {}", 阶乘(5));
}
```

## 本章小结

1. **`#[测试]`** 标记测试函数
2. **`断言!`、`断言相等!`、`断言不等!`** 是常用断言宏
3. 单元测试放在源码文件中，用 `#[cfg(测试)]` 保护
4. 集成测试放在 `tests/` 目录下
5. **`///`** 文档注释，代码示例会被自动测试
