# 第二十章：测试与文档

写代码只是工作的一半。另一半是确保代码**正确**并且**易于理解**。

这一章学习 Rust 的测试框架和文档系统。

---

## 20.1 什么是测试

> 🎯 **生活类比**：测试就像**考试**——你写完作业后，需要检查答案是否正确。单元测试是"每道题单独检查"，集成测试是"整张卷子一起做"。

```
┌── 测试金字塔 ──────────────────────┐
│                                    │
│          ╱╲                        │
│         ╱  ╲   端到端测试          │
│        ╱────╲  （完整流程）        │
│       ╱      ╲                     │
│      ╱────────╲  集成测试          │
│     ╱          ╲ （模块间协作）    │
│    ╱────────────╲                  │
│   ╱              ╲  单元测试       │
│  ╱                ╲ （单个函数）   │
│ ╱──────────────────╲               │
│  数量最多，速度最快                  │
└────────────────────────────────────┘
```

## 20.2 单元测试

用 **`#[测试]`**（`#[test]`）标记测试函数：

```rust
函数 加(甲: 整数, 乙: 整数) -> 整数 {
    甲 + 乙
}

函数 减(甲: 整数, 乙: 整数) -> 整数 {
    甲 - 乙
}

#[cfg(测试)]
模块 测试 {
    使用 超级::*;

    #[测试]
    函数 测试加() {
        断言相等!(加(2, 3), 5);
        断言相等!(加(0, 0), 0);
        断言相等!(加(-1, 1), 0);
    }

    #[测试]
    函数 测试减() {
        断言相等!(减(5, 3), 2);
        断言相等!(减(0, 0), 0);
    }
}
```

> ✨ **宏调用提示**：本章首次出现 `断言相等!` 宏。和之前一样，不需要手动写感叹号——`断言相等!(...)` 和 `断言相等(...)` 都可以，工具会自动补上 `!`。类似的还有 `断言!`、`断言不等!` 等测试宏。

- **`#[cfg(测试)]`** 表示"只在测试时编译这个模块"。
- **`使用 超级::*`** 引入父模块的所有内容。
- **`#[测试]`** 标记一个函数为测试用例。
- **`断言相等!`** 检查两个值是否相等，不等则测试失败。

### 运行测试

```bash
cargo test
```

### 更多断言宏

```rust
#[测试]
函数 测试示例() {
    断言!(真);              // 断言条件为真
    断言相等!(2 + 2, 4);   // 断言相等
    断言不等!(2, 3);        // 断言不等
}
```

```
断言宏对比：
┌──────────────────────────────────────┐
│ 断言!(条件)                          │
│   → 条件为假时失败                   │
│                                      │
│ 断言相等!(a, b)                      │
│   → a != b 时失败，显示具体值        │
│                                      │
│ 断言不等!(a, b)                      │
│   → a == b 时失败                    │
└──────────────────────────────────────┘
```

## 20.3 集成测试

集成测试放在 `tests/` 目录下，测试整个包的公共 API：

```
我的项目/
├── src/
│   └── lib.zh
└── tests/
    └── 集成测试.zh
```

`tests/集成测试.zh`：

```rust
使用 我的项目::加;

#[测试]
函数 测试公共接口() {
    断言相等!(加(1, 2), 3);
}
```

```
单元测试 vs 集成测试：
┌──────────────────────────────────────┐
│ 单元测试：                           │
│ ├── 放在 src/ 中                     │
│ ├── 可以访问私有函数                 │
│ ├── 用 #[cfg(测试)] 保护            │
│ └── 测试内部实现细节                │
│                                      │
│ 集成测试：                           │
│ ├── 放在 tests/ 中                   │
│ ├── 只能访问公开 API                 │
│ ├── 像外部用户一样使用你的库         │
│ └── 测试模块间协作                   │
└──────────────────────────────────────┘
```

## 20.4 文档注释

> 🎯 **类比**：文档注释就像**产品说明书**——告诉用户这个函数怎么用、有什么参数、返回什么、有没有例子。

用 **`///`** 写文档注释——它们会被工具解析为文档：

```rust
/// 计算两个整数的和。
///
/// # 示例
///
/// ```
/// 让 结果 = 加(2, 3);
/// 断言相等!(结果, 5);
/// ```
函数 加(甲: 整数, 乙: 整数) -> 整数 {
    甲 + 乙
}
```

### 文档注释的常用段落

```rust
/// 从字符串中解析整数。
///
/// # 参数
///
/// * `输入` - 要解析的字符串
///
/// # 返回
///
/// 成功时返回 `成功(整数)`，失败时返回 `错误(解析错误)`
///
/// # 示例
///
/// ```
/// 让 数字 = 解析("42").解包();
/// 断言相等!(数字, 42);
/// ```
///
/// # 错误
///
/// 如果字符串不是有效整数，返回错误。
函数 解析(输入: &文本) -> 结果<整数, 解析错误> {
    输入.解析::<整数>()
}
```

## 20.5 文档测试

Rust 会**运行文档中的代码示例**作为测试：

```bash
cargo test
```

如果文档中的代码示例不能编译或运行结果不对，测试会失败。

这确保你的文档始终是**准确的**。

---

## 常见错误

### ❌ 测试函数忘记 #[测试]

```rust
#[cfg(测试)]
模块 测试 {
    使用 超级::*;

    // 函数 测试加() {  // ❌ 忘记加 #[测试]
    #[测试]
    函数 测试加() {     // ✅
        断言相等!(加(2, 3), 5);
    }
}
```

### ❌ 文档示例代码不正确

```rust
/// ```
/// 让 x = 加(2, 3);
/// 断言相等!(x, 6);  // ❌ 应该是 5
/// ```
```

### 练习 1：为阶乘函数写测试

为 `阶乘(n: 整数) -> 整数` 函数写单元测试，覆盖 0、1、5、10 的情况。

<details>
<summary>参考答案</summary>

```rust
函数 阶乘(n: 整数) -> 整数 {
    如果 n <= 1 { 返回 1; }
    n * 阶乘(n - 1)
}

#[cfg(测试)]
模块 测试 {
    使用 超级::*;

    #[测试]
    函数 测试阶乘() {
        断言相等!(阶乘(0), 1);
        断言相等!(阶乘(1), 1);
        断言相等!(阶乘(5), 120);
        断言相等!(阶乘(10), 3628800);
    }
}
```
</details>

### 练习 2：为安全除法写测试

为第十五章的 `安全除法` 函数写测试，覆盖正常除法和除零的情况。

<details>
<summary>参考答案</summary>

```rust
函数 安全除法(甲: 浮点数, 乙: 浮点数) -> 结果<浮点数, 字符串> {
    如果 乙 == 0.0 {
        结果::错误("除数不能为零".转字符串())
    } 否则 {
        结果::成功(甲 / 乙)
    }
}

#[cfg(测试)]
模块 测试 {
    使用 超级::*;

    #[测试]
    函数 测试正常除法() {
        匹配 安全除法(10.0, 2.0) {
            结果::成功(值) => 断言!((值 - 5.0).绝对值() < 0.001),
            _ => 恐慌!("应该成功"),
        }
    }

    #[测试]
    函数 测试除零() {
        匹配 安全除法(10.0, 0.0) {
            结果::错误(_) => {}  // 预期行为
            _ => 恐慌!("应该失败"),
        }
    }
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| `#[测试]` | 标记测试函数 |
