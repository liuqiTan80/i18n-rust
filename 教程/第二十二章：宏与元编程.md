# 第二十二章：宏与元编程

前面我们一直在"写代码"。现在我们要学一种更高级的技能——**用代码写代码**。这就是**宏**（metaprogramming）。

---

## 22.1 什么是宏

> 🎯 **生活类比**：宏就像一个**文字模板**。你告诉它"帮我写一封给 XX 的信"，它就按照模板自动生成一封完整的信。你不需要每次手写，只需要换个名字就行。

Rust 有两种宏：

| 类型 | 语法 | 用途 |
|------|------|------|
| **声明式宏** | `macro_rules!` | 基于模式匹配的文本替换，像"高级查找替换" |
| **过程宏** | `#[派生(...)]`、`#[属性]` | 接收代码作为输入，处理后返回新代码 |

> ✨ **宏调用提示**：在中文 Rust 中，宏名后面不需要手动加感叹号。`打印行("你好")` 和 `打印行!("你好")` 都可以，工具会自动补上 `!`。

---

## 22.2 声明式宏（macro_rules!）

### 最简单的宏

```rust
// 定义一个宏：创建包含指定值的向量
宏 创建向量 {
    // 规则：接受逗号分隔的表达式
    ($($元素:expr),*) => {
        {
            让 可变 临时 = 向量::新建();
            $(临时.推($元素);)*
            临时
        }
    };
}

函数 主函数() {
    让 v = 创建向量!(1, 2, 3);
    打印行!("{:?}", v);  // [1, 2, 3]
}
```

看起来复杂？我们逐部分拆解：

```
┌──────────────────────────────────────────────┐
│  宏 创建向量 {                                │
│    ($($元素:expr),*)  ←── 匹配规则（"输入格式"） │
│      =>                    ←── 替换规则（"输出代码"）│
│        { ... }                                 │
│  }                                            │
└──────────────────────────────────────────────┘
```

### 匹配符详解

| 符号 | 含义 | 示例 |
|------|------|------|
| `$变量:片段类型` | 匹配一个指定类型的片段 | `$名字:ident` 匹配标识符 |
| `$( ... )*` | 重复 0 次或多次 | `$(, $x:expr)*` |
| `$( ... )+` | 重复 1 次或多次 | `$(+ $x:expr)+` |
| `$( ... ),*` | 用逗号分隔的重复 | `$($x:expr),*` |

### 常用片段类型

| 片段类型 | 匹配什么 | 示例 |
|----------|---------|------|
| `expr` | 表达式 | `1+2`、`x.字段` |
| `ident` | 标识符 | `变量名`、`函数名` |
| `ty` | 类型 | `整数`、`字符串` |
| `stmt` | 语句 | `让 x = 5;` |
| `path` | 路径 | `标准库::集合::向量` |
| `tt` | 任意单个 token 树 | 几乎任何东西 |

### 实用宏示例

```rust
// 示例 1：assert 风格的断言宏
宏 断言大于 {
    ($左:expr, $右:expr) => {
        如果 !($左 > $右) {
            恐慌!("断言失败：{} 不大于 {}，在 {}:{}",
                字符串化!($左), 字符串化!($右),
                文件!(), 行!());
        }
    };
}

// 示例 2：快速创建哈希映射
宏 哈希映射 {
    ($($键:expr => $值:expr),* $(,)?) => {
        {
            让 可变 map = 标准库::集合::哈希映射::新建();
            $(map.插入($键, $值);)*
            map
        }
    };
}

函数 主函数() {
    断言大于!(10, 5);  // ✅ 通过

    让 分数 = 哈希映射!{
        "小明" => 85,
        "小红" => 92,
        "小刚" => 78,
    };
    打印行!("{:?}", 分数);
}
```

## 22.3 过程宏

过程宏比声明式宏更强大。它接收**代码的抽象语法树**作为输入，可以任意变换后输出新代码。

> 🎯 **生活类比**：如果声明式宏是"填空题模板"，那过程宏就是"AI 写作助手"——它理解你的代码，然后生成新代码。

### 派生宏（derive）

最常见的过程宏。第十二章已经用过 `#[派生(调试)]`，现在我们来**自己写一个**：

```rust
// 假设有一个过程宏库 crate
使用 过程宏::TokenStream;
使用 引用::字符串::引用字符串;

#[过程宏(派生)]
// 为结构体自动生成 摘要() 方法
函数 摘要(input: TokenStream) -> TokenStream {
    let 输入 = input.to_string();
    // 解析结构体名（简化处理）
    let 结构体名 = 解析结构体名(&输入);

    let 输出 = 格式!(r#"
        实现 {} {{
            函数 摘要(&自我) -> 字符串 {{
                格式化!("{{}} 的实例", "{}")
            }}
        }}
    "#, 输入, 结构体名);

    输出.parse().expect("解析失败")
}
```

使用方式：

```rust
使用 我的宏库::摘要;

#[派生(摘要)]
结构体 文章 {
    标题: 字符串,
    内容: 字符串,
}

函数 主函数() {
    让 文 = 文章 {
        标题: "学习Rust".转字符串(),
        内容: "Rust 是一门...".转字符串(),
    };
    打印行!("{}", 文.摘要());  // "文章 的实例"
}
```

### 属性宏

属性宏可以作用于函数、结构体等，比派生宏更灵活：

```rust
// 一个给函数添加"执行计时"的属性宏
#[属性(计时)]
函数 慢速计算() -> 整数 {
    // ... 耗时操作
    42
}

// 宏展开后大致相当于：
函数 慢速计算() -> 整数 {
    让 开始 = 即时::现在();
    让 结果 = { 42 };  // 原始函数体
    让 耗时 = 开始.经过时间();
    打印行!("慢速计算 耗时: {:?}", 耗时);
    结果
}
```

## 22.4 宏 vs 函数

什么时候用宏，什么时候用函数？

| 场景 | 用宏 | 用函数 |
|------|------|--------|
| 参数数量不固定 | ✅ | ❌ |
| 需要生成新代码/类型 | ✅ | ❌ |
| 编译时计算 | ✅ | ❌ |
| 只是封装逻辑 | ❌ | ✅ |
| 需要类型检查 | ❌ | ✅ |
| 错误信息友好 | ❌ | ✅ |

**经验法则**：能用函数就用函数。函数更简单、错误信息更清晰、类型检查更严格。只有当函数做不到时（如可变参数、代码生成），才用宏。

## 22.5 宏的卫生性

Rust 的声明式宏是**卫生的**——宏内部的变量名不会和外部冲突：

```rust
宏 创建变量 {
    () => {
        让 x = 42;  // 这个 x 是宏"内部"的
    };
}

函数 主函数() {
    让 x = 10;      // 这个 x 是"外部"的
    创建变量!();
    打印行!("{}", x);  // 10，不是 42！
}
```

```
┌── 宏外部 ──────────────────┐
│  让 x = 10;               │
│  ┌── 宏内部 ────────────┐ │
│  │  让 x = 42; (卫生的) │ │
│  └──────────────────────┘ │
│  打印行!("{}", x); → 10   │
└───────────────────────────┘
```

> ⚠️ **注意**：过程宏**不是**卫生的，它们可以自由操作标识符。

## 常见错误

### ❌ 宏匹配规则顺序

宏的规则按**从上到下**匹配，第一个匹配成功的规则生效：

```rust
宏 测试宏 {
    (1) => { 打印行!("一"); },      // 精确匹配 1
    ($x:expr) => { 打印行!("其他"); },  // 匹配任何表达式
}

测试宏!(1);   // "一"（第一条规则先匹配）
测试宏!(2);   // "其他"
```

### ❌ 重复分隔符不匹配

```rust
宏 错误宏 {
    // ❌ 重复体用逗号分隔，但实际调用用分号
    ($($x:expr),*) => { };
}

错误宏!(1; 2; 3);  // 编译错误！
```

### ❌ 宏展开顺序

宏展开是**从外到内**的，不要假设某个宏在另一个宏之前展开：

```rust
// 不要依赖宏的展开顺序
让 x = 宏A!(宏B!(...));  // 宏B 先展开，然后 宏A
```

### 练习 2：计时宏

写一个宏 `计时!`，接受一段代码，执行它并打印耗时：

```rust
计时!({
    // 一些耗时操作
    让 可变 总和 = 0;
    对于 i 在 0..1000000 { 总和 += i; }
});
// 输出：耗时 12ms
```

<details>
<summary>参考答案</summary>

```rust
宏 计时 {
    ($代码:block) => {
        {
            让 开始 = 即时::现在();
            让 结果 = { $代码 };
            让 耗时 = 开始.经过时间();
            打印行!("耗时 {:?}", 耗时);
            结果
        }
    };
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| 声明式宏 | 基于模式匹配的文本替换 |
