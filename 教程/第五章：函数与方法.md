# 第五章：函数与方法

到目前为止，我们把所有代码都写在 `主函数` 里。但真正的程序不可能这么写——代码一多，就会变得混乱不堪。

这一章，我们学习如何把代码**组织成函数**，让程序更清晰、更可复用。

---

## 5.1 为什么需要函数？

### 生活类比

想象你是一个厨师。如果每次做菜都要从头开始——洗菜、切菜、炒菜、装盘——那做 100 份同样的菜就要重复 100 次所有步骤。

但如果你把"炒西红柿鸡蛋"这个流程**总结成一个菜谱**，每次只需要说"按菜谱做"就行了。

函数就是这个"菜谱"——把一段代码**打包**，给它一个名字，需要时直接调用。

```
没有函数：
  洗菜→切菜→炒菜→装盘→洗菜→切菜→炒菜→装盘→洗菜→切菜→炒菜→装盘
  （重复 3 次，代码冗长）

有函数：
  函数 做一道菜() { 洗菜→切菜→炒菜→装盘 }
  做一道菜()
  做一道菜()
  做一道菜()
  （简洁，可复用）
```

---

## 5.2 定义和调用函数

### 最简单的函数

```rust
函数 打招呼() {
    打印行!("你好！");
}

函数 主函数() {
    打招呼();  // 调用函数
    打招呼();  // 再调用一次
    打招呼();  // 再调用一次
}
```

输出：

```
你好！
你好！
你好！
```

> **函数定义后，可以在任何地方调用。** 不管函数定义在 `主函数` 前面还是后面。

---

## 5.3 参数：让函数接收输入

### 生活类比

菜谱（函数）可以接受不同的食材（参数）：

```
函数 炒(食材) {
    洗食材 → 切食材 → 炒食材 → 装盘
}

炒("西红柿")  → 炒西红柿
炒("鸡蛋")    → 炒鸡蛋
炒("青椒")    → 炒青椒
```

### 基本语法

```rust
函数 打招呼(名字: &文本) {
    //          ↑ 参数名: 参数类型
    打印行!("你好，{}！", 名字);
}

函数 主函数() {
    打招呼("小明");  // 传入 "小明"
    打招呼("小红");  // 传入 "小红"
}
```

输出：

```
你好，小明！
你好，小红！
```

> **参数必须标注类型**。这和 `让` 不同——`让` 可以自动推断类型，但函数参数不行。

### 多个参数

```rust
函数 求和(甲: 整数, 乙: 整数) {
    打印行!("{} + {} = {}", 甲, 乙, 甲 + 乙);
}

函数 主函数() {
    求和(3, 5);     // 输出 3 + 5 = 8
    求和(10, 20);   // 输出 10 + 20 = 30
}
```

## 5.4 返回值：让函数输出结果

### 生活类比

函数不仅可以接收输入，还可以**输出结果**：

```
函数 计算面积(长, 宽) → 面积 {
    返回 长 × 宽
}

计算面积(3, 4) → 12
计算面积(5, 6) → 30
```

### 基本语法

```rust
函数 求和(甲: 整数, 乙: 整数) -> 整数 {
    //                          ↑ 返回类型
    甲 + 乙   // 最后一行没有分号，就是返回值
}

函数 主函数() {
    让 结果 = 求和(3, 5);
    打印行!("3 + 5 = {}", 结果);  // 输出 3 + 5 = 8
}
```

### 两种返回方式

**方式一：表达式（推荐）**

函数体的**最后一行**如果**没有分号**，它就是返回值：

```rust
函数 翻倍(n: 整数) -> 整数 {
    n * 2   // 没有分号 → 这就是返回值
}
```

**方式二：`返回` 关键字**

用 **`返回`** 提前返回：

```rust
函数 检查(分数: 整数) -> 布尔 {
    如果 分数 < 0 {
        返回 假;  // 提前返回，函数到此结束
    }
    如果 分数 > 100 {
        返回 假;
    }
    真  // 最后一行，隐式返回
}
```

> **建议**：尽量用表达式返回值，少用 `返回`。这样代码更简洁。

### 不返回值的函数

如果函数不需要返回值，可以省略 `->`：

```rust
函数 打印问候(名字: &文本) {
    打印行!("你好，{}！", 名字);
    // 没有 -> 表示不返回值（隐式返回 ()）
}
```

## 5.5 语句与表达式

这是 Rust 的一个核心概念：

```
┌────────────────────────────────────────────────┐
│ 语句（Statement）  │ 表达式（Expression）       │
├────────────────────────────────────────────────┤
│ 执行动作           │ 产生一个值                │
│ 不返回值           │ 可以返回值                │
│ 以分号结尾         │ 通常不以分号结尾           │
│ 例：让 x = 5;     │ 例：5 + 3 → 8            │
└────────────────────────────────────────────────┘
```

在函数中，区别很明显：

```rust
// ✅ 表达式风格（推荐）
函数 加一(n: 整数) -> 整数 {
    n + 1   // 表达式，返回值
}

// 语句风格（也能工作，但不推荐）
函数 加一(n: 整数) -> 整数 {
    返回 n + 1;  // 语句，用 返回 关键字
}
```

**加了分号就变成语句，不再返回值：**

```rust
函数 加一(n: 整数) -> 整数 {
    n + 1;  // ❌ 加了分号，变成语句
}
// 编译报错：期望返回整数，实际得到 ()
```

> **记忆技巧**：分号就像句号——加了句号，这句话就"说完了"，不再有"言外之意"（返回值）。

## 5.6 函数调用栈

### 什么是调用栈？

当一个函数调用另一个函数时，计算机会"记住"当前执行到哪里，然后跳去执行被调用的函数。执行完后，再跳回来继续。

这个过程用一个叫**调用栈**（call stack）的数据结构来管理：

```
调用 求和(3, 5) 时：

┌──────────────────┐
│ 求和(3, 5)       │  ← 当前执行
│   甲=3, 乙=5     │
├──────────────────┤
│ 主函数()         │  ← 等待求和返回
│   等待结果...     │
└──────────────────┘

求和返回 8 后：

┌──────────────────┐
│ 主函数()         │  ← 继续执行
│   结果 = 8       │
└──────────────────┘
```

### 嵌套调用示例

```rust
函数 甲() {
    打印行!("甲 开始");
    乙();
    打印行!("甲 结束");
}

函数 乙() {
    打印行!("乙 开始");
    丙();
    打印行!("乙 结束");
}

函数 丙() {
    打印行!("丙 执行");
}

函数 主函数() {
    甲();
}
```

输出和调用栈变化：

```
甲 开始        → 调用栈：[主函数, 甲]
乙 开始        → 调用栈：[主函数, 甲, 乙]
丙 执行        → 调用栈：[主函数, 甲, 乙, 丙]
乙 结束        → 丙返回，调用栈：[主函数, 甲, 乙]
甲 结束        → 乙返回，甲继续，然后甲返回
               → 调用栈：[主函数]
```

## 5.7 方法：绑定到类型的函数

### 什么是方法？

**方法**（method）就是绑定到某个类型上的函数。

普通函数是"独立的"，方法则"属于"某个类型。

```
普通函数：  求和(3, 5)         → 不依赖于任何类型
方法：      "hello".长度()     → 属于 文本 类型
```

### 用 `实现` 块定义方法

```rust
结构体 矩形 {
    宽: 浮点数,
    高: 浮点数,
}

实现 矩形 {
    // 关联函数（构造器）—— 不属于某个实例
    函数 新建(宽: 浮点数, 高: 浮点数) -> 自身 {
        自身 { 宽, 高 }
    }

    // 方法 —— 第一个参数是 &自我
    函数 面积(&自我) -> 浮点数 {
        自我.宽 * 自我.高
    }

    函数 周长(&自我) -> 浮点数 {
        2.0 * (自我.宽 + 自我.高)
    }
}

函数 主函数() {
    让 r = 矩形::新建(3.0, 4.0);
    打印行!("面积：{}", r.面积());     // 12
    打印行!("周长：{}", r.周长());     // 14
}
```

理解要点：

| 语法 | 含义 |
|------|------|
| `实现 矩形` | 为 `矩形` 类型定义方法 |
| `函数 新建(...)` | 关联函数（不接收 `自我`），通常用作构造器 |
| `函数 面积(&自我)` | 方法，`&自我` 表示"借用自身" |
| `矩形::新建(...)` | 用 `::` 调用关联函数 |
| `r.面积()` | 用 `.` 调用方法 |

## 5.8 常见错误

### 错误 1：忘记返回类型

```rust
函数 求和(甲: 整数, 乙: 整数) {  // ❌ 缺少 -> 整数
    甲 + 乙
}
```

### 错误 2：最后一行加了分号

```rust
函数 加一(n: 整数) -> 整数 {
    n + 1;  // ❌ 加了分号，返回 () 而不是整数
}
```

### 错误 3：参数缺少类型标注

```rust
函数 打招呼(名字) {  // ❌ 参数必须标注类型
    打印行!("你好，{}", 名字);
}
```

### 错误 4：返回值类型不匹配

```rust
函数 获取名字() -> 整数 {
    "小明"  // ❌ 期望返回整数，实际返回文本
}
```

## 5.9 动手实验

### 实验 1：温度转换函数

```rust
函数 摄氏转华氏(摄氏: 浮点数) -> 浮点数 {
    摄氏 * 9.0 / 5.0 + 32.0
}

函数 华氏转摄氏(华氏: 浮点数) -> 浮点数 {
    (华氏 - 32.0) * 5.0 / 9.0
}

函数 主函数() {
    让 摄氏 = 36.6;
    让 华氏 = 摄氏转华氏(摄氏);
    打印行!("{}°C = {}°F", 摄氏, 华氏);
    打印行!("{}°F = {}°C", 华氏, 华氏转摄氏(华氏));
}
```

### 实验 2：判断素数

```rust
函数 是否素数(n: 整数) -> 布尔 {
    如果 n < 2 {
        返回 假;
    }
    让 可变 i = 2;
    当 i * i <= n {
        如果 n % i == 0 {
            返回 假;
        }
        i += 1;
    }
    真
}

函数 主函数() {
    对于 n 在 1..=20 {
        如果 是否素数(n) {
            打印!("{} ", n);
        }
    }
    打印行!();
}
```

### 实验 3：斐波那契数列

```rust
函数 斐波那契(n: 整数) -> 整数 {
    如果 n <= 1 {
        返回 n;
    }
    斐波那契(n - 1) + 斐波那契(n - 2)
}

函数 主函数() {
    对于 i 在 0..10 {
        打印!("{} ", 斐波那契(i));
    }
    打印行!();
}
```

## 本章小结

1. **`函数 名字(参数) { ... }`** 定义函数
2. 参数**必须标注类型**：`名字: 类型`
3. 用 **`-> 类型`** 指定返回类型
4. 最后一行**没有分号**就是返回值（表达式风格）
5. **`返回`** 用于提前返回
6. **语句**执行动作，**表达式**产生值
7. **`实现 类型 { ... }`** 定义方法，`&自我` 表示借用自身
8. 函数调用使用**栈**结构——后进先出
