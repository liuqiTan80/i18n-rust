# 第一章：你好，世界

欢迎来到中文 Rust 的世界！

在这一章里，你将完成人生中第一件了不起的事——用中文写一段能运行的程序。别担心，我会一步一步带你走，就像教一个从没下过厨的人做第一道菜。

---

## 1.1 什么是中文 Rust？

在开始之前，我们先聊一个最重要的问题：**为什么要有中文 Rust？**

你可能听说过，学编程要先学英语。`if`、`else`、`for`、`while`……这些英文单词是程序员的"日常用语"。但对于很多中文母语者来说，一边学编程逻辑，一边还要记英文单词，就像同时学两门外语，难度翻倍了。

**中文 Rust 就是来解决这个问题的。**

它让你用中文关键字写 Rust 代码。比如：

- 英文 Rust 里写 `fn`，中文 Rust 里写 **`函数`**
- 英文 Rust 里写 `let`，中文 Rust 里写 **`让`**
- 英文 Rust 里写 `if`，中文 Rust 里写 **`如果`**

你写的代码看起来就像中文伪代码，但它是**真正可以编译运行的程序**。

```rust
函数 主函数() {
    打印行!("你好，世界！");
}
```

这段代码会被自动翻译成标准 Rust，然后编译执行。你不需要关心翻译过程——你只需要专注学编程本身。

> **核心理念**：编程是一种思维方式，不应该被语言门槛挡住。

## 1.2 安装 rzc 编译器

要运行中文 Rust 代码，你需要安装一个叫做 **rzc** 的工具。它就像一个翻译官——把你写的中文代码翻译成英文，再交给 Rust 编译器去执行。

### 第一步：安装 Rust

rzc 依赖 Rust 编译器。如果你的电脑上还没有 Rust，请先安装它。

打开终端（Windows 用户请打开 PowerShell 或 CMD），输入：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

安装完成后，关闭并重新打开终端，然后验证：

```bash
rustc --version
```

如果看到类似 `rustc 1.75.0` 的输出，说明安装成功。

### 第二步：下载并编译 rzc

rzc 是本项目自带的工具。进入项目目录，执行：

```bash
cd /你的路径/zrRust
cargo build --workspace
```

编译完成后，你会在 `target/debug/` 目录下看到 `rzc` 可执行文件。

验证一下：

```bash
./target/debug/rzc --help
```

如果看到帮助信息，恭喜你，安装完成！

> **小贴士**：为了方便使用，你可以把 `rzc` 复制到系统 PATH 中，或者创建一个别名。

## 1.3 第一个程序：你好，世界

现在，让我们写第一个程序。这是每个程序员的"成人礼"——不管学什么语言，第一个程序永远是打印"你好，世界"。

### 创建项目

使用 rzc 创建一个新项目：

```bash
./target/debug/rzc init 你好世界 --语言 zh
```

这条命令会创建一个叫 `你好世界` 的文件夹，里面包含：

```
你好世界/
├── Cargo.toml          # 项目配置文件
├── rust-toolchain.toml # Rust 版本锁定
├── 语言包/             # 中文语言包
└── src/
    └── main.zh         # 你的中文源码文件
```

### 编写代码

打开 `src/main.zh`，你会看到默认的代码：

```rust
函数 主函数() {
    打印行!("你好，世界！");
}
```

这就是你的第一个中文 Rust 程序。让我逐行解释：

- **`函数 主函数()`** —— 定义了一个叫做"主函数"的函数。这是程序的入口，Rust 总是从这里开始执行。
- **`打印行!("你好，世界！")`** —— 调用了一个宏，在屏幕上打印一行文字，并自动换行。
- **`{` 和 `}`** —— 花括号包围的部分叫做"函数体"，里面是函数要执行的具体内容。

### 运行程序

保存文件后，在终端中执行：

```bash
./target/debug/rzc run src/main.zh
```

你会看到输出：

```
你好，世界！
```

恭喜！你已经成功运行了第一个中文 Rust 程序。

## 1.4 理解程序结构

让我们更深入地理解刚才写的代码。

```rust
函数 主函数() {
    打印行!("你好，世界！");
}
```

### 函数

在中文 Rust 中，**`函数`** 关键字用来定义一个函数（对应英文的 `fn`）。函数是一段可以重复使用的代码块。

**`主函数`** 是一个特殊的名字。Rust 规定，每个可执行程序都必须有一个叫 `main` 的函数作为入口。在中文 Rust 里，你写 **`主函数`**，rzc 会自动把它翻译成 `main`。

### 语句与分号

注意代码末尾的分号 **`;`**。在 Rust 中，分号表示一条语句的结束。就像中文里的句号一样，它告诉编译器"这句话说完了"。

如果你忘了写分号，编译器会报错。别担心，错误信息会告诉你哪里出了问题。

### 宏

**`打印行!`** 后面有一个感叹号 **`!`**。这个感叹号表示它是一个**宏**，而不是普通函数。

宏和函数很像，但宏在编译时展开，可以接受可变数量的参数。你暂时不需要深入理解宏的工作原理——只要记住：**看到感叹号，就知道它是宏**。

常用的宏还有：
- **`打印!`** —— 打印但不换行
- **`格式化`** —— 格式化字符串
- **`断言!`** —— 检查条件是否为真

## 1.5 修改程序，动手实验

学习编程最好的方式就是**动手改代码**。让我们修改刚才的程序。

### 实验 1：改变输出内容

把代码改成：

```rust
函数 主函数() {
    打印行!("你好，我是小明！");
    打印行!("我正在学中文 Rust。");
}
```

运行后输出：

```
你好，我是小明！
我正在学中文 Rust。
```

> **观察**：每条 `打印行!` 都会自动换行。如果你想连续打印在同一行，用 **`打印!`**。

### 实验 2：使用打印（不换行）

```rust
函数 主函数() {
    打印!("你好，");
    打印!("世界！");
}
```

运行后输出：

```
你好，世界！
```

两个 `打印!` 的内容连在了一起，因为没有换行。

### 实验 3：使用格式化字符串

```rust
函数 主函数() {
    让 名字 = "小明";
    让 年龄 = 20;
    打印行!("我叫{}，今年{}岁。", 名字, 年龄);
}
```

运行后输出：

```
我叫小明，今年20岁。
```

这里用到了 **`{}`** 占位符。`打印行!` 会把后面的参数依次填入花括号的位置。

> **注意**：`让` 是中文 Rust 的关键字，对应英文的 `let`，用来声明变量。我们下一章会详细讲。

## 1.6 编译与运行流程

你可能好奇：中文代码是怎么变成可执行程序的？

当你执行 `rzc run src/main.zh` 时，背后发生了以下步骤：

```
你的中文代码 (main.zh)
    ↓  rzc 翻译
标准 Rust 代码 (main.rs)
    ↓  rustc 编译
机器码 (可执行文件)
    ↓  运行
输出结果
```

1. **翻译阶段**：rzc 读取你的 `.zh` 文件，把中文关键字替换为英文关键字（如 `函数` → `fn`），生成临时的 `.rs` 文件。
2. **编译阶段**：Rust 编译器 `rustc` 把 `.rs` 文件编译成机器码。
3. **运行阶段**：执行编译好的程序，输出结果。

整个过程是自动的，你不需要手动执行每一步。

### 查看翻译后的代码

如果你想看看翻译后的英文代码长什么样，可以使用 `eject` 命令：

```bash
./target/debug/rzc eject src/main.zh
```

这会生成一个 `src/main.rs` 文件，内容类似：

```rust
fn main() {
    println!("你好，世界！");
}
```

注意：字符串里的中文不会被翻译——只有关键字和标识符会被替换。

## 1.7 使用 rzc check 检查错误

写代码时难免犯错。Rust 编译器以"严格"著称——它会在编译阶段就帮你发现很多潜在问题。

让我们故意写一段有错误的代码：

```rust
函数 主函数() {
    打印行!("你好"
}
```

注意：我故意漏掉了右括号 `)` 和分号 `;`。

运行检查：

```bash
./target/debug/rzc check src/main.zh
```

你会看到中文错误提示：

```
错误[E0001]: 期望 `)`，实际得到 `}`
  --> src/main.zh:2:18
   |
2  |     打印行!("你好"
   |                  ^ 期望 `)`
💡 请检查括号是否匹配。
```

rzc 会把英文错误翻译成中文，并附上 💡 教学提示，帮你理解错误原因。

> **好习惯**：每次修改代码后，先用 `rzc check` 检查，再运行。这样能更快定位问题。

## 1.8 代码风格与约定

虽然中文 Rust 让你用中文写代码，但仍有一些约定需要遵守：

### 缩进

使用 **4 个空格** 缩进（不要使用 Tab）。这是 Rust 社区的标准。

```rust
函数 主函数() {
    打印行!("正确缩进");  // ✅ 4 个空格
}
```

### 命名

- **函数名**：使用中文，如 `主函数`、`计算总和`、`获取用户输入`
- **变量名**：使用中文，如 `名字`、`年龄`、`数量`
- **类型名**：使用中文，如 `整数`、`字符串`、`布尔`

### 注释

使用 `//` 写单行注释，使用 `/* */` 写多行注释。注释内容可以是任意语言。

```rust
// 这是单行注释

/*
  这是多行注释
  可以写很多行
*/

函数 主函数() {
    打印行!("你好"); // 行尾注释
}
```

## 1.9 常见问题

### Q1：中文 Rust 能使用所有 Rust 功能吗？

目前支持大部分常用功能，包括：
- 变量、类型、控制流
- 函数、结构体、枚举
- 泛型、特征、生命周期
- 错误处理、模块系统
- 第三方库（通过中文别名）

少数高级功能仍在完善中。

### Q2：中文代码运行速度慢吗？

不会。中文代码在编译前会被翻译成标准 Rust，最终生成的机器码和英文 Rust 完全一样。性能零损失。

### Q3：我能混合使用中英文吗？

可以。关键字用中文，变量名可以用中文也可以用英文，字符串里可以写任何内容。但建议统一使用中文，保持一致性。

### Q4：去哪里找完整的中文关键字列表？

参见本教程附录：**中文 Rust 映射表参考**。
