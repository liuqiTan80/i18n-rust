# 第一章：你好，世界

欢迎来到中文 Rust 的世界！

在这一章里，你将完成人生中第一件了不起的事——用中文写一段能运行的程序。

> 如果你从来没写过代码，别担心。本章会从**最基础的概念**讲起，就像教一个从没下过厨的人做第一道菜——先认识厨房，再认识食材，最后才动手做菜。

---

## 1.1 什么是编程？什么是中文 Rust？

### 编程是什么？

想象你是一个机器人，你完全按照指令行动。编程就是**写指令**——告诉计算机"先做这个，再做那个"。

你写的指令叫做**代码**（code），写代码的工具叫做**编程语言**（programming language）。

就像人类有中文、英文、日文等不同语言，编程语言也有很多种：Python、Java、C++、Rust……它们各有特点，但核心思想是一样的——**用文字告诉计算机该做什么**。

### 为什么要有中文 Rust？

大多数编程语言的关键字都是英文的：`if`、`else`、`for`、`while`、`fn`、`let`……对英语母语者来说，这些词很自然。但对中文母语者来说，一边学编程逻辑，一边还要记英文单词，就像**同时学两门外语**，难度翻倍了。

**中文 Rust 就是来解决这个问题的。**

它让你用中文关键字写 Rust 代码：

| 英文 Rust | 中文 Rust | 含义 |
|-----------|-----------|------|
| `fn` | `函数` | 定义一段可重复使用的指令 |
| `let` | `让` | 创建一个"盒子"来存放数据 |
| `if` | `如果` | 根据条件决定做不做某事 |
| `for` | `对于` | 重复做某事 |
| `println!` | `打印行!` | 在屏幕上显示文字 |

你写的代码看起来就像中文伪代码，但它是**真正可以编译运行的程序**。

```rust
函数 主函数() {
    打印行!("你好，世界！");
}
```

> ✨ **宏调用提示**：在中文 Rust 中，所有宏名后面**不需要手动加感叹号**。工具会自动帮你补上。你只需要写 `打印行("你好，世界！")` 即可。当然，写了 `!` 也不会出错——两种写法都支持。

> **核心理念**：编程是一种**思维方式**，不应该被语言门槛挡住。

## 1.2 认识你的开发工具

在开始写代码之前，你需要准备几样工具。就像做饭需要锅碗瓢盆，写代码也需要工具。

### 终端（Terminal）

终端是一个**文字界面**，你在里面输入命令，计算机执行后返回结果。

- **macOS**：按 `Cmd + 空格`，输入"终端"或"Terminal"
- **Linux**：按 `Ctrl + Alt + T`
- **Windows**：搜索"PowerShell"或"命令提示符"

打开终端后，你会看到一个闪烁的光标——那就是你和计算机对话的入口。

### 编译器（Compiler）

你写的代码是**人类可读的文字**，但计算机只懂**二进制**（0 和 1）。编译器就是一个"翻译官"——把你的代码翻译成计算机能执行的指令。

```
你写的代码（人类语言）
    ↓ 编译器翻译
机器码（01010101...）
    ↓ 计算机执行
输出结果
```

中文 Rust 的编译器叫 **rzc**（Rust 中文编译器）。它分两步工作：

```
中文代码 (.zh 文件)
    ↓ rzc 翻译
标准 Rust 代码 (.rs 文件)
    ↓ Rust 编译器 (rustc) 编译
机器码（可执行文件）
    ↓ 运行
输出结果
```

### 文本编辑器

你需要一个工具来写代码。推荐：

- **VS Code**（免费，功能强大）—— 安装"Rust 中文"扩展即可获得中文语法高亮
- **Vim / Neovim**（终端内使用，适合进阶用户）

## 1.3 安装 rzc 编译器

### 第一步：安装 Rust

rzc 依赖 Rust 编译器。打开终端，输入：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

> 这行命令会从网上下载并安装 Rust。安装过程可能需要几分钟。

安装完成后，**关闭并重新打开终端**（这一步很重要！），然后验证：

```bash
rustc --version
```

如果看到类似 `rustc 1.75.0` 的输出，说明安装成功。

> **遇到问题？** 如果提示"命令未找到"，可能是 PATH 没有更新。试试关闭终端重新打开，或者运行 `source ~/.bashrc`（或 `source ~/.zshrc`）。

### 第二步：编译 rzc

rzc 是本项目自带的工具。进入项目目录：

```bash
cd /你的路径/zrRust
cargo build --workspace
```

> `cargo build` 是 Rust 的构建命令。它会下载依赖并编译项目。第一次编译可能需要几分钟。

编译完成后，验证一下：

```bash
./target/debug/rzc --help
```

如果看到帮助信息，恭喜，安装完成！

## 1.4 第一个程序：你好，世界

现在，让我们写第一个程序。这是每个程序员的"成人礼"——不管学什么语言，第一个程序永远是打印"你好，世界"。

### 创建项目

```bash
./target/debug/rzc init 你好世界 --语言 zh
```

这条命令会创建一个文件夹，结构如下：

```
你好世界/
├── Cargo.toml          ← 项目配置文件（记录项目名称、依赖等）
├── rust-toolchain.toml ← Rust 版本锁定
├── 语言包/             ← 中文语言包（关键字映射表）
└── src/
    └── main.zh         ← 你的源码文件（在这里写代码）
```

> 你只需要关心 `src/main.zh`——这是你写代码的地方。

### 编写代码

打开 `src/main.zh`，输入：

```rust
函数 主函数() {
    打印行!("你好，世界！");
}
```

让我们**逐字逐句**理解这段代码：

| 代码 | 含义 |
|------|------|
| `函数` | 关键字，表示"我要定义一段指令" |
| `主函数` | 这段指令的名字。Rust 规定程序必须从 `main`（中文映射为 `主函数`）开始执行 |
| `()` | 括号里放"参数"——函数需要的输入。这里为空，表示不需要输入 |
| `{` | 函数体开始——接下来是具体的指令 |
| `打印行!` | 一个内置工具，作用是在屏幕上显示文字 |
| `!` | 感叹号表示这是**宏**（一种特殊的工具），不是普通函数 |
| `("你好，世界！")` | 括号里是要显示的内容，用双引号包裹的文字叫做**字符串** |
| `;` | 分号表示一条指令结束，就像中文的句号 |
| `}` | 函数体结束 |

### 运行程序

保存文件后，在终端执行：

```bash
./target/debug/rzc run src/main.zh
```

你会看到：

```
你好，世界！
```

**恭喜！你已经成功运行了第一个中文 Rust 程序。**

## 1.5 理解编译流程

你可能好奇：中文代码是怎么变成可执行程序的？

当你执行 `rzc run` 时，背后发生了三步：

```
┌─────────────────────┐
│  你的中文代码         │  你写的：函数 主函数() { ... }
│  (main.zh)          │
└─────────┬───────────┘
          │ ① rzc 翻译
          ▼
┌─────────────────────┐
│  标准 Rust 代码      │  翻译后：fn main() { ... }
│  (main.rs)          │
└─────────┬───────────┘
          │ ② rustc 编译
          ▼
┌─────────────────────┐
│  机器码              │  计算机能执行的 0 和 1
│  (可执行文件)        │
└─────────┬───────────┘
          │ ③ 运行
          ▼
┌─────────────────────┐
│  输出结果            │  屏幕上显示：你好，世界！
└─────────────────────┘
```

1. **翻译**：rzc 把中文关键字替换为英文（`函数` → `fn`，`打印行` → `println`）
2. **编译**：Rust 编译器把英文代码翻译成机器码
3. **运行**：执行编译好的程序

> 整个过程是自动的。你只需要写 `.zh` 文件，其他的不需要操心。

### 查看翻译后的代码

好奇翻译后的英文长什么样？

```bash
./target/debug/rzc eject src/main.zh
```

这会生成 `src/main.rs`：

```rust
fn main() {
    println!("你好，世界！");
}
```

> 注意：字符串里的中文**不会**被翻译——只有关键字和标识符会被替换。

## 1.6 动手实验

学习编程最好的方式就是**动手改代码**。

### 实验 1：改变输出内容

```rust
函数 主函数() {
    打印行!("你好，我是小明！");
    打印行!("我正在学中文 Rust。");
}
```

运行后：

```
你好，我是小明！
我正在学中文 Rust。
```

> **观察**：每条 `打印行!` 都会自动换行。

### 实验 2：不换行打印

```rust
函数 主函数() {
    打印!("你好，");
    打印!("世界！");
}
```

运行后：

```
你好，世界！
```

两个 `打印!` 的内容连在了一起，因为没有换行。

### 实验 3：格式化字符串

```rust
函数 主函数() {
    让 名字 = "小明";
    让 年龄 = 20;
    打印行!("我叫{}，今年{}岁。", 名字, 年龄);
}
```

运行后：

```
我叫小明，今年20岁。
```

`{}` 是**占位符**——`打印行!` 会把后面的参数依次填入花括号的位置：

```
"我叫{}，今年{}岁。"
      ↓       ↓
    名字     年龄
      ↓       ↓
"我叫小明，今年20岁。"
```

> `让` 是中文 Rust 的关键字，对应英文的 `let`，用来创建变量（"数据盒子"）。下一章会详细讲。

## 1.7 错误处理：学会读懂报错

写代码时难免犯错。Rust 编译器以"严格"著称——它会在编译阶段就帮你发现很多潜在问题。

### 常见错误 1：漏掉括号

```rust
函数 主函数() {
    打印行!("你好"
}
```

报错：

```
错误[E0001]: 期望 `)`，实际得到 `}`
  --> src/main.zh:2:18
   |
2  |     打印行!("你好"
   |                  ^ 期望 `)`
💡 请检查括号是否匹配。
```

> **读报错的技巧**：编译器会告诉你**文件名**、**行号**、**错误类型**和**修复建议**。从第一行开始看，通常第一个错误修复后，后面的错误会消失。

### 常见错误 2：拼错关键字

```rust
函数 主函数() {
    打印行!("你好");
    打应行!("世界");  // ❌ "打应行" 不是关键字
}
```

报错：

```
错误[E0002]: 未知标识符 `打应行`
  --> src/main.zh:3:5
   |
3  |     打应行!("世界");
   |     ^^^^^^ 未找到此标识符
💡 你是不是想用 `打印行`？
```

### 常见错误 3：忘记分号

```rust
函数 主函数() {
    打印行!("你好")   // ❌ 缺少分号
}
```

报错：

```
错误[E0003]: 期望 `;`
  --> src/main.zh:2:21
   |
2  |     打印行!("你好")
   |                     ^ 缺少 `;`
💡 每条语句末尾需要分号。
```

> **好习惯**：每次修改代码后，先用 `rzc check` 检查，再运行。

## 1.8 代码风格

虽然中文 Rust 让你用中文写代码，但仍有一些约定需要遵守：

### 缩进

使用 **4 个空格** 缩进。花括号内的代码要缩进，表示"属于"这个函数。

```rust
函数 主函数() {
    打印行!("正确缩进");  // ✅ 4 个空格
}
```

### 命名

| 类别 | 风格 | 例子 |
|------|------|------|
| 函数名 | 中文动词/动宾短语 | `计算总和`、`获取用户输入` |
| 变量名 | 中文名词 | `名字`、`年龄`、`数量` |
| 类型名 | 中文名词 | `整数`、`字符串`、`学生信息` |

### 注释

注释是给**人**看的说明文字，编译器会忽略它。用 `//` 写单行注释：

```rust
// 这是单行注释，编译器会忽略

函数 主函数() {
    打印行!("你好"); // 行尾注释
    // 让 名字 = "小明";  // 被注释掉的代码不会执行
}
```

## 1.10 练习题

### 练习 1：自我介绍

写一个程序，在屏幕上输出你的自我介绍，至少包含三行：

```
大家好，我叫 XXX。
我今年 XX 岁。
我正在学习中文 Rust！
```

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    打印行!("大家好，我叫小明。");
    打印行!("我今年 20 岁。");
    打印行!("我正在学习中文 Rust！");
}
```

</details>

### 练习 2：格式化输出

写一个程序，声明两个变量 `城市` 和 `温度`，然后输出一句话：

```
北京今天气温 25 度。
```

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    让 城市 = "北京";
    让 温度 = 25;
    打印行!("{}今天气温 {} 度。", 城市, 温度);
}
```

</details>

### 练习 3（挑战）：画一个三角形

用 `打印!` 和 `打印行!` 在屏幕上输出一个三角形：

```
*
**
***
****
*****
```

<details>
<summary>参考答案</summary>

```rust
函数 主函数() {
    打印行!("*");
    打印行!("**");
    打印行!("***");
    打印行!("****");
    打印行!("*****");
}
```

</details>
