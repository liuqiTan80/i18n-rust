# 第十九章：并发与多线程

现代程序经常需要同时做多件事——下载文件的同时显示进度，处理请求的同时记录日志。

Rust 提供了强大的并发工具，而且**在编译时就能发现数据竞争**。

---

## 19.1 创建线程

用 **`线程::生成`**（`thread::spawn`）创建新线程：

```rust
使用 标准库::线程;
使用 标准库::time::持续时间;

函数 主函数() {
    让 句柄 = 线程::生成(|| {
        对于 i 在 1..=5 {
            打印行!("工作线程：{}", i);
            线程::线程休眠(持续时间::从毫秒(100));
        }
    });

    对于 i 在 1..=3 {
        打印行!("主线程：{}", i);
        线程::线程休眠(持续时间::从毫秒(100));
    }

    句柄.等待().解包();  // 等待工作线程完成
    打印行!("全部完成");
}
```

- **`线程::生成(|| { ... })`** 创建并启动一个新线程。
- **`||`** 是闭包（匿名函数）。
- **`.等待()`** 等待线程结束。

---

## 19.2 移动（move）

线程需要**拥有**它使用的数据。用 **`移动`**（`move`）把数据所有权转移给线程：

```rust
使用 标准库::线程;

函数 主函数() {
    让 数据 = 向量![1, 2, 3];

    让 句柄 = 线程::生成(移动 || {
        打印行!("线程中的数据：{:?}", 数据);
    });

    句柄.等待().解包();
    // 打印行!("{:?}", 数据);  // ❌ data 已经移动到线程中
}
```

## 19.3 通道（Channel）

线程之间用**通道**传递消息：

```rust
使用 标准库::sync::mpsc;
使用 标准库::线程;

函数 主函数() {
    让 (发送端, 接收端) = mpsc::channel();

    线程::生成(移动 || {
        发送端.发送("你好，主线程！".转字符串()).解包();
    });

    让 消息 = 接收端.接收().解包();
    打印行!("收到：{}", 消息);
}
```

- **`mpsc::channel()`** 创建通道（多生产者，单消费者）。
- **`.发送(值)`** 发送消息（会转移所有权）。
- **`.接收()`** 接收消息（阻塞等待）。

### 多个消息

```rust
使用 标准库::sync::mpsc;
使用 标准库::线程;

函数 主函数() {
    让 (发送端, 接收端) = mpsc::channel();

    线程::生成(移动 || {
        对于 i 在 1..=5 {
            发送端.发送(格式化!("消息 {}", i)).解包();
        }
    });

    对于 消息 在 接收端 {
        打印行!("收到：{}", 消息);
    }
}
```

## 19.4 互斥锁（Mutex）

当多个线程需要**共享可变数据**时，用**互斥锁**：

```rust
使用 标准库::sync::{互斥锁, 原子引用计数};
使用 标准库::线程;

函数 主函数() {
    让 计数器 = 原子引用计数::新建(互斥锁::新建(0));
    让 可变 句柄们 = 向量![];

    对于 _ 在 0..10 {
        让 计数器克隆 = 原子引用计数::克隆(&计数器);
        让 句柄 = 线程::生成(移动 || {
            让 可变 数字 = 计数器克隆.加锁().解包();
            *数字 += 1;
        });
        句柄们.推(句柄);
    }

    对于 句柄 在 句柄们 {
        句柄.等待().解包();
    }

    打印行!("最终计数：{}", *计数器.加锁().解包());
}
```

- **`互斥锁`**（`Mutex`）确保同一时间只有一个线程能访问数据。
- **`.加锁()`** 获取锁（阻塞直到可用）。
- **`Arc`** 让互斥锁可以在多个线程间共享。

## 19.5 Rust 的并发安全保证

Rust 在编译时阻止以下情况：

1. **数据竞争**：两个线程同时访问同一数据，至少一个是写操作
2. **跨线程移动无效类型**：不是所有类型都能安全地跨线程使用

```rust
// 编译器会阻止数据竞争
使用 标准库::线程;

函数 主函数() {
    让 可变 数据 = 0;

    让 h1 = 线程::生成(|| {
        // 数据 += 1;  // ❌ 不能借用可变数据到多个线程
    });

    让 h2 = 线程::生成(|| {
        // 数据 += 2;  // ❌ 同上
    });
}
```

---

## 本章小结

1. **`线程::生成`** 创建新线程
2. **`移动`** 闭包把数据所有权转移给线程
3. **通道**（`mpsc::channel`）用于线程间消息传递
4. **互斥锁**（`Mutex`）+ **`Arc`** 用于共享可变状态
5. Rust 在编译时阻止数据竞争
