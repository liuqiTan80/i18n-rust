# 第十九章：并发与多线程

现代程序经常需要同时做多件事——下载文件的同时显示进度，处理请求的同时记录日志。

Rust 提供了强大的并发工具，而且**在编译时就能发现数据竞争**。

---

## 19.1 什么是并发

> 🎯 **生活类比**：并发就像**厨房里的多个厨师**。一个厨师切菜，另一个炒菜，第三个煲汤——他们同时工作，但需要协调（比如不能同时用同一个灶台）。

```
同步（一个人做所有事）：
时间 ──────────────────────────→
厨师：切菜 → 炒菜 → 煲汤 → 完成
                     总时间 = 切菜 + 炒菜 + 煲汤

并发（多个人同时做）：
时间 ──────────────────────────→
厨师A：切菜 ──────→ 帮忙
厨师B：    炒菜 ──────→ 完成
厨师C：煲汤 ──────────────→ 完成
           总时间 ≈ max(切菜, 炒菜, 煲汤)
```

## 19.2 创建线程

用 **`线程::生成`**（`thread::spawn`）创建新线程：

```rust
使用 标准库::线程;
使用 标准库::time::持续时间;

函数 主函数() {
    让 句柄 = 线程::生成(|| {
        对于 i 在 1..=5 {
            打印行!("工作线程：{}", i);
            线程::线程休眠(持续时间::从毫秒(100));
        }
    });

    对于 i 在 1..=3 {
        打印行!("主线程：{}", i);
        线程::线程休眠(持续时间::从毫秒(100));
    }

    句柄.等待().解包();  // 等待工作线程完成
    打印行!("全部完成");
}
```

```
主线程 ──────────────────────────→
│ 打印 "主线程：1"
│ 打印 "主线程：2"         ┌── 工作线程 ──────→
│ 打印 "主线程：3"         │ 打印 "工作：1"
│ 等待...                  │ 打印 "工作：2"
│                          │ 打印 "工作：3"
│                          │ 打印 "工作：4"
│                          │ 打印 "工作：5"
│ 打印 "全部完成"          └── 完成
└── 完成
```

- **`线程::生成(|| { ... })`** 创建并启动一个新线程。
- **`||`** 是闭包（匿名函数）。
- **`.等待()`** 等待线程结束。

## 19.3 移动（move）

线程需要**拥有**它使用的数据。用 **`移动`**（`move`）把数据所有权转移给线程：

```rust
使用 标准库::线程;

函数 主函数() {
    让 数据 = 向量![1, 2, 3];

    让 句柄 = 线程::生成(移动 || {
        打印行!("线程中的数据：{:?}", 数据);
    });

    句柄.等待().解包();
    // 打印行!("{:?}", 数据);  // ❌ data 已经移动到线程中
}
```

```
移动前：                    移动后：
主线程拥有 data             线程拥有 data
┌──────┐                  ┌──────┐
│ data │ ──── move ────→  │ 线程 │
│ [1,2,3]│                │ [1,2,3]│
└──────┘                  └──────┘
主线程不能再使用 data
```

## 19.4 通道（Channel）

> 🎯 **类比**：通道就像**传送带**——一个厨师通过传送带把菜递给另一个厨师。消息从发送端流入，从接收端流出。

```
发送端 ──────→ 通道 ──────→ 接收端
  线程A        (管道)        主线程
```

```rust
使用 标准库::sync::mpsc;
使用 标准库::线程;

函数 主函数() {
    让 (发送端, 接收端) = mpsc::channel();

    线程::生成(移动 || {
        发送端.发送("你好，主线程！".转字符串()).解包();
    });

    让 消息 = 接收端.接收().解包();
    打印行!("收到：{}", 消息);
}
```

- **`mpsc::channel()`** 创建通道（多生产者，单消费者）。
- **`.发送(值)`** 发送消息（会转移所有权）。
- **`.接收()`** 接收消息（阻塞等待）。

### 多个消息

```rust
使用 标准库::sync::mpsc;
使用 标准库::线程;

函数 主函数() {
    让 (发送端, 接收端) = mpsc::channel();

    线程::生成(移动 || {
        对于 i 在 1..=5 {
            发送端.发送(格式化!("消息 {}", i)).解包();
        }
    });

    对于 消息 在 接收端 {
        打印行!("收到：{}", 消息);
    }
}
```

## 19.5 互斥锁（Mutex）

> 🎯 **类比**：互斥锁就像**浴室的门锁**——一次只能有一个人进去。其他人必须等门开了才能用。

```
┌── 浴室（共享数据）──┐
│                     │
│  🔒 锁住了          │  ← 线程A 正在使用
│  线程A 在里面       │
│                     │
│  线程B 在等...      │  ← 等待锁释放
│  线程C 在等...      │
└─────────────────────┘
```

```rust
使用 标准库::sync::{互斥锁, 原子引用计数};
使用 标准库::线程;

函数 主函数() {
    让 计数器 = 原子引用计数::新建(互斥锁::新建(0));
    让 可变 句柄们 = 向量![];

    对于 _ 在 0..10 {
        让 计数器克隆 = 原子引用计数::克隆(&计数器);
        让 句柄 = 线程::生成(移动 || {
            让 可变 数字 = 计数器克隆.加锁().解包();
            *数字 += 1;
        });
        句柄们.推(句柄);
    }

    对于 句柄 在 句柄们 {
        句柄.等待().解包();
    }

    打印行!("最终计数：{}", *计数器.加锁().解包());
}
```

- **`互斥锁`**（`Mutex`）确保同一时间只有一个线程能访问数据。
- **`.加锁()`** 获取锁（阻塞直到可用）。
- **`Arc`** 让互斥锁可以在多个线程间共享。

```
Arc + Mutex 的组合：
┌────────────────────────────────┐
│ Arc（原子引用计数）             │
│  └── Mutex（互斥锁）           │
│       └── 数据（共享可变状态）  │
│                                │
│  多个线程通过 Arc 共享          │
│  通过 Mutex 保证一次只有一个   │
│  线程修改数据                  │
└────────────────────────────────┘
```

## 19.6 Rust 的并发安全保证

Rust 在编译时阻止以下情况：

1. **数据竞争**：两个线程同时访问同一数据，至少一个是写操作
2. **跨线程移动无效类型**：不是所有类型都能安全地跨线程使用

```rust
// 编译器会阻止数据竞争
使用 标准库::线程;

函数 主函数() {
    让 可变 数据 = 0;

    让 h1 = 线程::生成(|| {
        // 数据 += 1;  // ❌ 不能借用可变数据到多个线程
    });

    让 h2 = 线程::生成(|| {
        // 数据 += 2;  // ❌ 同上
    });
}
```

```
Rust 的并发安全：
┌──────────────────────────────────────┐
│  编译时检查：                        │
│  ├── 数据竞争 → 编译错误            │
│  ├── 跨线程移动无效类型 → 编译错误  │
│  └── 生命周期问题 → 编译错误        │
│                                      │
│  运行时保证：                        │
│  ├── 无数据竞争                      │
│  ├── 无悬垂引用                      │
│  └── 无 use-after-free              │
└──────────────────────────────────────┘
```

## 常见错误

### ❌ 忘记 .等待()

```rust
使用 标准库::线程;

函数 主函数() {
    线程::生成(|| {
        打印行!("你好");
    });
    // 忘记 .等待()，主线程可能先结束
    // 修复：让 句柄 = ...; 句柄.等待();
}
```

### ❌ 线程间共享可变数据不用锁

```rust
使用 标准库::线程;

函数 主函数() {
    让 可变 计数 = 0;
    // 线程::生成(|| { 计数 += 1; });  // ❌ 数据竞争
    // 修复：用 Arc<Mutex<i32>>
}
```

## 练习题

### 练习 1：多线程计数器

用 `Arc<Mutex<整数>>` 创建一个共享计数器，启动 5 个线程，每个线程把计数器加 100。

<details>
<summary>参考答案</summary>

```rust
使用 标准库::sync::{互斥锁, 原子引用计数};
使用 标准库::线程;

函数 主函数() {
    让 计数 = 原子引用计数::新建(互斥锁::新建(0));
    让 可变 句柄们 = 向量![];

    对于 _ 在 0..5 {
        让 计数克隆 = 计数.克隆();
        让 句柄 = 线程::生成(移动 || {
            对于 _ 在 0..100 {
                *计数克隆.加锁().解包() += 1;
            }
        });
        句柄们.推(句柄);
    }

    对于 句柄 在 句柄们 {
        句柄.等待().解包();
    }

    打印行!("最终计数：{}", *计数.加锁().解包());  // 500
}
```
</details>
