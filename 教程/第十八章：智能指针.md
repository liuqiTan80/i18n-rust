# 第十八章：智能指针

指针是一个存储内存地址的变量。Rust 有几种"智能指针"——不仅存储地址，还附带额外的功能（如内存管理）。

---

## 18.1 什么是智能指针

> 🎯 **生活类比**：普通指针是一张**便签纸**，上面写着东西放在哪。智能指针则是**带遥控的便签纸**——它不仅告诉你东西在哪，还能帮你管理东西（比如自动回收、计数共享等）。

```
普通引用：只指向数据
┌──────┐     ┌──────┐
│ 便签 │ ──→ │ 数据 │
└──────┘     └──────┘

智能指针：指向数据 + 额外功能
┌──────────────┐     ┌──────┐
│ 便签 + 遥控器│ ──→ │ 数据 │
│ (计数/自动释放)│    └──────┘
└──────────────┘
```

---

## 18.2 盒子（Box）

**`盒子`**（`Box`）是最简单的智能指针——把数据存储在**堆**上。

```rust
函数 主函数() {
    让 b = 盒子::新建(5);  // 把 5 放到堆上
    打印行!("b = {}", b);
}
```

```
栈                  堆
┌──────┐          ┌──────┐
│ 盒子 │ ───────→ │  5   │
│ (指针)│          └──────┘
└──────┘
```

### 什么时候用 Box？

1. **编译时不知道大小的类型**
2. **大量数据需要共享而不复制**
3. **递归类型**

### 递归类型

```rust
// 链表节点
枚举 列表 {
    节点(整数, 盒子<列表>),
    空,
}

函数 主函数() {
    让 链表 = 列表::节点(1,
        盒子::新建(列表::节点(2,
            盒子::新建(列表::节点(3,
                盒子::新建(列表::空))))));

    打印链表(&链表);
}

函数 打印链表(node: &列表) {
    匹配 node {
        列表::节点(值, 下一个) => {
            打印!("{} ", 值);
            打印链表(下一个);
        }
        列表::空 => 打印行!(),
    }
}
```

```
没有 Box：递归类型大小无限
┌── 列表 ──┐
│ 节点(1,  │
│   列表(2,│
│     列表(3, ...∞)))  ← 无限嵌套！
└──────────┘

有 Box：每个节点只存一个指针
┌── 节点 ──┐     ┌── 节点 ──┐     ┌── 节点 ──┐
│ 1 │ 指针 │ ──→ │ 2 │ 指针 │ ──→ │ 3 │ 空  │
└──────────┘     └──────────┘     └──────────┘
  在堆上           在堆上           在堆上
```

## 18.3 引用计数（Rc）

**`引用计数`**（`Rc`，Reference Counted）允许多个所有者共享同一份数据。

> 🎯 **类比**：图书馆的一本书——每次有人借走一本，计数器 +1；还回来时 -1。当计数归零，书就被回收。

```rust
使用 标准库::rc::引用计数;

函数 主函数() {
    让 共享数据 = 引用计数::新建("你好".转字符串());

    让 a = 共享数据.克隆();  // 引用计数 +1
    让 b = 共享数据.克隆();  // 引用计数 +1

    打印行!("引用计数：{}", 引用计数::强计数(&共享数据));  // 3

    打印行!("a = {}", a);
    打印行!("b = {}", b);

    // a 和 b 被释放时，引用计数 -1
    // 当计数归零时，数据被释放
}
```

```
引用计数 的工作流程：
时间线 ──────────────────────────→
  新建("你好")    → 计数 = 1
  a = 克隆()      → 计数 = 2
  b = 克隆()      → 计数 = 3
  打印计数         → 显示 3
  a 被释放         → 计数 = 2
  b 被释放         → 计数 = 1
  共享数据 被释放  → 计数 = 0 → 数据被回收
```

> 💡 **注意**：`引用计数` 只能用于**不可变**的共享数据。如果需要多线程，用 `原子引用计数`。

---

## 18.4 原子引用计数（Arc）

**`原子引用计数`**（`Arc`，Atomic Reference Counted）是 `引用计数` 的线程安全版本。

```rust
使用 标准库::sync::原子引用计数;
使用 标准库::线程;

函数 主函数() {
    让 数据 = 原子引用计数::新建("共享数据".转字符串());

    让 可变 句柄们 = 向量![];

    对于 i 在 0..3 {
        让 数据克隆 = 数据.克隆();
        让 句柄 = 线程::生成线程(移动 || {
            打印行!("线程 {} 读到：{}", i, 数据克隆);
        });
        句柄们.推(句柄);
    }

    对于 句柄 在 句柄们 {
        句柄.等待().解包();
    }
}
```

```
┌── Rc vs Arc ──────────────────────┐
│                                  │
│  Rc：单线程共享                   │
│  ├── 快（非原子操作）            │
│  └── 不能跨线程                  │
│                                  │
│  Arc：多线程共享                  │
│  ├── 稍慢（原子操作）            │
│  └── 可以跨线程                  │
│                                  │
└──────────────────────────────────┘
```

## 18.5 内部可变性（RefCell）

> 🎯 **类比**：`RefCell` 就像一个**带锁的日记本**——日记本本身是"不可变"的（你不能换本子），但你可以打开锁修改里面的内容。

```rust
使用 标准库::cell::引用单元;

函数 主函数() {
    让 数据 = 引用单元::新建(5);

    // 虽然 data 不可变，但可以修改内部值
    数据.借用可变().写入(10);

    打印行!("data = {}", 数据.借用());
}
```

> 💡 `RefCell` 在运行时检查借用规则（违反会 panic），而普通引用在编译时检查。

## 常见错误

### ❌ Rc 跨线程使用

```rust
使用 标准库::rc::引用计数;
使用 标准库::线程;

函数 主函数() {
    让 数据 = 引用计数::新建(5);
    // 线程::生成线程(移动 || {  // ❌ Rc 不能跨线程
    //     打印行!("{}", 数据);
    // });
    // 修复：用 Arc（原子引用计数）
}
```

### ❌ RefCell 运行时借用冲突

```rust
使用 标准库::cell::引用单元;

函数 主函数() {
    让 数据 = 引用单元::新建(5);
    让 借用1 = 数据.借用();
    // 让 借用2 = 数据.借用可变();  // ❌ 运行时 panic！
    // 修复：确保借用不重叠
}
```

## 本章小结

| 概念 | 一句话 |
|------|--------|
| `盒子` | 把数据放堆上——递归类型、大数据 |
| `引用计数` | 多所有者共享不可变数据（单线程） |
| `原子引用计数` | 多所有者共享（多线程安全） |
| `引用单元` | 运行时借用检查——内部可变性 |
