# 第十八章：智能指针

指针是一个存储内存地址的变量。Rust 有几种"智能指针"——不仅存储地址，还附带额外的功能（如内存管理）。

---

## 18.1 盒子（Box）

**`盒子`**（`Box`）是最简单的智能指针——把数据存储在**堆**上。

```rust
函数 主函数() {
    让 b = 盒子::新建(5);  // 把 5 放到堆上
    打印行!("b = {}", b);
}
```

### 什么时候用 Box？

1. **编译时不知道大小的类型**
2. **大量数据需要共享而不复制**
3. **递归类型**

### 递归类型

```rust
// 链表节点
枚举 列表 {
    节点(整数, 盒子<列表>),
    空,
}

函数 主函数() {
    让 链表 = 列表::节点(1,
        盒子::新建(列表::节点(2,
            盒子::新建(列表::节点(3,
                盒子::新建(列表::空))))));

    打印链表(&链表);
}

函数 打印链表(node: &列表) {
    匹配 node {
        列表::节点(值, 下一个) => {
            打印!("{} ", 值);
            打印链表(下一个);
        }
        列表::空 => 打印行!(),
    }
}
```

没有 `盒子`，递归类型的大小是无限的（无限嵌套），编译器无法分配。`盒子` 把"下一个节点"放在堆上，只存一个指针。

## 18.2 引用计数（Rc）

**`引用计数`**（`Rc`，Reference Counted）允许多个所有者共享同一份数据。

```rust
使用 标准库::rc::引用计数;

函数 主函数() {
    让 共享数据 = 引用计数::新建("你好".转字符串());

    让 a = 共享数据.克隆();  // 引用计数 +1
    让 b = 共享数据.克隆();  // 引用计数 +1

    打印行!("引用计数：{}", 引用计数::强计数(&共享数据));  // 3

    打印行!("a = {}", a);
    打印行!("b = {}", b);

    // a 和 b 被释放时，引用计数 -1
    // 当计数归零时，数据被释放
}
```

> **注意**：`引用计数` 只能用于**不可变**的共享数据。如果需要多线程，用 `原子引用计数`。

---

## 18.3 原子引用计数（Arc）

**`原子引用计数`**（`Arc`，Atomic Reference Counted）是 `引用计数` 的线程安全版本。

```rust
使用 标准库::sync::原子引用计数;
使用 标准库::线程;

函数 主函数() {
    让 数据 = 原子引用计数::新建("共享数据".转字符串());

    让 可变 句柄们 = 向量![];

    对于 i 在 0..3 {
        让 数据克隆 = 数据.克隆();
        让 句柄 = 线程::生成线程(移动 || {
            打印行!("线程 {} 读到：{}", i, 数据克隆);
        });
        句柄们.推(句柄);
    }

    对于 句柄 在 句柄们 {
        句柄.等待().解包();
    }
}
```

---

## 本章小结

1. **`盒子`**（`Box`）：把数据放堆上，用于递归类型和大数据
2. **`引用计数`**（`Rc`）：多所有者共享不可变数据
3. **`原子引用计数`**（`Arc`）：线程安全的引用计数
