# 第九章：结构体

到目前为止，我们用过的类型——整数、字符串、向量——都是 Rust 内置的。但真实程序需要**自定义类型**。

比如你想表示一个"学生"，他有名字、年龄、成绩。用三个独立变量太散了。**结构体**可以把相关数据打包成一个整体。

---

## 9.1 什么是结构体

> 🎯 **生活类比**：结构体就像一张**信息登记表**。表上有"姓名"、"年龄"、"成绩"等栏目，每个栏目填一个值。结构体就是你自己设计的表格——你决定有哪些栏目（字段），每个栏目是什么类型。

```
┌─────────── 学生信息卡 ───────────┐
│  姓名：小明                       │
│  年龄：20                         │
│  成绩：95.5                       │
└────────────────────────────┘
```

### 定义结构体

```rust
结构体 学生 {
    姓名: 字符串,
    年龄: 整数,
    成绩: 浮点数,
}

函数 主函数() {
    让 小明 = 学生 {
        姓名: "小明".转字符串(),
        年龄: 20,
        成绩: 95.5,
    };

    打印行!("姓名：{}", 小明.姓名);
    打印行!("年龄：{}", 小明.年龄);
    打印行!("成绩：{}", 小明.成绩);
}
```

- **`结构体 学生 { ... }`** 定义了一个新类型——相当于设计了一张表格的模板。
- 每个**字段**都有名字和类型——相当于表格的每一栏。
- 创建实例时用 `学生 { 字段: 值, ... }` 语法——相当于填好一张表。
- 用 **`.`** 访问字段：`小明.姓名`——相当于查看表的某一栏。

---

## 9.2 修改字段

默认情况下，结构体实例是**不可变的**（就像用钢笔写的表格）。要修改字段，需要声明为 `可变`（就像用铅笔写的表格）：

```rust
结构体 学生 {
    姓名: 字符串,
    年龄: 整数,
    成绩: 浮点数,
}

函数 主函数() {
    让 可变 小明 = 学生 {
        姓名: "小明".转字符串(),
        年龄: 20,
        成绩: 95.5,
    };

    小明.年龄 = 21;     // ✅ 可以修改
    小明.成绩 = 98.0;   // ✅ 可以修改

    打印行!("更新后：{}岁，成绩{}", 小明.年龄, 小明.成绩);
}
```

```
┌── 不可变（默认）──┐    ┌── 可变 ──┐
│  让 小明 = ...    │    │  让 可变 小明 = ... │
│  小明.年龄 = 21;  │    │  小明.年龄 = 21;  │
│  ❌ 编译错误！    │    │  ✅ 可以修改      │
└──────────────────┘    └──────────────────┘
```

## 9.3 更新语法

如果你想基于一个已有实例创建新实例，只改几个字段，用**更新语法**：

```rust
结构体 学生 {
    姓名: 字符串,
    年龄: 整数,
    成绩: 浮点数,
}

函数 主函数() {
    让 小明 = 学生 {
        姓名: "小明".转字符串(),
        年龄: 20,
        成绩: 95.5,
    };

    // 基于小明创建新实例，只改年龄和成绩
    让 大明 = 学生 {
        姓名: "大明".转字符串(),
        ..小明  // 其余字段复制小明的
    };

    打印行!("大明：{}岁", 大明.年龄);  // 20（继承自小明）
}
```

`..小明` 表示"其余字段从小明那里复制"。就像复印一张表格，只改其中几栏。

## 9.4 元组结构体

如果你不需要字段名，只需要位置，可以用**元组结构体**：

```rust
结构体 颜色(整数, 整数, 整数);
结构体 点(浮点数, 浮点数);

函数 主函数() {
    让 红色 = 颜色(255, 0, 0);
    让 原点 = 点(0.0, 0.0);

    打印行!("红色 RGB：({}, {}, {})", 红色.0, 红色.1, 红色.2);
    打印行!("原点：({}, {})", 原点.0, 原点.1);
}
```

```
普通结构体：字段有名字     元组结构体：字段有位置
┌──────────────┐          ┌──────────────┐
│ 姓名: "小明"  │          │ 位置0: 255   │
│ 年龄: 20     │          │ 位置1: 0     │
│ 成绩: 95.5   │          │ 位置2: 0     │
└──────────────┘          └──────────────┘
  用 .姓名 访问              用 .0 访问
```

## 9.5 方法

第五章已经介绍过方法。这里结合结构体再深入：

```rust
结构体 矩形 {
    宽: 浮点数,
    高: 浮点数,
}

实现 矩形 {
    // 关联函数（构造器）——不需要 self
    函数 新建(宽: 浮点数, 高: 浮点数) -> 自身 {
        自身 { 宽, 高 }
    }

    // 方法：计算面积——借用自身
    函数 面积(&自我) -> 浮点数 {
        自我.宽 * 自我.高
    }

    // 方法：计算周长
    函数 周长(&自我) -> 浮点数 {
        2.0 * (自我.宽 + 自我.高)
    }

    // 方法：缩放——可变借用自身
    函数 缩放(可变引用 自我, 倍数: 浮点数) {
        自我.宽 *= 倍数;
        自我.高 *= 倍数;
    }
}

函数 主函数() {
    让 可变 r = 矩形::新建(3.0, 4.0);

    打印行!("面积：{}", r.面积());
    打印行!("周长：{}", r.周长());

    r.缩放(2.0);
    打印行!("缩放后：{}×{}", r.宽, r.高);
}
```

三种 `self` 的区别：

| 写法 | 含义 | 类比 |
|------|------|------|
| `&自我` | 只读借用 | 看看表格内容 |
| `可变引用 自我` | 可变借用 | 修改表格内容 |
| `自身`（无 self） | 关联函数/构造器 | 制作空白表格 |

## 9.6 结构体与所有权

结构体字段遵循所有权规则。如果字段是引用类型，需要标注生命周期：

```rust
结构体 摘要<'a> {
    文本: &'a 文本,
}

函数 主函数() {
    让 小说 = "很久很久以前...".转字符串();
    让 摘 = 摘要 { 文本: &小说 };
    打印行!("摘要：{}", 摘.文本);
}
```

> 💡 生命周期标注会在第十三章详细讲解。现在只需要知道：结构体"记住"数据时，需要告诉编译器"我不会比数据活得久"。

## 常见错误

### ❌ 忘记 `可变` 就修改字段

```rust
结构体 点 { x: 浮点数, y: 浮点数 }

函数 主函数() {
    让 p = 点 { x: 0.0, y: 0.0 };
    p.x = 1.0;  // ❌ 不能修改不可变变量的字段
    // 修复：让 可变 p = ...
}
```

### ❌ 更新语法中引用了自身

```rust
函数 主函数() {
    让 小明 = 学生 { 姓名: "小明".转字符串(), 年龄: 20, 成绩: 95.5 };
    让 小明2 = 学生 { 年龄: 21, ..小明 };
    // 打印行!("{}", 小明.姓名);  // ❌ 小明 已移动！
    // 修复：先克隆，或用引用
}
```

### ❌ 方法中忘记 `&自我`

```rust
实现 矩形 {
    函数 面积(自我) -> 浮点数 {  // ❌ 这会消耗整个矩形
        自我.宽 * 自我.高
    }
}
// 修复：用 &自我（借用）而不是 自我（获取所有权）
```

### 练习 2：给矩形添加方法

给 `矩形` 结构体添加一个 `是否正方形` 方法（宽和高差的绝对值小于 0.001 就算正方形）。

<details>
<summary>参考答案</summary>

```rust
结构体 矩形 { 宽: 浮点数, 高: 浮点数 }

实现 矩形 {
    函数 新建(宽: 浮点数, 高: 浮点数) -> 自身 {
        自身 { 宽, 高 }
    }

    函数 是否正方形(&自我) -> 布尔 {
        (自我.宽 - 自我.高).绝对值() < 0.001
    }
}

函数 主函数() {
    让 r1 = 矩形::新建(3.0, 3.0);
    让 r2 = 矩形::新建(3.0, 4.0);
    打印行!("r1 是正方形？{}", r1.是否正方形());  // 真
    打印行!("r2 是正方形？{}", r2.是否正方形());  // 假
}
```
</details>

### 练习 3：学生管理系统

用结构体实现一个简单的学生管理系统：定义 `学生` 结构体，实现 `新建`、`是否及格`（成绩 >= 60）、`等级`（优秀/良好/及格/不及格）方法。在 `主函数` 中创建 3 个学生并打印信息。

<details>
<summary>参考答案</summary>

```rust
结构体 学生 {
    姓名: 字符串,
    成绩: 浮点数,
}

实现 学生 {
    函数 新建(姓名: &文本, 成绩: 浮点数) -> 自身 {
        自身 { 姓名: 姓名.转字符串(), 成绩 }
    }

    函数 是否及格(&自我) -> 布尔 {
        自我.成绩 >= 60.0
    }

    函数 等级(&自我) -> &文本 {
        匹配 自我.成绩 作为 整数 {
            90..=100 => "优秀",
            80..=89  => "良好",
            60..=79  => "及格",
            _        => "不及格",
        }
    }
}

函数 主函数() {
    让 学生们 = [
        学生::新建("小明", 92.0),
        学生::新建("小红", 78.5),
        学生::新建("小刚", 55.0),
    ];

    对于 s 在 学生们 {
        打印行!("{}：{}分 - {}", s.姓名, s.成绩, s.等级());
    }
}
```
</details>

## 本章小结

| 概念 | 一句话 |
|------|--------|
| `结构体` | 把相关数据打包成一个自定义类型 |
| `.` 访问 | 用 `.` 读取和修改字段（需要 `可变`） |
| `..旧实例` | 更新语法：基于已有实例创建新实例 |
| 元组结构体 | 用位置而非字段名 |
| `&自我` | 方法只读借用自身 |
| `可变引用 自我` | 方法可变借用自身 |
| 关联函数 | 不接收 `自我`，用 `类型::函数名()` 调用 |
