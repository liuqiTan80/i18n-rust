# 第九章：结构体

到目前为止，我们用过的类型——整数、字符串、向量——都是 Rust 内置的。但真实程序需要**自定义类型**。

比如你想表示一个"学生"，他有名字、年龄、成绩。用三个独立变量太散了。**结构体**（`结构体`）可以把相关数据打包成一个整体。

---

## 9.1 定义结构体

```rust
结构体 学生 {
    姓名: 字符串,
    年龄: 整数,
    成绩: 浮点数,
}

函数 主函数() {
    让 小明 = 学生 {
        姓名: "小明".转字符串(),
        年龄: 20,
        成绩: 95.5,
    };

    打印行!("姓名：{}", 小明.姓名);
    打印行!("年龄：{}", 小明.年龄);
    打印行!("成绩：{}", 小明.成绩);
}
```

- **`结构体 学生 { ... }`** 定义了一个新类型。
- 每个**字段**都有名字和类型。
- 创建实例时用 `学生 { 字段: 值, ... }` 语法。
- 用 **`.`** 访问字段：`小明.姓名`。

---

## 9.2 修改字段

默认情况下，结构体实例是不可变的。要修改字段，需要声明为 `可变`：

```rust
结构体 学生 {
    姓名: 字符串,
    年龄: 整数,
    成绩: 浮点数,
}

函数 主函数() {
    让 可变 小明 = 学生 {
        姓名: "小明".转字符串(),
        年龄: 20,
        成绩: 95.5,
    };

    小明.年龄 = 21;
    小明.成绩 = 98.0;

    打印行!("更新后：{}岁，成绩{}", 小明.年龄, 小明.成绩);
}
```

---

## 9.3 更新语法

如果你想基于一个已有实例创建新实例，只改几个字段，用**更新语法**：

```rust
结构体 学生 {
    姓名: 字符串,
    年龄: 整数,
    成绩: 浮点数,
}

函数 主函数() {
    让 小明 = 学生 {
        姓名: "小明".转字符串(),
        年龄: 20,
        成绩: 95.5,
    };

    // 基于小明创建新实例，只改年龄和成绩
    让 大明 = 学生 {
        姓名: "大明".转字符串(),
        ..小明  // 其余字段复制小明的
    };

    打印行!("大明：{}岁", 大明.年龄);  // 20（继承自小明）
}
```

`..小明` 表示"其余字段从小明那里复制"。

---

## 9.4 元组结构体

如果你不需要字段名，只需要位置，可以用**元组结构体**：

```rust
结构体 颜色(整数, 整数, 整数);
结构体 点(浮点数, 浮点数);

函数 主函数() {
    让 红色 = 颜色(255, 0, 0);
    让 原点 = 点(0.0, 0.0);

    打印行!("红色 RGB：({}, {}, {})", 红色.0, 红色.1, 红色.2);
    打印行!("原点：({}, {})", 原点.0, 原点.1);
}
```

## 9.5 方法

第五章已经介绍过方法。这里结合结构体再深入：

```rust
结构体 矩形 {
    宽: 浮点数,
    高: 浮点数,
}

实现 矩形 {
    // 关联函数（构造器）
    函数 新建(宽: 浮点数, 高: 浮点数) -> 自身 {
        自身 { 宽, 高 }
    }

    // 方法：计算面积
    函数 面积(&自我) -> 浮点数 {
        自我.宽 * 自我.高
    }

    // 方法：计算周长
    函数 周长(&自我) -> 浮点数 {
        2.0 * (自我.宽 + 自我.高)
    }

    // 方法：是否为正方形
    函数 是否正方形(&自我) -> 布尔 {
        (自我.宽 - 自我.高).绝对值() < 0.001
    }

    // 方法：缩放（需要可变引用）
    函数 缩放(可变引用 自我, 倍数: 浮点数) {
        自我.宽 *= 倍数;
        自我.高 *= 倍数;
    }
}

函数 主函数() {
    让 可变 r = 矩形::新建(3.0, 4.0);

    打印行!("面积：{}", r.面积());
    打印行!("周长：{}", r.周长());
    打印行!("是正方形？{}", r.是否正方形());

    r.缩放(2.0);
    打印行!("缩放后：{}×{}", r.宽, r.高);
}
```

- **`&自我`**：不可变借用自身
- **`&mut 自我`**：可变借用自身
- **`-> 自身`**：返回自身类型（用于构造器）

## 9.6 动手实验

### 实验 1：学生管理系统

```rust
结构体 学生 {
    姓名: 字符串,
    成绩: 浮点数,
}

实现 学生 {
    函数 新建(姓名: &文本, 成绩: 浮点数) -> 自身 {
        自身 {
            姓名: 姓名.转字符串(),
            成绩,
        }
    }

    函数 是否及格(&自我) -> 布尔 {
        自我.成绩 >= 60.0
    }

    函数 等级(&自我) -> &文本 {
        匹配 自我.成绩 作为 整数 {
            90..=100 => "优秀",
            80..=89  => "良好",
            60..=79  => "及格",
            _        => "不及格",
        }
    }
}

函数 主函数() {
    让 学生们 = [
        学生::新建("小明", 92.0),
        学生::新建("小红", 78.5),
        学生::新建("小刚", 55.0),
    ];

    对于 s 在 学生们 {
        打印行!("{}：{}分 - {}（{}）",
            s.姓名, s.成绩,
            如果 s.是否及格() { "及格" } 否则 { "不及格" },
            s.等级());
    }
}
```

## 本章小结

1. **`结构体`** 把相关数据打包成一个自定义类型
2. 用 `.` 访问和修改字段（需要 `可变`）
3. **更新语法** `..旧实例` 基于已有实例创建新实例
4. **元组结构体** 用位置而非字段名
5. **`实现`** 块定义方法：`&自我`（不可变）、`&mut 自我`（可变）
6. 关联函数（如 `新建`）不接收 `自我`，用 `类型::函数名()` 调用
