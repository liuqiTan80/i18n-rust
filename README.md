# i18n-rust：中文 Rust 教学方言编译器

让中文用户用母语编写 Rust 代码，零英语障碍学习编程。

## 项目愿景

- **教育优先**：让编程教育回归逻辑思维，而非英语记忆
- **母语可执行**：用中文编写的代码可直接编译运行
- **渐进过渡**：掌握概念后可平滑切换到标准 Rust
- **多语言原生**：架构天生支持任意自然语言

## 快速开始

### 安装

```bash
cargo build --workspace
```

### 创建教学项目

```bash
./target/debug/rzc init 我的项目 --语言 zh
```

### 运行中文代码

```rust
// src/main.zh
函数 主函数() {
    让 可变 数量 = 10;
    数量 = 数量 + 1;
    打印行!("数量是：{}", 数量);
}
```

```bash
./target/debug/rzc run src/main.zh
```

### 类型检查（中文错误提示）

```bash
./target/debug/rzc check src/main.zh
```

### 导出为标准 Rust

```bash
./target/debug/rzc eject src/main.zh
# 生成 src/main.rs
```

## 项目结构

```
i18n-rust/
├── 核心/引擎/          # 语言无关核心库
│   ├── 词法处理.rs     # 关键字 token 替换
│   ├── 映射管理.rs     # 语言包加载
│   ├── 映射源.rs       # 分类映射加载器
│   ├── 诊断.rs         # rustc 错误中文翻译
│   ├── 模块路径替换.rs # use 路径替换
│   └── 别名替换.rs     # 标识符别名替换
├── 工具/
│   ├── 命令行/         # rzc CLI 工具
│   ├── LSP代理/        # rust-analyzer 代理
│   └── vscode扩展/     # VS Code 扩展
└── 语言包/中文/        # 中文语言包数据
    ├── 关键字.toml     # 关键字映射
    ├── 标准库.toml     # 标准库别名
    ├── 错误消息.toml   # 错误码翻译
    ├── 模块路径.toml   # 模块路径映射
    └── 第三方库/       # 第三方库分类映射
```

## 核心功能

### 1. 词法转译

基于 `rustc_lexer` 精确分词，仅替换标识符 token，保留注释和字符串内容。

### 2. 中文错误诊断

解析 rustc JSON 输出，结合语言包翻译为中文教学诊断，附带 💡 学习建议。

### 3. LSP 智能补全

通过 rust-analyzer 代理实现中文代码的实时补全、定义跳转、引用查找。

### 4. VS Code 集成

- `.zh` 文件语法高亮
- 中文错误提示
- 一键运行/检查/导出

## 语言包规范

语言包是包含 TOML 文件的目录，例如 `语言包/中文/`：

- **关键字.toml**：中文关键字 → 英文关键字
- **标准库.toml**：标准库标识符别名
- **错误消息.toml**：错误码 → 中文翻译 + 教学提示
- **模块路径.toml**：模块路径中文段 → 英文段
- **第三方库/**：按功能分类的第三方库映射

## 示例代码

```rust
// 中文 Rust 示例
函数 阶乘(n: 整数) -> 整数 {
    如果 n <= 1 {
        返回 1;
    } 否则 {
        返回 n * 阶乘(n - 1);
    }
}

函数 主函数() {
    让 结果 = 阶乘(5);
    打印行!("5的阶乘是：{}", 结果);
}
```
