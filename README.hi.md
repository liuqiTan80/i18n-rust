# rzc: बहुभाषी Rust शिक्षण बोली कंपाइलर

> 🌍 **अपनी मातृभाषा में Rust लिखें।** · 10 भाषाएँ · असली Rust, असली टूलचेन · `rzc eject` से कभी भी स्नातक हों

**rzc एक बहुभाषी Rust बोली कंपाइलर है**: आप अपनी मातृभाषा में कोड लिखते हैं, rzc उसे वास्तविक समय में मानक Rust में अनुवादित करता है, आधिकारिक टूलचेन उसे संकलित और चलाता है, और प्रत्येक निदान शैक्षिक संकेतों के साथ आपकी भाषा में लौटता है। अंग्रेज़ी नहीं, प्रोग्रामिंग सीखें।

- 🌍 **स्यूडोकोड नहीं**: आपकी भाषा का कोड मानक Rust के साथ पूर्णतः समरूप है — संकलन, निष्पादन, निर्भरताएँ और पारिस्थितिकी 100% वास्तविक
- 🎓 **शुरुआती लोगों के लिए बना**: त्रुटि संदेश अंग्रेज़ी की दीवार के बजाय «आगे क्या करें» का मार्गदर्शन बन जाते हैं
- 🚪 **जब चाहें स्नातक**: `rzc eject` एक चरण में मानक Rust निर्यात करता है — कोई बंधन नहीं, पारिस्थितिकी से पूर्णतः संगत

```rust
// src/main.hi — हिंदी Rust शिक्षण बोली
फंक्शन मुख्य() {
    मानो परिवर्तनीय संख्या = 10;
    संख्या = संख्या + 1;
    पंक्ति_छापो!("संख्या: {}", संख्या);
}
```

```bash
$ rzc run src/main.hi
संख्या: 11
```

गलती होना कोई बात नहीं — संदेश भी आपकी भाषा में हैं:

```
त्रुटि[E0384]: अपरिवर्तनीय चर `संख्या` को दो बार मान नहीं दे सकते
  --> src/main.hi:3:5
💡 यदि आपको चर का मान बदलना है, तो इसे `मानो परिवर्तनीय` से घोषित करें।
```

वही प्रोग्राम सभी 10 अंतर्निहित बोलियों में चलता है — जैसे चीनी (`函数 主函数()`, `打印行!`) या जापानी (`関数 主関数()`, `表示行!`) में। मानक Rust (`fn main()`) सदैव ज्यों का त्यों स्वीकार्य है।

## 📦 स्थापना

दो विकल्प हैं: **विकल्प 1 — crates.io से इंस्टॉल** (अनुशंसित, अधिकांश उपयोगकर्ताओं के लिए); **विकल्प 2 — स्रोत से बिल्ड** (नवीनतम डेवलपमेंट संस्करण या rzc में बदलाव के बाद स्थानीय बिल्ड)।

**विकल्प 1: crates.io से इंस्टॉल (अनुशंसित)** — crates.io पर प्रकाशित; Rust टूलचेन हो तो एक कमांड ही काफी है:

```bash
cargo install rzc        # crates.io से प्राप्त कर स्थानीय रूप से बिल्ड (1–3 मिनट)
rzc --version            # वर्शन नंबर आए तो सफल
rzc init मेरा-प्रोजेक्ट && cd मेरा-प्रोजेक्ट && rzc run src/main.hi
```

> भाषा पैक पहले से शामिल हैं — कोई अतिरिक्त सेटअप नहीं। crate पेज: <https://crates.io/crates/rzc>; अपग्रेड: `cargo install rzc --force`। Rust टूलचेन नहीं है? पहले नीचे «1.» देखें।

**विकल्प 2: स्रोत से बिल्ड (डेवलपर)** — नवीनतम डेवलपमेंट संस्करण या rzc में बदलाव के बाद संकलन के लिए। **सबसे छोटा रास्ता** (Rust टूलचेन हो तो पहले प्रोग्राम तक 4 कमांड):

```bash
git clone https://github.com/liuqiTan80/i18n-rust && cd i18n-rust
cargo build --release --workspace   # लगभग 1–3 मिनट
cargo install --path crates/cli     # rzc को वैश्विक बनाएँ (या ./target/release/rzc सीधे चलाएँ)
rzc init मेरा-प्रोजेक्ट && cd मेरा-प्रोजेक्ट && rzc run src/main.hi
```

विकल्प 2 की पूरी चरण-दर-चरण प्रक्रिया नीचे है (पूर्वापेक्षाएँ → बिल्ड → सत्यापन); «1.» दोनों विकल्पों के लिए समान है।

### पूर्वापेक्षाएँ

| उपकरण | उद्देश्य | आवश्यक? |
|---|---|---|
| **Rust टूलचेन** (rustc + cargo) | rzc को ही बिल्ड करना | ✅ हाँ |
| **git** | सोर्स कोड प्राप्त करना | ✅ हाँ (या सोर्स ZIP) |
| **इंटरनेट** | पहली बिल्ड पर निर्भरताएँ डाउनलोड करना | ✅ हाँ (पहली बार) |
| **Node.js 18+ और npm** | VS Code एक्सटेंशन बिल्ड करना | वैकल्पिक (केवल IDE) |
| **rust-analyzer** | IDE पूर्णता/डायग्नोस्टिक्स बैकएंड | वैकल्पिक (केवल IDE) |

### 1. Rust टूलचेन स्थापित करें

अनुशंसित तरीका [rustup](https://rustup.rs) है (एक साथ rustc, cargo और rustup स्थापित करता है)।

- **Linux / macOS** (टर्मिनल में):

  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```

  फिर `source "$HOME/.cargo/env"` चलाएँ (या टर्मिनल फिर से खोलें)।

- **Windows**: [rustup-init.exe](https://rustup.rs) डाउनलोड करके विज़ार्ड का पालन करें (या PowerShell में `winget install --id Rustlang.Rustup`)।

जाँचें (टर्मिनल फिर से खोलकर):

```bash
rustc --version   # उदा.: rustc 1.98.0
cargo --version
```

### 2. सोर्स प्राप्त करें और बिल्ड करें

```bash
git clone https://github.com/liuqiTan80/i18n-rust.git
cd i18n-rust
cargo build --release --workspace
./target/release/rzc --version
```

पहली बिल्ड निर्भरताएँ डाउनलोड करती है और सभी घटकों को संकलित करती है (1–3 मिनट)। परिणाम:

- `target/release/rzc` — CLI उपकरण
- `target/release/i18n-rust-lsp` — भाषा सर्वर (VS Code एक्सटेंशन बैकएंड)

### 3. (वैकल्पिक) rzc को वैश्विक रूप से उपलब्ध करें

```bash
cargo install --path crates/cli   # स्थानीय रूप से बिल्ड करके ~/.cargo/bin में स्थापित करें
```

### 4. (वैकल्पिक) IDE सुविधाओं के लिए rust-analyzer स्थापित करें

```bash
rzc install toolchain --ra-only --force
```

आधिकारिक स्टैंडअलोन rust-analyzer `~/.rz/toolchain` में स्थापित होता है; rzc और भाषा सर्वर उसे स्वतः प्राथमिकता देते हैं।

### 5. (वैकल्पिक) VS Code एक्सटेंशन बिल्ड करें

Node.js 18+ और npm चाहिए ([nodejs.org](https://nodejs.org) से):

```bash
cd tools/vscode-extension
npm ci
npm run package    # i18n-rust-<संस्करण>.vsix बनाता है
```

`.vsix` को VS Code में «Install from VSIX...» से स्थापित करें — सिंटैक्स हाइलाइटिंग, स्मार्ट ऑटो-कम्प्लीशन, डायग्नोस्टिक्स, होवर और स्वामित्व विज़ुअलाइज़ेशन मिलता है; भाषा सर्वर `rzc install lsp` प्रदान करता है (अंतर्निहित टूलचेन स्वतः खोजता है)।

### पूर्ण सेटअप (प्रत्येक घटक के लिए एक कमांड)

```bash
rzc install lsp          # भाषा सर्वर (VS Code ऑटो-कम्प्लीशन/डायग्नोस्टिक्स/होवर बैकएंड)
rzc install toolchain    # अंतर्निहित आधिकारिक टूलचेन (~/.rz/toolchain में स्टैंडअलोन rustc/cargo/rust-analyzer)
rzc doctor               # टूलचेन परिवेश की स्थिति (अंतर्निहित/PATH/संस्करण तुलना)
```

स्थापना के बाद rzc और भाषा सर्वर स्वतः अंतर्निहित टूलचेन को प्राथमिकता देते हैं; एकल-फ़ाइल प्रोजेक्ट cargo इंडेक्स के बिना rustc को सीधे कॉल करते हैं।

### पर्यावरण चर (वैकल्पिक, सामान्यतः अनावश्यक)

| चर | उद्देश्य |
|---|---|
| `RZ_LANG_DIR` | भाषा पैक निर्देशिका (डिफ़ॉल्ट: अंतर्निहित पैक) |
| `RUST_ANALYZER_PATH` | rust-analyzer का पथ (स्वतः पहचान विफल होने पर) |

VS Code सेटिंग `i18n-rust.serverPath` LSP बाइनरी का पथ स्पष्ट रूप से निर्दिष्ट करती है (स्वतः पहचान विफल होने पर उपयोग होती है)।

### टूलचेन के किसी विशिष्ट घटक को अपग्रेड करें

| स्थिति | कमांड |
|---|---|
| rustc/cargo अपग्रेड (उदा. 1.98 → 1.99) | `rzc install toolchain --version 1.99.0 --force` |
| केवल rust-analyzer अपग्रेड (300MB दोबारा डाउनलोड किए बिना) | `rzc install toolchain --ra-tag <डेटा-टैग> --ra-only --force` |
| वर्तमान संस्करण और स्थिति देखें | `rzc doctor` |

### संपादक बदलें (VSCodium / Cursor और VS Code परिवार)

i18n-rust एक्सटेंशन (.vsix) सभी VS Code-आधारित संपादकों के साथ संगत है; rzc, भाषा सर्वर और टूलचेन संपादक से स्वतंत्र हैं:

1. नए संपादक में: एक्सटेंशन → «Install from VSIX» → `i18n-rust-<संस्करण>.vsix` चुनें;
2. मानक स्थानों पर घटक जोड़ें (rzc बिल्ड होने पर):
   ```bash
   rzc install lsp        # भाषा सर्वर → ~/.cargo/bin
   rzc install toolchain  # अंतर्निहित टूलचेन → ~/.rz/toolchain (ऑनलाइन; या वितरक के ऑफ़लाइन पैक से कॉपी करें)
   ```
3. `.hi` फ़ाइल खोलें और बस (एक्सटेंशन सर्वर और टूलचेन स्वतः खोज लेता है; `RUST_ANALYZER_PATH` या `i18n-rust.serverPath` सेटिंग से बदला जा सकता है)।

### वितरकों के लिए: ऑफ़लाइन रिलीज़ पैक (कक्षा-व्यापी वितरण)

रिपॉज़िटरी में एक-कमांड पैकेजिंग स्क्रिप्ट शामिल है (स्थानीय बिल्ड, वर्तमान प्लेटफ़ॉर्म के लिए पैक, Releases/फ़ाइल साझा करने के लिए):

| प्लेटफ़ॉर्म | कमांड | आउटपुट |
|---|---|---|
| Linux / macOS | `./release-offline.sh` | `release/rzc-<संस्करण>-linux/macos-<आर्किटेक्चर>.tar.gz` |
| Windows (PowerShell) | `.\release-offline.ps1` | `release/rzc-<संस्करण>-windows-x86_64.zip` |

पूर्वापेक्षा: release बिल्ड (ऊपर चरण 2) और ऑनलाइन रहते हुए `rzc install toolchain --ra-only --force` एक बार चलाना (स्क्रिप्ट उस प्लेटफ़ॉर्म का rust-analyzer पैक में कॉपी करता है)।

स्क्रिप्ट प्लेटफ़ॉर्म (Linux / Darwin / Windows) स्वतः पहचानती है; पैक में rzc, i18n-rust-lsp, rust-analyzer, 11 अंतर्निहित भाषा पैक (10 प्राकृतिक भाषाएँ + `en` पहचान पैक) और ट्यूटोरियल शामिल हैं — अनज़िप करें और उपयोग करें (विवरण ट्यूटोरियल के परिशिष्ट D.5 में)।

## 🚀त्वरित आरंभ

```bash
rzc init मेरा-प्रोजेक्ट        # चलने-योग्य प्रोजेक्ट ढांचा बनाएँ (Cargo.toml + src/main.hi)
cd मेरा-प्रोजेक्ट
rzc run src/main.hi            # अनुवाद → संकलन → निष्पादन
```

तीन चरणों में आपका पहला मातृभाषीय Rust प्रोग्राम चल जाता है।

## 🛠️ कमांड

| कमांड | विवरण |
|------------------------------------|------------------------------------------------------|
| `rzc init <नाम>` | प्रोजेक्ट बनाएँ (टूलचेन संस्करण स्थानीय रूप से स्थिर; IDE-तैयार) |
| `rzc run <फ़ाइल>` | अनुवाद कर चलाएँ; चेतावनियाँ/त्रुटियाँ/बिल्ड प्रगति आपकी भाषा में |
| `rzc check <फ़ाइल>` | स्थानीयकृत शैक्षिक निदान के साथ टाइप जाँच |
| `rzc eject <फ़ाइल>` | मानक Rust कोड में निर्यात करें (क्रमिक संक्रमण) |
| `rzc transpile <फ़ाइल>` | केवल अनुवाद — मानक आउटपुट पर मानक Rust |
| `rzc cheat <भाषा>` | भाषा ↔ Rust चीटशीट (`--markdown` से दस्तावेज़ों में एम्बेड करें) |
| `rzc add <crate>[@संस्करण]` | निर्भरता जोड़ें (`cargo add` का रैपर, मातृभाषा मैपिंग संकेतों के साथ) |
| `rzc doctor` | टूलचेन परिवेश का निदान (अंतर्निहित / PATH / संस्करण तुलना) |
| `rzc lang list` | स्थापित भाषा पैक की सूची |
| `rzc lang install <कोड/निर्देशिका>` | भाषा पैक स्थापित करें (रिमोट रजिस्ट्री या स्थानीय निर्देशिका) |
| `rzc lang search [कीवर्ड]` | स्थापित करने योग्य रिमोट भाषा पैक खोजें |
| `rzc lang remove <कोड>` | उपयोगकर्ता-स्थापित भाषा पैक हटाएँ |
| `rzc mapping auto <crate> [--target-version <संस्करण>]` | तृतीय-पक्ष crate की मातृभाषा मैपिंग स्वतः बनाएँ (AI/नियम); `--target-version` से आधार संस्करण स्थिर करें |
| `rzc mapping check [लक्ष्य]` | मैपिंग गुणवत्ता जाँचें (डुप्लीकेट कुंजियाँ / कीवर्ड टकराव / फ़ाइलों के बीच टकराव / अनिवार्य अनुभाग) |
| `rzc mapping coverage [--lang <भाषा>]` | वास्तविक कोड से भाषा पैक कवरेज मापें; अनुपलब्ध मैपिंग सूचीबद्ध करें (रिपॉज़िटरी रूट से चलाएँ) |
| `rzc mapping scaffold <स्रोत> <लक्ष्य>` | नई भाषा के लिए अनुवाद ढांचा बनाएँ; `--provider deepseek` से AI अनुवाद सक्षम करें |
| `rzc crate search [कीवर्ड]` | समुदाय द्वारा साझा तृतीय-पक्ष मैपिंग खोजें (रजिस्ट्री) |
| `rzc crate install <crate> --lang <भाषा>` | रजिस्ट्री की तृतीय-पक्ष मैपिंग वैश्विक भाषा पैक में स्थापित करें |
| `rzc crate list` | स्थापित समुदाय मैपिंग की सूची |
| `rzc crate remove <crate> --lang <भाषा>` | स्थापित समुदाय मैपिंग हटाएँ |
| `rzc crate update` | मेनिफ़ेस्ट के अनुसार सभी स्थापित मैपिंग पुनः डाउनलोड करें (अपडेट प्राप्त करें) |
| `rzc crate publish <crate> --lang <भाषा>` | अपनी स्थानीय मैपिंग रजिस्ट्री में प्रकाशित करें (पहले गुणवत्ता जाँच से गुज़रती हैं) |
| `rzc install <lsp\|toolchain>` | सहायक घटक स्थापित करें (भाषा सर्वर / अंतर्निहित आधिकारिक टूलचेन) |

पूरा संदर्भ: [परिशिष्ट D: rzc कमांड चीटशीट (चीनी)](tutorials/附录D：rzc命令速查.md).

## ✨ विशेषताएँ

### अपनी मातृभाषा में प्रोग्रामिंग

अपनी भाषा के कीवर्ड (`फंक्शन`, `मानो`, `यदि`, `मिलान`…) और अपनी भाषा की मानक लाइब्रेरी (`स्ट्रिंग`, `वेक्टर::नया()`, `उपयोग मानक::संग्रह::हैशमैप`) से पूर्ण प्रोग्राम लिखें। मैक्रो, लाइफ़टाइम, जेनेरिक्स और ट्रेट्स — सब समर्थित।

### 10 अंतर्निहित भाषाएँ

| भाषा    | एक्सटेंशन | भाषा      | एक्सटेंशन |
|---------|-----------|-----------|-----------|
| 中文    | `.zh`     | Español   | `.es`     |
| Deutsch | `.de`     | Français  | `.fr`     |
| 日本語  | `.ja`     | Português | `.pt`     |
| 한국어  | `.ko`     | العربية   | `.ar`     |
| Русский | `.ru`     | हिन्दी    | `.hi`     |

चूँकि Rust स्वयं अंग्रेज़ी में लिखी गई है, अंग्रेज़ी एक शिक्षण बोली नहीं है (पहचान मैपिंग का शैक्षिक मूल्य नहीं है); भाषा पैक निर्देशिका में पहचान मैपिंग और अंग्रेज़ी UI पाठ परिदृश्यों के लिए एक अलग `en` पहचान पैक (एक्सटेंशन `.en`) है। ऊपर की 10 प्राकृतिक भाषाएँ फ़ाइल एक्सटेंशन से स्वतः पहचानी जाती हैं और एक ही प्रोजेक्ट में साथ रह सकती हैं।

### शैक्षिक स्तर का निदान

- **दोहरा अनुवाद: कोड + संदेश**: rustc त्रुटि कोड, बिना कोड वाली lint चेतावनियाँ और सहायता वाक्यों तक कवरेज
- **स्थानीयकृत प्रकार नाम**: `std::fmt::Display` → `मानक::प्रारूप::प्रदर्शनीय`
- **💡 शैक्षिक संकेत**: हर त्रुटि में «आगे क्या करें» सुझाव शामिल; स्वामित्व त्रुटियों में 📌 स्थानांतरण/उधार कथा शामिल
- **निर्भरता मार्गदर्शन**: अनघोषित तृतीय-पक्ष crate का पता लगाकर `rzc add <crate>` सुझाता है

### पूर्ण IDE अनुभव (VS Code / Qoder एक्सटेंशन)

सिंटैक्स हाइलाइटिंग, स्मार्ट ऑटो-कम्प्लीशन, होवर दस्तावेज़, परिभाषा पर जाना, संदर्भ खोज, नाम बदलना, कोड फ़ॉर्मेटिंग, एक क्लिक में चलाएँ/जाँचें, पूर्ण-चौड़ाई विराम-चिह्न का स्वतः रूपांतरण, AI-सहायित अनुवाद।

### आपकी भाषा में तृतीय-पक्ष crates

`rzc mapping auto` स्थापित crates के सार्वजनिक API निकालकर आपकी भाषा में नाम (AI) बनाता है; उत्पादन मैपिंग `--target-version` से अपना आधार संस्करण स्थिर करती हैं (फ़ाइल हेडर में दर्ज); समुदाय मैपिंग `rzc mapping check` गुणवत्ता जाँच से गुज़रती हैं।

### यह «खिलौना भाषा» क्यों नहीं है

| | ठेठ खिलौना «मातृभाषा भाषाएँ» | rzc |
|---|---|---|
| कोड का रूप | नया आविष्कृत सिंटैक्स या स्यूडोकोड | मानक Rust के साथ पूर्ण समरूप — केवल पहचानकर्ता स्थानीयकृत |
| संकलन और निष्पादन | अपना इंटरप्रेटर / केवल ट्रांसपाइल | आधिकारिक rustc/cargo — वास्तविक संकलन व निष्पादन |
| पारिस्थितिकी | बंद या कटी-फटी | पूरा crates.io (`rzc add` + मातृभाषा मैपिंग) |
| त्रुटि अनुभव | शुद्ध अंग्रेज़ी या घर-गढ़े संकेत | अनूदित संदेश + त्रुटि कोड + शैक्षिक संकेत |
| निकलने की लागत | शून्य से पुनर्लेखन | `rzc eject` एक चरण में मानक Rust निर्यात करता है |

```text
आपकी भाषा का सोर्स कोड (.hi)
   │  शब्दावली अनुवाद → मॉड्यूल पथ प्रतिस्थापन → उपनाम प्रतिस्थापन   ← engine (भाषा-निरपेक्ष)
   ▼
मानक Rust कोड
   │  cargo build / run (आधिकारिक टूलचेन)
   ▼
JSON निदान → कोड/संदेश अनुवाद + प्रकार स्थानीयकरण + शैक्षिक संकेत → आपकी भाषा में आउटपुट
```

| `crates/engine/lang-packs` | 11 अंतर्निहित भाषा पैक (10 प्राकृतिक भाषाएँ + `en` पहचान पैक: कीवर्ड / मानक लाइब्रेरी / मॉड्यूल पथ / त्रुटि अनुवाद / UI पाठ) |
| `tools/vscode-extension`   | VS Code / Qoder एक्सटेंशन |
