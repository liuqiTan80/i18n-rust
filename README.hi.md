# rzc: बहुभाषी Rust शिक्षण बोली संकलक

अपनी मातृभाषा में Rust प्रोग्राम लिखें। rzc स्वचालित रूप से उन्हें मानक Rust में अनुवादित करता है, संकलित करता है और चलाता है — प्रोग्रामिंग शिक्षा अंग्रेजी याद करने से नहीं, तार्किक सोच में लौटती है।

```rust
// src/main.hi — हिन्दी Rust शिक्षण बोली
फंक्शन मुख्य() {
    मानो परिवर्तनीय संख्या = 10;
    संख्या = संख्या + 1;
    पंक्ति_छापो!("संख्या: {}", संख्या);
}
```

```bash
$ rzc run src/main.hi
संख्या: 11
```

## ✨ विशेषताएं

- **मातृभाषा प्रोग्रामिंग**: हिन्दी कीवर्ड्स (`फंक्शन`, `मानो`, `यदि`, `लौटाओ`…) से पूर्ण Rust प्रोग्राम लिखें
- **बहुभाषी नेटिव**: आर्किटेक्चर किसी भी प्राकृतिक भाषा का समर्थन करता है; 11 पैक अंतर्निर्मित, अन्य रिमोट से इंस्टॉल करने योग्य
- **स्वचालित एक्सटेंशन पहचान**: `.zh`, `.en`, `.de` स्वचालित रूप से संबंधित भाषा पैक से मेल खाते हैं
- **स्थानीयकृत त्रुटि निदान**: rustc आउटपुट अनुवादित 💡 शिक्षण संकेतों के साथ; स्वामित्व त्रुटियां JSON के माध्यम से दृश्यमान
- **स्वामित्व दृश्यांकन**: VS Code एक्सटेंशन वेरिएबल मूव (पीला), पुन: उपयोग (लाल) और लाइफटाइम (हरा) को हाइलाइट करता है
- **पूर्ण LSP समर्थन**: ऑटोप्लीट, होवर, परिभाषा पर जाएं, संदर्भ खोजें, नाम बदलें
- **मैक्रो ऑटोप्लीट**: `!` छोड़ा जा सकता है; ट्रांसपाइलिंग पर स्वचालित रूप से जुड़ता है
- **क्रमिक संक्रमण**: `eject` एक चरण में मानक Rust कोड निर्यात करता है
- **पूर्ण ट्यूटोरियल**: 24 अध्याय + 4 परिशिष्ट, पूर्ण शुरुआतकर्ता से व्यापक प्रोजेक्ट तक

## 📦 इंस्टॉलेशन

### crates.io के माध्यम से (अनुशंसित)

```bash
cargo install rzc
```

### स्रोत से बिल्ड करें

```bash
# अंतरराष्ट्रीय
git clone https://github.com/liuqiTan80/i18n-rust.git
cd i18n-rust
cargo build --release --workspace
```

## 🚀 त्वरित शुरुआत

```bash
rzc init मेरा-प्रोजेक्ट
cd मेरा-प्रोजेक्ट
rzc run src/main.hi
```

## 🛠️ कमांड

| कमांड | विवरण |
|-------|-------|
| `rzc init <नाम>` | नया प्रोजेक्ट बनाएं |
| `rzc run <फ़ाइल>` | `.hi` स्रोत अनुवादित करें और चलाएं |
| `rzc check <फ़ाइल>` | प्रकार जांच + शिक्षण निदान |
| `rzc eject <फ़ाइल>` | मानक `.rs` कोड में निर्यात करें |
| `rzc lang list` | इंस्टॉल किए गए भाषा पैक की सूची |
| `rzc lang install <स्रोत>` | भाषा पैक इंस्टॉल करें |
| `rzc lang remove <कोड>` | भाषा पैक हटाएं |
| `rzc mapping auto <crate>` | तृतीय-पक्ष crate मैपिंग स्वचालित रूप से बनाएं |

## ❓ सामान्य प्रश्न

**प्र: मैक्रो में विस्मयादिबोधक चिह्न क्यों छोड़ा जा सकता है?**
शुरुआतकारों की याददाश्त का बोझ कम करने के लिए। ट्रांसपाइलर स्वचालित रूप से `!` जोड़ता है।

**प्र: क्या मैं हिन्दी वेरिएबल नाम उपयोग कर सकता हूं?**
हां। `संख्या` और `मुख्य` मान्य पहचानकर्ता हैं। Rust Unicode पहचानकर्ताओं का समर्थन करता है।

**प्र: अन्य भाषा पैक कैसे इंस्टॉल करें?**
`rzc lang install ja` (रिमोट) या `rzc lang install ./डायरेक्टरी` (स्थानीय)।
