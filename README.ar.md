# rzc: مترجم لهجة Rust متعدد اللغات للتعليم

اكتب برامج Rust بلغتك الأم. يقوم rzc بترجمتها تلقائيًا إلى Rust القياسي ثم تجميعها وتشغيلها — يعود تعليم البرمجة إلى التفكير المنطقي، وليس حفظ الإنجليزية.

```rust
函数 主函数() {
    让 可变 数量 = 10;
    数量 = 数量 + 1;
    打印行!("数量是：{}", 数量);
}
```

```bash
$ rzc run src/main.zh
数量是：11
```

## ✨ المميزات

- **البرمجة باللغة الأم**: اكتب برامج Rust كاملة باستخدام كلمات مفتاحية صينية
- **متعدد اللغات بطبيعته**: البنية تدعم أي لغة طبيعية؛ حزمة صينية مدمجة، وأخرى يمكن تثبيتها عن بُعد
- **الكشف التلقائي بالامتداد**: `.zh` و `.ja` و `.ru` تُطابق تلقائيًا مع حزمة اللغة المناسبة
- **تشخيصات مترجمة**: أخطاء rustc مترجمة مع 💡 نصائح تعليمية؛ أخطاء الملكية مرئية عبر JSON
- **تصور الملكية**: إضافة VS Code تُميّز النقل (أصفر) وإعادة الاستخدام (أحمر) وأعمار المتغيرات (أخضر)
- **دعم LSP كامل**: إكمال تلقائي، تمرير، انتقال للتعاريف، بحث عن مراجع، إعادة تسمية
- **إكمال تلقائي للوحدات الكبيرة**: يمكن حذف `!`؛ يُضاف تلقائيًا عند الترجمة
- **انتقال تدريجي**: `eject` يصدّر كود Rust القياسي في خطوة واحدة
- **دروس كاملة**: 24 فصلًا + 4 ملاحق، من المبتدئ تمامًا إلى مشروع شامل

## 📦 التثبيت

### عبر crates.io (موصى به)

```bash
cargo install rzc
```

### من المصدر

```bash
# مرآة الصين
git clone https://gitcode.com/tan80/zrRust.git
# دولي
git clone https://github.com/liuqiTan80/i18n-rust.git
cd zrRust أو i18n-rust
cargo build --release --workspace
```

## 🚀 البداية السريعة

```bash
rzc init مشروعي
cd مشروعي
rzc run src/main.zh
```

## 🛠️ الأوامر

| الأمر | الوصف |
|-------|-------|
| `rzc init <اسم>` | إنشاء مشروع جديد |
| `rzc run <ملف>` | ترجمة وتشغيل كود `.zh` |
| `rzc check <ملف>` | فحص الأنواع مع تشخيصات تعليمية |
| `rzc eject <ملف>` | تصدير إلى كود `.rs` قياسي |
| `rzc lang list` | قائمة حزم اللغات المثبتة |
| `rzc lang install <مصدر>` | تثبيت حزمة لغة |
| `rzc lang remove <رمز>` | إزالة حزمة لغة |
| `rzc mapping auto <crate>` | إنشاء تعيينات تلقائية لمكتبات الطرف الثالث |

## ❓ الأسئلة الشائعة

**س: لماذا يمكن حذف علامة التعجب من الوحدات الكبيرة؟**
لتقليل الحفظ على المبتدئين. المترجم يضيف `!` تلقائيًا.

**س: هل يمكنني استخدام أسماء متغيرات صينية؟**
نعم. Rust يدعم المعرفات Unicode.

**س: كيف أثبت حزم لغات أخرى؟**
`rzc lang install 日本語` (عن بُعد) أو `rzc lang install ./مجلد` (محلي).
