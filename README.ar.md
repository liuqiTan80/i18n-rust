# rzc: مترجم لهجة رست التعليمية متعدد اللغات

> 🌍 **اكتب Rust بلغتك الأم.** · 10 لغات · Rust حقيقي وسلسلة أدوات حقيقية · تخرّج متى شئت عبر `rzc eject`

**rzc مترجم متعدد اللغات للهجات رست**: تكتب الكود بلغتك الأم، فيترجمه rzc فوريًا إلى رست القياسية، وتجمّعه وتشغّله سلسلة الأدوات الرسمية، وتعود كل تشخيصات الأخطاء مترجمة إلى لغتك مع نصائح تعليمية. تعلّم البرمجة، لا الإنجليزية.

- 🌍 **ليس شبه كود**: الكود بلغتك الأم متماثل تمامًا مع رست القياسية — التجميع والتنفيذ والتبعيات والمنظومة حقيقية 100%
- 🎓 **مصمم للمبتدئين**: رسائل الخطأ تتحول إلى توجيه «ما الذي تفعله بعد ذلك» بدل جدار من الإنجليزية
- 🚪 **تخرّج متى شئت**: `rzc eject` يصدّر رست القياسية في خطوة واحدة — بلا قيود، متوافق تمامًا مع المنظومة

```rust
// src/main.ar — لهجة رست التعليمية بالعربية
دالة رئيسي() {
    دع متغير عدد = 10;
    عدد = عدد + 1;
    اطبع_سطرا!("العدد: {}", عدد);
}
```

```bash
$ rzc run src/main.ar
العدد: 11
```

لا مشكلة في الخطأ — فالرسائل أيضًا بلغتك:

```
خطأ[E0384]: لا يمكن الإسناد مرتين إلى المتغير غير القابل للتغيير `عدد`
  --> src/main.ar:3:5
💡 إذا كنت بحاجة إلى تغيير قيمة متغير، أعلنه بـ `دع متغير`.
```

يعمل البرنامج نفسه في اللهجات العشر المدمجة — مثلًا بالصينية (`函数 主函数()`, `打印行!`) أو اليابانية (`関数 主関数()`, `表示行!`). رست القياسية (`fn main()`) مقبولة دائمًا كما هي.

## 📦 التثبيت

خياران: **الخيار 1 — التثبيت من crates.io** (موصى به، لمعظم المستخدمين)؛ **الخيار 2 — البناء من المصدر** (أحدث نسخة تطويرية أو البناء المحلي بعد تعديل rzc).

**الخيار 1: التثبيت من crates.io (موصى به)** — منشور على crates.io؛ مع وجود أدوات رست يكفي أمر واحد:

```bash
cargo install rzc        # يجلب من crates.io ويبني محليًا (1–3 دقائق)
rzc --version            # ظهور رقم الإصدار يعني النجاح
rzc init مشروعي && cd مشروعي && rzc run src/main.ar
```

> حزم اللغات مدمجة — لا حاجة لإعداد إضافي. صفحة الحزمة: <https://crates.io/crates/rzc>؛ الترقية: `cargo install rzc --force`. لا تتوفر أدوات رست بعد؟ راجع «1.» أدناه.

**الخيار 2: البناء من المصدر (للمطورين)** — لاستخدام أحدث نسخة تطويرية أو البناء بعد تعديل rzc. **أقصر مسار** (مع وجود أدوات رست — أربعة أوامر حتى أول برنامج):

```bash
git clone https://github.com/liuqiTan80/i18n-rust && cd i18n-rust
cargo build --release --workspace   # حوالي 1–3 دقائق
cargo install --path crates/cli     # يجعل rzc متاحًا عالميًا (أو استخدم ./target/release/rzc مباشرة)
rzc init مشروعي && cd مشروعي && rzc run src/main.ar
```

الخطوات الكاملة للخيار 2 أدناه (المتطلبات ← البناء ← التحقق)؛ «1.» مشترك بين الخيارين.

### المتطلبات الأساسية

| الأداة | الغرض | مطلوبة؟ |
|---|---|---|
| **أدوات رست** (rustc + cargo) | بناء rzc نفسه | ✅ نعم |
| **git** | الحصول على الكود المصدري | ✅ نعم (أو تحميل ZIP) |
| **الإنترنت** | تنزيل التبعيات عند البناء الأول | ✅ نعم (المرة الأولى) |
| **Node.js 18+ و npm** | بناء إضافة VS Code | اختياري (لبيئة IDE فقط) |
| **rust-analyzer** | خلفية الإكمال/التشخيص في IDE | اختياري (لبيئة IDE فقط) |

### 1. تثبيت أدوات رست

الطريقة الموصى بها هي [rustup](https://rustup.rs) (يثبّت rustc و cargo و rustup دفعة واحدة).

- **Linux / macOS** (في الطرفية):

  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```

  ثم نفّذ `source "$HOME/.cargo/env"` (أو أعد فتح الطرفية).

- **Windows**: حمّل [rustup-init.exe](https://rustup.rs) واتبع المعالج (أو نفّذ `winget install --id Rustlang.Rustup` في PowerShell).

تحقق (بعد إعادة فتح الطرفية):

```bash
rustc --version   # مثل: rustc 1.98.0
cargo --version
```

### 2. الحصول على المصدر والبناء

```bash
git clone https://github.com/liuqiTan80/i18n-rust.git
cd i18n-rust
cargo build --release --workspace
./target/release/rzc --version
```

البناء الأول ينزّل التبعيات ويجمّع كل المكونات (1–3 دقائق). النواتج:

- `target/release/rzc` — أداة سطر الأوامر
- `target/release/i18n-rust-lsp` — خادم اللغة (خلفية إضافة VS Code)

### 3. (اختياري) جعل rzc متاحًا عالميًا

```bash
cargo install --path crates/cli   # بناء محلي وتثبيت إلى ~/.cargo/bin
```

### 4. (اختياري) تثبيت rust-analyzer لميزات IDE

```bash
rzc install toolchain --ra-only --force
```

يُثبَّت rust-analyzer المستقل الرسمي في `~/.rz/toolchain`؛ ويفضّله rzc وخادم اللغة تلقائيًا.

### 5. (اختياري) بناء إضافة VS Code

يتطلب Node.js 18+ و npm (من [nodejs.org](https://nodejs.org)):

```bash
cd tools/vscode-extension
npm ci
npm run package    # ينتج i18n-rust-<الإصدار>.vsix
```

ثبّت ملف `.vsix` عبر «Install from VSIX...» في VS Code — ستحصل على إبراز الصيغة والإكمال الذكي والتشخيصات والتمرير وتصور الملكية؛ خادم اللغة يوفره `rzc install lsp` (يحدد موقع الأدوات المدمجة تلقائيًا).

### الإعداد الكامل (أمر واحد لكل مكوّن)

```bash
rzc install lsp          # خادم اللغة (خلفية الإكمال/التشخيص/التمرير في VS Code)
rzc install toolchain    # سلسلة الأدوات الرسمية المدمجة (rustc/cargo/rust-analyzer مستقلة في ~/.rz/toolchain)
rzc doctor               # حالة بيئة سلسلة الأدوات (المدمجة / PATH / مقارنة الإصدارات)
```

بعد التثبيت، يفضّل rzc وخادم اللغة تلقائيًا سلسلة الأدوات المدمجة؛ والمشاريع أحادية الملف تستدعي rustc مباشرة دون فهرس cargo.

### متغيرات البيئة (اختيارية، غالبًا غير ضرورية)

| المتغير | الغرض |
|---|---|
| `RZ_LANG_DIR` | دليل حزم اللغات (الافتراضي: الحزم المدمجة) |
| `RUST_ANALYZER_PATH` | مسار rust-analyzer (عند فشل الاكتشاف التلقائي) |

إعداد VS Code ‏`i18n-rust.serverPath` يحدد صراحةً مسار ملف LSP التنفيذي (يُستخدم عند فشل الاكتشاف التلقائي).

### ترقية مكوّن معيّن من سلسلة الأدوات

| الحالة | الأمر |
|---|---|
| ترقية rustc/cargo (مثلًا 1.98 → 1.99) | `rzc install toolchain --version 1.99.0 --force` |
| ترقية rust-analyzer فقط (دون إعادة تنزيل 300MB) | `rzc install toolchain --ra-tag <وسم-البيانات> --ra-only --force` |
| عرض الإصدارات والحالة الحالية | `rzc doctor` |

### تغيير المحرر (VSCodium / Cursor وغيرهما من عائلة VS Code)

إضافة i18n-rust ‏(.vsix) متوافقة مع كل المحررات المبنية على VS Code؛ وrzc وخادم اللغة وسلسلة الأدوات مستقلة عن المحرر:

1. في المحرر الجديد: الإضافات → «Install from VSIX» → اختر `i18n-rust-<الإصدار>.vsix`;
2. اربط المكونات في المواقع القياسية (مع وجود rzc مبنيًا):
   ```bash
   rzc install lsp        # خادم اللغة → ~/.cargo/bin
   rzc install toolchain  # سلسلة الأدوات المدمجة → ~/.rz/toolchain (عبر الإنترنت؛ أو انسخها من حزمة موزّع دون اتصال)
   ```
3. افتح ملف `.ar` وانتهى الأمر (تجد الإضافة الخادم وسلسلة الأدوات تلقائيًا؛ ويمكن تجاوز ذلك عبر `RUST_ANALYZER_PATH` أو إعداد `i18n-rust.serverPath`).

### للموزّعين: حزمة إصدار دون اتصال (توزيع صفّي)

يتضمن المستودع سكربت تغليف بأمر واحد (بناء محلي، وحزمة للمنصة الحالية، لاستخدامها في Releases / مشاركة الملفات):

| المنصة | الأمر | الناتج |
|---|---|---|
| Linux / macOS | `./release-offline.sh` | `release/rzc-<الإصدار>-linux/macos-<المعمارية>.tar.gz` |
| Windows (PowerShell) | `.\release-offline.ps1` | `release/rzc-<الإصدار>-windows-x86_64.zip` |

المتطلب المسبق: بناء release (الخطوة 2 أعلاه) وتشغيل `rzc install toolchain --ra-only --force` مرة واحدة عبر الإنترنت (ينسخ السكربت rust-analyzer الخاص بالمنصة إلى الحزمة).

يكتشف السكربت المنصة تلقائيًا (Linux / Darwin / Windows)؛ وتحتوي الحزمة على rzc و i18n-rust-lsp و rust-analyzer وحزم اللغات الـ 11 المدمجة (10 لغات طبيعية + حزمة الهوية `en`) والبرنامج التعليمي — فك الضغط واستخدم مباشرة (التفاصيل في الملحق D.5 من البرنامج التعليمي).

## 🚀بدء سريع

```bash
rzc init مشروعي        # إنشاء هيكل مشروع جاهز للتشغيل (Cargo.toml + src/main.ar)
cd مشروعي
rzc run src/main.ar    # ترجمة → تجميع → تشغيل
```

بثلاث خطوات، يعمل أول برنامج رست لك بلغتك الأم.

## 🛠️ الأوامر

| الأمر | الوصف |
|------------------------------------|------------------------------------------------------|
| `rzc init <الاسم>` | إنشاء مشروع (إصدار سلسلة الأدوات مثبّت محليًا؛ جاهز للـ IDE) |
| `rzc run <ملف>` | ترجمة وتشغيل؛ التحذيرات/الأخطاء/تقدم البناء بلغتك |
| `rzc check <ملف>` | فحص الأنواع مع تشخيص تعليمي مترجم |
| `rzc eject <ملف>` | تصدير إلى كود رست القياسي (انتقال تدريجي) |
| `rzc transpile <ملف>` | ترجمة فقط — رست القياسية على المخرج القياسي |
| `rzc cheat <لغة>` | جدول مرجعي لغة ↔ رست (`--markdown` للتضمين في المستندات) |
| `rzc add <crate>[@إصدار]` | إضافة تبعية (يغلّف `cargo add` مع تلميحات التعيين بلغتك) |
| `rzc doctor` | تشخيص بيئة سلسلة الأدوات (المدمجة / PATH / مقارنة الإصدارات) |
| `rzc lang list` | عرض حزم اللغات المثبتة |
| `rzc lang install <رمز/دليل>` | تثبيت حزمة لغة (سجل بعيد أو دليل محلي) |
| `rzc lang search [كلمة]` | البحث عن حزم لغات بعيدة قابلة للتثبيت |
| `rzc lang remove <رمز>` | إزالة حزمة لغة مثبتة من المستخدم |
| `rzc mapping auto <crate> [--target-version <إصدار>]` | توليد تعيينات بلغتك لمكتبة خارجية تلقائيًا (ذكاء اصطناعي/قواعد)؛ تثبيت إصدار الأساس عبر `--target-version` |
| `rzc mapping check [هدف]` | التحقق من جودة التعيينات (مفاتيح مكررة / تعارض كلمات مفتاحية / تعارض بين الملفات / أقسام إلزامية) |
| `rzc mapping coverage [--lang <لغة>]` | قياس تغطية حزمة اللغة بكود حقيقي؛ سرد التعيينات الناقصة (شغّله من جذر المستودع) |
| `rzc mapping scaffold <مصدر> <هدف>` | توليد هيكل ترجمة للغة جديدة؛ `--provider deepseek` للترجمة بالذكاء الاصطناعي |
| `rzc crate search [كلمة]` | البحث في تعيينات المكتبات الخارجية التي شاركها المجتمع (السجل) |
| `rzc crate install <crate> --lang <لغة>` | تثبيت تعيين خارجي من السجل في حزمة اللغة العامة |
| `rzc crate list` | سرد تعيينات المجتمع المثبتة |
| `rzc crate remove <crate> --lang <لغة>` | إزالة تعيين مجتمعي مثبت |
| `rzc crate update` | إعادة تنزيل كل التعيينات المثبتة وفق البيان (الحصول على التحديثات) |
| `rzc crate publish <crate> --lang <لغة>` | نشر تعييناتك المحلية إلى السجل (يمر أولًا بفحص الجودة) |
| `rzc install <lsp\|toolchain>` | تثبيت مكونات مساعدة (خادم اللغة / سلسلة الأدوات الرسمية المدمجة) |

مرجع كامل: [الملحق D: جدول أوامر rzc السريع (بالصينية)](tutorials/附录D：rzc命令速查.md).

## ✨ الميزات

### البرمجة بلغتك الأم

اكتب برامج كاملة بكلمات مفتاحية بلغتك (`دالة`, `دع`, `إذا`, `طابق`…) ومكتبة قياسية بلغتك (`سلسلة`, `مصفوفة::جديد()`, `استخدم قياسي::مجموعات::قاموس`). وحدات الماكرو وأعمار المراجع والأنواع العامة والسمات — كلها مدعومة.

### 10 لغات مدمجة

| اللغة   | الامتداد  | اللغة     | الامتداد |
|---------|-----------|-----------|----------|
| 中文    | `.zh`     | Español   | `.es`    |
| Deutsch | `.de`     | Français  | `.fr`    |
| 日本語  | `.ja`     | Português | `.pt`    |
| 한국어  | `.ko`     | العربية   | `.ar`    |
| Русский | `.ru`     | हिन्दी    | `.hi`    |

لأن رست نفسها مكتوبة بالإنجليزية، فالإنجليزية ليست لهجة تعليمية (التعيين المطابق بلا قيمة تعليمية)؛ توجد في دليل حزم اللغات حزمة هوية `en` منفصلة (امتداد `.en`) لسيناريوهات التعيين المطابق ونصوص الواجهة الإنجليزية. اللغات الطبيعية العشر أعلاه تُكتشف تلقائيًا بامتداد الملف ويمكن أن تتعايش في المشروع نفسه.

### تشخيص بمستوى تعليمي

- **ترجمة مزدوجة: الرموز + الرسائل**: تغطي رموز أخطاء rustc وتحذيرات lint بلا رموز وجمل المساعدة
- **أسماء أنواع مترجمة**: `std::fmt::Display` → `قياسي::تنسيق::قابل_للعرض`
- **💡 تلميحات تعليمية**: كل خطأ يتضمن اقتراح «ما الذي تفعله بعد ذلك»؛ وأخطاء الملكية تتضمن سرد 📌 للنقل/الاستعارة
- **توجيه التبعيات**: يكتشف مكتبات خارجية غير معلنة ويقترح `rzc add <crate>`

### تجربة IDE كاملة (إضافة VS Code / Qoder)

إبراز الصيغة، إكمال ذكي، توثيق عند التمرير، الانتقال إلى التعريف، البحث عن المراجع، إعادة التسمية، تنسيق الكود، تشغيل/فحص بنقرة واحدة، تحويل تلقائي لعلامات الترقيم كاملة العرض، ترجمة بمساعدة الذكاء الاصطناعي.

### مكتبات خارجية بلغتك الأم

يستخرج `rzc mapping auto` الواجهات العامة للمكتبات المثبتة ويولّد أسماء بلغتك (ذكاء اصطناعي)؛ وتعيينات الإنتاج تثبّت إصدار أساسها بـ `--target-version` (يُسجَّل في ترويسة الملف)؛ وتعيينات المجتمع تمر بفحص الجودة `rzc mapping check`.

### لماذا ليست «لغة ألعاب»

| | «اللغات الأم» اللعبية النموذجية | rzc |
|---|---|---|
| شكل الكود | صيغة مبتكرة أو شبه كود | مماثل تمامًا لرست القياسية — تُترجم المعرّفات فقط |
| الترجمة والتنفيذ | مفسّر خاص / ترجمة مصدرية فقط | rustc/cargo الرسميان — ترجمة وتنفيذ حقيقيان |
| المنظومة | مغلقة أو مقطوعة | كامل crates.io ‏(`rzc add` + تعيينات بلغتك) |
| تجربة الأخطاء | إنجليزية صرفة أو تلميحات محلية الصنع | رسائل مترجمة + رموز أخطاء + تلميحات تعليمية |
| كلفة الخروج | إعادة كتابة من الصفر | `rzc eject` يصدّر رست القياسية في خطوة واحدة |

## 📖البرنامج التعليمي

برنامج تعليمي كامل بالصينية للمبتدئين: **26 فصلًا + مسرد مصطلحات + 5 ملاحق** — انظر [tutorials/](tutorials/). من «مرحبًا بالعالم» إلى الملكية والإغلاقات وasync ووحدات الماكرو، حتى المشروع النهائي التجميعي؛ وكل الأمثلة مكتوبة برست الصينية.

🌐 **قراءة عبر الإنترنت**: [الوثائق على الإنترنت](https://liuqiTan80.github.io/i18n-rust/) (mdBook، 4 لغات مع محوّل في الشريط العلوي؛ معاينة محلية عبر `make site-serve`).

**ترجمات جارية**: الإنجليزية (المقدمة، الفصول 1-13، الملحق D، 15/33)، اليابانية (الفصول 1-11، 11/33)، الروسية (الفصول 1-15، 15/33) — التقدم والدفعة القادمة في [translation-status.md](docs/translation-status.md). الترجمات العربية مرحّب بها — انظر «المساهمة».

> جودة البرنامج التعليمي محمية بالـ CI ([tools/verify-tutorials.py](tools/verify-tutorials.py)): يجب أن يُترجم كل كتلة كود، ويجب أن تُخرج أمثلة الأخطاء رمز الخطأ المذكور في التعليق (`// 预期错误: EXXXX`). التحقق محليًا بعد التعديل: `make tutorials` (بالصينية) أو `make tutorials-all` (الإنجليزية/اليابانية/الروسية).

> الأسئلة الشائعة ومسار التعلم: [الملحق E (بالصينية)](tutorials/附录E：常见问题、迁移指南与学习路线.md).

## 🏗️ بنية المشروع وكيف يعمل

```text
كود المصدر بلغتك الأم (.ar)
   │  ترجمة معجمية → استبدال مسارات الوحدات → استبدال الأسماء المستعارة   ← engine (مستقل عن اللغة)
   ▼
كود رست القياسي
   │  cargo build / run (سلسلة الأدوات الرسمية)
   ▼
تشخيصات JSON → ترجمة الرموز/الرسائل + توطين الأنواع + تلميحات تعليمية → مخرجات بلغتك
```

| الدليل                     | المسؤولية                                                                |
|----------------------------|---------------------------------------------------------------------------------|
| `crates/engine`            | المحرك الأساسي المستقل عن اللغة: خط أنابيب الترجمة، إدارة التعيينات، ترجمة التشخيصات، الذاكرة المؤقتة التراكمية، فحوص أمان Unicode |
| `crates/cli`               | أداة سطر الأوامر `rzc` |
| `crates/lsp`               | `i18n-rust-lsp`: يوكّل خادم اللغة الرسمي (rust-analyzer) ويترجم المواقع والتشخيصات في الاتجاهين |
| `crates/engine/lang-packs` | 11 حزمة لغات مدمجة (10 لغات طبيعية + حزمة الهوية `en`: كلمات مفتاحية / مكتبة قياسية / مسارات وحدات / ترجمات أخطاء / نصوص واجهة) |
| `tools/vscode-extension`   | إضافة VS Code / Qoder |
| `tools`                    | بوابات وسكربتات البناء: التحقق من البرنامج التعليمي، انحدار المقاييس، تجميع موقع الوثائق ([tools/README.md](tools/README.md)) |
| `tutorials`                | برنامج تعليمي صيني من 26 فصلًا مع ملاحق (ترجمات en/ja/ru جارية) |
| `book`                     | مصدر تجميع موقع الوثائق (mdBook، [book/README.md](book/README.md)) |
| `docs`                     | وثائق مرجعية وتطويرية، [خريطة المشروع](docs/project-map.md); والتشغيل وخارطة الطريق في [docs/strategy/](docs/strategy/README.md) |

**مبدأ التصميم**: المحرك لا يثبّت أي لغة بعينها — إضافة لغة طبيعية = إضافة دليل حزمة لغة (يُضمَّن تلقائيًا عند البناء). لنقل هذا النموذج إلى لغات برمجة أخرى (مثلًا بايثون بالصينية)، انظر [مخطط إطار اللهجات](docs/dialect-framework-blueprint.md).
