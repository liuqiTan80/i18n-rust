# rzc：多言語 Rust 教育方言コンパイラ

母語で Rust プログラムを書きましょう。rzc が自動的に標準 Rust に翻訳し、コンパイル・実行します。プログラミング教育は論理的思考に戻るべきで、英語の暗記ではありません。

```rust
// src/main.ja — 日本語 Rust 教育方言
関数 主関数() {
    宣言 可変 数 = 10;
    数 = 数 + 1;
    表示行!("数は：{}", 数);
}
```

```bash
$ rzc run src/main.ja
数は：11
```

## ✨ 機能

- **母語プログラミング**：日本語キーワード（`関数`、`宣言`、`もし`、`返す`…）で完全な Rust プログラムを作成
- **多言語ネイティブ**：アーキテクチャはあらゆる自然言語をネイティブサポート。11 言語パック内蔵、他言語はリモートインストール可能
- **拡張子自動判定**：`.zh`、`.en`、`.de` などが対応する言語パックに自動マッチ
- **ローカライズエラー診断**：rustc 出力を翻訳し 💡 教育ヒントを付加。所有権エラーは構造化 JSON で可視化
- **所有権の可視化**：VS Code 拡張で変数の移動（黄）、再利用（赤）、ライフタイム（緑）をハイライト
- **完全 LSP サポート**：補完、ホバー、定義ジャンプ、参照検索、リネーム、コードアクション
- **マクロ自動補完**：マクロ呼び出しの `!` を省略可能。トランスパイル時に自動補完
- **段階的移行**：`eject` で標準 Rust コードをワンステップエクスポート
- **完全チュートリアル**：24 章 + 4 付録、初心者から総合実戦まで

## 📦 インストール

### crates.io 経由（推奨）

```bash
cargo install rzc
```

Rust ツールチェーン（rustup の stable）が必要です。

### ソースからビルド

```bash
# 国際版
git clone https://github.com/liuqiTan80/i18n-rust.git

cd または i18n-rust
cargo build --release --workspace
```

## 🚀 クイックスタート

```bash
rzc init my-project
cd my-project
rzc run src/main.ja
```

## 🛠️ コマンド一覧

| コマンド | 説明 |
|---------|------|
| `rzc init <名前>` | 新規プロジェクト作成 |
| `rzc run <ファイル>` | `.ja` ソースを翻訳・実行 |
| `rzc check <ファイル>` | 型チェック＋教育診断出力 |
| `rzc eject <ファイル>` | 標準 `.rs` コードにエクスポート |
| `rzc lang list` | インストール済み言語パック一覧 |
| `rzc lang install <ソース>` | 言語パックをインストール |
| `rzc lang remove <コード>` | ユーザー言語パックを削除 |
| `rzc mapping auto <crate名>` | サードパーティマッピング自動生成 |

## 🌍 言語パック管理

rzc は 11 言語パックを内蔵しています（日本語、英語、中国語、ドイツ語、ロシア語、スペイン語、フランス語、ポルトガル語、韓国語、アラビア語、ヒンディー語。各パックにエラーコード翻訳とローカライズされた教育ヒント）。

- **自動判定**：`main.zh`/`main.en`/`main.de` が対応する内蔵パックを自動ロード。エラー表示はファイルの言語にローカライズ
- **リモートインストール**：GitCode からダウンロード、失敗時 GitHub にフォールバック
- **カスタムソース**：`RZ_LANG_REPO` 環境変数を設定
- **ローカルインストール**：`rzc lang install ./言語パックディレクトリ`

## ❓ FAQ

**Q：マクロの感嘆号を省略できるのはなぜ？**
初心者の暗記負担を減らすため。トランスパイラが自動補完し、標準 Rust エクスポート時に復元します。

**Q：日本語の変数名・関数名を使えますか？**
はい。`数` や `主関数` は有効な識別子です。Rust は Unicode 識別子をサポートしています。

**Q：他の言語パックのインストール方法は？**
`rzc lang install ja`（リモート）または `rzc lang install ./言語パック`（ローカル）。
